## 本文

### 公開からの 3 日間で何が変わったか

| 指標 | 公開時(2026-05-13) | 拡大後(2026-05-16) | 変化 |
|---|---|---|---|
| 収録・サイト掲載スキル数 | **3,862 件** | **10,160 件** | **+163%** |
| 全文ダウンロード可能(寛容ライセンス) | 1,336 件 | **7,066 件** | **+429%** |
| 日本語訳 description | 約 6,800 件 | **約 10,000 件**(配信全件) | +47% |
| 日本語訳 SKILL.md 本文 | (なし) | **10,076 件**(配信中の 99%) | 新規対応 |
| 対応カテゴリ | 12 | 13 | +1 |
| 月額運用コスト | 約 950 円 | **約 2,400 円** | +1,450 円 |

### 拡大の方法

ALSEL は Vercel Labs が運営する Agent Skills の最大ディレクトリ **skills.sh**(全世界 90,000 件超)を継続的に観測し、利用実績(インストール数)上位 10,000 件のメタデータをサイトマップ経由で取得しました。重複と低品質を除外した約 7,800 件を 1,412 個の GitHub リポジトリから個別取得し、Anthropic Claude(Sonnet 4.6 / Haiku 4.5)で日本語化したうえで Meilisearch に投入しています。さらにフォーク重複を内容ハッシュで検出し、同一スキルは canonical 1 件のみ表示するよう自動整理しました。

データ取得・翻訳のすべては自動化されており、今回の拡大全体に要した費用は **約 67 ドル(約 10,000 円)** 、API 呼び出しを含めた所要時間は **約 3 時間** でした。

### 主な機能アップデート

1. **本文 SKILL.md の日本語化**
   公開時は説明文(description)のみだった日本語化を、SKILL.md 全文にも拡大。サイト掲載中の 10,160 件のうち **10,076 件(88%)** が本文を日本語で読める状態になり、英語が苦手な開発者・事業者でもスキルの内部ロジックまで理解しやすくなりました。

2. **ZIP 一括ダウンロード対応**
   寛容ライセンスのスキルは、英語原本と日本語訳本文を **1 つの ZIP** にまとめて取得可能。`/api/skill/<slug>/zip` から直接取得できるため、IDE への取り込みもスムーズ。

3. **ライセンス自動ゲート**
   寛容ライセンス(MIT・Apache-2.0・BSD・ISC・CC0 等)のみ全文を配布し、それ以外(NOASSERTION・AGPL・GPL・Proprietary 等)は **プレビューと原本リポジトリへの誘導のみ** を表示。API エンドポイントも同一のロジックで保護(403 を返却)。

4. **スキル横断分類の精度向上**
   AI/開発・データ・DevOps・セキュリティ・EC マーケティングなど 13 カテゴリへ自動分類。サイトマップ・install 数ランクと統合された品質スコアで上位スキルを上に表示。

### ライセンス・著作権の取り扱い

すべての SKILL.md は **公開時点でリポジトリに明示されている寛容ライセンス** を再確認したうえで提供しています。確認できなかったもの・コピーレフト系・NOASSERTION 等は **プレビューのみ表示し、本文の配布は行いません**。/takedown フォーム(DMCA 対応)も従来通り稼働しています。

ALSEL は **「スキル本体の所有者はあくまで原作者」** という原則を貫いており、サイトはあくまでも日本語インデックスとして機能します。
