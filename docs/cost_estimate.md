## スケール時のコスト試算

5 万件 → 50 万件にスケールした場合:

| 項目 | 5 万件 | 50 万件 |
|------|--------|---------|
| Meilisearch RAM 要件 | 2GB | 4〜8GB |
| Hetzner サイズ | CX11 ($5) | CX31 ($16) |
| 月次翻訳量(増分10%) | 2,000 件 ($1.3) | 20,000 件 ($13) |
| **合計** | $6.3 | **$29 (4,350 円)** |

---

## コスト削減の余地

- Meilisearch を Cloudflare R2 + Lambda などで自前運用 → 〜$2/月
- Hetzner の代わりに Oracle Cloud Free Tier(永久無料、ただし可用性低)
- 翻訳を Haiku → DeepSeek にすると 1/10 程度
