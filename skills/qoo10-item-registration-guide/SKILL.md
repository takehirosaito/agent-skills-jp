# Qoo10 商品登録ガイド（QSM）

## 概要

Qoo10（QSM）の商品登録を、カテゴリ・商品名・オプション(SKU)・価格/在庫・画像・配送の各項目に分けて設計するスキル。Qoo10は若年層・コスメ/雑貨に強く、検索とメガ割が売上を左右する。商品名のキーワード設計とオプション構成、画像の見せ方を最初から整えることで、検索露出と転換率の取りこぼしを防ぐ。

## 最重要原則

**「商品名は検索される語を前方に／オプション(SKU)は購入導線が崩れない粒度で／価格はメガ割クーポン込みの見え方で設計／メイン画像は一覧で勝てる見せ方／配送設定を商品に正しく紐付け」**。Qoo10は商品名と画像の影響が大きい。オプションを増やしすぎると在庫管理と表示が煩雑になるため、売れ筋粒度に絞る。

## 知識ベース

登録項目の主要ブロック：

| 項目 | 設計ポイント |
|---|---|
| カテゴリ | 最適カテゴリ選定（誤カテゴリは露出減） |
| 商品名 | ブランド/主要属性/用途キーワードを前方配置。記号乱用・無関係語は避ける |
| オプション(SKU) | 色/サイズ/容量等。価格差・在庫を個別管理。粒度は売れ筋優先 |
| 価格/在庫 | 販売価格・参考価格、在庫数。メガ割の値引き後の見え方を意識 |
| 画像 | メイン画像は背景・主役・要点が一覧で伝わるもの。テキスト過多に注意 |
| 配送 | 配送方法・送料・発送目安の紐付け |

> 文字数上限・画像規定・入力欄の名称は仕様変更がある。確定は QSM/公式ヘルプで確認。

## 処理フロー

### Step 1：商材とターゲットの確認
- 商材、想定購買層、競合の見せ方、メガ割での値引き想定
不明時は「コスメ/雑貨・10〜20代中心・メガ割活用」を仮置きし明示。

### Step 2：カテゴリ選定
- 最適カテゴリと、その配下で見られる属性を確認。

### Step 3：商品名設計
- 検索語を前方に置いた商品名案を複数提示（字数併記）。スパム羅列は不可。

### Step 4：オプション(SKU)設計
- 色/サイズ/容量等のSKU構成を、在庫管理と購入導線の観点で適正粒度に設計。

### Step 5：価格・画像・配送
- メガ割後の見え方を踏まえた価格、メイン画像の方針、配送方法の紐付けを整理。

### Step 6：登録前チェック
- 必須項目・特商法・表現規制（コスメは薬機法）の確認。

## 出力フォーマット

```
# Qoo10 商品登録 設計：[商品]

## 0. 前提（商材/ターゲット・仮定）
## 1. カテゴリ選定
## 2. 商品名案（複数・字数・キーワード根拠）
## 3. オプション(SKU)構成表
   | オプション | 値 | 価格差 | 在庫管理 |
## 4. 価格（メガ割後の見え方）・在庫
## 5. メイン画像/追加画像の方針
## 6. 配送設定の紐付け
## 7. 登録前チェックリスト（必須項目/薬機法/特商法）
```

## 品質ゲート
- 商品名が検索語を活かし、スパム/無関係語が無いか
- オプション粒度が在庫管理と導線を壊さないか
- 価格がメガ割後の見え方で破綻しないか
- コスメ等の表現が薬機法に反していないか

## 注意事項
- 仕様（文字数・画像規定）は変動。確定は QSM/公式で確認。
- 化粧品・健康関連は効能の断定・誇大表現を避ける（薬機法・景表法）。
- 真贋・知財・規制商材の確認を行う。
