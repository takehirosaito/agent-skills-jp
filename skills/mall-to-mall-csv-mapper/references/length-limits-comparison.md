# 文字数・byte制限の比較

各モールの主要列の最大長を比較。**byte指定と文字数指定が混在**しているため要注意。

## 単位の前提

- 1byte = 半角英数字1文字、Shift_JISの半角カナ1文字
- 全角文字（漢字・かな・全角英数）：
  - SJIS：2byte
  - UTF-8：3byte（一部4byte）
- 「全角XX字」と書かれた場合、半角はXX×2字（合計バイト数は変動）

## 商品名

| モール | 制限 | 換算 |
|---|---|---|
| 楽天 | 255byte | SJIS：全角127字＋1byte／UTF-8：全角85字相当 |
| Amazon（一般） | 200字 / 推奨80字 | 全角文字数で計算 |
| Amazon（アパレル） | 130字 | カテゴリ別 |
| Amazon（カメラ） | 全角50字 | カテゴリ別 |
| Yahoo! | 全角75字 | 約150byte（SJIS） |
| Shopify | 255文字（柔軟） | SEOタイトルは別途60-70字推奨 |

→ **最短はYahoo!の全角75字**。他モール用の長い商品名はYahoo!で切り詰めが必要。

## 短文・キャッチコピー

| モール | 制限 |
|---|---|
| 楽天 キャッチコピー | 174byte（SJIS全角87字） |
| Amazon bullet_point1-5 | 各255byte／検索対象は先頭1,000byte |
| Yahoo! headline | 全角60字 |
| Shopify | 該当列なし（メタフィールド代用） |

→ 楽天キャッチコピー → Amazon bullet：1項目を5本に分割するのが定石。

## 説明文

| モール | 制限 | HTML |
|---|---|---|
| 楽天 PC用 | 10,240byte | 可（タグ制限あり） |
| 楽天 SP用 | 10,240byte | 可（PC用と別、禁止タグ厳しめ：div/script/iframe/form/input/style禁止） |
| Amazon product_description | 2,000字 | 不可（プレーンテキスト推奨、改行のみ） |
| Yahoo! caption | 全角5,000字 | 可 |

| Shopify Body (HTML) | 実質無制限 | 可（自由） |

→ 楽天 10,240byte → Amazon 2,000字 は大幅短縮が必要。HTMLも除去。

## 切り詰めの優先順位（実務）

文字数オーバー時の切り詰めポイント：

1. **商品名後半の補助情報**（型番・カラー・サイズ）から削る
2. **ブランド名／メーカー名の重複**を削る
3. **記号類**（【】★☆等）を削る
4. **絵文字**を削る
5. それでもダメなら**型番のみ残す**

逆に削ってはいけない要素：
- ブランド名（先頭）
- 商品の本質的機能（防水／コードレス／充電式 など）
- サイズ・容量（誤購入の原因）

## 文字数計算の落とし穴

- **絵文字は2-4文字としてカウントされる**（サロゲートペア）
- **半角カナはSJISで1byte、UTF-8で3byte**
- **改行コードもカウントされる**（CR+LFなら2byte）
- **HTMLタグもカウント対象**（モール仕様で異なる）

## まとめ：実務での扱い

1. **最短のモール（Yahoo!商品名75字）に合わせる**と全モール展開で安全
2. **Amazon product_description 2,000字／HTMLなし**が説明文の上限ルール
3. **キャッチコピーは174byte（楽天基準）で運用**しAmazon bulletに5分割
4. **商品コードは30字（ネクストエンジン基準）以内で半角英数のみ**
