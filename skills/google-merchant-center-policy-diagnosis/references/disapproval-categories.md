# GMC不承認カテゴリの詳細

GMCの不承認は大きく次の3カテゴリに分類される。具体的な分類はGoogleのヘルプメッセージで提示される。

---

## 1. 商品データの問題

### 1-1. 価格の不一致

- **症状**：フィードの価格と商品ページの価格が違う
- **典型原因**：セール価格の同期遅れ／税込・税抜の取り違え／送料込み・別の取り違え
- **修正**：フィードの自動更新間隔短縮、両方の価格を同期、税込で統一

### 1-2. 在庫の不一致

- **症状**：フィードで「in_stock」、商品ページで「在庫切れ」
- **典型原因**：在庫管理システムとフィードの同期遅れ／予約商品の扱い不明確
- **修正**：在庫API連携／予約は `preorder`、入荷待ちは `backorder`

### 1-3. GTIN欠落・誤り

- **症状**：GTIN必須カテゴリでGTIN未指定／チェックデジット不一致
- **修正**：GTINを取得（メーカー or GS1）、または `identifier_exists=no` で免除申請（自社オリジナル等）
- 詳細：`gtin-requirements.md`

### 1-4. 画像の問題

- **症状**：画像が荒い／背景が複雑／文字・ロゴ・透かしが入っている／配色がGMC基準と異なる
- **修正**：純白背景・商品占有率高め・テキスト/ロゴ無し・1000px以上

### 1-5. タイトル・説明の問題

- **症状**：プロモーション語（「セール」「最安」）／全大文字／繰返し／絵文字
- **修正**：商品名 + ブランド + 主要属性で構成、不要装飾を除去

### 1-6. カテゴリ・分類の誤り

- **症状**：`google_product_category` 未指定／カテゴリが商品と一致しない
- **修正**：Google分類体系に従う

## 2. ポリシー違反

### 2-1. 偽造品・模倣品

- **症状**：ブランド名を商品ページで使いながら正規品の証明なし
- **修正**：並行輸入品は明示、ブランド名の使用権限を確認、偽造品は出品停止

### 2-2. 医療機器・健康関連

- **症状**：薬機法的な効能訴求（化粧品で「シミに効く」等）、未承認医療機器（雑貨での効能訴求）
- **修正**：薬機法・景表法表現の修正（別スキル: `yakki-keihyo-expression-check`）

### 2-3. 制限商品（アルコール・タバコ・武器・成人向け）

- **症状**：禁止商品の出品／制限地域での配信
- **修正**：禁止商品は出品停止／制限商品は対象地域・年齢確認

### 2-4. 不正なビジネス慣行

- **症状**：偽の割引（実態のない「定価」設定）／ベイト&スイッチ（広告と異なる商品）／二重価格の根拠なし
- **修正**：景表法の二重価格8週間ルールに従う／実態のある価格設定

### 2-5. 個人を狙うコンテンツ

- **症状**：「あなたの体型を改善」「シニアの方へ」のような個人特性を直接ターゲット
- **修正**：商品の特徴ベースの記述に変更（「軽量タイプ」「省スペース」）

### 2-6. 法的問題のあるコンテンツ

- **症状**：著作権侵害／商標侵害／法令違反商品
- **修正**：権利関係の確認・取得

---

## 3. ランディングページ（LP）の問題

### 3-1. アクセス不可

- **症状**：404／500／タイムアウト／robots.txtでGoogle Botブロック
- **修正**：URL有効性確認、robots.txtでBot許可

### 3-2. SSL未対応

- **症状**：http:// のみ／自己署名証明書
- **修正**：https://対応、信頼できる認証局のSSL証明書

### 3-3. リダイレクト過多

- **症状**：複数のリダイレクトを経由して商品ページに到達／A/Bテストツールの介在
- **修正**：直接アクセス可能なURL、リダイレクトは1回まで

### 3-4. 連絡先情報不足

- **症状**：電話・メール・住所がLPで確認できない
- **修正**：フッターに連絡先を表示、特商法ページへの動線

### 3-5. 特商法・返品ポリシーの不備

- **症状**：特商法ページが無い／返品ポリシーが無い／動線が無い
- **修正**：両ページを整備、フッターからリンク

### 3-6. 不適切なコンテンツ

- **症状**：アダルト画像／暴力的表現／差別的表現
- **修正**：コンテンツ修正

### 3-7. 表示速度・モバイル対応

- **症状**：表示に時間がかかる／モバイルで表示崩れ
- **修正**：画像最適化、レスポンシブ対応、コアウェブバイタル改善

### 3-8. 自動再生メディア・ポップアップ

- **症状**：音声付き動画の自動再生／閉じられないポップアップ
- **修正**：自動再生停止、ポップアップに閉じるボタン

---

## 4. アカウントレベルの問題

### 4-1. アカウント停止

- **症状**：「Account suspended」の通知、全商品の配信停止
- **典型原因**：複数の不承認の累積／重大なポリシー違反（偽造品・成人向け等）
- **対応**：原因特定 → 全面修正 → 再審査依頼（数週間かかることも）

### 4-2. 警告

- **症状**：警告メッセージはあるが配信は継続中
- **対応**：警告対象を期限内に修正、放置するとアカウント停止に至る

### 4-3. 商品データの整合性問題（フィード全体）

- **症状**：フィード全体の質が低いと判定
- **対応**：必須属性の埋め込み率向上、GTIN網羅率向上、画像品質向上

## 5. メッセージから原因を絞り込む早見表

| メッセージのキーワード | 想定原因 | 第一の確認場所 |
|---|---|---|
| 価格／Price mismatch | フィード ↔ LP 価格不一致 | フィード価格属性とLP表示 |
| 在庫／Stock | フィード ↔ LP 在庫不一致 | フィード availability とLP表示 |
| 画像／Image | 画像品質・規格 | 画像URL・サイズ・背景 |
| GTIN／Identifier | GTIN欠落・誤り | フィード gtin / identifier_exists |
| 医療／Health／Medical | 健康・薬機法 | 商品ページの効能訴求 |
| 制限商品／Restricted | 制限商品該当 | 商品自体の出品可否 |
| ポリシー違反／Policy violation | 各種ポリシー | メッセージ詳細の確認 |
| 配送／Shipping | 配送情報不足 | フィード shipping 属性 |
| ランディングページ／Landing page | LP不備 | LPアクセス可否・内容 |
| 連絡先／Contact | 連絡先情報不足 | LPフッター・特商法 |
| 利用規約／Terms | 返品・特商法不備 | 返品ポリシー・特商法 |

---

## 6. 再審査依頼の流れ

1. 不承認の **原因をすべて特定**（個別商品・アカウント全体）
2. **修正を完了** してから再審査依頼
3. Merchant Center の「アカウントの問題」「商品の問題」から「再審査をリクエスト」
4. 再審査は通常 **3-7営業日**（複雑な場合は数週間）
5. **同じ問題で再度不承認になると審査が遅くなる** ので、初回の修正で完全に対応

### 再審査前の自己チェック
- [ ] 全商品でフィード ↔ LP整合
- [ ] 特商法・返品ポリシーが整備されフッターから動線
- [ ] 連絡先・SSL・モバイル対応
- [ ] 制限商品・薬機法表現の修正完了
- [ ] 必要なら専門家確認済み
