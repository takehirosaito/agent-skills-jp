# 楽天 文字数仕様と配置原則

## CSV登録の文字数仕様

| 項目 | byte | 全角換算 | 備考 |
|---|---|---|---|
| 商品管理番号 | 32 | - | 半角英数のみ |
| 商品名 | 255 | 約127字 | 商品ページタイトルに使われる |
| キャッチコピー | 174 | 約87字 | 商品名直下に表示 |
| PC用商品説明文 | 10,240 | 約5,120字 | HTML可（一部タグ制限） |
| SP用商品説明文 | 10,240 | 約5,120字 | div/script/iframe/form/input/styleは禁止 |
| ジャンルID | 6 | - | 半角数字 |
| カタログID | 30 | - | JAN/EAN/ISBN/UPC |
| タグID | 最大32タグ |  |  |

## 文字コード

- 規定：Shift_JIS（CP932）
- 改行：CR+LF
- BOMなし

### Shift_JISで化ける／弾かれる文字

- 一部の絵文字
- ㈱ など機種依存文字（環境次第でOKだが避けるのが無難）
- 一部の中国語簡体字・繁体字
- 機種依存記号（①②③など）

→ 商品名・キャッチコピーには **基本的な日本語＋ASCII＋一般記号** に限定。

## byte数の数え方

| 文字 | byte |
|---|---|
| 半角英数（A、1） | 1 |
| 半角記号（!@#$） | 1 |
| 全角ひらがな・カタカナ・漢字 | 2 |
| 全角記号（、。「」） | 2 |
| 一部の絵文字 | 4 |
| サロゲートペア文字 | 4 |

簡易計算：商品名は **全角127字 ≒ 半角255文字**。

### Pythonでのbyte数確認例

```python
text = "【母の日 ギフト】スキンケアセット 50代 60代 母 プレゼント"
print(len(text.encode('shift_jis')))  # 実byte数
```

## 配置原則（楽天SEO）

### 商品名 先頭20文字（最重要ゾーン）

- スマホ商品一覧では商品名が **先頭20文字程度で省略** されて表示される
- 「【】」等の装飾で先頭を消費しすぎないこと
- 主要検索語（指名語）を必ずここに

### 商品名 先頭20〜80文字

- 用途・状況・特徴
- 「ギフト」「プレゼント」等の贈答語（該当時）

### 商品名 後半

- 「送料無料」「あす楽」「ラッピング無料」等の特典訴求
- 季節キーワード（春夏／秋冬）
- 「お得」「人気」等のソフト訴求

### キャッチコピー（174byte）

- ベネフィット・特典・送料・レビュー数を簡潔に
- 商品名と重複しすぎない
- 値引き・期間限定訴求

### PC用説明文

- 段組みOK（一部HTMLタグ）
- 比較表・FAQ・素材詳細

### SP用説明文

- 禁止タグ：div、script、iframe、form、input、style、外部CSS／JS
- 許可されるタグは限定的（p、br、a、img、table 等の基本タグ）
- 画像10枚（一部20枚）

## キーワード配置の頻度

- 同じ語の繰り返しは **3〜4回まで** が目安
- 5回以上連続するとキーワードスタッフィング扱いの可能性
- 「○○ ○○ ○○ ○○ ○○」のような並び替えも不自然になる

## NG装飾と推奨表現

| NG装飾 | 理由 |
|---|---|
| ◆◇★☆※ の過剰使用 | 楽天独自審査で警告対象になることあり |
| !!!! 連続感嘆符 | 同上 |
| 全角英数（A→Ａ等） | 検索一致しない |
| 機種依存文字（㈱、①②） | 文字化けリスク |
| 半角カナ | 視認性低下、規定外 |

## 検索流入の優先順位（楽天タンタンサーチ）

1. 商品名に含まれるか
2. キャッチコピーに含まれるか
3. 商品ジャンル・タグID
4. 説明文（補助的、影響度低い）

→ **商品名・キャッチコピーが最重要**。説明文に語を入れても流入には限界があるが、Google検索からの流入には効く。
