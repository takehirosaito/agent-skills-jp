# 楽天キーワードマップ作成

## 概要

楽天市場の検索流入を最大化するには、「指名語」「用途語」「状況・属性語」「季節・贈答語」「類義語」を体系的にマップ化し、商品名・キャッチコピー・説明文・タグID・レビュー誘導に配分する必要があります。本スキルは商品ジャンルと商品プロファイルから、これらの軸をジャンル別頻出語と組み合わせてマップ化します。

楽天独自のbyte制約（商品名255byte／全角127字、キャッチコピー174byte／全角87字、PC/SP説明文10,240byte）に収まる配置案までセットで出します。

## 最重要原則

**「指名語×用途語×状況属性語×季節贈答語×類義語の5軸で並べ、商品名にビッグKW、キャッチコピーに状況属性KW、説明文に類義語＋ロングテールを配置する」**。1つの軸だけ厚く詰めるとSEO効果が薄れる。

## 知識ベース

楽天キーワードマップの5軸：

| 軸 | 例（ワンピースの場合） |
|---|---|
| 指名語 | ワンピース、ロングワンピース |
| 用途 | オフィス、結婚式、デイリー、通勤 |
| 状況・属性 | 30代、ぽっちゃり、きれいめ、大きいサイズ |
| 季節・贈答 | 春夏、母の日、プレゼント |
| 類義語 | ドレス、チュニック、ガウン |

詳細：
- ジャンル別頻出キーワード（レディース／メンズ／食品／インテリア／家電／美容など）：`references/category-keywords.md`
- 類義語・言い換え対応表：`references/synonyms.md`
- 楽天文字数仕様（商品名／キャッチ／説明文／タグID）：`references/rakuten-text-spec.md`
- 完成マップの例：`references/examples.md`

楽天文字数の重要数値：

| 項目 | byte上限 | 全角換算 |
|---|---|---|
| 商品名 | 255byte | 127字 |
| キャッチコピー | 174byte | 87字 |
| PC用商品説明文 | 10,240byte | 5,120字 |
| SP用商品説明文 | 10,240byte | 5,120字 |
| カタログID | 30byte | - |
| タグID | 最大32個 | - |

## 処理フロー

### Step 1：商品プロファイル把握

ユーザーから以下を確認（不足時は仮定）：

- 商品カテゴリ（ジャンルID）
- 売価帯
- ターゲット属性
- 季節性／通年商品
- ブランド名・型番

不明な場合は「30代女性／春夏／通年」など仮定して進める。

### Step 2：5軸キーワードの収集

`references/category-keywords.md` のジャンル別頻出語から候補を抽出。`references/synonyms.md` で類義語を補強。

### Step 3：優先度づけ

| 優先度 | 配置先 | 性質 |
|---|---|---|
| 高 | 商品名 | 指名語＋ビッグ用途語 |
| 中 | キャッチコピー | 状況属性語＋差別化 |
| 中 | タグID | 状況属性＋季節（楽天独自のタグ） |
| 低 | 説明文 | 類義語＋ロングテール |
| 低 | レビュー誘導 | 体験語・口コミ語 |

### Step 4：byte見積もり

商品名・キャッチコピーの候補を作り、半角／全角byte換算（半角1byte、全角3byte※Shift_JIS換算）で検算。

### Step 5：配置案の出力

5軸×配置先のマトリクスで「どのKWをどこに置くか」を明示。

### Step 6：除外候補の警告

薬機法／景表法に抵触する語（「シミに効く」「最安」「No.1」根拠なし）は除外候補としてリスト化。

## 代表例

### 例：レディースワンピース（30代向け／春夏）

5軸マップ：

| 軸 | キーワード |
|---|---|
| 指名語 | ワンピース、ロングワンピース、マキシワンピース |
| 用途 | オフィス、通勤、デイリー、お呼ばれ、結婚式 |
| 状況・属性 | 30代、きれいめ、フェミニン、ぽっちゃり、大きいサイズ |
| 季節・贈答 | 春夏、夏、半袖、母の日、誕生日プレゼント |
| 類義語 | ドレス、チュニック、ワンピ |

配置案：
- 商品名（255byte / 全角127字以内）：「ロングワンピース レディース 春夏 半袖 きれいめ オフィス 通勤 ロング丈 マキシ丈 30代 40代 大きいサイズ M L LL お呼ばれ 結婚式 母の日 ギフト」
- キャッチコピー（174byte / 87字以内）：「ぽっちゃりさんも美シルエット／きれいめ通勤ワンピ／春夏新作」
- タグID：「春夏」「半袖」「きれいめ」「オフィス」「大きいサイズ」など
- 説明文：類義語＋ロングテール（コーデ例、サイズ感、洗濯方法）

完全な例集：`references/examples.md`

## 品質ゲート

- 5軸（指名／用途／状況属性／季節贈答／類義語）すべてに最低3語あるか
- 商品名・キャッチコピーがbyte上限を超えていないか
- タグID候補が楽天独自タグの形式を意識しているか
- 薬機法・景表法抵触語を除外候補としてリスト化しているか
- 競合ブランド名（商標問題）を含めていないか
- 完全数値（「最安」「No.1」「業界一」等）の使用回避

## エッジケース

- **指名語が非常にビッグ（例：化粧水）**：用途×状況×成分の組合せで差別化
- **ニッチ商品（業務用・専門品）**：用途語が一般語と乖離、専門用語を厚くする
- **化粧品・健食**：効能訴求KW（「シミに効く」等）は除外、用途×状況で勝負
- **季節商品**：オフシーズン用の「予約」「先行」KWも入れる
- **ギフト需要が強い商品**：別途 `rakuten-gift-demand-keywords` を併用

## 注意事項

- 楽天検索のアルゴリズムは公開されておらず、本マップは経験則に基づく
- 商品名・キャッチコピーの楽天仕様は管理画面で随時改定、最新仕様で確認
- byte換算は文字コードによって変動（Shift_JIS基準が安全）
- 競合ブランド名・商標を商品名に含めない（規約違反）
- 薬機法・景表法に抵触する語は除外し、安全寄りの代替表現を提案
