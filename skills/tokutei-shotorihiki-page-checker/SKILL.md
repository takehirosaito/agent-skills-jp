# 特定商取引法 ページ／最終確認画面チェック

## 概要

通販ECサイトの「特定商取引法に基づく表記」ページ、および定期購入を含む申込時の「最終確認画面」の必須記載項目・整合性・表記ブレ・誤認誘発リスクを検証する。

2022年6月の特商法改正により、最終確認画面で6項目の表示が義務化され、違反は **3年以下の懲役または300万円以下の罰金（直罰）** に。EC事業者にとって法的リスクが大きい領域。

## ★最重要原則

**「特商法ページに書いてある」ことと「最終確認画面に表示している」ことは別の義務。** 2022.6改正で最終確認画面6項目の表示は直罰対象になった。特商法ページの完備だけでは違反になり得る。**両方を別観点でチェック**することが必須。

要点（本ファイルに留める）：

### 通販の必須13項目

1. 販売価格
2. 送料その他の負担額
3. 支払時期・方法
4. 商品の引渡時期
5. 申込撤回・解除に関する事項（**返品特約**）
6. 事業者の氏名（法人名）・住所・電話番号
7. 責任者の氏名
8. 申込の有効期限
9. 価格以外の負担すべき金銭
10. 隠れた瑕疵についての販売業者の責任
11. ソフトウェアの動作環境
12. 定期購入の場合の条件（2回以上の継続購入）
13. 数量制限その他特別な販売条件

### 最終確認画面6項目（2022.6改正）

1. **分量**（個数・回数・期間。定期は「無期限」「○回まで」を明示）
2. **販売価格／支払総額**（初回価格と通常価格が異なる場合は支払総額を表示）
3. **支払時期・方法**
4. **引渡時期**
5. **申込撤回・解除条件**（返品特約・定期解約方法・解約連絡先）
6. **申込期間制限**（期間限定販売の場合）

違反は **3年以下の懲役または300万円以下の罰金（直罰）**。改善命令を経ずに直接刑罰対象。

### 定期購入の特別要件

- 「お試し」「初回〇〇円」が定期購入の初回である場合、その事実を**目立つ位置で明示**
- 2回目以降の価格・回数・総額・解約方法を明示
- ダークパターン（小さく定期表示、解約導線の隠蔽）はNG

## 処理フロー

### Step 1：チェック対象の特定

- 特商法ページのURL／本文
- 最終確認画面（カートの注文確定直前ページ）のスクショ／HTML
- 定期購入商品の場合：定期条件の記載箇所

### Step 2：特商法ページ13項目チェック

13項目の網羅性を表形式で検証。`references/tokutei-13-items.md` の項目ごとの記載例と照合。

特に頻出の漏れ：

- 責任者氏名（社長名と分けて記載）
- 隠れた瑕疵責任（民法改正で「契約不適合責任」への言及）
- 申込有効期限（「ご注文確定後○日以内に入金がない場合は…」）
- 数量制限（「お一人様○点まで」がある場合）

### Step 3：最終確認画面6項目チェック

注文確定ボタン直前の画面に6項目が**同一画面で**表示されているか確認。リンク先・ポップアップ・別ページにある場合は要件未満となり得る。

### Step 4：事業者情報の開示要件

- 法人：商業登記上の正式名称・代表者または責任者・本店所在地・連絡可能な電話番号
- 個人事業主：屋号と本名併記、住所、電話番号（私書箱・バーチャルオフィスの可否はモールにより異なる）
- 連絡可能なメールアドレス／問合せフォーム
- 「電話番号は注文者のみ開示」型の運用には消費者庁の見解上の制約

### Step 5：定期購入の追加チェック

定期購入商品では `references/subscription-disclosure.md` のチェックリストを適用：

- 「初回○○円」表記の周辺に「2回目以降は××円」「○回継続が条件」「総額」「解約方法」が明示
- 解約方法（電話のみ・受付時間限定・違約金の有無）
- 「いつでも解約可能」と謳いながら実質的に解約が困難な設計の検出

### Step 6：モール固有ルールとの整合

`references/mall-tokutei-rules.md` のモール別追加要件と照合（楽天は店舗情報ページ、Amazonは出品者情報ページ、Yahoo は会社概要、Shopifyは規約ページなど）。

## 品質ゲート

- [ ] 特商法ページと最終確認画面を**別観点**でチェックしている
- [ ] 最終確認画面6項目について「直罰対象」と明記している
- [ ] 定期購入商品では総額・解約方法を必ずチェックしている
- [ ] 事業者情報が「電話番号未掲載・私書箱住所」等の典型回避パターンに陥っていない
- [ ] 「弊社規定により返品不可」等の特商法違反となる包括返品否認文を検出している
- [ ] 法的最終判断は弁護士または消費者庁へという免責を明記

## エッジケース

- **デジタルコンテンツ・サブスク** → クーリングオフ適用外でも返金条件・解約方法の表示は必要
- **海外向け販売** → 日本国内発送の特商法表記とは別に、輸出規制・関税の表記要否
- **個人事業主のバーチャルオフィス住所** → モールにより可否が異なる、特商法上は連絡可能な実態が問われる
- **「電話番号は購入者にのみ開示」型** → 消費者庁の見解では原則NG、購入前から確認可能であるべき
- **モールの店舗ページに記載がある場合の自社ECとの整合** → 同一事業者として両方で整合が必要

## 注意事項

- 特商法は改正頻度が高い。最新は消費者庁の公式情報を確認
- 本スキルは社内一次チェック用。最終判断は弁護士・消費者庁・各モール審査窓口に確認
- 顧客情報・取引データは出力に含めない
- 「特商法に違反していない」と断定せず「該当箇所のリスク」として表現
