| 自前で作るより Dawn 標準を使うべき | Section |
|---|---|
| ヒーロー | image-banner |

| ブログリスト | featured-blog |

| お知らせバー | announcement-bar |

| リッチテキスト | rich-text |

→ **30案以上は Dawn 標準で対応可能**。自前実装はカスタムが必要なものに絞る。

## 業種特化が必要な案

汎用50案で十分なケースが多いが、業種特化が必要なもの：

| 業種特化 | 案 |
|---|---|
| 化粧品 | 全成分表示、パッチテスト済みバッジ、化粧品56効能内の効能表 |
| アパレル | サイズ表、モデル着用情報、お手入れマーク |
| 食品 | 賞味期限、アレルゲン、JAS認証マーク |
| 健食 | 届出文言表示、摂取目安、注意表示 |
| ギフト | のし対応、配送日カレンダー、メッセージカード入力 |

これらは `references/by-industry-priorities.md` を参照。

## 50案の使い方

1. **業種・課題から優先案を抽出**
2. **Dawn 標準で代替可能なものを除外**
3. **App Block で代替可能なものを別管理**
4. **残った中から「最優先10案」「中期20案」「長期20案」に振り分け**

100案ありきではなく、**実装するセクションを厳選**する判断が重要。
