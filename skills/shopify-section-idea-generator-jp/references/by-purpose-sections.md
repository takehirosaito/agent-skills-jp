## 目的の組み合わせ

実際のストアは複数の目的が混在：
- **CVR向上 + 信頼形成**：レビュー + 会社情報 + バッジ
- **回遊 + SEO**：関連コレクション + ブログ + パンくず
- **客単価 + LTV**：定期購入 + クロスセル + バンドル

## 目的の優先付け

```
売れていない → CVR向上 を最優先
売れているが伸び悩み → 客単価 / LTV
新規流入が少ない → SEO / コンテンツ
リピート率低い → 信頼形成 / LTV
運用が回らない → 運用効率 / 自動化
```
