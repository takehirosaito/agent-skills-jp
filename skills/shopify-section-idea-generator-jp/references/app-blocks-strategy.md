# App Block 活用の判断

## App Block とは

Shopify アプリが提供する **テーマに直接埋め込める block**。Theme App Extension の仕組みで実装される。

### 仕組み

1. アプリをインストール
2. テーマカスタマイザーで「セクションを追加」or「ブロックを追加」
3. アプリの App Block が選択肢に出る
4. マーチャントが配置・編集

### 利点

- 自前実装より早い・安い
- 専門アプリのほうが機能が豊富
- メンテはアプリ提供者が行う
- セキュリティ・パフォーマンスは検証済み

### 欠点

- 月額費用
- アプリ独自の制約（デザインの自由度低）
- アプリ廃止のリスク
- 過剰なJS（パフォーマンス劣化のリスク）

## App Block の組み込み方

### 1. テーマで App Block を受け入れる宣言

セクションの schema で：

```json
"blocks": [
  { "type": "@app" }
]
```

または OS 2.0 の Theme Blocks で：

```liquid
{% content_for 'blocks' %}
```

### 2. マーチャント操作

- アプリをインストール
- テーマカスタマイザー → セクション → 「ブロックを追加」
- アプリの App Block が表示される
- 選択して配置

### 3. 設定

各 App Block は独自の settings を持つ。マーチャントが管理画面で編集。

## 自前実装 vs App Block の判断フロー

```
要件を分解
├── レビュー機能？
│   └── ✅ App Block（Judge.me 等）
├── サブスク機能？
│   └── ✅ App Block（Recharge）
├── 翻訳機能？
│   └── ✅ App Block（Translate & Adapt）
├── フィルタ機能？
│   └── ✅ Shopify Search & Discovery（無料公式）
├── 業種特有の表示（化粧品の成分等）？
│   └── ❌ 自前実装（Metafield 連動）
├── ブランド独自の見せ方？
│   └── ❌ 自前実装
└── 標準的なヒーロー・特徴？
    └── △ Dawn 標準で十分
```

## 月額アプリ費用の試算

中規模ストア（売上 月100-500万円）の典型的なアプリ構成：

|---|---|
| Judge.me（レビュー） | $15 |
| Recharge（サブスク） | $99 |
| Translate & Adapt（翻訳） | $0（公式無料） |
| Search & Discovery（フィルタ） | $0（公式無料） |
| Tidio（ライブチャット） | $0-50 |

## App Block の制約

### デザイン自由度

- アプリ提供のスタイルがベース
- CSS のオーバーライドで調整可能（限界あり）
- 完全カスタムが必要なら自前実装

### パフォーマンス

- アプリの JS は全ページに読み込まれることがある
- Lighthouse スコアに影響
- 必要なページでのみ App Block を使う

### 廃止リスク

- アプリが廃止 / 値上げ / 機能削減の可能性
- 重要機能は **データを Shopify 側で持つアプリ** が安全（Metafield や Customer 属性として保存）

### Markets 連動

- 一部アプリが Markets に未対応
- 多言語対応の有無を確認

## 自前実装すべきケース

- ブランド独自の見せ方（差別化）
- 業種特有の機能（化粧品の成分表示、機能性表示食品の届出文言）
- パフォーマンスが最重要（LCP に影響しないシンプル実装が必要）
- アプリの月額費用を継続的に払えない
- データを Shopify 内で完結させたい

## アプリ選定のポイント

### 1. レビュー数・評価

Shopify アプリストアで：
- レビュー数 100件以上
- 平均評価 4.5以上
- 最新コメントの内容

### 2. サポート対応

- 日本語サポート対応か
- レスポンス時間
- ドキュメントの充実度

### 3. データの所有権

- アプリ廃止時にデータをエクスポートできるか
- Shopify Metafield に保存するアプリが安全

### 4. パフォーマンス

- インストール後、Lighthouse Performance を再測定
- 5pt以上悪化したら見直し

### 5. 解約条件

- アプリ削除でデータが消えるか
- 月額契約 / 年額契約
