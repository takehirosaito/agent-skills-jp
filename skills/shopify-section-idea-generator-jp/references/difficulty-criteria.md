# 実装難易度の判定基準

## 難易度ランク

| ランク | 工数 | 内容 |
|---|---|---|
| 低 | 半日〜1日 | テキスト+画像+CTAの単純なセクション |
| 中 | 1-3日 | カルーセル、Metafield連動、アニメーション |
| 高 | 1週間〜 | AJAX、外部API、フィルタ、複雑な状態管理 |

## 低難易度の例

### 特徴
- HTML/CSS のみで完結
- JavaScript 不要
- schema もシンプル（10項目以内）

### 例

| Section | 工数目安 |
|---|---|
| ヒーローバナー（背景画像+H1+CTA） | 半日 |
| 3カラム特徴 | 半日 |
| 信頼バッジ列 | 半日 |
| お知らせバー | 1時間 |
| リッチテキスト編集 | 1時間（Dawn 流用） |
| 動画埋め込み（YouTube/Vimeo） | 半日 |
| メルマガ登録フォーム | 半日 |
| アコーディオン FAQ（CSS のみ） | 1日 |

### CSS のみで実装できる

- `<details>` `<summary>` でアコーディオン
- CSS Grid / Flexbox でレイアウト
- `:hover` でホバーエフェクト
- `transition` でアニメーション

## 中難易度の例

### 特徴
- JavaScript が必要（軽め）
- Metafield や API 連動
- 状態管理（開閉・選択・スライド）

### 例

| Section | 工数目安 |
|---|---|
| カルーセル（スライダー） | 2日（自前）/ 1日（既存ライブラリ） |
| タブ切替セクション | 1日 |
| Metafield 連動の商品スペック表 | 1日 |
| 商品の Variant ピッカー | 2-3日 |
| 動的レビュー表示（アプリ連動なし） | 2-3日 |
| 比較表（Metafield ベース） | 2日 |
| カウントダウンタイマー | 1日 |
| スクロールイン アニメーション | 1日 |

### JavaScript の使い方

- IntersectionObserver（スクロールイン）
- ResizeObserver（レスポンシブ調整）
- Vanilla JS でクラス付与・属性切替
- fetch / Shopify Section Rendering API

## 高難易度の例

### 特徴
- 複雑な状態管理
- 外部API / Shopify Storefront API
- AJAX で動的更新
- パフォーマンス最適化が必須

### 例

| Section | 工数目安 |
|---|---|
| AJAX カート連動セクション（送料無料閾値バー） | 3-5日 |
| クイックビュー（モーダルで商品詳細） | 1週間 |
| フィルタ付き商品グリッド（自前） | 2週間 |
| 「最近見た商品」（クッキー＋AJAX） | 1週間 |
| カスタマイズ商品（オプション選択で構成変化） | 2週間+ |
| AR/3D 商品プレビュー | 専門知識必要 |
| ライブチャット内蔵 | アプリ連携前提 |
| 多通貨計算機 | 1週間 |

### 採用判断

高難易度は **自前実装より App Block** の方が安いケースが多い：
- レビュー：Judge.me / Loox
- フィルタ：Search & Discovery（Shopify公式 無料）
- サブスク：Recharge
- ライブチャット：Tidio / Gorgias
- ロイヤルティ：Smile.io

## 工数見積りの方法

### 1. schema の項目数

- settings 5項目以下：半日
- settings 5-15項目：1日
- settings 15-30項目：2日
- settings 30+：3日+

### 2. block の有無

- block なし：基本工数
- block あり（type 1種類）：+0.5日
- block あり（type 複数）：+1-2日

### 3. JavaScript の有無

- JS なし：基本工数
- JS 軽（数十行）：+0.5日
- JS 中（100-300行）：+1-2日
- JS 重（数百行+）：+3-5日

### 4. 動的データ連動

- 静的：基本工数
- Metafield 連動：+0.5日
- 商品データ連動：+1日
- AJAX / API 連動：+2-3日

### 5. レスポンシブ

- シンプル（折り返し）：+0.5日
- 別レイアウト：+1日
- PC/SP で別 HTML：+2日

## 工数の合計

```
基本工数（schema）
+ block分（あれば）
+ JS分（あれば）
+ 動的データ連動分
+ レスポンシブ分
= 総工数
```

## チーム規模別の判断

### 個人事業者（1人）

- 低難易度：自分で実装可能
- 中難易度：勉強しながら実装 or 外注
- 高難易度：必ず外注 or App Block

### 小規模チーム（2-5人）

- 低・中難易度：内製可能
- 高難易度：専門エンジニアが必要

### 中〜大規模

- ほぼ全難易度を内製可能
- ただし App Block で代替できるものは効率重視

## 初心者の優先順位

「最初に作る10個」は必ず **低難易度** を中心に：

| 優先順位 | 難易度 | 例 |
|---|---|---|
| Phase 1（最初の2週間） | 低のみ | ヒーロー、特徴、CTA、FAQ |
| Phase 2（1ヶ月以内） | 低+中 | カルーセル、お客様の声、Metafield 連動 |
| Phase 3（3ヶ月以内） | 中+高 | AJAX、フィルタ、サブスク |

→ 「100案あります」より「**最初に作る10個を低難易度で固める**」方が実装が進む。

## App Block 採用判断

| 機能 | 自前 vs App Block |
|---|---|
| レビュー | App Block 一択（Judge.me 等） |
| フィルタ | Shopify Search & Discovery（無料公式） |
| サブスク | App Block（Recharge） |
| Wishlist | App Block（Wishlist Plus） |
| Instagram フィード | App Block |
| ライブチャット | App Block |
| メール配信 | Shopify Email or Klaviyo |
| ロイヤルティ | App Block（Smile.io） |

→ 上記は **自前実装するより App Block の方が早い・安い・保守容易**。
