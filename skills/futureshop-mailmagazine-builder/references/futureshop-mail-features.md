# futureshop メール配信機能の要点

futureshop（コマースクリエイター対応）のメール配信まわりの運用知識。仕様は変更されるため、最終的には futureshop 公式ヘルプ・管理画面で最新を確認すること。

## メール配信の経路

### 1. futureshop 標準のメルマガ機能

- 管理画面 → メール機能から配信
- 顧客リストの絞込み（購入回数・最終購入日・購入金額・会員ランクなど）
- HTML／テキスト両対応
- 配信予約・即時配信

### 2. 自動送信メール（システムメール）

注文確定・発送完了・お問合せ受付などのトランザクションメール。テンプレートは管理画面で編集可。

- 注文確認メール
- 発送完了メール
- お問合せ受付メール
- 会員登録完了メール
- パスワード再設定メール
- お気に入り再入荷通知

### 3. ステップメール／シナリオメール

futureshop 標準機能でカバーできる範囲と、外部MAツール連携（CRM PLUS など）で対応する範囲がある。長期的なシナリオ設計は外部MAツール連携を検討。

### 4. 外部MAツール連携

- CRM PLUS on LINE（LINE配信統合）
- Klaviyo、HubSpot、Salesforce Marketing Cloud などのMAツールとの連携が可能（要対応確認）

## テンプレートの基本

### HTMLメール

- 幅600pxの1カラム
- インラインCSSが基本（Outlook対応のため）
- 画像はaltテキスト必須
- 主要リンクは「テキストリンク」と「ボタン」の両方で配置

### テキストメール

- 横幅60〜80字で改行
- URL はそのまま貼る（短縮URLは迷惑メール判定リスクあり）
- 区切り線は `------` のような単純な記号

## 顧客セグメントの作り方（一般則）

futureshop 標準で絞込める軸の例：

| セグメント | 抽出条件例 |
|---|---|
| 新規 | 初回購入から30日以内 |
| 既存リピーター | 購入回数2回以上、最終購入90日以内 |
| 休眠 | 最終購入180日以上、登録会員 |
| 高単価層 | 累計購入金額○○円以上 |
| 特定カテゴリ購入者 | カテゴリ○○の購入履歴あり |
| お気に入り登録者 | 商品○○をお気に入りに追加済 |

具体的な抽出条件の構成は管理画面の絞込み機能で確認。

## 配信時の運用ポイント

### テスト配信

- 本配信前に自分宛＋関係者宛にテスト送信
- スマホ・PC・複数メールクライアント（Gmail/Outlook/Apple Mail）でレンダリング確認
- 全リンクのクリック動作確認

### 配信タイミング

- 平日朝（7:00-9:00）
- 平日昼（11:30-13:00）
- 平日夜（20:00-22:00）
- 週末は土曜午前・日曜夜

ジャンルにより最適時間が異なるため、**自社実績（開封率・クリック率の時間帯別データ）が最優先**。

### 配信頻度

- 週1〜2回が一般的
- 週3以上は配信解除率が上昇しやすい
- 新規購入直後はステップメール頻度を高め、安定期は週1に落とすなど顧客状態で変える

### 配信後の確認

- 開封率（HTMLメールのみ計測可、テキストは不可）
- クリック率（クリック計測リンクの設定が必要）
- コンバージョン率
- 配信解除率（目安0.5%以下）
- 不達率（バウンス率、3%超は配信品質低下）

## コマースクリエイター との連動

コマースクリエイター（CC）で構築したLPやキャンペーンページとメール導線を一致させる：

- メールのリンク先LPはCC側で事前に公開・動作確認
- UTMパラメータでメール経由のトラフィックを計測
- セールキャンペーンは「メール件名・本文・LP・SNS」のメッセージを統一

## 注意点

- **個人情報を含む顧客リスト** を本スキルの入出力に貼らない
- **配信解除済の顧客リスト** に再配信しない（特電法違反）
- **過去30日以内の配信内容** との重複・矛盾を確認（同じセール内容を別件名で再配信は信頼毀損）
- **テスト配信時のテストデータ** が本番配信に混入しないよう、配信前に最終確認
