# 件名フォーミュラ集

メールマーケで使える件名パターンを軸別に整理する。**ベネフィット軸 / 緊急性軸 / 好奇心軸** の3軸でA/Bテストするのが基本。

## 1. ベネフィット軸（読むと得することを伝える）

| パターン | 例 |
|---|---|
| ○○%OFF系 | 「全商品15%OFF・本日から3日間」 |
| 無料化系 | 「5,000円以上で送料無料／本日まで」 |
| 特典系 | 「ご新規様限定500円OFFクーポン」 |
| 比較系 | 「同価格帯で一番選ばれている○○」 |
| 約束系 | 「○日で使い始められる○○」 |

## 2. 緊急性軸（今行動する理由を伝える）

| パターン | 例 |
|---|---|
| 期間限定 | 「3日間限定・○月○日23:59まで」 |
| 数量限定 | 「先着100名様限定」 |
| 在庫薄 | 「残りわずか○○が入荷しました」 |
| 締切間近 | 「あと24時間で終了します」 |
| 季節終了 | 「今シーズン最後の○○セール」 |

## 3. 好奇心軸（クリックさせる仕掛け）

| パターン | 例 |
|---|---|
| 問いかけ | 「○○、続けられていますか？」 |
| ギャップ | 「実は○○の使い方を間違えていました」 |
| 数字 | 「3年間続いた定番が、4代目に進化」 |
| ストーリー | 「工房に行ってきました」 |
| 警告 | 「○○の使い方、こうなっていませんか」 |

## 4. セグメント別の冒頭ワード

| セグメント | 冒頭ワード例 |
|---|---|
| 新規 | 「ご新規様限定」「初回特典」「歓迎クーポン」 |
| リピーター | 「いつもありがとうございます」「リピーター様限定」 |
| 休眠 | 「お久しぶりです」「お待ちしておりました」 |
| 購入直後 | 「ご注文ありがとうございます」「お届けのご案内」 |
| 誕生月 | 「お誕生月のお祝いに」「Birthdayクーポン」 |

## 5. NGな件名

| NG例 | 理由 |
|---|---|
| 「!!!!　最安!!!!　絶対お得!!!!」 | 過剰な記号・景表法（最安・絶対）リスク |
| 「○○でシミが消える！」 | 薬機法違反（化粧品で効能効果断定） |
| 「業界No.1!!」（根拠なし） | 景表法（根拠なきNo.1表記） |
| 「【重要】ご確認ください」（実は単なる宣伝） | スパム的・信頼毀損 |
| 「Re:○○」（実は新規・返信偽装） | スパム的・信頼毀損 |
| 「もう一度送ります」（実は別内容） | 信頼毀損 |

## 6. 件名の長さ

- **スマホ受信箱**：おおむね全角20〜25字で見切れる
- **PC Gmail プレビュー**：おおむね全角30〜35字
- **設計の目安**：26〜30字。最初の20字に主要訴求を入れる

## 7. 絵文字の使い方

- ブランドトーンに合うなら 1-2 個まで
- B2B・高単価ブランドは控えめに
- 絵文字を件名先頭に置くと迷惑メール判定の確率がやや上がるという観測あり（媒体依存・自社で検証）

## 8. プリヘッダー（プレビュー文）

- 件名で省略した内容を補完する
- 60字前後で完結
- 「メールが正しく表示されない場合は…」のようなテンプレ文を冒頭に置かない（プリヘッダーに採用されてしまう）

## 9. A/Bテストの基本ルール

- 件名のみ変えて2案を同条件で配信
- 開封率の差が**統計的に有意**（最低500通×2グループ）か確認
- 「件名 ベネフィット軸 vs 好奇心軸」「絵文字あり vs なし」が定番テスト
- 開封率10%以下が続くならセグメントを見直す
