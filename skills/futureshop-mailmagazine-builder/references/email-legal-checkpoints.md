# 特電法・景表法・薬機法 メール固有の論点

メール配信に固有の法令ポイント。具体的な表現判定は `yakki-keihyo-expression-check` スキルと併用する。

## 1. 特定電子メール法（特電法）

広告・宣伝目的のメールには次の表記が必要：

### 必須記載

- **送信者の氏名または名称**（個人事業主は屋号と氏名）
- **送信者の住所**
- **配信停止（オプトアウト）の方法**：解除URL or 解除メールアドレス
- **苦情の受付先**：通常は送信者の連絡先と兼用

### オプトイン原則

- 事前に受信者から「メール配信に同意」を得ること
- ECサイトの「会員登録時にメルマガ受信」のデフォルトチェックは、明確に同意取得できる導線になっていれば可（ダークパターンは不可）
- 取引関係者（過去に商品を購入した顧客など）への通知は例外的に許容される範囲があるが、配信解除導線は必ず提供

### 配信停止の運用

- 配信停止の手続きは **本人確認なしで即時可能** にする
- 解除URLは1クリックで完了する設計が望ましい
- 解除後の配信ストップは速やかに（数営業日以内）

## 2. 景品表示法（景表法）

メール本文に含まれる広告表現も景表法の対象。

### 二重価格表示（8週間ルール）

セール価格と「通常価格」を併記する場合、「通常価格」は **セール開始直前8週間のうち過半（4週間以上）で実販売されていた価格** であること。

**OK例**：
- 「通常2,000円 → 1,500円（25%OFF）」
- ただし「通常2,000円」は直前8週のうち4週以上で2,000円で販売実績がある

**NG例**：
- 8週のうち1週しか2,000円で売っていない
- 過去に高い価格をつけていただけで、最近の実販売実績がない
- 「希望小売価格」を実売実績の代わりに使う（条件を満たさない場合）

### No.1表記の4要件

- 比較する商品等が適切に選定されている
- 調査対象者が適切に選定されている
- 調査が公平な方法で実施されている
- 表示内容と調査結果が適切に対応している

必須明示：**調査主体・期間・対象・方法・出典**

### 打消し表示

- 「※個人の感想」「※全員に当てはまるものではありません」は **打消しとして機能しない場合がある**
- 主張と打消しが同じ視認性で読める配置にすること

### 課徴金（2024改正）

- 売上の3%（最大3年分）
- 5,000万円未満は適用除外
- 繰返し違反は4.5%

## 3. 薬機法（医薬品医療機器等法）

メールに化粧品・健康食品・医療機器・サプリメントを掲載する際の表現規制。

### 化粧品の効能効果56項目

化粧品の広告表現は厚生労働省が認めた56項目の範囲内のみ。

**OK例**：
- 「肌にうるおいを与える」
- 「乾燥による小ジワを目立たなくする」（試験裏付け必須）
- 「肌のキメを整える」

**NG例**：
- 「シミが消える」
- 「美白できる」（医薬部外品の承認効能なら別）
- 「アンチエイジング」
- 「ニキビが治る」

詳細：`yakki-keihyo-expression-check` スキル参照

### 健康食品の4分類

- **特定保健用食品（トクホ）**：許可された保健の用途のみ表現可
- **機能性表示食品**：届出した機能性表示の範囲内
- **栄養機能食品**：国が定めた栄養素の機能のみ
- **いわゆる健康食品**：効能効果の標榜不可、一般的表現のみ

「痩せる」「血糖値が下がる」「免疫力アップ」等は **トクホ・機能性表示食品で届出した範囲外では使えない**。

## 4. ステルスマーケティング規制（2023.10.1〜）

- 規制対象：広告主（事業者）のみ
- インフルエンサーレビューを引用する場合は「PR」「広告」「プロモーション」「Sponsored」を明示
- 投稿冒頭または常時表示が必要。極小文字やタグ末尾埋込はNG
- メール内でインフルエンサーの声を引用する場合も、配信元事業者の広告である以上、PR表記が必要

## 5. 食品アレルゲン

メールに食品を掲載する場合、特定原材料の表示有無を本文中に注記するのが望ましい。

## 7. チェック早見表

| 項目 | OK条件 |
|---|---|
| 件名「最安」「No.1」 | 根拠（調査主体・期間・対象・方法）を本文に明記、または使わない |
| 「通常○円 → セール△円」 | 8週間のうち4週以上で通常価格での実販売 |
| 化粧品の効能効果 | 厚労省56項目の範囲内 |
| 健康食品の効能効果 | トクホ／機能性表示／栄養機能食品の届出範囲内、それ以外は一般表現 |

| 配信停止導線 | 1クリックで解除可、本人確認なし |
| 配信者情報 | 氏名／名称・住所が本文末尾に明記 |
| 「※個人の感想」 | 主張と同等の視認性で記載 |
