# futureshop メルマガ作成

## 概要

futureshop（コマースクリエイター対応）のメール配信は、標準メルマガ／システムメール／ステップメール／外部MA連携（CRM PLUS on LINE 等）の4経路がある。本スキルは、これら経路を前提に件名・プリヘッダー・本文・セグメント設計・配信タイミング・フッタ（特電法表記）まで含む完成形を作る。

メール本文は **薬機法／景表法／特電法／ステマ規制** すべての対象。文案作成と同時に法令チェックを通す設計にする。

## ★最重要原則

**「件名で開封させ、本文の1スクロール目で結論を出し、フッタで法令を満たす」**。EC メルマガで失敗する典型は (1) 件名が長すぎてスマホ受信箱で切れる、(2) リード3〜5行で結論に達しない、(3) 配信停止導線・送信者住所が抜けて特電法違反、の3つ。これらをテンプレ段階で塞ぐ。

セール・キャンペーンを扱う場合は **二重価格表示の8週間ルール**（セール開始直前8週のうち4週以上で実販売実績が必要）を必ず本文と齟齬ない形にする。

## 処理フロー

### Step 1：前提確認（仮置きOK）

- 配信目的：新商品告知／キャンペーン／休眠掘り起こし／購入後フォロー／レビュー依頼／ステップメール
- ターゲットセグメント：新規／既存リピーター／休眠／高単価層／特定カテゴリ購入者／お気に入り登録者
- 配信経路：標準メルマガ／ステップメール／システムメール／外部MA連携
- 配信タイミング：単発／予約／シナリオ（購入後N日）
- ブランドトーン・客単価帯・主要ジャンル

不明な項目は仮置きで進め、冒頭で「仮定」として明示。

### Step 2：件名を3案出す

`references/subject-formulas.md` の3軸（ベネフィット／緊急性／好奇心）から各1案。
- スマホ受信箱で見切れないよう **26〜30字**、最初の20字に主要訴求
- 「!!!!」「最安」「絶対」「シミが消える」等の景表法・薬機法NG表現を排除
- 「Re:」「【重要】」「もう一度送ります」など信頼を毀損する偽装表現は禁止

### Step 3：プリヘッダー（60字前後）

件名で省略した内容を補完。「メールが正しく表示されない場合は…」のテンプレ文を冒頭に置かない（プリヘッダーに採用されてしまう）。

### Step 4：本文を組む

- HTMLメール：幅600pxの1カラム、インラインCSSが基本（Outlook対応）、画像 alt 必須、主要リンクは「テキストリンク」と「ボタン」の両方
- テキストメール：横幅60〜80字で改行、URL はそのまま貼る（短縮URLは迷惑判定リスク）、区切り線は `------`
- 構造：宛名 → リード（1〜3行で結論）→ 詳細（箇条書き）→ CTA（URL）→ 補足 → フッタ
- 1スクロール目（スマホで約400px）で「何のメールか・何をすればいいか」を読了できる

### Step 5：CTA とリンク

- 主要 CTA は1つに絞る（リンクが3つ以上あると迷う）
- CC（コマースクリエイター）で構築したLPと完全に動作確認のうえリンク
- UTMパラメータでメール経由トラフィックを計測

### Step 6：フッタ（特電法を満たす）

```
------
[ブランド名]
運営会社：[会社名]
住所：[住所]
電話：[電話番号]
メール：[メールアドレス]

配信停止：[URL]
特定商取引法に基づく表記：[URL]
プライバシーポリシー：[URL]
```

配信停止は **本人確認なしの1クリック解除** が望ましい。

### Step 7：法令チェック

- 二重価格（通常○円→セール△円）：直前8週のうち4週以上で「通常価格」で実販売実績があるか
- No.1表記：4要件（適切な比較・調査対象・調査方法・対応）と調査主体／期間／対象／方法／出典の明示
- 化粧品の効能効果：56項目内（`yakki-keihyo-expression-check` 併用）
- 健康食品：トクホ／機能性表示／栄養機能／いわゆる健康食品の4分類の届出範囲内
- インフルエンサー引用：「PR」「広告」表記
- 食品アレルゲン：特定原材料8品目（えび／かに／くるみ／小麦／そば／卵／乳／落花生）の表示

### Step 8：配信タイミング・テスト配信

- 平日朝7-9時／昼11:30-13:00／夜20-22時、または週末土曜午前・日曜夜が一般則。**自社実績（時間帯別開封率）が最優先**
- 配信前に自分宛＋関係者宛にテスト配信、Gmail / Outlook / Apple Mail / スマホで表示確認、全リンク動作確認

## 品質ゲート

- [ ] 件名が26〜30字以内、最初の20字に主要訴求
- [ ] スマホ1スクロール目（約400px）で「何のメール・何をする」が読了可
- [ ] フッタに送信者名・住所・配信停止URL・特商法表記URL が揃っている
- [ ] 配信停止が1クリックで完結する設計
- [ ] 主要CTA は1つに絞られている
- [ ] セール価格を含む場合、二重価格表示の8週間ルールを満たす根拠が確認済
- [ ] 化粧品／健食／医療機器の薬機法逸脱が無い
- [ ] インフルエンサー引用に「PR」「広告」表記
- [ ] 「Re:」「もう一度送ります」等の偽装件名でない
- [ ] CC（コマースクリエイター）で構築したLPと整合（メール件名・本文・LP・SNS のメッセージ統一）

## エッジケース

- **HTMLメール未対応の受信者**：テキスト版を必ず併送（マルチパート）。テキストでも構造（区切り・改行）を保つ
- **配信解除済リストへの誤送信**：特電法違反。配信前に解除リスト除外を二重確認
- **同じセール内容を別件名で再配信**：信頼毀損。過去30日以内の配信履歴と重複・矛盾を必ずチェック
- **レビュー依頼で高評価誘導**：「高評価で○円OFF」はステマ規制・景表法NG。投稿内容の自由度を担保
- **食品メルマガでアレルゲン未記載**：特定原材料8品目（2024追加でくるみ）の表示注記を本文中に
- **休眠リストへの配信頻度**：3日間程度のクーポン期限つきで1〜2通、反応なければそれ以上配信しない（配信解除率上昇要因）

## 注意事項

- **個人情報を含む顧客リスト** を本スキルの入出力に貼らない
- **配信解除済の顧客リスト** に再配信しない（特電法違反）
- futureshop の **メール配信機能の操作画面・HTMLテンプレ仕様・配信本数の上限** は変動する。最終的に管理画面と公式ヘルプで確認
- 法令適用の最終判断は **専門家／消費者庁・厚労省・公正取引委員会等の公式ガイドライン** で確認
- 開封率／クリック率／配信解除率／不達率の数値目安は業界・ジャンル依存。自社実績で校正する
