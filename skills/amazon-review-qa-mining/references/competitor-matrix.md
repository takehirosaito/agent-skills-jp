# 競合比較マトリクス

自社商品と競合上位3商品のレビューを並べて、差別化軸を発見する手順。

## 比較対象の選定

### 同カテゴリ・同価格帯の上位3〜5商品
- 検索結果での上位（オーガニック）
- スポンサーブランド広告枠の上位
- 自社のベストセラー競合
- 顧客が「比較検討」と Q&A で言及する商品

### 1段下・1段上の価格帯の代表
- 自社が「上位機種」なら下位機種との比較
- 自社が「お手頃機種」なら上位機種との比較

## 観点別の深堀り

### 1. ★高評価の主理由

各商品の★4-5レビューで頻出する単語・フレーズを集計：

| 商品 | 頻出する満足要素 |
|---|---|
| 自社 | 軽さ、片手で扱える、LED |
| 競合A | 吸引力、デザイン、長時間バッテリー |
| 競合B | 安さ、シンプル、コスパ |

→ 自社の独自満足要素を見出す。

### 2. ★低評価の主理由

各商品の★1-3レビューで頻出する不満：

| 商品 | 頻出する不満 |
|---|---|
| 自社 | バッテリー持ち、カーペット吸引 |
| 競合A | 重い、高い、操作複雑 |
| 競合B | 吸引力弱い、すぐ壊れる |

→ 自社の弱点と、競合の弱点が見える。

### 3. Q&A 上位質問の違い

| 商品 | Q&A 上位質問の傾向 |
|---|---|
| 自社 | ペットの毛・畳・バッテリー交換 |
| 競合A | 重量・操作性 |
| 競合B | 故障時対応・保証 |

→ 各商品の「不安ポイント」のパターン。

## 4軸マトリクスでの差別化発見

```text
        高品質
          |
   自社 ● | ● 競合A
          |
低価格 ----+---- 高価格
          |
   競合C ● | ● 競合B
          |
        低品質
```

差別化軸の発見：
- 自社が「高品質・低価格」の象限に位置
- 競合が「高品質・高価格」「低品質・低価格」に分散
- 自社の独自ポジションを A+・タイトル・bullet で強化

## 観点別の差別化案

### 観点1：機能差別化
- 自社の独自機能（LED・自走アシスト・HEPAフィルター）
- 競合が持っていない機能を強調

### 観点2：価格差別化
- 同等品より安い → 「同等性能で○%安」
- 同等品より高い → 「価格差を補う価値」（保証・サポート・素材）

### 観点3：信頼差別化
- 日本国内サポート vs 海外サポート
- メーカー直販 vs 代理店
- 保証期間（2年 vs 1年）

### 観点4：サービス差別化
- プライム配送
- ギフト包装
- 詰替セット・定期便
- カスタマーサポート対応

## マトリクスから生まれる改善案

### 自社が優位な点 → 強化
- レビューで頻出する満足要素 → タイトル・bullet 上位
- A+ のヒーローセクションで強調

### 自社が劣後な点 → 改善
- ★1-3 の頻出不満 → 製品改良・付属品追加
- Q&A 不安への先回り回答を bullet・A+ FAQ で

### 自社にない競合の強み → 差別化方向修正
- 単に追随するか、別の軸で勝負するか

## 差別化軸の言語化

マトリクス分析の結果を「**1文の差別化ステートメント**」にまとめる：

例：「軽量1.2kg・片手で扱える設計と LED 搭載で、競合と同等の吸引力をより使いやすく」

このステートメントが：
- タイトルの主訴求
- bullet 1 の見出し
- A+ ヒーローの見出し
- ブランドストアのキービジュアル
すべてに反映される。

## 競合分析のサイクル

| 頻度 | 内容 |
|---|---|
| 月次 | ★分布・レビュー件数の推移 |
| 四半期 | 上位3商品の主訴求変化 |
| 半期 | 価格帯の変動・新商品参入 |
| 年次 | カテゴリ全体の構造変化 |

## マトリクスの限界

- レビュー・Q&A は「購入者だけ」の声（離脱者の声は見えない）
- レビュー操作（サクラ）の影響
- 季節商品・短期キャンペーン商品の歪み
- カテゴリ違いの商品が混在することがある

→ Brand Analytics（検索KW・購入者属性）と組み合わせると盲点を補える。

## レビュー数の少ない競合の扱い

- レビュー10件未満の競合は判断材料として弱い
- ただし「新興商品の差別化軸」として参考になる
- Q&A は少なくても貴重（事前不安が明確）
