# ★1-3レビューの優先対応マップ

★1-3のネガティブレビューを優先度別に整理し、商品・運用・コミュニケーションの改善につなげる。

## ★1-3 の優先度判定

### 件数 × 重大度マトリクス

|   | 低重大度 | 中重大度 | 高重大度 |
|---|---|---|---|
| 件数少 | 様子見 | 改善検討 | 即対応 |
| 件数中 | 改善検討 | 即対応 | 即対応＋製品改良 |
| 件数多 | 即対応 | 即対応＋製品改良 | 販売停止検討 |

### 重大度の判定
- **高重大度**：安全性問題・初期不良・誤認誘導
- **中重大度**：機能不足・期待ギャップ・サポート不満
- **低重大度**：好みの違い・誤購入・配送遅延

## 不満タイプ別の対応

### タイプ1：商品自体の問題（製品改良）

| 不満 | 対応 |
|---|---|
| 初期不良 | 検品強化、保証期間延長、出荷前テスト追加 |
| 部品の弱さ | 製造改良、素材変更 |
| 期待スペックを満たさない | スペック表記の見直し、bullet で実態に合わせる |
| 操作の難しさ | 説明書改善、A+ で使い方解説 |

### タイプ2：説明不足（コピー改善）

| 不満 | 対応 |
|---|---|
| サイズが思ったのと違う | サイズ感をサブ画像・bullet・商品仕様で明示 |
| 使い方が分からない | A+ コンテンツで使い方ステップ |
| 適合機種を間違えた | bullet 1 に適合機種を明記 |
| 成分・素材で予想外 | bullet・商品仕様欄で詳細明示 |

### タイプ3：配送・梱包の問題（運用改善）

| 不満 | 対応 |
|---|---|
| 配送遅延 | FBA 活用、出荷準備日数の見直し |
| 梱包が雑 | 梱包資材の見直し、検品強化 |
| 配送中の破損 | 梱包強化、緩衝材追加 |
| 開封しにくい | 開封ガイド追加 |

### タイプ4：サポート不満（対応改善）

| 不満 | 対応 |
|---|---|
| 問い合わせ返信が遅い | サポート体制強化、24時間以内返信 |
| 返品手続きが面倒 | 返品ポリシーの分かりやすさ向上 |
| 日本語が通じない | 国内サポート体制構築 |
| 修理対応がない | 修理／部品交換サービスの整備 |

### タイプ5：価格不満（戦略の見直し）

| 不満 | 対応 |
|---|---|
| 高い | 価値訴求の強化、コスパの可視化 |
| セールに乗り遅れた | セール頻度の調整、定期便割引の提供 |
| 同じ商品が他で安い | 価格戦略の見直し、独占供給契約 |

## ★1-3 への返信戦略

商品ページからセラー返信が可能。返信のポイント：

### 良い返信例

```text
ご購入いただきありがとうございます。

ご指摘のバッテリー持ちについて、ご不便をおかけして申し訳ございません。
現在の仕様では強モードで約25分、標準モードで約40分の連続稼働です。
強モードを継続使用されている場合、想定より早く充電が必要になる可能性があります。

予備バッテリー（型番○○）の単体販売もご用意しております。
また、次年度モデルでバッテリー容量の見直しを検討しております。

今後ともよろしくお願いいたします。
[ブランド名]
```

### NG返信例

```text
それは仕様です。返品はご遠慮ください。
```

→ 防御的、上から目線、ブランド毀損

### 返信時の注意
- レビュアーの言い分をまず受け止める
- 事実関係を明示
- 改善・対応の方向を示す
- 個人攻撃・反論はしない
- 公開される返信は他の購入検討者も読む

## 削除依頼の可否

### 削除依頼できるケース
- 商品と関係ない内容（配送業者への文句のみ等）
- 個人攻撃・差別表現を含む
- 競合からの嫌がらせと明らかに分かる
- 公序良俗に反する内容

→ Amazon コミュニティガイドライン違反として通報。

### 削除依頼できないケース
- 商品への正当な不満
- 期待ギャップに対する正直な感想
- ★1だが具体的な理由が書かれている

→ レビュー自由の範囲なので削除不可。改善で対応。

## ★1-3 を活かす商品改良

### 短期改良（1〜3ヶ月）
- 商品ページコピーの修正（タイトル・bullet・画像）
- 説明書の改善
- 梱包資材の見直し
- サポート体制強化

### 中期改良（3〜12ヶ月）
- 同梱物の追加（サポートカード・予備パーツ）
- 製品のマイナーチェンジ
- 価格戦略の見直し
- セット商品・バリエーション追加

### 長期改良（次世代モデル）
- 製品の根本的な改良
- 新機能の追加
- ターゲット顧客の再定義

## 改善効果の検証

改善後の検証ポイント：
- ★1-3 の月次件数の推移
- 改善前後の同種不満レビューの減少
- 平均★の改善
- CVR・売上の変化

## ★低評価レビューの活用例

### Bullet・A+ FAQ への反映
- ★1-3 の頻出不満 → 先回り回答を bullet・A+ FAQ で
- 例：「バッテリー持ちが短い」→ FAQ「Q：標準モードで何分使えますか？／A：約40分です」

### 改良アピール
- 製品改良が完了したら「2025年モデル：バッテリー強化版」として明記
- レビュー欄に「2025年モデルからバッテリー容量30%増」と社告

### ターゲット再定義
- 「家庭用」前提だったが、ペット飼育家庭で不満多 → 「ペット家庭向け」モデルを別途販売

## ★1集中の緊急事態

ある時期から急激に★1が増える場合：
- 製品ロットの不具合
- 競合からの組織的攻撃
- 物流問題（誤配・破損集中）
- 価格・送料の急変による反発

48時間以内に原因特定 → 対応開始。社内アラートを設定。
