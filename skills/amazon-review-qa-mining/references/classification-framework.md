# レビュー分類フレームワーク

レビュー本文を意味のある単位に分解するためのフレームワーク。

## フレームワーク1：5W2H

レビューを「いつ／どこで／誰が／何を／なぜ／どうやって／どれくらい」で分解。

| W/H | 内容 | 例 |
|---|---|---|
| When | いつ使う | 朝・夜・季節・休日 |
| Where | どこで使う | リビング・洗面所・通勤・出張 |
| Who | 誰が使う | 自分・家族・ペット・赤ちゃん |
| What | 何を使うか | 商品の用途（明示・暗黙） |
| Why | なぜ買った | 機能・デザイン・価格・ギフト・代替 |
| How | どう使う | 使用頻度・量・組合せ |
| How much | どれくらい使う | 何回・何分・何日 |

レビュー：「朝の支度時間に、洗面所で家族3人分のシャンプーとして使っています。コスパが良いのでリピートです」

→ When：朝、Where：洗面所、Who：家族3人、What：シャンプー、Why：コスパ、How：日常使用

## フレームワーク2：JTBD（Job To Be Done）

「お客様が商品を雇って解決したい仕事は何か？」という観点で分類。

### JTBD の3階層

1. **Functional Job**：機能的な解決（汚れを落とす／時間短縮）
2. **Emotional Job**：感情的な解決（安心・癒し・自己満足）
3. **Social Job**：社会的な解決（家族への配慮・周囲への印象）

レビュー：「子供のお弁当を毎朝作るのが大変だったが、これがあれば10分早く準備できる。子供にもキャラ弁を作ってあげられるようになった」

→ Functional：時短10分、Emotional：余裕、Social：子供への愛情表現

### JTBD で見えてくるもの

- 「機能だけ」訴求 → 「機能＋感情＋社会的価値」訴求へシフト
- 競合と違う JTBD 軸での差別化

## フレームワーク3：FAB（Feature・Advantage・Benefit）

| 階層 | 内容 | 例 |
|---|---|---|
| Feature（属性） | 仕様・成分・規格 | 「セラミド5種配合」 |
| Advantage（強み） | 機能上の優位性 | 「角層のすみずみまで浸透」 |
| Benefit（顧客価値） | 顧客の生活上の意味 | 「乾燥した肌が一日中うるおう」 |

レビューには Benefit が現れることが多い：
- 「肌の調子が良くなった」
- 「化粧ノリが変わった」

bullet ・A+ コピーでは Feature → Advantage → Benefit の3段で表現すると説得力が出る。

## レビュー本文の分類タグ

### 満足要素（ポジティブ）

| タグ | 例 |
|---|---|
| 機能満足 | 「思ったより吸引力が強い」 |
| デザイン満足 | 「色合いが想像以上に良い」 |
| 価格満足 | 「この価格でこの品質はお得」 |
| 配送満足 | 「翌日届いて助かった」 |
| 梱包満足 | 「ギフト用に綺麗に梱包されていた」 |
| サポート満足 | 「問い合わせに親切に対応してもらった」 |
| 想定通り | 「期待通りの商品」 |
| 想定以上 | 「想像していた以上の質感」 |
| 期待ギャップ無し | 「写真と実物が同じ」 |

### 不満要素（ネガティブ）

| タグ | 例 |
|---|---|
| 機能不満 | 「期待した吸引力ではなかった」 |
| デザイン不満 | 「写真の色味と違った」 |
| 品質不満 | 「すぐ壊れた」「初期不良」 |
| サイズ違い | 「思ったより小さい・大きい」 |
| 説明書不足 | 「使い方が分からない」 |
| 配送遅延 | 「届くのが遅かった」 |
| 梱包不満 | 「梱包が雑だった」 |
| サポート不満 | 「問い合わせて返信が遅い」 |
| 期待裏切り | 「広告と実物が違う」 |

## 写真／動画レビューの分類

| 要素 | 意味 | 活用 |
|---|---|---|
| 商品単体カット | 期待通りの外見 | サブ画像参考 |
| 使用シーン | 実際の使われ方 | A+使用シーン画像参考 |
| サイズ比較（手・他物） | サイズ感の伝達 | サブ画像にサイズ比較追加 |
| 開封時カット | 梱包・付属品 | 梱包設計の改善 |
| ビフォーアフター | 効果実感 | A+のストーリー参考（薬機対象は注意） |
| 不具合・故障 | クレーム証拠 | 製品改良の最優先 |

## 信頼性の判定

### サクラレビューの傾向
- 日本語表現が不自然
- 短文（1〜2行）が大量
- 同時期に同じような★5レビューが大量
- 商品と関係ない内容（「速い配送ありがとう」のみで内容無し）
- 同一ユーザーが多商品に★5

### サクラチェックツール
- Fakespot
- サクラチェッカー
- ReviewMeta

完全に信頼できるツールはない。最終判断は人間で。

## 取捨選択の指針

### 重視するレビュー
- 本文200字以上の詳細レビュー
- 写真・動画付きレビュー
- 「Amazon の認証済み購入」マーク付き
- 投稿者の他レビュー履歴が自然
- 良い点・悪い点の両方を書いている（バランス感覚あり）

### 軽視するレビュー
- 1〜2行の短文
- 商品と関係ない内容
- 過度に感情的・誇張表現
- 投稿時期が集中（短期間に大量）

## 期間別の傾向

レビューを期間別に並べると、商品改良の効果が見える：
- 発売直後：初期不良・期待ギャップが多い
- 3ヶ月後：定着レビュー
- 1年後：長期使用レビュー
- 改良後：「以前のレビューを見て不安だったが、改善されていた」

時系列で見ることで、製品改良の効果検証ができる。

## 顧客属性の推定

レビューから推定できる属性：
- 性別：一人称（私／僕／自分）・話題（メイク・髭剃り）
- 年齢層：話題（学生・子育て・退職後）
- 家族構成：「妻が」「子供が」「両親が」
- 職業：「在宅勤務で」「出張先で」「主婦業で」
- 関心：「他のブランド使ってきたが」（比較好き／こだわり）

属性別の不満・満足を分けて見ると、ターゲット顧客の明確化に役立つ。
