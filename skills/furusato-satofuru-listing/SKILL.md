# さとふる・ふるさとチョイス 返礼品掲載 設計

## 概要

さとふる・ふるさとチョイス等のふるさと納税ポータルでの返礼品掲載を支援するスキル。各ポータルの掲載項目・カテゴリ・検索特性に合わせた返礼品名/説明文、内容量/配送時期の明記、複数ポータル横展開時の原稿/写真最適化、レビュー/ランキング対策を設計する。返礼品ルール順守が前提。楽天ふるさと納税向け（`furusato-rakuten-listing`）とはポータル仕様・検索が異なるため別スキルとして扱う。

## 最重要原則

**「返礼品ルール（地場産品・返礼割合・表示）を順守／各ポータルの掲載項目とカテゴリに合わせる／寄附者は容量・配送時期・コスパで選ぶ→明記／複数ポータルは原稿を使い回さず各々の検索/表示に最適化／配送時期と発送方法を明確に」**。ポータルごとに見られる項目・表示が違うため、同じ原稿の流用は機会損失になる。制度ルールはどのポータルでも共通で順守。

## 知識ベース

ポータル横展開の着眼：

| 観点 | ポイント |
|---|---|
| 掲載項目 | ポータルごとの必須項目・規格・カテゴリ階層に合わせる |
| 返礼品名 | 品目・容量・特徴・季節を、各ポータルの検索特性に合わせて配置 |
| 説明文 | 内容量・規格・賞味期限・配送時期・注意事項を明確に |
| 写真 | 量が伝わる主役カット＋規格＋利用シーン |
| 評価/ランキング | レビュー獲得、ランキング上位の傾向把握 |
| 横展開 | 在庫・配送時期・寄附金額の整合、原稿の個別最適化 |

寄附者の傾向：容量・定期便・季節品・人気/ランキング重視。年末に寄附集中。

> 返礼品制度・基準・各ポータル仕様は改定される。確定は総務省/自治体/各ポータルの最新情報で確認。

## 処理フロー

### Step 1：返礼品とポータルの確認
- 品目・容量・配送時期、掲載先ポータル、自治体/中間事業者体制、既存掲載の有無
不明時は仮定を置いて明示し、ルール確認を促す。

### Step 2：ルール順守チェック
- 地場産品基準・返礼割合・表示の確認事項（★確定は自治体/総務省）。

### Step 3：ポータル別 返礼品名・説明文
- 各ポータルの項目/検索に合わせた返礼品名・説明文を設計。

### Step 4：写真・配送・規格
- 量が伝わる写真構成、配送時期/方法、内容量/賞味期限の明記。

### Step 5：横展開整合とランキング対策
- 複数ポータル間の整合（在庫/配送/金額）、レビュー獲得・ランキング傾向の活用。

## 出力フォーマット

```
# さとふる/チョイス 返礼品掲載：[品目]

## 0. 前提（品目/ポータル/配送・仮定）
## 1. ルール順守チェック（★自治体/総務省確認）
## 2. ポータル別 返礼品名・説明文
## 3. 写真・配送・規格の明記
## 4. 横展開整合（在庫/配送/金額）
## 5. レビュー・ランキング対策
```

## 品質ゲート
- 返礼品ルールの確認を促したか
- 各ポータルの項目/検索に合わせて最適化したか（流用しすぎていないか）
- 容量・配送時期・賞味期限を明確にしたか
- 横展開時の整合を取ったか

## 注意事項
- 返礼品制度・各ポータル仕様は変動。確定は総務省/自治体/各ポータルで確認。
- 食品は賞味期限・アレルギー・保存方法を明記。薬機/景表に反する表現は不可。
- 配送時期の誤表示・在庫齟齬はトラブルの元。
