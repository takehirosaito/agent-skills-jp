# 返品・返金ポリシー整合性チェック

## 概要

EC通販の返品・交換・キャンセル・返金ポリシーが、特商法（返品特約）・PL法（製造物責任）・民法（契約不適合責任）・景表法と整合し、かつ複数の表示箇所（商品ページ、特商法ページ、FAQ、利用規約、注文確認メール、配送同梱物）で表記が一致しているかを横断的に検証する。

## ★最重要原則

**返品ポリシーは「法令準拠」と「表記整合」の2軸で見る。** 特商法の返品特約は記載があれば原則優先されるが、PL法や民法による不良品対応の責任は契約で免除できない。そして、商品ページ・特商法ページ・FAQで返品条件がズレていると、消費者紛争・モール審査・景表法上の有利誤認の問題になる。

要点（本ファイルに留める）：

### 法的に「返品不可」と書けないケース

| 状況 | 返品不可と書けるか | 根拠 |
|---|---|---|
| 商品が破損・不良で届いた | **不可**（返品・交換に応じる義務） | 民法契約不適合責任、PL法 |
| 注文と異なる商品が届いた | **不可** | 民法契約不適合責任 |
| 食品の賞味期限切れ等の安全性問題 | **不可** | 食品衛生法、PL法 |
| お客様都合の返品（イメージ違い等） | **可**（特商法上、特約があれば免除可） | 特商法の返品特約 |
| 「弊社規定により一切の返品不可」 | **包括的にはNG** | 不良品も拒否することになるため |

### 特商法の返品特約

- 通販には**法定のクーリングオフは無い**（訪問販売・電話勧誘とは異なる）
- ただし返品特約の表示がない場合、商品到着後**8日以内**は返品可能
- 特約を設定すれば「お客様都合の返品不可」「未開封のみ可」等の設定が可能
- 特約は商品ページ・特商法ページの双方に明確に表示が必要

### 表記が整合すべき箇所

1. 商品ページの「返品について」ブロック
2. 特商法ページの「返品・交換」項目
3. FAQ・ヘルプページ
4. 利用規約
5. 注文確認メール
6. 配送同梱物（納品書・返品案内）
7. モール側のショップ情報ページ（楽天店舗情報／Amazon出品者プロフィール／Yahoo会社概要）

## 処理フロー

### Step 1：対象コンテンツの収集

返品関連の文言を全箇所から収集：

- 商品ページの返品セクション
- 特商法ページの返品項目
- FAQ／ヘルプの返品関連Q&A
- 利用規約の関連条項
- 注文確認メールテンプレート
- モール店舗情報ページ

### Step 2：法的妥当性チェック

`references/return-law-basics.md` の判定マトリクスで各ポリシーを評価：

- 不良品・誤発送への対応を排除していないか
- 「一切の返品不可」「いかなる場合も返品不可」等の包括否認になっていないか
- 食品・化粧品など特性上開封後返品不可の根拠は適切か（衛生上の理由を明示）
- クーリングオフという言葉を通販で誤用していないか（通販は法定クーリングオフなし）

### Step 3：表記整合性の横断チェック

`references/cross-page-checklist.md` の項目で複数箇所の整合を確認：

- 返品可能期間（到着後○日／発送後○日／注文後○日）
- 返送料負担（お客様／販売者／不良品時のみ販売者）
- 返金方法（クレカ取消／銀行振込／ポイント返還）
- 返金タイミング（到着確認後○営業日／検品後○営業日）
- 返品の連絡方法（電話／メール／問い合わせフォーム／マイページ）
- 例外（受注生産品／オーダー品／カット食品／開封済み化粧品）

整合していない箇所をすべて列挙する。

### Step 4：景表法上の有利誤認チェック

- 「返品OK」と謳いながら実際には条件が厳しく事実上不可
- 「全額返金保証」と謳いながら送料・手数料を控除
- 「いつでも解約」と謳いながら解約手段が限られる（定期購入と同じ問題）

### Step 5：業界別テンプレートとの照合

`references/policy-templates.md` の業界別推奨テンプレートと比較し、業界水準から外れた条項を検出。

### Step 6：修正版の生成

整合性を保ち、法令違反のない返品ポリシー文の修正版を生成し、各箇所（商品ページ／特商法ページ／FAQ／メール）に展開する。

## 品質ゲート

- [ ] 法令準拠と表記整合の**2軸**で評価している
- [ ] 「一切の返品不可」等の包括否認文を必ず検出している
- [ ] 不良品・誤発送への対応を保護する文言が残っている
- [ ] 食品・化粧品の開封後返品不可には衛生上の理由を明示している
- [ ] 修正版テキストを箇所別に分けて出力している
- [ ] 法的最終判断は弁護士・消費者庁・モール審査窓口に確認との免責を明記

## エッジケース

- **オーダーメイド／受注生産** → 「お客様都合の返品不可」は妥当だが、不良品対応は別途必要
- **食品の賞味期限近接品** → 賞味期限表示を明確にし、近接品の交換可否を別途明示
- **化粧品の「肌に合わない」場合** → 開封後返品不可が一般的だが、初回お試しサイズでの「肌チェック後の本商品交換」等の特例運用あり
- **海外発送** → 国際送料・関税の取扱いを明示
- **モール独自のお客様保証制度** → 楽天「あんしんショッピングサービス」、Amazon「マーケットプレイス保証」等が店舗の返品ポリシーに優先する場合あり

## 注意事項

- 返品関連法令は改正頻度が高い（民法改正・消費者契約法改正等）。最新は消費者庁の公式情報を確認
- 本スキルは社内一次チェック用。最終判断は弁護士・消費者庁・各モール審査窓口に確認
- 顧客情報・取引データは出力に含めない
- 業界水準は変動するため、固定的に「業界標準」とは表現しない
