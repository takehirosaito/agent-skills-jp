# 検索意図の4分類

検索クエリは大きく4つの意図に分類できる。それぞれに最適な記事タイプと送り先が異なる。

## 1. 情報収集型（Informational）

### クエリ例

- 「○○とは」
- 「○○ 原因」
- 「○○ 種類」
- 「○○ 効果」
- 「○○ 仕組み」
- 「○○ 違い」

### 特徴

- ユーザーは知識を得ようとしている
- 購入意欲は低い／まだ無い
- 検索ボリュームは多い（広く浅く）
- 競合が強い

### 適した記事タイプ

- 解説記事
- 用語解説
- 「○○とは何か」をクリアに

### 送り先

- 関連コレクション（広く商品を見せる）
- 関連する「比較記事」へ
- 「使い方記事」へ

→ **直接商品ページへ送るより、検討段階を進める記事へ送る**のが効率的。

### 例

「ビタミンCとは」で来た読者：
1. 記事「ビタミンCの効果と種類」（情報）
2. → 記事「ビタミンC美容液の選び方」（比較）
3. → コレクション「ビタミンC美容液」（購入意図）
4. → 商品ページ（購買）

## 2. 比較検討型（Commercial）

### クエリ例

- 「○○ おすすめ」
- 「○○ ランキング」
- 「○○ 比較」
- 「○○ どれ」
- 「○○ vs ○○」
- 「○○ 2026」（年次比較）

### 特徴

- 商品購入を検討中
- 複数候補から選びたい
- 「自分に合う1つ」を探している
- 検索ボリュームは中〜多

### 適した記事タイプ

- 比較記事
- ランキング記事
- 厳選記事「○○選」

### 送り先

- 厳選コレクション（記事で紹介した商品を集めたページ）
- 複数の商品ページ
- 「選び方ガイド」記事

### 例

「美容液 30代 おすすめ」で来た読者：
1. 記事「30代に人気の美容液5選」
2. → 各商品ページ
3. → コレクション「30代向け美容液」

## 3. 購入意図型（Transactional）

### クエリ例

- 「○○ 通販」
- 「○○ 購入」
- 「○○ 通信販売」
- 「○○ 公式」
- 「○○ 取扱店」
- 「○○ 送料無料」
- 「○○ ふるさと納税」（食品）

### 特徴

- 購入を決めている、または直前
- 「どこで買うか」を探している
- 検索ボリュームは中

### 適した記事タイプ

- 商品深堀記事
- 公式販売案内
- 配送・返品ガイド
- ガイド記事（購入直前の不安解消）

### 送り先

- 商品ページ（直接）
- コレクション（候補商品の一覧）
- 配送・返品ポリシーページ

### 例

「○○商品 通販」：
1. 商品ページ直接 or
2. 記事「○○商品の取扱店・公式販売案内」 → 商品ページ

## 4. 指名検索型（Navigational）

### クエリ例

- 「ブランド名」
- 「ブランド名 商品名」
- 「ブランド名 公式」
- 「ブランド名 ○○ レビュー」
- 「ブランド名 ○○ 口コミ」

### 特徴

- ブランド／商品をすでに知っている
- 公式サイトへの導線を探している
- 検索ボリュームはブランドの認知度に依存

### 適した記事タイプ

- 商品ページ自体
- 商品深堀記事
- ブランドストーリーページ
- レビューまとめ記事

### 送り先

- 商品ページ
- ブランドページ
- レビューページ

### 例

「ブランドX セラム レビュー」：
1. 商品ページに直接送る
2. または「ブランドX セラム 30日使用レビュー」記事 → 商品ページ

## 意図の混在

実際のクエリは複数意図が混在することが多い：

- 「美容液 敏感肌 おすすめ 2026」：比較（おすすめ） × 情報（敏感肌の特性）

→ 主たる意図を1つ決め、補助的に他の意図にも対応する。

## 検索意図の見抜き方

1. Google で実際に検索してみる
2. 上位10記事のタイトルとmeta description を読む
3. 上位記事に共通する見出し構造を抽出
4. 「People Also Ask」（PAA）の質問を確認
5. 「関連する検索」を確認

→ 「Googleが上位に表示している記事タイプ」が、Googleの判断した検索意図に最も近い。

## クエリと記事タイプの対応表

| クエリ | 意図 | 記事タイプ | 文字数 | 送り先 |
|---|---|---|---|---|
| 「○○とは」 | 情報 | 解説 | 1,500-3,000 | 関連コレクション |
| 「○○ 効果」 | 情報 | 解説 | 1,500-3,000 | 関連コレクション |
| 「○○ 選び方」 | 情報＋比較 | ガイド | 2,000-4,000 | 厳選コレクション |
| 「○○ おすすめ」 | 比較 | 比較／ランキング | 3,000-6,000 | 厳選コレクション＋商品 |
| 「○○ 比較」 | 比較 | 比較 | 3,000-5,000 | 商品×複数 |
| 「○○ 使い方」 | 情報 | 使い方 | 1,500-3,000 | 商品＋関連商品 |
| 「○○ レビュー」 | 指名 | レビュー記事 | 1,500-3,000 | 商品ページ |
| 「ブランド名 ○○」 | 指名 | 商品深堀 | 2,000-3,000 | 商品ページ |
| 「○○ ピリピリ」（悩み） | 情報 | 悩み解決 | 2,000-3,500 | 関連商品＋コレクション |
