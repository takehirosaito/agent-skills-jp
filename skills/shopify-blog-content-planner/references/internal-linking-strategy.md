# 内部リンク戦略

ブログ記事の内部リンクは「**売上に直結する送客**」と「**SEOの順位強化**」の2軸で設計する。

## 戦略の全体像

```
[情報収集型 記事]
  ↓
[比較検討型 記事 or 厳選コレクション]
  ↓
[商品ページ]
```

→ 検索意図の段階を **記事ごとに上げていく** ルートを設計。

## ブログ記事 → 商品ページ

### 数：1記事に1-3商品

- 多すぎると「広告まみれ」と認識される
- 少なすぎると送客効果が弱い
- 「文脈に合った」3商品が黄金比

### 配置場所

| 場所 | 効果 |
|---|---|
| 記事冒頭の結論部 | 高（読まずに買う層） |
| 各H2見出し直下 | 高（その章で紹介する商品） |
| 文中の具体例 | 中（自然な訴求） |
| 末尾のまとめ | 高（読了直後の購買意欲） |
| サイドバー（任意） | 中（読みながら気になる） |

### アンカーテキスト

NG：「こちら」「詳しくはこちら」「→」「リンク」

OK：「Bloom Petal セラム 30mL」「ビタミンC美容液の詳細を見る」「敏感肌向け美容液コレクション」

→ アンカーテキストにリンク先のKWを含める。

## ブログ記事 → コレクションページ

### 数：1記事に1-2コレクション

- 「広く見たい」読者のため
- 「他の選択肢」を見たい読者のため

### 配置場所

- 記事末尾（最も自然）
- 「もっと見る」「全ての○○を見る」などのCTA

例：
> もっと敏感肌向けの美容液を見たい方は、[敏感肌向け美容液コレクション](/collections/sensitive-skin-serum)もご覧ください。

## ブログ記事 → 他のブログ記事

### 数：1記事に2-5本

### 戦略：

- **上位記事（情報型）→ 下位記事（比較型）**：検討段階を進める
- **下位記事（比較型）→ 上位記事（情報型）**：背景知識の補完
- **横の関連記事**：同じカテゴリの別記事
- **シリーズ記事**：全○回の連載

例：
- 「美容液とは」（情報）→「美容液の選び方」（比較）
- 「美容液の選び方」（比較）→「美容液 vs クリーム」（比較）
- 「ビタミンC美容液の効果」→「30代におすすめのビタミンC美容液5選」

## 商品ページ → ブログ記事

これも重要。**商品ページからブログへ送る** ことで、SEO とコンテンツ消費の両方を強化。

### 配置

- 商品説明本文の中（「使い方の詳細はこちら」）
- 商品ページ下部の「関連記事」セクション

### Liquid 実装例

商品 metafield に関連記事を持たせる：

```
Product metafield: custom.related_articles
Type: list.article_reference
```

```liquid
{%- for article in product.metafields.custom.related_articles.value -%}
  <a href="{{ article.url }}">{{ article.title }}</a>
{%- endfor -%}
```

## コレクションページ → ブログ記事

コレクションページの下部に「カテゴリの選び方」記事へのリンクを置く。

### Liquid 実装例

collection metafield：

```
Collection metafield: custom.related_articles
Type: list.article_reference
```

下部説明の最後に：

```liquid
{%- if collection.metafields.custom.related_articles.value != blank -%}
  <h2>このカテゴリの参考記事</h2>
  <ul>
    {%- for article in collection.metafields.custom.related_articles.value -%}
      <li><a href="{{ article.url }}">{{ article.title }}</a></li>
    {%- endfor -%}
  </ul>
{%- endif -%}
```

## トピッククラスター戦略

ピラー記事（中核）＋クラスター記事（周辺）の構造：

```
ピラー：「美容液 完全ガイド」（5,000-10,000字、広く深く）
  ├─ クラスター：「ビタミンC美容液の効果」
  ├─ クラスター：「敏感肌向け美容液の選び方」
  ├─ クラスター：「美容液の使い方ステップ」
  ├─ クラスター：「30代向け美容液おすすめ」
  └─ クラスター：「美容液 vs クリーム」
```

- クラスター記事はピラー記事へリンク
- ピラー記事は全クラスター記事へリンク
- ピラー記事＋クラスター記事全体で「美容液」というトピックのオーソリティを構築

## 外部リンク（出典・引用）

- 公的機関（厚生労働省／消費者庁／JCIA等）への出典リンクは信頼性を上げる
- `rel="noopener"` を付ける（外部リンク）
- 競合サイトへのリンクは慎重に

## アンカーテキストの黄金比

| 比率 | アンカータイプ |
|---|---|
| 40% | KWを含む自然な文 |
| 30% | 商品名・記事タイトル |
| 20% | ブランド名・URL |
| 10% | 「こちら」など（最小限） |

- [ ] 1記事に商品リンク 1-3個

- [ ] 「こちら」を最小限に
