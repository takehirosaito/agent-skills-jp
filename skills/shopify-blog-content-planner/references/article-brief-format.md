# 執筆ブリーフ フォーマット

ライター／Codex／AI に渡せる執筆指示書のテンプレート。

## ブリーフ構造

```markdown
# 執筆ブリーフ：[記事タイトル案]

## 1. 基本情報
- 記事ID：
- メインKW：
- 関連KW：
- 想定文字数：
- 公開予定日：
- 担当ライター：

## 2. 検索意図と読者
- 検索意図：（情報／比較／購入／指名）
- 想定読者：（年齢／性別／ライフスタイル／悩み）
- 想定するペルソナ：
  - 名前（仮）：
  - 状況：「○○で悩んでいる○歳の○○」

## 3. 記事の目的
- 売上ゴール：（どの商品／コレクションへ送るか）
- SEOゴール：（メインKWで何位以内を狙うか）
- 副次ゴール：（メルマガ登録、SNSシェア等）

## 4. 構成（見出しと意図）

### H1：[タイトル]

### 冒頭リード（200-300字）
- 読者の悩みを言語化
- 結論を提示
- 読了後にできるようになることを明示

### H2：[見出し]
**書く内容**：
- ポイント1
- ポイント2

**注意**：
- ○○について書いてはいけない（薬機法等）

### H2：[次の見出し]
...

## 5. 送り先（内部リンク）
- 商品ページ1：[商品名] (/products/...) — 配置位置：見出し3直下
- 商品ページ2：[商品名] (/products/...) — 配置位置：まとめ
- コレクションページ：[コレクション名] (/collections/...) — 配置位置：末尾CTA
- 関連記事：[記事タイトル] (/blogs/news/...) — 配置位置：H2 末尾

## 6. 引用・出典・参考
- 公式情報源：（厚労省・消費者庁・JCIA等）
- 統計データ：（出典明記必須）
- 競合記事（参考、コピー不可）：

## 7. 文体・トーン
- 文体：です・ます調
- トーン：（プロフェッショナル／フレンドリー／専門的）
- 一人称：（「私たち」「編集部」）
- 二人称：（「あなた」「お客様」）

## 8. 法令・媒体ポリシー注意
- 化粧品なら：薬機法56項目内、「効く」「治す」NG
- 健食なら：届出文言厳守、効能効果標榜不可
- 景表法：「No.1」根拠5項目、二重価格8週ルール
- ステマ：PR表記の有無

## 9. 必要画像
- アイキャッチ：（指定 or 撮影 or 既存使用）
- 本文中：各H2に1枚目安
- 表・図解：必要なら

## 10. 出力フォーマット
- HTML（リッチエディタ用）
- マークダウン
- Google ドキュメント

## 11. 受け入れ条件
- [ ] メインKWが title／H1／meta description／本文に自然に含まれる
- [ ] 文字数が指定範囲内
- [ ] 全H2に本文がある
- [ ] FAQ 3-5問
- [ ] 内部リンク 5-10個
- [ ] 出典・引用が明記
- [ ] 法令違反表現なし
- [ ] 画像 alt 設定済み
```

## ブリーフの具体例

```markdown
# 執筆ブリーフ：敏感肌の美容液の選び方 5つの基準

## 1. 基本情報
- 記事ID：BLG-2026-001
- メインKW：美容液 敏感肌 選び方
- 関連KW：美容液 ピリピリ、敏感肌 美容液 おすすめ、低刺激 美容液
- 想定文字数：2,500-3,500字
- 公開予定日：2026-06-01

## 2. 検索意図と読者
- 検索意図：情報＋比較
- 想定読者：敏感肌で美容液選びに失敗した経験のある30-40代女性
- ペルソナ：30代後半、過去にピリピリして使えなかった経験あり、慎重に選びたい

## 3. 記事の目的
- 売上ゴール：「敏感肌向け美容液コレクション」へ送客
- SEOゴール：メインKW で20位以内（3ヶ月以内）

## 4. 構成

### H1：敏感肌の美容液の選び方｜失敗しない5つの基準

### 冒頭リード
「敏感肌だと、新しい美容液を試すたびに『ピリピリしたらどうしよう』と不安になりますよね。この記事では、敏感肌の方が美容液を選ぶときに必ずチェックすべき5つの基準と、避けるべき成分・選び方のコツをお伝えします。」

### H2：結論：敏感肌の美容液は「成分・濃度・テクスチャ」で選ぶ

### H2：基準1：アルコール（エタノール）フリーかどうか

### H2：基準2：香料・着色料フリーかどうか

### H2：基準3：パッチテスト済みかどうか

### H2：基準4：保湿成分が含まれているか

### H2：基準5：使い心地（テクスチャ）が自分に合うか

### H2：これでも合わない時の対処法

### H2：敏感肌向けの美容液おすすめ
- 商品A（リンク）
- 商品B（リンク）
- 商品C（リンク）

### H2：よくあるご質問

### H2：まとめ＋関連コレクション

## 5. 送り先
- コレクション：敏感肌向け美容液 (/collections/sensitive-skin-serum)
- 商品：Bloom Petal セラム 30mL
- 関連記事：「美容液の使い方ステップガイド」「30代向け美容液おすすめ5選」

## 6. 引用・出典
- JCIA「化粧品等の適正広告ガイドライン」
- 日本皮膚科学会「敏感肌の定義と特徴」
- 自社調査：敏感肌モニター50名アンケート（出典明示）

## 7. 文体
- です・ます調、フレンドリー寄り
- 「敏感肌で悩むあなたへ」のような共感的トーン

## 8. 法令注意
- 化粧品カテゴリの記事
- 「シミに効く」「シワが消える」「アンチエイジング」NG
- 「日やけによるシミ・ソバカスを防ぐ」（医薬部外品は別）
- 商品の「効果」を断定しない
- 専門家への相談を推奨（皮膚科）

## 9. 必要画像
- アイキャッチ：1200×675、洗練された美容ビジュアル
- H2 各章に1枚（実物 or イメージ）

## 10. 出力フォーマット
- HTML（Shopify ブログのリッチエディタに貼る）

## 11. 受け入れ条件
- [ ] メインKW が title／H1／meta description／本文（自然に3-5箇所）に
- [ ] 文字数 2,500-3,500字
- [ ] 商品リンク 1-3個（アンカーテキストに商品名）
- [ ] コレクションリンク 1個（末尾CTA）
- [ ] 関連記事リンク 2-3個
- [ ] FAQ 4問
- [ ] 出典明記（JCIA・日本皮膚科学会）
- [ ] 薬機法違反表現なし
- [ ] 全画像 alt 設定
```

## ブリーフを渡す相手別の調整

### ライター（人）

- ペルソナを具体的に
- 文体例を1-2文示す
- 競合記事を参考に（コピーNG）

### Codex / Claude Code（AI）

- 構造を厳密に
- 出力形式（HTML / マークダウン）を明示
- 法令注意を箇条書きで（漏れ防止）

### Shopify Magic / Sidekick

- 短く具体的に
- 既存記事のトーンを学習させる
- 出力後の手直しを前提に

## チェックリスト

- [ ] 法令注意が網羅
- [ ] 出典・引用元が指定
- [ ] 受け入れ条件がチェックリスト形式
