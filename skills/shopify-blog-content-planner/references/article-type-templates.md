# 記事タイプ別 見出し構成テンプレ

## タイプ1：選び方ガイド

### 構成

```
H1: ○○の選び方｜失敗しない5つの基準
H2: 結論：選び方の3ステップ
H2: 基準1：[基準名]
H2: 基準2：[基準名]
H2: 基準3：[基準名]
H2: 基準4：[基準名]
H2: 基準5：[基準名]
H2: 価格帯別の選び方
  H3: 〜3,000円
  H3: 3,000〜10,000円
  H3: 10,000円〜
H2: よくあるご質問
H2: まとめ＋おすすめコレクション
```

### 文字数目安
2,000-4,000字

### 送り先
- コレクションページ（厳選）
- 比較記事

### 必要要素
- 結論を冒頭に提示（「結論から言うと、○○を選ぶなら3つの基準が大切」）
- 各基準の理由＋具体例
- 価格帯別／用途別の絞り込み
- 末尾でコレクションへ誘導

## タイプ2：比較記事／ランキング

### 構成

```
H1: ○○のおすすめ5選｜2026年版 比較ランキング
H2: 結論：用途別おすすめ
  H3: コスパ重視なら：商品A
  H3: 高機能なら：商品B
  H3: 初心者なら：商品C
H2: 比較表（一覧）
H2: 選定基準
H2: 1位：商品A
  H3: 特徴
  H3: メリット
  H3: デメリット
  H3: こんな人におすすめ
H2: 2位：商品B
  H3: ...
（以下同様）
H2: 選び方
H2: よくあるご質問
H2: まとめ
```

### 文字数目安
3,000-6,000字

### 送り先
- 各商品ページ（1記事から5-10商品）
- 厳選コレクション

### 必要要素
- 比較表（横スクロール可）
- 各商品の長所・短所をフェアに
- 選定基準の明示（編集部独自基準／調査ベース）
- 「アフィリエイト」「PR」表記（あれば）
- 比較する商品の選定理由（恣意的選定でない）

### 注意（景表法）

- 「No.1」表記は4要件（主体／期間／対象／方法／出典）
- 「最安」「業界初」は根拠が必要
- 「○○の95%が満足」など実態調査の根拠を明記

## タイプ3：使い方記事

### 構成

```
H1: ○○の使い方｜効果を最大化する4ステップ
H2: 基本の使い方
H2: ステップ1：[ステップ名]
  H3: ポイント
  H3: 注意点
H2: ステップ2：[ステップ名]
H2: ステップ3：[ステップ名]
H2: ステップ4：[ステップ名]
H2: 注意点
H2: よくあるご質問
H2: 関連商品
```

### 文字数目安
1,500-3,000字

### 送り先
- 該当商品ページ
- 関連商品ページ
- 使い方系の関連記事

### 必要要素
- 写真／図解（ステップごとに1枚以上）
- 所要時間の明示
- 失敗例とその対策
- 関連商品（補完商品）へのリンク

## タイプ4：悩み解決記事

### 構成

```
H1: ○○の悩み｜原因と対策、おすすめアイテム
H2: ○○の悩みとは
H2: 主な原因
  H3: 原因1
  H3: 原因2
  H3: 原因3
H2: 対策方法
  H3: セルフケア編
  H3: アイテム選び編
  H3: 専門家相談編
H2: おすすめアイテム
  H3: 初心者向け：商品A
  H3: 効果重視：商品B
  H3: 続けやすさ：商品C
H2: 改善までの期間目安
H2: よくあるご質問
H2: まとめ
```

### 文字数目安
2,000-3,500字

### 送り先
- 該当商品（1-3個）
- 解決系コレクション

### 必要要素
- 悩みへの共感（「ピリピリしますよね…」）
- 原因の専門的根拠（出典明示）
- 専門家への相談を推奨（医療系の場合）
- 商品で「治す／効く」と断定しない（薬機法）

### 注意（薬機法・健康増進法）

- 化粧品：「シミに効く」「シワを改善」NG → 「日やけによるシミ・ソバカスを防ぐ」OK
- 健康食品：「症状を治す」NG。機能性表示食品は届出文言のみOK
- 一般食品：効能効果の標榜不可

## 共通要素

### 冒頭（リード文）

3-5行で：
- 誰の悩みを解決する記事か
- 結論／要約
- 読んだ後にできるようになること

### FAQ（必須）

最低3-5問。検索意図と関連する疑問を網羅：

```
Q. ○○と○○の違いは？
A. ...

Q. ○○の効果はどれくらいで出ますか？
A. ...

Q. 敏感肌でも使えますか？
A. ...
```

FAQ schema（JSON-LD）を出すと、Google SERP で目立つ。

### まとめ

- 記事の要約（3-5行）
- 次のアクション提示（コレクションへ／商品ページへ／関連記事へ）

### 内部リンク

- 記事内に最低3-5箇所、商品／コレクション／関連記事へリンク
- アンカーテキストにKWを含む（「こちら」を使わない）

### 著者プロフィール

YMYL（医療・健康・金融）系は著者情報・経歴・監修者の明示が必須。

### 公開日・更新日

`<time>` 要素で構造化。古い記事は年次更新で `updated_at` を更新。
