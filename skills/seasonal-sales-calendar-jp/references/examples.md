## 例1：化粧品ブランド 母の日販促（5月第2日曜）

**ピーク**：5月第2日曜

**逆算スケジュール**：
| 時期 | 工程 |
|---|---|
| 2月初 | 商品企画・セット組み |
| 2月末 | 商品撮影・モデル撮影 |
| 3月初 | LP・商品ページ作成 |
| 3月中旬 | 広告クリエイティブ完成 |
| 3月末 | 仕入発注・在庫増量 |
| 4月初 | 楽天・Amazon・Yahoo!・自社EC同時販売開始 |
| 4月中旬 | テレビCM・SNS認知拡大 |
| 5月第1週 | 駆け込み購入対応強化 |
| 5月第2日曜 | 母の日（販促ピーク） |
| 5月中旬 | 販促終了・在庫消化 |

**訴求方向性**：
- ターゲット：30〜60代女性（贈り主）／50〜80代女性（受け取り手）
- キーワード：「ありがとうの気持ちを」「母娘で使える」「いつまでも美しく」
- カラー：ピンク・パステル・優しい色味
- ギフト訴求：包装・熨斗・カード対応

**配送リードタイム**：
- 5月第2日曜配送に間に合うラインを明示
- 「5月XX日23:59までのご注文で母の日にお届け」

## 例6：健食 年始（1月：「今年こそ」需要）

**ピーク**：1月1日〜1月末

**逆算スケジュール**：
| 時期 | 工程 |
|---|---|
| 10月 | 年始キャンペーン企画 |
| 11月 | 商品撮影・LP制作 |
| 12月初 | プレキャンペーン |
| 12月末 | 年末年始営業告知 |
| 1月1日 | 年始キャンペーン開始 |
| 1月中旬 | 認知拡大広告 |
| 1月末 | キャンペーン終了 |
| 2月以降 | 通常運用 |

**訴求方向性**：
- ターゲット：年始の新習慣を始めたい層
- キーワード：「今年こそ」「新年から」「新しい習慣」「健康への投資」
- カラー：赤・金・白

**法令注意**：
- 機能性表示食品の届出文言改変NG
- 「○○に効く」「ダイエット効果」等は標榜不可
- 定期購入の特商法表示

**LTV設計**：
- 1月の新規顧客を定期コースへ誘導
- 3ヶ月継続で黒字化試算（別スキル price-margin-simulator）

## 共通の運用ポイント

1. **ピーク当日から全工程を逆算**
2. **業界別ピーク**を反映
3. **配送業者繁忙期**（年末・お盆・GW）を加味
4. **モールセール時期**との連動
5. **在庫増量タイミング**を仕入LTから逆算
6. **キャンペーン後の在庫処分計画**
7. **法令適合性チェック**（別スキル yakki-keihyo-expression-check）
8. **粗利インパクト試算**（別スキル price-margin-simulator）

## 複数イベントの重なり対応

### 12月：クリスマス＋お歳暮＋年末年始
- 商品ラインアップを分ける
- 配送スケジュールを各イベント別に
- 在庫管理を独立させる

### 5月：GW＋母の日＋こどもの日
- GW前後で販売チャネル切替
- 母の日と他イベントで顧客層が違う

### 11月：七五三＋ブラックフライデー＋お歳暮準備
- 七五三は写真撮影需要
- ブラックフライデーは家電・雑貨中心
- お歳暮は予約販売（11月初〜12月初）
