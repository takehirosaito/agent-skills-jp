# 販促リードタイム逆算表

「ピーク当日 − 全工程のリードタイム = 開始日」

## 標準的な販促プロジェクトの工程

| 工程 | 標準日数 | 内容 |
|---|---:|---|
| 商品企画・コンセプト決定 | 2〜4週 | セット内容・価格・コピー方向性 |
| 仕入発注・在庫準備 | 仕入LT次第 | 国内2〜4週、海外4〜12週 |
| 撮影 | 1〜2週 | 商品撮影・モデル撮影 |
| LP・ページ作成 | 1〜2週 | デザイン・コーディング |
| 広告クリエイティブ | 1〜2週 | バナー・動画 |
| 広告審査 | 1〜3日 | Google・Meta・Yahoo!広告 |
| モール審査 | 1〜7日 | 楽天・Amazon・Yahoo! |
| プレキャンペーン | 2週 | メルマガ・SNS告知 |
| 本キャンペーン | 1〜4週 | 販促実施 |
| ポストキャンペーン | 1〜2週 | 在庫消化・分析 |

合計：**約2〜4ヶ月のリードタイム**が必要。

## 仕入リードタイム別の調整

### 国内仕入（2〜4週）
- 企画から2ヶ月前後で対応可

### 海外仕入（中国・東南アジア 4〜12週）
- 旧正月（1〜2月）を避ける
- 企画から3〜4ヶ月前

### OEM・自社製造（4〜8週）
- 製造ロット・賞味期限を考慮

### 受注生産（個別対応）
- 在庫リスクなしだが配送リードタイムが長い

## モールセール時の準備期間

### 楽天スーパーセール（年4回）
- エントリー：1ヶ月前
- 商品準備：2週間前
- バナー・LPアップ：1週間前
- 当日：システムチェック

### Amazon プライムデー
- セラーセントラルでセール参加申請：1ヶ月前
- 在庫増量：2〜3週間前（FBA納品リードタイム含む）

### Yahoo! 5の付く日
- 通常運用の範囲で対応
- 大型キャンペーン（超PayPay祭等）は1ヶ月前準備

## 配送リードタイムへの配慮

### お中元・お歳暮の配送締切
- 7月中旬：お中元の配送ピーク
- 12月20日頃：お歳暮の配送締切
- これより遅いと「年内お届け」が間に合わない

### クリスマス・年末配送
- 12月22日が最終配送目安
- 配送業者の年末繁忙期で1〜2日遅延の可能性
- 「12月22日 23:59までのご注文で年内お届け」のような明示

### 大型家具・冷蔵庫等
- 通常配送よりリードタイム長め
- 設置・搬入の予約取り

## 在庫増量のタイミング

### イベントピーク前
- 通常時の2〜3倍の在庫を準備
- 仕入リードタイム逆算

### モールセール前
- 楽天スーパーセール前：1ヶ月前から段階的に増量
- Amazon プライムデー：FBA納品リードタイム（1〜2週間）を加味

### キャンペーン後の在庫処分
- 過剰在庫を残さない販売目標設定
- 残った場合の処分計画（別スキル deadstock-clearance-planner）

## 広告予算配分

### イベント前1ヶ月
- 通常時の1.5倍
- 認知拡大広告（リーチ重視）

### イベント1週間前〜当日
- 通常時の2〜3倍
- コンバージョン重視広告

### イベント後
- 通常時に戻す
- リターゲティング（カート放棄者）

## 失敗を避けるチェックリスト

- [ ] ピーク当日 − 全工程リードタイム = 開始日を計算
- [ ] 仕入リードタイムを実値で（特に海外仕入の旧正月）
- [ ] 配送業者の繁忙期を加味（年末・お盆・GW）
- [ ] モール審査期間を加味
- [ ] 広告審査期間を加味
- [ ] 在庫増量は仕入リードタイムから逆算
- [ ] イベント後の在庫処分計画
- [ ] キャンペーン原資・ポイント原資の粗利インパクト試算
