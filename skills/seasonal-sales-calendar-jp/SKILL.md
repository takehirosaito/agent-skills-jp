# 日本EC 年間販促カレンダー

## 概要

日本ECの年間販促を、暦の主要イベント（母の日・父の日・お中元・お歳暮 等）／モールセール（楽天SS・Amazonプライムデー・ブラックフライデー 等）／業界別ピーク（おせち・福袋・節分 等）／配送繁忙期と組み合わせて、商品ジャンル別の年間カレンダーを設計するスキル。

ピーク当日から「企画・撮影・LP・広告・仕入・モール審査・プレキャンペーン」全工程を逆算し、いつ着手すべきかを月単位で出す。年間販促を「思いつきの単発企画」ではなく「逆算スケジュールに基づく投資計画」として運用する。

## ★最重要原則

**ピーク当日 − 全工程リードタイム = 企画着手日。** 母の日5/10ピークなら2月初に企画着手・3月中旬LP完成・4月初仕入入荷・5月8日当日着最終。海外仕入なら旧正月（1〜2月）を避けてさらに前倒し。**「ピークが来てから動く」では間に合わない**。仕入・撮影・LP・広告審査・モール審査の全工程を月単位で逆算する。

## 年間主要イベント（要点）

### 季節イベント（時期固定）
- 1月：福袋・初売り／成人式／鏡開き
- 2月：節分／バレンタイン
- 3月：ひな祭り／ホワイトデー／卒業・卒園／春のお彼岸
- 4月：入学・入園／新生活
- 5月：GW／こどもの日／**母の日（第2日曜）**
- 6月：**父の日（第3日曜）**／ジューンブライド／梅雨対策
- 7月：**お中元（関東6下旬-7/15）**／七夕／海の日／夏休み
- 8月：お盆／山の日／**夏祭り・花火**
- 9月：防災の日／**敬老の日（第3月曜）**／秋分の日／シルバーウィーク
- 10月：衣替え／スポーツの日／**ハロウィン**
- 11月：七五三／**ブラックフライデー（最終金曜）**／ボジョレー解禁
- 12月：**お歳暮（12/13-12/25）**／クリスマス／大晦日／**おせち**

### モールセール
- 楽天スーパーセール：年4回（3月・6月・9月・12月、各月初旬の4日20:00〜11日01:59）
- 楽天お買い物マラソン：月複数回（1ショップ1,000円以上で買いまわり最大10倍／通常ポイント上限7,000pt）
- Amazon プライムデー：7月中旬・2日間
- Amazon ブラックフライデー／サイバーマンデー：11月末〜12月初
- Yahoo! 5の付く日／プレミアムな日曜日／ゾロ目の日（11・22）

詳細は `references/monthly-calendar.md` と `references/mall-campaigns.md`。

## 処理フロー

### Step 1：入力情報の整理

必須：
- 商品ジャンル（食品／スイーツ／酒／コスメ／健食／家電／アパレル／ベビー／ペット／雑貨）
- 主要商品ライン（通年商品／季節商品／ギフト商品）
- 仕入元・仕入リードタイム（国内2〜4週／海外中国・東南アジア4〜12週／OEM4〜8週／受注生産）
- 販売チャネル（楽天／Amazon／Yahoo!／自社EC／Shopify）

任意：
- 前年実績（月別売上・キャンペーン売上比率）
- 在庫保管能力
- キャッシュフロー・支払サイト
- 広告予算枠

### Step 2：自社ジャンルのピークマッピング

業界別の販売ピーク月を商品に合わせて確定（`references/industry-peaks.md`）：

- 食品：お中元（6-7月）・お歳暮（10-12月）・年末年始（12-1月）
- スイーツ：バレンタイン（1-2月）・母の日（4-5月）・お中元（6-7月）・クリスマス（11-12月）
- 酒：父の日（5-6月）・お中元（6-7月）・お歳暮（10-12月）・年末（12月）
- コスメ：母の日（4-5月）・敬老の日（8-9月）・クリスマス（11-12月）
- 健食：年始（1月）・夏バテ（7-8月）・年末（11-12月）
- 家電：新生活（3-4月）・夏（6-8月）・冬（11-2月）・年末セール
- アパレル：春（2-4月）・夏（5-7月）・秋（9-10月）・冬（10-1月）・セール期（7・1月）
- ベビー：通年＋出産祝シーズン（4-9月の出産多い時期）
- ペット：通年＋ペットの記念日（11/1犬の日 等）

### Step 3：ピーク当日からの逆算

全工程リードタイム：

| 工程 | 標準日数 |
|---|---:|
| 企画・コンセプト決定 | 2〜4週 |
| 仕入発注・入荷 | 国内2〜4週／海外4〜12週／OEM4〜8週 |
| 撮影 | 1〜2週 |
| LP・ページ作成 | 1〜2週 |
| 広告クリエイティブ | 1〜2週 |
| 広告審査 | 1〜3日 |
| モール審査 | 1〜7日 |
| プレキャンペーン | 2週 |

合計：**2〜4ヶ月のリードタイム**。海外仕入なら3〜4ヶ月。

### Step 4：月別カレンダーへの落とし込み

12ヶ月の各月に「ピーク」「企画着手」「仕入発注」「LP・撮影」「広告開始」「販促実施」「在庫消化」を割り付け。

例（母の日 5/10ピーク）：
- 2月初：企画開始
- 2月末：商品確定・撮影
- 3月中旬：LP・ページ作成
- 3月末：広告クリエイティブ完成
- 4月初：仕入入荷・販促開始
- 4月中旬：認知拡大広告
- 5月第1週：駆け込みCTA
- 5月10日：ピーク
- 5月11日：表記オフ・在庫消化

### Step 5：モールセールの組み込み

モールセールは固定イベントなので必ずカレンダーに反映：
- 楽天SS：3月／6月／9月／12月（各月初旬）
- お買い物マラソン：月複数回
- Amazonプライムデー：7月中旬
- ブラックフライデー：11月最終金曜

各セールの**準備期間**を逆算：
- 楽天SS：エントリー1ヶ月前／商品準備2週間前／バナー1週間前
- Amazonプライムデー：参加申請1ヶ月前／FBA増量2〜3週間前
- ブラックフライデー：1ヶ月前準備

### Step 6：仕入リードタイムと旧正月の考慮

海外仕入（中国・東南アジア）の旧正月（1〜2月、2〜3週間の生産停止）は必ず加味：
- 母の日商品（5月ピーク）→ 1月発注では旧正月で間に合わない可能性。12月発注で確実に
- お中元商品（7月ピーク）→ 4月発注で間に合うが、生地・原料は2月までに確保

### Step 7：広告予算配分

| 時期 | 予算倍率 | 主な広告タイプ |
|---|---|---|
| イベント1ヶ月前 | 1.5倍 | 認知拡大（リーチ重視） |
| イベント1週間前〜当日 | 2-3倍 | コンバージョン重視 |
| イベント後 | 通常 | リターゲ（カート放棄者） |

### Step 8：在庫処分と次シーズン準備

シーズン終了時：
- 残在庫の処分計画（別スキル `deadstock-clearance-planner`）
- 表記オフ日に広告停止・LP切替・商品名から「○月○日まで」削除
- 翌シーズンへの企画着手（クリスマス終了直後にバレンタイン企画開始）

## 代表例：化粧品ブランドの年間カレンダー

**入力**：
- ジャンル：化粧品（保湿化粧水・美容液）
- 仕入：国内OEM（リードタイム6週）
- チャネル：楽天・Amazon・自社EC

**年間ピーク**：母の日（5月）・敬老の日（9月）・クリスマス（12月）

**月別カレンダー**：

| 月 | 主要施策 | 着手・準備 |
|---|---|---|
| 1 | 年始キャンペーン・福袋消化／春商品企画開始 | 母の日企画着手 |
| 2 | バレンタイン関連薄／春商品撮影 | 母の日撮影 |
| 3 | 楽天SS第1弾／ホワイトデー対応 | 母の日LP・広告完成 |
| 4 | 新生活訴求／母の日早割スタート | 母の日仕入入荷・敬老の日企画着手 |
| 5 | **母の日ピーク（第2日曜）**／5/11表記オフ | 父の日商品の準備 |
| 6 | 楽天SS第2弾／梅雨スキンケア訴求 | 敬老の日撮影 |
| 7 | Amazonプライムデー／夏スキンケア | 敬老の日LP完成 |
| 8 | 夏スキンケア継続 | 敬老の日仕入入荷／クリスマス企画着手 |
| 9 | 楽天SS第3弾／**敬老の日（第3月曜）** | クリスマス撮影 |
| 10 | 秋スキンケア／ハロウィン薄 | クリスマスLP完成・お歳暮企画着手 |
| 11 | **ブラックフライデー**／お歳暮ギフト | クリスマス仕入入荷 |
| 12 | 楽天SS第4弾／**クリスマスピーク**／お歳暮 | 翌年1月福袋・春商品企画着手 |

**広告予算配分**：
- 通常月：100
- 母の日／敬老の日／クリスマス／楽天SS／プライムデー：200-300
- ブラックフライデー：300

## エッジケース

- **新規ブランドで前年実績がない**：業界平均的なピーク月を採用し、初年度は「実績収集年」として割り切る。翌年から自社実績ベース。
- **海外仕入で旧正月を逃すリスク**：12月までに発注完了が安全。1月以降の発注は3月末以降の入荷を覚悟。
- **賞味期限が短い商品（食品）**：シーズン終了前に消化できる発注量に制限。賞味期限制約は `reorder-point-forecast-lite` 参照。
- **モールセールが重複する月（3・6・9・12月）**：楽天SS／お買い物マラソン／自社セールが重なる。広告予算と在庫が同時に必要、優先順位を決める。
- **業界別ピークが薄いジャンル（雑貨・ベビー通年商品）**：モールセールへの参加で売上ピークを作る設計。

## 注意事項

- モールセールの日程は変動する。各モール公式（楽天RMS・セラーセントラル・Yahoo!ストアマネージャー）で最新確認。
- 海外仕入の旧正月（中国・東南アジア）は2〜3週間の生産停止。年末までの発注完了が安全。
- 配送業者（ヤマト・佐川・日本郵便）の繁忙期は通常+1〜2日遅延。お中元・お盆・お歳暮・年末は特に。
- 商品ジャンル別ピークは業界平均値。自社実績との乖離が大きい場合は自社データを優先。
- 母の日／父の日／敬老の日の日付は毎年変わる（第○日曜・第○月曜）。年初に必ずカレンダーで確認。
- イベント終了後の表記オフ日（「母の日」「○月○日まで」削除・広告停止・LP切替）を必ずカレンダーに入れる。
- ステマ規制・薬機法・景表法の遵守は別スキル（`yakki-keihyo-expression-check` `influencer-brief-generator`）で確認。
