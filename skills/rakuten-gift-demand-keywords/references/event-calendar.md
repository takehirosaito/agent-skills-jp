## 検索ピーク前後の運用

| 時期 | 運用内容 |
|---|---|
| ピーク2-4週間前 | キーワード設定完了、商品ページ準備、在庫確保 |
| ピーク2週間前 | 早割訴求、メルマガ配信 |
| ピーク1週間前 | あす楽・即日訴求、最終受付告知 |
| ピーク前日〜当日 | 即日商品中心、配送日確定告知 |
| ピーク翌日 | 該当イベント文言を即削除／通年版へ |

## イベント別 配送日指定の重要度

| イベント | 配送日指定の重要度 | 注記 |
|---|---|---|
| 母の日／父の日 | 高 | 当日着希望が多い |
| バレンタイン／ホワイトデー | 高 | 13日着指定が殺到 |
| クリスマス | 中 | 24日着 or 25日着 |
| お中元／お歳暮 | 高 | 受付期間が地域で異なる |
| 敬老の日 | 中 | 当日着 or 前日着 |
| 誕生日 | 高 | 個別指定が必須 |
| 内祝い・出産祝い | 低 | 配送日指定不要なことも |
