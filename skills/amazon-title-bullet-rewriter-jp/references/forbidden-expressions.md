# 禁止表現・カテゴリ別NG

タイトル・bullet・商品説明欄で使ってはいけない表現の一覧。

## 全カテゴリ共通の禁止表現

### 最上級・誇大表現
- 「No.1」「ナンバーワン」「1位」「業界一」「世界一」「日本一」
- 「最高」「最強」「最高峰」「最先端」「最大」
- 「世界初」「日本初」「業界初」「唯一」
- 「最も」「断然」「圧倒的」

→ 根拠5項目（主体・期間・対象・方法・出典）が必要。Amazon もブランドストアの審査でリジェクト対象。

### 断定表現
- 「絶対」「必ず」「100%」「完全」「完璧」
- 「全員」「すべての方」「万能」
- 「○○できます！」（実態に裏付けなし）

### プロモーション期間語
- 「セール中」「期間限定」「数量限定」「在庫限り」
- 「タイムセール」「割引中」「半額」「○%OFF」
- 「お買い得」「お得」「特価」

→ タイトル・bullet は永続表示なので NG。

### Amazon ポリシー違反
- 「Amazon限定」（事実でない場合）
- 「Amazonで購入」「Prime対象」（タイトル本文に書く必要なし）
- 「Amazonランキング1位」（他媒体ランキング含む）

### 競合への言及
- 競合他社ブランド名・商品名
- 「○○A社比 ○%」「他社製品より優れています」

### 装飾過剰
- 「✨」「♥」「★★★」（絵文字）
- 「【超軽量】【高性能】【LED搭載】」（装飾記号過多）
- 全大文字英文（「BEST QUALITY」等）

### 外部誘導
- URL・メールアドレス・電話番号
- 「○○で検索」「公式サイトへ」
- SNS（X / Instagram / TikTok）への誘導

### HTMLタグ
- `<br>` `<p>` `<b>` 等
- bullet は通常テキストのみ

## 化粧品の禁止表現

### 化粧品56項目外の効能
- 「シミが消える」「シミを治す」「シワを治す」「シワが改善」
- 「美白」（医薬部外品の承認効能、化粧品では使えない）
- 「アンチエイジング」「若返り」「年齢肌を治す」
- 「ニキビが治る」「ニキビを治療」
- 「アトピー」「アトピーが治る」
- 「リフトアップ」「血行促進」「ターンオーバー促進」
- 「細胞活性化」「肌の再生」

### 化粧品56項目内（OK）
- 「肌にうるおいを与える」
- 「皮膚を保護する」
- 「皮膚の乾燥を防ぐ」
- 「日やけによるシミ・ソバカスを防ぐ」（37番）
- 「乾燥による小ジワを目立たなくする」（56番、試験必要）

### 医薬部外品の承認効能（医薬部外品のみOK）
- 「メラニンの生成を抑え、シミ・ソバカスを防ぐ」
- 「肌荒れを防ぐ」
- 「ニキビを防ぐ」（防ぐ＝予防のみ、治療はNG）

詳細：`yakki-keihyo-expression-check` スキルの `references/cosmetics-56-effects.md`

## 食品の禁止表現

### 一般食品で禁止
- 「効く」「効能」「効果」（具体的健康効果）
- 「治る」「治療」「予防」
- 「ダイエット」「痩せる」「脂肪燃焼」「太りにくい」
- 「血圧低下」「血糖値抑制」「コレステロール改善」
- 「免疫力向上」「腸内環境改善」「アンチエイジング」

### トクホ・機能性表示食品（届出文言の範囲内でOK）
- トクホ：許可された保健の用途のみ
- 機能性表示：届出文言のまま改変不可、届出番号併記
- 栄養機能食品：国の定型文のまま

### OK表現（一般食品）
- 「忙しい朝の手軽な食事に」
- 「美味しい・コクのある味わい」
- 「素材・産地」（具体的事実）
- 「賞味期限」「保存方法」

## ベビー・キッズの禁止表現

- 「絶対安全」「事故ゼロ」「100%安心」
- 「アレルギーゼロ」
- 「○○病が治る・治療」
- 医療的効能訴求

### OK
- 「SGマーク取得」「STマーク取得」（事実）
- 「対象月齢○ヶ月〜」（具体的）
- 「素材検査済み・第三者機関」

## ペットの禁止表現

- 「治る」「治療」「予防」（動物医薬品的）
- 「ガン予防」「アレルギー改善」
- 「絶対安全」

### OK
- 「年齢別の栄養配合」
- 「グレインフリー」
- 「タンパク質含有率○%」

## 家電の禁止表現

- 根拠なき「世界最強の吸引力」「最高性能」
- 安全規格未取得品の販売自体が法令違反

### OK
- 「PSE取得済み」（事実、Amazon カテゴリでは販売条件）
- 「吸引力○kPa」「消費電力○W」（数値）

## アパレルの禁止表現

- 「絶対色落ちしない」（断定）
- 「アトピー・敏感肌の方も安心」（医薬品的）
- 「世界最高の素材」（根拠なき最上級）

### OK
- 「綿100%・肌触りの良い天然素材」
- 「色落ちに配慮した染色加工」
- 「サイズ感はモデル身長170cm Mサイズ着用」

## ジュエリー・時計の禁止表現

- 「永久保証」（実際に永久でない場合）
- 「世界限定○本」（販売数の偽り）
- 「ダイヤモンドのカラットを誤魔化す表記」

## 医療機器・健康器具の禁止表現

- 未承認医療機器の効能訴求
- 「美容医療」「医療効果」（承認なし）
- 物理的行為以外の身体への影響訴求

## 文具・オフィスの禁止表現

- 一般的な誇大表現
- 「○○製の最高品質」（根拠なし）

## ステマ規制違反

2023年10月施行のステマ規制：
- 事業者のために行うのに「広告」「PR」表示なし
- インフルエンサー投稿の隠匿
- 自社レビュー操作

→ タイトル・bullet には直接出ないが、商品ページ全体・関連投稿で違反すると Amazon サスペンドリスク

## 違反検出のためのキーワードリスト

機械的にスキャンすべき NG ワード：

```text
NG_WORDS = [
    # 最上級
    "No.1", "ナンバーワン", "業界一", "世界一", "日本一", "最高",
    "最強", "業界唯一", "世界初", "日本初",
    # 断定
    "絶対", "必ず", "100%", "完全", "完璧",
    # プロモ
    "セール中", "期間限定", "割引中", "半額",
    # 薬機（化粧品）
    "シミが消える", "シワを治す", "美白",  # 医薬部外品でないとNG
    "アンチエイジング", "若返り", "リフトアップ",
    "ニキビを治療", "アトピーが治る",
    # 薬機（食品）
    "ダイエット", "痩せる", "脂肪燃焼",
    "血圧低下", "血糖値抑制", "免疫力向上",
    "ガン予防",
    # 一般
    "治る", "治療", "効く", "効能",
]
```

## チェック手順

タイトル・bullet 完成後：
1. 全文を1つの文字列に結合
2. NG_WORDS をスキャン
3. 該当語をハイライト
4. 該当ありなら代替表現で書き換え
5. 再スキャンで0件確認

## 違反時の影響

| 違反 | 影響 |
|---|---|
| Amazon ポリシー違反 | 検索ペナルティ・出品停止 |
| 景表法違反 | 措置命令・課徴金（売上3〜4.5%） |
| 薬機法違反 | 措置命令・業務停止・刑事罰 |
| 商標権侵害 | 損害賠償・差止請求 |

## 代替表現の例

| NG | 代替 |
|---|---|
| シミが消える | 日やけによるシミ・ソバカスを防ぐ（化粧品56項目37） |
| 美白（化粧品） | エイジングケア（年齢に応じたお手入れ） |
| 痩せる（食品） | 美しいスタイルを目指す方に |
| 血圧低下（一般食品） | 健康的な毎日を |
| No.1 | （根拠あれば）2025年○○調査で1位（主体・期間・対象明示） |
| 絶対安全 | 安全基準SG・EN1888準拠 |
| 最高品質 | 国内検査済み・第三者機関認証 |
