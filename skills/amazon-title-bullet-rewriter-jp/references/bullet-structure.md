# bullet 5箇条 構造ガイド（要点）

bullet 詳細は `amazon-bullet-attribute-benefit` スキル参照。本ファイルではタイトルとの連動という観点で要点をまとめる。

## bullet の基本仕様

| 項目 | 仕様 |
|---|---|
| 件数 | 5件 |
| 1件のバイト上限 | 255バイト |
| 検索インデックス | 先頭1,000バイト（タイトル＋bullet 1-2 で約100〜250字相当） |
| HTML | 不可 |
| 改行 | 不可 |
| 絵文字 | 不可 |

## タイトルとの役割分担

### タイトルが担う
- ブランド名
- 商品名
- 主要差別化属性（2〜3個）
- カテゴリ語
- 安心要素の核

### bullet が担う
- 主要属性の**ベネフィット詳細**
- タイトルで言えない補助属性
- 顧客不安への先回り回答
- 安心要素の詳細

## bullet 5項目の標準構造

| # | テーマ | 内容 |
|---|---|---|
| 1 | 主訴求 | タイトル主要属性のベネフィット深掘り |
| 2 | 差別化属性 | 競合と違う独自属性のベネフィット |
| 3 | 使い勝手 | 使用シーン・操作の容易さ |
| 4 | 安心要素 | 保証・認証・素材の安全 |
| 5 | 互換・サイズ・付属 | 適合・サイズ展開・対応規格 |

## タイトル → bullet の展開例

### タイトル
「[ブランド] コードレス掃除機 1.2kg 片手対応 LED搭載 20kPa強力吸引 国内2年保証」

### bullet 展開

| # | タイトル要素 | bullet 内容 |
|---|---|---|
| 1 | 1.2kg・片手対応 | 「1.2kg軽量・片手で天井まで。両手で持つ重さだった〜」（詳細＋シーン） |
| 2 | 20kPa強力吸引 | 「吸引力20kPa・ワンパス除去。フローリングの細かい砂や〜」（詳細＋効果） |
| 3 | LED搭載 + 補助 | 「40分連続稼働・LED搭載。1回の充電で〜」（補助属性40分も追加） |
| 4 | （タイトル外） | 「HEPAフィルター・花粉99.97%捕集。0.3μm粒子の〜」（タイトル外の安心要素） |
| 5 | 国内2年保証 | 「日本国内2年保証。メーカー直販で〜」（詳細＋サポート内容） |

→ タイトルの主要KW を bullet で深掘り、タイトルで言えなかった補助属性を bullet で補完。

## 「属性 × ベネフィット」の構造

### 良い bullet
```text
【見出し】属性（具体的事実）→ ベネフィット（顧客への価値）
```

例：
```text
【1.2kg軽量・片手で天井まで】両手で持つ重さだったハンディ掃除機を1.2kgに軽量化。片手で天井のホコリまで届き、高齢のご家族にも扱いやすい設計です。
```

### NG bullet（属性のみ）
```text
重量1.2kg、高さ45cm、幅12cm、奥行7cm
```
→ 仕様書貼り付け、顧客は読まない

### NG bullet（ベネフィットのみ）
```text
驚きの軽さ。誰でも快適に使えます。
```
→ 抽象的、信頼できない

詳細：`amazon-bullet-attribute-benefit` スキル

## 文字数（バイト数）の目安

| 全角字数 | バイト数 |
|---|---|
| 50字 | 150バイト |
| 60字 | 180バイト |
| 70字 | 210バイト |
| 80字 | 240バイト |
| 85字 | 255バイト |

実務目安：**1bullet あたり全角50〜80字**

## タイトルと bullet で「同じ KW を繰り返す」べきか

### YES の場合
- タイトル：主要KW（短い形）
- bullet：同じKW を文脈の中で詳説

例：
- タイトル：「20kPa強力吸引」
- bullet：「吸引力20kPa・ワンパス除去」

両方に「20kPa」が入るが、文脈が違う。冗長ではない。

### NO の場合
- 同じKWを同じ文脈で繰り返す
- 例：bullet 1 と bullet 3 で「軽量」を別の文脈なく繰り返す
- → 情報密度低下、もったいない

## 情報密度の最大化

5箇条で同じことを繰り返さず、5つの異なる視点を入れる：

| 視点 | 例（コードレス掃除機） |
|---|---|
| 1. 顧客便益 | 軽量・片手対応 |
| 2. 性能 | 吸引力 |
| 3. 機能 | LED・連続稼働 |
| 4. 安全・健康 | HEPA・花粉 |
| 5. 保証 | 国内2年 |

5箇条で5つの異なる「買う理由」を提示する。

## 数字を必ず入れる

各 bullet に数字を最低1つは入れる：
- 重量、容量、寸法
- 連続稼働時間、保証年数、対象月齢
- 成分割合、捕集率

数字は具体性・差別化・説得力に直結。

## 顧客不安への先回り

レビュー・Q&Aで頻出する不安を bullet で先回り：

| 顧客の不安 | bullet での回答 |
|---|---|
| ペットがいるけど大丈夫？ | bullet 3-4 で「ペット家庭にも」 |
| バッテリーは交換できる？ | bullet 5 で「バッテリー単体購入可」 |
| 保証はある？ | bullet 5 で「国内2年保証」 |
| サイズはどれくらい？ | bullet 5 で「折畳サイズ○cm」 |

詳細：`amazon-review-qa-mining` スキル

## 5箇条のNGパターン

### 1. 同じテーマを複数bulletで
- bullet 1 と 2 で「軽量」を別表現で繰り返し
- 情報密度低下

### 2. 抽象的表現の連発
- 「最高の品質」「驚きの使い心地」
- 具体性なし

### 3. 仕様羅列のみ
- 数字だけで読み物にならない
- ベネフィットが不在

### 4. 5箇条で完結しない情報
- 「詳細は商品説明欄をご覧ください」
- bullet は完結した情報を

### 5. bullet 5項目が独立していない
- 1〜5が連続した文章のように繋がっている
- 各bullet は独立して読める単位に

## 「タイトルと bullet」を1セットで設計する手順

### Step 1：商品の属性とベネフィットを全列挙
### Step 2：最重要属性 2〜3個を抽出 → タイトルへ
### Step 3：残り属性を bullet 5項目に配分
### Step 4：タイトルの主要属性を bullet 1-2 で深掘り
### Step 5：タイトル外の補助属性を bullet 3-5 で補完
### Step 6：禁止表現・文字数チェック
### Step 7：検索インデックス先頭1,000バイトに主要KW

## 完成後の検証

| 検証項目 | OK基準 |
|---|---|
| タイトル文字数 | カテゴリ別上限内 |
| bullet 各バイト数 | 255バイト以内 |
| タイトル＋bullet 1-2 合計 | 1,000バイト以内に主要KW |
| 主要KW の役割分担 | タイトル中心、bulletで深掘り |
| 5箇条の独立性 | 各bullet が完結している |
| 数字 | 各bullet に1つ以上 |
| 顧客不安への先回り | Q&A 上位質問に bulletで回答 |
| 禁止表現 | なし |
