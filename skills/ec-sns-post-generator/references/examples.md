## 例1：コスメ（化粧水）／Instagram フィード／自社アカウント

### 前提
- 媒体：Instagram フィード（1:1）
- 投稿主体：自社
- PR表記：不要（自社アカウント＝明らかな事業者の表示）

### キャプション

```
朝のスキンケアに、新しい時間を。

30代を過ぎて、いつもの化粧水で物足りなさを感じる方へ。
単一農園で栽培した○○エキスを保湿成分として配合した、
保湿化粧水ができました。

肌のうるおいを保つ、シンプルな処方。
余計なものは入れず、必要なものだけ。

肌のうるおいを保ちたい、自分にやさしい時間を作りたい
そんな日々のお手伝いができれば嬉しいです。

▼商品詳細はプロフィールリンクから

#保湿化粧水 #乾燥肌スキンケア
#30代スキンケア #シンプルスキンケア
#国産化粧品 #農園コスメ
#コスメ好きさんと繋がりたい
```

### 画像（カルーセル5枚）
1. 商品＋朝の窓辺
2. 成分表示の図解
3. 単一農園の写真
4. テクスチャ
5. パッケージ全体

### 法務チェック
- 「保湿」「うるおいを保つ」：56項目内 OK
- 「効く」「治る」「シミ消える」未使用 OK
- 個人属性断定なし
- PR表記不要（自社）

## 例2：機能性表示食品（脂肪対策）／TikTok／インフルエンサーPR

### 前提
- 媒体：TikTok 縦動画15秒
- 投稿主体：インフルエンサー（事業者から依頼・対価あり）
- PR表記：**必須**

### 動画台本（15秒）

```
[0-2秒]
画面全面に「PR」テロップ（黒帯＋白文字・常時表示）
インフルエンサー：「PRです。40代の私が始めたサプリ」

[2-7秒]
商品アップ＋「機能性表示食品 届出番号A123」字幕
ナレ：「葛の花由来イソフラボンが脂肪を減らすのを助けるサプリ」

[7-12秒]
パッケージ開封シーン＋使用シーン
字幕：「1日2粒、続けています」

[12-15秒]
オファー画面：「初回70%OFF」＋公式リンク
インフルエンサー：「気になる人はプロフィールから」
```

### キャプション

```
PR｜40代から始めた、内臓脂肪対策サプリ #PR
葛の花由来イソフラボンの機能性表示食品です（届出番号A123）。
1日2粒、続けて3ヶ月。
気になる人はプロフィールから🔗

#PR #機能性表示食品 #40代の健康
```

### 法務チェック
- PR表記：動画冒頭から常時表示＋キャプション冒頭にも明記
- 届出番号A123を動画字幕＋キャプション両方で明示
- 機能性表示の届出文言と一字一句一致
- 「○kg痩せた」「内臓脂肪が消えた」NG（届出文言外）
- before/afterは使用不可

## 例3：家電（コードレス掃除機）／X（旧Twitter）／自社アカウント

### 前提
- 媒体：X
- 投稿主体：自社
- PR表記：不要

### ポスト1（140字以内）

```
夜21時、階下を気にせず掃除できる。

騒音dB58実測の物理ダンパー構造コードレス掃除機。
集合住宅の30代共働きの方に。

商品詳細▼
（自社URL）

#コードレス掃除機
```

### ポスト2（140字以内）

```
「夜の掃除、本当にいいよね」というお声を多くいただいています。

3万円台で5年保証＋30日返金保証。
プロフィールから商品ページへ。

#時短家電
```

### 法務チェック
- 「-12dB」根拠：競合機種・測定機関を商品ページで明示
- 「No.1」「絶対」未使用
- 個人属性断定なし

## 例4：アパレル（メンズスニーカー）／Instagram リール／インフルエンサーPR

### 前提
- 媒体：Instagram リール 30秒
- 投稿主体：インフルエンサー（事業者から商品提供）
- PR表記：**必須**

### 動画台本（30秒）

```
[0-3秒]
画面冒頭に「PR」テロップ＋音楽
インフルエンサー：「PRです。育てるスニーカー、買ってみた」

[3-15秒]
商品開封シーン＋装着
ナレ：「30代向けレザースニーカー。修理保証5年。」

[15-25秒]
コーディネート3パターン（カジュアル／ジャケット／オフィスカジュアル）
字幕：「シーンを選ばない」

[25-30秒]
オファー画面：「サイズ交換無料／送料無料」＋ブランド名
インフルエンサー：「気になる人はストーリーから飛べます」
```

### キャプション

```
【PR】30代の靴選びに迷ってる人へ #PR
○○ブランドの育てるレザースニーカー、
修理保証5年でサイズ交換無料です。
3パターンでコーデしてみました🔗ストーリーから

#PR #メンズコーデ #大人カジュアル
#スニーカーコーデ
```

### 法務チェック
- PR表記：動画冒頭＋キャプション冒頭
- 「修理保証5年」：事業者側の実運用と一致
- 「サイズ交換無料」：実運用と一致
- ブランド名タグだけでPR表記なしはNG

## 例5：食品ギフト（バスクチーズケーキ）／Instagram ストーリー／自社

### 前提
- 媒体：Instagram ストーリー（5枚連投）
- 投稿主体：自社
- 期間：母の日2週間前

### スライド1
- 画像：商品＋カーネーション
- テキスト：「母の日、5月8日までお届け」
- スタンプ：カウントダウン「あと10日」

### スライド2
- 画像：開封シーン
- テキスト：「職人手作りのバスクチーズケーキ」

### スライド3
- 画像：メッセージカード見本
- テキスト：「メッセージカード付き／のし対応／母の日限定包装」

### スライド4
- 画像：配送スケジュール表
- テキスト：「5月1日まで＝5月3日着／5月8日まで＝5月10日着」

### スライド5
- 画像：商品＋オファー帯
- テキスト：「送料無料・5月8日まで」
- スタンプ：リンクスタンプ（商品ページへ）

### 法務チェック
- 特定原材料8品目（卵・乳・小麦）：商品ページで明示
- 配送締切：FV／LP／投稿の3箇所で明示
- 「日本一」「No.1」未使用
- イベント後（5月11日以降）の投稿停止計画

## 例6：ペット用品（猫用フード）／Threads／自社アカウント

### 前提
- 媒体：Threads
- 投稿主体：自社
- PR表記：不要

### ポスト（500字以内）

```
猫のフードを選ぶとき、何を重視していますか？

うちの商品は、肉種別の％を全公開しています。
チキン30% / サーモン20% / ラム10% ──など。

「肉類」とだけ書いてあるフードが多い中で、
「うちの子に何を食べさせているか」を
飼い主さんに知ってほしいと思っています。

商品詳細はプロフィールから。

#愛猫家
```

### Instagram連動
- 同じ投稿をInstagramフィードでも展開
- ストーリーで「Threadsでも話してます」誘導

### 法務チェック
- ペットフード安全法：原材料表記が商品ページで明示
- 「療法食」と混同される表現を避ける
- 「獣医監修」未使用（実態を伴わないとリスク）

## 例7：レビュー転載（自社EC内）の注意

### NG例（化粧品）

```
「3週間使ってシミが薄くなりました！」「肌が見違えるほど明るく！」
──★★★★★ Aさん（30代女性）
```
→ 効能効果に関するレビューは事業者の表示として薬機法違反

### OK例（化粧品）

```
「香りが好きで毎朝のスキンケアが楽しみになりました」
──★★★★★ Aさん（30代女性）
```
→ 効能効果に触れていないレビューは転載可

### NG例（健食・一般食品）

```
「3ヶ月で-5kg達成！」
──★★★★★ Bさん（40代男性）
```
→ 一般食品の効能効果訴求は薬機法違反

### OK例（機能性表示食品で届出文言の範囲内）

```
「3ヶ月続けています」
──★★★★★ Bさん（40代男性）
```
