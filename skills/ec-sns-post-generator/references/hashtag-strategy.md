# 媒体別ハッシュタグ戦略

ハッシュタグは「検索流入」と「アルゴリズム」両方に効くが、媒体によって最適個数・組み合わせが異なる。

---

## Instagram

### 推奨個数
- **5-15個**（多すぎると逆効果、20個超は減速）
- リールは少なめ（3-10個）でも問題なし

### タグの組み合わせ

| 種類 | 例（保湿化粧水） | 目的 |
|---|---|---|
| ブランド | #ブランド名 #商品名 | ブランド認知 |
| カテゴリ・大 | #スキンケア #化粧水 #コスメ | 大規模リーチ |
| カテゴリ・中 | #保湿化粧水 #乾燥肌スキンケア | ターゲット流入 |
| カテゴリ・小（ニッチ） | #30代スキンケア #敏感肌コスメ | 質の高い流入 |
| ターゲット | #30代女性 #働く女性 | ペルソナマッチ |
| トレンド | #PR #コスメ好きさんと繋がりたい | 拡散性 |

### 配置
- キャプション末尾（推奨）
- 最初のコメント欄（タグを隠したい場合）
- 「.」を改行で挟んで視覚的に分離

### NG
- 関係ない人気タグの濫用（#followme #l4l 等）
- 25個超
- 大規模タグだけ（#コスメ 数百万投稿 だと埋もれる）

---

## X（旧Twitter）

### 推奨個数
- **1-2個**が最適
- 3個以上はスパム感

### タグの目的
- トレンド連動（イベント・季節）
- ブランドキャンペーン（独自タグ）

### 例

```
朝のカサつきが気になる季節。
単一農園素材の保湿化粧水で、肌のうるおいを保つ朝のスキンケアを。
プロフィールから詳細▼ #乾燥対策
```

### NG
- 1ポストに大量タグ
- 関係ないトレンドタグ便乗
- 文中にタグ多用で読みにくい

---

## TikTok

### 推奨個数
- **3-5個**＋トレンドタグ

### 組み合わせ

| 種類 | 例 |
|---|---|
| ブランド | #ブランド名 |
| カテゴリ | #スキンケア #コスメ |
| トレンド | #PR #コスメ好きさんと繋がりたい #おすすめ |
| 行動誘発 | #フォローしてね #保存して見直して |

### TikTokトレンドタグ
- For You ページで使われている流行タグを最新でチェック
- 「○○チャレンジ」「○○トレンド」に乗る

### NG
- 1動画に10個以上のタグ
- 関係ないバズタグ便乗

---

## Threads

### 推奨個数
- **1-3個**で十分
- まだタグ文化が固まっていない（2024-2025）

### 例

```
朝のスキンケア、何を使ってますか？
うちは単一農園素材の化粧水を3ヶ月リピート中です🌱

#スキンケア
```

### 戦略
- 会話・問いかけ中心
- タグよりもリプライ・コミュニケーションが伸びる

---

## YouTube Shorts

### 推奨個数
- **3-5個**
- タイトル・説明文に分散

### 戦略
- 検索ボリュームのあるキーワードをタグ化
- YouTube本動画への導線で長期SEO

---

## ハッシュタグ運用の基本原則

### 1. 規模の異なるタグを組み合わせる
- 大規模（数百万投稿）：露出は多いが埋もれる
- 中規模（数十万投稿）：バランス良し
- 小規模（数千〜数万）：質の高い流入

### 2. ターゲットが検索するタグを優先
- 自社ブランド名／商品名
- ターゲットが調べる悩み・状況
- カテゴリの中でも「自分向け」と感じるタグ

### 3. PR表記タグは独立して目立たせる
- 「#PR」を末尾大量タグの最後に紛れ込ませるとステマ規制違反
- 投稿冒頭または独立した行に明示

### 4. 季節・イベント連動

| 季節 | タグ例 |
|---|---|
| 春 | #春コスメ #花粉症対策 #母の日ギフト |
| 夏 | #紫外線対策 #日焼け対策 #夏ファッション #お中元 |
| 秋 | #秋メイク #ハロウィン #敬老の日 |
| 冬 | #乾燥対策 #ホワイトデー #バレンタイン #お歳暮 #クリスマス |

## 禁止／要注意タグ

### 各媒体共通
- アダルト関連
- 差別的タグ
- 著作権侵害（無断のキャラクター名）

### Instagram注意
- 過去にシャドウバンを受けたタグ（変動するので最新検索で確認）

### TikTok注意
- 危険行為タグ
- 健康被害誘発タグ

---

## ステマ規制とハッシュタグ

- **「#PR」を末尾の大量タグに埋もれさせるのはNG**
- 投稿冒頭の本文に「【PR】」「PR｜」と明記＋末尾タグにも「#PR」を独立配置
- 媒体のタイアップ投稿機能（Instagram Paid Partnership、TikTok Spark Ads）併用

---

## ハッシュタグ分析と改善

### 投稿後にチェック
- リーチ（タグ経由の見られた数）
- 保存・共有（タグから来た人の行動）

### 改善
- 効果の出るタグを2-3週おきに見直し
- 季節タグの入れ替え
- ニッチタグを増やして質を上げる
