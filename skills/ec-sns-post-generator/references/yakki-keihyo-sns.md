# SNS特有の薬機法・景表法リスクと言い換え

SNS投稿でやりがちなNGパターンと、適法な言い換え。

---

## 化粧品（化粧品・医薬部外品）

### 化粧品で言える効能効果56項目（代表）
- 「肌のキメを整える」「肌荒れを防ぐ」
- 「皮膚にうるおいを与える」「皮膚を保護する」
- 「日やけによるシミ・ソバカスを防ぐ」（日焼け止め含む）
- 「乾燥による小ジワを目立たなくする」（試験必要）
- 詳細：yakki-keihyo-expression-check スキル

### 医薬部外品（薬用化粧品）で追加で言えること
- 「メラニンの生成を抑え、シミ・ソバカスを防ぐ」（美白訴求）
- 「肌荒れを防ぐ」「ニキビを防ぐ」（薬用）
- 「皮膚を清浄にし、にきびを防ぐ」（洗顔料）
- 容器・包装に「医薬部外品」表示があること

### NG → OK 言い換え（SNS）

| NG | OK |
|---|---|
| シミが消えました！ | 日やけによるシミ・ソバカスを防ぐ |
| シワが減った！ | 乾燥による小ジワを目立たなくする（試験必要） |
| アンチエイジング | エイジングケア（年齢に応じたお手入れ） |
| 美白効果あり（化粧品） | 化粧品では言えない／医薬部外品なら可 |
| ハリ・弾力回復 | 肌にハリを与える |
| 毛穴が消える | 肌のキメを整える |
| ニキビが治った（化粧品） | 化粧品では言えない／医薬部外品で「肌荒れを防ぐ」 |
| 顔のリフトアップ | （化粧品では言えない／物理的なマッサージのみ） |

### before/after画像
- **化粧品では原則NG**
- メーキャップ・物理効果（化粧くずれ防止・カラーリング）のみOK
- 「スキンケアによる肌の変化」を示すbefore/afterは違反扱い

## 健康食品

### カテゴリ別の言える範囲

| カテゴリ | 言える範囲 | SNSでの注意 |
|---|---|---|
| 特定保健用食品（トクホ） | 許可された保健の用途 | 表現は許可文言と一致 |
| 機能性表示食品 | 届出した機能性表示 | **届出番号必須**、届出文言と一字一句一致 |
| 栄養機能食品 | 国の定型文のみ | 改変NG |
| いわゆる健康食品 | 効能効果の標榜不可 | 一般的表現のみ |

### NG → OK 言い換え（SNS）

| NG | OK |
|---|---|
| 痩せる／脂肪燃焼（一般食品） | 「美しいスタイルを目指す方に」 |
| -5kg達成！ | 機能性表示食品の届出文言以外NG／個人の体験談として書いてもNG |
| 便秘解消（一般食品） | 「毎日のスッキリをサポート」 |
| 血圧が下がった（一般食品） | 「健康な毎日を」 |
| 内臓脂肪が消えた（機能性表示） | 届出文言「葛の花由来イソフラボンには、肥満気味の方の体重・お腹の脂肪を減らすのを助ける機能があることが報告されています」 |
| 病気が治った | 削除（薬機法違反・体験談でもNG） |

### 機能性表示食品をSNSで紹介する場合の必須項目
- **届出番号（A123等）を必ず併記**
- 機能性表示文言と一字一句一致
- 摂取目安量・摂取上の注意（簡略でも触れる）
- 「機能性表示食品」と明示
- before/after画像はNG

## 美容雑貨・健康器具

### NG → OK 言い換え

| NG | OK |
|---|---|
| 血行促進（雑貨） | 「マッサージ」「お手入れ」 |
| リフトアップ（雑貨） | 物理的な「引き上げ動作」「ストレッチ」 |
| 痩身効果（雑貨） | 「セルフケア時間」「リフレッシュ」 |
| シワ改善（美顔器） | 一般家電なら「肌のお手入れ」／医療機器承認があれば承認範囲内 |
| 治る／治療（雑貨） | NG（医療機器扱いになる） |

雑貨を「未承認医療機器」扱いとされるリスクがあるので、**身体の構造機能への影響を標榜しない**。

## 景表法（最上級表現・No.1表記）

### NG → OK 言い換え

| NG | OK |
|---|---|
| 業界No.1！ | 根拠5項目（主体・期間・対象・方法・出典）併記 |
| 日本初の○○ | 客観的に確認できる事実のみ |
| 最安値！ | 根拠なしならNG／「お得な価格」「リーズナブル」 |
| 絶対○○！ | 「○○できる」（断定回避） |
| 100%満足保証！ | 「30日返金保証」（具体的条件で） |
| 永久保証 | 「○年保証」（具体期間） |
| 完全無添加 | 「○○・○○・○○不使用」（具体的に列挙） |
| 完治／治癒 | NG（薬機法でも） |

### No.1表記の必須5項目
- 調査主体
- 調査期間
- 調査対象
- 調査方法
- 出典

SNSでは文字数が限られるが、必ず**何らかの形で明示**する。例：「○○調べ 2024年4月 全国の20-60代女性1,000名調査 楽天市場保湿化粧水部門売上1位」

## 二重価格表示（SNS）

- 「通常価格○○円→今だけ○○円」を投稿に書く場合、**セール開始直前8週間中4週間以上の実販売実績**が必要
- 「今だけ70%OFF」とSNSで言いつつ、常時セール中はNG（有利誤認）

## 体験談・お客様の声

### NG
- 「シミが消えました！」（化粧品なら薬機法違反）
- 「3ヶ月で-5kg」（一般食品・機能性表示の届出文言外）
- 「私もこのサプリで治りました」（薬機法違反）
- 個人の感想として書いてもNG（事業者の表示なら）

### OK
- 「使い心地が気に入っています」
- 「香りが好きです」
- 機能性表示食品で届出文言の範囲内

### 「個人の感想です」打消しの限界
- 打消し表示7原則を満たさなければ機能しない（極小文字・本文と離れすぎ等はNG）
- 効能効果の体験談を「個人の感想」として書いてもNGになる

---

## レビュー転載（自社サイトへのSNS埋め込み）

- 効能効果に関するレビューを自社サイトに転載すると**事業者の表示**となり、化粧品なら薬機法違反
- 「香り・使い心地・パッケージ」など効能効果に関わらないレビューのみ転載可
- インフルエンサーの投稿を埋め込む場合、**PR表記が含まれた投稿のみ**
