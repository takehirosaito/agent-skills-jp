# ステマ規制（2023.10.1〜）PR表記チェックリスト

景品表示法5条3号「一般消費者が事業者の表示であることを判別することが困難である表示」。

---

## 規制対象と責任

- **規制対象**：商品・サービスを供給する**事業者（広告主）のみ**
- インフルエンサー等の第三者は**規制対象外**だが、広告主が責任を負う
- 違反時の措置命令は広告主に対して行われる

---

## 「事業者の表示」と判断される条件

以下のいずれかに該当すると、第三者の投稿でも「事業者の表示」とみなされる：

- 事業者がインフルエンサーに**依頼・指示**している
- **対価関係**（金銭・商品提供・割引・将来の取引示唆）がある
- 投稿原稿の**事前確認・修正依頼**が行われている
- 投稿アカウントを事業者が指定している

---

## OK：明瞭な広告表示の例

### 表記の方法
- 投稿冒頭または常時表示で**「広告」「PR」「プロモーション」「Sponsored」**のいずれか
- 「A社から商品の提供を受けて投稿しています」等の文章
- 動画は**冒頭・終盤の両方**または**常時表示**
- Instagramの**タイアップ投稿機能（Paid Partnership ラベル）**
- YouTubeの**「有料プロモーションを含みます」表示**
- TikTokの**Spark Ads**化（投稿主アカウントに広告ラベルが付く）

### 表記サンプル（媒体別）

**Instagram キャプション冒頭**：
```
【PR】○○ブランドからご提供いただきました。
...
```

**X ポスト冒頭**：
```
PR｜○○ブランドさんから商品提供で投稿しています。
...
```

**TikTok 動画**：
- 動画冒頭から終盤まで「PR」字幕を常時表示
- キャプション冒頭にも「#PR」「【PR】」明記

---

## NG：不明瞭表示の例

| パターン | NG理由 |
|---|---|
| 投稿末尾に大量ハッシュタグで紛れ込ませる：「#コーデ #今日服 ... #PR」 | PRが他のタグに埋没 |
| 「もっと見る」を押さないと表示されない位置 | 一見して判別不能 |
| リプライ（ツリー）にのみ「広告」と記載 | 元投稿で判別不能 |
| 動画の冒頭のみ・極小フォント・背景同化色 | 視認できない |
| 動画の終盤のみ（短時間） | 視認不可 |
| アフィリエイトサイトでトップに小さく「アフィリエイト広告を利用しています」だけ | 個別記事の事業者依頼部分には別途明示が必要 |
| 「これすごく良かった！」とだけ書き、依頼関係を非開示 | 依頼関係の隠蔽 |
| 「@商品名」「@ブランド名」だけでPR表記なし | 依頼関係不明 |

## EC事業者がインフルエンサー起用時にすべきこと

### 1. 契約書／指示書でPR表記を義務化
具体例：

> 「投稿の冒頭または常時表示で『#PR』『広告』『プロモーション』のいずれかを明示すること。投稿末尾のハッシュタグ群への埋没は不可。動画の場合は冒頭・終盤の両方または常時表示で表記すること」

### 2. 投稿前の事前確認
- PR表記の位置・サイズ・コントラストを目視チェック
- スクリーンショットを保存

### 3. 過去投稿の継続表示確認
- 2023年10月施行前の投稿も、**継続表示中なら表記必須**
- 投稿主の過去アーカイブの見直し

### 4. ガイドライン明文化
- 自社の「インフルエンサー起用ガイドライン」を整備し、起用前に配布
- NG表現リスト・薬機法カテゴリ別の留意点を含む

---

## 違反時のペナルティ

- **措置命令**（差止・公示・再発防止）
- ステマ規制違反**単体では課徴金対象外**（ただし優良誤認・有利誤認に該当すれば課徴金対象＝売上3%）
- 公正取引委員会のステマ規制違反事業者として**公表**（風評リスク）

---

## 自社EC・自社サイトの場合

- 自社サイト上の商品紹介ページは**明らかに事業者の表示**なので、ステマ規制の対象外（広告と認識される前提）
- ただし、自社サイトに「**お客様の声**」「**レビュー**」として掲載する場合、**事業者が依頼・対価関係がある体験談なら事業者の表示**になる
- 「事業者が依頼して作成させた体験談を、第三者の口コミのように見せる」は典型的なNGパターン

---

## アフィリエイト広告との関係

- アフィリエイトサイト自体は媒体の判断でPR表記する
- ただし広告主（EC事業者）がアフィリエイターに**具体的に投稿原稿・表現を指示**している場合、「事業者の表示」となり、広告主に責任が及ぶ
- アフィリエイターに渡す素材・原稿・テンプレに「#PR を含めること」「具体的な訴求は依頼に基づくこと」等を明記

---

## レビュー・口コミの扱い

### OK
- **自発的なレビュー**（依頼・対価関係なし）：規制対象外
- **モニター調査結果の概要表示**：「商品提供を受けたモニター100名の声」と明記
- **★平均と件数の集計表示**：「★4.5 / 1,200件」

### NG
- 事業者がインフルエンサーに依頼した投稿を「第三者の自発的レビュー」のように見せる
- 効能効果に関するレビューを商品ページに「お客様の声」として転載（化粧品なら薬機法違反も）

## チェックリスト

投稿公開前に：

- [ ] PR表記が冒頭または常時表示か
- [ ] 表記が「PR／広告／プロモーション／Sponsored」のいずれか
- [ ] 末尾ハッシュタグ群に埋没していないか
- [ ] 「もっと見る」を押さずに見えるか
- [ ] 動画は冒頭・終盤両方または常時表示か
- [ ] 視認できるフォントサイズ・コントラストか
- [ ] 契約書／指示書でPR表記を義務化したか
- [ ] スクリーンショット保存

## よくある質問

### Q1：プレゼント企画でPR表記は必要？
A：「商品提供を受けて投稿」しているなら必要。「自分で買った商品をプレゼントとして配る」だけなら不要。

### Q2：会社の従業員が投稿する場合は？
A：従業員が職務として投稿しているなら事業者の表示。会社の利益のために投稿しているなら明示推奨。

### Q3：海外の商品を日本で紹介する場合は？
A：日本国内の消費者向け表示なら景表法適用。海外ブランドからの依頼でもPR表記必須。

### Q4：「個人の感想です」と書けば？
A：打消し表示としては機能しない。打消し表示7原則（文字サイズ・位置・コントラスト等）を満たさなければ違反扱い。PR表記とは別物。
