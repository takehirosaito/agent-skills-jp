# EC向けSNS投稿生成

## 概要

EC事業者が自社運用するSNS（Instagram フィード／リール／ストーリー、X（旧Twitter）、TikTok、Threads、YouTube Shorts）の投稿を、各媒体の文字数・拡散ロジック・トーン・ハッシュタグ戦略に合わせて生成する。

単発投稿だけでなく、新商品ローンチの4週間プラン／既存商品テコ入れの8週間プラン／季節キャンペーン（母の日・お中元等）のシリーズ設計にも対応する。薬機法（化粧品56項目・機能性表示食品の届出文言と届出番号）・景表法（No.1根拠5項目・二重価格8週間）・ステマ規制（PR表記）・媒体ポリシー（Meta系の個人属性断定）の4軸チェックを構成段階で組み込む。

## 最重要原則

**SNS投稿は「媒体ごとの拡散ロジック」と「カテゴリ別の法令」の両方を満たしてはじめて成立する。**

文字数を守るだけでは足りない。Instagramは保存数・共有数がアルゴリズムに効くため「保存したくなる情報設計」、Xは即時性とトレンド連動、TikTokは冒頭3秒と完視聴率、Threadsは会話的問いかけが拡散の源泉。一方で化粧品56項目外の表現・機能性表示食品の届出文言外・No.1の根拠不備・個人属性断定（Meta系）は1投稿で違反扱いになる。**媒体ロジック × カテゴリ法令** を両立する投稿だけを出す。

## 処理フロー

### Step 1：入力情報と前提確認

ユーザーから受け取る情報：
- 商品（商品名・カテゴリ・価格・USP）
- 配信媒体（複数可）
- 投稿目的（認知／興味関心／比較検討／購入直前／リテンション）
- キャンペーン条件（オファー・期間）
- ブランドトーン（敬語／カジュアル／関西弁等）
- 配信頻度／シリーズ要否（単発／シリーズ）
- ステマ規制対応の有無（自社運用か、インフルエンサー素材含むか）

不足している場合は仮置きで初稿を出し、冒頭に「最終確定にはXX確認が必要」を明示する。

### Step 2：商品カテゴリの法令前提確定

- 化粧品 → 56項目内、医薬関係者推薦NG、before/after原則NG
- 医薬部外品 → 承認効能内＋「医薬部外品」表示
- 機能性表示食品 → 届出番号＋届出文言と一字一句一致＋摂取目安に触れる
- いわゆる健康食品 → 効能効果の標榜不可（暗示的表現のみ）
- 美容雑貨／健康器具 → 身体への影響を標榜しない

カテゴリ不明の場合は最も可能性の高い「仮カテゴリ」で暫定投稿を出し、冒頭に「カテゴリ確認が必要」を明示する。

### Step 3：媒体ごとの最初の1行設計

どの媒体でも**1行目（モバイル冒頭表示）で離脱が決まる**：
- Instagram：「もっと見る」が出る前の最初の数行（80-100字程度）
- X：最初の30字
- TikTok：動画3秒＋キャプション20字
- Threads：最初の80字

最初の1行に「誰向け」「核ベネフィット」「フック」のいずれかを必ず置く。

### Step 4：媒体別の本文生成

各媒体の文字数・トーン・絵文字頻度・一文の長さを `references/media-culture.md` のガイドに合わせて生成する。

- Instagram：敬語ベース＋親しみ／絵文字適度／中文／世界観
- X：カジュアル多め／絵文字少なめ／短文／即時性
- TikTok：カジュアル＋テンポ／絵文字多め／超短文
- Threads：会話的・問いかけ／適度な絵文字

### Step 5：画像／動画指示

媒体別の比率と冒頭3秒設計：
- Instagram フィード：1:1（1080×1080）／4:5（1080×1350）
- Instagram ストーリー／リール／TikTok：9:16（1080×1920）
- リール／TikTok 動画は冒頭3秒に最重要要素＋字幕（音OFF視聴前提）

### Step 6：ハッシュタグ設計

`references/hashtag-strategy.md` のガイドに沿って、ブランド／カテゴリ大／カテゴリ中／ニッチ／ターゲット／トレンド の組み合わせを設計する。PR投稿の場合は **「#PR」を末尾の大量タグ群に紛れ込ませず、本文冒頭または独立行に明示** する。

### Step 7：法令＋ステマ規制チェック

- 化粧品56項目外の効能訴求なし
- 機能性表示食品は届出番号＋届出文言一字一句一致
- before/after画像（化粧品・健食）なし
- No.1・最上級・最安・「絶対」「100%」「完全」に根拠5項目併記 or 削除
- 二重価格は8週間ルール
- 「皮膚科医推薦」（化粧品）未使用
- 個人属性断定（Meta系の「あなたは○○ですね」）未使用
- ステマ規制：依頼・対価関係がある投稿はPR表記（冒頭または常時表示）、媒体機能（Instagram Paid Partnership／TikTok Spark Ads／YouTube有料プロモーション表示）を利用

### Step 8：シリーズ設計（必要時）

4週間／8週間プランの場合、Week 1（認知）／Week 2（興味）／Week 3（証拠）／Week 4（購入直前）の各週の投稿を生成する。季節キャンペーンは配送締切＋表記オフ日まで含める。

## 品質ゲート

- [ ] 各媒体の文字数を満たしている（Instagram2200字／X140字／TikTok150字推奨／Threads500字）
- [ ] 最初の1行（モバイル冒頭表示）で離脱しない設計になっている
- [ ] ハッシュタグの個数が媒体推奨範囲内（Instagram5-15／X1-2／TikTok3-5／Threads1-3）
- [ ] 化粧品56項目外の効能訴求を含まない
- [ ] 機能性表示食品の場合、届出番号と届出文言を一字一句一致で記載
- [ ] before/after画像（化粧品・健食）を使っていない
- [ ] No.1・最上級・最安・「絶対」「100%」「完全」に根拠5項目を併記 or 削除
- [ ] 「皮膚科医推薦」を化粧品で使っていない（化粧品適正広告ガイドライン違反）
- [ ] 個人属性断定（「あなたは○○ですね」）を使っていない（Meta系）
- [ ] PR表記が必要な場合、冒頭または常時表示で「PR／広告／プロモーション／Sponsored」を明示
- [ ] PR表記が末尾の大量ハッシュタグ群に埋没していない
- [ ] レビュー転載で効能効果に関する体験談を含まない（化粧品なら薬機法違反）
- [ ] 動画は冒頭3秒に最重要要素＋音OFF対応字幕
- [ ] 画像のテキスト占有率が20%以内
- [ ] 「個人の感想です」だけでは効能効果の体験談は擁護されない（打消し7原則を満たしても、事業者の表示なら違反扱い）

## エッジケース

1. **インフルエンサー投稿を埋め込む場合**：投稿に正しくPR表記がされているもののみ埋め込む。事業者依頼の体験談はステマ規制対象（広告主が責任）
2. **機能性表示食品で文字数が足りない（X140字）**：届出番号は短縮できないため、本文を圧縮しつつ届出番号・「機能性表示食品」明示・摂取目安への注記を残す
3. **季節キャンペーンの締切後**：投稿停止・通常版に切替、商品名／コピー／バナーから「母の日」「○月○日まで」を削除（運用カレンダーに表記オフ日を記載）
4. **TikTok For You ページ狙い**：完視聴率・ループ視聴を意識した動画台本、音楽トレンド連動、9:16必須、横動画は伸びない
5. **Threads でフォロワー少ない場合**：会話・問いかけで起点。商品宣伝より「使い心地・開発ストーリー」を語る。Instagram連動でリーチ補完

## 注意事項

- 各SNSの仕様（Instagram タイアップ投稿機能／TikTok Spark Ads／YouTube 有料プロモーション表示／X長文投稿）は変動するため、運用前に各媒体公式ヘルプの最新版を確認する
- ステマ規制（景表法5条3号・2023.10.1施行）対象は広告主のみ。インフルエンサー素材の利用、自社サイトの「お客様の声」で依頼・対価関係がある体験談はPR表記必要
- PR表記は「PR／広告／プロモーション／Sponsored」のいずれか。「もっと見る」を押さないと見えない位置／末尾ハッシュタグ群への埋没／極小フォント／動画末尾0.5秒のみ等はNG
- 化粧品適正広告ガイドラインで医薬関係者の推薦表示は原則NG
- 機能性表示食品は届出文言と一字一句一致＋届出番号必須＋摂取目安への注記
- 二重価格は8週間ルール、No.1は根拠5項目（主体・期間・対象・方法・出典）併記必須
- 違反時：薬機法（業務停止／2年以下懲役）／景表法（措置命令／課徴金売上3%／繰返し4.5%）／ステマ規制違反は公正取引委員会から事業者として公表（風評リスク）
