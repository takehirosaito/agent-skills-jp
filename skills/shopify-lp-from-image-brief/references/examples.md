# LP 分解 実例集

## 例1：化粧品 LP（美容液）

### 提供素材
- 縦長画像（PC：1440×4000、SP：750×6000）
- 商品写真3枚（PC：1200×1200）
- Figma 共有リンク

### 全体構成

| # | セクション | テキスト/画像 | Section化 |
|---|---|---|---|
| 1 | ヒーロー | テキスト+背景画像 | 再利用 |
| 2 | 悩み訴求（3つ） | テキスト+SVGアイコン | LP専用 |
| 3 | 商品紹介 | テキスト+商品画像 | 再利用（product-spec） |
| 4 | 3つの特徴 | テキスト+SVGアイコン | 再利用（feature-3col） |
| 5 | 成分エビデンス | テキスト+図解画像 | LP専用 |
| 6 | 使い方 4ステップ | テキスト+ステップ画像 | 再利用（steps） |
| 7 | お客様の声（3件） | テキスト+顔写真 | 再利用（testimonials） |
| 8 | 比較表 | テキスト表 | LP専用 |
| 9 | FAQ（5件） | テキスト | 再利用（faq） |
| 10 | 第二CTA | テキスト+ボタン | 再利用（cta-block） |
| 11 | 特商法表記 | テキスト | フッター流用 |

### デザインルール

```
カラー：
- 主色 #F4A8B8（コーラル）
- 副色 #FFF5F2（クリーム）
- アクセント #2D2D2D（黒：CTA）
- 本文 #333333

フォント：
- 見出し Noto Serif JP Bold（雑誌調）
- 本文 Noto Sans JP Regular
- H1: 56/32 (PC/SP)
- H2: 36/24
- 本文: 16/14

余白：
- セクション間: 120/60
- 内側: 80/40
- 要素間: 24/16

角丸：
- ボタン 8px
- 画像 12px
- カード 16px

影：
- カード 0 4px 12px rgba(0,0,0,0.06)
- ボタン hover 0 6px 16px rgba(0,0,0,0.12)
```

### 法令注意

- 「シミに効く」「シワが消える」NG
- 「日やけによるシミ・ソバカスを防ぐ」「乾燥による小ジワを目立たなくする（試験必要）」のみ可
- 「医師推奨」NG（化粧品適正広告ガイドライン）
- 体験談で効能訴求NG
- `yakki-keihyo-expression-check` 併用

## 例2：アパレル LP（ワンピース）

### 提供素材
- 画像（PC：1440×5000、SP：750×7500）
- モデル着用写真5枚
- 商品写真3枚（正面・背面・ディテール）

### 全体構成

| # | セクション | テキスト/画像 | Section化 |
|---|---|---|---|
| 1 | ヒーロー（モデル着用） | テキスト+背景画像 | 再利用 |
| 2 | ブランドストーリー | テキスト+画像 | LP専用 |
| 3 | 商品紹介（素材・サイズ） | テキスト+商品画像 | 再利用 |
| 4 | シルエット詳細 | テキスト+画像 | LP専用 |
| 5 | 着回しコーデ（3パターン） | テキスト+モデル写真 | LP専用 |
| 6 | サイズガイド | テキスト表+モデル身長表 | 再利用 |
| 7 | お手入れ方法 | テキスト+洗濯マーク画像 | 再利用 |
| 8 | お客様レビュー | テキスト+ユーザー投稿写真 | 再利用 |
| 9 | FAQ | テキスト | 再利用 |
| 10 | 購入CTA | テキスト+ボタン | 再利用 |

### デザインルール

```
カラー：
- 主色 #1A1A1A（ブラック）
- 副色 #F5F2EB（ベージュ）
- 本文 #333333

フォント：
- 見出し Playfair Display Italic（モード感）
- 本文 Noto Sans JP
- H1 64/40 (PC/SP)
- H2 40/28

余白：
- セクション間 140/80
- 内側 100/40

特殊：
- 罫線あしらい多用
- 写真は大きめ（フルワイド多い）
```

### 注意

- サイズ表記（号 / cm / inch）の整合
- 素材表示（家庭用品品質表示法：「綿100%」等正確に）
- お手入れマークが JIS L0001（新JIS）準拠
- 「世界一」「最高級」など最上級は根拠必要

## 例3：機能性表示食品 LP

### 提供素材
- 画像（PC：1440×6000、SP：750×9000）
- 商品写真2枚
- 機能性関与成分の説明図

### 全体構成

| # | セクション | テキスト/画像 | Section化 |
|---|---|---|---|
| 1 | ヒーロー | テキスト+背景画像 | 再利用 |
| 2 | 機能性表示食品の説明 | テキスト+図解 | LP専用 |
| 3 | 商品紹介（届出番号併記） | テキスト+商品画像 | 再利用 |
| 4 | 届出文言（一字一句） | テキスト | LP専用（コピー禁止） |
| 5 | 機能性関与成分の説明 | テキスト+図解 | LP専用 |
| 6 | 摂取目安・注意事項 | テキスト | 再利用（health-food-disclaimer） |
| 7 | お客様の声（個人差・効能訴求NG） | テキスト | 再利用 |
| 8 | 定期購入のご案内 | テキスト+表 | 再利用 |
| 9 | FAQ | テキスト | 再利用 |
| 10 | 第二CTA | テキスト+ボタン | 再利用 |
| 11 | 特商法表記 | テキスト | フッター |

### 法令注意（最重要）

- 機能性表示食品の届出文言を **一字一句改変しない**
- 「治る」「効く」「血圧を下げる」断定NG
- 「報告されています」の表記を含める
- 「医薬品ではありません」を明示
- 摂取上の注意（多量摂取で疾病治癒しない／目安量を守る／原材料アレルギー注意／疾病罹患時は医師相談）を必ず記載
- 体験談・個人の感想による効能訴求NG
- 「効果には個人差があります」だけでは打消し表示として不十分
- `yakki-keihyo-expression-check` 必須

### 届出文言の例

```
本品にはDHA・EPAが含まれます。DHA・EPAには血中中性脂肪を低下させる機能が報告されています。
```

→ 上記を以下のように変えるとNG：
- 「血中中性脂肪を下げる」（断定）
- 「DHA・EPAで血中中性脂肪を低下」（語順改変）
- 「血中中性脂肪を低下させます」（断定）

## ジャンル別の留意点

| ジャンル | 主要セクション | 法令注意 |
|---|---|---|
| 化粧品 | 成分・低刺激・使い方 | 薬機法56効能 |
| アパレル | 素材・サイズ・お手入れ | 品質表示法・新JIS |
| 食品 | 産地・賞味期限・調理法 | 健康増進法 |
| 機能性表示食品 | 届出文言・摂取目安・注意 | 届出文言厳守 |
| 健康器具 | 物理機能のみ | 未承認医療機器扱い回避 |
| 家電 | スペック・保証・PSE | PSE法 |

## 提供素材が不足している場合

### Figma なし、画像のみ

- フォント名・色を画像から推定
- 推定であることを冒頭明示
- 確認質問リストを添付

### 商品情報が不明確

- 仮想商品情報で骨格を作る
- 「商品名」「価格」「リンク先」は仮置き
- 実装時に差し替え可能な構造に

### 多言語対応の有無が不明

- 画像内テキストを最小限にする方針で進める
- 後から多言語対応する場合の改修コストを警告
