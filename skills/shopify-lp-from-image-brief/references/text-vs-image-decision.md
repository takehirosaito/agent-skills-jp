# テキスト化／画像化の判定基準

## 判定マトリクス

| 要素 | テキスト | 画像 | 判定理由 |
|---|---|---|---|
| H1（メイン見出し） | ✅ 必須 | ❌ | SEO・アクセシビリティ |
| H2-H3（中見出し） | ✅ 必須 | ❌ | 同上 |
| 本文 | ✅ 必須 | ❌ | 同上 |
| 価格 | ✅ 必須 | ❌ | 動的更新・通貨対応 |
| CTA ボタンラベル | ✅ 必須 | ❌ | クリック領域・アクセシビリティ |
| ロゴ | △ | ✅（SVG） | デザイン忠実度 |
| アイコン | △ | ✅（SVG） | 軽量・拡縮対応 |
| 装飾的グラフィック | ❌ | ✅ | 機能性なし |
| 商品写真 | ❌ | ✅ | 視覚情報 |
| お客様の声（テキスト部分） | ✅ 必須 | ❌ | SEO・コピー可能 |
| お客様の顔写真 | ❌ | ✅ | 視覚情報 |
| 表（簡単な） | ✅ | ❌ | アクセシビリティ |
| 表（複雑な） | △ | ✅ | レイアウト優先時 |
| グラフ・チャート | ❌ | ✅ | 視覚情報 |
| 装飾的背景 | ❌ | ✅ | 機能性なし |
| 引用 | ✅ 必須 | ❌ | コピー可能 |
| FAQ の Q&A | ✅ 必須 | ❌ | FAQ schema 対応 |

## テキスト化が必須な理由

### 1. SEO

Google は **画像内のテキストを認識しない**（OCR 精度が低い）。商品名・キャッチコピー・本文を画像化すると検索に引っかからない。

### 2. アクセシビリティ

- スクリーンリーダーで読めない
- 視覚障害者・読字障害者が情報にアクセスできない
- 画像 alt は補完だが、長文の場合は不十分

### 3. 多言語化（Markets）

- Shopify Translate & Adapt は **HTMLテキストのみ翻訳可能**
- 画像内テキストは別ファイルに差し替えが必要
- 言語数 × セクション数の画像を作る運用負荷

### 4. 更新性

- マーチャントが画像を作り直す必要
- デザイナー依頼が発生
- 1文字直すのに時間がかかる

### 5. レスポンシブ

- 画像内テキストはモバイルで小さくなる
- 画像比率が変わるとテキストが崩れる
- 端末別に画像を用意する負担

## 画像化が妥当な要素

### 1. 装飾要素

- 飾り罫
- 背景パターン
- 余白を埋めるグラフィック

### 2. 視覚情報

- 商品写真
- 使用シーン写真
- インフルエンサー写真

### 3. 図解・インフォグラフィック

- 「使い方の4ステップ」を写真とイラストで
- 商品比較を視覚的に
- データのグラフ

### 4. ロゴ・アイコン

- SVG 推奨（拡縮で崩れない、軽量）
- PNG なら 2倍サイズ（Retina）

## ハイブリッドパターン（テキスト + 背景画像）

ヒーローセクションの定番：

```html
<section class="hero" style="background-image: url('{{ image.url }}');">
  <div class="hero__content">
    <h1>肌に寄り添う美容液</h1>
    <p>敏感肌のための高濃度ビタミンC10%</p>
    <a href="/products/xxx" class="btn">今すぐ購入</a>
  </div>
</section>
```

- 背景は画像（雰囲気・色味）
- 文字は HTML テキスト（SEO・編集・翻訳可能）

## デザイナーへの説明

デザイナーがLPで「テキストを画像にしたい」と主張するケース：

- 「フォントが Web Font に無いから」→ Adobe Fonts / Google Fonts で代替可能。それでも合わなければ部分的に画像化
- 「装飾が複雑だから」→ 背景画像 + テキスト重ねで再現可能
- 「位置が崩れるから」→ CSS で制御可能

**「画像化しないと再現できない」のは実は少ない**。CSSの flexbox / grid / clip-path / mix-blend-mode 等で大半は実現できる。

## 段階的アプローチ

すぐにテキスト化が難しい場合：

1. **MVP**：すべて画像でリリース（緊急性）
2. **Phase 2**：見出し・本文をテキスト化
3. **Phase 3**：装飾を CSS で実装
4. **Phase 4**：レスポンシブ最適化

ただし MVP のままでは SEO 損失・更新負荷が継続するため、Phase 2 までは必須。

## チェックリスト

- [ ] 見出し（H1-H3）が全てテキスト化されている
- [ ] 本文が全てテキスト化されている
- [ ] 価格・CTA・購入ボタンがテキスト化されている
- [ ] FAQ の Q&A がテキスト化されている
- [ ] アイコンは SVG で実装
- [ ] 装飾的グラフィックのみ画像（PNG/JPG/WebP）
- [ ] 商品写真は WebP（フォールバックJPG）
- [ ] 画像 alt が全枚数設定
- [ ] 多言語化が必要な場合、画像内テキストはゼロ

## 例外

### ロゴ・タイポグラフィー作品

ブランドロゴそのものは「画像扱い」で OK。SVG での実装を推奨。

### 法的ディスクレーマー

「※効能評価試験済み」など小さな注釈は **絶対にテキスト化**。画像化すると法的根拠が読めず違反扱いになる可能性。

### キャンペーン期間限定バナー

期間限定のキャッチを画像化することがあるが、テキストレイヤーは分離して JSON で管理することを推奨。
