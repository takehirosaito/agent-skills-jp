# 検収チェックリスト

LP実装の完成基準。実装者・QA・ディレクター全員が同じ基準で判定できるように。

## 機能要件

### Theme Editor

- [ ] 全セクションが Theme Editor で追加可能
- [ ] 各セクションの settings が編集→保存→反映される
- [ ] block の追加・削除・並び替えが動く
- [ ] preset で初期 block が埋め込まれる
- [ ] `block.shopify_attributes` で block 編集パネルが開く

### 動的要素

- [ ] 商品データ（product_reference）が正しく表示
- [ ] Metafield 参照が空欄時に崩れない
- [ ] 在庫状態（available）が反映
- [ ] 価格表示が正しい（税込／税別）

### リンク

- [ ] CTA ボタンのリンク先が正常
- [ ] 内部リンクが正しい URL
- [ ] 外部リンクは `rel="noopener"` 付き

## UI / レイアウト

### レスポンシブ

- [ ] PC（≥990px）：デザイン通り
- [ ] タブレット（749-989px）：折り返し正常
- [ ] モバイル（<749px）：縦並び正常
- [ ] 各ブレークポイントで画像・テキスト崩壊なし
- [ ] 横スクロール発生なし

### 視覚

- [ ] フォント・サイズ・色がデザイン通り
- [ ] 余白・行間・字間がデザイン通り
- [ ] 角丸・影が要素ごとに正しい
- [ ] 画像比率が正しい（PC/SP 別画像対応）

### インタラクション

- [ ] ホバー時のアニメーション（ボタン・カード）
- [ ] スクロールイン（あれば）
- [ ] アコーディオン（FAQ）の開閉
- [ ] カルーセル（あれば）の操作

## 性能

### Lighthouse スコア（モバイル）

- [ ] Performance 70+
- [ ] Accessibility 90+
- [ ] Best Practices 90+
- [ ] SEO 90+

### Web Vitals

- [ ] LCP（Largest Contentful Paint）2.5秒以内
- [ ] INP（Interaction to Next Paint）200ms以内
- [ ] CLS（Cumulative Layout Shift）0.1以内

### 画像

- [ ] WebP 提供（JPG フォールバック）
- [ ] srcset / sizes で複数サイズ
- [ ] `loading="lazy"` をファーストビュー外に
- [ ] LCP 画像は `loading="eager"` `fetchpriority="high"`
- [ ] width / height 指定（CLS 防止）

### CSS / JS

- [ ] CSS が section スコープ
- [ ] グローバル CSS 汚染なし
- [ ] JS が Vanilla（jQuery 不使用）
- [ ] JS が必要な分だけ読み込み

## アクセシビリティ

### セマンティック HTML

- [ ] 見出し階層が正しい（H1→H2→H3、飛ばさない）
- [ ] H1 がページ唯一
- [ ] `<button>` と `<a>` を使い分け
- [ ] `<nav>` `<main>` `<section>` `<article>` 適切に

### 画像

- [ ] 全画像に alt 属性
- [ ] 装飾画像は `alt=""`
- [ ] アイコンが意味を持つ場合 aria-label

### キーボード

- [ ] タブ移動で全要素にアクセス可能
- [ ] フォーカスインジケーター見える
- [ ] アコーディオン・タブをキーボードで操作可能
- [ ] モーダルをエスケープキーで閉じる

### カラーコントラスト

- [ ] WCAG AA（4.5:1）以上
- [ ] ボタンと背景のコントラスト
- [ ] テキストと背景のコントラスト

### 支援技術

- [ ] スクリーンリーダーで読み上げ可能
- [ ] aria-label / aria-expanded 等が必要箇所に
- [ ] 動画にキャプション（必要時）

## SEO

### メタ情報

- [ ] title タグが設定（テンプレート別）
- [ ] meta description が設定
- [ ] og:image, og:title, og:description
- [ ] Twitter card

### 構造化データ

- [ ] BreadcrumbList schema
- [ ] Product schema（商品ページの場合）
- [ ] Article schema（ブログの場合）
- [ ] Google「リッチリザルトテスト」で警告ゼロ

### 内部リンク

- [ ] パンくず
- [ ] 関連商品 / 関連記事
- [ ] フッターのナビゲーション

## 法令・規約

### 特商法

- [ ] フッターから「特定商取引法に基づく表記」へのリンク
- [ ] 販売者情報・住所・連絡先

### 景表法

- [ ] 「No.1」「最安」表記に根拠（必要時）
- [ ] 二重価格表示が8週ルール準拠（必要時）
- [ ] 「絶対」「完全」など根拠なし最上級なし

### 薬機法（化粧品・健食）

- [ ] 化粧品56効能内の表現
- [ ] 機能性表示食品の届出文言が一字一句一致
- [ ] 「効く」「治る」断定なし
- [ ] `yakki-keihyo-expression-check` で一次チェック済み

### 個人情報保護

- [ ] プライバシーポリシーへのリンク
- [ ] フォームに利用目的の明示

### 配信規約

- [ ] メール配信停止リンク（フッター or 規定箇所）

## 引き渡し時の納品物

- [ ] 全コードファイル（Liquid / CSS / JS）
- [ ] 動作確認チェックリスト（このファイル）
- [ ] マーチャント向け操作マニュアル
- [ ] git コミット履歴 or 差分一覧
- [ ] 既知のバグ・制約リスト

## 不合格判定

以下のいずれか1つでも該当すれば不合格：

1. Lighthouse Performance < 60（モバイル）
2. Lighthouse Accessibility < 80
3. 主要KPI 機能（CTA 押下・カート追加）が動かない
4. モバイルでレイアウト破綻
5. 法令違反表現が含まれる
6. Theme Editor で編集できない設定がある

```markdown

### 編集画面の開き方
1. Shopify管理画面 → Online Store → Themes
2. Customize ボタンをクリック
3. 上部プルダウンから対象ページを選択

### ヒーロー画像の差し替え
1. 「ヒーロー」セクションをクリック
2. 「PC背景画像」「SP背景画像」を入れ替え
3. 「保存」をクリック

### CTAリンクの変更
...

### 注意事項
- 画像サイズ：PC 1920×800、SP 750×900 推奨
- フォーマット：JPG or PNG（自動で WebP 化されます）
```
