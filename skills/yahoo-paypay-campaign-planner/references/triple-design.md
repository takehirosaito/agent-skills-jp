# ストアポイント＋優良配送＋PayPayステップ「トリプル」設計

Yahoo!ショッピングで売上を伸ばすには、**この3要素の同時最適化**が肝。1つだけ強くしても効きが弱い。

---

## 1. ストアポイント

### 設定可能範囲
- ストアクリエイターPro「ストアポイント設定」で任意倍率
- 1倍／2倍／3倍／5倍／10倍／15倍等
- 全商品一律／カテゴリ別／商品個別の3パターン

### 原資負担
- **完全にストア負担**
- 倍率を上げるほど原資が増える（粗利を圧迫）

### 設計指針
- 通常時：1倍〜3倍程度
- 5の付く日：5倍〜10倍に増額（イベント認知UPの誘い水）
- ゾロ目／超PayPay祭：10倍〜15倍
- **粗利30%未満の商品で10倍はリスク大**（赤字化）

### 競合比較
- 同カテゴリの上位ストアのポイント倍率を観察
- 「ストアポイント10倍以上」のフィルタで検索流入

---

## 2. 優良配送

### 公式要件（過去頻出基準・最新は公式確認）
- **注文受付から2日以内に商品到着**（地域別に翌々日着・あす着）
- **出荷遅延率 5%未満**（注文後の翌営業日に出荷指示できなかった割合）
- **ストア都合キャンセル率 2.5%未満**
- **翌日優良配送（2024.5～）**：あす着対応商品の優遇枠

### 2025.11からの評価基準変更
- 総合評価：13点 → 10点
- 優良店評価：5点 → 6点
- 評価項目の重み再調整あり

### 設計指針
- **当日朝注文 → 当日出荷／翌日出荷** の体制を維持
- 在庫切れ商品を販売停止せず受注継続するとキャンセル率悪化
- 仕入リードタイムの長い商品（受注生産・取り寄せ）は「お取り寄せ商品」として分離
- 大型連休・大量受注期に**出荷体制を倍にする**計画必須

### 効果
- 検索結果バッジ表示
- 検索順位優遇
- 優良配送フィルタでの露出
- ストア評価向上 → さらに検索優遇のループ

---

## 3. PayPayステップ

### 顧客側の達成条件（過去例・最新確認）
- PayPay決済を月間○回／○円以上
- 対象アプリ利用（PayPayアプリ・LINE等）
- LYPプレミアム会員加入

### ストア側でやること
- **PayPay決済を選べるようにする**（Yahoo!ショッピングではデフォルト）
- 「PayPayステップ達成で最大○%」を商品ページに明記（条件付き表示）

### 原資負担
- **PayPay／Yahoo!負担**（ストアではない）

### 設計指針
- 高額商品の検討中ユーザーには「PayPayステップ達成で○○ポイント返って実質XX,XXX円」と訴求
- 5の付く日／プレミアム日曜と組み合わせて訴求

---

## 4. トリプル の組み合わせ訴求例

### 例1：通常時の商品ページ
```
ストアポイント 通常3倍
+ 優良配送（あす着対応）
+ PayPayステップ最大適用
※条件達成で最大○%相当の還元
```

### 例2：5の付く日の商品ページ
```
本日限定 ストアポイント 10倍
+ 5の付く日 +4%（LYPプレミアム+2%）
+ PayPayステップ最大適用
+ 優良配送（あす着）
※条件達成で最大○%相当の還元
```

### 例3：ゾロ目の日の商品ページ
```
ゾロ目クーポン 5,000円OFF（10,000円以上で利用可）
+ ストアポイント 10倍
+ PayPayステップ最大適用
+ 優良配送
※条件達成で実質XX,XXX円
```

---

## 5. 注意点

- **「最大○%」表記**は条件併記が必須（景表法・有利誤認）
- **打消し表示**を小さくしすぎない（7原則）
- **原資負担の自社／他社区分**を粗利計算で混同しない
- **優良配送維持**を販促集中日も守れる出荷体制を確保
- 「PayPayステップ達成必須」を一般会員にも適用しているように誤認させない
