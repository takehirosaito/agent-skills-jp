# 販促終了後の KPI 定義

販促日終了後、**翌日中**に下記KPIを集計する。鉄は熱いうちに打つ。

---

## 売上系

| 指標 | 定義 | 計算 |
|---|---|---|
| 売上高 | 当日売上合計 | ストアクリエイターProから取得 |
| 件数 | 注文件数 | 同上 |
| 客単価 | 売上 ÷ 件数 |  |
| 平均購入点数 | 注文商品数 ÷ 件数 |  |
| 売上前年同月比 | 当日売上 ÷ 前年同イベント日 | YoY |
| 売上前月比 | 当日売上 ÷ 前月同イベント日 | MoM |

---

## 粗利系

| 指標 | 定義 | 計算 |
|---|---|---|
| 粗利率 | (売上 − 仕入原価) ÷ 売上 |  |
| 還元率 | (ストアポイント原資 + 自社クーポン原資) ÷ 売上 |  |
| 広告費比率 | 広告費 ÷ 売上 | ACoS的 |
| 営業利益率 | 粗利率 − 還元率 − 広告費比率 |  |

**販促日は通常日より営業利益率が下がるのが正常**。問題は「下がり幅」と「将来リターン」。

---

## 流入・転換系

| 指標 | 定義 |
|---|---|
| セッション数 | ストアアクセス数 |
| 訪問者数 | ユニーク |
| 転換率 (CVR) | 件数 ÷ セッション数 |
| カート投入率 | カート投入 ÷ セッション数 |
| カート離脱率 | (カート投入 − 件数) ÷ カート投入 |

---

## 広告系

| 指標 | 定義 |
|---|---|
| 広告費 | アイテムマッチ等の支出 |
| 広告経由売上 | 広告流入からの売上 |
| 広告ROAS | 広告経由売上 ÷ 広告費 |
| CPC平均 | 広告費 ÷ クリック数 |
| 広告経由CVR | 広告経由件数 ÷ クリック数 |

ROAS目標：主力商品 5倍以上、新規拡張商品 3倍以上が目安。

---

## クーポン系

| 指標 | 定義 |
|---|---|
| クーポン使用枚数 | 当日使用枚数 |
| クーポン経由売上 | クーポン適用注文の売上 |
| クーポン使用率 | 使用枚数 ÷ 配布枚数 |
| クーポン原資 | 使用枚数 × クーポン額 |

クーポン使用率：5〜15%が一般的。極端に低いなら告知不足／極端に高いなら閾値が緩すぎ。

---

## 在庫・出荷系

| 指標 | 定義 | 目標 |
|---|---|---|
| 在庫消化率 | 売上数 ÷ 期首在庫 | 主力50%、在庫処分80% |
| 在庫切れ件数 | 当日に在庫0になったSKU数 | 0が望ましい（主力） |
| 出荷遅延件数 | 翌営業日に出荷できなかった件数 | 0が望ましい |
| ストア都合キャンセル件数 | 同上 | 0が望ましい |
| 優良配送維持 | 上記2基準を満たしたか | YES |

---

## 顧客系

| 指標 | 定義 |
|---|---|
| 新規顧客数 | 初回購入の顧客数 |
| リピート顧客数 | 2回目以降の購入顧客数 |
| LYPプレミアム会員比率 | LYP会員注文 ÷ 全注文 |

---

## レビュー・評価系

| 指標 | 定義 | 目標 |
|---|---|---|
| 当日販売分のレビュー獲得率 | レビュー数 ÷ 件数 | 5%以上 |
| 平均評価 | 5点満点での当日販売分の平均 | 4.5以上 |
| ストア評価 | 総合／優良店評価点数 | 維持 |

---

## 振り返りフォーマット

```
販促日：YYYY-MM-DD（5の付く日／ゾロ目／超PayPay祭）

【売上】
- 売上高：XXX,XXX円（目標比 XX%／前年比 XX%）
- 件数：XX件
- 客単価：X,XXX円

【粗利】
- 粗利率：XX%
- 還元率：XX%
- 広告費比率：XX%
- 営業利益率：XX%

【流入】
- セッション：XXX,XXX
- CVR：X.XX%

【次回への学び】
- 良かった点：
- 悪かった点：
- 次回試すこと：
```

毎回テンプレ化して **3ヶ月、半年、1年単位**で改善を回す。
