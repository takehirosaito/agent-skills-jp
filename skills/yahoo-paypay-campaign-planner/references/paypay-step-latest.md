## 原資負担の整理

| 還元元 | 負担者 | 設計時の扱い |
|---|---|---|
| 通常ストアポイント | ストア | 自社原資。粗利検算に含める |
| 上乗せストアポイント | ストア | 自社原資 |
| 5の付く日 上乗せ | PayPay／Yahoo! | 自社原資ではない |
| LYPプレミアム特典 | LYPプレミアム側 | 自社原資ではない |
| PayPayステップ | PayPay | 自社原資ではない |
| ゾロ目クーポン | Yahoo!負担／ストア負担 両方あり | クーポン作成時に負担区分確認必須 |
| 自社設定クーポン | ストア | 自社原資 |

**よくある誤解**：「最大○○%還元」のうち、ストア負担は**通常ポイント＋ストア上乗せ分のみ**。広告とポイント原資の両方をストア負担として粗利検算する。

## 「最大○○%還元」表記の作り方

「最大15%」のような表記を訴求する場合：

- 内訳を**自社サイト・LP・キャプションに明記**できるよう数値根拠を保持
- 「PayPayステップ最大適用」「LYPプレミアム会員」「5の付く日」など**条件併記**
- 条件を満たさない一般顧客に誤認させない（景表法上のリスク）

NG例：「最大15%還元！」だけ大きく書き、条件を読めないサイズで打消し
OK例：「最大15%還元（PayPayステップ最大適用＋LYPプレミアム会員＋5の付く日）」

景表法上、**最上位条件のすべてを達成しないと得られない還元率を「最大」として表記する**場合は、達成条件を明示しないと**有利誤認**にあたるリスク。
