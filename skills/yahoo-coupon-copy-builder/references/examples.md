## 例1：5の付く日 主力商品クーポン

**設計**：
- クーポン名（社内）：2024-12-15_5付く日_主力バッグ_500OFF_先着1000
- ユーザー視認名：「【5の付く日限定】対象バッグ5,000円以上で500円OFF」
- 対象：レディースバッグカテゴリ
- 閾値：5,000円以上
- 割引：500円OFF
- 枚数：先着1,000枚
- 期間：当日 0:00〜23:59
- 併用：他クーポン不可、PayPayステップ可

**バナー**：「本日限定 5,000円以上で500円OFF」

**商品ページ訴求**：
```
【5の付く日 限定クーポン】
対象のレディースバッグを5,000円（税込）以上のご購入で500円OFF
※他クーポンとの併用不可／本日0:00〜23:59／先着1,000枚

[ クーポンを取得する ]
```

**メルマガ件名**：「【本日限り】対象バッグ500円OFFクーポン配布中」

**粗利検算**：
- 想定使用枚数：500枚（使用率50%）
- 原資：500枚 × 500円 = 250,000円
- 想定売上：500枚 × 平均6,500円 = 3,250,000円
- 還元率：250,000 / 3,250,000 = 7.7%
- 粗利40% - 7.7% - 広告費5% = 営業利益率 約27%

## 例2：ゾロ目の日 高額クーポン

**設計**：
- クーポン名（社内）：2024-12-22_ゾロ目_高額_5000OFF_先着100
- ユーザー視認名：「【ゾロ目の日】30,000円以上で5,000円OFF」
- 対象：全商品
- 閾値：30,000円以上
- 割引：5,000円OFF
- 枚数：先着100枚
- 期間：22日 0:00〜23:59

**バナー**：「【ゾロ目限定】30,000円以上で5,000円OFF」

**商品ページ訴求**：
```
【ゾロ目の日 限定】
30,000円（税込）以上のお買い物で5,000円OFFクーポン
※先着100枚／本日23:59まで／他クーポン併用不可
```

**粗利検算**：
- 想定使用：80枚
- 原資：80 × 5,000 = 400,000円
- 想定売上：80 × 平均45,000円 = 3,600,000円
- 還元率：11.1%
- 粗利30% - 11.1% - 広告5% = 約14%

```
500円OFFクーポンをお送りしました

```

**期待効果**：カート離脱率の20〜40%が復活

## 例6：在庫処分アウトレットクーポン

**設計**：
- ユーザー視認名：「【冬物アウトレット】対象商品 30%OFF」
- 対象：在庫処分対象50SKU
- 閾値：なし
- 割引：30%OFF
- 期間：1ヶ月

**バナー**：「冬物アウトレット 全品30%OFF」

**商品ページ訴求**：
```
🏷️ 冬物アウトレットセール

対象商品 30%OFFクーポン配布中
（在庫がなくなり次第終了）

[ 対象商品一覧へ ]
```

**注意**：
- 在庫処分・アウトレット表記は実態と一致（季節終わり等の実態）
- 二重価格表示（通常価格→アウトレット）は8週間ルール確認
- 期間明示
- 終了後は訴求を必ず削除（媒体に残置すると景表問題）

**粗利検算**：
- 粗利率は通常40% → 30%OFFで実質10%
- キャッシュ化目的のため許容
