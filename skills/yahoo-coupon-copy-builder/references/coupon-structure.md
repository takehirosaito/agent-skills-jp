# Yahoo!クーポン構造の基礎

---

## 1. クーポンの種類（原資負担別）

| 種類 | 原資 | 設定 |
|---|---|---|
| ストア発行クーポン | ストア | ストアクリエイターProで作成・配布 |
| PayPay負担クーポン | PayPay | PayPay側の告知に応じてセット |
| Yahoo!負担クーポン | Yahoo! | キャンペーン連動でYahoo!が配布 |
| LYP負担（プレミアム会員向け） | LYP | プレミアム特典 |

ストア発行クーポンが**ストア側の粗利を圧迫**する分。設計時に最優先で意識。

---

## 2. クーポンの種類（割引方式別）

| 方式 | 例 | 特徴 |
|---|---|---|
| 金額OFF | 500円OFF／1,000円OFF | 高額商品で割引率が下がる／低額商品で過剰割引 |
| %OFF | 10%OFF／20%OFF | 単価に応じて割引額が変動 |
| 固定金額（上限あり） | 10%OFF（最大1,000円） | 高額商品の割引を抑える |
| 送料無料 | 送料無料クーポン | 単価低い商品で効果大 |

---

## 3. クーポンの種類（適用条件別）

| 条件 | 例 |
|---|---|
| 全商品対象 | 全商品500円OFF |
| カテゴリ限定 | レディースバッグカテゴリのみ |
| 商品個別 | 対象商品（型番A〜B） |
| 閾値あり | 5,000円以上で利用可 |
| 閾値なし | 1点から利用可 |
| 新規限定 | 初めての方限定 |
| リピーター限定 | 過去購入者限定 |
| LYPプレミアム会員限定 | LYP会員のみ |

---

## 4. 5要素テンプレ

### A. 対象範囲
- 全商品
- 「○○カテゴリ」全商品
- 対象商品（商品名 or 商品ID）

### B. 閾値
- なし（1円から）
- 3,000円以上
- 5,000円以上 ← LYPプレミアム日曜と同じ金額
- 10,000円以上 ← ゾロ目高額狙い

### C. 割引
- 500円OFF
- 1,000円OFF
- 5,000円OFF（高額商品向け）
- 5%OFF
- 10%OFF
- 20%OFF（在庫処分等）

### D. 枚数・期間
- 先着100枚／500枚／1,000枚／無制限
- 日付 ＋ 時刻（例：1/15 0:00〜23:59）
- 期間制 vs 当日限定

### E. 併用条件
- 他クーポンと併用可
- 他クーポンと併用不可
- PayPayステップとは併用可（基本デフォルト）
- LYP特典との併用（明示）

| 項目 | 記載必須 |

| 割引額 or 率 | ◯ |

| 利用方法（取得→決済時適用） | ◯ |

## 6. クーポン名のつけ方

### 管理画面用（社内識別）
- 「2024-12-15_5の付く日_主力バッグ_500OFF_先着500」のように**日付・イベント・対象・額・枚数**を入れる
- 過去のクーポン履歴と区別しやすい

### ユーザー視認用
- 「【5の付く日限定】対象バッグ5,000円以上で500円OFF」
- ユーザーが3秒で理解できる

## 7. クーポン使用率の想定

| クーポン種別 | 使用率目安 |
|---|---|
| 既存顧客向けメルマガ配布 | 10〜30% |
| 一般配布（ストアトップ） | 1〜5% |
| カート離脱救済（自動配信） | 20〜40% |
| 新規限定（初回購入） | 5〜15% |
| 販促日 ストアトップバナー | 5〜15% |

原資 ＝ 使用率 × 枚数 × 額。粗利検算で必ず使う。

## 8. クーポン発行のタイミング

| タイミング | 効果 |
|---|---|
| 前日21:00 メルマガ | 翌日販促日への期待醸成 |
| 当日0:00 ストアトップ | 深夜層を逃さない |
| 当日10:00 LINE | 昼間流入 |
| 当日18:00 メルマガ | 帰宅後流入 |
| 当日20:00 ストアトップ更新 | プライムタイム流入 |
| カート投入24時間後 自動配信 | 離脱救済 |
