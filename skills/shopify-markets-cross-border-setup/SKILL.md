# Shopify Markets 越境設定 設計

## 概要

Shopify Markets を用いて、1ストアから複数国へ販売するための設定（マーケット定義・多通貨・多言語・国別価格・ドメイン構成・関税/輸入税の扱い・配送・決済）を抜け漏れなく設計するスキル。「どの国を1つのマーケットにまとめるか」「価格と通貨をどう見せるか」「関税は誰が負担するか(DDP/DDU)」といった判断を整理し、越境ストアの体験崩れと想定外コストを防ぐ。

## 最重要原則

**「マーケットの粒度を先に決める／価格は通貨換算＋丸めで現地に馴染ませる／関税負担(DDP=着払い無し vs DDU=現地で追徴)を明確にして表示と一致させる／ドメイン構成とhreflangを最初から揃える」**。後から国を分割・統合すると価格やSEOがやり直しになる。関税の扱いを曖昧にすると「到着時に追加請求された」というクレームと返品が増える。

## 知識ベース

設定の主要ブロック：

| ブロック | 論点 |
|---|---|
| マーケット定義 | 国/地域をどうグルーピングするか（主要国は単独、その他は地域束ね） |
| 通貨・価格 | 自動換算 or 固定価格、価格丸め(端数処理)、心理価格 |
| 言語・翻訳 | 対応言語、翻訳の運用(アプリ/手動)、未翻訳フォールバック |
| ドメイン | 国別ドメイン / サブドメイン / サブフォルダ のいずれか＋hreflang整合 |
| 関税・輸入税 | DDP（事前徴収して着地で追徴なし）/ DDU（現地で受取人負担）、Duties表示 |
| 配送 | 配送ゾーン・送料・配送業者・配送日数の明示 |
| 決済 | 現地で使われるカード/ウォレットの対応可否、通貨建て決済 |

ドメイン構成の典型：
- サブフォルダ（example.com/en, /fr）… SEO資産集約しやすい・運用が軽い → 多くのケースで推奨
- 国別ドメイン（example.fr）… 現地感は強いが運用とSEO分散の負担大

> 機能の対応可否・名称（Managed Markets、Markets Pro、Duties機能等）やプラン要件は変わるため、確定は Shopify ヘルプで確認する。

## 処理フロー

### Step 1：販売先と優先度の確認
- 進出したい国/地域、優先順位、現状の海外注文の有無
- 取扱商材（関税分類が重い商材か、規制品か）
- 既存ドメイン構成と国内SEOの状況
不明時は「英語圏(米/英/豪)＋単一サブフォルダ構成・自動換算・DDU」を仮置きし明示。

### Step 2：マーケット定義
- 主要国は単独マーケット、ロングテール国は地域マーケットに束ねる方針を提示。

### Step 3：通貨・価格戦略
- 自動換算＋丸めルール、または重点国は固定価格で心理価格に整える判断。

### Step 4：言語・ドメイン・hreflang
- 対応言語と翻訳運用、ドメイン構成を決め、hreflang整合の要件を提示（詳細設計は `multilingual-hreflang-planner` へ連携）。

### Step 5：関税・輸入税ポリシー（DDP/DDU）
- DDP（事前徴収）か DDU（現地負担）かを商材単価・配送先で選び、チェックアウト表示と一致させる。
- HSコード/税率の見積は `cross-border-hs-code-duty-estimator` へ連携。

### Step 6：配送・決済
- 配送ゾーン・送料テーブル・配送業者、現地で使われる決済手段の対応可否を整理。

### Step 7：ローンチ前チェック
- 各国の価格・通貨・言語・関税表示・送料・決済が一致しているかのチェックリスト。

## 出力フォーマット

```
# Shopify Markets 越境設定：[ストア名]

## 0. 前提（確認/仮定）
## 1. マーケット定義（国/地域グルーピング表）
   | マーケット | 含む国 | 通貨 | 言語 | 関税 |
## 2. 通貨・価格（換算/丸め/固定 の方針）
## 3. 言語・ドメイン・hreflang 方針
## 4. 関税ポリシー（DDP/DDU と表示の整合）
## 5. 配送ゾーン・送料・決済
## 6. ローンチ前チェックリスト
```

## 品質ゲート
- マーケットの粒度に根拠があるか（主要国単独/ロングテール束ね）
- 価格・通貨・言語・関税の表示が4点セットで国ごとに一致しているか
- DDP/DDU を明示し、チェックアウト表示と矛盾しないか
- ドメイン構成とhreflang方針が国内SEOを壊さないか

## 注意事項
- Shopify の機能名・プラン要件・対応国は改定される。確定は公式ヘルプで確認する。
- 関税・税の確定額は通関時に決まる。本スキルは見積・方針整理であり保証ではない。
- 各国の表示規制・特定商取引法相当のルールは別途確認が必要。
