# オプションデータCSV の主要列リスト

MakeShop の商品オプション（色・サイズ・タイプ）は **独立したCSV ファイル**（オプションデータCSV）で管理する。

仕様は変更されるため、最終的には MakeShop 管理画面のCSV インポート画面で最新を確認すること。

## 主要列

| 役割 | 一般的な列名 | 必須 | 内容 |
|---|---|---|---|
| 商品コード | goods_id | 必須 | 商品データCSV と完全一致 |
| オプションコード | オプションコード | 必須 | オプションの識別子 |
| オプション名 | オプション名 | 必須 | 例：「色」「サイズ」 |
| オプション値 | オプション値 | 必須 | 例：「赤」「M」 |
| 価格差 | 価格差 | 任意 | プラス／マイナスの数値 |
| 在庫数 | 在庫数 | 任意 | オプション別在庫 |
| 在庫管理区分 | 在庫管理区分 | 任意 | する／しない |
| 表示順 | 表示順 | 任意 | オプション内の並び順 |
| 在庫表示 | 在庫表示 | 任意 | 在庫切れ時の表示 |
| JANコード | janコード | 任意 | オプション別JAN |
| 画像 | 画像ファイル名 | 任意 | オプション別画像 |

## オプションの2階層モデル

MakeShop のオプションは一般に「**オプション項目（色／サイズ）**」と「**オプション値（赤／青／M／L）**」の2階層。

例：

```
goods_id: tshirt-001
  オプション項目「色」
    オプション値：赤
    オプション値：青
    オプション値：黒
  オプション項目「サイズ」
    オプション値：S
    オプション値：M
    オプション値：L
```

組合せ：色3 × サイズ3 = 9バリエーション

オプション値ごとに価格差・在庫・JANを設定できる。組合せベース（色×サイズで個別在庫）は店舗仕様による。

## goods_id 紐付けの基本ルール

- オプションデータCSV の goods_id は **商品データCSV の goods_id と完全一致** が必要
- 大文字小文字・半角全角・前後スペースの違いも別物扱い
- 商品データCSV に存在しない goods_id をオプション側で指定すると、エラー or 無視される

## アップロード順序

- **商品データCSV を先にアップロード** → **オプションデータCSV を後にアップロード**
- 商品が存在しない状態でオプションを入れることはできない

逆順でアップロードすると、オプション側で「該当商品なし」エラーになる。

## 重複・矛盾のチェック

### 同一goods_id内でオプション値の重複

```
NG例：
goods_id, オプション名, オプション値
tshirt-001, 色, 赤
tshirt-001, 色, 赤   ← 重複
```

### 価格差の数値形式

```
NG例：
価格差：+500円  ← 「円」が混入
価格差：500.5  ← 整数指定の場合は小数NG
```

### 在庫数と在庫管理区分の矛盾

- 在庫管理区分「しない」なのに在庫数を入れている
- 在庫管理区分「する」なのに在庫数が空白

## オプション数の上限

1商品あたりのオプション項目数・オプション値数・組合せ総数には上限がある。仕様変動するため最新を確認。

典型的な上限の目安（店舗プランにより異なる）：
- オプション項目数：5〜10程度
- オプション項目あたりの値数：30〜50程度
- 1商品あたりの組合せ総数：100〜200程度

上限を超えると一部のオプションがアップロードされない／カート画面で表示されないなどの不具合が起きる。

## オプションの表示順

- 表示順列に数値（小さいほど上位）を入れる
- 同一順位がある場合の挙動は仕様による（goods_id 順、アップロード順など）

## オプション別画像

- 色違いごとに画像を切替表示したい場合、オプション別画像列に画像ファイル名を入れる
- 画像ファイル名はFTP等で事前にアップロード済であること
- 画像ファイル名は半角英数・ハイフン・アンダースコアのみ推奨

## トラブルシューティング

### 症状：「オプション選択肢が商品ページに表示されない」

可能性：

1. goods_id 不一致（大文字小文字・全角混入）
2. 商品データCSV のオプション有効フラグが「無効」になっている
3. オプションデータCSV のアップロードが失敗していたが管理画面で警告が見えていない
4. オプション値の在庫がすべて0（在庫管理「する」の場合）

確認順序：

1. 商品マスタ管理画面でオプション項目が表示されているか
2. オプションデータCSV のgoods_id を grep で抽出し、商品データCSV のgoods_id と diff
3. 管理画面のアップロードログ（履歴）を確認

### 症状：「価格差が反映されない」

可能性：

1. 価格差列が空白（差なしと判定される）
2. 価格差の数値形式が不正（記号・カンマ・円混入）
3. 店舗仕様で「オプション別価格差」を無効化している
