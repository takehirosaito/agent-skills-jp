# 典型的なエラー原因と修正例（10パターン）

MakeShop の商品CSV／オプションCSV運用で頻発するエラー10パターンと修正方針。

## 1. オプションデータCSV の goods_id 不一致（大文字小文字）

**症状**：管理画面でオプションデータCSV「アップロード成功」だが、商品ページでバリエーション選択が表示されない。

**原因**：
- 商品データCSV：`item-001`
- オプションデータCSV：`Item-001`

**修正**：
- 全件 grep で抽出し diff
- オプションデータCSV を `item-001` に揃え、再アップロード

```sh
# 商品データCSV から goods_id 抽出
cut -d, -f1 products.csv | sort > goods_in_products.txt

# オプションデータCSV から goods_id 抽出
cut -d, -f1 options.csv | sort | uniq > goods_in_options.txt

# 差分
diff goods_in_products.txt goods_in_options.txt
```

## 2. フリースペース1にHTMLを入れたら列がずれた

**症状**：商品データCSV をアップロードすると「列数が一致しません」エラー。

**原因**：フリースペース1の値に `"` が含まれているが、列値を `"` で囲んでいない、または `"` を `""` に二重化していない。

**NG例**：
```
goods_id,フリースペース1
item-001,<a href="https://example.com">詳細</a>
```
↑ カンマやダブルクォートを含む値が `"` で囲まれていない。

**修正**：
```
goods_id,フリースペース1
item-001,"<a href=""https://example.com"">詳細</a>"
```
- 値全体を `"` で囲む
- 内部の `"` を `""` に二重化

## 3. JANコードの先頭0が Excel で落ちた

**症状**：JANコード列に「490123456789」のような12桁が並ぶ（本来13桁）。

**原因**：Excel が JANコードを数値と判定し、先頭の 0 を削除。

**修正**：

- VS Code 等で開き直し、元データから再抽出
- 列の書式を「文字列」にしてからCSVを開く（Excel）
- JANコードのチェックデジット検証は `jan-code-checker` スキル併用

## 4. 画像ファイル名にスペース・全角

**症状**：画像ファイル名列を含むCSV をアップロード後、画像が表示されない。

**原因**：ファイル名に全角文字・スペース・記号が含まれている。

**NG例**：
- `商品画像_1.jpg`
- `item 001.jpg`
- `item-001(red).jpg`

**修正**：
- ファイル名を `item-001-red.jpg` のように半角英数・ハイフン・アンダースコアに変更
- FTPで再アップロード
- CSV側の画像ファイル名列を新ファイル名に更新

## 5. 商品分類のタイポ（既存カテゴリと不一致）

**症状**：「商品分類が存在しません」または商品が未分類で登録される。

**原因**：CSV で指定した商品分類が、管理画面に存在しない or 表記揺れ。

**NG例**：
- 管理画面：「スキンケア > 化粧水」
- CSV：「スキンケア＞化粧水」（記号違い）
- CSV：「スキンケア > 化粧水 」（末尾スペース）

**修正**：
- 管理画面で正確な分類名（または分類ID）を確認
- CSV側を完全一致に修正
- 新規分類を初めて指定する場合は、事前に管理画面で分類を作成

## 6. 税込・税抜の混在

**症状**：商品ページの価格表示が想定より高い／低い。

**原因**：店舗設定が「税込表示」なのに、CSV側で税抜価格を入れた（またはその逆）。

**修正**：
- 店舗設定の税表示を確認（管理画面 → 店舗設定）
- CSV の価格を税表示に合わせて修正
- 税率・軽減税率対象の確認

## 7. 在庫管理区分と在庫数の矛盾

**症状**：在庫管理「しない」設定の商品なのに、在庫切れ表示が出る／在庫管理「する」設定の商品なのに在庫切れ判定されない。

**原因**：

- 在庫管理「しない」なのに在庫数 0 を入れた
- 在庫管理「する」なのに在庫数列が空
- オプションデータCSV と商品データCSV で在庫管理区分が矛盾

**修正**：
- 在庫管理区分と在庫数の整合を全行で確認
- 商品データCSV とオプションデータCSV で在庫管理ポリシーを統一

## 8. SEOタイトル超過・テンプレ文の使い回し

**症状**：Google 検索結果のタイトルが切れる／全商品で同じスニペット。

**原因**：

- SEOタイトル列の文字数超過（32字以上）
- 全商品で「商品名 | ブランド名 | 通販ショップ | 最安 | 公式」のような同一テンプレ
- meta description が全商品で同文

**修正**：
- SEOタイトルは商品ごとに 28〜32字で個別作成
- メタディスクリプションは 80〜120字で商品個別
- 「最安」「業界No.1」は根拠なく使わない（景表法）

## 9. 改行コード混在

**症状**：CSV をアップロードすると、特定の行から先がエラー or 取り込まれない。

**原因**：複数人で編集中に CR+LF と LF が混在。

**修正**：
- VS Code で開き、右下「LF/CRLF」表示をクリックして統一
- コマンドラインで変換：
  ```sh
  # CRLF に統一
  awk 'sub("$", "\r")' in.csv > out.csv
  ```
- アップロード前に統一を確認

## 10. オプション組合せ上限超過

**症状**：オプションデータCSV「アップロード成功」だが、一部の組合せが商品ページに表示されない。

**原因**：1商品あたりのオプション組合せ総数の上限を超過。

**修正**：
- オプション項目（色／サイズ／タイプ）を整理し、組合せ数を減らす
- 必要なら 1商品を複数商品に分割（例：「赤・青・黒の3色を1商品」→「赤」「青」「黒」を3商品に）
- 上限値は店舗プランによる。管理画面 or サポートに確認

## チェックリスト（10パターン横断）

CSV アップロード前に必ず確認：

- [ ] 商品データCSV の goods_id がすべて半角英数で重複なし
- [ ] オプションデータCSV の goods_id がすべて商品データCSV に存在
- [ ] 文字コード（指定値）・改行コード（指定値）・BOM（指定値）が要件通り
- [ ] フリースペース内のHTML が `"` 二重化・カンマエスケープ済
- [ ] JANコードの先頭0が保持されている（13桁）
- [ ] 画像ファイル名が半角英数・ハイフン・アンダースコアのみ
- [ ] 商品分類が管理画面の既存カテゴリと完全一致
- [ ] 税込／税抜が店舗設定と一致
- [ ] 在庫管理区分と在庫数の整合
- [ ] SEOタイトル・メタが商品個別（テンプレ文使い回しなし）
- [ ] オプション組合せ総数が上限内
- [ ] 過去CSV のバックアップを取った
