# 独自タグ（フリースペース1-10）の使い方・破損パターン

MakeShop には商品ページのテンプレート側に擬似タグ（独自タグ）を埋め込み、商品マスタの「フリースペース1〜10」列の内容を動的に差し込む仕組みがある。

商品ごとに動的な差込（独自セクション・キャンペーン文言・スペック表・FAQ）ができるため、商品ページのカスタマイズで多用される。

## 擬似タグの典型形

商品ページのテンプレート（HTML）に次のような擬似タグを書く：

```
<!--MS:商品名-->
<!--MS:販売価格-->
<!--MS:商品説明-->
<!--MS:フリースペース1-->
<!--MS:フリースペース2-->
...
<!--MS:フリースペース10-->
<!--MS:JANコード-->
<!--MS:メーカー-->
```

具体的なタグ表記は MakeShop の仕様・テンプレート設定による。最終的には管理画面のテンプレ編集画面で確認すること。

## フリースペース1〜10の使い分け例

CSV側の各フリースペース列に入れる内容の典型例：

| フリースペース | 用途例 |
|---|---|
| 1 | 商品ページ冒頭のキャッチコピー（HTMLあり） |
| 2 | スペック表（テーブルHTML） |
| 3 | 使い方ステップ（番号付きリスト） |
| 4 | お手入れ方法 |
| 5 | よくある質問（FAQ） |
| 6 | レビュー抜粋 |
| 7 | 関連商品案内 |
| 8 | 配送・返品案内（商品個別の特記事項） |
| 9 | 季節キャンペーン文言 |
| 10 | 製造者・産地・ブランドストーリー |

## CSV側に入れるHTML の注意

### 1. ダブルクォート `"` のエスケープ

CSVで「列値全体をダブルクォートで囲んでいる」場合、内部のダブルクォートは `""` に二重化する。

OK例（CSV1行）：
```
goods_id,フリースペース1
item-001,"<a href=""https://example.com"">詳細はこちら</a>"
```

NG例（パース失敗）：
```
goods_id,フリースペース1
item-001,"<a href="https://example.com">詳細はこちら</a>"
```

### 2. カンマ `,` を含む場合

列値全体を `"` で囲む。

OK例：
```
goods_id,フリースペース1
item-001,"特徴：軽量、防水、速乾"
```

### 3. 改行を含む場合

CSV列値内の改行は、列値全体を `"` で囲った中であれば許容される（RFC 4180 準拠）。

OK例：
```
goods_id,フリースペース1
item-001,"1行目
2行目
3行目"
```

ただし MakeShop のCSV パーサが改行入りに対応しているかは仕様による。最新は管理画面のCSVインポートガイドで確認。改行入りで失敗する場合は `<br>` に置換する。

### 4. HTMLタグの閉じ忘れ

```
NG：<div>テキスト  ← </div> の閉じ忘れ
NG：<p>テキスト</p ← > の欠落
NG：<a href="...">テキスト  ← </a> 閉じ忘れ
```

商品ページのレイアウトが崩れる、または他のセクションを巻き込む。

### 5. `<script>` `<iframe>` `<style>` の扱い

- セキュリティ上、これらのタグを商品マスタCSV から差し込めるかは店舗仕様による
- 通常はサニタイズ（除去）される
- 動画埋込みなどで `<iframe>` が必要な場合は、店舗のセキュリティポリシーと相談

### 6. インラインCSS

- `style="color: red;"` のようなインラインCSSは許容されることが多い
- ただしレスポンシブ崩れ・モバイル表示不全の原因になることがある

## フリースペース更新時の運用フロー

### 1. テンプレート側で受けるタグ位置を確認

商品ページのテンプレに `<!--MS:フリースペース1-->` がどこに配置されているか把握。

### 2. プレビュー商品でテスト

本番商品にいきなりCSV更新せず、テスト用商品で1件試す。

### 3. CSV を作成・編集

エディタは VS Code 等のテキストエディタ推奨。Excel は文字コード・先頭0落ち・改行コード変換などの事故が起きやすい。

### 4. CSV のエスケープ規則をチェック

- `,` を含む値は `"` で囲む
- 値内の `"` は `""` に二重化
- 改行を含む値は `"` で囲む

### 5. アップロード

差分アップロード（更新する商品のみ）が安全。

### 6. 表示確認

公開ページ・商品ページのフリースペース差込位置を実機で確認。

## 典型的な破損パターン

### パターンA：「列数が一致しません」

- ダブルクォートのエスケープ漏れ
- カンマを含む値が `"` で囲まれていない

### パターンB：「アップロード成功なのにフリースペースが反映されない」

- 商品マスタ管理画面で対象列の値が空 or 文字化け
- 文字コード不一致

### パターンC：「商品ページのレイアウトが崩れた」

- HTML タグの閉じ忘れ
- 想定外のCSSが入った
- 改行が想定と違う形で残った（`<br>` と CSV改行の混在）

### パターンD：「特殊文字が表示不可」

- `<` `>` `&` を実体参照（`&lt;` `&gt;` `&amp;`）でエスケープしなければ表示不可な箇所がある
- CSV側でHTMLタグとして書くか、テキストとしてエスケープして書くかをテンプレ側と合わせる

## フリースペース運用のコツ

- **フリースペース1〜10 にどんな内容を入れるかを店舗で標準化** する（例：1=キャッチ、2=スペック表、3=使い方…）
- **HTML を入れるならテンプレを見て、必要なクラス名・構造を把握** してからCSV化
- **更新前後のCSV を世代管理**（Git や日付バックアップ）
- **長文の本文は「商品説明（詳細）」列に書き、フリースペースは構造化された短いHTMLパーツに使う**
