# 除外条件の判定ロジック

## 在庫関連

### 在庫切れ（必須除外）

```
在庫数 = 0 → 除外
```

理由：広告流入してもCV不可、広告費100%損失。

### 在庫僅少（推奨除外）

```
在庫数 <= 2 → 除外検討
在庫数 <= 5 ＆ 売れ筋（過去30日販売10個以上） → 除外検討
```

理由：すぐ売り切れる可能性、配送遅延クレームリスク。

### 例外
- 受注生産品（リードタイム明示の場合）：除外しない
- 入荷予定が明確な商品：除外しない or 「予約販売」明記

## 粗利関連

### 粗利マイナス（必須除外）

```
売価 - 原価 - 平均広告費 - 送料負担 < 0 → 除外
```

理由：売れば売るほど赤字。

### 粗利率10%未満（推奨除外）

```
（売価 - 原価 - 平均広告費 - 送料負担） / 売価 < 0.10 → 除外
```

理由：広告費を入れて粗利率10%未満は事業的に厳しい。

### 例外（ロス・リーダー戦略）
- 集客目的で意図的に低粗利商品を広告する場合は除外しない
- ただし「集客→他商品クロスセル」の効果を別途検証

## RPP実績関連

### ROAS悪化（検討除外）

```
過去30日ROAS < 3.0 → 除外検討
過去30日ROAS < 2.0 → 除外推奨
過去30日ROAS < 1.0 → 必須除外（赤字）
```

ROAS（Return on Ad Spend）：売上 ÷ 広告費

### クリック多いがCV少ない（検討除外）

```
過去30日：
  クリック数 >= 30 ＆ CV数 = 0 → 除外検討
  クリック数 >= 100 ＆ CV数 = 0 → 除外推奨
```

理由：広告効果が出ていない、商品ページ・価格に問題がある可能性。

### CTR極端に低い（検討除外）

```
過去30日：
  CTR < 0.3% → 除外検討（広告デザイン・商品名見直し）
```

### 例外（新商品）
- 販売開始から30日未満の商品は実績不足で判定不可
- 「販売実績収集期間」として除外しない（評価不能）

## 季節関連

### 季節終了商品（必須除外）

シーズンが終わった商品：

| 商品 | シーズン | 除外時期 |
|---|---|---|
| 夏物（水着・浴衣・冷感寝具） | 5月-8月 | 9月以降 |
| 冬物（暖房・防寒着） | 10月-2月 | 3月以降 |
| クリスマス商品 | 11月-12月 | 1月以降 |
| 母の日ギフト | 4月-5月 | 5月第3日曜以降 |
| 父の日ギフト | 5月-6月 | 6月第4日曜以降 |
| お中元 | 6月-7月 | 8月以降 |
| お歳暮 | 11月-12月 | 1月以降 |

### 例外
- 通年使える季節商品（年中使うエアコン等）：除外しない
- 海外向け（季節が逆）：別管理

## 廃番関連

### 廃番予定（必須除外）

```
販売停止予定日 - 今日 <= 30日 → 段階的除外
販売停止予定日 - 今日 <= 7日 → 完全除外
販売停止後 → 商品削除＋除外維持
```

理由：在庫処分後に注文が入って欠品クレーム。

## 商標・規制関連

### 競合ブランド名キーワード（必須除外）

- 競合の商標・固有名詞への入札NG
- 商標権侵害リスク
- 楽天の独自審査でも違反扱い

### 薬機法・景表法リスクキーワード（必須除外）

- 「シミに効く」「アンチエイジング」（化粧品）
- 「痩せる」「便秘解消」（健食）
- 「業界No.1」「最安」（根拠なし）

## カテゴリ関連

### 特定カテゴリの除外

商品自体は良くても、特定カテゴリではCV率が低い場合の除外：

- 法人取引専用商品 → 個人向け検索からは除外
- 業務用商品 → 家庭用検索からは除外

## 除外条件の優先順位

複数条件に該当する場合の処理：

1. **必須除外**（在庫切れ・粗利マイナス・廃番）：即除外
2. **推奨除外**（低粗利・低ROAS・季節終了）：基本除外、戦略次第で判断
3. **検討除外**（中ROAS・低CTR）：実績次第で判断、新商品は除外しない

## 除外解除のトリガー

除外した商品を再開する条件：

| 解除条件 | トリガー |
|---|---|
| 在庫補充 | 在庫数3個以上に回復 |
| 粗利改善 | 価格改定・原価削減 |
| 季節到来 | シーズン1ヶ月前 |
| 実績改善 | 商品ページ改善後30日 |

## 除外解除のスケジュール

| 解除頻度 | 内容 |
|---|---|
| 毎日 | 在庫切れ商品の補充確認 |
| 毎週 | 季節商品の段階的解除 |
| 毎月 | 粗利改善・実績改善の見直し |
| 季節前 | 季節商品の本格解除 |

## 自動化の可能性

| 条件 | 自動化 |
|---|---|
| 在庫切れ | 在庫システムと連動して自動除外 |
| 粗利マイナス | 商品マスタの粗利情報から自動判定 |
| ROAS悪化 | RPP実績CSVから自動抽出 |
| 季節終了 | カレンダーベースで自動 |
| 廃番 | 商品マスタの販売停止フラグから |

自動化することで、見落としを防ぐ＋運用負荷を削減。

## 除外設計の効果測定

| 指標 | 計算 |
|---|---|
| 広告費削減額 | 除外前の広告費 - 除外後の広告費 |
| ROAS改善 | 除外前のROAS → 除外後のROAS |
| 無駄クリック削減 | 除外商品の過去クリック数 |
| 在庫切れクレーム削減 | 在庫切れ商品への広告流入 → 0 |

→ 月次で効果測定し、除外条件の見直し。
