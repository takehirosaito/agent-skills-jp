# 送料無料条件の表記注意（実務ノート）

---

## 1. 「全国送料無料」の地雷

「全国送料無料」と書くと、**沖縄・離島・北海道**の例外を必ず明示しないと**有利誤認・特商法違反**となる。

NG例：
```
全国送料無料！
```

OK例：
```
全国送料無料（一部離島・沖縄県を除く）
```

OK例2（離島・沖縄も含む場合）：
```
全国送料無料（沖縄・離島も含む）
```

---

## 2. 「○○円以上で送料無料」の表記

NG：閾値が3者（商品ページ／ストア情報／お買い物ガイド）で食い違う

OK：3者すべてに同一閾値・同一除外条件を記載

```
5,500円（税込）以上のご注文で送料無料
※沖縄県・離島は別途送料がかかります（XXX円）
※大型・冷凍商品は別途送料がかかる場合があります
```

---

## 3. 地域別送料の書き方

過去頻出パターン：

| 地域 | 送料目安 |
|---|---|
| 本州・四国・九州 | 700〜1,000円 |
| 北海道 | 1,000〜1,500円 |
| 沖縄 | 1,500〜2,500円 |
| 離島 | 別途見積もり |

商品ページとストア情報の地域・金額が一致しているか確認。

---

## 4. 「期間限定送料無料」の落とし穴

- 開始日・終了日を必ず明示
- 期間終了後は商品ページから訴求を削除
- バナー画像にも期間表示
- 終期未表示で続けると景表法上問題

---

## 5. 「ポイント込み送料無料」表記

「ポイント還元込みで実質送料無料」のような表記は**有利誤認リスク**。実際に送料は発生しているため、明確に分けて表記する。

NG：「送料無料！」（実は送料1,000円かかるがポイント1,000pt還元）
OK：「送料1,000円／ポイント1,000pt還元」

---

## 6. 大型・冷凍・特殊配送

| 種別 | 送料無料対象から除外したい場合の書き方 |
|---|---|
| 大型家具 | 「大型商品は別途送料・配送業者の指定があります」 |
| 冷凍・冷蔵 | 「冷凍便商品は別途クール便手数料がかかります」 |
| 代引手数料 | 「代引きをご利用の場合、別途手数料XXX円がかかります」 |

---

## 7. 「配送無料」「配達無料」など類似表現

すべて「送料無料」と同等に扱われる。混在させず**用語統一**。

---

## 8. 楽天との混同を避ける

楽天では「3,980円以上で送料無料ライン施策」がデフォルト。Yahoo!ではストア任意設定。ストア独自閾値を**明確に伝える**こと（楽天と同じだと思って閾値を勘違いするユーザーがいる）。

---

## 9. 送料無料の原資負担

- 商品単価に送料分を上乗せして「送料無料」訴求 → 競合との価格比較で不利
- 純粋に送料を吸収 → 粗利圧迫
- 5,000円以上等の閾値で送料無料 → 客単価UP効果も

設計時に**送料原資をどこで負担するか**を明示。

---

## 10. 送料無料訴求のチェックリスト

- [ ] 「全国」と書いた場合、沖縄・離島・北海道の例外を明示
- [ ] 閾値が商品ページ／ストア情報／お買い物ガイドで一致
- [ ] 期間限定なら開始日・終了日を明示
- [ ] ポイント込みではなく純粋な送料無料か
- [ ] 大型・冷凍・特殊配送の例外を明示
- [ ] 「送料無料」「配送無料」など用語の統一
- [ ] 送料原資（商品単価上乗せ／自社吸収／閾値超え）を社内で明確化
