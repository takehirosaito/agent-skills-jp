# Yahoo!配送・返品 表記矛盾 実例7パターン

---

## 例1：「全国送料無料・翌日発送」と特商法表記の矛盾

**商品ページ**：「全国送料無料！ご注文から翌日発送！」

**ストア情報**：
- 送料：本州・四国・九州 700円、北海道 1,000円、沖縄 1,500円
- 出荷目安：1〜3営業日以内

**お買い物ガイド**：5,500円以上で送料無料（沖縄・離島除く）

**判定**：
- 「全国送料無料」は事実と矛盾（送料設定あり） → 有利誤認・特商法違反リスク高
- 「翌日発送」と「1〜3営業日」が矛盾 → 顧客苦情・キャンセル要因

**修正方向**：
- 商品ページに「5,500円以上で送料無料（沖縄・離島は別途送料）」
- 「平日15時までのご注文で翌営業日出荷」に修正し、ストア情報と一致

## 例2：あす着維持失敗

**商品ページ**：「あす着可能」

**実態**：
- 出荷遅延率 8%
- ストア都合キャンセル率 4%

**判定**：
- 優良配送基準（出荷遅延5%／キャンセル2.5%）を超過 → 「あす着」表記が現実と乖離
- 優良配送ステータスが外れるリスク

**対処**：
- 商品ページから一時的に「あす着」訴求を外す
- 出荷キャパ拡大、在庫管理改善
- 30日程度の改善でステータス復帰見込み

## 例3：返品不可カテゴリの明記漏れ

**商品**：化粧水（200ml）

**商品ページ**：返品に関する記載なし

**ストア情報**：「お客様都合の返品は8日以内、未開封のみ」

**判定**：
- 化粧品は衛生上、開封後の返品が困難
- 商品ページに「化粧品のため返品不可」を明記すべき
- ユーザーが返品申請 → トラブル

**対処**：
商品ページに以下を明記：
```
※化粧品の特性上、お客様都合による返品はお受けできません。
※不良品・誤配送の場合は到着後7日以内にご連絡ください。
```

## 例4：返品送料負担の食い違い

**ストア情報**：「お客様都合の返品送料はお客様負担」

**商品ページ**：「サイズが合わなければ返品OK！」

**カスタマーサポートメール**：「往復送料はストア負担で対応します」

**判定**：3者で送料負担が不一致。お客様にとって有利誤認／社内対応にもブレ。

**対処**：
- 「ストア負担で返品OK」を採用するなら、ストア情報・商品ページ・お買い物ガイドすべて統一
- 「お客様負担」を採用するなら、商品ページの「返品OK」訴求を「ご返送送料お客様ご負担にて返品可能」に変更

## 例5：3営業日 vs 4日のずれ

**商品ページ**：「お届けまで通常3日」

**ストア情報**：「ご注文から3営業日以内に出荷」

**判定**：
- 「3日（カレンダー日）」と「3営業日」は意味が違う
- 金曜注文 → 3営業日 = 翌週水曜出荷／「3日」だと月曜到着の認識ずれ
- ユーザー期待値とのギャップで苦情・キャンセル

**対処**：
表現を「営業日」or「カレンダー日」で統一。営業日の定義（土日祝休 等）を明記。
```
ご注文確認後、平日3営業日以内に発送いたします（土日祝・年末年始除く）。
発送後、到着まで本州・四国・九州 1〜2日、北海道 2〜3日、沖縄 3〜5日です。
```

## 例6：配送業者の追跡番号未通知

**実態**：発送後の追跡番号通知が手動で、忘れることがある

**判定**：
- 「いつ届くか分からない」ストレス → ユーザー評価低下
- 「ストアからの連絡がない」苦情
- Yahoo!ショッピングのストア評価マイナス

**対処**：
- 自動通知システム導入（受注→出荷→追跡番号メール送信）
- 商品ページに「発送後、追跡番号をメールでお知らせします」と記載
- 配送業者の追跡URLも同時通知

## 例7：お盆・年末年始の出荷停止表記漏れ

**商品ページ**：「平日15時までのご注文で翌営業日出荷」

**実態**：8月13〜15日・12月29日〜1月3日は出荷停止

**判定**：
- 連休中の注文 → ユーザーは「翌営業日出荷」と期待 → 連休明けまで届かず苦情
- 優良配送のステータス維持にも影響

**対処**：
- 連休前1週間からストアトップ・商品ページに**連休告知バナー**
- 「8/13〜8/15はお盆休業のため出荷を停止いたします。8/16より順次出荷いたします。」
- お買い物ガイドに通年の休業日カレンダー
- 連休前は仕入・出荷を前倒し

## まとめ：定期チェックのリズム

| 頻度 | 確認内容 |
|---|---|
| 月次 | 3者整合性（送料／配送日／返品）／優良配送ステータス |
| 四半期 | 特商法13項目・最終確認画面6項目／返品実績の集計 |
| 半年 | 連休カレンダー更新／配送業者見直し |
| 年次 | 特商法改正対応／優良配送基準変更対応 |
