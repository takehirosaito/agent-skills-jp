# 価格・粗利の計算式と検算例

## 完全版 粗利式

```
粗利 = 販売価格
     − 仕入原価
     − 送料原価（送料込みプランの場合）
     − モール手数料（販売価格 × 手数料率）
     − ポイント原資（販売価格 × ポイント還元率）
     − キャンペーン原資（販売価格 × キャンペーン期間中の追加原資率）
     − クーポン原資（クーポン使用率 × クーポン額）
     − 広告費（売上 ÷ ROAS、または販売価格 × 広告費率）
     − 決済手数料（販売価格 × 決済手数料率）
     − 後払い手数料（後払い利用率 × 後払い手数料）
     − 返品ロス（販売価格 × 返品率 × 返品損失率）
     − 梱包資材費（1注文あたり）
     − ピッキング・出荷工数費（1注文あたり）
     − その他固定費按分（撮影費・LP費の販売数按分等）

粗利率 = 粗利 ÷ 販売価格
```

## 損益分岐値引率
```
損益分岐値引率 = 1 − 全コスト ÷ 元の販売価格
全コスト = 仕入原価 + 送料 + 手数料 + ポイント + 広告費 + その他
```

これより深く値引くと販売するほど赤字。ただし在庫処分・新規獲得LTV回収観点では赤字許容シナリオもあり得る。

## 価格弾力性

販売価格と販売数量の関係：
```
価格弾力性 = (販売数量変化率) ÷ (価格変化率)
```

例：10%値下げで20%販売増 → 価格弾力性 = 20 ÷ −10 = **−2.0**

|価格弾力性| > 1 なら値下げで売上増、< 1 なら値下げで売上減。

### 粗利維持に必要な販売数増加率
```
必要販売数増加率 = (元の粗利) ÷ (値引き後の粗利) − 1
```

例：元粗利1,000円、値引き後粗利800円
→ 必要増加率 = 1,000 ÷ 800 − 1 = 0.25 = **25%**

つまり値引き後の粗利で粗利総額を維持するには、販売数が25%増える必要。

## 検算例A：化粧品美容液 楽天販売

**前提**：
- 販売価格3,800円、仕入原価1,200円
- 送料原価500円（送料込みプラン）
- 楽天手数料率8%、ポイント原資3%
- クーポン原資1%（クーポン使用率20% × クーポン額5%）
- 広告費率6%、決済手数料率3%
- 返品率3%、返品損失率50%（返品時に商品が再販売不可になる確率）
- 梱包資材費80円

**コスト積み上げ**：

| 項目 | 金額 |
|---|---:|
| 販売価格 | 3,800 |
| 仕入原価 | −1,200 |
| 送料原価 | −500 |
| モール手数料（3,800×8%） | −304 |
| ポイント原資（3,800×3%） | −114 |
| クーポン原資（3,800×1%） | −38 |
| 広告費（3,800×6%） | −228 |
| 決済手数料（3,800×3%） | −114 |
| 返品ロス（3,800×3%×50%） | −57 |
| 梱包資材費 | −80 |
| **粗利** | **1,165** |

**粗利率**：1,165 ÷ 3,800 = **30.66%**

**損益分岐値引率**：
- 全コスト = 1,200 + 500 + 304 + 114 + 38 + 228 + 114 + 57 + 80 = 2,635円
- 損益分岐値引率 = 1 − 2,635 ÷ 3,800 = **30.7%**

検算：販売価格 = 仮価格×(1-0.307) → 仮価格 = 3,800なら粗利＝0、確かに約30.7%引きが損益分岐。
ただしモール手数料・ポイント原資・広告費・決済手数料・返品ロスは「販売価格×率」なので、値引きすると分子も減る。再計算：

値引き後販売価格をxとすると：
```
粗利 = x − 1,200 − 500 − 0.08x − 0.03x − 0.01x − 0.06x − 0.03x − 0.015x − 80
     = x(1 − 0.08 − 0.03 − 0.01 − 0.06 − 0.03 − 0.015) − 1,200 − 500 − 80
     = 0.775x − 1,780
```

粗利=0 となるx：
0.775x = 1,780 → x = **2,297円**

→ 損益分岐価格は2,297円。値引率：(3,800 − 2,297) ÷ 3,800 = **39.6%**

実際の計算式（コスト項目に販売価格×率が多い）を加味すると、損益分岐値引率は約40%。先程の30.7%は単純計算ミスだったので訂正。

### 訂正版 シナリオ比較

| 価格 | 値引率 | 粗利 | 粗利率 |
|---:|---:|---:|---:|
| 3,800 | 0% | 0.775×3,800 − 1,780 = 1,165 | 30.7% |
| 3,420（10%引）| 10% | 0.775×3,420 − 1,780 = 871 | 25.5% |
| 3,040（20%引）| 20% | 0.775×3,040 − 1,780 = 576 | 18.9% |
| 2,660（30%引）| 30% | 0.775×2,660 − 1,780 = 282 | 10.6% |
| 2,297（39.6%引） | 39.6% | 0 | 0% |

**結論**：損益分岐値引率は39.6%まで。これより深い値引きは赤字。

## 検算例B：低粗利アパレル

**前提**：
- 販売価格5,000円、仕入原価2,500円（原価率50%）
- 送料原価700円
- モール手数料率10%（楽天想定）
- ポイント原資3%、広告費率8%、決済手数料3%
- 返品率8%、返品損失率30%（再販売可能率70%）

**コスト積み上げ**：

| 項目 | 金額 |
|---|---:|
| 販売価格 | 5,000 |
| 仕入原価 | −2,500 |
| 送料原価 | −700 |
| モール手数料 | −500 |
| ポイント原資 | −150 |
| 広告費 | −400 |
| 決済手数料 | −150 |
| 返品ロス（5,000×8%×30%） | −120 |
| 梱包資材費 | −100 |
| **粗利** | **380** |

**粗利率**：380 ÷ 5,000 = **7.6%**

→ 粗利率がかなり薄い。値引キャンペーンで簡単に赤字化する。
損益分岐値引率：x(1 − 0.10 − 0.03 − 0.08 − 0.03 − 0.024) − 2,500 − 700 − 100 = 0
→ 0.736x = 3,300 → x = **4,484円**
→ 損益分岐値引率：(5,000 − 4,484) ÷ 5,000 = **10.3%**

→ 10%引きまで。それ以上は赤字。

## 検算例C：高単価家電 Amazon販売

**前提**：
- 販売価格28,000円、仕入原価17,000円
- FBA手数料：800円（小型）
- Amazon販売手数料率：10%
- 広告費率：5%
- 返品率：5%、返品損失率20%

**コスト積み上げ**：

| 項目 | 金額 |
|---|---:|
| 販売価格 | 28,000 |
| 仕入原価 | −17,000 |
| FBA手数料 | −800 |
| 販売手数料 | −2,800 |
| 広告費 | −1,400 |
| 返品ロス（28,000×5%×20%） | −280 |
| **粗利** | **5,720** |

**粗利率**：5,720 ÷ 28,000 = **20.4%**

→ 比較的健全な粗利率。FBA手数料は商品サイズで変動するため正確には公式FBA料金表で確認。

## ポイント原資の計算（楽天）

楽天では複数のポイント原資が積み上がる：
- 通常ポイント1倍（売上の1%）：店舗負担0% or 1%（コース次第）
- ポイント変倍（5倍・10倍等）：上乗せ分は店舗負担
- 楽天スーパーセール：店舗負担2%上乗せ等
- イーグルス感謝祭：1〜2%
- お買い物マラソン：店舗エントリーすると上乗せ

**通常時のポイント原資目安**：販売額の2〜3%
**キャンペーン時**：販売額の5〜10%

通常時のシミュレーションには3%、セール時のシミュレーションには8〜10%で計算するのが現実的。

## 広告費率の出し方

```
広告費率 = 1 ÷ ROAS
```

例：
- ROAS 500% → 広告費率 20%
- ROAS 800% → 広告費率 12.5%
- ROAS 1000% → 広告費率 10%
- ROAS 2000% → 広告費率 5%

実績ROASから逆算するか、業界平均（化粧品6〜10%、健食8〜12%、アパレル6〜10%）を使う。

## 価格弾力性 検算例

**前提**：販売価格3,800円、粗利1,165円、月販100個

**シナリオ：10%値引き → 価格3,420円、粗利871円**
- 同じ月販100個維持：粗利総額116,500 → 87,100円（**−29,400円**）
- 粗利維持に必要な販売数：1,165 × 100 ÷ 871 = **約134個**（+34%）
- つまり10%値引きで34%以上販売増 → 粗利UP

**実務上**：化粧品で10%値引きの販売数増は5〜15%程度が一般的（業界次第）。粗利維持には不足し、粗利減少を覚悟するか、別の集客効果（新規獲得LTV）で正当化する必要。
