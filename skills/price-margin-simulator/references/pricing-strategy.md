# 価格戦略・値引き戦略

## 値引きで使える販売数増加率の現実値

業界平均的な値引き弾力性（自社データでの検証必須）：

| カテゴリ | 10%値引き時の販売増 | 20%値引き時の販売増 |
|---|---|---|
| 化粧品 | +5〜15% | +20〜40% |
| 健食 | +10〜20% | +30〜60% |
| アパレル | +15〜25% | +40〜80% |
| 食品ギフト | +5〜10% | +15〜30% |
| 家電 | +5〜10% | +15〜30% |
| 雑貨 | +10〜30% | +30〜70% |

弾力性は商品単価・季節性・競合状況で大きく変動。短期A/Bテストでの実測が原則。

## 粗利維持に必要な販売数増加率の計算

```
必要販売数増加率 = (元の粗利) ÷ (値引き後の粗利) − 1
```

例：粗利率30%の商品で10%値引き → 値引き後粗利率約20% → 必要増加率約50%

**値引き弾力性 < 必要増加率 なら値引きするほど粗利減少**。

## 二重価格表示の8週間ルール

「通常価格〇〇円のところ、特別価格〇〇円」と表示する場合：
- 「通常価格」がセール開始直前の8週間のうち過半（4週以上）で実販売されていること
- 違反は景表法上の有利誤認、措置命令・課徴金リスク

「メーカー希望小売価格」「定価」表記は別途扱いだが、安易な併記は二重価格として違反になる可能性。

## 値引きの代替施策

「値引き」以外で売上を伸ばす施策：
1. **クーポン**：使用期限・併用条件付きで値引き感の演出
2. **ポイント付与**：実質値引きだが「お得感」を残す
3. **送料込み**：閾値設定で客単価UP
4. **まとめ買い割引**：個数増で全体粗利UP
5. **定期購入**：継続性で値引き原資を回収
6. **会員限定価格**：価格固定でも「特別感」を維持
7. **ノベルティ付与**：価格は据置で「お得」演出
8. **ギフトラッピング無料**：価格据置で価値向上

## 損益分岐値引率を超える値引きを許容する場面

通常は損益分岐値引率より深い値引きは赤字だが、以下のシナリオでは許容：

1. **新規獲得（LTV回収前提）**：初回赤字でリピートで回収
2. **在庫処分**：保管継続コスト＋評価損より値引き販売が有利
3. **季節終了**：来年に持ち越せない（賞味期限・流行）
4. **競合キャンペーン対抗**：短期で対応、長期は粗利戻し
5. **顧客満足度回復**：クレーム対応・お詫び価格

これらの場合、「赤字を許容する根拠」を明確にし、期間限定で実施。

## モール別の価格戦略

### 楽天
- ポイントキャンペーン（ポイント10倍等）でポイント原資を増やす方が、価格を下げるより粗利インパクトが小さい場合あり
- 「楽天お買い物マラソン」「楽天スーパーセール」期間中はキャンペーン原資が増えるため、通常時より粗利が薄い
- 楽天市場検索で「ポイント10倍」表示は強い訴求

### Amazon
- ポイント施策はAmazonでは弱い
- 値引き＋クーポン併用が定石
- セール時の「タイムセール」「クーポン」設定で目立つ

### Yahoo!
- PayPayキャンペーン（5の付く日・ゾロ目の日等）期間にPayPayポイント大量還元
- 自店舗のストアポイント設定とPayPay側キャンペーンの組合せ

## 価格決定の3つの基準

### 1. コストプラス（原価＋目標粗利）
- 仕入原価 × (1 + 目標粗利倍率) ＋ 各種コスト = 販売価格
- 安全だが市場の妥当性を反映していない
- 「うちはこの価格で売りたい」が市場拒否なら売れない

### 2. 競合価格基準
- 同等品の市場価格を調査
- ±5〜10%の範囲で設定
- 競合より安すぎても「品質懸念」、高すぎても「割高感」

### 3. 価値ベース（顧客の支払意欲）
- 顧客が「この価値ならこの価格」と感じる水準
- ブランド力・体験価値・希少性で正当化
- 高粗利を確保しやすいが、初期投資・ブランド構築が必要

## 推奨アプローチ

3つの基準を組合せ：
1. コストプラスで**最低価格ライン**を決める（損益分岐）
2. 競合価格基準で**市場価格レンジ**を把握
3. 価値ベースで**理想価格**を設定

→ 最低価格 < 設定価格 < 市場上限 になるよう調整。

## ペネトレーション vs スキミング

新商品の初期価格設定：

### ペネトレーション戦略（低価格で市場浸透）
- 初期は低価格・低粗利で売上拡大
- 競合排除・市場シェア獲得が目的
- リピート率の高い商材で機能
- リスク：低価格イメージ固定

### スキミング戦略（高価格で利益確保）
- 初期は高価格・高粗利で売上回収
- 早期ファンから順次広げる
- 新商品の独自性が高い場合に機能
- リスク：競合参入で価格崩れ

## 価格テストの実施手順

1. 仮説：「価格を10%上げてもCVR維持できる」「20%値引きで売上1.5倍化」
2. A/Bテスト：期間限定・対象限定で2グループに分割
3. KPI測定：CVR・AOV・粗利・売上総額
4. 結果分析：統計的有意性を確認
5. 本格展開：勝ちパターンを全体適用

短期テストでは需要変動・季節変動を加味して判断。
