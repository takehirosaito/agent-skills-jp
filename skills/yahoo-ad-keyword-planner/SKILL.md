# Yahoo!ショッピング 広告キーワード計画

## 概要

Yahoo!ショッピングの広告は、アイテムマッチ（旧PRオプション含む）と検索広告（Yahoo!広告 検索広告／LINEヤフー）に大別される。本スキルは、商品×ターゲットに対するキーワード設計、マッチタイプ、入札単価、予算配分、除外キーワード、そして検索クエリレポートを用いた継続最適化のループを設計する。

ECモール広告のROAS改善は、「無駄クリックを排除する除外語」と「CVRの高い狭意図ロングテール」を育てる仕組みで決まる。

## 最重要原則

**指名語は自然流入で取り、広告予算は一般語と用途・悩み語のロングテールに寄せる。** 自社ブランドの指名語に過剰投資すると、本来無料で取れるはずの売上を有償化してしまう。広告でレバレッジが効くのは「一般語の競合の中で目立たせる」「用途・悩み語でCVR高いロングテールを育てる」場面。これを基本姿勢とする。

要点：
- KW6分類：指名／一般／用途／悩み／競合／除外候補
- マッチタイプ：完全一致／フレーズ一致／部分一致（仕様は最新確認）
- ROAS = 売上÷広告費。商品単価×CVR×粗利率と入札単価のバランスで決まる
- 競合ブランド名への入札は商標権リスクあり、正規取扱品以外は基本回避

## 処理フロー

### Step 1：商品×目的の確認
- 対象商品（SKU／代表商品名／粗利率／在庫余力）
- 目的：新規獲得／指名買い防御／競合からの奪取／ロングテール拡張
- 月額予算と目標ROAS

### Step 2：KWブレインストーミング（6分類）
`references/keyword-classification.md` の表に従い、以下に振り分け：
1. 指名語（自社ブランド／型番）
2. 一般語（カテゴリ・商品タイプ）
3. 用途語（シーン・目的）
4. 悩み語（解決・属性）
5. 競合語（他社ブランド）
6. 除外候補

### Step 3：優先度マトリクスで序列化
| 分類 | 推奨アクション |
|---|---|
| 指名 × 自然1位 | 広告抑制（防御出稿は別途検討） |
| 指名 × 自然下位 | 検索広告で防御出稿 |
| 一般 × ボリューム高 | 主力配分（フレーズ一致主体） |
| 用途・悩み × CVR高 | ロングテール強化（完全一致） |
| 競合 × 正規取扱 | 表記注意のうえ慎重出稿 |
| 競合 × 取扱なし | 除外（商標リスク） |
| 明らかな意図ミスマッチ | 除外語リスト追加 |

### Step 4：マッチタイプ設計
- 完全一致：高CVR確定KW、商標リスクKW
- フレーズ一致：主力一般語、語順を保ちたいKW
- 部分一致：新規探索フェーズ（除外語整備とセット）

### Step 5：入札単価と予算配分
- 商品単価 × 目標CVR × 粗利率 ÷ 目標ROAS = 上限CPCの目安
- 例：単価5,000円／粗利率30％／CVR2％／目標ROAS5 → 上限CPC＝5,000×0.3×0.02÷(1/5)= **30円**
- 上記の数式は前提を変えると結果も変わるため、必ず自社の粗利・CVR実績で再計算する

### Step 6：除外キーワード初期設計
`references/negative-keywords.md` を参照し、以下のテンプレを当てる：
- 性別・年齢ミスマッチ（メンズ商品なら「レディース」「キッズ」除外）
- カテゴリ違い
- 否定意図（「コピー」「偽物」「中古」「無料」）
- 法務リスク（薬機抵触の効能語）

### Step 7：検索クエリレポート最適化ループ
`references/query-report-loop.md` の手順で、週次／月次：
1. 検索クエリレポート抽出
2. 想定外の高ボリュームKW → 新規KWとして登録
3. クリック多×コンバージョン0 → 除外語に追加
4. CVR高いKW → 入札単価アップ／マッチタイプを完全一致へ

### Step 8：実装KW計画の出力
分類×マッチタイプ×入札単価×アクションの一覧表で出力。

## 代表例

### ポーター 二つ折り財布 本革（正規取扱）

**指名語**：ポーター 二つ折り／PORTER タンカー／吉田カバン 財布
→ 自然1位なら抑制、競合出稿があれば防御出稿

**一般語**：二つ折り財布 メンズ／本革 財布 メンズ／革財布 メンズ
→ 主力配分（フレーズ一致、上限CPC 30〜60円目安）

**用途語**：通勤 財布 メンズ／ビジネス 財布 メンズ／父の日 財布
→ ロングテール強化（完全一致）

**悩み語**：カードたくさん入る 財布／薄い 財布 メンズ
→ USPと一致するなら完全一致で強化

**競合語（正規取扱外は除外）**：「ホワイトハウスコックス」等は除外候補

**除外語**：レディース、女性、子供、キッズ、コピー、偽物、中古、無料、ジャンク

## 品質ゲート

- 上限CPCを「粗利率×CVR×ROAS目標」から計算しているか
- 指名語に過剰投資していないか（自然1位は抑制が原則）
- 競合ブランド名は正規取扱の範囲内か
- 除外語リストに「コピー」「偽物」「中古」「無料」等の典型を入れているか
- 検索クエリレポートのレビュー頻度（週次／月次）を決めているか
- 季節KW（父の日／クリスマス等）のオン／オフ期を明確に管理しているか

## エッジケース

- **新商品で実績データなし**：類似カテゴリのCVRを参考に上限CPCを保守的に設定。最初の2週間は部分一致中心で探索、その後フレーズ一致／完全一致に絞る
- **指名語で競合が防御出稿してくる**：自社の自然順位が下がっているなら防御出稿は妥当。順位回復したら徐々に抑制
- **競合ブランド入札の商標リスク**：Yahoo!広告の商標権ガイドラインと商標権者の方針に従う。自社が正規取扱なら「正規品」表記で出稿可、それ以外は基本回避
- **低単価商品の上限CPC**：単価1,000円台では上限CPC10〜20円程度になり、競合と取り合いにならない。ロングテール中心の戦略へ
- **季節商品の予算配分**：父の日／母の日／クリスマスは2週間前から徐々に増額、当日から3日後に急減

## 注意事項

- Yahoo!広告の仕様（マッチタイプの種類、入札方式、PRオプションとの関係）は変更されるため、出稿前にYahoo!広告ヘルプおよびYahoo!ショッピング ストアクリエイターProヘルプで最新仕様を確認する
- 商標権を侵害するKWへの入札は商標権者から差止請求や損害賠償を受けるリスクがある
- ROAS目標は粗利率に応じて変える（粗利30%ならROAS3〜5、粗利50%ならROAS2〜3も成立）
- 上限CPCの試算は前提変数（CVR・粗利率）を置いた目安。実数値で必ず再計算する
