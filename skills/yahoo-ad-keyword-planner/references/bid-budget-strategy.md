## 2. CPC設計の基本

### ジャンル別の目安（実務感覚）

| ジャンル | 標準CPC目安 |
|---|---|
| ファッション（メンズ／レディース） | 30〜80円 |
| 食品（一般）| 20〜50円 |
| 食品ギフト | 50〜100円 |
| 家電 | 50〜150円 |
| コスメ | 30〜80円 |
| ベビー・キッズ | 30〜70円 |
| ペット | 30〜60円 |

ジャンル・KW競合度・販促日で大きく変動。

### CPC設計の式

```
CPC = (商品単価 × CVR × 粗利率) / 目標ROAS
```

例：
- 商品単価 5,000円
- CVR 2%（クリック → 購入の確率）
- 粗利率 40%
- 目標ROAS 5倍

```
CPC = (5,000 × 0.02 × 0.4) / 5 = 8円？
```

→ この計算式は損益分岐に近い。実務では「営業利益 + CPC」で計算：

```
許容CPC = (商品単価 × CVR × 粗利率) − 必要営業利益
       = (5,000 × 0.02 × 0.4) − 必要営業利益(20円/件)
       = 40 − 20 = 20円
```

CVR 2%なら、許容CPC 20円程度。

## 3. CPC階層

### 階層化
- **指名語**：抑制（CPC 20〜40円）
- **一般語（流入大）**：強化（CPC 50〜100円）
- **用途語**：中（CPC 40〜80円）
- **悩み語**：中〜強（CPC 40〜80円）
- **競合語（正規取扱）**：慎重（CPC 30〜60円）

### 上限の決め方
- 損益分岐CPCを計算
- 主力商品は損益分岐の80〜90%
- 在庫処分は損益分岐の50〜70%（広告原資を抑える）

---

## 4. 予算配分

### 月額予算の設計
- ストア売上 × 5〜10% を広告費の目安
- 売上 1,000,000円なら広告費 50,000〜100,000円

### 商品別配分
- 主力（売上7割を占める商品）：予算の60〜70%
- 育成商品：20%
- 在庫処分・探索：10〜20%

### 日次配分
- 月予算 100,000円 → 1日 3,300円
- 販促日（5の付く日／ゾロ目／プレミアム日曜）は 5,000〜10,000円
- 通常日は2,000〜3,000円

---

## 5. 販促日強化スケジュール

### 5の付く日（毎月3回）
- 3日前：CPC 1.2倍、予算 1.2倍
- 前日：1.5倍 / 1.5倍
- 当日：2倍 / 2倍
- 翌日：通常に戻す

### ゾロ目の日（11／22）
- 高額商品ターゲット、3日前から強化
- 当日は2〜3倍

### 超PayPay祭（年数回）
- 期間中（10日間程度）通常の2倍予算
- 期間後半に追い込みでさらに強化

## 7. 入札最適化の手順

1. 初期入札：損益分岐CPCの50〜70%で開始
2. 1週間：データ蓄積
3. 2週間：低ROAS-KWを抑制、高ROAS-KWを上げる
4. 1ヶ月：全体ROASを目標値に
5. 継続：月次で見直し

---

## 8. 入札タイプの使い分け

### 上限CPC方式
- 任意の最大CPCを設定
- 順位は競合との相対
- 予算消化が予測しやすい

### 自動入札（提供されている場合）
- システムが最適化
- データ蓄積後に有効
- ROAS目標やCVR目標を設定

---

## 9. 商品ページ品質と入札

CPCを上げてもCVRが低ければROASは下がる。**広告KW × 商品ページの一致度**が重要：

| 状態 | 改善方向 |
|---|---|
| 広告KW「カードたくさん入る 財布」／商品名「メンズ財布 二つ折り」 | 商品名・captionにKW反映 |
| 広告KW「セラミド 化粧水」／商品ページに成分表なし | サブ画像で成分表示 |
| 広告KW「父の日 ギフト」／商品ページにギフト訴求なし | ラッピング・メッセージカード対応の表記追加 |

商品ページの改善 → CVR向上 → 同じCPCでもROAS向上。

---

## 10. 入札ミスのリカバリ

### ミスのパターン
- 在庫切れ商品に広告継続 → 損切り
- 競合ブランド名を入札 → 商標リスク／除外
- 大量の関連性低い部分一致KW → 除外KW追加
- CPC高すぎて予算が早朝で枯れる → CPC下げる／予算上げる

### 即対応
- 異常CPC上昇 → 一時停止
- 大量の異常クリック（不自然なIP） → Yahoo!サポート連絡
- ROAS急落 → 商品ページ崩れ確認（価格表示／在庫切れ）
