# 検索クエリレポート 運用ループ

検索クエリレポートはアイテムマッチ広告の**最も価値あるデータ**。月次で必ず確認。

---

## 1. 検索クエリレポートとは

ユーザーが**実際に検索したKW**が記録される。広告主が設定したKWではなく、ユーザーの生の検索語。

含まれる情報：
- 検索語（クエリ）
- インプレッション数
- クリック数
- CTR（クリック率）
- 平均CPC
- 売上
- ROAS
- 注文件数
- CVR

---

## 2. レポートの取得

ストアクリエイターProの広告管理画面：
1. アイテムマッチ → レポート
2. 「検索クエリレポート」を選択
3. 期間指定（過去1ヶ月）
4. CSV ダウンロード

---

## 3. レポート分析の手順

### Step 1：インプレッション降順でソート
- 高インプレッション → 重要KW
- 低インプレッション × CV あり → ニッチで有望

### Step 2：CTR で異常値を見る
- CTR 0% → 商品とKWのミスマッチ／除外候補
- CTR > 10% → 関心高い／予算強化

### Step 3：ROAS でクラスタリング

| ROAS | アクション |
|---|---|
| 10倍以上 | 強化（CPC上げる、類似KW探索） |
| 5〜10倍 | 維持 |
| 3〜5倍 | 商品ページ改善で底上げ |
| 1〜3倍 | 損益分岐を確認、抑制検討 |
| 1倍未満 | 抑制／除外 |

### Step 4：CVR の異常値
- 高CTR × 低CVR → 商品ページに問題（価格／在庫／訴求）
- 低CTR × 高CVR → 露出を増やす（CPC上げ）

---

## 4. KW のアクション分類

### 高ROAS-KW
- 同じKWを完全一致で追加
- 類似KW（揺れ・複合語）を探索
- CPCを1.2〜1.5倍に
- 商品名・captionに反映

### 中ROAS-KW
- 商品ページ改善
- 関連訴求の追加
- 維持

### 低ROAS-KW
- CPC抑制
- マッチタイプを完全一致に絞る
- 商品との適合性を再確認

### CVゼロKW
- 関連性チェック
- 関連性低なら除外
- 関連性高ならランディング先（商品ページ）改善

## 5. 月次運用ループ（テンプレ）

```
■ 月：YYYY-MM
■ 担当：○○

【1. データ取得】
- 検索クエリレポート（前月分）
- 商品別売上レポート

【2. KW分析】
- インプレッション TOP 30 を抽出
- ROAS降順で並び替え
- 高ROAS-KW / 中ROAS-KW / 低ROAS-KW / CVゼロKW に分類

【3. アクション】
- 高ROAS-KW (5個)：
  - 類似KW探索
  - CPC強化
  - 商品名反映

- 低ROAS-KW (5個)：
  - 抑制／停止
  - マッチタイプ完全一致化

- CVゼロKW (10個)：
  - 除外追加

- 新KW (5個)：
  - 探索開始（低CPC）

【4. 商品ページ改善】
- 主力KWで流入したのに直帰多い商品：
  - 商品名・caption・画像の見直し

【5. 翌月計画】
- 強化商品
- 強化KW
- 月額予算
- 販促日（5の付く日／ゾロ目／プレミアム日曜）の予算配分
```

## 6. レポート活用の落とし穴

### データ期間が短すぎる
- 1週間ではノイズが多い → 最低1ヶ月
- 季節商品は3ヶ月単位

### サンプル数が少ない
- インプレッション 100 未満は判断が早い
- 統計的に有意なサンプルを待つ

### CVRの誤評価
- 商品ごとにCVRは大きく異なる
- 「絶対値」より「同商品の他KWとの相対比較」

### 季節要因の混入
- 12月に売れる商品の1月のデータは別評価
- 前年同月との比較で見る

---

## 7. KW別の戦略テンプレ

### 高インプレッション × 高ROAS
→ 主軸KW。完全一致＋商品名反映で固める。CPC強化。

### 高インプレッション × 低ROAS
→ 商品ページに改善余地。直帰要因（価格／在庫／訴求）を特定。

### 低インプレッション × 高ROAS
→ ニッチで有望。類似KW探索、CPC強化。

### 低インプレッション × 低ROAS
→ 関連性確認。除外候補。

---

## 8. 商品ページとの連動

検索クエリで上位のKWが商品名／captionに反映されているか：

| KW（流入多） | 商品名 反映 | caption 反映 |
|---|---|---|
| 二つ折り財布 メンズ | ◯ | ◯ |
| 本革 財布 | ◯ | ◯ |
| カードたくさん入る | ✕ → 要追加 | ✕ → 要追加 |
| 父の日 ギフト | △ | ◯ |

未反映KWで流入があるなら：
- 商品名・headline・captionに反映
- 反映後2週間でCVR改善するか観察

---

## 9. 異常検知

- ある日のCPCが急上昇 → 競合が入札強化／予算消化早期化
- ある日のクリックが急増 → 不正クリックの可能性／Yahoo!サポート連絡
- ROAS急落 → 商品ページの不具合（在庫切れ／価格表示エラー）
- 0インプレッション継続 → 入札不足／審査リジェクト

---

## 10. 年次サマリーへの活用

月次レポートの蓄積から年次パターンを把握：

- 季節別のKW傾向
- 販促日の効果
- 競合動向（CPC相場の変化）
- 主力商品のROAS推移
- 新規KW探索の成功率

来年の戦略立案に活用。
