# 商品×KW 優先度マトリクス

ROAS だけで判断せず、**粗利・在庫・LTV** を加えた多軸で優先度を決める。

---

## 1. 商品の3層分類

| 層 | 特徴 | 広告投資 |
|---|---|---|
| 主力（高粗利） | 売上の柱／粗利30%以上／在庫余裕 | 大 |
| 主力（育成） | 新商品／中粗利／在庫余裕 | 中（探索） |
| 在庫処分 | 季節終わり／低粗利／大量在庫 | 小（ROAS薄め許容） |
| 新規拡張 | 新カテゴリ／LTV狙い | 中（中長期） |

---

## 2. ROAS × 粗利 × 在庫 マトリクス

| 状況 | 判断 |
|---|---|
| ROAS高 / 粗利高 / 在庫余裕 | 強化（A評価） |
| ROAS高 / 粗利低 / 在庫余裕 | 営業利益確認、ROAS高くても赤字なら抑制 |
| ROAS低 / 粗利高 / 在庫余裕 | KW・商品ページ見直し、CPC最適化 |
| ROAS低 / 粗利低 / 在庫余裕 | 停止または大幅抑制 |
| 任意 / 任意 / 在庫切れ間近 | 一時停止／停止 |
| ROAS低 / 粗利高 / LTV見込み | 新規獲得目的で許容 |
| 在庫処分 / ROAS低 | 2〜3倍ROASでも許容（キャッシュ化目的） |

---

## 3. 営業利益チェック

ROAS高でも営業利益が出ているとは限らない。

### 計算
```
売上 = 100,000円
広告費 = 20,000円（ROAS = 5倍）
粗利率 = 30% → 粗利 = 30,000円
広告費を引いた営業利益 = 30,000 − 20,000 = 10,000円（営業利益率 10%）
```

→ ROAS 5倍でも、粗利30%なら営業利益10%。
→ ROAS 5倍で粗利20%なら、営業利益0%（広告分でちょうど）。
→ ROAS 5倍で粗利15%なら、営業利益マイナス。

### 損益分岐ROAS
- 粗利20% → ROAS 5倍が損益分岐
- 粗利30% → ROAS 3.3倍が損益分岐
- 粗利40% → ROAS 2.5倍が損益分岐
- 粗利50% → ROAS 2倍が損益分岐

**ROAS目標は粗利率の逆数を最低ライン**として設定。

---

## 4. LTV を加えた判断

新規顧客は初回購入のROAS低くても、リピートを含めると採算が合う場合がある。

### 例
- 初回購入：5,000円（粗利40% = 2,000円、広告費2,500円 → 営業利益 −500円）
- 6ヶ月リピート購入：10,000円（粗利40% = 4,000円、広告費なし → 営業利益 +4,000円）
- LTV：3,500円の営業利益

→ **新規獲得KW**はLTVベースで許容。
→ 主力商品の既存顧客流入KWはROAS厳しめ。

## 6. 販促日連動

5の付く日／ゾロ目／プレミアム日曜：

| タイミング | アクション |
|---|---|
| 3日前 | CPC を 1.2〜1.5倍に上げる |
| 前日 | 1.5倍 |
| 当日 | 1.5〜2倍 |
| 翌日朝 | 通常に戻す |

主力商品の一般語・用途語が中心。指名語は自然流入で取れるため販促日も抑制可。

## 7. 季節商戦

| ジャンル | 高需要期 | 閑散期 |
|---|---|---|
| メンズ財布 | 父の日（5〜6月）、ボーナス（12月） | 1〜2月 |
| 化粧水 | 季節の変わり目、母の日 | 真夏 |
| 食品ギフト | お中元（6〜7月）、お歳暮（11〜12月） | 端境期 |
| ベビー用品 | 春の出産シーズン、入園 | 真夏 |

高需要期にCPC強化、閑散期に抑制／停止。

---

## 8. 判定の意思決定フロー

```
1. 在庫切れ間近か？ → YES → 停止／販売停止
2. 粗利率 × ROAS = 営業利益はプラスか？ → NO → 停止 or 大幅抑制
3. LTV見込みが立つ新規獲得か？ → YES → 許容
4. 在庫処分目的か？ → YES → 低ROAS許容
5. 主力 × 高粗利 × 在庫余裕 → 強化
6. 主力 × 中粗利 × 在庫余裕 → 維持
```
