# 素材統一ルール

## 繊維素材

### 単一素材

| 統一表記 | 揺れ候補 |
|---|---|
| 綿 100% | コットン100％／cotton 100%／綿100% |
| ポリエステル 100% | PET／polyester／ポリ／ポリエステル100％ |
| ナイロン 100% | ナイロン／nylon |
| 麻 100% | リネン／linen／リネン100％ |
| 絹 100% | シルク／silk |
| ウール 100% | 羊毛／ウール |
| カシミヤ 100% | カシミア／cashmere |
| アクリル 100% | acrylic |
| レーヨン 100% | rayon／人絹 |

**運用ルール**：
- 配合率は必ず保持（「綿」だけにしない）
- 配合率は半角数字＋半角%
- 配合率は「綿 100%」形式（数字の前にスペース）

### 配合素材

```
綿 95% ポリウレタン 5%
ポリエステル 65% 綿 35%
ウール 70% アクリル 30%
```

**運用ルール**：
- 主成分（配合率高い順）から記載
- 各成分の間にスペース
- 配合率合計が100%になることを確認

### 部位別の素材

ジャケット・コート等で部位別の素材が違う場合：
```
表地：ウール 100%
裏地：ポリエステル 100%
別布：ナイロン 100%
中わた：ポリエステル 100%
```

属性列を「表地」「裏地」「中わた」と分ける、または素材列を複数行で記載。

|---|---|
| 本革（牛革） | 牛の本革 |
| 本革（羊革） | 羊の本革 |
| 本革（豚革） | 豚の本革 |

| ベジタブルタンニンレザー | 植物タンニン鞣しの本革 |

**重要**：景表法の優良誤認に直結。

- 「フェイクレザー」「ヴィーガンレザー」は合成皮革の同義

## 食品の原材料表記

食品衛生法の規定：
- 原材料は使用量の多い順
- アレルゲン7品目＋推奨20品目の表示
- 添加物の明示
- 原料原産地表示

商品マスタには「原材料名」列を別途持ち、機械的統一は行わない（法定表示要件のため）。

## 化粧品の全成分表示

薬機法の規定：
- 全成分を配合量の多い順
- 1%以下の成分は順不同でOK
- INCI名（International Nomenclature of Cosmetic Ingredients）に基づく

商品マスタには「全成分」列を別途持ち、原則そのまま記載。

## 家庭用品品質表示法の対象

繊維製品・合成樹脂加工品・電気機械器具・雑貨工業品の一部が対象。
表示すべき項目：
- 繊維の組成
- 性能（防水・吸水・保温等）
- 取扱方法
- 製造業者等の氏名

家庭用品品質表示法は消費者庁所管。詳細は消費者庁ヘルプ参照。

## 素材属性の運用

### バリエーション軸として使う
複数素材展開がある商品（同型・素材違い）：
- 親商品コード：ABCD-100
- 素材別SKU：ABCD-100-COT（綿）、ABCD-100-POL（ポリエステル）

### 検索用キーワードとして併用
商品名・商品説明に素材名を入れる：
- 「綿100%」「コットン素材」「天然麻」など

### モール属性スキーマ
モールごとに素材属性の入力欄が異なる。詳細は別ファイル参照。

## 統一の限界

機械的統一が難しいケース：
1. **オーガニックコットン vs コットン**：認証の有無で別物
2. **再生ポリエステル vs ポリエステル**：環境訴求で別扱い
3. **本革（牛）vs 本革（羊）**：本革でも種類で価値が違う
4. **シルク vs サテン**：素材（シルク）と織り方（サテン）の混同

→ 機械的に「綿」「ポリエステル」「シルク」に統一せず、ブランドの訴求軸を考慮して保持・統合を判断する。
