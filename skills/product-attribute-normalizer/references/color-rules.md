# カラー統一ルール

## 標準30色

EC実務でよく使うカラー名30種類。これに収まるように統一を提案：

### 無彩色
- ブラック
- ホワイト
- グレー（チャコール／ライトグレー／ダークグレーは別色保持可）
- ベージュ（オフホワイト／アイボリーは別色保持可）

### 暖色
- レッド（クリムゾン／ボルドー／ワインは別色保持可）
- ピンク（ローズピンク／ベビーピンク／コーラルピンクは別色保持可）
- オレンジ
- イエロー（マスタード／レモンイエローは別色保持可）
- ブラウン（キャメル／チョコレートは別色保持可）

### 寒色
- ブルー（ライトブルー／サックス／ロイヤルブルーは別色保持可）
- ネイビー
- グリーン（カーキ／オリーブ／フォレストグリーンは別色保持可）
- ターコイズ
- パープル（バイオレット／ラベンダーは別色保持可）

### メタリック・特殊
- ゴールド
- シルバー
- ブロンズ／カッパー
- パール
- マルチカラー
- 柄物（プリント／チェック／ストライプ／ドット など）

## 厳密に別色として保持する候補

機械的に「ピンク」「ブラウン」等にまとめると商品意味が崩れるケース：

| 別色保持 | 統合先と思いがちな色 | 理由 |
|---|---|---|
| ローズピンク | ピンク | 色相が異なる |
| ベビーピンク | ピンク | 彩度が低い |
| サーモンピンク | ピンク／オレンジ | 中間色 |
| ボルドー | レッド | ワイン色は別 |
| ワインレッド | レッド | 深い赤 |
| キャメル | ブラウン | 黄味の茶 |
| チョコレート | ブラウン | 暗い茶 |
| カーキ | グリーン | 黄味の緑 |
| オリーブ | グリーン | 緑黄 |
| サックス | ブルー | 淡い青 |
| ターコイズ | ブルー／グリーン | 青緑 |

## カラー名表記の文字種

- **基本はカタカナ**（モール検索の主流）
- 例外1：和風商品・呉服・伝統工芸品は漢字色名OK（朱色／藍色／鶯色 等）
- 例外2：ブランドの世界観で英語表記を使う場合（「BLACK」「NAVY」）
- 例外3：色番号運用（PANTONE 18-3949等）は色番号として別列で

## モール別の表記要件

### 楽天
- カタカナ統一が検索性高い
- 「ネイビー」で絞り込みされやすい

### Amazon
- 英語表記併記が国際カタログ的に有利
- 「Navy」「Black」も併記

### Yahoo!ショッピング
- カタカナ統一

### Google Merchant Center
- 英語表記（カラー属性は英語の方が認識精度高い）

## 多色商品（マルチカラー）の扱い

商品全体に複数色がある場合：
- **柄物**：「柄物」「プリント」「チェック」「ストライプ」「ドット」「マルチカラー」のいずれかを統一表記
- **メイン色＋差し色**：「ホワイト×ブラック」「ネイビー×レッド」のような形式
- **季節限定パターン**：「サマーフラワー」「ホリデーパターン」等は別色名

## カラー名と商品名の関係

商品名にカラー名を含める場合：
- 商品名：「[ブランド] スリムフィットTシャツ ネイビー」のように末尾に
- バリエーション軸：「ネイビー」だけを属性列に
- 検索性：商品名にもカラー名を入れる方がモール内検索で有利

## カラーバリエーションSKUの管理

色違いを同一商品の中でバリエーションとして展開する場合：
- 親商品コード：ABCD-001
- カラー別SKU：ABCD-001-NV（ネイビー）、ABCD-001-BK（ブラック）、ABCD-001-RD（レッド）
- カラー別JAN：各色で個別採番が原則

楽天SKUプロジェクト、Amazon親子バリエーション、Yahoo!バリエーションで同様の構造。
