# 在庫ステータス7区分

## 区分定義

### 1. 欠品（在庫0）
- 在庫数 = 0
- 販売中止／予約販売／代替誘導が必要
- 機会損失が発生中

### 2. 危険（残り日数 < リードタイム）
- 残り日数 < リードタイム日数
- 補充が間に合わず欠品確実
- 緊急発注（航空便・別仕入先）／販売制限

### 3. 注意（残り日数 < リードタイム × 1.5）
- 補充タイミング近接
- 通常発注対応

### 4. 適正（残り日数 リードタイム×1.5 〜 60日）
- 在庫は健全
- 様子見・補充ペース維持

### 5. 過剰（残り日数 60〜90日）
- やや在庫多め
- 広告強化・販促検討
- 発注ペースを落とす

### 6. 滞留入口（残り日数 90〜180日）
- 滞留化の予兆
- 値引き・セット化検討
- ページ改善（タイトル・画像・説明文）

### 7. 重度滞留（残り日数 180日以上）
- 滞留確定
- 在庫処分計画（別スキル deadstock-clearance-planner）

## 判定の優先順位

複数の区分に該当する場合：
1. 欠品が最優先
2. 危険・注意は機会損失額順
3. 過剰・滞留は在庫金額順

## 期間別の判定（重要）

「平均日販」を直近どの期間で算出するかで結論が変わる：

- 直近30日：直近トレンド重視（推奨）
- 直近60日：中期トレンド
- 直近90日：長期トレンド・季節調整

短期と長期で大きく乖離する場合（例：直近30日販売3本／日、直近90日販売1本／日）は両方提示し、ユーザーに判断を促す。

## 季節商品の特例

通常の判定式は「過去販売 = 将来販売」を前提とする。季節商品はこれが成り立たないため：

- 「年同期比較」で判定（前年同月の販売数を基準）
- 「シーズン残り日数」で適正在庫を算出
- シーズン外の在庫は「保管継続 vs 値引き処分」のシナリオ比較

## トレンド判定

直近販売数の傾向：
- 上昇：直近7日 > 直近30日平均×1.2
- 下降：直近7日 < 直近30日平均×0.8
- 横ばい：それ以外

上昇トレンドのSKUは安全在庫を多めに、下降トレンドは発注量抑制。

## 重要度マトリクス

在庫ステータス × 売上貢献度（ABC分析）：

| | A（売上上位） | B（中位） | C（下位） |
|---|---|---|---|
| 欠品 | 最優先発注 | 通常発注 | 廃番検討 |
| 危険 | 緊急発注 | 通常発注 | 様子見 |
| 注意 | 早期発注 | 通常発注 | 発注遅延OK |
| 適正 | 維持 | 維持 | 維持 |
| 過剰 | 様子見 | 広告強化 | 値引き検討 |
| 滞留 | 値引き | 処分計画 | 廃番・処分 |

ABC分析：
- A群：売上の70〜80%を占める上位20%のSKU
- B群：売上の15〜20%を占める中位30%のSKU
- C群：売上の5〜10%を占める下位50%のSKU

## 広告連動アラート

- 配信中広告がある SKU で在庫切れ → 即広告停止
- 配信中広告がある SKU で残り日数 < 7日 → 入札弱化・除外検討
- 配信中広告がある SKU で滞留中 → ROI見直し

楽天RPP・Amazon SP・Yahoo!アイテムマッチ・Google Shoppingで、これらのSKUを管理画面の除外設定で対応。
