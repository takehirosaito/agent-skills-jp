# 在庫アラート 計算式と検算例

## 基本式

### 残り日数
```
残り日数 = 現在庫数 ÷ 平均日販
```

### 平均日販
```
平均日販 = 期間内販売数 ÷ 期間日数
```

直近30日／60日／90日で計算し、傾向の異なる場合は両方提示する。

### 標準偏差（日販変動）
```
標準偏差 σ = √( Σ(日販 − 平均日販)² ÷ 日数 )
```

### 安全在庫
```
安全在庫 = 安全係数 × 標準偏差 × √リードタイム日数
```

**安全係数の目安**：
- 欠品許容率5%：1.65
- 欠品許容率2.5%：1.96
- 欠品許容率1%：2.33
- 欠品許容率0.1%：3.09

### 発注点
```
発注点 = 平均日販 × リードタイム日数 + 安全在庫
```

在庫数が発注点を下回ったら発注。

### 適正発注量（経済的発注量 EOQ）
```
EOQ = √( 2 × 年間需要 × 1回の発注費 ÷ 在庫保管費単価 )
```

EOQは古典的な公式だが、実務では「最小発注単位」「ロット割引」「賞味期限」等の制約で調整。

### 簡易発注量（実務）
```
発注量 = (発注後在庫目標 − 現在庫 − 発注済) + 安全在庫
発注後在庫目標 = 平均日販 × 適正在庫日数（例：30日）
```

### 機会損失額
```
1日あたり機会損失 = 平均日販 × 単価 × 粗利率
欠品中の累計機会損失 = 1日あたり機会損失 × 欠品予測日数
```

### 滞留損失予測
```
滞留損失 = 取得原価 × 在庫数 × 滞留係数（経過日数×0.001 等の逓減関数）
```

## 検算例A：化粧水の補充判断

**前提**：
- SKU-A001 化粧水
- 在庫50本
- 直近30日販売数：150本 → 平均日販5本
- 標準偏差：σ = 2本
- リードタイム：7日
- 欠品許容5% → 安全係数1.65
- 単価3,000円、粗利率50%

**計算**：

1. **残り日数**：50 ÷ 5 = **10日**
2. **安全在庫**：1.65 × 2 × √7 = 1.65 × 2 × 2.6458 = **約8.7本** → 9本
3. **発注点**：5 × 7 + 9 = **44本**
4. **判定**：在庫50本 > 発注点44本だが、近い。残り10日のうち7日でリードタイムが消費されるため、3日後には発注必要
5. **機会損失（欠品時）**：5本 × 3,000円 × 50% = 7,500円／日
6. **推奨**：50本 - 44本 = 6本の余裕。3日後を目処に発注

**発注量**：
- 適正在庫日数：30日と仮定
- 発注後在庫目標：5 × 30 = 150本
- 発注量：150 − 50 + 9 = **109本**
- ロット単位（仮に50本ロット）に合わせて100本 or 150本

## 検算例B：美容液 欠品予測

**前提**：
- SKU-A015 美容液
- 在庫5本
- 平均日販3本、σ = 1本
- リードタイム14日
- 単価7,000円、粗利率55%

**計算**：

1. **残り日数**：5 ÷ 3 = **1.67日**
2. **欠品予測**：リードタイム14日 − 残り1.67日 = **12.33日の欠品**
3. **安全在庫**：1.65 × 1 × √14 = 1.65 × 3.742 = **約6.2本** → 7本
4. **発注点**：3 × 14 + 7 = **49本**
5. **判定**：在庫5本 << 発注点49本。「危険」ステータス、即発注必須
6. **機会損失額／日**：3本 × 7,000円 × 55% = **11,550円／日**
7. **欠品中の累計機会損失**：11,550 × 12.33 = **約14.2万円**
8. **推奨アクション**：
   - 緊急発注（航空便等でリードタイム短縮）
   - 在庫切れ前に「販売制限」設定（1人1個まで）
   - 代替品への誘導
   - 広告停止

**発注量**：
- 適正在庫日数：45日（欠品対策で多めに）
- 発注後在庫目標：3 × 45 = 135本
- 発注量：135 − 5 + 7 = **137本**

## 検算例C：滞留入口商品の判定

**前提**：
- SKU-B055 廃番候補リップ
- 在庫300本
- 直近90日販売数：15本
- 平均日販：15 ÷ 90 = **0.167本**
- 取得原価500円

**計算**：

1. **残り日数**：300 ÷ 0.167 = **約1,800日（5年）**
2. **在庫金額**：500 × 300 = **150,000円**
3. **判定**：完全な滞留商品。在庫処分計画へ
4. **広告除外**：販売数が極端に低いため広告ROIマイナス、即除外

## 検算例D：季節商品の判定

**前提**：
- SKU-C010 夏物アイスケース
- 在庫500個、現在2月
- 過去2年の販売パターン：6月50個／7月150個／8月200個／9月80個

**計算**：

1. **直近30日（1月）の平均日販**：1本／日
2. **来年6〜9月の予測販売数**：480個（過去2年平均）
3. **残り日数（現在の平均日販ベース）**：500日（無意味）
4. **季節考慮の判定**：
   - 来シーズン（6〜9月）の予測販売480個 vs 在庫500個 → ほぼ消化可能
   - 倉庫保管料：100円／月 × 4ヶ月 = 400円 × 500個 = 20万円相当
   - 評価：保管継続 vs 値引き処分のシナリオ比較が必要

5. **推奨**：来シーズンへ保管（倉庫費吸収）、来シーズン終盤に未消化分の処分計画

## 検算例E：新商品の初期判定

**前提**：
- SKU-D001 新商品（発売後14日）
- 14日販売数：35個 → 平均日販2.5個
- 在庫150個
- 標準偏差不明（データ少）

**計算**：

1. **残り日数**：150 ÷ 2.5 = **60日**
2. **判定**：適正範囲。ただしデータが14日分しかないため判定信頼度低
3. **推奨**：30日経過後に再評価。初期発注後の追加発注はトレンドが見えてから

## 安全係数の選び方

| 商品の重要度・特性 | 推奨欠品許容率 | 安全係数 |
|---|---|---|
| 看板商品・売れ筋・広告投下中 | 1〜2% | 2.05〜2.33 |
| 主力商品 | 5% | 1.65 |
| 一般商品 | 10% | 1.28 |
| 季節商品・トレンド商品 | 15% | 1.04 |
| 廃番候補・リピートなし | 50% | 0 |

## ロット制約の考慮

最小発注単位がある場合：
```
実発注量 = max(計算上の発注量, 最小発注単位) を ロット単位に切り上げ
```

例：計算上109本、ロット単位50本 → 150本発注

## 賞味期限がある場合

```
発注量上限 = (賞味期限日数 − リードタイム) × 平均日販
```

例：賞味期限180日、リードタイム30日、平均日販2個
→ 発注量上限 = (180 − 30) × 2 = **300個**

これ以上発注すると、賞味期限切れリスク。

## モール間在庫差分

複数モール出店時、それぞれの在庫管理が独立だと矛盾が発生：
- 楽天在庫50本／Amazon在庫30本／自社在庫合計80本のはず → 同じ商品で別管理だと売り過ぎリスク

ネクストエンジン等の一元管理ツール使用が前提。在庫差分が見つかったら即対応：
- 売り過ぎ：仕入緊急発注／顧客への謝罪・キャンセル対応
- 売れ残し：モール間で在庫平準化
