# 実質単価計算式と楽天ポイント体系

## 顧客視点の実質単価

```
顧客実質単価
 = 商品価格
 + 送料
 - クーポン値引
 - 獲得ポイント合計（楽天負担＋店舗負担）
```

獲得ポイントは「実質的に1円相当」として計算（楽天ポイントは1pt=1円）。

## 楽天ポイント体系

### 通常ポイント（1%）
- 楽天が標準で付与
- 全商品共通
- 店舗負担なし

### SPU（Super Point Up Program）
- 楽天会員が条件を満たすと最大16倍まで上昇
- 主な要素：
  - 楽天モバイル：+4倍
  - 楽天カード：+2倍
  - 楽天プレミアムカード：+4倍
  - 楽天銀行：+0.5倍
  - 楽天ブックス：+0.5倍
  - 楽天証券：+0.5倍
  - 楽天トラベル：+1倍
  - 楽天ファッション：+0.5倍
  - 楽天ビューティ：+1倍
  - 楽天ペイ：+0.5倍
  - その他多数
- 店舗負担なし（楽天が負担）
- 顧客の会員状況により獲得倍率が変動

### 買いまわり倍率（SS／マラソン）
- 1ショップ1,000円以上の購入で最大10倍
- 10ショップ買いまわりで最大+9倍
- 店舗負担なし（楽天負担）

### 店舗独自ポイント
- 店舗が任意で設定するポイント倍率（通常1倍超過分）
- **店舗負担**：商品売価×追加倍率分が店舗コスト
- 例：店舗が「3倍」設定 → 店舗負担は商品売価×2%

### 各種キャンペーンポイント
- 楽天主催：店舗負担なし（楽天負担）
- 店舗主催：店舗負担

## 計算例A：シンプルケース

**前提**：
- 商品価格 5,000円
- 送料無料（店舗負担500円相当）
- クーポンなし
- 楽天通常ポイント 1%
- SPU 4倍（顧客の状況）
- 店舗独自ポイント 1倍（追加なし）

**顧客視点**：
- 商品価格：5,000円
- 送料：0円
- クーポン：0円
- 獲得ポイント：5,000 × 5% = 250pt（通常1% + SPU 4倍分）
- 実質単価：5,000 - 250 = **4,750円**

**店舗視点**：
- 顧客支払：5,000円
- システム利用料（仮5%）：250円
- 決済手数料（仮3%）：150円
- 店舗負担ポイント原資：0円（店舗独自ポイントなし）
- 送料負担：500円
- 原価（粗利率30%仮定）：3,500円
- 粗利額：5,000 - 250 - 150 - 0 - 500 - 3,500 = 600円
- 粗利率：600 / 5,000 = **12.0%**

## 計算例B：SS買いまわり時

**前提**：例A + 買いまわり倍率5倍

**顧客視点**：
- 獲得ポイント：5,000 × (1% + 4%[SPU] + 5%[買いまわり]) = 5,000 × 10% = 500pt
- 実質単価：5,000 - 500 = **4,500円**

→ 買いまわり倍率5倍で実質単価が250円下がる（顧客視点）。

**店舗視点**：粗利は例Aと同じ12.0%（買いまわりは楽天負担）。

→ 買いまわり倍率は店舗コストにならず、顧客の実質単価感覚を下げる。**集客力が上がる**。

## 計算例C：店舗独自ポイント3倍上乗せ

**前提**：例A + 店舗独自ポイント 通常1倍に3倍上乗せ（=ポイント合計4倍相当）

**顧客視点**：
- 獲得ポイント：5,000 × (1% + 4%[SPU] + 3%[店舗負担]) = 5,000 × 8% = 400pt
- 実質単価：5,000 - 400 = **4,600円**

**店舗視点**：
- 店舗負担ポイント原資：5,000 × 3% = 150円
- 粗利額：5,000 - 250 - 150 - 150 - 500 - 3,500 = 450円
- 粗利率：450 / 5,000 = **9.0%**

→ 店舗独自ポイントの上乗せは店舗コスト。粗利率が下がる。顧客の実質単価は150円下がる。

## 計算例D：クーポン併用

**前提**：例A + 500円OFFクーポン

**顧客視点**：
- 顧客支払：5,000 - 500 = 4,500円
- 獲得ポイント：4,500 × 5% = 225pt
- 実質単価：4,500 - 225 = **4,275円**

**店舗視点**：
- 顧客支払：4,500円
- システム利用料：4,500 × 5% = 225円
- 決済手数料：4,500 × 3% = 135円
- 送料負担：500円
- 原価：3,500円
- 粗利額：4,500 - 225 - 135 - 500 - 3,500 = 140円
- 粗利率：140 / 4,500 = **3.1%**

→ クーポン500円は店舗コスト直撃。粗利率が大幅低下。

## 計算例E：競合との実質単価比較

**前提**：類似商品3店舗

| 項目 | 自店 | 競合A | 競合B |
|---|---|---|---|
| 商品価格 | 5,000 | 4,800 | 4,500 |
| 送料 | 0（無料） | 0（無料） | 800（別途） |
| クーポン | -500 | 0 | 0 |
| 楽天通常P+SPU（5%想定） | 250 | 240 | 265 |
| 店舗独自P（自店3倍） | 150 | 0 | 0 |
| **顧客実質単価** | **4,100** | **4,560** | **5,035** |

→ 商品価格では自店が最高だが、実質単価では最安。

## 顧客視点と店舗視点のトレードオフ

| 戦略 | 顧客実質単価 | 店舗粗利率 | 集客力 |
|---|---|---|---|
| 価格を下げる | 下がる | 下がる | 上がる |
| 店舗ポイント上乗せ | 下がる | 下がる | やや上がる |
| クーポン配布 | 下がる | 下がる | 上がる |
| SPU連動施策に参加 | 下がる | **下がらない** | 上がる |
| 買いまわり期に集中 | 下がる | **下がらない** | 大幅に上がる |

→ **店舗負担せずに顧客実質単価を下げられる施策（SPU・買いまわり）を最大活用**するのが楽天運用の基本。

## 計算で押さえるべきポイント

1. 「実質単価」と「店舗粗利」は別軸。両方を見る
2. 楽天負担と店舗負担を区別する
3. クーポンは店舗負担100%
4. 店舗独自ポイントは追加倍率分だけ店舗負担
5. SPU・買いまわり倍率は楽天負担100%
6. 競合の SPU は顧客次第（自社では制御不能）
