# 実質単価比較 実例4パターン

## 例1：電気ケトル（3店舗比較）

### 前提
類似仕様の電気ケトル（1.0L・温度調整付き）、お買い物マラソン期間中、SPU 4倍想定。

### 価格比較

| 項目 | 自店 | 競合A | 競合B |
|---|---|---|---|
| 商品価格 | 5,000 | 4,800 | 4,500 |
| 送料 | 0（無料） | 0（無料） | 800（別途） |
| クーポン | -500（自店配布） | 0 | 0 |
| 顧客支払額 | 4,500 | 4,800 | 5,300 |
| 楽天通常P（1%） | 45 | 48 | 53 |
| SPU想定（+4%） | 180 | 192 | 212 |
| 買いまわり倍率 5倍想定 | 225 | 240 | 265 |
| 店舗独自P（+2%自店のみ） | 90 | 0 | 0 |
| 獲得ポイント合計 | 540 | 480 | 530 |
| **顧客実質単価** | **3,960** | **4,320** | **4,770** |

→ 自店は商品価格は最高だが、クーポン＋店舗独自ポイントで実質単価最安。

### 店舗粗利（自店）

- 原価（粗利率30%想定）：3,500円
- 顧客支払：4,500円
- システム利用料（5%仮定）：225円
- 決済手数料（3%仮定）：135円
- 店舗負担ポイント：90円
- 送料負担：500円
- 粗利：4,500 - 225 - 135 - 90 - 500 - 3,500 = 50円
- 粗利率：50 / 4,500 = **1.1%**

→ 集客効果はあるが粗利は極めて薄い。バンドル販売・関連商品クロスセルが必要。

### 推奨戦略
- 単品の値引はこれ以上やらない
- 関連商品（コーヒー豆・ティーバッグ等）のクロスセル強化
- レビュー獲得施策で「ランキング・レビュー数」での集客に転換

## 例2：化粧品スキンケアセット

### 前提
化粧水＋乳液＋美容液のセット、母の日ギフト需要、SPU 3倍想定。

### 価格比較

| 項目 | 自店 | 競合A | 競合B |
|---|---|---|---|
| 商品価格 | 8,000 | 7,500 | 7,200 |
| 送料 | 0 | 0 | 0 |
| クーポン | -500 | 0 | -300 |
| 顧客支払額 | 7,500 | 7,500 | 6,900 |
| 通常P+SPU（4%） | 300 | 300 | 276 |
| 店舗独自P（自店のみ +3%） | 225 | 0 | 0 |
| 獲得P合計 | 525 | 300 | 276 |
| **顧客実質単価** | **6,975** | **7,200** | **6,624** |

→ 競合Bが最安。自店は2位。

### 推奨戦略
- 商品価格は妥当、クーポン額を増額（500→800）すれば競合Bを下回れる
- ただし粗利率が下がるため、ラッピング・サンプル付・送料無料の付加価値で差別化

## 例3：食品ギフト（産直フルーツ・お中元）

### 前提
産直メロン2玉セット、お中元需要、SPU 2倍想定。

### 価格比較

| 項目 | 自店 | 競合A |
|---|---|---|
| 商品価格 | 5,000 | 4,800 |
| 送料 | 0 | 0 |
| クーポン | 0 | -200（お中元クーポン） |
| 顧客支払額 | 5,000 | 4,600 |
| 通常P+SPU（3%） | 150 | 138 |
| 店舗独自P | 0 | 0 |
| 獲得P合計 | 150 | 138 |
| **顧客実質単価** | **4,850** | **4,462** |

→ 競合Aが安い。

### 戦略
- 産直の独自価値（生産者の顔・産地・配送日指定）で差別化
- 食品なら「のし」「メッセージカード」「冷蔵配送」の充実
- 「○○農園 直送」のストーリー訴求
- 価格追随よりプレミアム戦略が向く

## 例4：インテリア家具（2人掛けソファ）

### 前提
2人掛けソファ・布張り、新生活シーズン、SPU 3倍想定。

### 価格比較

| 項目 | 自店 | 競合A |
|---|---|---|
| 商品価格 | 35,000 | 32,000 |
| 送料 | 0 | 3,000（別途） |
| クーポン | -2,000（自店） | 0 |
| 顧客支払額 | 33,000 | 35,000 |
| 通常P+SPU（4%） | 1,320 | 1,400 |
| 店舗独自P（+5%自店） | 1,650 | 0 |
| 獲得P合計 | 2,970 | 1,400 |
| **顧客実質単価** | **30,030** | **33,600** |

→ 自店が圧倒的に有利（送料無料＋クーポン＋店舗独自ポイント）。

### 店舗粗利（自店）

- 原価（粗利率40%想定）：21,000円
- 顧客支払：33,000円
- システム利用料（5%）：1,650円
- 決済手数料（3%）：990円
- 店舗負担ポイント：1,650円
- 送料負担（家具配送費）：3,500円仮定
- 粗利：33,000 - 1,650 - 990 - 1,650 - 3,500 - 21,000 = 4,210円
- 粗利率：4,210 / 33,000 = **12.8%**

→ 粗利率は確保できている（高額商品なので絶対額も大きい）。

### 戦略
- 送料無料＋ポイント上乗せのコンビが効いている
- これ以上の値引は粗利を侵食
- アップセル（オットマン・カバーセット等）で客単価アップ
