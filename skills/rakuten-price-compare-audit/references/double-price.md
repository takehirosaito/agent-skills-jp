# 二重価格表示・8週間ルール詳細

## 二重価格表示とは

「通常価格○○円 → セール価格○○円」のように、**比較対照価格** と **販売価格** を併記する表示。景表法・消費者庁ガイドラインで根拠が必要。

## 8週間ルール

セール開始直前の **8週間のうち過半（4週間以上）** で、その比較対照価格で **実際に販売されていた価格** であることが必要。

### 該当する／しないの判定

| 状況 | 8週間ルール |
|---|---|
| 直近8週間ずっと通常価格5,000円で販売、今週セール3,000円 | ✅ 該当 |
| 直近8週間のうち5週間が5,000円、3週間がセール3,500円、今週3,000円 | ✅ 該当（5週間 > 4週間で過半） |
| 直近8週間のうち3週間が5,000円、5週間がセール3,500円、今週3,000円 | ❌ 該当しない（過半は3,500円） |
| 直近8週間ずっと3,500円で販売、今週「通常5,000円→3,000円」と表示 | ❌ 該当しない（5,000円での実販売実績なし） |
| 新商品（販売開始2週間）、メーカー希望小売価格5,000円→3,000円 | △ 希望小売価格として表示する場合は実在する希望小売価格が必要 |

## 比較対照価格の種類

### 通常価格（自店過去価格）
- 8週間ルール適用
- 過半（4週間以上）で実販売されていた価格

### メーカー希望小売価格（オープン価格）
- メーカーが希望する小売価格として表示可能
- ただし「実在する希望小売価格」であること
- メーカーが「オープン価格」とした商品では希望小売価格は使えない

### 当社旧価格・旧モデル価格
- 自店での過去販売実績が必要
- 旧モデル（型番違い）の価格を新モデルの比較対照に使うのは原則NG

### 競合価格
- 「他店では○○円」の表示は不当比較・優良誤認のリスク
- 競合の固有名詞を出すのは商標問題
- 原則として競合価格を比較対照に使わない

## 比較対照価格の表示方法

| OK | NG |
|---|---|
| 「通常価格5,000円→3,000円」（8週間ルール根拠あり） | 通常価格の根拠なし |
| 「メーカー希望小売価格5,000円→3,000円」（実在する場合） | 希望小売価格が架空 |
| 「○月○日まで限定価格3,000円」（期間明示） | 永続的に「セール」表示 |
| 「20%OFF（5,000円→4,000円）」（根拠あり） | 比較対照価格不明 |

## 「○%OFF」の表示

「○%OFF」は比較対照価格との差分を示す表示。比較対照価格の根拠（8週間ルール等）が必要。

### 計算と表示の対応

- 「20%OFF（5,000円→4,000円）」：通常5,000円→セール4,000円、1,000円OFF、20%減
- 「半額（5,000円→2,500円）」：50%OFF
- 「セール価格3,000円（通常5,000円から40%OFF）」：明示的な比較

### NG表示

- 「最大50%OFF」（実際は10〜50%幅で大半が10〜20%）：誇大表示
- 「全品20%OFF」（一部対象外）：有利誤認

## 「半額」「半額以下」「最安」等の最上級表現

| 表現 | 根拠 |
|---|---|
| 半額／半額以下 | 比較対照価格の8週間ルール根拠 |
| 最安／最安値 | 何との比較か明示、根拠あり |
| 業界最安 | 業界範囲の定義、調査根拠 |
| 過去最安 | 自店過去の最安値であれば事実 |
| 期間最安 | 期間限定での最安、期間明示 |

## 「2点目半額」「2点目無料」等の組合せ表示

- 単品実質価格の根拠が必要
- 「2点で○○円」と表示できる場合のみ「半額」「無料」を使う
- 1点目だけ買う顧客との価格差を不当に大きく見せない

## ポイント還元との関係

- ポイント還元は **値引き表示ではない**（買い物時の負担額は減らない、後日ポイントが付く）
- 「実質○○円OFF」のような表現には注意（楽天は別途独自ガイドあり）
- 「ポイント10倍」「ポイント還元20%」は事実ベースで表示可能

## 楽天独自審査

楽天市場は法令に加えて独自審査基準を持つ：

- 「通常価格」「メーカー希望小売価格」表記の根拠提出要請
- 「最安」「業界初」等の最上級表現に証明資料要請
- 違反点数の累積で違反レベル上昇、最悪契約解除

楽天運用では **法令＋楽天独自基準** の両方を満たすことが必要。

## 表示に迷ったとき

1. 比較対照価格の根拠（販売実績）を準備できるか
2. 8週間ルール根拠（実販売記録）が手元にあるか
3. 期間明示・条件明示がされているか
4. 「最安」「No.1」の根拠調査資料があるか
5. 楽天プレビュー画面で違和感がないか

これらが揃わない場合は、シンプルに「セール価格○○円」だけで売る方が安全。

## チェックリスト

二重価格表示する前：

- [ ] 通常価格として表示する金額は、直近8週間のうち4週間以上で実販売していた価格
- [ ] メーカー希望小売価格として表示する金額は、実在するメーカー設定価格
- [ ] 「半額」「○%OFF」の比較対照価格に根拠あり
- [ ] 「最安」「最大」の表現に客観的根拠あり
- [ ] 期間限定の場合、期間が明示されている
- [ ] 終了日に文言切替が予約されている
- [ ] 楽天独自基準（違反点数リスク）も確認した
