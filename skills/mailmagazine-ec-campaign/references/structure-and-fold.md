# メルマガ本文構成と1スクロール領域

## 本文の標準構成

```
[ヘッダー（ロゴ・ナビ）]
[1スクロール領域：通知文・オファー・第一CTA]
─────────────────────
[商品紹介（複数）]
[第二CTA]
─────────────────────
[セカンダリ情報（ブログ・SNS・お知らせ）]
[第三CTA（任意）]
─────────────────────
[フッター：会社情報・特商法表示・配信解除]
```

## 1スクロール領域の重要性

スマホでメールを開いた瞬間に見える領域は約400-500px（コンテンツ部分）。ここに以下を必ず配置：

1. **挨拶は短く**（1-2行で済ませる）
2. **キャンペーンの結論**（何が・いくら・いつまで）
3. **第一CTA**（クーポン取得 or 商品ページへ）

避ける：
- 長い前置き・自己紹介
- 「いつも誠にありがとうございます」の段落で1スクロール埋め尽くす
- 画像が大きすぎてオファーが見えない

## 構成パターン

```
[ヘッダー]：ロゴ＋ナビ

[1スクロール]：

─────────────────────

[セカンダリ]：今週のスタッフコーデ／ブログ更新

[フッター]：会社情報＋配信解除
```

```

```

## CTAの設計

### CTAボタン文言

| パターン | 例 |
|---|---|
| 動詞＋具体性 | クーポンを取得する／商品ページを見る |
| ベネフィット | 30%OFFで購入する／無料サンプルを試す |
| 急がせる | あと2日、今すぐ見る |

避ける：
- 「こちら」「詳細」だけ（クリック理由が不明）
- 「お問い合わせ」だけのCTA（販促メールでは目的不明）

### CTA配置

| 位置 | 役割 |
|---|---|
| 1スクロール領域 | 第一CTA、即決層を捕まえる |
| 商品ブロック内 | 各商品ごとのCTA |
| 末尾 | 第二CTA、読了層を捕まえる |

### CTAボタンのデザイン

- 色：ブランドのアクセントカラー（青／赤／緑）
- サイズ：スマホでタップしやすい44px以上の高さ
- 余白：周囲に十分な空白
- 文言：簡潔に（最大15文字程度）

## 商品ブロックの設計

複数商品を並べる場合：

| 要素 | 内容 |
|---|---|
| 画像 | 商品メイン画像（正方形 or 4:5） |
| 商品名 | 2-3行で完結 |
| 価格 | 通常価格・セール価格・割引率 |
| 簡潔な訴求 | 「リネン100%」「軽量」「人気No.1（根拠明示）」 |
| CTA | [詳細を見る] [カートに入れる] |

3-5商品が読みやすい上限。それ以上は「全商品を見る」へ。

## 文字数の目安

| ブロック | 字数 |
|---|---|
| 挨拶＋導入 | 50-100字 |
| キャンペーン説明 | 100-200字 |
| 商品紹介（1商品） | 30-100字 |
| 本文全体 | 500-1,500字 |
| プレーンテキスト版 | 500-1,000字 |

長すぎる本文は読まれない。「何度かのスクロールで読み切れる」が目安。

## 「PS（追伸）」の効果

メール末尾のPSは、本文を読まず末尾だけ見る読者にもう一度フックを当てる。

例：
```
PS：このセールは8/3（日）23:59まで。クーポンコードは不要、自動で30%OFFが適用されます。
```

PSは1-2行で、本文で言ったオファーを再度想起させる。

## A/Bテストの設計

1メールにつき1要素ずつテスト：

| テスト要素 | 設計 |
|---|---|
| 件名 | パターンA／B を50/50で配信 |
| プリヘッダー | パターンA／B を50/50 |
| 配信時間 | 朝7時／昼12時 |
| CTAボタン文言 | 「商品を見る」／「30%OFFで見る」 |
| 第一CTA位置 | 1スクロール上／中段 |

複数同時テストは結果が交絡するので避ける。

## モバイル／デスクトップの違い

| 観点 | モバイル | デスクトップ |
|---|---|---|
| 表示幅 | 320-414px | 600-800px |
| 1スクロール | 約500px | 約800px |
| 1行の長さ | 短く | 長くてOK |
| 画像 | 軽量・スマホ最適化 | 高解像度可 |
| ボタンサイズ | 大きく（44px以上） | 通常サイズ |

モバイル優先（モバイルファースト）で設計し、デスクトップでは余裕を持つ。

## 読了率とエンゲージメント

| 指標 | 目安 |
|---|---|
| 開封率 | BtoC 15-25%、BtoB 20-30% |
| クリック率 | 2-5% |
| 開封後のスクロール率（測定可能なツールで） | 30-50% |
| 末尾までの読了率 | 10-20% |
| コンバージョン率 | 0.5-2%（業種・キャンペーンで大きく変動） |

これらを継続的に観測し、配信ごとに効果検証を行う。

## NG構成例

### NG例1：自己紹介で1スクロール埋まる
```
○○ オンラインストアです。いつも当店をご愛顧いただき誠にありがとうございます。
昨日は休日中にもかかわらず、多くのお客様にご来店いただきました。
スタッフ一同心より感謝申し上げます。
さて、本日は皆様にお得なお知らせがございます！
それは...
```
→ 結論まで遠すぎる。「○○様。本日18:30から夏物30%OFFセールがスタートしました。」と冒頭から結論。

### NG例2：CTAなし or 不明確
```
本日からセール開始です。ぜひお越しください。
```
→ どこに行けばよいか分からない。明確なリンクとボタンを置く。

### NG例3：複数テーマの混在
```
本日からセール開始＋新店オープン＋会員制度リニューアル＋ブログ更新
```
→ 1メール1テーマが原則。複数を1メールに詰めると全部読まれない。

## 配信頻度と読了率

| 頻度 | 読者の反応 |
|---|---|
| 月1-2回 | 期待感、開封率高 |
| 週1回 | 標準、関心維持 |
| 週2-3回 | 業種次第、ECは可能 |
| 週4回以上 | 解除率上昇のリスク |
| 毎日 | 緊密関係のあるブランドのみ |

過剰配信は解除率と迷惑メール扱いを誘発。月の配信回数を計画的に管理する。
