# 配信時間とセグメント設計

## 配信時間帯と開封率の関係

### 時間帯別の特徴

| 時間帯 | 特徴 | 開封率傾向 |
|---|---|---|
| 朝5:00-7:00 | 早朝、開封されにくい | 低 |
| 通勤7:00-9:00 | スマホ流し見、即決層に強い | 中〜高 |
| 朝9:00-11:00 | 仕事開始、メール埋もれやすい | 低〜中 |
| 昼11:00-13:00 | 昼休憩、開封率最高 | 高 |
| 午後13:00-17:00 | 仕事中、即時開封されにくい | 低 |
| 夕方17:00-19:00 | 帰宅前、移動中スマホ | 中 |
| 夜19:00-22:00 | 帰宅後、購買検討モード | 高 |
| 深夜22:00以降 | 翌朝には埋もれる | 低 |

### 業種別の最適配信時間

| 業種 | 推奨時間 |
|---|---|
| BtoC アパレル | 平日夜19-21時 ／ 休日10-12時 |
| BtoC 食品・日用品 | 平日朝7-9時 ／ 夕方17-19時 |
| BtoC コスメ | 平日昼12-13時 ／ 夜20-21時 |
| BtoB オフィス用品 | 平日朝10時 ／ 昼13時 |
| BtoB ITサービス | 平日昼12-14時 |
| BtoC 高単価品（家電・家具） | 休日午前 ／ 平日夜 |

これらは目安。自社の顧客データで実測検証する。

### 曜日別の傾向

| 曜日 | 特徴 |
|---|---|
| 月曜 | 週初め、メール溜まりやすい、競合と埋もれる |
| 火-木曜 | 標準、開封率安定 |
| 金曜 | 週末前、土日のお出かけ・買い物意欲喚起 |
| 土曜 | 朝はEC活発、夜はメール開封減 |
| 日曜 | 朝〜午前は購入検討、夕方は翌週準備 |

EC事業者の経験則：「金曜夕方」「日曜夜」がキャンペーン告知の鉄板。月曜午前は避ける傾向。

### A/Bテストでの実測検証

業種・客層で最適時間は異なるため、同じ内容を2つの時間帯で配信比較：

| テスト | 配信時間A | 配信時間B |
|---|---|---|
| パターン1 | 平日12:00 | 平日19:00 |
| パターン2 | 金曜18:00 | 日曜19:00 |
| パターン3 | 土曜10:00 | 平日昼12:00 |

開封率とクリック率を比較し、自社の最適時間を見つける。

## セグメント配信設計

### セグメントの設計軸

| 軸 | 例 |
|---|---|
| 購入履歴 | 直近30日／90日／半年／1年以内 |
| 累計購入金額 | 1万円以下／3万円／5万円／10万円超（VIP） |
| 購入カテゴリ | コスメ／アパレル／食品 等 |
| エンゲージメント | 過去メール開封者／クリック者 |
| 友だち追加経路 | 検索／広告／QR／キャンペーン |
| 性別／年代／地域 | 推定情報 |
| 会員ステージ | 一般／プラチナ／ダイヤモンド 等 |

### 主要セグメント別の配信設計

#### セグメント1：新規会員（登録〜2週間）
- 件名：「ご登録ありがとうございます／初回特典のご案内」
- 本文：自己紹介＋初回クーポン＋人気商品
- 頻度：登録直後＋3日後＋7日後＋14日後（ステップ）

#### セグメント2：直近購入者（〜30日）
- 件名：「ご注文ありがとうございました／関連商品のご案内」
- 本文：購入商品の関連・使い方ガイド・レビュー依頼（規約内）
- 頻度：購入後2-3日、7日、30日

#### セグメント3：定期購入者（リピート顧客）
- 件名：「次回お届けまであと[X]日／追加注文のご案内」
- 本文：次回お届け予定の確認＋他商品の提案
- 頻度：次回お届け予定の1週間前

#### セグメント4：休眠顧客（3-6ヶ月未購入）
- 件名：「お久しぶりです／復活クーポンのご案内」
- 本文：復活特典＋新商品＋ブランド近況
- 頻度：月1-2回（過剰配信は解除誘発）

#### セグメント5：VIP顧客（累計購入額5万円超）
- 件名：「VIP限定先行販売／特別招待」
- 本文：先行販売・限定品・パーソナル提案
- 頻度：月1回程度（特別感を保つ）

#### セグメント6：カート放棄者
- 件名：「カートに残っている商品があります」
- 本文：放棄したカートのリマインド＋数量限定特典
- 頻度：放棄から24時間後、72時間後、1週間後

### セグメント効果の計測

| セグメント | 期待される効果 |
|---|---|
| 新規ステップ | 初回購入率の向上 |
| 関連商品 | クロスセル金額の向上 |
| 休眠復活 | 復活率（特定期間内の再購入） |
| VIP | ロイヤルティ向上、解除率低下 |
| カート放棄 | カート復帰率、CV金額 |

全配信より絞り込み配信のほうが開封率・クリック率が高くなる傾向。

## セグメント配信の運用負荷

セグメントの数だけ運用工数が増える。現実的な上限：

- 小規模：3-5セグメント
- 中規模：5-10セグメント
- 大規模：10-20セグメント

それ以上はマーケティングオートメーション（MA）ツールで自動化する。

## マーケティングオートメーション連携

ECの主要MA／配信ツール：

- Mailchimp
- SendGrid（API中心）
- Klaviyo（Shopify連携強い）
- futureshop メルマガ機能
- 楽天市場メールマガジン
- HubSpot
- Salesforce Marketing Cloud
- Repro

各ツールでセグメント機能・ステップ配信・効果測定の仕様が異なる。導入時に各ツールのドキュメントを確認。

## 配信頻度の月次計画例

中規模EC（友だち10,000人）の月次配信計画例：

| 週 | 配信内容 | セグメント |
|---|---|---|
| 第1週 火 | 月初のテーマ紹介 | 全配信 |
| 第1週 金 | 新作入荷 | 直近購入者＋休眠 |
| 第2週 火 | ブログ更新告知 | 全配信 |
| 第2週 金 | セール告知（中盤） | 全配信 |
| 第3週 火 | ステップ配信（自動） | 新規 |
| 第3週 金 | 関連商品提案 | 直近購入者 |
| 第4週 火 | 月末セール告知 | 全配信＋休眠 |
| 第4週 金 | VIP限定 | VIP |

月8配信、平均週2回、セグメント別の運用負荷を分散。

## 配信解除の運用

特定電子メール法に基づき、配信解除リンクの明示は必須。

- 解除リンクは末尾に明示
- ワンクリックで解除可能（複雑な手続き不要）
- 解除後の確認メールは不要（即時反映）
- 解除理由を任意で聞く（運用改善のヒント）

解除率の目安：
- 1配信あたり 0.1-0.5%：健全
- 0.5-1%：注意
- 1%超：内容・頻度の見直し
- 2%超：配信戦略を変更

## 災害・社会情勢時の配信判断

- 大規模災害・感染症拡大時は販促配信を一時停止
- お見舞いメッセージ・状況説明に切り替える
- 該当地域のみセグメントで配信停止
- 配信再開時は配慮した文面（突然のセール訴求は反感）

## まとめ：時間×セグメントの最適化

1. 業種に応じた基本時間帯を選ぶ
2. A/Bテストで自社の最適時間を発見
3. 5-10のセグメントを設計
4. 月次配信計画を立て、過剰配信を避ける
5. 効果測定（開封率・クリック率・解除率）を継続観測
6. 解除率1%超でアラート、配信戦略を見直す
