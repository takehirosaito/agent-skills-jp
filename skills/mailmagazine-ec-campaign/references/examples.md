## 共通：各実例の配信前チェック

各実例で確認すべき項目：

- [ ] 件名30字以内、フックあり
- [ ] プリヘッダー70字以内、件名と重複なし
- [ ] 1スクロール領域に結論・第一CTA
- [ ] CTA中段・末尾の2箇所配置
- [ ] リンク先有効
- [ ] 法務確認（薬機法・景表法・特商法）
- [ ] BIMI/DKIM/DMARC設定
- [ ] ダークモード対応色指定
- [ ] 画像オフ時のalt
- [ ] テキスト版併送
- [ ] 配信解除リンク明示
- [ ] セグメント設定
- [ ] 配信時間（推奨帯）
- [ ] 通数試算
- [ ] A/Bテスト案（件名／配信時間）

## A/Bテスト設計例

各実例で実施できるA/Bテスト：

| 例 | A/Bテスト対象 | パターンA | パターンB |
|---|---|---|---|
| 例1 | 件名 | 【3日限定】夏物ALL30%OFFスタート | 残り3日、夏物の見直しチャンス |
| 例2 | プリヘッダー | 有効期限14日、3,000円以上のお買い物... | 初めての方限定、人気No.1のお試しセット紹介 |
| 例3 | 配信時間 | 木曜21:00 | 土曜10:00 |
| 例4 | CTA文言 | セール商品を見る | 10%OFFで購入する |
| 例5 | プリヘッダー | 次回お届け日：YYYY/MM/DD... | 内容変更は5日前まで、お忘れなく |
| 例6 | 件名 | 【法人様限定】新製品サンプル無料... | サンプル無料発送、ご導入検討の方へ |
```
