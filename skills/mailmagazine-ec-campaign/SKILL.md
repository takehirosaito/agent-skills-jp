# ECメルマガキャンペーン設計

## 概要

EC事業者のメルマガキャンペーン全体を設計するスキル。件名・プリヘッダー・本文構成・商品導線・セグメント設計・配信時間・到達率対策を一貫して扱う。

メルマガは「配信ボリュームと到達率の両立」「迷惑メール扱いの回避」「セグメント絞り込みでの効果最大化」の3点が成否を決める。BIMI/DKIM/DMARC等のドメイン認証、Gmail/Yahoo!の2024年新ガイドライン、特定電子メール法の遵守を前提に設計する。

## ★最重要原則

**「1スクロール領域で結論・第一CTAを出し切る」**。
スマホでメールを開いた瞬間の400-500px（コンテンツ部分）に「短い挨拶＋キャンペーン結論（何が・いくら・いつまで）＋第一CTA」を必ず配置。長い前置きや自己紹介で1スクロールを埋め尽くしてはならない。

## 知識ベース（要点 + references/）

### 本文の標準構成

```
[ヘッダー（ロゴ・ナビ）]
[1スクロール領域：通知文・オファー・第一CTA]
[商品紹介（複数）]
[第二CTA]
[セカンダリ情報（ブログ・SNS・お知らせ）]
[フッター：会社情報・特商法表示・配信解除]
```

3パターン：A. 商品オファー型（セール告知）／B. 教育・コンテンツ型（ブランディング）／C. ステップ配信型（新規教育）。詳細：`references/structure-and-fold.md`

### 件名・プリヘッダー設計

| 要素 | 字数目安 | 役割 |
|---|---|---|
| 件名 | 30字以内 | 開封理由を提示 |
| プリヘッダー | 70字以内 | 件名の補足、件名と重複させない |
| 通知文（モバイル受信トレイ表示） | 件名＋プリヘッダー合計100字以内 | 開封判断 |

件名は「期限性＋ベネフィット」の組み合わせ。「【3日間限定】夏物ALL30%OFFスタート」のように具体数値とフックを入れる。10案出して上位を採用するのが定石。

### 到達率（BIMI／DKIM／DMARC・2024年Gmail/Yahoo!ガイドライン）

| 認証 | 役割 |
|---|---|
| SPF | 送信元IPの正当性 |
| DKIM | 本文改ざん検出の電子署名 |
| DMARC | SPF/DKIM失敗時の処理ポリシー（none/quarantine/reject） |
| BIMI | 認証済みメールにブランドロゴ表示（VMC証明書必要） |

**2024年〜のGmail/Yahoo!新ガイドライン（日次5,000通超送信者は必須）**：
1. SPF・DKIM 認証通過
2. DMARC ポリシー（p=none以上）の設定
3. 送信元ドメインのPTRレコード設定
4. `List-Unsubscribe`ヘッダに1クリック解除リンク
5. 苦情率0.3%以下を維持

詳細：`references/deliverability.md`

### セグメント設計

| セグメント | 件名指針 | 頻度 |
|---|---|---|
| 新規会員（登録〜2週間） | 「ご登録ありがとうございます／初回特典のご案内」 | 登録直後＋3日後＋7日後＋14日後（ステップ） |
| 直近購入者（〜30日） | 「ご注文ありがとうございました／関連商品のご案内」 | 購入後2-3日、7日、30日 |
| 定期購入者 | 「次回お届けまであと[X]日／追加注文のご案内」 | 次回お届け予定の1週間前 |
| 休眠（3-6ヶ月未購入） | 「お久しぶりです／復活クーポンのご案内」 | 月1-2回 |
| VIP（累計5万円超） | 「VIP限定先行販売／特別招待」 | 月1回程度 |
| カート放棄 | 「カートに残っている商品があります」 | 放棄から24h／72h／1週間後 |

詳細：`references/timing-segment.md`

### 配信時間帯（業種別目安）

| 業種 | 推奨時間 |
|---|---|
| BtoC アパレル | 平日夜19-21時／休日10-12時 |
| BtoC 食品・日用品 | 平日朝7-9時／夕方17-19時 |
| BtoC コスメ | 平日昼12-13時／夜20-21時 |
| BtoB オフィス用品 | 平日朝10時／昼13時 |
| BtoC 高単価（家電・家具） | 休日午前／平日夜 |

EC事業者の経験則として「金曜夕方」「日曜夜」がキャンペーン告知の鉄板、月曜午前は避ける傾向。自社実測でA/Bテスト検証。

### HTMLメール設計（モバイル・ダークモード・画像オフ）

- メイン幅 600px、テーブルレイアウト、インラインCSS
- viewport設定、`x-apple-disable-message-reformatting`、`color-scheme: light dark`
- alt属性で画像オフ時も意味が通る
- bulletproof button（画像なしでも見えるボタン）
- プレーンテキスト版を必ず同送
- HTML本文50KB以下、画像合計300KB以下

詳細：`references/html-design.md`

## 処理フロー

### Step 1：配信目的・ターゲット・キャンペーン内容を確定
1メール1テーマが原則。複数テーマを詰め込まない。

### Step 2：セグメントを設計
新規・既存・定期・休眠・VIP・カート放棄 のどれか。中規模ECで5-10セグメントが現実的な上限。

### Step 3：件名10案・プリヘッダーを作成
件名：30字以内、期限性＋ベネフィット。プリヘッダー：70字以内、件名と重複させない。

### Step 4：本文構成（1スクロール領域→商品ブロック→フッター）
1スクロール内に「挨拶＋キャンペーン結論＋第一CTA」を必ず収める。中段に第二CTA、末尾にPSで再フック。

### Step 5：HTML設計とプレーンテキスト版
モバイル幅対応、ダークモード対応色、画像オフ時のalt、bulletproof button。プレーンテキスト版を同送。

### Step 6：配信時間・到達率対策
業種別の推奨時間帯、SPF/DKIM/DMARC設定確認、`List-Unsubscribe`対応、配信解除リンク明示、送信者情報（特定電子メール法に基づき会社名・所在地・連絡先必須）。

### Step 7：A/Bテストの設計
1配信1要素ずつテスト。件名／プリヘッダー／配信時間／CTA文言／第一CTA位置 のどれか。

入力情報が不足する場合は冒頭に「仮定」「追加確認」を分けて明示。

## 品質ゲート

- 件名と本文の期待値が一致している（件名で煽って本文がショボくない）
- 1スクロール領域に結論・第一CTAが入っている
- 「いつも誠にありがとうございます」段落で1スクロールを埋め尽くしていない
- 1メール1テーマ（複数オファー混在で焦点分散していない）
- 過剰煽り表現（「絶対」「保証」「完全」「No.1」「最安」「!!!」連発）がない
- 化粧品：効能効果は薬機法56効能の範囲内
- 健康食品：トクホ・機能性表示・栄養機能・一般食品のカテゴリで表現範囲を守る
- 配信解除リンクが明示されている（特定電子メール法）
- 送信者情報（会社名・所在地・連絡先）が記載されている
- 画像のみで構成されていない（テキストとのバランス）
- 短縮URL（bit.ly等）を多用していない（迷惑メール判定要因）

## エッジケース

- **日次5,000通超の大量配信を始める前**：SPF/DKIM/DMARC設定とPTRレコード、`List-Unsubscribe`対応を完了させてから段階的にボリューム増加（IPウォームアップ）
- **苦情率0.3%超**：直近キャンペーン内容見直し、解除リンク改善、配信頻度ダウン、セグメント絞り込み強化
- **バウンス率5%超**：ハードバウンス（存在しないアドレス）を即時除外、リスト鮮度向上
- **災害・社会情勢時**：販促配信を一時停止、お見舞いメッセージに切り替え、配信再開時は配慮した文面
- **楽天市場メルマガ・futureshopメルマガ**：モール／カートの独自仕様（テンプレート・パラメータ・タグ）に従う必要があり、本スキルでは全体設計まで。各モール固有の入稿は別スキル

## 注意事項

- 仕様（Gmail/Yahoo!ガイドライン・LINE料金体系等）は変動する。導入時に各サービス公式ヘルプで最新確認
- 特定電子メール法：オプトイン取得済みリストにのみ配信、配信解除後の再送は禁止、違反は措置命令・罰金（最大3,000万円）
- BIMI導入はVMC証明書が年間3-5万円〜必要、商標登録ロゴが前提
- 配信プラットフォームごとに認証・レピュテーション管理の仕様が異なる（Klaviyo・SendGrid・Mailchimp・futureshop・楽天等）
- 「No.1」「最安」表記は調査主体・期間・対象・方法・出典の明示が必要（景表法）
