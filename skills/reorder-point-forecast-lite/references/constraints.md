# 発注の制約条件

## ロット制約

### 最小発注単位（MOQ：Minimum Order Quantity）
仕入先・製造元が定める1回の最低発注数。

- 大手メーカー：5〜10個（小売向け）
- 中堅メーカー：12〜30個
- 海外OEM：100〜1000個（コンテナ単位等）
- 自社製造：製造ロット50〜500個

### ロットサイズ
発注は「ロット倍数」でしか受け付けないケース：
- 10個ロット → 10、20、30、40...
- 50個ロット → 50、100、150...

計算上の発注量はロット単位に切り上げ：
```
最終発注量 = max(計算量, MOQ) を ロット単位に切り上げ
```

例：計算上109個、MOQ50、ロット50
→ 切り上げ150個

### ロット割引
発注量が多いほど単価が下がる：
- 100個未満：100円／個
- 100〜499個：90円／個
- 500個以上：80円／個

この場合、EOQ計算では平均単価が変わるためロット別に検算。

## 賞味期限制約

### 賞味期限と発注量上限
```
発注量上限 = (賞味期限日数 − リードタイム − 流通在庫期間) × 平均日販
```

例：賞味期限180日、LT30日、流通在庫30日、平均日販2個
→ 発注量上限 = (180 − 30 − 30) × 2 = **240個**

これ以上発注すると、消費者に届く時点で賞味期限残が短く、クレーム多発のリスク。

### 1/3ルール（食品業界）
日本の食品流通では「賞味期限の1/3ルール」が慣行：
- 製造から賞味期限まで180日
- 製造から1/3（60日）以内に小売へ納品
- 賞味期限残2/3（120日）残して納品

この慣行により、発注タイミングが厳しい。

### 化粧品の使用期限
- 未開封：製造から3年（薬機法）
- 開封後：3〜6ヶ月（自社判断）

製造日表示・使用期限表示の有無で消費者の受容性が変わる。

## 倉庫スペース制約

### 保管可能容量
- パレット数・棚数の上限
- 季節商品の入れ替え時期に圧迫
- 過剰発注で倉庫費が急増

### 保管コスト
```
1個・年保管費 = (年間倉庫費) ÷ (年間平均在庫数)
```

例：年間倉庫費240万円、平均在庫1,000個
→ 1個・年保管費 = 2,400円／個・年

これがEOQ計算の「在庫保管費単価」に入る。

## キャッシュフロー制約

### 発注金額の上限
- 月間の仕入予算が固定されている
- 大口発注ができない場合は分割発注

### 支払サイト
- 仕入：月末締め翌月末払い／翌々月10日払い 等
- 売上：モール入金は月2回など
- キャッシュ・コンバージョン・サイクル（CCC）の管理

## 仕入先の発注制約

### 発注締切
- 「毎週月曜12時締切、翌週金曜入荷」のような曜日サイクル
- 締切を逃すと1週間遅延

### 仕入先の休業
- 旧正月（中国）：1〜2月で2〜3週間休業（OEM・海外仕入で影響大）
- 年末年始（日本）：12月末〜1月初
- お盆休み：8月中旬

### 仕入先のリードタイム変動
- 通常時LT7日 → 繁忙期LT14日 等
- 仕入先の在庫状況・製造状況による

### 仕入先のキャパシティ
- 一度に大量発注しても入荷が分割される場合
- 「毎月100個まで」のような月別上限

## モール固有の制約

### Amazon FBA 保管制限
- 古い在庫の保管手数料が割高
- 長期在庫保管手数料（半年・1年経過）

### 倉庫間移動コスト
- 自社倉庫からFBA倉庫へ送る配送料
- 楽天スーパーロジスティクスへの移動費用

## 受注ロット・梱包制約

### 同梱対応
- 複数商品を1配送で送る場合のサイズ制約
- 宅配便60〜200サイズの境界に注意

### 発注時の単位 vs 販売時の単位
- 仕入：12個入りカートン
- 販売：1個ずつバラ売り
- 在庫管理：12個でも1個でもカウントする必要

## 法令・規制の制約

### 医薬部外品・医療機器
- 薬機法上の許認可必須
- 製造販売業者・販売業者の許可がない仕入は不可

### 食品衛生法
- 食品衛生責任者の届出
- アレルゲン表示・原産国表示

### 輸入規制
- 化粧品：薬機法
- 食品：食品衛生法、植物検疫
- 医薬部外品：薬機法上の輸入届出

## 制約をすべて反映した発注量

```
最終発注量 = min(
    max(計算上の発注量, MOQ),
    賞味期限制約,
    倉庫スペース制約,
    キャッシュ制約,
    仕入先キャパ制約
) をロット単位に切り上げ
```

例：
- 計算上：109個
- MOQ：50個
- 賞味期限制約：300個
- 倉庫スペース：200個
- ロット：50単位

→ 最終発注量：150個（MOQ以上、賞味期限内、倉庫内、ロット切り上げ）

## 制約緩和の交渉

### MOQ引き下げ交渉
- 試験的に少ロット仕入の交渉
- 段階的に発注量を増やす条件

### リードタイム短縮交渉
- 「定期発注」の確約と引き換えに短縮
- 在庫を仕入先に持たせる契約

### 賞味期限延長交渉
- 「製造直後の商品をください」と指定

### ロット割引交渉
- 年間総量で割引条件
- 競合品のロット割引情報を提示

## 制約管理の運用ルール

1. **MOQ・ロット・賞味期限を商品マスタに保持**
2. **仕入先カレンダー（発注締切・休業日）をシステム化**
3. **倉庫スペース監視**（月次で容量確認）
4. **キャッシュフロー連動**（仕入予算を月次レビュー）
5. **トラブル時のリスト**（メーカー欠品・LT延長時の代替仕入先）
