# LPワイヤーフレーム標準テンプレート

3種類のLPタイプ別に、ワイヤーフレームと推奨セクション順を示す。

---

## テンプレート1：単発購入LP（標準型）

### 適用
- 1回限り購入の化粧品・家電・アパレル・食品
- 定期購入ではない通常の商品ページの拡張版

### 構成（縦並び）

```
[1] FV
  ├─ ターゲット呼びかけ（10字）
  ├─ 主見出し（30字）
  ├─ サブコピー（60字）
  ├─ メイン画像
  ├─ オファー帯（「初回30%OFF」等）
  ├─ CTA①（購入ボタン）
  └─ 信頼マーク（受賞／レビュー★／返金保証ロゴ）

[2] 共感
  ├─ ターゲットの悩み3つ
  └─ 共感画像（人物）

[3] 解決
  ├─ 商品が解決する仕組み
  ├─ 成分／技術／素材の図解
  └─ CTA②

[4] 証拠
  ├─ 受賞歴
  ├─ メディア露出
  ├─ レビュー抜粋（写真付き3-5件）
  └─ ★平均と件数

[5] 比較
  ├─ 比較表（自社 vs 他社A vs 他社B）
  └─ 客観的事実のみ

[6] 使用方法
  ├─ 3-5ステップで図解
  └─ 注意事項

[7] FAQ
  ├─ Q1: 敏感肌でも使える？
  ├─ Q2: いつ届く？
  ├─ Q3: 返品できる？
  ├─ Q4: 子供にも使える？
  └─ Q5: 他の商品と併用できる？

[8] オファー
  ├─ 価格／送料
  ├─ 特典（プレゼント・サンプル）
  ├─ 保証（30日返金）
  └─ 在庫・期限

[9] CTA③（最終）
  ├─ 大型CTAボタン
  └─ オファーリマインダー

[10] 特商法表記（フッター）
```

## テンプレート2：定期購入LP

### 適用
- サプリ／化粧品／日用品の定期コース

### 構成

```
[1] FV
  ├─ 主見出し（30字）
  ├─ 定期コースの核オファー：「初回○%OFF・いつでも解約可・最低回数なし」を明示
  ├─ メイン画像
  ├─ CTA①
  └─ 信頼マーク

[2] 共感

[3] 解決

[4] 証拠（レビュー・受賞・成分・科学的根拠）

[5] 続けることの価値
  ├─ 効果実感までの期間（例：3ヶ月）
  └─ 続けた人の声

[6] 比較
  ├─ 単品購入 vs 定期コースの価格比較表
  └─ 他社定期 vs 自社定期の比較

[7] FAQ（特に解約・配送頻度を厚く）
  ├─ Q1: いつでも解約できる？
  ├─ Q2: 配送頻度は変更できる？
  ├─ Q3: 最低継続回数はある？
  ├─ Q4: 解約方法は？
  ├─ Q5: 休止できる？
  └─ Q6: お届け日は変更できる？

[8] オファー
  ├─ 初回価格
  ├─ 2回目以降価格
  ├─ 送料
  ├─ 解約条件
  ├─ 配送頻度
  └─ 特典

[9] CTA②（定期申込）
  └─ 必ず確認画面で最終確認画面6項目を表示

[10] 特商法 最終確認画面6項目
  ├─ 分量（個数・回数・期間）
  ├─ 販売価格・支払総額
  ├─ 支払時期・方法
  ├─ 引渡時期
  ├─ 申込撤回・解除条件
  └─ 申込期間制限

[11] 特商法表記（フッター）
```

### 定期購入LPの重要ルール（2022.6改正）
- 最終確認画面6項目を**明瞭に**（小さい文字・グレー文字・スクロール隠しNG）
- 解約条件は**最終確認画面とFV近傍の両方**で明示
- 「いつでも解約可」と書いたら**実運用と一致させる**（最低回数縛りがあれば有利誤認）
- 「お試し」「初回限定」と書いたら**それが定期コースの一部であることを明示**
- 違反は3年以下懲役・300万円以下罰金（直罰）

## テンプレート3：季節キャンペーンLP

### 適用
- 母の日・父の日・お中元・お歳暮・敬老の日・バレンタイン・ホワイトデー・クリスマス

### 構成

```
[1] FV
  ├─ イベント名（「母の日」「お中元」）
  ├─ 配送締切日（「5月8日まで／6月15日まで」）
  ├─ メイン画像（季節感のあるパッケージ）
  ├─ CTA①
  └─ ギフト対応マーク（のし・包装・カード）

[2] 贈る相手別おすすめ
  ├─ 「お母さん向け」
  ├─ 「お義母さん向け」
  └─ 「祖母向け」

[3] 商品ラインアップ
  ├─ 価格帯別（3,000円台／5,000円台／10,000円台）
  └─ 商品グリッド

[4] ギフト対応
  ├─ のし（用途別の表書き例）
  ├─ ラッピング
  ├─ メッセージカード
  ├─ 配送日指定
  └─ 送り先住所複数対応

[5] 配送スケジュール
  ├─ 注文締切：○月○日
  ├─ 発送：○月○日〜
  └─ お届け：○月○日まで

[6] FAQ
  ├─ Q1: 何日までに注文すれば間に合う？
  ├─ Q2: 送り先を複数指定できる？
  ├─ Q3: のしの表書きは？
  ├─ Q4: 賞味期限は？
  └─ Q5: アレルゲンは？

[7] 商品詳細（各SKU）

[8] CTA②（最終）

[9] 特商法表記
```

### 季節キャンペーンLPの注意
- **配送締切は最大限目立たせる**（FV／CTA上／FAQの3箇所最低）
- イベント終了後（5月11日／6月19日等）は速やかに広告・LPを停止または通常版に切り替え
- 配送遅延の警告：物流ピーク時の遅延可能性
- 食品ギフトは**特定原材料8品目アレルゲン表示**必須

## FV（ファーストビュー）の必須4要素

どのテンプレートでもFVに必ず含める：

| 要素 | 内容 | 例 |
|---|---|---|
| Who（誰向け） | ターゲットの明示 | 「30代乾燥肌の方へ」 |
| What（何が） | 商品の核 | 「単一農園素材の保湿化粧水」 |
| Why now（なぜ今） | オファー／限定性／保証 | 「初回30%OFF・30日返金保証」 |
| Action（行動） | CTAボタン | 「今すぐ初回30%OFFで始める」 |

### スマホFV設計
- スマホで縦480pxに収まる情報量
- 主見出し1行（30字以内）
- CTAは親指で押せる大きさ（最低48px高さ）
- 重要情報はテキストで（画像内テキストはOGP・SEO・読み上げで読まれない）

---

## CTAの推奨配置（3箇所最低）

1. **FV直下**：認知直後の即決層
2. **証拠セクション直後**：信頼が高まった瞬間
3. **オファーセクション直後／LP末尾**：全情報を見た最終判断層

各CTAの**直上**には「今買うべき理由」リマインダー：
- 「初回30%OFF・30日返金保証・送料無料」
- 「本日23:59まで100名限定」

## モバイルとPCでのレイアウト分岐

| 要素 | モバイル | PC |
|---|---|---|
| FV見出し | 1行30字 | 2行60字可 |
| 比較表 | 縦並び or 横スクロール | 横並び |
| FAQ | アコーディオン | 全展開 or アコーディオン |
| CTA | 親指で押せる大きさ | マウスホバー前提 |
| 画像 | 縦長優先 | 横長OK |

モバイル経由が70-80%なので、**モバイルファースト**で設計する。
