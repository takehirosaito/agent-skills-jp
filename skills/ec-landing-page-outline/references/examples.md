## 例1：保湿化粧水 単発購入LP

### 前提
- 商品：保湿化粧水120ml 3,200円
- 流入広告：Meta「乾燥肌の30代へ・初回30%OFF」
- ターゲット：30-40代乾燥肌女性

### FV
- 主見出し：「朝のカサつきに、単一農園素材の保湿化粧水」
- サブコピー：「初回30%OFF・30日返金保証・送料無料」
- 画像：商品＋朝の窓辺の光＋オファー帯
- CTA：「今すぐ初回30%OFFで始める」

### 構成
| # | 見出し |
|---|---|
| 共感 | 「30代を過ぎて、いつもの化粧水で物足りなさを感じる日が増えていませんか」 |
| 解決 | 「単一農園で栽培した○○エキスで肌のうるおいを保つ」 |
| 証拠 | 「2024年ベストコスメ受賞／★4.6 / 1,200件レビュー」 |
| 比較 | 「他社化粧水との保湿成分配合量・原料比較表」 |
| 使用方法 | 「朝晩、500円玉サイズを優しくなじませる」 |
| FAQ | 敏感肌／配送／返金／併用 |
| オファー | 「初回30%OFF・30日返金保証・送料無料」 |
| CTA | 「今すぐ初回30%OFFで始める」 |

### 法務チェック
- 「保湿」「うるおいを保つ」：化粧品56項目内 OK
- 「30%OFF」二重価格：通常価格3,200円でセール開始前8週間中4週間以上の実販売
- ベストコスメ：正式名称・年・カテゴリ明示
- 「皮膚科医推薦」未使用 OK

## 例2：機能性表示食品 定期購入LP

### 前提

- 初回1,980円／2回目以降4,500円／月1回・解約まで継続

- サブコピー：「葛の花由来イソフラボンが脂肪を減らすのを助ける／届出番号A123／初回70%OFF・いつでも解約可」
- 画像：商品＋成分名帯＋届出番号
- CTA：「初回70%OFFで始める（定期コース）」

### 構成
| # | 見出し |
|---|---|
| 共感 | 「健康診断で内臓脂肪を指摘されていませんか」 |
| 解決 | 「葛の花由来イソフラボン35mg配合（機能性関与成分）」 |
| 証拠 | 「届出番号A123／届出文言の根拠論文／★4.5 / 5,400件」 |
| 続ける価値 | 「3ヶ月続けた人の腹囲推移グラフ（届出論文より）」 |
| 比較 | 「単品 vs 定期コースの価格比較表」 |

- 最終確認画面6項目を明瞭に
- 「内臓脂肪が消える」「○kg痩せる」NG（届出文言外）

## 例4：母の日ギフトスイーツ 季節キャンペーンLP

### 前提
- 商品：バスクチーズケーキ4号 4,800円
- 配信期間：4月15日〜5月10日
- 配送締切：5月8日まで

### FV
- 主見出し：「母の日、5月8日までお届け／職人手作りバスクチーズケーキ」
- サブコピー：「のし／メッセージカード／母の日限定包装／送料無料」
- 画像：商品＋カーネーション＋メッセージカード
- CTA：「母の日に届ける（5月8日までお届け）」

### 構成
| # | 見出し |
|---|---|
| 贈る相手別 | お母さん／お義母さん／祖母 別おすすめ |
| 商品ラインアップ | 4号／5号／6号＋ドリンクセット |
| ギフト対応 | のし・包装・メッセージカード・送り先複数 |
| 配送スケジュール | 5月1日まで＝5月3日着／5月8日まで＝5月10日着 |
| FAQ | 配送締切／賞味期限／アレルゲン／送り先複数 |
| 商品詳細 | 原材料・賞味期限・アレルゲン（卵・乳・小麦） |
| CTA | 「5月8日までお届け」リマインダー付き |

### 法務チェック
- 特定原材料8品目（卵・乳・小麦）を**LPと商品ページ**で明示
- 賞味期限：商品到着後○日以内
- 「日本一」「No.1」未使用
- 「美味しさ100%保証」未使用
- 配送遅延の可能性：物流ピーク時に注意書き

### イベント後の対応
- 5月11日以降：広告・LP停止／コピーから「母の日」表記を削除
- 残在庫があれば「通常販売」に切り替え
