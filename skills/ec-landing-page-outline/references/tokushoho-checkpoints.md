# 特商法 通販必須記載・最終確認画面 チェック

LPと特商法ページに必要な記載事項。違反は重い処分につながるので、構成段階で組み込む。

---

## 特商法 通販必須記載13項目

通販の広告（LP・商品ページ・カタログ）で、以下を**漏れなく明示**する必要がある（特定商取引法11条）。

| # | 項目 | 補足 |
|---|---|---|
| 1 | 販売価格 | 税込で表示。送料を含む総額が望ましい |
| 2 | 送料 | 地域別・サイズ別に明示。送料無料ラインも |
| 3 | 支払時期・方法 | 後払い／前払い／代引き／クレジット |
| 4 | 引渡時期 | 「注文確認後○営業日以内発送」など具体的に |
| 5 | 申込撤回・解除（返品特約） | 返品可否／期間／送料負担 |
| 6 | 事業者氏名・住所・電話番号 | 法人なら登記情報、個人なら本名 |
| 7 | 責任者氏名 | 代表者または運営責任者 |
| 8 | 申込有効期限 | 申込から何日以内の発送 |
| 9 | 価格以外の負担 | 振込手数料・代引手数料など |
| 10 | 隠れた瑕疵責任 | 返品・交換・補修の条件 |
| 11 | ソフトウェア動作環境 | デジタルコンテンツの場合 |
| 12 | 定期購入条件（2回以上） | 詳細は下記 |
| 13 | 数量制限等 | 「お一人様1点まで」など |

## 特商法 最終確認画面6項目（2022.6改正）

定期購入・サブスクの**注文最終確認画面**で必須。違反は**3年以下懲役・300万円以下罰金（直罰）**。

| # | 項目 | 注意点 |
|---|---|---|
| 1 | 分量（個数・回数・期間） | 「30ml×月1回・解約まで継続」など具体的に |
| 2 | 販売価格・支払総額 | 初回／2回目以降の各価格と支払総額 |
| 3 | 支払時期・方法 | クレジット・代引き等 |
| 4 | 引渡時期 | 発送タイミング |
| 5 | 申込撤回・解除条件 | 解約方法・期限・連絡先 |
| 6 | 申込期間制限 | キャンペーン期間・在庫制限 |

### 「明瞭に」表示すること
- 小さい文字／グレー文字／背景同化色／スクロール隠し はNG
- 主要情報と同等のフォントサイズ
- ボタンの「申し込む」直近に表示

## 定期購入の「ダークパターン」回避チェック

以下は2022年改正以降の典型違反パターン：

| パターン | 違反 | 対応 |
|---|---|---|
| 「初回限定半額」と大書きし、定期コースであることを小さく書く | 定期コース明示義務違反 | FV／カート上で定期であることを明示 |
| 「いつでも解約OK」と書きながら最低継続回数縛り | 有利誤認・解約条件違反 | 最低回数を明示するか、本当にいつでも解約可にする |
| 解約には電話のみ受付・電話がつながらない | 不当な解約妨害 | メール・フォーム・マイページで解約可に |
| 解約締切が「次回発送日の20日前」と異常に厳しい | 不当な解約妨害 | 業界標準は次回発送日10日前まで |
| 2回目以降価格が初回の3倍以上 | 有利誤認 | 価格差を明示・1人1回オファーを徹底 |
| 「お試し」と書きながら継続購入になる | 定期コース明示義務違反 | 「お試し（定期コース初回）」など正確に |

## 二重価格表示 8週間ルール

「通常価格○○円→今だけ○○円」のような二重価格を表示する場合：

- セール開始**直前8週間**のうち、**過半（4週間以上）**でその通常価格で**実販売**されていた事実が必要
- 「メーカー希望小売価格」を併記する場合、その価格が実在し市場で実態のあるものであること
- 「○○%OFF」表示も上記ルール準拠

### NG例
- 常にセールしているのに「通常価格」併記 → 有利誤認
- セール開始前1週間しか通常価格で売っていない → 8週間ルール違反

## No.1表記の4要件＋必須明示

「楽天1位」「○○ランキング1位」「業界No.1」を使う場合：

### 4要件
1. 比較する商品等が適切に選定
2. 調査対象者が適切に選定
3. 調査が公平な方法で実施
4. 表示内容と調査結果が適切に対応

### 必須明示5項目
- **調査主体**：誰が調査したか
- **調査期間**：いつの調査か
- **調査対象**：誰／どの商品が対象か
- **調査方法**：どう調べたか
- **出典**：データの公開先・引用元

### 例
- NG：「業界No.1」（単独表記）
- OK：「○○調べ 2024年4月 全国の20-60代女性1,000名対象 楽天市場保湿化粧水部門 売上ランキング1位」

## 打消し表示7原則

「※個人の感想です」「※効果には個人差があります」のような打消し表示は、以下を満たさなければ機能しない：

1. **文字の大きさ**：本文と同等
2. **表示位置**：主要表示の近傍
3. **表示時間**：動画の場合は十分な秒数
4. **背景との対比**：色・コントラストで視認可
5. **表示エリア**：見えるエリア内
6. **視認しやすさ**：他の情報に埋もれない
7. **重要な情報からの距離**：主要表示と離れすぎない

### NG例
- メインコピーが大きく、打消しが極小グレー → 機能せず違反扱い
- 動画末尾に0.5秒だけ表示 → 視認不可
