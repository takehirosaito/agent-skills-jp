# ネクストエンジン 商品マスタ 主要項目

以下は2025-2026年時点で確認されている主要項目。**最新仕様はネクストエンジン公式ヘルプで確認**すること。

## 必須・基本項目

| 項目名（API/CSV） | 内容 | 主な制約 |
|---|---|---|
| goods_id | 商品コード（マスタの主キー） | 30字以内、半角英数・一部記号 |
| goods_name | 商品名 | — |
| daihyou_shouhin_code | 代表商品コード（セット商品の親） | goods_idへの参照 |
| stock_goods_id | 在庫管理コード（在庫減算元） | goods_idへの参照 |
| zaiko_su | 在庫数 | **加減算方式**（CSV上書きNG） |
| visible_flg | 公開フラグ | 0=非公開, 1=公開 |
| supplier_code | 仕入先コード | — |
| category | カテゴリ | — |

## CSV書き出し時の標準形式

- 文字コード：Shift_JIS(CP932)
- 改行：CR+LF
- 区切り：カンマ
- ヘッダー：1行目に項目名

## 命名規則の推奨

### goods_id の設計

- 30字以内（厳守）
- 半角英数＋ハイフン `-`（推奨）
- アンダースコア `_`、ピリオド `.`、スラッシュ `/` などは混在させない
- 大文字統一（小文字混在で表記ゆれが発生しやすい）
- バリエーション識別子の付け方を統一：
  - 例：`TSH-001-BLK-S`（商品-番号-色-サイズ）
  - 例：`TSH-001-01-01`（数値コード）

### モール側SKUとの関係

- ネクストエンジンの goods_id = 楽天の項目選択肢別SKU
- ネクストエンジンの daihyou_shouhin_code = 楽天の商品管理番号（親）
- ネクストエンジンの stock_goods_id = 在庫減算先（通常は goods_id 自身）

セット商品の場合：
- 親商品（販売単位）：goods_id = TSH-SET-001, set_flg=1
- 在庫減算元：stock_goods_id を子商品のgoods_idに設定
- 子商品（在庫管理単位）：goods_id = TSH-001-BLK-S, set_flg=0

## CSV書き出し操作

1. ネクストエンジン管理画面 → 商品マスタ
2. 検索条件で対象を絞り込み
3. CSVダウンロード
4. SJIS / CR+LF / カンマ区切りで出力

## 更新の流れ

### 安全な更新（推奨）
1. 管理画面の「商品マスタ編集」で個別変更
2. 在庫変更は「在庫変更」機能で実数値登録
3. 一括変更は「商品マスタ一括編集」CSVで実施

### 危険な更新（事故源）
- 通常の商品マスタCSVをダウンロード → 在庫数を編集 → アップロード
- → 加減算ロジックで意図しない在庫値になる
- 在庫はCSVでは触らない

## 入出力フォーマットの落とし穴

- **0落ち**：goods_idが数値だけ（例：`0001234`）の場合、Excelで開くと先頭0が消える
- **表記ゆれ**：半角全角混在、大文字小文字混在、ハイフン種違い
- **空白混入**：CSVのセル前後の空白がgoods_idの一部として認識される
- **改行コード混在**：他システムと連携で改行が変わる
