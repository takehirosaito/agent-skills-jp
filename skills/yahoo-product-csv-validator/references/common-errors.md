# ストアクリエイターPro 主要エラーメッセージ × 原因 × 対処

メッセージ文言は実際のシステム表記と多少異なる場合がある。**最終的な対応は管理画面のエラー詳細を参照**。

---

## 1. ファイル全体エラー

| エラー文（例） | 原因 | 対処 |
|---|---|---|
| 「ヘッダー行が認識できません」 | 1行目が日本語列名／全角／BOM混入／改行なし | 半角列名・Shift_JIS・CR+LF・BOM無しで保存 |
| 「文字コードが正しくありません」 | UTF-8で保存 | Shift_JIS（CP932）で再保存 |
| 「行が認識されない／1行になっている」 | 改行が LF または CR のみ | CR+LFに変換 |
| 「ファイルサイズが上限を超えています」 | 1ファイルの行数／サイズ超過 | 分割アップロード |

## 2. 列・値エラー

| エラー文（例） | 原因 | 対処 |
|---|---|---|
| 「列 `XXX` は無効です」 | 列名スペルミス／大文字／全角 | 公式ヘッダー名（半角小文字・ハイフン）に修正 |
| 「必須項目 `code` がありません」 | 必須列欠落 | code／name／price／path／display を追加 |
| 「商品名が長すぎます」 | name 全角75文字超 | 短縮 |
| 「価格が不正です」 | price に「2,980円」「2980 」「￥2980」混入 | 半角整数のみに |
| 「数量が不正です」 | quantity に文字混入 | 半角整数に |
| 「日付の形式が不正」 | sale-period-start の形式違反 | `YYYY-MM-DD hh:mm:ss` 形式 |
| 「画像が見つかりません」 | ystore-image1 のパス／URL誤り | 画像名・URLを修正 |

## 3. コード／キー整合性エラー

| エラー文（例） | 原因 | 対処 |
|---|---|---|
| 「商品コードが重複しています」 | 同一ファイル内で code 重複 | 重複行を削除／統合 |
| 「在庫データの商品コードが商品データに存在しません」 | 孤立在庫 | 商品データに code 追加 or 在庫データから削除 |
| 「オプションデータの商品コードが見つかりません」 | 孤立オプション | 同上 |
| 「商品コードに使用できない文字が含まれています」 | 全角・特殊記号 | 半角英数記号に統一 |

## 4. カテゴリ・分類エラー

| エラー文（例） | 原因 | 対処 |
|---|---|---|
| 「ストアカテゴリが存在しません」 | path に未作成カテゴリを指定 | ストアクリエイターProでカテゴリ作成 |
| 「プロダクトカテゴリIDが無効です」 | product-category に存在しないID | Yahoo!プロダクトカテゴリ一覧から選定 |
| 「ブランドコードが無効です」 | brand-code に存在しないID | ブランドコード検索で確認 |

## 5. 価格・販売関連

| エラー文（例） | 原因 | 対処 |
|---|---|---|
| 「セール価格が販売価格より高い」 | sale-price >= price | 値を修正 |
| 「セール期間が現在より過去」 | sale-period-end < 現在時刻 | 期間を再設定 |
| 「税区分が不正」 | taxable に 0/1 以外 | 0または1に |

## 6. 警告（取り込みは通るが推奨修正）

| 警告 | 内容 | 対応 |
|---|---|---|
| 「プロダクトカテゴリ未設定」 | product-category 空欄 | 設定で検索露出UP |
| 「product-code 未設定」 | JAN/ISBN 空欄 | 設定でカタログマッチング |
| 「キャプション空欄」 | caption 空 | 商品説明を入れる |
| 「ystore-image1 未設定」 | メイン画像なし | 必ず設定 |

## 7. 対処のフロー

1. **エラー文を**そのまま全文確認
2. **ファイル全体エラー（文字コード／改行／ヘッダー）**が出ていれば最優先で修正
3. 個別行エラーは**行番号付き**で抽出し、対応表で原因照合
4. 修正後は**display=0で一部行を先行アップロード**してから本番反映

## 8. 取り込み結果ログの読み方

ストアクリエイターProは取り込み完了後に「取り込み結果ファイル」を出力する。

- 「成功件数」「失敗件数」「警告件数」
- 失敗行は「行番号／code／エラー内容」で出力される
- このログをCSVとして残し、修正後の再アップロードと差分比較する
