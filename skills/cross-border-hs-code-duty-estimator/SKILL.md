# 越境EC HSコード・関税 概算見積

## 概要

越境ECで販売する商品について、HSコード（Harmonized System、関税分類番号）の候補を素材・用途・加工度から絞り込み、仕向国の関税率・輸入消費税(VAT/GST)・通関論点・デミニミス(少額免税)を整理して、原価への上乗せを概算するスキル。「いくら関税がかかるか」「DDPでいくら前払い設定にするか」を事前に見立て、到着時の追徴によるクレームや赤字を防ぐ。

**重要**: 本スキルの数値は事前見積であり、正式なHSコード認定と税額は税関・通関士の判断が確定値。

## 最重要原則

**「HSは素材×用途×加工度で決まる／同じ商品でも仕向国でコードと税率が違いうる／デミニミス(免税枠)を必ず確認／関税は CIF か FOB かなど課税標準の取り方で変わる／DDPなら見積を価格に内包させる」**。HSの取り違えは追徴・差し止め・信用問題に直結する。確定はプロに委ねつつ、事前の桁感とリスクを掴むのが本スキルの役割。

## 知識ベース

HSコードの構造：
- 上6桁が国際共通（類→項→号）、それ以降は各国独自（日本は9桁、米国HTSは10桁等）。
- 分類は「何でできているか(素材)」「何に使うか(用途)」「どこまで加工したか」で決まる。複合品は GRI（解釈通則）で主たる性質に寄せる。

コスト構成（仕向国で輸入時にかかる代表例）：

| 項目 | 内容 |
|---|---|
| 関税(Duty) | HSコード×原産地×仕向国税率。EPA/FTA で軽減される場合あり（原産地証明が要件） |
| 輸入消費税 | EUのVAT、豪/NZ等のGST、米国は連邦の付加価値税なし(州売上税は別系統) |
| 通関手数料/立替 | クーリエの通関代行・立替手数料 |
| デミニミス | 一定額未満は関税/税免除になる国がある（基準額は国ごとに大きく異なる） |

> 税率・デミニミス基準・EPA適用条件は国と時期で変わる。本スキルは確認手順を示し、確定は税関タリフDB/通関士で取得させる。

## 処理フロー

### Step 1：商品情報の確認
- 商品名・主素材（綿/ポリ/革/金属/プラ/木/電子部品等）・用途・加工度・セット内容
- 原産国（製造国）、仕向国、1個あたり販売価格・重量
不明時は仮定を置いて明示。

### Step 2：HSコード候補の提示
- 素材×用途からHS上6桁の候補を1〜3件提示し、各候補の判断根拠と「迷いやすい分岐」を示す。
- 確定は仕向国のタリフDB（例：米国HTS、EU TARIC、日本の実行関税率表）で照合するよう案内。

### Step 3：税率・輸入税・免税枠の確認手順
- 仕向国の関税率・VAT/GST・デミニミス基準の調べ方を提示。EPA/FTA適用可能性も指摘。

### Step 4：概算コスト計算
- 課税標準（CIF想定など）を置き、Duty＋輸入税＋通関手数料を概算。1個あたり上乗せ額を算出。

### Step 5：DDP/DDU と価格内包の判断
- DDPなら見積を販売価格に内包、DDUなら購入者負担を明示。閾値（デミニミス）をまたぐ価格設定の注意を提示。

```
## 3. 概算コスト
   | 項目 | 率/額 | 1個あたり |
   | 関税 | … | … |

```

## 品質ゲート
- HS候補に判断根拠と「迷う分岐」を併記したか
- 税率・デミニミスを断定せず確認手順を示したか
- 課税標準(CIF/FOB等)の前提を明示したか
- 確定はプロ判断である旨を明記したか

## 注意事項
- 本スキルは確定的な税務・通関助言ではない。最終判断は税関・通関士・専門家に委ねる。
- 規制品（食品・医薬部外品・電気・武器類・ワシントン条約対象等）は別途許認可が必要。
- 原産地規則(EPA/FTA)の適用には証明書等の要件がある。
