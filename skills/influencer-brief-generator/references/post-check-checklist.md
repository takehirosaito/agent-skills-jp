# 投稿確認チェックリスト

事業者側・インフルエンサー側の双方が使えるチェックリスト。

---

## 事業者側 事前確認チェック

### PR表記
- [ ] 表記語句が「PR／広告／プロモーション／Sponsored」のいずれか
- [ ] 表記位置が冒頭または常時表示
- [ ] 動画は冒頭・終盤の両方または常時表示
- [ ] フォントサイズが本文と同等以上
- [ ] 背景とのコントラストが十分
- [ ] 「もっと見る」を押さずに見える位置
- [ ] 末尾の大量ハッシュタグ群に埋没していない
- [ ] 媒体機能（Paid Partnership／Spark Ads／有料プロモーション表示）が設定されている

### 商品情報の正確性
- [ ] 商品名（正式名称）が正確
- [ ] ブランド名が正確
- [ ] 公式URL（プロフィールリンク等）への誘導
- [ ] オファー条件（価格・割引・保証）が正確
- [ ] 機能性表示食品の場合、届出番号が明示

### NG表現チェック
- [ ] カテゴリ別NG表現を使っていない
- [ ] 薬機法対象カテゴリの表現範囲内
- [ ] before/after画像（化粧品・健食）を使っていない
- [ ] 「治る／治療／予防」を使っていない
- [ ] No.1・最上級・最安に根拠あり or 削除
- [ ] 個人属性断定（「あなた」等）をしていない
- [ ] 競合を貶める表現がない

### 画像・動画の素材
- [ ] 提供素材を正しく使用
- [ ] ブランドロゴの表示位置・サイズ
- [ ] 商品の見栄え（暗すぎ／傾き／映り込み）
- [ ] 動画の音声・字幕の明瞭性

### 投稿後の運用
- [ ] 削除禁止期間が明示済み
- [ ] 二次利用権の範囲が合意済み
- [ ] 報酬支払時期・方法が確定済み

## インフルエンサー側 投稿前チェック

### PR表記（最重要）
- [ ] 投稿冒頭に「【PR】」「PR｜」「#PR」のいずれかを明記
- [ ] 動画なら冒頭・終盤の両方または常時表示で「PR」字幕
- [ ] Instagram の場合、タイアップ投稿機能（Paid Partnership）でブランド設定
- [ ] TikTok の場合、Spark Ads 化を相談
- [ ] YouTube の場合、「有料プロモーションを含みます」設定
- [ ] PR表記が**他のハッシュタグに紛れていない**

### 商品情報
- [ ] 商品名・ブランド名のスペル確認
- [ ] 公式URL（短縮URL含む）の動作確認
- [ ] オファー条件（価格・期間・特典）の正確性

### NG表現の自己チェック
- [ ] 事業者から渡されたNG表現リストを再確認
- [ ] 薬機法カテゴリの表現に注意
- [ ] 効能効果を断定する表現を避けた
- [ ] 個人的な使用感の範囲で書いた

### 画像・動画
- [ ] 商品が美しく映っている
- [ ] ブランドロゴ・パッケージ表示が指定通り
- [ ] 動画の字幕が読みやすい（音OFFでも理解できる）
- [ ] 著作権・肖像権に問題がない（他人の写真・音楽）

### 媒体特性
- [ ] Instagram：1:1または9:16比率／ハッシュタグ5-15個
- [ ] TikTok：9:16縦動画／冒頭3秒の訴求／音楽の商用利用可確認
- [ ] X：140字以内
- [ ] YouTube：冒頭で口頭でもPR言及

## 投稿公開後の事業者チェック

### 公開直後（24時間以内）
- [ ] 投稿が予定通り公開された
- [ ] PR表記が見える位置に表示されている
- [ ] スクリーンショットを保存（証拠保全）
- [ ] 提供素材が指示通り使われている
- [ ] エンゲージメント（いいね・コメント）の傾向確認

### 1週間後
- [ ] コメント欄に問題がないか
- [ ] インフルエンサーからの問い合わせ対応
- [ ] 投稿のリーチ・インプレッション分析

### 1ヶ月後・継続表示中
- [ ] 投稿が削除されていない
- [ ] PR表記が継続して表示されている
- [ ] 二次利用の予定があれば素材を確保

### 6ヶ月後（削除禁止期間終了後）
- [ ] 削除可否の合意
- [ ] 投稿の継続表示について再協議

---

## 過去投稿（2023.10.1施行前）の見直しチェック

- [ ] 過去にこのインフルエンサーに依頼した投稿の一覧化
- [ ] 各投稿のPR表記の有無確認
- [ ] PR表記がない投稿について、追記または削除の依頼
- [ ] 継続表示中の場合、必ず遡及対応

---

## 違反発覚時の対応フロー

### 軽微な違反（PR表記の位置が不十分等）
1. 投稿の修正依頼
2. 修正履歴のスクショ保存
3. 今後の契約書条項を強化

### 重大な違反（PR表記なし／NG表現使用／効能効果違反）
1. 投稿の即時削除依頼
2. 報酬の減額または不支払（契約に基づく）
3. 損害賠償の検討（事業者がステマ規制違反の措置命令を受けた場合）
4. 弁護士相談

### 措置命令を受けた場合
1. 公正取引委員会の措置命令内容を確認
2. 該当投稿を全削除
3. 再発防止策の策定
4. 自社サイト・SNSでの公示（措置命令の場合）

## 媒体別 PR表記が正しく付いている画面の例

### Instagram フィード（OK例）
```
キャプション：
【PR】○○ブランドからご提供いただきました🌱

朝のスキンケアに新しい時間を──
（本文）

──
✓「Paid partnership with @○○ブランド」のラベルが投稿上部に表示
```

### Instagram フィード（NG例）
```
キャプション：
朝のスキンケアに新しい時間を──
（本文）

#スキンケア #保湿化粧水 #乾燥肌スキンケア #コスメ好き #美容垢
#コスメ好きさんと繋がりたい #PR
```
→ #PR が大量ハッシュタグの末尾に埋没。違反。

### TikTok（OK例）
- 動画全編に「PR」字幕（右上）を常時表示
- 動画冒頭：「PRです」と口頭でも言及
- キャプション冒頭：「【PR】」明記
- Spark Ads 化（投稿主アカウントに広告ラベル）

### TikTok（NG例）
- 動画冒頭の0.5秒だけ極小フォントで「PR」表示
- キャプション末尾の大量タグに「#PR」紛れ込み
→ 視認不可・埋没。違反。

### YouTube（OK例）
- 動画開始時に「有料プロモーションを含みます」表示（YouTube公式機能）
- 概要欄1行目に「【PR】」明記
- 動画冒頭で「今日は○○ブランドさんからご提供いただきました」と口頭で言及

### YouTube（NG例）
- 「有料プロモーションを含みます」設定なし
- 概要欄末尾に小さく「※提供」と書いてある
→ 視認不可。違反。

## チェックリストの使い方

1. **契約時**：このチェックリストを添付してインフルエンサーに事前共有
2. **原稿提出時**：事業者側でPR表記・NG表現を確認
3. **公開直後**：スクショ保存しチェックリスト記入
4. **継続表示中**：1ヶ月後・6ヶ月後に再確認
5. **記録保管**：契約終了後3年保管推奨（措置命令時の証拠）
