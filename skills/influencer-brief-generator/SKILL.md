# インフルエンサー依頼ブリーフ作成

## 概要

商品提供／対価／指示を伴うインフルエンサー・アンバサダー・モニター案件で必須となる依頼ブリーフ＋契約条項を、**ステマ規制（景表法5条3号・2023.10.1施行）**および**カテゴリ別の薬機法・景表法・健康増進法**に完全対応した形で生成するスキル。

ステマ規制の規制対象は**広告主（事業者）のみ**で、インフルエンサーは規制対象外。**事業者が責任を負う**。PR表記の語句・位置・サイズ・媒体機能（Paid Partnership／Spark Ads／有料プロモーション表示）まで含めて、媒体別に正しい指示書として出す。

## ★最重要原則

**「事業者の表示」と判断される投稿には、媒体別に正しい位置・サイズ・タイミングでPR表記が必須。** タグ末尾の「#PR」だけ、極小フォント、「もっと見る」を押さないと見えない位置への配置はNG。Instagram は Paid Partnership 機能、TikTok は Spark Ads、YouTube は「有料プロモーションを含みます」表示など、**媒体公式機能の併用**で証跡を残すのが安全。違反すると措置命令・公表（風評）リスク。

## 媒体別 PR表記要件（要点）

| 媒体 | PR表記の位置 | 媒体公式機能 |
|---|---|---|
| Instagram フィード | キャプション**冒頭1行目**「【PR】」 | **Paid Partnership**（タイアップ投稿） |
| Instagram リール | 動画冒頭3秒以内＋全編「PR」字幕＋キャプション冒頭 | Paid Partnership |
| Instagram ストーリー | 最初のスライドに「PR」テロップ、各スライド共通 | Paid Partnership |
| TikTok | 動画冒頭3秒以内＋終盤3秒（または全編字幕）＋キャプション冒頭 | **Spark Ads** |
| YouTube | 動画開始時に「有料プロモーションを含みます」公式表示＋概要欄冒頭＋動画冒頭で口頭 | YouTube公式の表示機能 |
| X（旧Twitter） | ポスト冒頭に「PR｜」「【PR】」 | （なし） |
| Threads | 投稿冒頭「【PR】」 | Instagram連動 |
| ブログ | 記事最上部に「PR」「広告」「アフィリエイト広告を利用しています」 | （なし） |

詳細は `references/stema-contract-clauses.md`。

## 処理フロー

### Step 1：入力情報の整理

必須：
- 商品情報（カテゴリ・薬機法カテゴリ・価格・USP）
- 依頼先属性（インフルエンサー名・フォロワー規模・主要ジャンル・属性）
- 投稿媒体（Instagram／TikTok／YouTube／X／Threads／ブログ／複数）
- 報酬・提供条件（現金・商品提供・アフィリ・固定費＋成果報酬 等）
- 投稿希望日・期間

任意：
- 訴求ポイント（USP・差別化・特長）
- NG表現の追加リスト
- 競合排他期間
- 二次利用したい媒体

不足時は仮置きで初稿を出し、冒頭に「最終確定にはXXの確認が必要」を表示（ハイブリッド設計）。

### Step 2：商品の薬機法カテゴリ確定

ここを間違えると言える効能が変わる：
- 化粧品（届出のみ）：56項目内
- 医薬部外品（薬用化粧品）：承認効能内＋容器に「医薬部外品」表示
- 機能性表示食品：届出文言と一字一句一致＋**届出番号を投稿内に明示**
- いわゆる健康食品（一般食品）：効能効果の標榜不可
- 美容雑貨：身体への効果標榜不可

カテゴリ不明な場合は最も可能性の高い「仮カテゴリ」で暫定ブリーフを出し、「カテゴリ確認が必要」を冒頭表示。

### Step 3：訴求ポイントの整理と「言える／言えない」分離

| カテゴリ | 言える範囲（OK） | 言えない（NG） |
|---|---|---|
| 化粧品 | 56項目内「保湿」「肌のキメを整える」「日やけによるシミ・ソバカスを防ぐ」 | 「シミに効く」「美白」「アンチエイジング」「皮膚科医推薦」 |
| 医薬部外品 | 承認効能（美白／肌荒れを防ぐ等） | 承認外効能 |
| 機能性表示食品 | 届出文言＋届出番号 | 届出文言外の効能 |
| 一般食品 | 「美味しい」「香りが良い」「忙しい毎日に」 | 「痩せる」「便秘解消」「免疫力アップ」 |
| 雑貨 | 物理的機能（軽い・薄い） | 「肩こりに効く」「血行促進」（医療機器領域） |

詳細は `references/category-ng-list.md`。

### Step 4：契約条項を10条構成で生成

1. **第1条 PR表記義務**（語句・位置・視認性・媒体機能）
2. **第2条 必須記載事項**（商品名・ブランド・URL・オファー条件・機能性表示食品の届出番号）
3. **第3条 NG表現の禁止**（カテゴリ別NG表現リスト添付）
4. **第4条 投稿原稿の事前確認**（3営業日前提出／2営業日確認／修正範囲を限定）
5. **第5条 公開・継続表示**（削除禁止期間最低6ヶ月・遡及PR表記）
6. **第6条 報酬・支払**（金額・税込税抜・支払時期5営業日・源泉徴収）
7. **第7条 二次利用権**（範囲・媒体・期間6ヶ月・表記・加工範囲）
8. **第8条 競合排他**（期間30日・対象カテゴリ）
9. **第9条 NDA**（守秘範囲・期間3年）
10. **第10条 違反時対応**（軽微・重大・損害賠償）

### Step 5：媒体別の具体的PR表記指示

媒体ごとに「冒頭何秒以内」「フォントサイズ」「公式機能の使用」を具体的に明記。

**Instagram フィードの例**：
```
キャプション冒頭：
【PR】[ブランド名]からご提供いただきました。
（本文）

Paid Partnership 設定方法：
1. 投稿時に「タイアップ投稿としてラベル付け」を選択
2. ブランドアカウントを指定
3. 投稿に「Paid partnership with @[ブランド名]」が表示される
```

### Step 6：投稿原稿事前確認プロセス

- 公開希望日の**3営業日前**までに原稿（コピー・画像・動画）を提出
- 事業者は**2営業日以内**に確認・FB
- 修正依頼の範囲は限定（PR表記の位置・NG表現修正・誤情報修正・届出文言修正）
- 自然なトーン・個人的感想・コーディネートの主観は**インフルエンサー裁量を尊重**（過度な台本化はステマ的）

### Step 7：投稿後の確認チェックリスト

| 項目 | チェック |
|---|---|
| PR表記の位置 | 冒頭1行目／動画冒頭3秒以内／全編字幕 |
| PR表記の視認性 | 本文と同等以上のフォントサイズ・コントラスト |
| 媒体公式機能 | Paid Partnership／Spark Ads／有料プロモーション表示 |
| 必須情報 | 商品名・ブランド・URL・届出番号（機能性表示食品） |
| NG表現 | カテゴリ別NG表現リストに該当しない |
| before/after | 化粧品・健食で使われていない |
| 過去投稿 | 2023.10.1以前で対価ありなら遡及PR表記 |

詳細は `references/post-check-checklist.md`。

## 代表例：保湿化粧水（Instagram フィード＋ストーリー）

**入力**：
- 商品：保湿化粧水 30ml 3,800円（**化粧品**・届出のみ）
- 依頼先：マイクロインフルエンサー（フォロワー1.5万・スキンケア系）
- 媒体：Instagram フィード＋ストーリー
- 報酬：3万円＋商品提供
- 投稿希望日：1週間後

**訴求ポイント（化粧品56項目内）**：
- ヒアルロン酸3種で肌のうるおいを保つ（56項目24番）
- ビタミンC誘導体で肌のキメを整える（56項目20番）
- 無香料・無着色・日本製

**NG表現（化粧品ゆえに）**：
- 「シミに効く／美白効果／アンチエイジング／皮膚科医推薦／リフトアップ／治る／効果」
- before/after画像

**Instagram フィードのPR表記**：

キャプション冒頭：
```
【PR】[ブランド名]さんからご提供いただきました。

乾燥が気になる夕方も、しっとり肌へ。
ヒアルロン酸3種 × ビタミンC誘導体配合の保湿化粧水を使ってみました。
無香料・無着色・日本製で家族で続けられます。

商品詳細はストーリーリンクから。

#PR #ブランド名 #スキンケア
```

Paid Partnership 設定：
- 投稿時に「タイアップ投稿としてラベル付け」
- ブランドアカウント @[ブランド名] を指定
- 「Paid partnership with @[ブランド名]」表示確認

**契約条項抜粋**：
- 第5条 削除禁止期間：投稿公開から6ヶ月
- 第7条 二次利用権：自社EC・公式SNS・広告（Meta／Google／Yahoo!／LINE）・LP・カタログ・店頭POP／期間6ヶ月
- 第8条 競合排他：投稿後30日間「保湿化粧水」カテゴリの他社製品PR禁止

**投稿確認チェックリスト**：
- [ ] キャプション冒頭1行目に【PR】
- [ ] Paid Partnership ラベル設定済み
- [ ] 商品名・ブランド名・URL明示
- [ ] 化粧品56項目外の効能訴求なし（「シミに効く」等なし）
- [ ] 「皮膚科医推薦」未使用
- [ ] before/after未使用
- [ ] No.1・最上級表現に根拠5項目 or 削除

詳細パターン（健食・食品・アパレル・家電）は `references/examples.md`。

## エッジケース

- **マイクロ／ナノインフルエンサー（フォロワー1万以下）**：報酬は商品提供＋少額または無償の場合あり。**対価関係があれば対価金額に関わらずPR表記必須**。
- **アフィリエイト広告として運用**：「アフィリエイト広告を利用しています」明記。事業者からの直接対価がなくても、アフィリエイトリンクで成果報酬がある場合は規制対象。
- **2023.10.1以前の投稿で継続表示中**：事業者から依頼・対価があったものは遡ってPR表記追加が必要。
- **インフルエンサー側のNG表現使用**：軽微（修正依頼）／重大（投稿削除・報酬減額・損害賠償）の対応を契約で明示。
- **二次利用での画像トリミング・字幕追加**：投稿の趣旨を曲げる改変は不可。トリミング・サイズ調整・字幕追加は可（事前同意取得）。
- **複数媒体同時投稿（Instagram→TikTok→YouTube）**：媒体ごとに正しいPR表記要件を満たす（媒体機能が違う）。

## 注意事項

- ステマ規制の規制対象は**事業者（広告主）のみ**。インフルエンサーは規制対象外。**事業者が責任を負う**。
- PR表記は「冒頭または常時表示」が原則。タグ末尾の「#PR」だけ、「もっと見る」を押さないと見えない位置、極小フォント、1秒未満の表示は**全てNG**。
- Instagram の Paid Partnership・TikTok の Spark Ads・YouTube の「有料プロモーションを含みます」表示は**媒体公式機能**。これを併用することで証跡が残り、PR表記不備のリスクが減る。
- 機能性表示食品の届出文言は一字一句一致が必須。「同等の意味」では違反になる。届出番号も必須。
- 化粧品の「皮膚科医推薦」「医師監修」は化粧品適正広告ガイドラインで原則NG。健食でも景表法リスク。
- 違反時のペナルティ：ステマ規制単体は措置命令＋公表（風評）／優良誤認・有利誤認該当なら課徴金売上3%（繰返し4.5%）／薬機法違反は業務停止・2年以下懲役／特商法定期購入違反は3年以下懲役・300万円以下罰金（直罰）。
- 過去投稿の遡及対応：2023.10.1以前で対価関係ありの投稿が継続表示中なら、PR表記を追加する。
