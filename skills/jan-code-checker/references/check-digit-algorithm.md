# GTIN/JAN チェックデジット計算アルゴリズム

## 共通アルゴリズム（GS1標準・モジュラス10）

GTIN-8、GTIN-12、GTIN-13、GTIN-14は**同じアルゴリズム**でチェックデジットを算出する。

### 手順

1. **チェックデジットを除いた本体部分**を取り出す（GTIN-13なら12桁、GTIN-8なら7桁）
2. 本体部分の **右端から順に** `3, 1, 3, 1, 3, 1, ...` の重みを各桁にかける
3. 重み付けされた値の合計を求める
4. **合計を10で割った余り** を `r` とする
5. **チェックデジット = (10 - r) mod 10**（rが0の場合はCDも0）

桁数によらず単一のアルゴリズム。「左から何桁目」で説明すると桁数によって重みの並びが変わって混乱するため、**必ず「本体の右端から」**で説明・実装する。

## 検算例（全て実際に計算済み）

### 例A：GTIN-13 完全な値の検証

入力：`4901234567894`

- 本体（12桁）：`490123456789`、CD：`4`
- 本体を右から並べる：`9 8 7 6 5 4 3 2 1 0 9 4`
- 重み（右から3,1,3,1,...）：`3 1 3 1 3 1 3 1 3 1 3 1`
- 積：`27 8 21 6 15 4 9 2 3 0 27 4` = 合計 **126**
- 126 % 10 = **6**
- (10 - 6) % 10 = **4** ✅ 入力CDと一致 → 有効

### 例B：GTIN-8 のCD算出

本体：`4960581`（7桁）

- 本体を右から並べる：`1 8 5 0 6 9 4`
- 重み（右から3,1,3,1,3,1,3）：`3 1 3 1 3 1 3`
- 積：`3 8 15 0 18 9 12` = 合計 **65**
- 65 % 10 = **5**
- (10 - 5) % 10 = **5** → チェックデジット **5**
- 完成GTIN-8：`49605815`

別のCD値（例：`49605813`）が来た場合は**不一致＝無効**と判定する。

### 例C：GTIN-12（UPC-A）の検証

入力：`012345678905`

- 本体（11桁）：`01234567890`、CD：`5`
- 本体を右から並べる：`0 9 8 7 6 5 4 3 2 1 0`
- 重み（右から3,1,3,1,3,1,3,1,3,1,3）：`3 1 3 1 3 1 3 1 3 1 3`
- 積：`0 9 24 7 18 5 12 3 6 1 0` = 合計 **85**
- 85 % 10 = **5**
- (10 - 5) % 10 = **5** ✅

### 例D：GTIN-14（ITF）

本体：`1490123456789`（13桁）

- 本体を右から並べる：`9 8 7 6 5 4 3 2 1 0 9 4 1`
- 重み：`3 1 3 1 3 1 3 1 3 1 3 1 3`
- 積：`27 8 21 6 15 4 9 2 3 0 27 4 3` = 合計 **129**
- 129 % 10 = **9**
- (10 - 9) % 10 = **1** → 完成GTIN-14：`14901234567891`

## 検証用Pythonコード（GTIN-8/12/13/14 共通）

```python
def gtin_check_digit(body: str) -> int:
    """
    GTIN本体（チェックデジットを除いた部分）から
    チェックデジットを計算する。

    GTIN-8 → body 7桁
    GTIN-12 → body 11桁
    GTIN-13 → body 12桁
    GTIN-14 → body 13桁
    """
    if not body.isdigit():
        raise ValueError("数字のみを渡してください")

    total = 0
    for index, digit in enumerate(reversed(body), start=1):
        weight = 3 if index % 2 == 1 else 1
        total += int(digit) * weight

    return (10 - (total % 10)) % 10


def validate_gtin(code: str) -> bool:
    """GTIN-8/12/13/14 を桁数で自動判別して検証"""
    cleaned = "".join(ch for ch in code if ch.isdigit())
    if len(cleaned) not in (8, 12, 13, 14):
        return False
    body, cd = cleaned[:-1], int(cleaned[-1])
    return gtin_check_digit(body) == cd
```

このコードはGS1標準に準拠。LLMで計算する場合も同じロジックを脳内で実行する。

## 計算例を追加する場合の注意

- 例示する数値は**必ず実際に計算してから記載**する
- タイポや誤計算をそのまま例として残すと、ユーザーが学習元として参照したときに誤った計算を覚えてしまう
- アルゴリズム説明は「本体右端から3,1,3,1...」の汎用表現を使う（「左から何桁目」は桁数で混乱するため避ける）
