# 国コード（プリフィックス）と GS1事業者コード構造

## GTIN/JAN コード種類と桁数

| コード | 桁数 | 別名 | 主な用途 |
|---|---|---|---|
| GTIN-8 / JAN-8 | 8桁 | EAN-8 | 小型商品（飲料缶・タバコ等） |
| GTIN-12 | 12桁 | UPC-A | 米国・カナダ |
| GTIN-13 / JAN-13 | 13桁 | EAN-13 | 日本国内・国際標準（日常のJAN） |
| GTIN-14 | 14桁 | ITF/集合包装コード | ケース・ボール単位の物流梱包 |
| SSCC-18 | 18桁 | シリアル輸送容器コード | パレット単位の物流梱包 |
| ISBN-13 | 13桁 | GTIN-13形式 | 書籍（先頭 978/979 固定） |
| ISSN | 13桁形式 | EAN-13形式 | 雑誌（先頭 977 固定） |

EC実務で頻出：GTIN-13（JAN-13）、ISBN-13。Amazon US輸出ではUPC-A（GTIN-12）。物流業務でGTIN-14（ITF）。

## 国コード（プリフィックス）

GTIN-13 の先頭2〜3桁は GS1 のプリフィックス（国・地域コード）。

| プリフィックス | 国／地域 |
|---|---|
| **45, 49** | **日本** |
| 00-13 | 米国・カナダ |
| 30-37 | フランス |
| 40-44 | ドイツ |
| 50 | 英国 |
| 690-699 | 中国 |
| 880 | 韓国 |
| 885 | タイ |
| 893 | ベトナム |
| 471 | 台湾 |
| 489 | 香港 |
| **02, 20-29** | **インストアマーキング**（社内・店舗内専用） |
| **977** | 雑誌（ISSN） |
| **978, 979** | 書籍（ISBN） |

## EC実務での判定ルール

| 観察 | 判定 |
|---|---|
| 先頭が 45 / 49 | 日本の事業者がGS1から正式発番したJAN（信頼度高） |
| 先頭が 02 / 20-29 | **店舗内コード**。外部流通・モール登録には使用不可 |
| 先頭が 690-699 | 中国製造業者のJAN（OEM・並行輸入で頻出） |
| 先頭が 978 / 979 | 書籍のISBN |
| 先頭が 977 | 雑誌のISSN |
| その他 | 外国のメーカーJAN／プリフィックス表で要確認 |

## インストアコードの位置づけ（重要）

GS1標準では先頭2桁が **02 または 20〜29** のコードは **インストアマーキング** と定義され、社内管理・店舗内（生鮮品の計量販売など）用途で**企業間取引・外部流通には使用しない**。

Amazon・楽天・Yahoo!ショッピング・Google Merchant Center 等の外部モールに登録するJAN欄にインストアコードを入れるのは、GS1標準から外れた使い方。

EC事業者によくあるミス：自社で振った社内コード（先頭20始まり等）を「JANのつもりで」モールに登録 → 他社のインストアコードと衝突する可能性、検索精度低下、最悪はアカウントペナルティ。

## GS1事業者コードの構造

GS1 Japan から発行される事業者コードには **9桁／10桁／7桁** の3パターンがある。

| 事業者コード長 | JAN-13の残り構造 | 商品アイテム数 |
|---|---|---|
| 9桁 | + 3桁アイテムコード + 1桁CD | 1,000品まで |
| 10桁 | + 2桁アイテムコード + 1桁CD | 100品まで |
| 7桁 | + 5桁アイテムコード + 1桁CD | 100,000品まで（中堅・大手） |

### JAN-13の構造例（事業者コード9桁の場合）

```
4  9  X  X  X  X  X  X  X  X  Y  Y  Y  C
└──┘  └──────────────────────┘  └─────┘  └┘
国    GS1事業者コード(9桁)        商品ｱｲﾃﾑ  CD
ｺｰﾄﾞ                            (3桁)
```

事業者コードは GS1 Japan の事業者情報検索サービス（**GEPIR**）で照会可能。事業者コードから企業名が判明する場合がある。

## 新規発番が必要な場合

- GS1 Japan の事業者コード新規登録（年間登録料がかかる）
- 売上規模・商品数に応じて事業者コードの桁長が決まる
- 取得後、自社で商品アイテムコードを採番し、チェックデジットを計算してJAN-13を完成させる
- 発番権はGS1にあるため、勝手に13桁を作って外部流通させてはいけない

## 既存JANの調査

- 仕入商品はメーカー発行の正式JANを使う（事業者コードはメーカー側）
- メーカーのカタログ・商品本体印字・出荷伝票で確認
- 不明な場合はメーカーに問い合わせ
- バリエーション毎に別JANが原則
