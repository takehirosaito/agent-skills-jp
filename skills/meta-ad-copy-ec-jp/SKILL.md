# Meta広告ECコピー作成

## 概要

Meta（Facebook／Instagram）広告のEC向けコピーを、プライマリテキスト125字／見出し40字／説明30字の文字数仕様・配信面別画像比率・動画ベストプラクティス・Metaポリシー（個人属性断定・健康訴求・センシティブカテゴリ）・薬機法／景表法／ステマ規制まで全て満たした形で生成する。

入稿後にリジェクトされる主要因（個人属性断定・健康劇的訴求・before/after・No.1根拠なし）を**入稿前に潰す**設計。リジェクトされた既存広告の改善にも対応。

## ★最重要原則

**「Metaの最頻出リジェクト原因は『個人属性断定』」。** 「あなたは○○ですね」「40歳のあなたへ」「敏感肌のあなた」のような断定形は配信制限される。**必ず客観形（「○○な方へ」「○代の方へ」）に変換する。** さらに、化粧品56項目外の効能訴求・健食の効能標榜・before/after画像・No.1根拠なし・二重価格8週間ルール違反も同列で潰す。

## Meta 文字数・配信面早見表（要点）

| 項目 | 推奨 |
|---|---|
| プライマリテキスト | **125字以内**（モバイルで「もっと見る」前に収まる） |
| 見出し | **40字以内** |
| 説明 | **30字以内** |

| 配信面 | 推奨比率 | 推奨サイズ |
|---|---|---|
| フィード | 1:1 | 1080×1080 |
| フィード（縦長） | 4:5 | 1080×1350 |
| ストーリー／リール | **9:16** | 1080×1920 |
| 右側広告（PC）／Audience Network | 1.91:1 | 1200×628 |

**動画**：冒頭3秒に最重要要素＋音OFF対応字幕／15秒以内で完視聴率高い／9:16でリーチ最大化／画像内テキスト占有率20%以内（暗黙）。

## 処理フロー

### Step 1：入力情報の整理と前提確認

必須：
- 商品情報（カテゴリ・薬機法カテゴリ・価格・USP）
- ターゲット（属性・悩み・状況）
- 配信面（フィード／ストーリー／リール／右側／Audience Network）
- 配信目的（認知／興味関心／比較検討／購入直前／リテンション）
- オファー（割引・送料無料・返金保証・特典）
- LP URL

任意：
- 既存広告のリジェクト履歴
- 過去のCTR・CVR
- ブランドガイドライン
- 競合広告

不足時は仮置きで初稿を出し、冒頭に「最終確定にはXXの確認が必要」を表示。

### Step 2：薬機法カテゴリ確定

ここを間違えると言える効能が変わる：
- 化粧品（届出のみ）：56項目内
- 医薬部外品：承認効能内＋「医薬部外品」表示
- 機能性表示食品：届出文言と一字一句一致＋**届出番号を投稿内に明示**
- 一般食品：効能効果の標榜不可
- 美容雑貨：身体への効果標榜不可

カテゴリ不明な場合は最も可能性の高い仮カテゴリで暫定コピーを出し、「カテゴリ確認が必要」を冒頭表示。

### Step 3：核訴求の1文圧縮

> 【ターゲット】に対して、【課題・状況】を【商品】が【ベネフィット】する

例：
> 「乾燥が気になる30代の方に対して、夕方の肌の手応えを、本品が朝までうるおって整える」

### Step 4：個人属性断定→客観形への変換

| カテゴリ | NG（断定） | OK（客観） |
|---|---|---|
| 健康 | あなたの乾燥肌に | 乾燥が気になる方へ |
| 年齢 | 40歳のあなたに | 40代の方へ |
| 体型 | 太っているあなた | 体型が気になる方 |
| 髪 | ハゲのあなた | 髪のボリュームが気になる方 |
| 経済 | 借金に困っているあなた | 家計を見直したい方へ |
| 美容 | 敏感肌のあなた | 敏感肌の方 |

「○○ですね」「○歳のあなた」「○○な方に断定」を機械的に潰す。

### Step 5：文字数枠への割り付け

**フィード／IG投稿型 PASONA短縮 or BEAF**：

```
プライマリ（125字以内）：
[共感の呼びかけ]
[商品のベネフィット]
[オファー]

例：
乾燥が気になる30代の方へ。夕方も気にならないうるおいケアを、ヒアルロン酸3種配合の保湿化粧水で。初回30%OFF・30日返金保証・送料無料。

見出し（40字以内）：
3種のヒアルロン酸でうるおい肌へ

説明（30字以内）：
初回30%OFF・送料無料
```

**ストーリー／リール QUEST動画台本**：

```
0-3秒：Q（質問）「夕方の肌の乾燥、気になりませんか？」字幕＋テロップ
3-7秒：U（理解）「同じ悩みの方に」共感シーン
7-12秒：E（教育）「ヒアルロン酸3種配合の化粧水で」商品紹介
12-15秒：S→T（行動）「初回30%OFFで始める」CTA字幕＋ボタン
```

### Step 6：画像／動画の指示

- 配信面別の比率・解像度を明示
- 動画は冒頭3秒に最重要要素＋音OFF対応字幕
- 9:16縦動画でリーチ最大化（フィード・ストーリー・リール）
- 画像内テキスト占有率20%以内
- 純白背景・人物の表情を見せる
- before/after（化粧品・健食）禁止

### Step 7：Metaポリシー＋法令チェック

機械的に潰す：
- [ ] 個人属性断定（「あなたは○○ですね」「○歳のあなた」）→ 客観形に
- [ ] 健康・体型の劇的訴求（「驚異的減量」「-5kg」「劇的に変化」）→ 穏当に
- [ ] before/after（化粧品・健食）→ 削除
- [ ] 化粧品56項目外の効能（「シミに効く」「美白」「アンチエイジング」）→ 削除／医薬部外品なら可
- [ ] 健食の効能標榜（一般食品）→ 削除／機能性表示食品は届出文言＋届出番号
- [ ] 「皮膚科医推薦」（化粧品）→ 削除
- [ ] No.1・最上級・最安・「絶対」「100%」「完全」→ 根拠5項目（主体・期間・対象・方法・出典） or 削除
- [ ] 二重価格 → 8週間ルール（直前8週間のうち4週間以上の実販売）
- [ ] LP内容と広告コピー一致（不一致は配信制限）
- [ ] ステマ規制（インフルエンサー素材流用時はPR表記）

### Step 8：A/Bテスト案を3案

訴求軸の違う3案を仮説付きで：
- A：悩み起点（PASONA短縮）
- B：ベネフィット先行（BEAF）
- C：社会的証明先行（★平均・件数・受賞）

各案1,000セッション以上で統計的有意性を確認する旨を明記。

## 代表例：保湿化粧水（化粧品・30代乾燥肌向け）

**入力**：
- 商品：保湿化粧水 30ml 3,800円（化粧品・届出のみ）
- ターゲット：30代乾燥肌女性
- 配信面：Instagram フィード＋ストーリー
- オファー：初回30%OFF・30日返金保証・送料無料
- 配信目的：購入直前（リターゲ）

**核訴求**：
> 乾燥が気になる30代の方に、夕方も気にならないうるおいケアを、本品が手軽な1ステップで届ける

**フィード コピーA（PASONA短縮）**：

```
プライマリ（123字）：
乾燥が気になる30代の方へ。夕方の肌のカサつき、気になりませんか。
ヒアルロン酸3種・ビタミンC誘導体配合の保湿化粧水で、朝までしっとり続くうるおい肌へ。
初回30%OFF・30日返金保証・送料無料です。

見出し（22字）：3種のヒアルロン酸でうるおい肌へ

説明（19字）：初回30%OFF・送料無料
```

**フィード コピーB（BEAF）**：
```
プライマリ：
夕方も気にならない、うるおい肌へ。（ベネフィット）
リピート率45%・★4.4のロングセラー化粧水。（証拠）
無香料・無着色・日本製で家族で続けられます。（優位性）
ヒアルロン酸3種＋ビタミンC誘導体配合。（特徴）
初回30%OFFで始める。

見出し：リピート率45%・★4.4の保湿化粧水
説明：初回30%OFF・送料無料
```

**フィード コピーC（社会的証明）**：
```
プライマリ：
★4.4・レビュー300件以上のロングセラー保湿化粧水。
30代の方に多く選ばれている、ヒアルロン酸3種配合のうるおいケア。
無香料・無着色・日本製。初回30%OFF・30日返金保証。

見出し：★4.4・300件レビューの保湿化粧水
説明：初回30%OFF・送料無料
```

**ストーリー動画台本（15秒）**：
- 0-3秒：Q「夕方の肌の乾燥、気になりませんか？」字幕＋テロップ
- 3-7秒：U 商品手元シーン「同じ悩みの方に選ばれて」
- 7-12秒：E 「ヒアルロン酸3種配合の化粧水で、朝までしっとり」
- 12-15秒：CTA「初回30%OFFで始める→」ボタン

**画像／動画指示**：
- フィード1080×1080（1:1）／商品単体＋人物使用シーン
- ストーリー1080×1920（9:16）／縦動画／音OFF対応字幕／冒頭3秒勝負
- テキスト占有率20%以内
- before/after画像未使用（化粧品ゆえ）

**Metaポリシー＋法令チェック**：
- [x] 個人属性断定なし（「30代の方へ」客観形）
- [x] 化粧品56項目内（「うるおい」「肌のキメ」OK／「美白」「シミに効く」未使用）
- [x] No.1・最上級表現に根拠5項目／使っていない
- [x] before/after未使用
- [x] 「皮膚科医推薦」未使用
- [x] 二重価格8週間ルール（初回30%OFFは新規初回特典）
- [x] LPと広告コピー一致

## エッジケース

- **化粧品で56項目内に収まる訴求が乏しい**：FAB分析でベネフィットを情緒訴求に寄せる（「鏡を見るのが楽しみになる肌」「家族にも勧められる」等）。56項目を「特長セクション」に押し込み、FVは情緒訴求中心に。
- **機能性表示食品で届出文言が長い**：プライマリで届出番号と届出文言を併記しつつ、見出しは届出文言の核心部分を短縮（一字一句一致の範囲内）。
- **過去にリジェクトされた広告の改善依頼**：リジェクト原因（個人属性断定／健康訴求／No.1根拠／LP不一致）を特定し、該当箇所を客観形に置換、根拠併記。
- **ストーリー／リール用の縦動画素材なし**：静止画＋テロップ＋音楽で疑似動画化、または静止画9:16で配信。冒頭3秒に最重要要素は同じ。
- **インフルエンサー素材を広告流用**：Paid Partnership／Spark Ads／「有料プロモーションを含みます」表示と契約条項（別スキル `influencer-brief-generator`）が必須。

## 注意事項

- Meta広告ポリシー・文字数仕様は変動するため、入稿前に Meta for Business 公式ヘルプで最新確認。
- 個人属性断定の判定は Meta 側で自動。「あなた」を「○○な方」に置換するのが安全。
- ステマ規制：インフルエンサー素材を広告に流用する場合は契約・PR表記対応必須。事業者が責任を負う。
- 違反時のペナルティ：広告リジェクト／配信制限／広告アカウント停止／ビジネスマネージャー停止／Pixel連動停止／薬機法は業務停止・2年以下懲役／景表法は措置命令・課徴金売上3%（繰返し4.5%）。
- LP内容と広告コピーの不一致は配信制限の主要因。広告で「初回30%OFF」と言ったらLPに「初回30%OFF」帯を必ず配置。
- 媒体横断（Google／LINE／Yahoo!／TikTok等）の広告ブリーフは別スキル `ec-ad-creative-brief` に委譲。本スキルはMeta特化。
