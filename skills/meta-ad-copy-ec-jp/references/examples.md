## 例1：化粧水（保湿）／Instagram フィード（1:1）／興味関心ファネル

### 前提
- ターゲット：30-40代女性／乾燥肌／スキンケアにこだわる層
- フレーム：PASONA短縮版
- LP：自社EC商品ページ
- オファー：初回30%OFF＋30日返金保証

### プライマリテキスト（118字）

> 朝起きると頬がカサつく、化粧ノリが悪い日が続いていませんか。乾燥が気になる季節に。単一農園の素材で作った保湿化粧水を、30日間試せる返金保証付きで。

### 見出し（25字）

> 朝のカサつきに、30日返金保証。

### 説明（27字）

> 初回30%OFF・送料無料・★4.6

### CTAボタン
詳しくはこちら

### 画像（1:1）
- 主役：化粧水ボトル＋朝の窓辺の光
- サブ：成分名と原料の単一農園写真（小さく）
- 訴求帯：「30%OFF」「30日返金保証」を右下
- テキスト占有率：15%

### A/Bテスト

| 案 | 訴求軸 | 検証する仮説 |
|---|---|---|
| A | 悩み起点（上記PASONA） | 共感アプローチが効くか |
| B | ベネフィット起点：「単一農園素材の保湿化粧水。30代の乾燥肌に、初回30%OFF・30日返金保証で。」 | 商品の核訴求が効くか |
| C | 社会的証明起点：「★4.6 / 1,200件のレビュー。30代乾燥肌に支持される単一農園素材の保湿化粧水。初回30%OFF」 | 数字で信頼を最初に出す案 |

### 法務チェック
- 「保湿」「うるおいを保つ」：化粧品56項目内 OK
- 「あなた」未使用 / 「乾燥が気になる方」客観形 OK
- 「効く」「治る」「シミ消える」未使用 OK
- before/after未使用 OK
- 「30%OFF」二重価格：通常価格でセール開始前8週間中4週間以上の実販売 必要
- 「★4.6 / 1,200件」：レビュー実数を反映

## 例2：機能性表示食品（脂肪対策）／Instagram フィード（1:1）／興味関心

### 前提
- ターゲット：40-50代男女／内臓脂肪が気になる層
- フレーム：BEAF

### プライマリテキスト（122字）

> 40代を過ぎてから、お腹まわりが気になっていませんか。同じ年代に支持されている機能性表示食品（届出番号A123）です。葛の花由来イソフラボンが脂肪を減らすのを助けます。30日返金保証付。

### 見出し（25字）

> 内臓脂肪が気になる方の機能性表示食品

### 説明（25字）

> 届出番号A123・初回70%OFF

### CTAボタン
詳しくはこちら

### 画像（1:1）
- 主役：商品パッケージ＋「機能性表示食品 届出番号A123」帯
- サブ：成分名「葛の花由来イソフラボン」
- 訴求帯：「30日返金保証」

### 法務チェック（最重要）
- 機能性表示食品：**届出番号A123必須**・届出文言と一字一句一致
- 「葛の花由来イソフラボンが脂肪を減らすのを助ける」：届出文言の範囲内
- 「○kg痩せる」「内臓脂肪が消える」NG（届出文言外）
- before/after：NG
- Meta個人属性断定：「40代のあなた」を避け「40代を過ぎてから」と客観形に
- 健康・体型の劇的訴求を避ける

### A/Bテスト

| 案 | 訴求軸 |
|---|---|
| A | 上記（共感→届出→機能） |
| B | 機能ベネフィット先行 |
| C | レビュー・★平均先行 |

## 例3：家電（コードレス掃除機）／Instagram フィード＋リール

### 前提
- ターゲット：集合住宅住みの30代共働き層
- フレーム：BEAF
- LP：自社EC

> 夜21時、階下を気にせず掃除できる。物理ダンパー構造＋低騒音モーター搭載の騒音dB58実測コードレス掃除機。集合住宅住みの30代共働きの方に。3万円台・5年保証・30日返金保証。

### 見出し（24字）

> 夜21時でも気兼ねなし掃除機

### 説明（25字）

> 騒音dB58・5年保証・送料無料

### CTAボタン
詳しくはこちら

### 画像（1:1）
- 主役：商品＋夜の部屋＋騒音dB計測表示
- 訴求帯：「dB58実測／5年保証／30日返金保証」

### リール動画台本（15秒・9:16）

```
[0-3秒] フック
画面：夜21時の暗い部屋＋テロップ「夜の掃除、階下を気にしてませんか？」

[3-8秒] 解決
商品起動シーン＋テロップ「騒音dB58実測＝図書館レベル」

[8-12秒] 証拠
比較表：同価格帯競合機種より-12dB／物理ダンパー構造

[12-15秒] CTA
オファー画面：「3万円台・5年保証／30日返金保証」＋プロフィールリンク誘導
```

### 法務チェック
- 「-12dB」：競合機種・測定条件・測定機関の根拠資料必要（LP側で）
- 「No.1」「絶対静か」「世界最静音」未使用 OK
- 「5年保証」：実運用が伴うこと
- 個人属性断定なし

## 例5：食品ギフト（バスクチーズケーキ）／母の日キャンペーン

### 前提
- ターゲット：母の日ギフト購入層（40-60代女性／60-80代女性に送る）
- 配信期間：4月15日〜5月10日
- 配送締切：5月8日まで
- フレーム：PASONA短縮（Problem→Offer→Action）

### プライマリテキスト（116字）

> 母の日、何を贈ろうか迷っていませんか。職人手作りのバスクチーズケーキを、メッセージカード付きで5月8日までにお届け。母の日限定包装で、特別な日を演出します。送料無料。

### 見出し（24字）

> 母の日に届く職人スイーツ

### 説明（27字）

> 5月8日までお届け・送料無料

### CTAボタン
詳しくはこちら

### 画像（1:1 フィード／9:16 ストーリー）

**フィード（1:1）**：
- 主役：商品＋メッセージカード＋カーネーション
- 訴求帯：「5月8日までお届け／送料無料」

**ストーリー（9:16）動画15秒**：
```
[0-3秒] 「母の日、何贈る？」テロップ
[3-7秒] 包装を開ける手元
[7-12秒] チーズケーキの断面アップ＋「職人手作り」字幕
[12-15秒] 「5月8日までお届け」＋CTA
```

### 法務チェック
- 特定原材料8品目（卵・乳・小麦）：パッケージとLPで明示
- 賞味期限・配送日：商品ページで明示
- 「日本一」「No.1」「最高の」未使用
- ステマ規制：インフルエンサー動画流用時はPR表記・契約で義務化

### 季節キャンペーン特有
- 配送締切（5月8日）を**広告コピーに明記**
- イベント後（5月11日以降）に広告必ず停止
- LP・商品名から「母の日」表記を削除

## 共通：入稿前チェック

- [ ] 個人属性断定（「あなたは○○ですね」）を使っていない
- [ ] 健康・体型の劇的変化訴求を避けている
- [ ] before/after（化粧品・健食）を使っていない
- [ ] 薬機法カテゴリの表現範囲内
- [ ] 機能性表示食品なら届出番号併記
- [ ] No.1・最上級表現に根拠 or 削除
- [ ] 二重価格は8週間ルール
- [ ] LP内容と広告コピーが一致
- [ ] プライマリ125字 / 見出し40字 / 説明30字
- [ ] 画像テキスト占有率20%以内
- [ ] 動画15秒以内＋字幕付与
- [ ] ステマ規制対応（インフルエンサー素材流用時）
