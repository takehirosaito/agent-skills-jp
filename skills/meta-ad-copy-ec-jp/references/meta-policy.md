# Meta広告ポリシー＋薬機法・景表法

Meta特有のリジェクト・配信制限要因と、それを避けるための言い換え。

---

## 個人属性に関する基準（最頻出リジェクト原因）

### NG：個人属性の断定

以下のように個人を**断定・推定**する表現は配信制限：

- 「**あなた**は乾燥肌ですね」
- 「**○歳のあなた**へ」
- 「**敏感肌のあなた**に」
- 「**借金に困っているあなた**へ」
- 「**ハゲ**を解消」
- 「**太っている方**のための」
- 「**40代主婦の方**へ」（断定的）

### OK：客観形の呼びかけ

- 「乾燥が気になる方へ」
- 「○代の女性に」
- 「敏感肌の方に」
- 「家計を見直したい方へ」
- 「髪のボリュームが気になる方へ」
- 「体型が気になる方へ」
- 「40代女性に」（断定でなく対象指示）

### NG/OK 言い換え表

| カテゴリ | NG | OK |
|---|---|---|
| 健康 | あなたの乾燥肌に | 乾燥が気になる方へ |
| 年齢 | 40歳のあなたに | 40代の方へ |
| 体型 | 太っているあなた | 体型が気になる方 |
| 髪 | ハゲのあなた | 髪のボリュームが気になる方 |
| 経済 | 借金に困っているあなた | 家計を見直したい方へ |
| 美容 | 敏感肌のあなた | 敏感肌の方 |
| 精神 | うつ病のあなた | （健康関連は専門家に） |

## 健康・体型訴求の制限

### NG：劇的変化訴求

- 「驚異的な減量」
- 「○kg痩せる」（具体的数値）
- 「劇的に変化」
- 「魔法のような」
- 「ニキビが消える」「シミが取れる」
- before/after（体重・肌）

### OK：穏当な訴求

- 「健康的なライフスタイル」
- 「自分にあった食習慣」
- 「年齢に応じたお手入れ」
- 「気になる方へ」

## Meta広告ポリシー違反時のペナルティ

| ペナルティ | 内容 |
|---|---|
| 広告のリジェクト | 入稿時に拒否 |
| 配信制限 | 既存広告の配信停止 |

| ビジネスマネージャー停止 | 連動するアカウント全停止 |

## 化粧品（薬機法）

### NG（化粧品）
- 「シミに効く／消える／薄くなる」
- 「シワが消える／改善／なくなる」
- 「美白効果」（化粧品では言えない／医薬部外品なら可）
- 「ニキビが治る」（化粧品では言えない）
- 「アンチエイジング」
- 「リフトアップ」
- 「血行促進」
- 「治る／治療／予防」
- 「皮膚科医も推薦」（化粧品適正広告ガイドライン違反）
- before/after画像（メーキャップ・物理効果を除く）

### OK（化粧品）
- 56項目内の効能効果
- 「肌のうるおいを保つ」「保湿」
- 「日やけによるシミ・ソバカスを防ぐ」
- 「乾燥による小ジワを目立たなくする」（試験必要）
- 「肌のキメを整える」「肌荒れを防ぐ」

### 医薬部外品（薬用化粧品）追加でOK
- 「メラニンの生成を抑え、シミ・ソバカスを防ぐ」（美白訴求）
- 「肌荒れを防ぐ」「ニキビを防ぐ」（薬用）
- 容器・包装に「医薬部外品」表示があること

## 健康食品

### 機能性表示食品
- **OK**：届出した機能性表示（届出文言と一字一句一致）
- **必須**：**届出番号を投稿内に明示**
- **NG**：届出文言外の効能訴求

### 一般食品
- **NG**：効能効果の標榜全般
- **NG**：「痩せる／脂肪燃焼／便秘解消／血圧が下がる」
- **OK**：「美しいスタイルを目指す方に」（暗示的）

### NG/OK 言い換え（健食）

| NG | OK |
|---|---|
| 痩せる／脂肪燃焼（一般食品） | 美しいスタイルを目指す方に |
| -5kg達成！ | 機能性表示食品の届出文言以外NG |
| 便秘解消（一般食品） | 毎日のスッキリをサポート |
| 内臓脂肪が消えた | 機能性表示食品の届出文言の範囲のみOK |
| 病気が治った | NG（薬機法違反） |

## 景表法（最上級・No.1）

### NG（景表法）
- 「No.1」「業界最高」「日本初」（根拠なし）
- 「最安値」「最低価格保証」（根拠なし）
- 「絶対」「100%」「完全」「永久」（最上級）
- 二重価格（8週間ルール違反）

### OK
- 「No.1」（根拠5項目を併記）：「○○調べ 2024年4月 楽天市場保湿化粧水部門売上1位」
- 「30日返金保証」（具体的条件）
- 「○年保証」（具体期間）

---

## No.1表記の4要件＋必須5項目

### 4要件
1. 比較する商品等が適切に選定
2. 調査対象者が適切に選定
3. 調査が公平な方法で実施
4. 表示内容と調査結果が適切に対応

### 必須明示5項目
- 調査主体
- 調査期間
- 調査対象
- 調査方法
- 出典

---

## 二重価格 8週間ルール

セール開始**直前8週間**のうち、**過半（4週間以上）**でその通常価格で**実販売**されていた事実が必要。

## ステマ規制（2023.10〜）

- インフルエンサー素材を広告に流用する場合は契約・PR表記
- 「@ブランド名」だけでPR表記なしはNG
- 投稿冒頭または常時表示で「PR」「広告」明示

---

## Branded Content（タイアップ投稿）

- インスタタイアップ投稿機能（Paid Partnership）でブランド設定
- インフルエンサー投稿に「Paid partnership with @ブランド名」が表示

## Meta広告審査でよくあるリジェクト

| 原因 | 対応 |
|---|---|
| 個人属性断定 | 客観形に修正 |
| 健康・体型の劇的訴求 | 穏当な表現に |
| before/after | 削除 |
| 「驚異的な」「劇的に」 | 穏当な表現に |
| No.1根拠なし | 根拠5項目併記 or 削除 |
| 二重価格8週間ルール違反 | 通常価格を見直し |
| LP内容との不一致 | LP修正 or 広告修正 |
| 偽の広告（クリックベイト） | 削除 |
| 16歳未満ターゲティング | ターゲティング修正 |
| 機微なカテゴリ（医薬品・賭博等） | 事前申請 |

---

## 入稿前の最終チェック

- [ ] 個人属性断定（「あなたは○○ですね」）を使っていない
- [ ] 健康・体型の劇的変化訴求を避けている
- [ ] before/after（化粧品・健食）を使っていない
- [ ] 薬機法カテゴリの表現範囲内
- [ ] No.1・最上級表現に根拠 or 削除
- [ ] 二重価格は8週間ルール
- [ ] LP内容と広告コピーが一致
- [ ] 機能性表示食品なら届出番号併記
- [ ] ステマ規制対応（インフルエンサー素材流用時）

---

## 違反時のリカバリー

### 単発リジェクト
- 修正して再入稿
- 過去のリジェクトパターンを記録して再発防止

### 配信制限・アカウント停止
- Meta for Business サポートへの異議申し立て
- 違反内容の改善・証拠提出
- 別アカウントへの避難（メインアカウント停止時）
