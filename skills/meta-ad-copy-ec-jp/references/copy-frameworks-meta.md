# 訴求フレームのMeta向け最適化

PASONA／PREP／BEAF／AIDMA／QUESTをMeta特有の文字数（プライマリ125字／見出し40字／説明30字）に合わせる。

---

## PASONA（パソナ）短縮版

**Problem→Affinity→Solution→Offer→Narrowing→Action**

### Meta プライマリテキスト向け（125字版）

```
[Problem 30字]→[Affinity 25字]→[Solution 30字]→[Offer 20字]→[Narrowing 10字]→[Action 10字]
```

### 例（保湿化粧水）

> 朝起きると頬がカサつく日が続いていませんか（Problem 22字）。30代の乾燥肌の悩みです（Affinity 14字）。単一農園素材の保湿化粧水で肌のうるおいを保ちます（Solution 26字）。初回30%OFF・30日返金保証（Offer 16字）。本日23:59まで（Narrowing 7字）。今すぐ試す（Action 5字）。

合計：約100字。125字以内に収まる。

### 適用シーン
- 興味関心〜比較検討段階
- フィード投稿のプライマリテキスト

---

## PREP（プレップ）

**Point→Reason→Example→Point**

### Meta 見出し＋説明向け

```
[見出し40字]：Point + Reason
[説明30字]：Example + Point
```

### 例（保湿化粧水）

- **見出し（27字）**：「乾燥肌の30代に、単一農園素材の化粧水」（Point + Reason）
- **説明（25字）**：「初回30%OFF・30日返金保証で安心」（Example + Point圧縮）

### 適用シーン
- 短文コピー
- 認知後の購入直前ファネル

---

## BEAF（ビーフ）

**Benefit→Evidence→Advantage→Feature**

### Meta プライマリテキスト向け（125字版）

```
[Benefit 30字]→[Evidence 30字]→[Advantage 30字]→[Feature 30字]
```

### 例（コードレス掃除機）

> 階下を気にせず夜21時に掃除できる（Benefit 17字）。騒音dB58実測＝図書館レベル（Evidence 17字）。同価格帯競合より-12dB（Advantage 14字）。物理ダンパー構造＋低騒音モーター搭載（Feature 22字）。3万円台・5年保証・送料無料。

合計：約95字＋オファー追加で125字以内。

### 適用シーン
- 比較検討段階
- 機能訴求が強いカテゴリ（家電・PC周辺機器）

---

## AIDMA（アイドマ）

**Attention→Interest→Desire→Memory→Action**

### Meta 短文コピー向け

```
[Attention 20字]→[Interest 25字]→[Desire 25字]→[Memory 15字]→[Action 10字]
```

### 例（コスメ）

> 朝のスキンケアに、新しい時間を（Attention 14字）。単一農園素材の保湿化粧水で、肌のうるおいを保ちます（Interest 27字）。30代乾燥肌の方が選ぶ理由を、初回30%OFFで試す（Desire 25字）。30日返金保証付（Memory 8字）。今すぐ試す（Action 5字）。

### 適用シーン
- 認知段階のクラシックな型
- 短いコピー・ストーリー広告

---

## QUEST（クエスト）

**Qualify→Understand→Educate→Stimulate→Transition**

### Meta 動画台本向け（15秒）

```
[Qualify 0-2秒]→[Understand 2-5秒]→[Educate 5-10秒]→[Stimulate 10-13秒]→[Transition 13-15秒]
```

### 例（保湿化粧水・15秒動画）

```
[0-2秒] Qualify
画面：朝の窓辺＋テロップ「30代乾燥肌の方へ」
ナレ：「朝起きるとカサついていませんか」

[2-5秒] Understand
画面：商品クローズアップ
ナレ：「乾燥肌の悩みに寄り添う化粧水ができました」

[5-10秒] Educate
画面：成分図解＋単一農園
ナレ：「単一農園で栽培した素材で保湿成分90%」

[10-13秒] Stimulate
画面：使用シーン＋オファー帯
ナレ：「初回30%OFF・30日返金保証で安心」

[13-15秒] Transition
画面：CTAボタン
ナレ：「気になる方はプロフィールリンクから」
```

### 適用シーン
- 認知〜興味関心
- 動画台本・長文記事広告

## ファネル段階×フレーム適用ガイド

| ファネル | 推奨フレーム | Meta活用 |
|---|---|---|
| 認知 | AIDMA／QUEST | リール・ストーリー動画 |
| 興味関心 | PASONA／QUEST | フィードのプライマリテキスト |
| 比較検討 | PASONA／BEAF | フィードカルーセル・コレクション |
| 購入直前 | PREP／PASONA短縮（Offer→Action） | フィード・リターゲ |
| 再購入 | BEAF | カスタムオーディエンスのリターゲ |

## コピーの「核」を1文に圧縮する技術

どのフレームを使う前にも、まず**核を1文に圧縮**する。

### 公式
> 【ターゲット】に対して、【課題・状況】を【商品名・特徴】が【ベネフィット】する

### 例
> 「乾燥肌の30代」に対して、「朝のカサつき」を「単一農園素材の保湿化粧水」が「30日返金保証で気軽に試せる形で」「肌のうるおいを保つ」

この1文があれば、PASONA・PREP・BEAFどのフレームにも展開可能。

## 配信面別のフレーム選択

### フィード（1:1 or 4:5）
- PASONA・BEAF・QUESTすべて使える
- プライマリテキスト125字を活かす

### ストーリー（9:16）
- 短文・冒頭3秒勝負
- AIDMA・PREP短縮

### リール（9:16）
- QUEST動画台本
- 音楽・テンポ重視

### Audience Network（1.91:1）
- AIDMA短文
- 配信ボリュームは出るがCV質が落ちる

## 文字数別のフレーム適合

| 文字数 | フレーム |
|---|---|
| 10-30字（CTA） | PREP（Point部分のみ） |
| 30-60字（説明） | PREP（Reason+Example圧縮） |
| 60-125字（プライマリ） | PASONA短縮／BEAF |
| 125字超（長文） | PASONA／QUEST |
| 動画15秒 | QUEST／AIDMA |
| 動画30秒以上 | QUEST／BEAF |

---

## A/Bテストでフレームを検証する

- A：PASONA（悩み起点）
- B：BEAF（ベネフィット先行）
- C：社会的証明先行（★平均・件数・受賞）

### 検証の例
| 仮説 | テスト案 |
|---|---|
| 悩み起点が共感を生むか | A：PASONA |
| ベネフィット先行が即決層に刺さるか | B：BEAF |
| 数字で信頼を最初に出すと安心するか | C：「★4.6 / 1,200件のレビュー」を冒頭に |

各案1,000セッション以上で統計的有意性を確認。

## フレームの実装テンプレ

### PASONA短縮 125字テンプレ

```
[1行目フック：悩み描写 20-30字]
[2行目：共感＋商品紹介 30-40字]
[3行目：オファー＋限定性 20-30字]
[4行目：CTA促進 10-15字]
```

### BEAF 125字テンプレ

```
[1行目：核ベネフィット 25-35字]
[2行目：証拠・数字 25-35字]
[3行目：競合優位 20-30字]
[4行目：オファー＋CTA 20-30字]
```

### AIDMA 短文テンプレ

```
見出し（40字）：Attention＋Interest
プライマリ（125字）：Desire＋Memory
説明（30字）：Action
```
