# Google Search Console 活用ガイド

## 主要レポート

### Performance → Search results

主要指標：
- **Total clicks**：SERPからのクリック数
- **Total impressions**：表示回数
- **Average CTR**：クリック率
- **Average position**：平均掲載順位

期間：最大16ヶ月。月次推移を比較可能。

### タブ

| タブ | 内容 |
|---|---|
| Queries | 検索クエリ別 |
| Pages | ランディングページ別 |
| Countries | 国別 |
| Devices | デバイス別 |
| Search appearance | リッチリザルト等 |
| Dates | 日別 |

## Queries タブの活用

### 1. クリック数 TOP10

「最も成果が出ているクエリ」。同じクエリが上位を維持できているか月次でチェック。

### 2. 表示回数 TOP10

「最も検索されているクエリ」。表示は多いがクリックが少ないクエリは機会損失。

### 3. CTR が低いクエリ

平均CTR が業界平均（1-3%）を大きく下回るなら、タイトル・description の改善余地。

### 4. 順位が下がったクエリ

前月／前年同月との比較で順位が低下したクエリは、リライト対象候補。

## Pages タブの活用

### 1. クリック数 TOP10 ページ

最も集客しているページ。これらが商品ページ／コレクションに送れているか確認。

### 2. 機会損失 TOP10 ページ

表示は多いが CTR が低い／コンバージョンに繋がらないページ。

### 3. 新着で順位上昇したページ

新規記事や更新済みページの効果を確認。

## クエリ × ページ マトリクス

「○○というクエリで、どのページに着地しているか」を分析。

期待と違うページに着地している場合：
- 商品ページに着地すべきがブログ記事に着地
- 解説記事に着地すべきが商品ページに着地

→ canonical 設定、内部リンク、KW配分の見直し。

## デバイス別

| デバイス | 比較ポイント |
|---|---|
| Desktop | 詳細検討層、長文記事に滞在 |
| Mobile | 衝動買い、商品ページに直接 |
| Tablet | PC寄り |

モバイル比率の変化を年次で追う（モバイル化の進行）。

## Coverage（カバレッジ）

| ステータス | 内容 |
|---|---|
| Valid | インデックス済み |
| Valid with warnings | 警告あり |
| Error | インデックスされていない |
| Excluded | 除外（noindex 等） |

→ **Error が増えていないか月次チェック**。

### よくあるエラー

- Server error（5xx）
- Not found（404）
- Redirect error（リダイレクトループ等）
- Soft 404
- Blocked by robots.txt
- Crawled - currently not indexed（クロール済み、未インデックス）
- Discovered - currently not indexed

### よくある除外

- noindex
- canonical で別ページを指定
- 重複コンテンツ

## Sitemaps

- sitemap.xml の送信状況
- 検出された URL数
- インデックス済みURL数

Shopify は自動で `/sitemap.xml` を生成。products / collections / pages / blogs / articles の sub-sitemap を含む。

## URL Inspection（URL検査）

特定URL について：
- インデックス状況
- 最終クロール日時
- canonical URL
- ページの問題

→ 「特定の記事がインデックスされない」「順位が突然下がった」時に確認。

## エクスポート方法

各レポート右上の「EXPORT」→ Google Sheets / Excel / CSV。

API 経由（Search Console API）：BigQuery と連携して大量データ処理。

## 月次レポートでの使い方

### A. 月次の表示・クリック・順位推移

| 月 | 表示回数 | クリック | CTR | 平均順位 |
|---|---|---|---|---|
| 2026/02 | 100,000 | 3,500 | 3.5% | 12.3 |
| 2026/03 | 120,000 | 4,800 | 4.0% | 11.5 |
| 2026/04 | 130,000 | 5,600 | 4.3% | 10.8 |

→ 改善方向か、悪化方向かを月次で把握。

### B. 伸びているクエリ Top10

前月比でクリック数が増えているクエリ。施策の効果検証。

### C. 落ちているクエリ Top10

前月比で減っているクエリ。リライト or 競合分析の対象。

### D. 機会損失クエリ Top10

表示は多い（>1,000）が CTR が低い（<1%）クエリ。

→ タイトル・description の改善、または該当ページのリライトで CTR を上げられる。

### E. ジャンル別のクエリ

```
化粧品関連クエリ（美容液 / 化粧水 / クリーム）
アパレル関連クエリ（ワンピース / スニーカー）
ギフト関連クエリ（プレゼント / お祝い）
```

ジャンル単位で勝ち負けを判定。

## Search Console と GA4 の連携

- GA4 の Acquisition → Google Organic Search のセッションは Search Console のクリック数と概ね一致するはず（誤差±10%）
- 大きく乖離している場合は計測設定を確認

## Discover / News（参考）

- Google Discover：パーソナライズフィード
- ニュースタブ：ニュース系の表示
- 自社サイトが対象なら確認
