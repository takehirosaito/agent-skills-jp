# エグゼクティブサマリの書き方

経営層が30秒で意思決定できるサマリを書く。

## 基本構造（3行）

```
1行目：今月の結果（数値・前月比）
2行目：何が良かったか／悪かったか（原因）
3行目：来月の重点アクション（What / Who / When）
```

## 良い例

### 例1：化粧品ストア

```
4月売上 ¥3,200,000（前月比 +12%、前年同月比 +25%）。
母の日特集ブログからの流入が前月比+180%、特集コレクションCVR 4.2%が牽引。
5月は母の日週（5月第2週）の在庫確保と広告強化、父の日企画記事の事前公開（5月下旬）。
```

### 例2：アパレル

```
4月売上 ¥4,800,000（前月比 -5%、前年同月比 +3%）。
モバイルCVRがPC比0.4と業界平均（0.5-0.7）を下回り、特にチェックアウト離脱が要因。
5月はチェックアウトのモバイル最適化（PayPay追加、autocomplete設定）を最優先で実施。
```

### 例3：機能性表示食品

```
4月売上 ¥2,400,000（前月比 +8%、前年同月比 +15%）。
定期購入率が25%まで上昇（前月比+5pt）、LTV/CAC 4.2と健全。
5月は定期購入の解約阻止メール強化と、機能性関与成分別の比較ブログ3本公開。
```

## 悪い例

### 数値だけ並べる

```
4月の売上は前月より増えました。CVRも上がりました。来月も頑張ります。
```

→ 「何が」「なぜ」「次にどうする」が無い。

### 抽象論

```
4月は順調でした。SEO強化を継続します。
```

→ 具体的な数値・原因・アクションが無い。

### 詰め込みすぎ

```
4月売上は前月比+12%、前年同月比+25%、CVRは0.2pt改善、AOVは5,800円から6,200円に上昇、新規顧客数は580人、リピーター比率は42%、Organic Searchが35%構成比、有料広告のCAC は3,800円、LTV/CACは4.5、母の日特集ブログが前月比+180%の流入、商品Aが売上トップ、商品Bが新着、競合のXYZが値上げした影響もありそう...
```

→ 3行に収まらず、結局何が重要か分からない。詳細は本文に。

## 書き方のコツ

### 1. 数値は1-2個まで

サマリに数値を詰め込まない。**売上と前月比・前年同月比** を主軸に。

### 2. 「何が」を1つだけ強調

複数原因があっても、**最も影響が大きかった1つ** に絞る。

### 3. 「来月どうする」を必ず

過去の振り返りだけで終わらせない。**来月の重点アクション** を最後に。

### 4. 数字で語る

「順調」「好調」「不調」より「+12%」「-5%」を使う。

### 5. 用語を統一

経営層が分かる用語：売上・CVR・前月比・前年同月比。**LTV/CAC** は説明が必要かも。

### 6. シーズナリティを明示

「母の日効果」「閑散期」など、季節要因は明示。前年同月比を併記すると説得力アップ。

## 経営層が知りたいこと

| 関心 | サマリで触れるべきか |
|---|---|
| 売上 | 必須 |
| 利益 | 必須（広告費・原価込みの粗利） |
| 在庫 | 必要時（リスクあれば） |
| 競合 | 必要時（影響あれば） |
| 法令変更 | リスクあれば必須 |
| 投資判断 | 来月以降の予算配分に関わる場合 |

## ボリューム

- **CEO 向け**：3行
- **マーケ部長向け**：5-10行（少し詳細）
- **現場担当向け**：10行以上＋詳細レポート

## 書く順番

1. 本文（KPI、ファネル、施策）を書く
2. 最後にサマリを書く（本文の結論を抽出）
3. サマリだけ読んで意思決定できるか自己チェック

## チェックリスト

- [ ] サマリが3-5行に収まっている
- [ ] 売上と前月比・前年同月比が含まれる
- [ ] 主な勝因 or 敗因を1つに絞っている
- [ ] 来月の重点アクションが具体的（What / Who / When）
- [ ] 抽象論（「順調」「好調」）を使っていない
- [ ] サマリだけで経営判断ができる
