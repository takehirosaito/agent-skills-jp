# 異常検知の閾値・判断基準

月次レポートで「何を異常とみなすか」の基準。閾値が明確だと、レポートで取り上げるべきトピックが客観的に決まる。

## 異常の閾値（前月比）

| KPI | 注意レベル | 警告レベル | 重大レベル |
|---|---|---|---|
| 売上 | ±10% | ±20% | ±30% |
| 全体 CVR | ±0.2pt | ±0.5pt | ±1pt |
| セッション | ±10% | ±20% | ±30% |
| AOV | ±5% | ±10% | ±15% |
| カート放棄率 | ±5pt | ±10pt | ±15pt |
| チャネル別売上構成比 | ±5pt | ±10pt | ±15pt |
| CAC | ±10% | ±25% | ±50% |
| LTV/CAC | ±0.5 | ±1.0 | ±2.0 |

## 異常の閾値（前年同月比）

季節調整後の異常。**前年同月比が±20%以上動いた KPI** は要分析。

|---|---|---|

| 主要KW クリック数 | ±20% | ±50% |

## 異常の原因仮説リスト

### 売上が急増した

1. **新規施策の効果**（新商品／キャンペーン／広告投下）
2. **季節要因**（母の日／ボーナス／年末）
3. **メディア露出**（テレビ／SNS／インフルエンサー）
4. **競合のトラブル**（在庫切れ／値上げ）
5. **計測エラー**（重複計測／タグの設定変更）

### 売上が急減した

1. **季節要因**（閑散期）
2. **広告予算の減額／停止**
3. **競合の新規参入／値下げ**
4. **Google アップデートで順位下落**
5. **サイトの障害**（重い／決済エラー／在庫切れ）
6. **計測エラー**（タグ消失／GA4 設定ミス）

### CVR が急低下

1. **流入の質が変わった**（広告予算増 / SNS バズ）
2. **商品在庫切れ**
3. **送料／配送条件の変更**
4. **決済エラー**（特に新規決済方法追加直後）
5. **サイト障害**

### CVR が急上昇

1. **指名検索の増加**（既存顧客流入）
2. **クーポン配布**
3. **広告ターゲティングの精緻化**
4. **新規施策（レビュー導入等）**

### セッションが急減

1. **広告停止**
2. **Google アップデート**
3. **競合の上位獲得**
4. **季節要因**

## 検証手順

### Step 1：異常の事実確認

- 数値の取得日時を確認（24-48時間後の確定データか）
- セグメント別に分解（デバイス／チャネル／新規 vs リピーター）
- 一過性か継続か（日次の推移）

### Step 2：仮説を立てる

- 上記「原因仮説リスト」から候補をピックアップ
- 「もしXが起きていたら、Yの数値も変動するはず」と従属仮説を立てる

### Step 3：従属仮説の検証

例：「Google アップデートで順位下落」が仮説
- Search Console で主要KW順位を確認
- アップデート発表日と一致するか
- 自社業界の他サイトでも同様の動きがあるか

### Step 4：施策の立案

- 原因が特定できれば施策へ
- 特定できない場合は「継続観察」と明示し、来月の判定基準を設定

## 通常変動 vs 異常変動

### 季節要因（無視してよい）

- 化粧品：1-2月（クリスマス後の閑散期）→ 8月（夏のスキンケア需要）
- アパレル：シーズン変わり目
- 食品ギフト：母の日（5月）／お中元（7月）／お歳暮（12月）／お正月（1月）

→ 前年同月比で判断、前月比だけで判断しない。

### イベント要因（事前に予測）

- ボーナス時期（6月／12月）
- 給料日後（25日後）
- セール期間（ブラックフライデー／年末年始）

### 一回限りの要因

- メディア露出（テレビ／雑誌）
- SNSバズ
- 競合の障害

→ 「再現性のない上昇」として注意。継続的施策と区別。

## 仮説立案で外注しがちな質問

「いつから／どこで／なぜ」を必ず確定：

- **いつから**：日次グラフで起点を特定
- **どこで**：チャネル／デバイス／ページ／クエリ別に分解
- **なぜ**：上記の仮説リストから候補抽出

## 良い異常検知レポートの例

> ### 観測：4月20日以降、Organic Search経由のCVRが0.5pt低下
> - 起点：4月20日（Googleコアアップデート発表日と一致）
> - 影響範囲：特定の比較系記事3本（順位 8位→18位）
> - 仮説：競合の新規記事が上位を獲得
> - 検証：競合の新記事を3本確認、専門性が高く出典明確
> - 施策：自社記事のリライト（出典追加・著者プロフィール強化・更新日反映）

## 悪い異常検知レポートの例

> ### 観測：CVR が低下した
> - 原因不明
> - 来月様子を見る

→ 起点・範囲・仮説が無く、施策に繋がらない。
