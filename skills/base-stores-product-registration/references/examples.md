# 商品説明実例 5パターン

ジャンル別の代表的な商品説明文の組立例。文字数は本文部分のみ（HTMLタグ・改行除く）。

## 例1：ハンドメイドアクセサリー（BASE・受注生産）

**前提**：作家1名運営、ピアス／イヤリング、客単価3,000〜6,000円、Instagram流入主軸、受注生産で発送まで7〜14日。

**商品名（55字）**：
14kgf 淡水パール一粒ピアス（イヤリング変更可）/ 受注制作 / mimosa.

**商品説明（約650字）**：

```
[h2] 一粒のパールで毎日が少しだけ華やぐ

一粒の淡水パールを 14kgf（金張り）の繊細なフックで仕立てた、
毎日使えるピアスです。受注いただいてからおひとつずつ
制作しています。

[h2] こんな方に
- オフィスにも普段使いにも合うシンプルな一粒ピアスが欲しい
- 金属アレルギーが心配で 14kgf や silver925 を探している
- 自分用にも、お祝いの贈り物にも使えるものが欲しい

[h2] スペック
- パール：淡水パール 6〜7mm（自然素材のため個体差あり）
- 金具：14kgf フックピアス
- 全長：約2cm
- 重量：約0.5g

[h2] イヤリング変更について
ピアスホールをお持ちでない方は、購入時の「商品オプション」
からイヤリング金具への変更を選んでください。差額は0円です。

[h2] 制作・発送までの目安
ご注文確定後 7〜14日で発送いたします。素材入荷状況により
前後する場合は、ご注文後にメールでご連絡します。

[h2] 配送・ギフト
- メール便（追跡あり・全国一律）
- 宅配便（指定日時可）
- ギフトボックス無料

[h2] 返品・交換について
自然素材のため、パールの色味・形状にわずかな個体差があります。
イメージ違いによる返品はお受けしておりませんが、初期不良
（金具不良・破損）の場合は到着後7日以内にご連絡ください。
```

**Apps構成**：カテゴリ管理・商品オプション・送料詳細設定・レビュー・Instagram連携

## 例4：コスメ（BASE・スキンケア）

**前提**：D2Cスキンケアブランド、保湿クリーム、化粧品分類。

**商品名（42字）**：
モイスチャライズクリーム 30g / 全肌質対応 / hana skin

**商品説明 冒頭（350字／薬機法配慮済）**：

```
[h2] みずみずしさが続く、毎日の保湿クリーム。

うるおいを与えながら、肌をすこやかに保つ
デイリーユースの保湿クリームです。

[h2] こんな方に
- 朝晩のスキンケアの最後に使うクリームを探している
- 季節の変わり目に肌の乾燥が気になる
- 軽い使い心地のクリームが好み

[h2] 使い方
化粧水・美容液で肌を整えたあと、適量（パール粒大）を
手のひらにとり、顔全体になじませてください。

[h2] 容量
30g（約2ヶ月分・1日2回使用の目安）

[h2] 全成分
（成分名をすべて表記）

[h2] ご注意
- 傷・湿疹など異常のある部位にはご使用にならないでください
- 使用中・使用後に赤み・かゆみ等の異常があらわれた場合は使用を
  中止し、皮膚科医にご相談ください
- 直射日光のあたる場所、極端に高温または低温の場所を避けて保管
```

**ポイント**：「シミが消える」「美白」「アンチエイジング」等の **化粧品の効能効果56項目を超える表現は使わない**。詳細は `yakki-keihyo-expression-check` スキル併用。

**Apps構成**：カテゴリ管理・レビュー・メルマガ配信・定期便（リピート購入用）

## 例5：デジタルコンテンツ（BASE・PDFテンプレート販売）

**前提**：個人クリエイター、Notion/Excelテンプレート販売、客単価500〜2,000円。

**商品名（38字）**：
家計管理 Notion テンプレート / 月次・年次集計 / v2.0

**商品説明 冒頭（300字）**：

```
[h2] 家計を「続けられる」シンプル設計。

家計簿を続けるためのNotionテンプレートです。月次の収支を
入力するだけで、年次集計・カテゴリ別グラフが自動で更新
されます。

[h2] 含まれるもの
- Notionテンプレート（URL招待制）
- セットアップガイド（PDF・全12ページ）
- カテゴリマスタExcel（参考）

[h2] 対応環境
- Notion 無料プラン以上
- ブラウザ／デスクトップアプリ／モバイルアプリ

[h2] 使い方の概要
1. 商品購入後、ダウンロードURLをメールでお送りします
2. Notionで「複製」ボタンを押し、自分のワークスペースへ
3. セットアップガイドに従い、初期カテゴリを編集

[h2] ご利用にあたって
- データの性質上、購入後のキャンセル・返金はお受けできません
- ご購入1アカウントにつき1名様での利用に限ります
- テンプレートの再配布・転売はお断りいたします
```

**Apps構成**：デジタルコンテンツ販売（必須）・カテゴリ管理・メルマガ配信

**注意**：デジタルコンテンツは **返品不可ポリシー** を商品説明・特商法表記の両方に明記する。
