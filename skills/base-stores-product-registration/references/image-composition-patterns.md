# ジャンル別 画像20枚構成パターン

BASE / STORES は商品画像を最大20枚まで登録できる（BASEの場合）。20枚を最大限活かす構成案をジャンル別に示す。

撮影リソースが限られる場合は **1〜8番** までを優先する。

## 撮影リソースが限られるとき

20枚を埋めようとしてクオリティの低い画像を入れると逆効果。次の優先順位で撮る：

1. メイン（白背景）
2. メイン（ライフスタイル）
3. ディテール
4. サイズ感（対比物あり）
5. パッケージ／同梱物
6. バリエーション
7. 使用シーン
8. SNS転用素材

不足分は文字＋シンプル背景の画像（仕様表・FAQ・配送案内）で補えば、見せ場のある商品ページになる。
