# BASE 商品登録項目の完全リスト

BASE管理画面「商品管理 → 商品を登録」で扱う項目を整理する。仕様は変更されることがあるため、最終的には BASE 公式ヘルプ・管理画面の項目表示で確認すること。

## 基本項目

| 項目 | 必須 | 内容 | 補足 |
|---|---|---|---|
| 商品名 | 必須 | 商品のタイトル | SNS共有時のOGPタイトル・カートサムネのキャプションに使われる。型番羅列より「ブランド+商品個性+種別」推奨 |
| 商品説明 | 必須 | 本文 | 簡易HTML可。h2/h3/p/strong/em/img/br/a など基本タグ。インラインCSSは控えめに。最低限の構造で書く |
| 価格 | 必須 | 税込／税抜表記はストア設定に準ずる | 単一価格。バリエーション別の価格差はバリエーション側で設定 |
| 在庫数 | 必須 | バリエーション別の場合はバリエーション側で個別管理 | 在庫切れ自動表示／非表示 |
| 商品画像 | 必須 | 最大20枚 | 1枚目がサムネイル。推奨は1280px以上の正方形 |
| バリエーション | 任意 | 種類（色／サイズ／タイプ等） | 1商品最大複数バリエーション。バリエーションごとに在庫と価格差 |
| カテゴリ | 任意 | カテゴリ管理App導入で最大3階層 | 1商品が複数カテゴリに所属可 |
| 商品ステータス | 必須 | 公開／下書き／非公開 | 販売期間Appと組合せで予約公開可 |
| 発送目安 | 推奨 | テキスト記述（例：「ご注文後3〜5営業日」） | ハンドメイド・受注生産は必ず明記 |
| 送料 | ストア共通設定 or 個別 | 送料詳細設定Appで地域別・重量別が可能 |  |

## HTMLタグの取り扱い

- 使用可：見出し(h2/h3)、段落(p)、改行(br)、強調(strong/em)、画像(img)、リンク(a)、リスト(ul/ol/li)、表(table)
- 過剰なインラインCSSやJavaScriptは推奨されない
- スマホ表示のため、横幅固定のtableは避け、シンプルな縦並びにする
- 画像は `references/image-composition-patterns.md` の構成に合わせて差し込み

## 文字数の目安

- 商品名：60字以内が読みやすい（管理画面の入力上限とは別の目安）
- 商品説明：本文は1,500〜3,000字程度が読了されやすい。長すぎる仕様羅列はテーブル化
- 発送目安：30字以内で1行で完結

## バリエーション設計のコツ

- 色／サイズ／タイプを軸に最大組合せ数を確認
- 例：色5×サイズ4＝20バリエーション
- バリエーション間で重量・送料が変わる場合は、送料詳細設定Appで重量別を有効化
- SKU命名規則は社内マスタと統一（例：`MIM-EAR-PEARL-14KGF-IY`）

## 商品ステータスの使い分け

- 公開：販売中
- 下書き：作成途中、ストア上に表示されない
- 非公開：完成済だが一時非表示（販売停止・在庫切れ）
- 販売期間設定App：公開日時の予約／販売終了日時の自動切り替え

## 注意点

- BASE は **商品ページ自体のSEO力はモールに比べて弱い** ため、商品名・商品説明の検索キーワード詰込みは効果が薄い。SNS／指名買いを前提に、読みやすいコピーで書く
- 楽天・Amazonの商品名（型番・属性詰込み）をそのままBASEに転用すると、ブランドの世界観が崩れる
- 商品説明のHTMLは管理画面のリッチエディタとソース編集を行き来する際に余計なタグが残ることがある。公開前にプレビューで確認
