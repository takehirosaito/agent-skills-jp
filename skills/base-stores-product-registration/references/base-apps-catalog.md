# BASE Apps 代表機能カタログ

BASE は本体機能を絞り、Apps（拡張機能）で必要な機能を後から追加する設計。多くは無料、一部に有料 Apps がある。

仕様・課金は変更されるため、導入前に **管理画面の Apps一覧／公式ヘルプ** で最新確認すること。

## 商品登録・在庫まわり

| Apps | 用途 | 課金（執筆時点） | 利用シーン |
|---|---|---|---|
| カテゴリ管理 | 商品カテゴリを最大3階層で作成 | 無料 | 商品数が増えてきた、ジャンル分けしたい |
| CSV商品管理 | 商品の一括登録・更新・在庫変更 | 無料 | 商品数100以上、定期的に大量更新する |
| 商品検索（ショップ内） | ストア内検索窓 | 無料 | 商品数50以上で必須レベル |
| 商品オプション | バリエーション以外の自由入力（名入れ、メッセージカード等） | 無料 | ハンドメイド・ギフト・受注対応 |
| バリエーション画像 | バリエーション選択時に画像を切替 | 無料 | 色違い・素材違いを視覚的に伝える |

## 販売条件まわり

| Apps | 用途 | 課金 |
|---|---|---|
| 配送日設定 | 注文時に希望配送日を選ばせる | 無料 |
| 送料詳細設定 | 地域別・重量別・商品別の送料 | 無料 |
| 販売期間設定 | 商品の公開開始／終了日時の自動設定 | 無料 |
| 予約販売 | 在庫の入荷前に受注、発送予定日を表示 | 無料 |
| デジタルコンテンツ販売 | データ販売（音源・PDF・画像など） | 無料 |
| 数量限定販売 | 1回の注文で購入できる個数制限 | 無料 |
| メンバーシップ | 会員限定価格・会員専用商品 | 一部有料／プラン依存 |
| 定期便（サブスク） | 定期購入販売 | 有料 |

## Apps の選び方の目安

ストアの状態別に「最初に入れるべき Apps」を提示する。

### スタート時（商品10点未満・個人作家）
- カテゴリ管理（任意：商品が増えてきたら）
- レビュー
- Instagram連携
- 送料詳細設定（メール便と宅配便で分けるなら必須）

### 商品100点超え
- CSV商品管理（必須レベル）
- 商品検索
- 商品オプション（カスタム対応の商品があれば）

### 季節商品・予約販売中心
- 販売期間設定
- 予約販売
- 数量限定販売

### デジタル販売中心
- デジタルコンテンツ販売（必須）
- 返品不可ポリシーの記載が前提

### 定期売上を伸ばす段階
- メルマガ配信
- クーポン
- メンバーシップ
- 定期便（サブスク）

## 注意点

- **Apps の有効化と無効化はストア全体に影響する**。Apps無効化により商品ページの表示や設定が消える場合があるので、無効化前に影響範囲を確認
- **有料 Apps の課金は月額制が多い**。利用していない期間も課金が続く場合があるため、定期的に Apps 棚卸し
- 「定期便（サブスク）」は **特商法の定期購入規制（2回以上）** の対象。契約期間・解約条件・総額表示などの記載義務に注意
