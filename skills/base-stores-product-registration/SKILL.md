# BASE / STORES 商品登録

## 概要

BASE と STORES ネットショップは「個人作家・小規模事業者の主戦場」となる軽量カート。本スキルは、両カートの仕様前提で商品ページ（商品名・商品説明・画像構成・バリエーション・送料説明）の文案を組み立てる。

両者は思想が異なる。BASE は本体機能を絞り Apps で拡張する軽量モデル、STORES は機能内蔵＋POSレジ／予約システム連携が強い中規模向け。本スキルは **BASE を主たる前提** にし、STORES の場合は差分を明示する。

商品名・本文の検索キーワード詰込みは効果が薄いカートのため、SNS／指名買い／ブランド世界観前提のコピーで設計する。

## ★最重要原則

**「Apps と画像20枚を前提に、SNS指名買いで読みやすいコピーを書く」**。BASE のSEO力は楽天・Amazonに比べて弱いため、商品名・本文を型番＋属性で詰め込まずに、ブランドトーンと購入判断要素（素材・サイズ・納期・返品）を1スクロールで読める形に組む。BASE の場合は **Apps 構成提案（カテゴリ管理／商品オプション／送料詳細設定／レビュー／Instagram連携など）も必ずセットで出す**。

## 処理フロー

### Step 1：前提整理（仮置きOK）

最初に以下を確認。情報不足でも止まらず仮置きで進める：
- カート：BASE か STORES か（不明なら BASE 仮定、冒頭で明示）
- ジャンル：アパレル／アクセ／食品／コスメ／雑貨／デジタル
- 販売形態：既製品／受注生産／ハンドメイド／予約販売／定期便
- 客単価帯・流入主軸（Instagram／自然検索／既存顧客）
- ブランドトーン（カジュアル／上品／ナチュラル等）

### Step 2：商品名を組む

構造：**[ブランド名] + [商品個性] + [種別] + [必要な属性]**
- 60字以内で1行完結（管理画面上限とは別の読みやすさ目安）
- 楽天的な「型番＋属性キーワード詰込み」は避ける
- SNS共有時のOGPタイトルに使われる前提で書く

### Step 3：商品説明本文を組む

構造（1,500〜3,000字推奨）：
1. リード（h2）：商品が「誰の」「どんな悩みや欲求」に応えるか1〜2文
2. こんな方に（箇条書き3〜5項目）
3. スペック（素材／サイズ／重量／対応／原産国）
4. （受注／ハンドメイドの場合）制作・発送までの目安を必ず明記
5. 配送・ギフト
6. 返品・交換の条件

BASE のリッチエディタはHTMLが残りやすい。`h2/h3/p/strong/em/img/br/a/ul/ol/li/table` のみで構成し、インラインCSSは控える。

### Step 4：画像20枚構成を提案

`references/image-composition-patterns.md` のジャンル別テンプレを基に、20枚（または撮影リソースで8枚優先）の役割を表で提示。1枚目はサムネ用の白背景。

### Step 5：バリエーション・オプション設計

- バリエーション：色／サイズ／タイプの組合せ数を確認（例：色5×サイズ4＝20）
- 価格差がある場合はバリエーション側で設定
- 受注生産・ギフト対応・名入れ等は **商品オプションApp** で別軸の自由入力にする（BASE）
- SKU命名規則は社内マスタと統一

### Step 6：送料・配送・返品の表記

- 送料詳細設定App（BASE）で地域別・重量別・商品別に分けるかを判定
- ハンドメイド／受注生産は **納期を必ず明記**（「ご注文後7〜14日で発送」など）
- 返品条件を曖昧にしない。返品不可なら理由（自然素材／衛生上）を添える
- 特商法表記ページとの整合を確認

### Step 7：Apps構成の提案（BASEの場合）

商品状態に応じた推奨 Apps セットを出す：
- スタート時（10商品未満）：レビュー／Instagram連携／送料詳細設定
- 商品100点超：CSV商品管理／商品検索／商品オプション
- 季節商品：販売期間設定／予約販売／数量限定販売
- デジタル販売：デジタルコンテンツ販売（必須）
- 定期売上強化：メルマガ／クーポン／メンバーシップ／定期便

定期便（サブスク）を使う場合は **特商法の定期購入規制（2回以上）** が必ずかかるため、契約期間・解約条件・総額表示を本文に明記する旨を注記。

### Step 8：SNS転用文（任意）

Instagram キャプション用に、商品説明から140〜280字の抜粋＋ハッシュタグを別途出す。

## 代表例：ハンドメイドアクセサリー（BASE・受注生産）

**前提**：作家1名運営、ピアス、客単価3,000〜6,000円、Instagram流入、受注生産7〜14日。

**商品名（55字）**：
14kgf 淡水パール一粒ピアス（イヤリング変更可）/ 受注制作 / mimosa.

**説明文（抜粋・約220字）**：
```
[h2] 一粒のパールで毎日が少しだけ華やぐ

一粒の淡水パールを 14kgf（金張り）の繊細なフックで仕立てた、
毎日使えるピアスです。受注いただいてからおひとつずつ
制作しています。

[h2] スペック
- パール：淡水パール 6〜7mm（自然素材のため個体差あり）
- 金具：14kgf フックピアス
- 全長：約2cm

[h2] 制作・発送までの目安
ご注文確定後 7〜14日で発送いたします。
```

**Apps構成**：カテゴリ管理／商品オプション（イヤリング変更）／送料詳細設定／レビュー／Instagram連携

他ジャンルの完全な実例は `references/examples.md`（既製品アパレル／食品ギフト／コスメ／デジタルコンテンツ）を参照。

## 品質ゲート

このスキル固有のチェック：

- [ ] BASE か STORES か（不明なら BASE 仮定の明示があるか）
- [ ] 画像20枚構成が **そのカートの上限内**（BASE：最大20、STORES：仕様確認）
- [ ] 受注生産／ハンドメイドの場合、納期明記がある
- [ ] 返品条件を「曖昧」「お受けできかねます」だけで終わらせていない
- [ ] BASE の場合、Apps 構成提案がセットになっている
- [ ] 商品オプション App と バリエーション の役割が混在していない
- [ ] SNS流入前提の読みやすさ（1段落3〜5行・h2区切り）
- [ ] 薬機法（化粧品の効能効果56項目／健康食品の4分類）を逸脱していない
- [ ] 景表法（最安／No.1／二重価格8週間ルール）を逸脱していない

## エッジケース

- **ハンドメイドで「制作期間が決まらない」**：「制作状況により○〜○日」と幅で明記、最長14日超なら問い合わせ導線必須
- **デジタルコンテンツ販売**：BASEは専用Appsが必須、返品不可ポリシー明記が前提
- **海外販売**：BASE海外販売App／STORES越境対応プランの仕様確認、関税・送料の事前明示
- **カラーバリエーション5以上**：バリエーション画像App（BASE）／バリエーション別画像（STORES）を活用
- **ギフト需要が主**：のし・メッセージカード・包装オプションを「商品オプションApp」で別軸化

詳細・追加例は `references/base-apps-catalog.md` と `references/examples.md` を参照。

## 注意事項

- BASE／STORES の **画像点数上限・カテゴリ階層・HTMLタグ対応範囲・Apps課金** は仕様変動が激しい。本ファイルの記述は2026年5月時点の整理であり、最終的に管理画面と公式ヘルプで最新確認すること
- BASE Apps の **有効化／無効化はストア全体に影響**。無効化前に影響範囲を必ず確認
- 「定期便（サブスク）」は **特商法の定期購入規制（2回以上）** 対象。契約期間・解約条件・総額表示の記載義務を逸脱しない
- 商品ページ本文に「最安」「No.1」「絶対」「治る」「保証」等の断定表現を入れない
- 法律・税務・規約の最終判断は専門家／各プラットフォーム公式情報で確認
- ログイン情報・顧客個人情報・秘密情報は出力例にも保存しない
