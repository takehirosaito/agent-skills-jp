## 例1：メンズ二つ折り財布

**現状（全角約74文字）**：
```
【楽天1位獲得！送料無料！】★人気★ ポーター 財布 PORTER 二つ折り 本革 牛革 メンズ プレゼント ギフト 父の日 母の日 おしゃれ かっこいい
```

**問題**：
- 先頭13文字を他モール訴求＋装飾★で消費
- 「母の日」がメンズ財布にはノイズ
- 装飾★が2セット

**改善A案（全角74文字）**：
```
ポーター 二つ折り財布 メンズ 本革 牛革 PORTER ブラック 父の日 ギフト プレゼント おしゃれ 大容量 カードたくさん 通勤 ビジネス
```

**改善B案（全角74文字）**：
```
ポーター メンズ 二つ折り財布 本革 父の日 ギフト プレゼント PORTER 牛革 黒 大容量 カードがたくさん入る ビジネス 通勤 ブランド
```

**改善C案（指名買い特化・全角73文字）**：
```
PORTER ポーター 二つ折り財布 タンカー ヒート 本革 メンズ 黒 ネイビー カモ 公式 正規品 ギフト 父の日 大容量 カード
```

## 例2：化粧水（化粧品カテゴリ）

**現状（全角約62文字）**：
```
シミに効く！高保湿化粧水 美白 アンチエイジング 30代 40代 乾燥肌 大容量 200ml
```

**問題**：
- 「シミに効く」→ 薬機法違反（化粧品で効能断定NG）
- 「美白」→ 化粧品ではNG（医薬部外品のみ）
- 「アンチエイジング」→ NG
- 文字数余裕あり

**改善A案（全角72文字）**：
```
化粧水 高保湿 200ml 大容量 セラミド配合 エイジングケア 30代 40代 乾燥肌 敏感肌 詰め替え 国内製造 無香料 アルコールフリー
```

**改善B案（全角73文字）**：
```
化粧水 200ml 保湿 セラミド エイジングケア 大容量 詰め替え 乾燥肌 敏感肌 日やけ後のお手入れ 弱酸性 無香料 国産 ギフト
```

## 例3：ワイヤレスヘッドホン（家電）

**現状（全角約45文字）**：
```
SONY WH-1000XM5 ヘッドホン ワイヤレス ノイキャン 高音質 黒
```

**問題**：
- 文字数余裕大きい（30文字以上余白）
- 「ノイキャン」より「ノイズキャンセリング」の方が検索ボリューム大

**改善A案（全角74文字）**：
```
SONY ソニー WH-1000XM5 ワイヤレスヘッドホン ノイズキャンセリング Bluetooth 5.2 30時間再生 ブラック 高音質 通勤 リモート会議
```

## 例4：明太子（食品）

**現状（全角約30文字）**：
```
博多明太子 並切 500g 福岡 国産 痩せる 健康
```

**問題**：
- 「痩せる」→ 一般食品で効能訴求不可（健康増進法・景表）
- 「健康」も曖昧で抵触リスク
- 文字数大幅余裕

**改善A案（全角74文字）**：
```
明太子 並切 500g 博多 福岡 ふくや 国産 ご飯のお供 おにぎり お弁当 おつまみ お取り寄せ グルメ ギフト 父の日 母の日 内祝い
```

## 例5：レディースワンピース（アパレル）

**現状（全角約50文字）**：
```
【楽天1位】夏ワンピース レディース 韓国風 きれいめ M L XL かわいい おしゃれ
```

**問題**：
- 楽天1位 → 削除
- 装飾【】1セットは可だが「楽天1位」がNG
- 文字数余裕あり

**改善A案（全角74文字）**：
```
ワンピース レディース 夏 韓国 きれいめ カジュアル ロング マキシ丈 半袖 ノースリーブ M L XL 大きいサイズ オフィス 通勤 デート
```

**改善B案（用途特化・全角73文字）**：
```
ワンピース レディース きれいめ 夏 オフィス 通勤 30代 40代 韓国風 ノースリーブ ロング丈 M L XL 体型カバー シンプル 上品
```

## まとめ：3案を出す型

| 案 | 重視 | 先頭25文字 |
|---|---|---|
| A | 検索ボリューム（一般語多め） | 指名語＋商品タイプ＋最重要属性＋対象 |
| B | 購買意欲（用途・シーン） | 商品タイプ＋対象＋用途語 |
| C | 指名買い（ブランド・モデル既知） | ブランド＋モデル＋型番＋商品タイプ |

各案ともに：
- 全角70〜75文字を使い切る
- 装飾記号最小
- 他モール訴求なし
- 薬機・景表抵触なし
