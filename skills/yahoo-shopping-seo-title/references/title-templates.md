# Yahoo!商品名 先頭25文字テンプレ／カテゴリ別キーワード順序

## 基本構造（全角75文字）

```
[先頭25文字：指名／商品タイプ／最重要属性／対象] [中盤25文字：サブ属性・サイズ・差別化] [末尾25文字：用途・シーン・表記揺れ]
```

各ブロックは目安。ジャンルにより重みが変わる。

---

## カテゴリ別 推奨順序

### 1. アパレル（メンズ／レディース／キッズ）

```
[商品タイプ] [対象] [素材] [色] [サイズ] [シーン] [スタイル] [ブランド／指名]
```

例：`Tシャツ メンズ 半袖 綿100% オーガニックコットン 白 黒 ネイビー L XL XXL 大きいサイズ 父の日 ギフト 無地 シンプル`

注意：
- 「コーデ」「韓国風」「きれいめ」等のスタイル語が検索される
- 大きいサイズ／背が高い／ぽっちゃり等の体型ワードを末尾に
- 色名はカタカナ＋漢字＋英字の3表記揺れを入れすぎない（1〜2色＋shopping-search-keywords で揺れカバー）

### 2. 家電・PC・周辺機器

```
[ブランド] [型番] [商品タイプ] [機能1] [機能2] [容量／サイズ] [対応OS／規格] [色] [用途]
```

例：`SONY ソニー WH-1000XM5 ワイヤレスヘッドホン ノイズキャンセリング Bluetooth 5.2 30時間再生 ブラック 通勤 リモート会議 高音質`

注意：
- 型番は半角・大文字で
- 「Bluetooth」「Wi-Fi」「USB-C」等の規格は必須属性
- 互換機種・対応OS（iPhone 15／Windows 11 等）はサブ属性

### 3. 食品・スイーツ・飲料

```
[商品タイプ] [ブランド／産地] [原材料] [容量／個数] [シーン／用途] [賞味期限・冷凍/冷蔵]
```

例：`ふくや 明太子 並切 500g 福岡 博多 国産 ご飯のお供 おにぎり お弁当 お取り寄せ グルメ ギフト 父の日`

注意：
- 産地・ブランド・原材料は信頼性キーワード
- 容量・個数は必須（500g／12本／30個）
- 効能訴求語（"痩せる"／"血糖値"）は使わない（健康食品4分類による）

### 4. コスメ・美容

```
[ブランド] [商品タイプ] [シリーズ] [容量／サイズ] [特徴] [対応肌] [色番／色名]
```

例：`資生堂 化粧水 アクアレーベル しっとり 200ml 保湿 敏感肌 乾燥肌 エイジングケア 詰め替え 国内正規品`

注意：
- 「美白」は医薬部外品の承認文言。化粧品でNG → 「日やけによるシミ・ソバカスを防ぐ」
- 「アンチエイジング」NG → 「エイジングケア」OK（年齢に応じたお手入れ）
- 効能断定（治す／消える）は禁止

### 5. 日用品・キッチン・インテリア

```
[商品タイプ] [素材] [サイズ／容量] [色] [機能] [シーン] [ブランド]
```

例：`タオル バスタオル 今治 4枚セット 60×120cm 綿100% ホワイト ベージュ 速乾 抗菌 大判 ホテル仕様 ギフト`

### 6. 書籍・CD・DVD・ゲーム

```
[タイトル] [著者／アーティスト] [出版社／レーベル] [シリーズ／巻数] [発売年] [形式]
```

例：`鬼滅の刃 全23巻セット 吾峠呼世晴 集英社 ジャンプコミックス 完結 新品`

注意：
- 書籍の場合、product-code は ISBN（978/979始まり）
- 書籍は装飾語ほぼ不要

### 7. ベビー・キッズ・マタニティ

```
[商品タイプ] [対象月齢／サイズ] [素材] [安全規格] [色／柄] [機能] [シーン]
```

例：`ベビー服 70cm 80cm 男の子 女の子 オーガニックコットン 出産祝い ギフト 春夏 半袖 ロンパース 新生児`

### 8. ペット用品

```
[商品タイプ] [対象動物] [サイズ／体重] [素材] [機能] [年齢] [ブランド]
```

例：`猫 トイレ 大きめ フード付き ホワイト ベージュ 大型猫 多頭飼い アイリスオーヤマ 飛び散り防止 砂落とし`

## 先頭25文字 ピッキング

| 含めたい4要素 | 例 |
|---|---|
| 指名語（ブランド・モデル） | ポーター／SONY／資生堂 |
| 商品タイプ | 財布／ヘッドホン／化粧水 |
| 最重要属性 | 本革／ノイズキャンセリング／200ml |
| 対象 | メンズ／レディース／敏感肌 |

例：`ポーター 二つ折り財布 メンズ 本革`（全角17文字、先頭25文字に余裕）

## 表記揺れの吸収

| 商品 | 商品名（1表記） | shopping-search-keywords（揺れ） |
|---|---|---|
| 革財布 | 本革 | 牛革 レザー 革製 |
| ワイヤレスイヤホン | ワイヤレスイヤホン | Bluetoothイヤホン bluetooth イヤホン無線 |
| 化粧水 | 化粧水 | スキンローション lotion 美容液 |
| 折りたたみ傘 | 折りたたみ傘 | 折り畳み傘 折畳傘 |

商品名に表記揺れをすべて入れず、shopping-search-keywords で吸収する。

---

## 75文字を最大限使うコツ

- カテゴリで決まる属性（"レディース服" → サイズ展開／素材／シーン）を網羅
- 用途・シーン語（プレゼント／父の日／通勤／登山）を1〜2個
- ターゲット属性（敏感肌／背が低い／40代）を必要なら1個
- 余ったら表記揺れではなく**ロングテール語**（「カードたくさん入る」「がま口」等）
