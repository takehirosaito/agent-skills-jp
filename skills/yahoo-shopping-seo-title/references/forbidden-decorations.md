# 商品名で避けるべき記号・装飾・NG表現

## 1. 装飾記号（基本不使用）

| 記号 | 理由 |
|---|---|
| ★☆◆◇♪♥♡ | 検索ヒットしない／視認性低下／煽り |
| 【】《》『』 | 1〜2セットは可、過剰使用は避ける |
| ！？！！？？ | 商品名末尾の感嘆符は基本不要 |
| ※ | 注釈は caption へ |
| ❤❤ ✨🎁 | 絵文字はShift_JISで化けるリスク／視認性 |

許容範囲：`【】` を1セット（例：`【正規品】`）まで。2セット以上は避ける。

## 2. 半角カナ・機種依存文字

| 種別 | 例 | 代替 |
|---|---|---|
| 半角カナ | ﾒﾝｽﾞ ﾚﾃﾞｨｰｽ | メンズ レディース |
| 丸数字 | ①②③ | (1)(2)(3) |
| 括弧株 | ㈱ | (株) |
| ローマ数字 | ⅠⅡⅢ | I II III |
| 単位記号 | ㎜㎝㎏ | mm cm kg |

## 3. 薬機抵触（化粧品・健康食品で要注意）

化粧品で**断定的に使ってはいけない**：
- 治る／治す／治療／予防／改善
- シミが消える／シワが消える
- アンチエイジング → **エイジングケア**（年齢に応じたお手入れ）はOK
- 美白 → 化粧品でNG。医薬部外品（薬用化粧品）のみ可
- アトピー／ニキビが治る
- 細胞活性化／DNA／幹細胞

健康食品で**断定的に使ってはいけない**：
- 痩せる／脂肪燃焼／代謝アップ（一般食品・サプリ）
- 血糖値が下がる／血圧が下がる（機能性表示・トクホの届出文言なら可）
- 便秘解消／不眠解消
- 効能効果の標榜全般（一般食品）

機能性表示食品の場合：**消費者庁データベースの届出文言を一字一句変えずに**書く。「機能性表示食品（届出番号XXX）」を併記。

## 4. 景表抵触（最上級・絶対的表現）

根拠なき断定はNG：

- 最安／最安値／業界最安
- 業界No.1／日本No.1（根拠5項目：主体・期間・対象・方法・出典が必須）
- 完全／完璧／絶対／100%（"綿100%" のような客観事実はOK）
- 必ず／間違いなく
- 保証する（商品保証の規約説明は別）
- 唯一／日本初／日本唯一（根拠必要）
- すべての方に／誰にでも

## 5. 他モール訴求

Yahoo!ショッピングの商品名に書かない：

- 楽天1位 / 楽天デイリーランキング / 楽天市場で人気
- Amazon's choice / Amazonで人気
- 「○○モール 1位」（出店モール名以外の言及）

理由：
- Yahoo!の表現ガイドライン上、他モール訴求は問題視され得る
- 検索意図と無関係でユーザーに不便
- Yahoo!の検索アルゴリズムにもプラスに働かない

## 6. 性別・年齢・国籍など差別的表現

- 老人／お年寄り → シニア／高齢者
- ハーフ／ガイジン → 海外の方／英語表記対応
- 黒人／白人 → 不要なら使わない
- 肌色（クレヨンの色名） → ペールオレンジ／ベージュ

## 7. 商標・他社ブランド名の無断使用

- 「○○風」「○○タイプ」など類似表現も商標権侵害リスク
- 正規取扱なら「○○ 正規品」OK、互換品の場合は「互換」「○○対応」と明示

## 8. 過度な煽り（媒体ポリシー上のグレー）

- 「在庫処分」「アウトレット」「訳あり」は実態と一致すればOK、煽り目的のみで使うのは×
- 「期間限定」「数量限定」は具体的に（「2024/12/31まで」「先着100名」）

## 9. メーカー指定価格・OPEN価格に対する記載

- 「定価12,000円」と表記する場合、メーカー希望小売価格／メーカー設定価格との整合性必須
- OPEN価格商品に勝手に「定価」を書かない（二重価格表示違反）

---

## まとめ：商品名に**入れていい記号**は基本これだけ

- 全角スペース／半角スペース（区切り）
- 半角ハイフン `-`（型番）
- 半角スラッシュ `/`（区切り）
- 半角・全角カッコ（最小限）
- 半角・全角数字
- 中黒 `・`（区切り）
- 「」（強調最小限）
