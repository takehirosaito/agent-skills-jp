# Yahoo!ショッピング商品名SEO

## 概要

Yahoo!ショッピングの検索流入は、商品名（name・全角75文字／150byte）と検索キーワード欄（shopping-search-keywords）の設計で決まる。Yahoo!は楽天と異なりPRオプション率の影響が小さく、「商品名内に主要KWが入っているか」「ジャンル（product-category）と整合しているか」「検索ノイズになる装飾語が少ないか」の3点が中核ロジック。

このスキルは、商品名の構造化（指名語／属性語／用途語の分離）、装飾記号の除去、全角75文字の有効活用、そして表記揺れを shopping-search-keywords 側に逃がす設計を出力する。

## 最重要原則

**商品名には1表記、揺れは shopping-search-keywords で吸収する。** 商品名にすべての表記揺れを詰め込むのではなく、商品名は「正規表記＋指名語＋最重要属性」で整え、表記揺れ（"レザー／革／本革"、"Bluetooth／ブルートゥース"）は検索キーワード欄で網羅する。これがYahoo!の検索アルゴリズムと最も整合する。

要点：
- name は全角75文字（150byte）。先頭25文字に「指名／商品タイプ／最重要属性／対象」を寄せる
- headline 60文字、caption 5,000文字、abstract 160文字、meta-description 80文字
- product-category と name の不整合は検索順位を大きく下げる（カテゴリ違いは即修正）
- shopping-search-keywords は半角スペース区切り、最大文字数に注意

## 処理フロー

### Step 1：入力情報の整理
- 商品名（現状）／JANまたは product-code
- カテゴリ（product-category／path）
- 商品スペック（素材／容量／対応規格／対象）
- ターゲット属性
- 競合商品名（3〜5件）
- 除外語（薬機・景表に抵触するもの、ブランド許諾なし語）

入力不足の場合は、最も自然な仮定を置いて初稿を出し、冒頭に「仮定」「不足情報」「追加確認したいこと」を明示する。

### Step 2：キーワードの分類
1. **指名語**：ブランド名・型番・シリーズ名（先頭近くに配置）
2. **商品タイプ語**：「化粧水」「Tシャツ」「財布」など一般名詞
3. **最重要属性**：素材／容量／規格／対象（メンズ/敏感肌等）
4. **用途・シーン語**：父の日／通勤／登山／ギフト
5. **表記揺れ語**：商品名には入れず shopping-search-keywords へ

### Step 3：商品名の構造化（全角75文字）
カテゴリに応じた順序を `references/title-templates.md` から選択。基本構造：
```
[先頭25字：指名／商品タイプ／最重要属性／対象] [中盤25字：サブ属性・サイズ・差別化] [末尾25字：用途・シーン]
```

### Step 4：装飾・NG表現の除去
`references/forbidden-decorations.md` の表に照らし、以下を削除：
- 装飾記号（★☆♪♥等）、絵文字、半角カナ、機種依存文字
- 薬機抵触語（治る／消える／美白＝化粧品ではNG）
- 景表抵触語（最安／No.1根拠なし／完全／必ず）
- 他モール訴求（楽天1位／Amazon's choice）

### Step 5：product-category との整合確認
商品名の主たる属性とカテゴリパスが一致するか。不一致なら「カテゴリ変更」または「商品名修正」のどちらが妥当か判定。

### Step 6：shopping-search-keywords の設計
- 表記揺れ語、英字／カナ／漢字の別表記、関連検索語
- 半角スペース区切り
- 商品名に既に入っている語は重複させない

### Step 7：複数案を目的別に出力
- A案：検索最大化（KW密度高め）
- B案：CVR重視（読みやすさ優先）
- C案：ギフト・シーン訴求重視

## 代表例

### 化粧水（コスメ）

Before：`【正規品】★大人気★資生堂 アクアレーベル 化粧水 200ml シミ消す美白 アンチエイジング 敏感肌でも安心 ！！`

問題点：
- ★装飾記号
- 「シミ消す」「美白」「アンチエイジング」は化粧品で薬機NG
- 「敏感肌でも安心」は安全性の断定でグレー

After（A案・検索最大化）：
`資生堂 アクアレーベル 化粧水 しっとり 200ml 国内正規品 保湿 エイジングケア 乾燥肌 詰め替え用本体 朝晩スキンケア ギフト`（全角68文字）

shopping-search-keywords：`シセイドウ aqualabel ローション スキンローション 保湿化粧水 詰替 詰め替え`

## 品質ゲート

- 全角75文字（150byte）を1文字でも超えていないか
- 先頭25文字に指名語または最重要属性が入っているか
- 同じ語の3回以上の繰り返しがないか（KW詰め込みペナルティリスク）
- 商品名と product-category の主要属性が一致しているか
- 化粧品で「美白／アンチエイジング」、健康食品で「痩せる／血糖値下がる」を一般食品で書いていないか
- 「最安」「No.1」「完全」「必ず」「保証」「治る」が断定形で残っていないか

## エッジケース

- **書籍・CD・DVD・ゲーム**：装飾語は不要。タイトル＋著者＋出版社＋シリーズ＋形式で十分。product-code は ISBN
- **正規取扱と互換品**：許諾ありなら「正規品」「正規代理店」、互換品なら「○○対応」「○○互換」を明示し、商標権侵害を避ける
- **食品の効能訴求**：機能性表示食品は届出文言を一字一句変えずに使い「機能性表示食品（届出番号XXX）」を併記。一般食品の効能標榜はNG
- **二重価格表示**：「定価」表記はメーカー希望小売価格との整合が必須。OPEN価格商品に勝手に定価を書かない
- **季節商品の使い回し**：「父の日」「クリスマス」を残したまま放置するとシーズン外で検索ノイズ。シーズン終了後の更新フローを別途設計

## 注意事項

- Yahoo!ショッピングの商品名仕様（最大文字数、禁止表記）は予告なく変更されるため、最終反映前に Yahoo!ショッピングストア向け公式ヘルプで確認する
- 商品名・キーワードの最終判断は商標権・薬機法・景表法の観点で必要に応じて専門家に確認する
- CSV一括更新を行う場合は必ずバックアップを取得し、差分確認のうえ少数SKUから段階反映する
- shopping-search-keywords を増やしすぎるとスパム判定リスク。表記揺れと関連検索語に限定する
