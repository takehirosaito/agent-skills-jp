# RMS各機能のチェック項目

## A. 店舗トップ

### チェック項目
- バナーの期間表示（イベント終了済みでないか）
- お知らせの最終更新日
- 営業案内・配送案内の最新性
- 「年末年始休業」「ゴールデンウィーク休業」等の文言切替
- トップ商品（おすすめ商品）の表示状態

### 異常パターン
- 「クリスマス特集」が1月に残置 → 即削除
- 「お盆休業」が9月に残置 → 即削除
- バナーリンク切れ → 即修正
- お知らせが3ヶ月以上更新されていない → 内容見直し

## B. 商品ページ

### チェック項目（売れ筋上位10-30件）
- 表示崩れ（HTML・画像）
- 売り切れ表示の正確性（在庫切れだが「販売中」表示等）
- レビューの新着・低評価
- 価格表示の正確性
- 違反対象（薬機法・景表法表現の混入）
- 比較対照価格の8週間ルール根拠
- 「No.1」「最安」等の根拠

### 異常パターン
- 商品ページHTMLが崩れて表示できない → 即修正
- 在庫切れだが「販売中」表示 → 即更新
- 削除済み画像のURL → 即修正
- 説明文に景表法・薬機法表現混入 → 即削除

### 推奨チェック頻度
- 売れ筋トップ10：毎日
- カテゴリ別売れ筋トップ：週2-3回
- ロングテール：月1回

## C. RPP広告

### チェック項目
- キャンペーンの配信状況（配信中／停止中）
- 予算消化率（日次・月次）
- CPC（上限到達商品）
- ROAS（目標との乖離）
- 除外商品・除外キーワード
- 新規追加すべきキーワード

### 異常パターン
- 配信停止（予算枯渇／設定ミス） → 即対応
- ROAS目標未達が続く → 入札調整
- 高CV商品の配信停止 → 即再開
- 除外CSVの更新漏れ → 当日中

### RPPの主要指標

| 指標 | 算式 | 目安 |
|---|---|---|
| CTR | クリック数 / 表示回数 | 1-3% |
| CPC | 広告費 / クリック数 | 業界・商品次第 |
| CVR | CV数 / クリック数 | 1-5% |
| ROAS | 売上 / 広告費 | 5倍以上が目安 |
| 広告費比率 | 広告費 / 売上 | 10-20%目安 |

詳細：`rakuten-rpp-keyword-audit` スキル

## D. 在庫

### チェック項目
- 欠品商品の対応
- 警告水準（残3-5以下）
- 売れ筋の補充計画
- 季節商品の在庫繰り
- ロット入荷予定との照合

### 異常パターン
- 売れ筋商品の欠品 → 即仕入手配
- 警告水準到達商品の発注遅延
- 入荷遅延の事前検知

### 在庫管理ツールとの連動
- ネクストエンジン等の在庫連携（約10分間隔）
- クロスモール在庫連携（30-60分）
- 楽天独自CSV更新

## E. イベント設定

### チェック項目
- クーポンの配布期間・利用期間
- クーポンの利用条件・対象商品
- SS／マラソン参加状況
- 終了済みイベントの設定残置
- 早割の終了日

### 異常パターン
- クーポンが「配布終了」なのにバナー残置 → 即削除
- イベント期間外なのにポイント還元が残っている → 修正
- 「今だけ」が長期化 → 文言見直し

## F. レビュー

### チェック項目
- 新着レビュー（毎日確認）
- 低評価（星3以下）の新着
- 返信が必要なもの
- 業者・ボット疑いのレビュー
- 効能訴求を含むレビュー（化粧品・健食）

### 対応フロー
- 星4-5：内容次第で返信
- 星3：返信＋改善ヒントとして記録
- 星1-2：48時間以内に返信＋個別対応

詳細：`rakuten-review-mining` `rakuten-review-reply-generator` スキル

## G. お問い合わせ

### チェック項目
- 未対応案件
- 期限超過（24時間以内対応推奨）
- エスカレーション必要なもの
- 補償・返品の確定対応
- 配送遅延・初期不良の問い合わせ

### 異常パターン
- 48時間以上未返信 → 即対応＋謝罪
- クレーム案件の放置 → 上長エスカレーション
- 法的トラブルの兆候 → 法務エスカレーション

### 対応SLA目安
- 通常問い合わせ：24時間以内
- 補償・返品：48時間以内
- 急ぎ／クレーム：12時間以内

## H. 違反点数・お知らせ

### チェック項目
- RMSの「お知らせ」（毎朝確認）
- 違反点数の累積
- 楽天からの個別連絡（メール／RMS）
- 仕様変更・規約変更の通知
- レビュー特典規制違反の通知

### 違反点数の対応

楽天の違反点数制度：
- 違反内容により点数加算（軽微1-5点／重大35点等）
- 累積点数で違反レベル上昇
- レベル5で契約解除＋違約金300万円

主な違反項目：
- レビュー特典規制違反：35点
- 薬機法違反：可能性あり
- 景表法違反：可能性あり
- 商標権侵害：可能性あり
- 商品配送遅延の常態化

## I. 関連店舗パトロール（任意）

### チェック項目（週次）
- 競合店舗の価格
- 競合の新商品
- 競合のキャンペーン
- 楽天ランキング順位

### 注意
- 競合の固有名詞を社内メモに残すのは可、商品ページへの記載は商標問題

## チェックリストの自動化

可能なものは自動化検討：

- 在庫警告（ネクストエンジン等の自動通知）
- RPP予算アラート（楽天独自の通知設定）
- 新着レビュー（メール通知）
- お問い合わせ未対応（CRMツール）

→ 自動化で「気づくのが遅い」を防ぐ。手動チェックは「目視確認」に絞る。

## パトロール手順の最適化

### 朝の進行順

1. **緊急度の高いものから**：違反点数 → 在庫 → RPP
2. **時間がかかるが重要**：レビュー → 問い合わせ
3. **目視確認**：店舗トップ → 商品ページ
4. **記録・共有**：朝報

### 所要時間の目安

| カテゴリ | 所要 |
|---|---|
| 店舗トップ | 5分 |
| 商品ページ（売れ筋10件） | 10-15分 |
| RPP | 10分 |
| 在庫 | 5-10分 |
| イベント設定 | 5分 |
| レビュー | 10分 |
| お問い合わせ | 10分 |
| 違反点数・お知らせ | 5分 |
| **合計** | **60-70分** |

→ 標準的な中規模店舗で1時間程度。大規模店舗・複数モール運用は分担推奨。
