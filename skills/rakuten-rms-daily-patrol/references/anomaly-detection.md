# 異常検知のしきい値・判定基準

## 在庫の異常判定

| 在庫数 | 判定 | 対応 |
|---|---|---|
| 残10以上 | 正常 | 通常運用 |
| 残3-9 | 要注意 | 補充計画の確認 |
| 残1-2 | 警告 | 即補充手配 |
| 残0 | 異常 | 即対応：仕入手配、商品ページに「入荷待ち」表示 |

### 例外
- 季節商品の終売直前は0でOK
- 受注生産品は0でも問題なし（リードタイム明示）
- 売れ筋商品は警告水準を高めに（残20以下で警告等）

## RPP広告の異常判定

### 予算消化率

| 消化率 | 判定 | 対応 |
|---|---|---|
| 50-80% | 正常 | 通常運用 |
| 80-95% | 要注意 | 月末予算の見通し確認 |
| 95-100% | 警告 | 配信停止リスク、予算追加検討 |
| 100%・停止 | 異常 | 即対応：配信停止解除、予算追加 |
| 30%未満 | 要注意 | 入札不足、キーワード不足の可能性 |

### CPC・ROAS

| 指標 | 正常 | 要注意 | 異常 |
|---|---|---|---|
| CPC | 目標±20% | 目標+30% | 目標+50% |
| ROAS | 目標±10% | 目標-20% | 目標-30%以下 |
| CTR | 1-3% | 0.5-1% | 0.5%未満 |
| CVR | 1-5% | 0.5-1% | 0.5%未満 |

### 異常時の対応
- ROAS急低下 → 配信を絞る、キーワード見直し
- CPC急上昇 → 競合状況確認、入札調整
- CTR急低下 → 商品名・画像見直し
- CVR急低下 → 商品ページ・価格見直し

## レビューの異常判定

| 状況 | 判定 | 対応 |
|---|---|---|
| 星4-5の新着 | 正常 | 内容確認、必要に応じ返信 |
| 星3の新着 | 要注意 | 返信、改善ヒントとして記録 |
| 星1-2の新着 | 異常 | 48h以内返信、原因調査、補償検討 |
| 同一商品で星1-2が連続 | 緊急異常 | 商品の問題か運用問題か即調査 |
| 業者・ボット疑い | 異常 | 楽天に通報検討 |

### 効能訴求を含むレビュー（化粧品・健食）

- 単発：通常返信（追認しない）
- 多発：商品ページの記載見直し（誤認を招く表現はないか）

## お問い合わせの異常判定

| 状況 | 判定 | 対応 |
|---|---|---|
| 24時間以内対応中 | 正常 | 通常運用 |
| 24-48時間未対応 | 要注意 | 当日中に対応 |
| 48時間以上未対応 | 異常 | 即対応＋謝罪、原因分析 |
| クレーム・法的トラブル | 緊急異常 | 上長・法務エスカレーション |

### 急増アラート
- 同種の問い合わせが1日5件以上 → システムトラブルか商品問題の可能性
- 配送遅延の問い合わせ急増 → 配送業者・倉庫の問題

## 違反点数の異常判定

| 累積点数 | 判定 | 対応 |
|---|---|---|
| 0点 | 正常 | 通常運用 |
| 1-9点 | 要注意 | 違反内容確認、再発防止策 |
| 10-29点 | 警告 | 違反内容の徹底改善、運用責任者報告 |
| 30-59点 | 異常 | 違反レベル進行リスク、緊急対応 |
| 60点以上 | 緊急異常 | 違反レベル進行、契約解除リスク |

### 違反レベル制度
- レベル1：軽微（35点以上）
- レベル2-4：段階的に厳しい措置
- レベル5：契約解除＋違約金300万円

## 店舗トップの異常判定

| 状況 | 判定 |
|---|---|
| バナー期間正常 | 正常 |
| バナー終了済みだが残置 | 要注意（即削除） |
| バナーリンク切れ | 異常（即修正） |
| お知らせ3ヶ月未更新 | 要注意 |
| 営業案内・配送案内が古い | 要注意 |

## 商品ページの異常判定

| 状況 | 判定 |
|---|---|
| 表示崩れ | 異常（即修正） |
| 売り切れだが販売中表示 | 異常（即更新） |
| 削除済み画像URL | 異常（即修正） |
| 景表法・薬機法表現混入 | 異常（即削除） |
| 8週間ルール根拠なき通常価格 | 要注意（根拠確認・削除検討） |
| No.1根拠なき表現 | 異常（即対応） |

## 異常検知の自動化検討

| 異常 | 自動化手段 |
|---|---|
| 在庫低下 | ネクストエンジン等の自動通知 |
| RPP予算枯渇 | 楽天独自の通知 |
| 新着レビュー（星1-2） | メール通知 |
| お問い合わせ24h超過 | CRMツールのアラート |
| 違反点数 | RMSのお知らせメール |
| 競合価格変動 | 価格モニタリングツール |

## 異常レポートのテンプレ

```
■ 日次パトロール異常レポート

日付：YYYY-MM-DD
担当：

【緊急（即対応）】
- カテゴリ：在庫
- 内容：商品Aの在庫切れ
- 対応：仕入手配中、商品ページに「入荷待ち」表示
- 担当：仕入担当
- 期限：当日中

【高（当日中）】
- カテゴリ：レビュー
- 内容：商品Bに星2レビュー、配送遅延の指摘
- 対応：返信＋配送業者調査
- 担当：CS
- 期限：当日中

【中（翌日まで）】
- カテゴリ：店舗トップ
- 内容：クリスマス特集バナーが残置
- 対応：通年版バナーに差し替え
- 担当：制作
- 期限：翌営業日

【その他】
- 月末予算消化率が95%、追加予算検討
```

## 異常パターンの蓄積

毎日のパトロールで見つかった異常を蓄積：

- 月次レビューで集計
- 頻発する異常は事前対策に転換
- 例外的な異常は原因分析

→ パトロール手順自体を継続改善する。
