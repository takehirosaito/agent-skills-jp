# 商品ベネフィットコピー作成

## 概要

商品の物理的な「特徴」をそのまま並べてもCVRは上がらない。顧客は「自分の暮らしや感情がどう変わるか（ベネフィット）」で買う。本スキルは「Feature → Function → Advantage → Benefit」の4階層変換で、商品ページのファーストビュー・特長・使用シーン・お客様の声・スペック・CTAまでを一貫して生成する。

カート別の細かい仕様（楽天／Amazon／MakeShop／FutureShop）には踏み込まず、**汎用の商品ベネフィットコピーとして使えるテキスト一式**を出すのが本スキルの役割。

## ★最重要原則

**「特徴」「機能」をそのまま訴求せず、必ず「顧客の暮らし・感情がどう変わるか」まで翻訳する。** 「ヒアルロン酸3種配合」（特徴）ではなく「乾燥を感じる夕方も、しっとり肌へ」（ベネフィット）。同時に、化粧品なら効能効果56項目内、健食なら届出文言（機能性表示食品）または効能効果非標榜（一般食品）の範囲を厳守する。

## 処理フロー

### Step 1：入力情報の整理と薬機法カテゴリ確定

必須：
- 商品カテゴリ（化粧品／医薬部外品／機能性表示食品／トクホ／栄養機能食品／一般食品／雑貨／家電／アパレル）
- 商品名・価格・容量／サイズ
- 主な特徴（成分・スペック・素材・産地・製法）
- ターゲット（できれば具体的ペルソナ）
- ベネフィットの仮説（顧客がどう変わるか）

任意：
- 競合商品・差別化ポイント（USP）
- レビューや過去のお客様の声
- 配信チャネル

不足時は最も可能性の高い前提を仮置きし、冒頭に「カテゴリ確認が必要」を表示（ハイブリッド設計）。**カテゴリが化粧品か医薬部外品かで言える効能が大きく違う**ため、ここは必ず確認。

### Step 2：FAB 4階層変換

商品の特徴を1つずつ表に展開：

| 特徴（Feature） | 機能（Function） | 利点（Advantage） | ベネフィット（Benefit） |
|---|---|---|---|
| ヒアルロン酸3種 | 異なる分子量で肌に届く | 表面と内側両方にうるおい | 乾燥を感じる夕方も気にならない |
| 30ml | 約2ヶ月分容量 | 1日2回で毎日使い切らない | 毎月買い足す手間がない |
| GMP認定工場 | 品質管理基準クリア | 安心して続けられる | 大切な家族にも勧められる |

**ベネフィット列が空欄のものは、まだコピー化に使えない**。WHY5層で深掘りして埋める。

### Step 3：核訴求の1文圧縮

> 【ターゲット】に対して、【課題・状況】を【商品名】が【ベネフィット】する

例：
> 「乾燥が気になる30代の方に対して、夕方の肌の手応えを、本品が朝までうるおって整える形で解決する」

この1文をPASONA／BEAF／QUEST／AIDMAどのフレームにも展開可能な核として確定。

### Step 4：商品ページ構造に沿ったコピー展開

商品ページの標準構造：
1. ファーストビュー（キャッチ＋サブ＋画像＋訴求アイコン3＋CTA）
2. 商品の特長（FAB変換した3-5項目）
3. 使用シーン（5W1H）
4. スペック表
5. お客様の声（社会的証明）
6. よくある質問
7. 配送・返品
8. CTA再掲

各セクションで「機能訴求 vs 情緒訴求」を使い分け（`references/framework.md`参照）：
- FV：情緒訴求（共感）
- 特長：機能訴求（説得）
- 使用シーン：情緒訴求（体験）
- スペック：機能訴求（比較）
- お客様の声：情緒訴求＋社会的証明

### Step 5：法令範囲内の表現に変換

カテゴリ別の「言える範囲」を厳守：

**化粧品（届出のみ）**：56項目内の効能効果のみ
- OK：「肌のうるおいを保つ」「日やけによるシミ・ソバカスを防ぐ」「肌のキメを整える」「乾燥による小ジワを目立たなくする」（試験データ必須）
- NG：「シミに効く／消える」「美白効果」「アンチエイジング」「リフトアップ」「ニキビが治る」「皮膚科医推薦」（適正広告ガイドライン違反）

**医薬部外品（薬用化粧品）**：承認された効能効果
- 容器・包装に「医薬部外品」表示が必要。化粧品と効能を取り違えない

**機能性表示食品**：届出文言と一字一句一致＋届出番号必須

**一般食品（いわゆる健康食品）**：効能効果の標榜不可
- OK：「忙しい毎日に」「美容を意識する方に」
- NG：「○○に効く」「痩せる」「免疫力アップ」

**景表法 共通NG**：根拠なき「No.1」「最上級」「最安」「絶対」「100%」「完全」／二重価格8週間ルール違反／優良誤認・有利誤認

詳細リストは `references/legal-boundaries.md`。

### Step 6：キャッチコピーの型を選ぶ

ターゲット・カテゴリに応じて：
- 数字＋ベネフィット：「3日でわかる、肌の手応え」
- 否定＋反転：「もう、午後の乾燥を気にしない」
- 質問：「いつものスキンケア、見直しませんか」
- 共感＋提案：「忙しい朝こそ、シンプルケア」
- 比喩：「水のように染み込む、新感覚化粧水」
- 二段組（コントラスト）：「ベタつかないのに、しっかりうるおう」

### Step 7：使用シーンを5W1Hで具体化

| 要素 | 例 |
|---|---|
| When | 朝起きてすぐ／お風呂上がり／メイク前 |
| Where | 洗面所／旅行先／オフィス |
| Who | 30代女性／敏感肌の方／忙しいママ |
| What | スキンケアの一環として |
| Why | 乾燥が気になる季節に |
| How | 化粧水後にプラス／単独で集中ケア |

シーンを3つ用意（朝・夜・特別な日）。

### Step 8：法令最終チェック

完成コピーを再走査：
- カテゴリ別NG表現（化粧品56項目外／健食効能標榜 等）
- 景表法（No.1・最上級・二重価格・打消し表示）
- ステマ規制（インフルエンサー素材使用時）
- 効能効果に関するレビュー転載（事業者表示扱いで違反）

詳細な薬機法・景表法のチェックは別スキル `yakki-keihyo-expression-check` を併用。

## 代表例：化粧品（保湿化粧水・30代乾燥肌向け）

**入力**：
- 商品：保湿化粧水 30ml／3,800円（化粧品・届出のみ）
- 特徴：ヒアルロン酸3種・ビタミンC誘導体5%・無香料・無着色・日本製
- ターゲット：30代乾燥肌女性

**FAB 4階層変換**：

| 特徴 | 機能 | 利点 | ベネフィット |
|---|---|---|---|
| ヒアルロン酸3種 | 異なる分子量で肌に届く | 表面と内側両方にうるおい | 乾燥を感じる夕方も気にならない |
| ビタミンC誘導体5% | キメを整える成分（化粧品56項目内：肌のキメを整える） | 化粧ノリの良い肌印象 | 朝のメイクが決まる |
| 30ml | 約2ヶ月分 | 1日2回で毎日使い切らない | 毎月買い足す手間がない |
| 無香料・無着色 | 添加物を抑えた処方 | 敏感肌でも使いやすい | 家族で続けられる |
| 日本製 | 国内工場での製造 | 品質管理が安心 | 安心して長く使える |

**核訴求**：
> 乾燥が気になる30代の方に、夕方も気にならないうるおいケアを、本品が手軽な1ステップで届ける。

**ファーストビュー**：
- キャッチ：「乾燥を感じる夕方も、しっとり肌へ。」
- サブ：「ヒアルロン酸3種 × ビタミンC誘導体5% ／ 無香料・無着色 ／ 日本製」
- 訴求アイコン3：「日本製」「無香料」「ヒアルロン酸3種」
- CTA：「今すぐ初回30%OFFで始める →」

**商品の特長（3項目）**：
1. **3種のヒアルロン酸で、肌のうるおいを保つ** — 異なる分子量のヒアルロン酸が肌の表面と内側にうるおいを与える設計
2. **ビタミンC誘導体5%配合で、肌のキメを整える** — 朝のメイクが決まる肌印象へ
3. **無香料・無着色・日本製で、家族で続けられる** — 添加物を抑えた処方

**使用シーン**：
- 朝：洗顔後、メイク前に。1日のうるおいを準備
- 夜：お風呂上がり、化粧水として。明日の肌の手応えへ
- 旅行先：軽くて持ち運びやすい30mlで、いつものケアを場所を選ばず

**こんな方におすすめ**：
- 夕方になると肌のカサつきを感じる方
- 30代後半でエイジングサインが気になり始めた方
- 敏感肌で添加物が気になる方
- 贈り物に上質なスキンケアを探している方

**法令範囲内チェック**：
- 「うるおいを保つ」「キメを整える」 → 化粧品56項目内 OK
- 「肌のうるおい」「化粧ノリの良い」 → 感想ベース・OK
- 「美白」「アンチエイジング」「シミに効く」 → 使用していない
- 「皮膚科医推薦」 → 使用していない

詳細パターン（健食・家電・食品・アパレル）は `references/examples.md`。

## 品質ゲート

- [ ] 商品カテゴリ（化粧品／医薬部外品／機能性表示食品／一般食品／雑貨／家電）を確定した
- [ ] FAB 4階層変換表が全特徴で埋まっている（ベネフィット列が空欄なし）
- [ ] 核訴求の1文がターゲット・課題・商品・ベネフィットを全て含む
- [ ] ファーストビューが Who／What／Why now／CTA の4要素を満たす
- [ ] 商品の特長が3-5項目、各20字以内の箇条書きで短い
- [ ] 使用シーンを3つ（朝／夜／特別な日 等）で描写した
- [ ] 化粧品なら56項目内、医薬部外品なら承認効能、機能性表示食品なら届出文言＋届出番号
- [ ] 一般食品で効能効果を標榜していない
- [ ] No.1・最上級・最安・「絶対」「100%」「完全」に根拠5項目 or 削除
- [ ] 二重価格表記は8週間ルール（直近8週間のうち4週間以上の実販売）
- [ ] before/after画像（化粧品・健食）を残していない／メーキャップ・物理効果は可
- [ ] 「皮膚科医推薦」（化粧品）を使っていない
- [ ] 効能効果に関するレビュー転載なし（事業者表示扱いで違反）
- [ ] 機能訴求と情緒訴求のセクション配分を意識した

## エッジケース

- **カテゴリが化粧品か医薬部外品か曖昧**：容器・包装の「医薬部外品」表示・承認番号を確認。化粧品で医薬部外品の効能（美白・ニキビを防ぐ等）を訴求すると違反。
- **機能性表示食品の届出文言と販促コピーが乖離**：届出文言は一字一句一致＋届出番号必須。販促コピーで言い換え不可。
- **「乾燥による小ジワを目立たなくする」を使いたい**：日本香粧品学会ガイドライン試験の裏付けが必須。試験データがない場合は使わない。
- **オーガニック・無添加・天然100%**：景表法の優良誤認リスク。実態と一致しているか・根拠あるか確認。
- **「日本製」「国産」**：製造工程の主要部分が国内であることを確認。海外OEMで国内パッケージングのみの場合は表示不可。

## 注意事項

- 化粧品56項目・医薬部外品承認効能・機能性表示食品の届出文言は、厚生労働省・消費者庁の公式情報源で最新を確認。
- 「皮膚科医推薦」「医師監修」（化粧品）：化粧品適正広告ガイドラインで医薬関係者の推薦は原則NG。健食でも景表法リスク。
- 効能効果に関する顧客レビューを商品ページに転載すると事業者の表示扱い。「シミが消えた」等を引用すると違反。
- ステマ規制（2023.10〜）：インフルエンサー素材を商品ページに流用する場合は契約・PR表記対応必須。
- カート別の細かい仕様（楽天タグ規制／Amazonタイトル文字数／MakeShop／FutureShopの装飾）は別スキルへ委譲。本スキルは汎用ベネフィットコピーに専念。
