# コピー構造のフレームワーク

## 商品ページの基本構造

```
1. ファーストビュー（10秒以内に判断される）
   - キャッチコピー
   - サブコピー
   - メイン画像
   - 主訴求アイコン3つ
   - CTAボタン

2. 商品の特長（特徴 → 機能 → 利点 → ベネフィット）
   - 特長1
   - 特長2
   - 特長3

3. 使用シーン・体験
   - 朝・夜・週末・季節等

4. 商品スペック
   - サイズ・容量・成分

5. お客様の声・レビュー
   - レビュー数・評価
   - 代表的なコメント

6. よくある質問

7. 配送・返品ポリシー

8. CTAボタン（再掲）
```

## ファーストビューの構造

### キャッチコピー（10〜20文字）
- 顧客のベネフィットを一言で
- 「乾燥を感じる夕方も、しっとり肌へ。」

### サブコピー（30〜50文字）
- 補足説明・主要成分・特徴
- 「ヒアルロン酸3種 × ビタミンC誘導体5%配合 / 無香料・無着色」

### 主訴求アイコン（3つ）
- 視覚的な特徴・認証・実績
- 「日本製」「無香料」「ヒアルロン酸3種」

### CTAボタン
- 「カートに入れる」「今すぐ買う」
- 在庫情報・送料情報・配送日も近くに

## コピーライティング型

### AIDMA / AIDCA
- Attention（注目）：キャッチコピー
- Interest（関心）：サブコピー・特徴
- Desire（欲求）：ベネフィット・体験
- Memory / Conviction（記憶・確信）：レビュー・受賞
- Action（行動）：CTA

### PASONA（神田昌典の販売型）
- Problem（問題）：「乾燥が気になる」
- Affinity（親近感）：「同じ悩み、ありますよね」
- Solution（解決策）：「本品はこう解決します」
- Offer（提案）：「特別価格・送料無料」
- Narrowing down（絞り込み）：「先着○名」
- Action（行動）：「今すぐ申し込む」

### QUEST（マーケティング2.0）
- Qualify（適格化）：「こんな悩みありませんか」
- Understand（理解）：「お気持ちわかります」
- Educate（教育）：「実は○○が原因」
- Stimulate（刺激）：「だから本品が必要」
- Transition（行動）：「今すぐお試し」

### BEAF
- Benefit（利益）：「効率2倍に」
- Evidence（証拠）：「導入1000社」
- Advantage（優位性）：「業界唯一」
- Feature（特徴）：「機能詳細」

## キャッチコピーの型

### 数字 + ベネフィット
- 「3日でわかる、肌の手応え。」
- 「1日2分で続けるエイジングケア。」（化粧品では「年齢に応じたお手入れ」に）

### 否定 + 反転
- 「もう、午後の乾燥を気にしない。」
- 「化粧崩れを、気にしない朝へ。」

### 質問
- 「いつものスキンケア、見直しませんか？」
- 「乾燥肌のための、新しい一本。」

### 共感 + 提案
- 「忙しい朝こそ、シンプルケア。」
- 「敏感肌の選択肢を、もっと豊かに。」

### 比喩
- 「水のように染み込む、新感覚化粧水。」
- 「絹のような肌触りに包まれる。」

### 二段組（コントラスト）
- 「ベタつかないのに、しっかりうるおう。」
- 「軽いつけ心地、確かなうるおい感。」

## サブコピー・ボディコピーの構造

### Three Reasons（3つの理由）
- 理由1：成分（具体的）
- 理由2：技術（独自性）
- 理由3：体験（顧客視点）

### Storytelling（物語）
- 始まり：開発のきっかけ
- 中盤：苦労・試行錯誤
- 結末：完成品・顧客の喜び

### Before / After
- Before：「化粧ノリが悪い朝」
- After：「キメの整った肌印象で迎える朝」

ただし化粧品・健食ではビフォーアフター画像はNG（スキンケア・効能訴求の領域）。メーキャップ・物理的効果のみOK。

## 箇条書きの作り方

### 3〜5項目が黄金比
- 多すぎると認知負荷
- 少なすぎると訴求弱い

### 各項目は短く（20文字以内）
- ❌「ヒアルロン酸3種配合で肌の各層にうるおいを与えることができます」
- ⭕「ヒアルロン酸3種で肌の各層にうるおい」

### 各項目に動詞 or 名詞句
- 「○○配合」「○○を実現」「○○で△△」

### 視覚的アイコン併用
- 各項目の冒頭にアイコン（チェック✓・星★）
- ※絵文字使用はモール検索性に影響する場合あり

## 使用シーンの描写

### 5W1H で具体的に

| 要素 | 例 |
|---|---|
| When（いつ） | 朝起きてすぐ／お風呂上がり／メイク前 |
| Where（どこで） | 洗面所／リビング／旅行先 |
| Who（誰が） | 30代女性／敏感肌の方／忙しいママ |
| What（何を） | スキンケアの一環として |
| Why（なぜ） | 乾燥が気になる季節に |
| How（どのように） | 化粧水後にプラス／単独で集中ケア |

### シーンを3つ用意
- 朝のシーン
- 夜のシーン
- 特別な日のシーン（旅行・イベント等）

## 「こんな方におすすめ」の書き方

### 4〜6項目で具体的に
- 「乾燥が気になる方」（一般的すぎ）
- 「夕方になると肌のカサつきを感じる方」（具体的）

### ターゲットの行動・状況を描写
- 「忙しくてケアを簡略化したい方」
- 「30代後半でエイジングサインが気になり始めた方」
- 「敏感肌で添加物が気になる方」
- 「贈り物に上質なスキンケアを探している方」

## CTAボタンの文言

| パターン | 例 |
|---|---|
| 直接的 | 「カートに入れる」「今すぐ買う」 |
| 体験訴求 | 「今すぐ試す」「7日間お試し」 |
| 限定訴求 | 「数量限定で予約する」「先着で申し込む」 |
| 安心訴求 | 「無料で資料請求」「気軽にお試し」 |

## モバイル最適化

スマホファースト時代のコピー：
- 1画面で完結する情報量
- フォントサイズ大きめ
- ボタン押しやすいサイズ・位置
- 読み飛ばし対応（要点を冒頭に）
- 縦スクロールで読み進められる順序

## A/Bテストで検証すべき要素

1. **キャッチコピー**：感情訴求 vs 機能訴求
2. **メイン画像**：商品単体 vs 使用シーン
3. **CTAボタン色・文言**
4. **価格表示**：通常価格→セール価格 vs セール価格のみ
5. **送料訴求**：「送料無料」表示の有無
6. **レビュー表示**：上部 vs 下部

## 法令チェックを最後に

コピーが完成したら：
1. 薬機法・景表法・健康増進法の主要違反語を再チェック
2. カテゴリ別の言える範囲を確認
3. 詳細チェックは別スキル（yakki-keihyo-expression-check）

## モール別のコピー特徴

### 楽天
- 商品名にキーワードを詰め込む傾向（モール内検索のため）
- 装飾文字「【】」「★」が多用される（ただし違反点数の対象）

### Amazon
- タイトル200文字以内、シンプルに
- 「ブランド名 + 商品名 + 特長」のフォーマット
- 装飾文字は推奨されない

### Yahoo!ショッピング
- 商品名150文字、楽天よりシンプル
- PayPayキャンペーンとの相性

### 自社EC（Shopify等）
- 完全自由
- ブランドの世界観を最大限表現可能
