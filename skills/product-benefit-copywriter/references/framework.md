# 特徴→ベネフィット変換フレームワーク

## FAB分析（Features / Advantages / Benefits）

マーケティングの古典的フレームワーク。FABの3段階で考える：

### Feature（特徴）
商品の仕様・成分・構造の事実情報。
- 例：「ヒアルロン酸配合」「14時間連続駆動」「綿100%」

### Advantage（利点）
特徴があることで生まれる商品の優位性・差別化。
- 例：「肌の各層に浸透」「外出先でも電池切れの心配がない」「肌に優しい」

### Benefit（ベネフィット）
顧客の体験・感情・暮らしの変化。
- 例：「乾燥を感じない夕方の肌」「予定通りに仕事を進められる」「敏感肌でも安心して使える」

## 4階層拡張（特徴→機能→利点→ベネフィット）

FABを4段階に細分化し、より精緻な変換を行う：

```
1. 特徴（Feature）：物理的事実
2. 機能（Function）：何をするか
3. 利点（Advantage）：商品の優位性
4. ベネフィット（Benefit）：顧客体験
```

### 化粧品の例

| 特徴 | 機能 | 利点 | ベネフィット |
|---|---|---|---|
| ヒアルロン酸3種 | 異なる分子量で肌に届く | 表面と内側両方にうるおい | 乾燥を感じる夕方も気にならない |
| ビタミンC誘導体5% | 肌のキメを整える成分 | キメの整った肌印象 | 化粧ノリの良い朝を迎える |
| 30ml | 約2ヶ月分容量 | 1日2回使用で毎日使い切らない | 毎月買い足す手間が無い |

### 健康食品の例

| 特徴 | 機能 | 利点 | ベネフィット |
|---|---|---|---|
| マルチビタミン12種 | 1日に必要なビタミン補給 | 食事で取りきれない栄養を補う | 忙しい毎日でも体調を整える |
| 30粒×3袋セット | 約3ヶ月分 | まとめ買いで送料効率 | 切らさない安心 |
| GMP認定工場製造 | 品質管理基準クリア | 安心して続けられる | 大切な家族にも勧められる |

※健食では「効く」「効果」「予防」等の効能標榜は不可。「○○の補給」「サポート」等の表現に。

### 家電の例

| 特徴 | 機能 | 利点 | ベネフィット |
|---|---|---|---|
| 14時間連続駆動 | 1日中使える | 充電の手間が少ない | 旅行や出張でも安心 |
| 重量250g | 軽量 | 片手で持ちやすい | 子供の世話をしながらでも使える |
| 防水IPX5 | 水しぶきに強い | キッチン・浴室でも使える | 場所を選ばず使える |

## 顧客のWHY（なぜ買うのか）を掘り下げる

### 5層の WHY

```
WHY1：何が欲しいの？ → 化粧水
WHY2：なぜそれが必要なの？ → 肌が乾燥するから
WHY3：なぜ乾燥するの？ → エアコンや冬の空気
WHY4：乾燥するとどうなるの？ → 肌がカサつく、化粧のりが悪い
WHY5：それがどんな影響を？ → 鏡を見るたびに気になる、自信が持てない
```

→ コピーで訴求すべきは WHY4・WHY5 のレベル。「化粧水ありますよ」ではなく「鏡を見るたびに自信を持てる肌へ」。

## 顧客のジョブ（仕事）を考える

「ジョブ理論」フレームワーク：顧客は商品を雇用して何かのジョブを片付ける。

| 顧客のジョブ | コピー訴求 |
|---|---|
| 肌の乾燥を解決したい | 「乾燥を感じる夕方も、しっとりした肌へ」 |
| 化粧ノリを良くしたい | 「朝のメイクが決まる、キメの整った肌へ」 |
| 自信を持ちたい | 「鏡を見るのが楽しみになるスキンケア」 |
| 大切な人に贈りたい | 「特別な日への贈り物として」 |
| 続けやすさを求める | 「忙しい毎日にも続けられる、1ステップケア」 |

## 感情の階段

顧客が商品を買う前後の感情変化：

```
1. 認識：問題に気づく（「最近肌が乾燥する」）
2. 探索：解決策を探す（「何か良い化粧水ないかな」）
3. 比較：選択肢を比べる（「これとあれ、どっちが良い？」）
4. 決定：購入を決める（「これにしよう」）
5. 体験：使ってみる（「使い心地どうだろう」）
6. 評価：満足度を判断（「これ良かった！」）
7. 推奨：他人に勧める（「友達にも教えよう」）
```

コピーは1〜4のステージにいる人を5以降に動かす役割。各ステージの感情に応じた言葉を選ぶ。

## 6つのモチベーション原則（Cialdiniの影響力）

1. **返報性**：「先に何かをもらった」感覚（無料サンプル・プレゼント）
2. **コミットメントと一貫性**：小さなYESを積み重ねる
3. **社会的証明**：「みんなが使っている」（レビュー数・売上ランキング）
4. **好意**：好きな人・親しみが持てる人から
5. **権威**：「専門家が認めた」（化粧品では医療関係者推薦は薬機法でNG）
6. **希少性**：「今だけ」「あと○個」（実態と一致していること）

各原則を法令範囲内で活用する。

## STAR（Situation / Task / Action / Result）

ベネフィットを物語化する：

- **Situation（状況）**：乾燥が気になる季節
- **Task（課題）**：化粧ノリが悪くなる
- **Action（行動）**：朝のお手入れに本品を加える
- **Result（結果）**：1日中うるおいを感じる肌に

物語化されたコピーは記憶に残りやすい。

## マズローの欲求階層

| 欲求段階 | 化粧品の訴求 | 健食の訴求 | 家電の訴求 |
|---|---|---|---|
| 生理的欲求 | 肌の基本ケア | 栄養補給 | 生活必需品 |
| 安全 | 肌に優しい | 安心の品質 | 故障しにくい |
| 所属と愛 | 大切な人に喜ばれる | 家族で続けられる | 家族で使える |
| 承認 | 周りから褒められる肌へ | 健康的な印象 | スタイリッシュ |
| 自己実現 | 自分らしい美しさ | なりたい自分へ | 暮らしを豊かに |

ターゲット顧客がどの段階の欲求に応えてほしいかを意識する。

## 機能訴求と情緒訴求の使い分け

| 訴求タイプ | 強み | 弱み | 向く場面 |
|---|---|---|---|
| 機能訴求 | 説得力・比較しやすい | 競合との価格競争に陥る | 新規顧客の認知獲得 |
| 情緒訴求 | ブランド愛着・差別化 | 効果の確信が薄い | リピート顧客の維持 |

実際のコピーは両方を組み合わせる：
- ファーストビュー：情緒訴求（共感を獲得）
- 商品の特長：機能訴求（説得）
- 使用シーン：情緒訴求（体験を想像）
- スペック：機能訴求（比較材料）
- お客様の声：情緒訴求（社会的証明）

## ターゲット解像度

「30代女性」では曖昧。具体的に：

- 32歳・正社員・既婚・子なし
- 朝7時起床、夜23時就寝、土日休み
- 化粧水・乳液は使うがエイジングケアまでは未着手
- 仕事のストレスで肌荒れ・乾燥が気になり始めた
- 月に5,000円程度のスキンケア投資はOK
- Instagram・YouTubeで情報収集

→ こうしたペルソナを持つと「ストレスで肌荒れする30代の朝に」のような具体コピーが書ける。
