# 法令の境界線 - カテゴリ別「言えること／言えないこと」

## 化粧品（届出のみ）

### 言える範囲：化粧品の効能効果56項目
代表例：
- うるおいを与える／うるおいを保つ
- 肌のキメを整える
- 肌荒れを防ぐ
- 日やけによるシミ・ソバカスを防ぐ
- 乾燥による小ジワを目立たなくする（試験データ必須）
- 肌をひきしめる
- 肌を保護する
- 皮膚の柔軟性を保つ

完全な56項目リストは別スキル（yakki-keihyo-expression-check）参照。

### NG表現（化粧品では言えない）
- 「シミに効く」「シミが消える」 → 医薬部外品でも「シミ・ソバカスを防ぐ」が限度
- 「シワが消える」 → NG。「乾燥による小ジワを目立たなくする」のみ可（試験データ必須）
- 「美白」 → 医薬部外品の承認効能。化粧品では NG。「日やけによるシミ・ソバカスを防ぐ」へ
- 「アンチエイジング」 → 「エイジングケア（年齢に応じたお手入れ）」へ
- 「リフトアップ」 → 物理的にメイクで持ち上げる場合のみ可。塗ってリフトアップは NG
- 「血行促進」「新陳代謝」 → 医薬部外品の領域
- 「ニキビを治す」 → NG。「ニキビを防ぐ（洗顔料）」のみ
- 「皮膚科医も推奨」「ドクターが認めた」 → 化粧品適正広告ガイドラインで医薬関係者の推薦は原則 NG

### OK表現
- 「肌印象が変わる」（感想ベース）
- 「化粧ノリの良い肌へ」
- 「うるおいで満たされた肌」
- 「年齢に応じたお手入れ」
- 「乾燥を感じない朝」

## 医薬部外品（薬用化粧品含む）

### 言える範囲：承認された効能効果
- 美白（メラニンの生成を抑え、シミ・ソバカスを防ぐ）
- 肌荒れ・あれ性
- ニキビを防ぐ
- 日やけによるシミ・ソバカスを防ぐ
- 制汗
- フケ・カユミを防ぐ
- 口内炎を防ぐ（薬用歯みがき）

「医薬部外品」の表示があるか、承認番号があるかを必ず確認。**化粧品で同じ効能を言うと違反**。

## 健康食品（一般食品）

### 言える範囲：効能効果の標榜不可、一般的表現のみ
- 美味しさ
- 食感
- 原材料の説明
- 「健康的な生活をサポート」「美容を意識した方に」
- 産地・製法の説明

### NG表現
- 「○○に効く」「効果がある」 → NG
- 「治る」「予防」「改善」 → NG
- 「ダイエット効果」「痩せる」 → NG
- 「免疫力アップ」「血液サラサラ」 → NG
- 「○○病に良い」「症状が和らぐ」 → NG
- 「日本一」「最強」「No.1」（根拠なし） → 景表法違反

### OK表現
- 「忙しい毎日に」
- 「美容を意識する方に」
- 「健康な生活を続けたい方へ」
- 「家族で続けられる」
- 「○○配合」（成分の事実）

## 機能性表示食品

### 言える範囲：届出した機能性表示のみ
- 消費者庁データベースで届出文言を確認
- **届出文言の改変は一字一句不可**
- 届出番号の明示が必要

例：
> 「本品には〇〇が含まれます。〇〇には△△する機能があることが報告されています。」

→ この文言をそのまま使う。「△△する」を「△△に効く」に変えるとNG。

### 機能性表示食品の必須注釈
- 「本品は、特定保健用食品とは異なり、消費者庁長官による個別審査を受けたものではありません。」
- 「食生活は、主食、主菜、副菜を基本に、食事のバランスを。」
- 「疾病の治療を目的としたものではありません。」

## 特定保健用食品（トクホ）

### 言える範囲：消費者庁長官の許可文言
- 許可表示そのままを使用
- 「お腹の調子を整える」「血圧が高めの方に」等

許可されていない表現はNG。

## 栄養機能食品

### 言える範囲：国が定めた定型文のみ
- 「ビタミンCは、皮膚や粘膜の健康維持を助けるとともに、抗酸化作用を持つ栄養素です。」（規格基準型）
- 改変不可

## 食品（一般食品）

### 言える範囲：美味しさ・食感・産地・製法
- 「素材の旨味」
- 「ふんわり食感」
- 「○○県産」
- 「昔ながらの製法」

### NG表現
- 「健康になる」「ダイエットに最適」「美肌効果」 → 健康食品と同じく標榜不可

### 食品表示法の必須項目
- 名称、原材料名、内容量、賞味期限、保存方法、原産国名、製造者名

## アパレル

### 規制が比較的緩い
- 着心地・デザイン・素材感の訴求
- 「軽い」「動きやすい」「シルエットが綺麗」
- 「日本製」「高品質」（事実なら可）

### 注意点
- 「世界一」「最強」「業界一」 → 景表法
- 「絶対似合う」「保証」 → 景表法
- 家庭用品品質表示法の繊維組成表示

## 雑貨

### 規制
- 物理的効果・機能のみ（軽い・薄い・収納力等）
- 身体への効果は標榜不可（「血行促進」「肩こりに効く」等 → 医療機器扱いの可能性）

### NG表現
- 「腰痛改善」「肩こりに効く」 → 医療機器・医薬部外品の領域
- 「血流改善」「体温上昇」 → 雑貨では NG
- 「電磁波カット」「マイナスイオン」 → 根拠データ必須

## 家電

### 言える範囲
- 機能・スペック（消費電力・対応サイズ・容量等）
- 性能（時短・省エネ等、JIS基準などの根拠）
- 認証・規格（PSEマーク・SG基準）

### NG表現
- 「世界最高」「業界最強」（根拠なし） → 景表法
- 「リフトアップ」「シワ取り」（美容家電） → 薬機法
- 健康効果の標榜（医療機器・医薬部外品の領域）

## 景表法 共通NG

### 優良誤認（事実より優れていると見せる）
- 「天然100%」（実は合成成分含む）
- 「日本製」（実は外国製造）
- 「医師推奨」（実は推奨されていない）

### 有利誤認（実際より得に見せる）
- 「通常価格○○円」（実際にその価格で売っていない）
- 「期間限定」（実際には常時セール）
- 「先着○名様」（実際には全員対象）

### No.1表記の4要件＋必須明示事項
1. 比較対象が適切
2. 調査対象者が適切
3. 調査が公平
4. 表示が調査と適切に対応

必須明示：調査主体・期間・対象・方法・出典

### 二重価格表示 8週間ルール
- セール開始直前の8週間のうち過半（4週間以上）で実販売されていた価格

### 打消し表示 7原則
- 文字サイズ・色・配置・タイミング・関連性・誤認排除・明確性

### 最上級表現
- 「最」「絶対」「完全」「世界一」「業界一」「日本一」 → 根拠5項目必須
- 「No.1」「最安」「最大」 → 同上

## ステマ規制（2023.10〜）

- 規制対象：広告主（事業者）
- インフルエンサー・モニター投稿で広告である旨を明示しないと違反
- PR表記：「広告」「PR」「プロモーション」「Sponsored」を投稿冒頭または常時表示
- タグ末尾埋め込み・極小文字はNG

## 「個人の感想」の打消し限界

- 「個人の感想です」「効果には個人差があります」を書いても**打消し7原則を満たさないと機能しない**
- 効能効果に関する顧客レビューを商品ページに転載すると事業者の表示扱い
- 「シミが消えました！」を商品ページに引用すると違反

## チェックの結論

コピーを書くときの判断順序：

1. **商品カテゴリを確認**（化粧品／医薬部外品／機能性表示食品／一般食品／雑貨等）
2. **そのカテゴリで言える範囲**を確認
3. **景表法・健康増進法・ステマ規制**の共通NGを確認
4. **「効く」「治る」「予防」「保証」「絶対」「最」「No.1」**は最終チェック
5. **詳細な法令確認**は別スキル yakki-keihyo-expression-check で実施
