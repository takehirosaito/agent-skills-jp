# 媒体ポリシー＋薬機法・景表法リスクチェック

各広告媒体の禁止・要注意表現と、法令上のリスク表現を統合。

---

## Meta広告（Facebook／Instagram）ポリシーの要点

### 個人属性の断定（最頻出リジェクト原因）
以下のように**個人を断定・推定**する表現はNG：
- 「あなたは○○ですね」
- 「○歳のあなた」
- 「○○で悩むあなた」
- 「敏感肌のあなた」
- 「最近お金に困っているあなた」

### NG/OK の言い換え
| NG | OK |
|---|---|
| あなたの乾燥肌に | 乾燥が気になる方へ |
| 40歳のあなたに | 40代の女性に |
| 太っているあなた | 体型が気になる方 |
| ハゲのあなた | 髪のボリュームが気になる方 |
| 借金に困っているあなた | 家計を見直したい方へ |

### 健康・美容の禁止カテゴリ
- 「驚異的な減量」「○kg痩せる」（具体数値減量訴求）
- 「ニキビが消える」「シミが取れる」
- before/after画像（特に体重・肌）

### センシティブカテゴリ
- 薬物・タバコ・酒（地域制限）
- 出会い系
- 仮想通貨・FX（事前審査）
- 賭博

### 違反時
- 広告アカウント停止
- ビジネスマネージャー停止
- Pixel連動停止

## 薬機法（医薬品医療機器等法）

### 化粧品の効能効果56項目
- 詳細：yakki-keihyo-expression-check スキルの `references/cosmetics-56-effects.md`
- 化粧品で「シミに効く」「シワを消す」は NG（医薬品的表現）
- 化粧品でOK：「日やけによるシミ・ソバカスを防ぐ」「乾燥による小ジワを目立たなくする」（試験必要）

### 健康食品
- **特定保健用食品（トクホ）**：消費者庁長官の個別許可、許可された保健の用途のみ
- **機能性表示食品**：事業者の届出制、**届出番号必須**、届出文言と一字一句一致
- **栄養機能食品**：国の定型文のみ
- **いわゆる健康食品**：効能効果の標榜不可

### NG表現
- 「治る」「治療」「予防」（化粧品・健食すべて）
- 「○○に効く」（化粧品・一般食品）
- 「○kg痩せる」（具体的減量訴求は機能性表示食品の届出文言以外NG）
- 医師・薬剤師の推薦（化粧品適正広告ガイドライン）

## 景品表示法

### 優良誤認（5条1号）
- 商品の品質を実際より著しく優良に見せる
- 「世界最先端」「業界初」「特許取得」（根拠が無い場合）

### 有利誤認（5条2号）
- 取引条件を著しく有利に見せる
- 二重価格表示（8週間ルール違反）
- 「いつでも解約OK」と実際は最低回数縛り

### No.1表記の4要件
1. 比較する商品等が適切に選定
2. 調査対象者が適切に選定
3. 調査が公平な方法で実施
4. 表示内容と調査結果が適切に対応

**必須明示**：調査主体／期間／対象／方法／出典 の5項目

### 二重価格表示 8週間ルール
セール開始直前8週間のうち過半（4週間以上）で実販売されていた価格であること。

### 打消し表示7原則
1. 文字の大きさ
2. 表示位置
3. 表示時間（動画）
4. 背景との対比（色・コントラスト）
5. 表示エリア
6. 視認しやすさ
7. 重要な情報からの距離

## ステマ規制（景表法5条3号・2023.10.1施行）

### 規制対象
- 商品・サービスを供給する**事業者（広告主）のみ**
- インフルエンサーは規制対象外（広告主が責任）

### PR表記
- 「広告」「PR」「プロモーション」「Sponsored」
- 投稿冒頭または常時表示
- NG：投稿末尾の大量ハッシュタグに紛れ込ませる／「もっと見る」を押さないと表示されない位置

### EC事業者がすべきこと
- インフルエンサー契約書でPR表記を義務化
- 投稿前の事前確認
- 自社EC上の「お客様の声」も依頼・対価関係がある体験談ならPR表記対象

## 違反時のペナルティ

| 法令 | ペナルティ |
|---|---|
| 薬機法 | 業務停止／業務改善命令／2年以下懲役 |
| 景表法 | 措置命令／課徴金（売上3%、繰り返し4.5%）／公表 |
| 健康増進法 | 勧告／命令／罰金 |
| 特商法 | 業務停止／業務禁止／3年以下懲役・300万円以下罰金（直罰） |
