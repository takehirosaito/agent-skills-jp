## 1. 家電（コードレス掃除機・18,000円）

属性とベネフィットの整理：
- 重量1.2kg → 片手・天井OK・高齢者対応
- 吸引力20kPa → カーペット奥のチリ除去
- バッテリー40分 → 家全体1回充電
- LED → 暗所視認
- HEPAフィルター → 花粉0.3μm 99.97%
- 2年保証＋国内サポート

### bullet
1. 【1.2kg軽量・片手で天井まで】両手で持つ重さだったハンディ掃除機を1.2kgに軽量化。片手で天井のホコリまで届き、高齢のご家族にも扱いやすい設計です。
2. 【吸引力20kPa・ワンパス除去】フローリングの細かい砂や毛足の長いカーペットの奥のチリも、20kPaの強力吸引で1回のパスで除去できます。
3. 【40分連続稼働・LED搭載】1回の充電で最大40分稼働、家全体を一気に。先端LEDで暗いソファ下・家具裏のホコリも見逃しません。
4. 【HEPAフィルター・花粉99.97%捕集】0.3μm粒子の99.97%を捕集するHEPAフィルター搭載。花粉・ハウスダストが気になるご家庭でも安心です。
5. 【日本国内2年保証】メーカー直販で2年保証付き。初期不良・故障時は国内サポートが日本語で対応、修理部品の長期供給に対応しています。

## 2. コスメ（敏感肌向け保湿クリーム・4,800円）

属性整理：
- セラミド5種配合
- 無香料・無着色・パラベンフリー
- 第三者皮膚科テスト済み
- 朝晩使用で約2ヶ月
- 詰替パウチ別売

### bullet
1. 【乾燥に揺らぐ敏感肌に】乾燥・季節変化・マスクで揺らぐ肌に。5種のセラミドが角層のすみずみまで浸透し、皮膚にうるおいを与え、皮膚を保護する処方設計です。
2. 【低刺激処方】無香料・無着色・パラベンフリー。アルコール・鉱物油不使用で、敏感肌の方の毎日のケアに使いやすい処方を目指しました。
3. 【朝晩のお手入れに】洗顔・化粧水のあと、適量を手のひらに広げて顔全体になじませてください。朝のメイク前にも使えるべたつかない使用感です。
4. 【第三者機関テスト済み】皮膚科医監修のもとパッチテスト・スティンギングテストを実施。アレルギー試験済み（すべての方に皮膚刺激が起きないわけではありません）。
5. 【30g・約2ヶ月分／詰替対応】朝晩使用で約2ヶ月。リピートしやすい詰替パウチ（別売）もご用意。ご自宅でも旅行用にも使いやすいサイズです。
