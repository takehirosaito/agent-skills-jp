# カテゴリ別 bullet 禁止表現・推奨表現

法令（薬機法・景表法・健康増進法）と Amazon ガイドラインの両面から避けるべき表現と、置き換え案。

## 食品（一般食品）

### NG
- 「○○を治す」「○○に効く」「○○予防」「○○を改善」
- 「ダイエット」「痩せる」「脂肪燃焼」「太りにくい」
- 「血圧低下」「血糖値抑制」「コレステロール改善」
- 「不眠改善」「免疫力向上」「腸内環境改善」

### OK／代替
- 「忙しい朝の手軽な食事に」
- 「美しいスタイルを目指す方に」
- 「毎日のスッキリをサポートする食事に」（届出文言なし）
- 「品質と原料にこだわった」

機能性表示食品・トクホ・栄養機能食品は届出文言・許可表示の範囲内でOK。bullet にも届出番号を付記する。

## 化粧品

### NG（化粧品56項目外）
- 「シミに効く」「シワを改善」「ニキビを治す」
- 「美白」（医薬部外品のみ）
- 「アンチエイジング」（化粧品では言えない）
- 「リフトアップ」「血行促進」「細胞活性化」
- 「ターンオーバー促進」

### OK／代替
- 「日やけによるシミ・ソバカスを防ぐ」（56項目37）
- 「乾燥による小ジワを目立たなくする」（56項目56・試験必要）
- 「肌荒れを防ぐ」（医薬部外品のみ）／「皮膚にうるおいを与える」（化粧品）
- 「エイジングケア（年齢に応じたお手入れ）」

## 医薬部外品

承認効能の範囲内であれば化粧品で言えない表現も可：
- 「メラニンの生成を抑え、シミ・ソバカスを防ぐ」
- 「ニキビを防ぐ」
- 「肌荒れを防ぐ」

ただし「医薬部外品」の表記必須、承認文言の改変不可。

## 健康食品（特定保健用食品／機能性表示／栄養機能食品）

### トクホ
- 個別許可された保健の用途（「お腹の調子を整える」「血圧が高めの方に」など）
- 許可マーク表示

### 機能性表示食品
- 届出文言を**一字一句**変えずに使用
- 例：「○○の機能が報告されています」
- 届出番号を付記

### 栄養機能食品
- 国の定型文をそのまま使用
- 例：「カルシウムは骨や歯の形成に必要な栄養素です」
- 改変NG

## 医療機器

### NG
- 未承認医療機器を医療機器として標榜
- 「美容機器」と称しながら身体の構造機能への影響を訴求
- 「リフトアップ」「血行促進」「シワが消える」

### OK／代替
- 物理的行為のみ（「振動でマッサージ」「温かさを与える」）
- 使用感の主観表現（「使用後のすっきり感」）
- 認証取得済みなら承認効能の範囲内

## 電化製品

### 安全規格
- PSEマーク取得は必須（家電一般）
- bullet に「PSE取得済み」と書く場合は事実のみ
- 「絶対安全」「事故ゼロ」のような誇大表現NG

### 性能訴求
- 数値根拠を明示（吸引力○kPa、騒音○dB）
- 「世界最強の吸引力」「最高性能」は根拠5項目必要
- ライバル比較は自社シリーズ内のみ（A社比はNG）

## アパレル・シューズ・バッグ

### NG
- 「世界最高の素材」（根拠なき最上級）
- 「アトピー・敏感肌の方も安心」（医薬品的）
- 「絶対色落ちしない」（断定表現）

### OK／代替
- 「綿100%、肌触りの良い天然素材」
- 「色落ちに配慮した染色加工」
- 「サイズ感はモデル身長170cm、Mサイズ着用」

### サイズ表記
- 必ず数値で（着丈・身幅・袖丈・ウエスト）
- 「フリーサイズ」のみは不十分、目安寸法を併記

## ベビー・キッズ

### NG
- 「絶対安全」「事故ゼロ」「100%安心」
- 「アレルギーゼロ」「アトピーが治る」
- 医療的効能訴求

### OK
- 「日本の安全基準（SG／PSE／STマーク等）取得」（事実のみ）
- 「対象年齢6か月〜36か月」（具体月齢）
- 「素材試験済み、第三者機関検査」（事実）

## ペット

### NG
- 「治療」「予防」「治す」（動物用医薬品的表現）
- 「絶対安全」
- 「ガン予防」「アレルギー改善」

### OK
- 「年齢別の栄養配合」
- 「グレインフリー（穀物不使用）」
- 「タンパク質含有率○%」

## 全カテゴリ共通

### NG
- No.1／業界一位（根拠5項目なし）
- 「絶対」「必ず」「100%」「完全」
- 「最高」「最強」「世界初」「日本初」（根拠なし）
- 「治る」「効く」「予防」「治療」（医薬品扱いになる）
- 競合企業名・他社商品名・他社ロゴ
- 外部URL、メールアドレス、電話番号
- HTML タグ
- 絵文字

### OK
- 数値で示した属性（具体的事実）
- 認証・規格・受賞歴（根拠を社内保管）
- 用途・対象顧客の限定（「○○向け」「○○なときに」）
- 関連商品との互換性（事実）
- 保証期間（事実）

## 違反時の影響

- Amazon サスペンド（出品停止）リスク
- 景表法措置命令・課徴金（売上3〜4.5%）
- 薬機法違反は措置命令・業務停止・刑事罰
- ステマ規制違反（事業者責任）

詳細な法令遵守チェックは別スキル `yakki-keihyo-expression-check` を併用。
