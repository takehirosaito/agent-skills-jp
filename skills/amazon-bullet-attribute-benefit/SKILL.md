# Amazon bullet 5箇条 属性→ベネフィット設計

## 概要

Amazon商品ページの「商品の特徴」欄に表示される 5箇条の箇条書き（bullet point）を、**「【属性】＋ベネフィット文」の型**で設計するスキル。属性だけ並べても刺さらず、ベネフィットだけだと検索に弱い。両方を1bulletに組み込む「属性→ベネフィット」型が定石。

本スキルはbullet 5箇条の「テーマ配分」「型」「バイト計算」「カテゴリ別NG表現」を中心に扱う。商品タイトルやA+コンテンツとは別レイヤーの最適化。

## ★最重要原則：「【属性】＋ベネフィット」を全bulletで徹底、5項目で重複させない

各bulletは「【属性で釣る】＋ベネフィットで説得する」の二段構造で書く。**5項目すべてが違うテーマ**になるようテーマ配分（標準パターン：主訴求／差別化／使い勝手／安心要素／互換）を先に固める。同じ属性が複数bulletで繰り返されているとCVRもSEOも下がる。

カテゴリ・属性が不明確な場合は、原則として確認質問をする。ただし急ぎの一次稿が必要な場合は、**「最も可能性の高い仮カテゴリで暫定稿を出し、冒頭に『最終判断にはカテゴリ確認が必要』を明示する」**ハイブリッド対応をする。

### バイト計算の早見（要点）

| 項目 | 上限 |
|---|---|
| 1bullet | 255バイト（全角約85字） |
| 5bullet 合計 検索インデックス対象 | 先頭1,000バイト |
| 各bullet 推奨レンジ | 150〜240バイト（全角50〜80字） |

文字種：半角英数1バイト／全角文字3バイト（UTF-8ベース）。数値・単位は半角化でバイト節約＋可読性向上（「１．２ｋｇ」11バイト → 「1.2kg」5バイト）。

## 処理フロー

### Step 1：入力情報の整理

最低限揃えたい情報：
- 商品ジャンル・カテゴリ
- 商品名・ブランド名
- 主要属性（成分／規格／サイズ／重量／容量／対応機種）
- 競合との差別化軸
- 想定顧客（誰のため）
- 価格帯（高単価／低単価／ギフト等のテーマ配分の判断軸）

カテゴリ不明時はハイブリッド対応：仮カテゴリで暫定稿を出し、冒頭で確認必要を明示。

### Step 2：テーマ配分の選定

`references/theme-patterns.md` から商品特性に合うパターンを選択：

| パターン | 適する商品 |
|---|---|
| 標準（誰のため／差別化／使い勝手／安心／互換） | 汎用 |
| 高関与（思想／性能／安全規格／保証／適合） | 家電・カメラ・ベビー（高単価） |
| 低単価・回転商品（主訴求／コスト／バリエ／定期／関連） | 消耗品・日用品 |
| ギフト（贈答シーン／包装／中身／産地／配送） | 贈答・お中元 |
| アパレル（コーデ／素材／サイズ／お手入れ／カラー） | 服・靴 |

### Step 3：属性→ベネフィットの抽出

商品の属性を、ベネフィット（顧客の生活上の意味）に翻訳：
- 「重量1.2kg」→「片手で天井のホコリまで届く、高齢のご家族にも扱いやすい」
- 「セラミド5種配合」→「角層のすみずみまで浸透、皮膚にうるおいを与える」（化粧品56項目内）
- 「ステンレス製」→「サビにくく、食洗機OK、毎日のお手入れがラク」

### Step 4：型に沿って5本書く

各bulletは以下の型：
```text
【属性キャッチ（全角5〜10字）】属性の具体説明＋顧客にとっての意味（全角40〜70字）
```

例：
```text
【1.2kg軽量・片手で天井まで】両手で持つ重さだったハンディ掃除機を1.2kgに軽量化。
片手で天井のホコリまで届き、高齢のご家族にも扱いやすい設計です。
```

### Step 5：バイト数の検算と調整

各bulletを `references/byte-rules.md` の換算で確認：
- 1bullet 255バイト以下
- 5bullet 合計の先頭1,000バイトに主要KW・サブKWが入っている
- 数値・単位は半角化

オーバー時の削り方：
1. 重複している語を1語に
2. 形容詞を削る（「とても」「非常に」は情報量ゼロ）
3. 単位を半角化
4. 接続詞「〜です。〜です」を「〜・〜」に
5. 2情報1bulletを1情報1bulletに再配分

### Step 6：NG表現チェック

`references/category-rules.md` の禁止表現と照合：
- 全カテゴリ共通：「No.1」「最高」「絶対」「100%」、URL／電話、絵文字、HTML、競合社名
- 食品：「治る」「効く」「予防」「ダイエット」「痩せる」「血圧低下」
- 化粧品：「美白」（医薬部外品のみ）、「アンチエイジング」「リフトアップ」「シミに効く」
- 化粧品56項目内の表現に統一
- 健康食品はトクホ／機能性表示の届出文言内

### Step 7：主要KWの配置確認

- 主要KWは **bullet 1番目** に最低1回
- 全bullet通じて先頭1,000バイト内に主要KW・サブKW・関連KW
- bullet 5番目末尾はSEO的に効きにくい → 保証・安心要素優先

## 代表例（コードレス掃除機・18,000円帯）

属性整理：
- 重量1.2kg → 片手・天井OK・高齢者対応
- 吸引力20kPa → カーペット奥のチリ除去
- バッテリー40分 → 家全体1回充電
- LED → 暗所視認
- HEPAフィルター → 花粉0.3μm 99.97%
- 2年保証＋国内サポート

### bullet 5箇条

1. 【1.2kg軽量・片手で天井まで】両手で持つ重さだったハンディ掃除機を1.2kgに軽量化。片手で天井のホコリまで届き、高齢のご家族にも扱いやすい設計です。
2. 【吸引力20kPa・ワンパス除去】フローリングの細かい砂や毛足の長いカーペットの奥のチリも、20kPaの強力吸引で1回のパスで除去できます。
3. 【40分連続稼働・LED搭載】1回の充電で最大40分稼働、家全体を一気に。先端LEDで暗いソファ下・家具裏のホコリも見逃しません。
4. 【HEPAフィルター・花粉99.97%捕集】0.3μm粒子の99.97%を捕集するHEPAフィルター搭載。花粉・ハウスダストが気になるご家庭でも安心です。
5. 【日本国内2年保証】メーカー直販で2年保証付き。初期不良・故障時は国内サポートが日本語で対応、修理部品の長期供給に対応しています。

他ジャンル（コスメ・食品・アパレル・日用品・ベビー・ペット・サプリ）は `references/examples.md` を参照。

## 品質ゲート

- 各bulletが255バイト以下
- 5bullet合計の先頭1,000バイトに主要KWが含まれる
- 主要KWがbullet 1番目に含まれる
- 5項目すべてが異なるテーマ（同一属性の重複なし）
- 全bulletに【属性キャッチ】＋ベネフィット文の型が適用されている
- 数値・単位が半角化されている
- 化粧品の場合は56項目内、健食はトクホ／機能性表示届出文言内、医薬部外品は承認効能内
- 「No.1」「最高」「絶対」「100%」「治る」「予防」等の禁止語なし
- 絵文字・HTML・URL・電話番号なし

## エッジケース

- **カテゴリ不確定**：仮カテゴリで暫定稿、冒頭に「最終判断にはカテゴリ確認が必要」明示（ハイブリッド対応）
- **属性が3つ以下しかない**：使い方シーン・想定顧客・購入後フォローを足して5項目埋める
- **高単価高関与（ベビー・医療機器類似）**：認証・規格（PSE／SG／ST／JIS）と保証・サポートを2項目以上
- **低単価消耗品**：1回あたりコスト・定期便・まとめ買い・補充パックを優先
- **ギフト**：「自分用ではない」前提で受け手目線、包装・熨斗・配送タイミング
- **アパレル**：モデル身長・着用サイズ・実寸目安を必ず入れる
- **健康食品**：トクホ／機能性表示の届出番号・届出表示文言を本文かサブ情報に明記

## 注意事項

- bullet 上限・検索インデックス対象バイト数は仕様変動の可能性あり。最新はAmazon セラーセントラル「スタイルガイド」を確認
- 薬機法・景表法・健康増進法に関する最終判断は別スキル `yakki-keihyo-expression-check` で再確認
- 同じ属性を別bulletに重複させると、CVR・SEO 両方で逆効果
- 文字数は仕様上の上限まで使う必要なし。読みやすさ優先（150〜240バイトが推奨レンジ）
