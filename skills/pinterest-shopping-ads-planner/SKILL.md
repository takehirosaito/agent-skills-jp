# Pinterest ショッピング広告・運用 設計

## 概要

Pinterest をEC集客に使うための運用設計スキル。ビジネスアカウント・商品カタログ連携・ショッピング広告/ピン・ボード/ピン設計・ターゲティング・季節先取りの投稿設計・計測タグを整理する。Pinterestは「これから買うものを計画・保存する」発見型×検索型の媒体で、保存される縦型ビジュアルと季節先取りが効く。インテリア・ファッション・コスメ・ギフト・DIY等と相性が良い。

## 最重要原則

**「縦型・高品質ビジュアルで保存される設計／カタログ連携で商品ピンを面で出す／検索される語（キーワード）とボードのテーマを合わせる／季節は先取り（ユーザーは数週間〜数ヶ月前から計画）／計測タグを入れて効果を可視化」**。Pinterestは即時購買より計画購買。先取りと保存される作りが資産になる。

## 知識ベース

運用の主要ブロック：

| ブロック | 論点 |
|---|---|
| アカウント/カタログ | ビジネスアカウント、商品データフィード連携、商品ピン |
| ピン/ボード | 縦型ビジュアル、説明文のキーワード、テーマ別ボード |
| 広告 | ショッピング広告・標準ピンのプロモート、目的別キャンペーン |
| ターゲティング | キーワード・興味関心・オーディエンス |
| 季節設計 | プランニング期（イベントの数週間〜数ヶ月前）から投入 |
| 計測 | Pinタグ、コンバージョン計測 |

相性の良い領域：インテリア/雑貨、ファッション、コスメ、ギフト、ウェディング、レシピ/DIY 等のビジュアル訴求商材。

> 広告メニュー・カタログ仕様・タグは改定される。確定は Pinterest Business 公式で確認。

## 処理フロー

### Step 1：商材・相性・目的の確認
- 商材（ビジュアル訴求の強さ）、ターゲット、目標、カタログの有無
不明時は「ビジュアル訴求商材・カタログ未連携・季節先取りで認知〜購買」を仮置きし明示。

### Step 2：カタログ・計測の基盤
- 商品フィード連携と商品ピン、Pinタグ・コンバージョン計測の設計。

### Step 3：ボード/ピン設計
- テーマ別ボード、縦型ビジュアル方針、説明文のキーワード設計。

### Step 4：広告・ターゲティング
- 目的別キャンペーン、キーワード/興味関心/オーディエンスの構成。

### Step 5：季節先取りカレンダー
- イベント（季節/ギフト需要）に対し、計画期からの投入スケジュール。

## 出力フォーマット

```
# Pinterest 運用設計：[商材]

## 0. 前提（商材/相性/目的・仮定）
## 1. カタログ・計測の基盤
## 2. ボード/ピン設計（テーマ・ビジュアル・キーワード）
## 3. 広告・ターゲティング構成
## 4. 季節先取りカレンダー
## 5. KPIと検証
```

## 品質ゲート
- 商材のビジュアル相性を踏まえているか
- カタログ連携と計測タグを基盤に置いたか
- ピン説明文に検索キーワードを反映したか
- 季節を先取りしたスケジュールか

## 注意事項
- 広告/カタログ仕様は変動。確定は公式で確認。
- コスメ等は薬機法、価格表示は景表法に配慮。誇大表現を避ける。
- 画像の著作権・権利処理を確認する。
