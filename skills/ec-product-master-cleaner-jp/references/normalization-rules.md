# 表記揺れ統一ルール

## カラー（color）

| 統一表記 | 揺れ候補 |
|---|---|
| ブラック | 黒／クロ／BLACK／Black／black／ブラック／ＢＬＡＣＫ |
| ホワイト | 白／シロ／WHITE／White／white／ホワイト |
| ネイビー | 紺／コン／NAVY／Navy／navy／ネイビー／濃紺 |
| グレー | 灰／灰色／GRAY／Gray／GREY／Grey／チャコール（厳密には別だが運用上統合する場合あり） |
| ピンク | 桃／桃色／PINK／Pink／pink／ローズピンク（厳密別） |
| レッド | 赤／RED／Red／red／クリムゾン（厳密別） |
| ブルー | 青／BLUE／Blue／blue／サックス（厳密別） |
| グリーン | 緑／GREEN／Green／green |
| イエロー | 黄／YELLOW／Yellow／yellow |
| ベージュ | BEIGE／Beige／beige／オークル（厳密別） |
| ブラウン | 茶／茶色／BROWN／Brown／brown／キャメル（厳密別） |
| パープル | 紫／PURPLE／Purple／purple／バイオレット（厳密別） |
| マルチカラー | 多色／マルチ／カラフル／柄物 |

**運用ルール**：
- カタカナ統一が基本（モール検索でカナ表記が主流）
- 厳密に色合いが異なる「クリムゾン」「サックス」「キャメル」等は別カラーとして保持
- 「桃色」など漢字色名は商品ジャンル次第（伝統工芸品・呉服等は漢字保持）
- 末尾のスペース・記号を除去

## サイズ（size）

### アパレル
| 統一表記 | 揺れ候補 |
|---|---|
| XS | XS／Ｘ Ｓ／X.S／エックスエス |
| S | S／Ｓ／small／Small／SMALL |
| M | M／Ｍ／medium／Medium／MEDIUM |
| L | L／Ｌ／large／Large／LARGE |
| LL／XL | LL／Ｌ Ｌ／XL／Ｘ Ｌ／2L／2Ｌ |
| 3L／XXL | 3L／3Ｌ／XXL／XX-L |

**運用ルール**：
- 半角英大文字に統一
- 全角→半角変換
- スペース除去（「Ｌ Ｌ」→「LL」）
- メンズ／レディース／キッズで同じ「L」でも実寸が違うため、サイズ列とは別に「対象列」「実寸列」を持つことを推奨

### 数値サイズ（衣類）
- 「24cm」「24.0cm」「24センチ」 → 「24cm」（半角数字＋半角cm）
- 「100/M」のような複合表記は分割（バスト100cm／Mサイズ）

| 統一 | 揺れ |
|---|---|
| 100ml | 100ml／100ｍｌ／100ミリリットル／100cc |
| 100g | 100g／100ｇ／100グラム |
| 1kg | 1kg／1ｋｇ／1キログラム／1000g |
| 1L | 1L／1Ｌ／1リットル／1000ml |

## 素材（material）

| 統一表記 | 揺れ候補 |
|---|---|
| 綿 100% | コットン100％／cotton 100%／綿100％ |
| ポリエステル 100% | PET／polyester／ポリエステル |
| ナイロン 100% | ナイロン／nylon |
| 麻 | リネン／linen（厳密にはリネンは麻の一種） |
| 絹 100% | シルク／silk |
| 革 | レザー／leather（合皮と本革の区別必須） |
| 合成皮革 | 合皮／PUレザー／フェイクレザー／synthetic leather |
| 本革 | 牛革／genuine leather／本牛革 |

**運用ルール**：
- 「綿」「コットン」のどちらかに統一（ブランド方針次第）
- 配合率は「綿 80% ポリエステル 20%」のフォーマットで統一
- パーセント記号は半角「%」に統一（全角「％」を半角化）
- 革製品は「本革」「合成皮革」を明確に区別（景表法の優良誤認に直結）

## 単位（unit）

| 統一 | 揺れ |
|---|---|
| g | ｇ／グラム／グラム重 |
| kg | ｋｇ／キログラム |
| mg | ｍｇ／ミリグラム |
| ml | ｍｌ／ミリリットル／cc（厳密には別単位） |
| L | Ｌ／リットル |
| cm | ｃｍ／センチ |
| mm | ｍｍ／ミリ |
| m | ｍ／メートル |
| 個 | 個／コ／pcs／個入 |
| 枚 | 枚／pcs／sheets |
| 本 | 本／ボトル／bottles |

**運用ルール**：
- 半角アルファベットの単位に統一
- 数字との間にスペースを入れない（「100g」、「100 g」ではない）
- 「個入り」「枚入り」「本入り」は数量表示の文脈で残す

## 数値表記

- **全角数字→半角数字**：「１２３」→「123」
- **小数点**：全角「．」→半角「.」
- **カンマ区切り**：金額は「3,000円」、寸法は「3000mm」のように使い分け
- **マイナス**：「-」（半角ハイフン）に統一、「−」（全角マイナス）「ー」（長音）と混同しない

## 空白・記号

- **全角スペース→半角スペース**：「商品名　XX」→「商品名 XX」
- **連続スペース→単一スペース**：「商品名  XX」→「商品名 XX」
- **行頭・行末スペース除去**：trim処理
- **タブ→スペース変換**
- **改行コード統一**：CRLF（Windows）／LF（Unix）／CR（旧Mac）→ターゲットモールに合わせて統一
- **句読点**：「、。」を統一、混在「，．」を避ける

## ブランド名・商品名

- **半角英数字の前後に半角スペース**：「ブランド名 Pro Plus 2024」のように半角統一
- **記号統一**：商品名のスラッシュ「/」、ハイフン「-」、コロン「:」を半角に
- **絵文字・装飾文字を商品名に入れない**：「☆」「★」「♪」「→」等の使用はモール検索ペナルティの可能性

## 価格

- **税込／税抜の混在を排除**：必ず一方に統一、列名で明示（price_tax_in / price_tax_out）
- **「￥」「¥」「円」の表記**：内部データは数値のみ保持、表示時に通貨記号付与
- **0円・マイナス価格**：エラーとして検出

## カテゴリ

- 自社カテゴリと各モールのカテゴリは別体系。マッピングテーブルで管理
- 楽天ジャンルID／Amazonブラウズノード／Yahoo!カテゴリID は別スキル（rakuten-genre-id-selector、yahoo-category-path-selector）で扱う

## JAN

- 別スキル（jan-code-checker）でチェックデジット・桁数・重複・国コードを検証
- Excel経由で先頭0が落ちていないかを必ず確認
