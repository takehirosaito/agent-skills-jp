# 未承認文字・機種依存文字・モール別禁止文字

## 機種依存文字（環境依存文字）の代表例

これらの文字は環境（OS／フォント）によって表示が変わる、または表示できないことがある。商品マスタには使わないのが安全。

### 丸数字・記号
| 機種依存 | 代替 |
|---|---|
| ①②③〜⑳ | (1)(2)(3)〜(20) |
| ㈱ | 株式会社 |
| ㊤㊥㊦ | (上)(中)(下) |
| ㈲ | 有限会社 |
| ㊑ | (株) |
| ⅠⅡⅢⅣⅤ | I II III IV V（半角英大文字） |
| ⅰⅱⅲ | i ii iii |
| ⓐⓑⓒ | (a)(b)(c) |
| ☎ | TEL： |
| ㎏㎜㎝ | kg mm cm |
| ℃ | ℃（U+2103）or 「度」 |

### 旧字体・JIS第3水準以降
- 髙（はしごだか）→ 高
- 﨑（たちさき）→ 崎
- 德 → 徳
- 圡 → 土

ただし**人名や地名は旧字体保持が必要な場合あり**（顧客名・店舗名）。商品マスタの本文内では原則新字体に。

## 絵文字

EmojiはUnicodeで割り当てられているが、商品名・属性に使うとモール検索や互換性に問題。

例：「🌟」「✨」「💯」「🌸」「☀️」「⭐」「🔥」

→ 商品名・カテゴリ・属性列での使用は**原則NG**。商品説明文の装飾用途でも、楽天・Amazonは制限・非推奨が多い。

## モール別の制限・禁止文字

### 楽天市場
- 商品名：機種依存文字・絵文字・HTMLタグ使用不可
- 商品名「【】」の多用に違反点数あり（過剰装飾規制）
- 「最安値」「日本一」「業界最安」等の最上級表現は景表法ガイドラインで根拠なしの場合NG
- 半角カナの使用は推奨されない（検索性）

### Amazon
- タイトル禁止文字（公式）：`! $ ? _ { } ^ ¬ ¦`
- HTML文字（`< > &`等）はエスケープ必須
- 絵文字・装飾文字の使用は推奨されない
- 全大文字（大文字のみのタイトル）は禁止

### Yahoo!ショッピング
- 商品名：機種依存文字・絵文字を避ける
- 文字数制限：商品名150文字以内（モール内検索キーワード分も含む）

### Shopify
- 一般的なUnicodeはOK
- ハンドル（URL）に日本語は使えるが、英数字推奨

### Google Merchant Center
- タイトル・説明文に絵文字を入れると不承認になることがある
- HTMLタグ（`<br>`等）は基本不可

## エンコーディング起因の文字化け

### Shift_JISで化ける文字
- `〜`（全角チルダ U+301C）→ Shift_JISでは`～`（U+FF5E）でないと化ける
- `‖`（縦並びダブルバー）
- `−`（全角マイナス U+2212）→ Shift_JISでは`－`（U+FF0D）
- `¢ £ ¬ ®`等の記号

→ Shift_JIS環境（楽天RMS、makeshopの一部）に出す場合、これらを変換するか半角記号に置き換える。

### BOM混入
- UTF-8 BOM（EF BB BF）が先頭に入ると、Excelで開いた時に1列目の名前に変な文字が付いて見える
- 楽天RMS等にBOM付きCSVをアップロードするとエラーになる場合あり
- BOM無しUTF-8で保存する習慣を

### 改行コード
- Windows: CRLF（`\r\n`）
- Unix/Mac: LF（`\n`）
- 旧Mac: CR（`\r`）

CSVでは商品説明欄に改行が含まれる場合、`""`でフィールドを囲む必要がある。エクスポート側・インポート側の改行コード設定を統一する。

## 検出方法

### 正規表現での検出例（参考）

```regex
# 機種依存文字（丸数字）
[①-⑳]   # ①〜⑳

# 絵文字（範囲は広いが代表的なもの）
[\u{1F300}-\u{1F6FF}]
[\u{2600}-\u{26FF}]

# 全角英数字
[０-９Ａ-Ｚａ-ｚ]

# 全角スペース
[　]

# HTML特殊文字
[<>&"']
```

### Excelでの簡易チェック
- 「データ→重複の削除」で重複検出
- 「条件付き書式→ルール→セルの強調表示」で空欄・特定文字を色付け
- ASC関数で全角→半角
- TRIM関数で前後スペース除去

## 修正時の優先順位

1. **モールがエラーで弾く文字**（即修正必要）
   - 楽天の文字数超過、Amazonの禁止記号、Yahoo!の文字数制限
2. **表示崩れの原因となる文字**（早期修正）
   - 機種依存文字、Shift_JIS非対応文字、BOM混入
3. **検索性に影響する文字**（順次修正）
   - 半角カナ、絵文字、装飾文字
4. **表記揺れ**（運用上随時）
   - カラー・サイズ・素材・単位
