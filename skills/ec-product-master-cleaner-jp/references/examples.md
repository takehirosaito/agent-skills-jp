## 例1：化粧品ブランド 500件 商品マスタ

**初期検出**：
- 商品コード重複：12件（型番のスペル違い）
- JAN空欄：35件
- カラー表記揺れ：「ピンク／PINK／桃色／Pink」混在 → 78件
- 機種依存文字「①〜⑤」：説明文に23件
- ㈱：5件
- 全角チルダ「〜」：156件（Shift_JIS化け要因）
- 価格0円：3件（テスト用残り）
- カテゴリ未紐付け：8件

**修正ルール**：

| 修正前 | 修正後 | 件数 |
|---|---|---|
| ピンク／PINK／Pink／桃色 | ピンク | 78 |
| ①〜⑤ | (1)〜(5) | 23 |
| ㈱ | 株式会社 | 5 |
| 〜 | ～（全角チルダ U+FF5E） | 156 |
| 価格0円 | 削除またはステータス変更 | 3 |
| カテゴリ空欄 | 確認の上「スキンケア＞化粧水」等 | 8 |

**段階反映**：
1. バックアップ取得（YYYYMMDD_master.csv）
2. テスト10件で文字置換確認
3. 全件適用
4. モール（楽天）にテストアップロード
5. エラーなければ本番反映

## 例2：食品ブランド 200件 季節商品マスタ

**初期検出**：
- 賞味期限列の表記揺れ：「2026/01/01」「2026.1.1」「2026年1月1日」「26-01-01」混在
- 内容量「100g」「100ｇ」「100グラム」混在 → 65件
- アレルゲン列が空欄：12件
- 商品説明文に絵文字「🍰」「🌟」：8件
- 原材料名が JIS第3水準漢字（旧字体）混入：3件
- 重量がkg表記とg表記混在：4件

**修正ルール**：

| 項目 | 修正前 | 修正後 |
|---|---|---|
| 賞味期限 | バラバラ | YYYY-MM-DD形式に統一 |
| 内容量 | 100ｇ／100グラム | 100g |
| アレルゲン | 空欄 | パッケージ表示を転記（要確認） |
| 絵文字 | 🍰 | 削除または「ケーキ」 |
| 旧字体 | 髙 | 高 |
| 重量混在 | 1kg／1000g | 1kg統一 |

**注意**：食品アレルゲン8品目（えび／かに／くるみ／小麦／そば／卵／乳／落花生）の表示は義務。確認漏れに注意。

## 例3：アパレル 1,200件（カラー×サイズ展開）

**初期検出**：
- バリエーション展開のSKU重複：35件
- カラー：「ネイビー」「紺」「NAVY」混在 → 約220件
- サイズ：「L／Ｌ／LL／Ｌ Ｌ」混在 → 約180件
- 素材表記：「綿100%」「コットン100%」「綿100％」（全角％）混在
- メンズ／レディース混在SKU：10件
- 画像URL 404：18件

**修正ルール**：

| 項目 | 修正前 | 修正後 | 件数 |
|---|---|---|---|
| カラー | ネイビー／紺／NAVY | ネイビー | 220 |
| サイズ | Ｌ／Ｌ Ｌ | L／LL | 180 |
| 素材 | コットン100％ | 綿 100% | 100 |
| 画像404 | 切れリンク | 撮影元から再取得 | 18 |

**バリエーション軸の整理**：
- 軸1：カラー（10色に統一）
- 軸2：サイズ（XS/S/M/L/LL/3L）
- 軸3：対象（メンズ／レディース／キッズ → 別商品コード）

## 例4：家電 80件 マスタ

**初期検出**：
- 型番に半角／全角ハイフン混在：「ABC-123」「ABC－123」 → 25件
- スペック列（W／Ｗ／ワット）混在
- メーカー名表記揺れ：「Panasonic」「パナソニック」「PANASONIC」混在
- 保証期間列空欄：8件
- 重量列の単位混在（kg/g）

**修正ルール**：

| 項目 | 修正前 | 修正後 |
|---|---|---|
| 型番ハイフン | ABC－123 | ABC-123 |
| 単位 | Ｗ／ワット | W |
| メーカー名 | パナソニック／PANASONIC | Panasonic（公式表記に統一） |
| 保証期間 | 空欄 | 商品仕様書から転記 |
| 重量 | 1,200g | 1.2kg（家電は通常kg） |

## 例5：雑貨 300件 マルチカテゴリ

**初期検出**：
- カテゴリ階層がモール間でバラバラ（楽天3階層／Amazon5階層／Yahoo!4階層）
- 同じ商品でモール別の商品名がバラバラ：85件
- 価格がモール別で違う：25件（意図的ならOK、誤入力もあり）
- 自社カテゴリと楽天ジャンルIDの紐付け切れ：18件

**修正ルール**：
- マスター商品名 ＋ モール別商品名（モール別の文字数制限対応）の2列構成に整理
- 価格は「マスター価格」と「モール別価格」を分け、意図的な差は理由列に記録
- カテゴリは別シートでマッピングテーブルを作成（楽天ジャンルID／Amazonノード／Yahoo!カテゴリID）

## 例6：健康食品 100件 マスタ

**初期検出**：
- 機能性表示食品の届出番号空欄：10件（届出済みなのに記載漏れ）
- 「効果」「効能」が説明文に混入：15件（薬機法違反リスク）
- 賞味期限の表記揺れ
- 原材料名の表記揺れ
- 内容量「30粒」「30タブレット」「30錠」混在

**修正ルール**：

| 項目 | 修正前 | 修正後 |
|---|---|---|
| 届出番号 | 空欄 | 消費者庁データベースから取得 |
| 「効果」「効能」 | 削除 | 別スキル（yakki-keihyo-expression-check）で表現チェック |
| 賞味期限 | バラバラ | YYYY-MM-DD |
| 内容量 | 30粒／30タブレット | 30粒（または製品仕様に合わせる） |

**薬機法注意**：
- 一般食品で「効果」「効能」「治る」「予防」は標榜不可
- 機能性表示食品でも届出文言以外は使えない
- 表現チェックは別スキルで実施
