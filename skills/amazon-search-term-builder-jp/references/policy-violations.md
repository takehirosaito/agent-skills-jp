# generic_keywords のポリシー違反語

含めるとサスペンド・検索ペナルティ・景表法／薬機法違反リスクのある語の整理。

## Amazon 規約違反語

### 他社ブランド名・商標
- 「Dyson」「Panasonic」「ルンバ」「ダイソン」（他社商標）
- 「iPhone」「ニンテンドー」「マリオ」
- 自社商品との比較・互換訴求でも含めない
- ブランド名を入れて検索を誘導する行為は明確なポリシー違反

### 他社商品の型番・モデル名
- 「DC74」「ER-X35」など競合の型番
- 商品互換性を訴求したい場合でも generic_keywords には不可
- 互換性は商品仕様欄・bullet で適切に説明

### 公式キャラクター・ライセンス名
- 「ディズニー」「ハローキティ」「ポケモン」「ジブリ」
- 自社が正規ライセンス契約していない限り使用NG

## 景表法違反語

### 根拠なき最上級
- 「No.1」「世界一」「日本一」「業界一」
- 「最高」「最強」「最大」「最先端」
- 「ナンバーワン」「トップ」「一番」

### 根拠なき断定
- 「絶対」「必ず」「100%」「完全」「保証」
- 「永久」「永久保証」（実際に永久保証でない場合）

### 二重価格表示の暗示
- 「○%OFF」「半額」「お買い得」
- 価格比較の根拠が不明な誇大表現

## 薬機法違反語

### 医薬品的効能（健康食品・化粧品）
- 「治る」「治療」「予防」「改善」「効く」「効能」
- 「痩せる」「ダイエット」「脂肪燃焼」（食品）
- 「血圧低下」「血糖値抑制」「コレステロール改善」（食品）
- 「シミが消える」「シワを治す」「アンチエイジング」（化粧品）
- 「美白」（医薬部外品の承認効能、化粧品で使うとNG）

### 化粧品56項目外
- 「リフトアップ」「血行促進」「ターンオーバー促進」
- 「細胞活性化」「肌の再生」
- 「アトピー」「敏感肌に効く」（効能訴求）

### 未承認医療機器
- 「美容医療」「医療効果」「医療レベル」
- 「医療機器」（承認なしで標榜不可）

### 動物用医薬品的表現（ペット）
- 「病気予防」「治療」「治す」
- 「ガン予防」「アレルギー改善」

## 健康増進法違反

### 食品の誇大表示
- 「免疫力向上」「腸内環境改善」（届出なし）
- 「アンチエイジング」「若返り」（食品で）
- 「がん予防」「生活習慣病予防」

## 食品表示法違反

### 産地・品質の誤認
- 「国産」（実際に輸入品）
- 「無添加」（実際は添加物あり）
- 「オーガニック」「有機」（認証なし）

## カスタマーレビューへの誘導語

- 「★5レビュー」「高評価」「人気No.1」
- レビュー操作を示唆する表現

## ステマ規制関連

- 「広告」「PR」「Sponsored」（広告主以外の語として使う場合）
- 「インフルエンサー絶賛」（無断使用・実態と異なる場合）

## カテゴリ別の追加注意

### 医薬品・健康食品
- カテゴリ自体に出品申請が必要
- 効能訴求は届出文言・許可表示の範囲内のみ
- 詳細は `yakki-keihyo-expression-check` スキル

### コスメ・スキンケア
- 化粧品56項目内のみ
- 医薬部外品の承認効能との混同に注意

### アパレル
- 「○○風」（他ブランドの真似を示唆）
- 「○○型」「○○モデル」（他社商品名）

### 家電
- PSE未取得商品の販売自体が違法（一部除く）
- 「医療機器」「治療器」（承認なしの場合）

## 違反検出のための機械チェック

### 機械的にスキャンすべきパターン

```python
ng_patterns = [
    # 他社ブランド
    "ダイソン", "ルンバ", "ニトリ", "ニンテンドー",
    # 最上級
    "No.1", "ナンバーワン", "最高", "最強", "世界一", "日本一",
    # 断定
    "絶対", "必ず", "100%", "完全",
    # 薬機抵触
    "治る", "治療", "予防", "効く",
    "痩せる", "ダイエット", "脂肪燃焼",
    "シミが消える", "美白",
    "アンチエイジング", "若返り",
    "リフトアップ", "血行促進",
]
```

generic_keywords の文字列に上記語が含まれていないか自動チェック。

## グレーゾーン

判断が分かれる語：

### 「効果」「効く」を含む語
- 「お手入れ効果」「美容効果」（汎用的）→ 状況により可
- 「ダイエット効果」「美白効果」（具体的効能）→ NG

### 「対策」「ケア」
- 「乾燥対策」「紫外線対策」（化粧品の56項目内訴求の補助）→ 状況により可
- 「シミ対策」「シワ対策」（効能訴求）→ NG

### 「予防」「改善」
- 「肌の乾燥予防」（汎用） → 状況により可（化粧品56項目「皮膚の乾燥を防ぐ」と整合）
- 「○○病予防」（医薬品的）→ NG

### 「サポート」
- 「健康サポート」「美容サポート」（一般的）→ 可（届出文言の範囲内）
- 「○○症状サポート」（医薬品的）→ NG

## 違反時の影響

### Amazon の対応
- 検索ペナルティ（検索結果に表示されにくくなる）
- 商品ページの非表示化
- サスペンド（出品停止）
- アカウント停止（重大違反の繰返し）

### 法的対応
- 景表法措置命令・課徴金（売上3〜4.5%）
- 薬機法違反は措置命令・業務停止・刑事罰
- 商標権侵害は損害賠償・差止請求

## 違反検出後の対応

1. 該当語を generic_keywords から削除
2. 修正版を再アップロード
3. タイトル・bullet・A+ にも同じ語が無いか確認
4. 過去ASIN すべてで一括スキャン
5. 社内コンプライアンスチェックフローの構築
