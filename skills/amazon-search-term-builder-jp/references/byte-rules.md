# generic_keywords バイト計算ルール

## 上限：249バイト

Amazon.co.jp の `generic_keywords` フィールドは249バイト上限。**超過分は完全に無視**される（一切検索ヒットしない）。

## バイト換算

| 文字種 | バイト数 |
|---|---|
| 半角英数字 | 1バイト |
| 半角記号 | 1バイト |
| 半角スペース | 1バイト |
| 全角ひらがな・カタカナ・漢字 | 3バイト |
| 全角英数字・全角記号 | 3バイト |
| 半角カタカナ | 3バイト |

## 計算例

### 例1：日本語のみ
```text
コードレス 掃除機 軽量 ハンディ ペット 畳 車内 マンション
```
- 全角文字：30字（コードレス5＋掃除機3＋軽量2＋ハンディ4＋ペット3＋畳1＋車内2＋マンション5）＝ 25字 + 7スペース
- バイト数：25 × 3 + 7 = 82バイト

### 例2：半角と全角の混在
```text
USB-C ケーブル 急速充電 PD対応 タイプC 充電器
```
- 半角：USB-C (5) + PD (2) = 7文字 + スペース
- 全角：ケーブル(4) + 急速充電(4) + 対応(2) + タイプC(3字+1半角C?) + 充電器(3)
  - 「PD対応」のPDは半角・対応は全角
  - 「タイプC」のタイプは全角、Cは半角
- 概算：半角文字計10+全角文字計16×3=48+6スペース=64バイト

## 文字数の目安

| バイト数 | 全角文字数 | 半角文字数 |
|---|---|---|
| 100 | 約33字 | 100字 |
| 150 | 約50字 | 150字 |
| 200 | 約66字 | 200字 |
| 249 | 約83字 | 249字 |

実務目安：**全角約80文字、または日本語ベースで20〜25語**

## 区切り文字

- スペース区切り（半角推奨）
- カンマ・ピリオド・括弧は不要・無効
- 改行は不可

## 半角／全角の使い分け

### 半角推奨
- 英数字・型番（USB-C、PD、A4、5G）
- 単位（kg、cm、ml）
- 規格・略語（PSE、TCO）

### 全角推奨
- 日本語（ひらがな・カタカナ・漢字）
- 商品名・カテゴリ名

### 半角推奨の理由
- バイト数が1/3で済む（249バイト枠の節約）
- 検索時に半角入力する顧客に合致

## バイト数チェックの実装

LLMで計算する場合：

```python
def byte_count(text: str) -> int:
    return sum(1 if ord(c) < 128 else 3 for c in text)
```

これで「半角＝1バイト・全角＝3バイト」の概算が得られる。

## 「重複してもバイトを使う」の罠

```text
コードレス コードレス 掃除機
```
↑ 「コードレス」を2回入れても2回分のバイトを消費するが、検索効果は1回と同じ。重複は無駄。

```text
コードレス 掃除機
```
↑ こちらで十分。

## 「単数複数」の扱い

```text
ペット ペットたち
```
↑ Amazon は単数複数を同一視するため、片方で十分。

## 「大文字小文字」の扱い

```text
USB usb Usb
```
↑ すべて同じ扱い。小文字で統一推奨（バイト節約と統一感）。

## 「漢字とひらがな」の扱い

```text
猫 ねこ ネコ
```
↑ 表記揺れは別語として扱われる可能性あり。**メインは漢字、補助でひらがな・カタカナ1つ**が安全。

ただしバイト消費を考えると、3表記すべて入れる価値は薄い。重要KWのみ表記揺れもカバー。

## ストップワードの除外

「が」「の」「を」「は」「で」「に」等の助詞は検索KWとして意味を持たない：

```text
ペットの毛 → ペット毛
車の中で使える → 車内 使える
```

助詞を抜くだけで数バイト節約できる。

## バイト超過時の調整

249バイトを超えたら以下の順で削る：

1. タイトル・bullet 既出KWを削る
2. 同じ意味の類義語（重複）を1つに統一
3. 助詞・接続詞を削る
4. 全角を半角に置換できるもの（英数字・単位）
5. 重要度の低いロングテール語を削る
6. 商品名の冗長部分を削る

## 「半角スペースを全角スペースに」の落とし穴

全角スペース「　」は3バイト消費する。半角スペース「 」を1バイトで節約。

## 「タイトル・bulletに含まれない言葉」の検出

タイトル・bullet 1〜5 のテキストを全結合し、各 KW候補が含まれていないか機械的にチェック：

```python
title_bullets = title + ' ' + ' '.join(bullets)
for kw in kw_candidates:
    if kw not in title_bullets:
        # generic_keywords に入れる候補
```

これで「既に拾えている語」を除外できる。

## 249バイト枠の優先順位

枠を埋める優先順位：
1. 顧客属性語（一人暮らし、高齢者、子育て）
2. 用途・シーン語（マンション、車内、ペット家庭）
3. 類義語（ハンディ、コードレス）
4. 連想・関連商品（新生活、プレゼント、引っ越し）
5. 季節・イベント（父の日、クリスマス）

汎用的すぎる形容詞（「良い」「安い」「便利」）は除外。

## 競合との比較

Brand Analytics の検索クエリパフォーマンスで：
- 自社が表示されているKW
- 競合のみが表示されているKW
- 業界全体で人気のKW

を分析。「競合のみ表示」のKWを generic_keywords に追加すると流入増の可能性。
