# カテゴリ別KW構造

カテゴリ別に「タイトル・bullet で拾えないが顧客が検索する KW」のパターン。

## 家電・電化製品

### タイトル既出になりやすいKW
- ブランド名、型番、スペック数値、容量、寸法、保証年数

### generic_keywords で拾うべきKW
| カテゴリ | 例 |
|---|---|
| 用途・シーン | キッチン、車内、リビング、洗面所、寝室、玄関、屋外 |
| 顧客属性 | 一人暮らし、二人暮らし、子育て、高齢者、ペット家庭、賃貸、マンション |
| 連想・関連 | 新生活、引っ越し祝い、出産祝い、家電プレゼント |
| 季節 | 父の日、母の日、敬老の日、クリスマス |
| 類義語 | ハンディ／コードレス、サイクロン／吸引、エコ／省エネ |
| 状況 | 静音、軽量、コンパクト、おしゃれ |

### 例：コードレス掃除機
```text
ハンディ クリーナー サイクロン マンション 賃貸 一人暮らし 高齢者 ペット 畳 車内 新生活 引っ越し 父の日 プレゼント
```

## カテゴリ横断のチェックリスト

generic_keywords を作る前に：
- [ ] 用途・シーンの語を含む
- [ ] 顧客属性の語を含む
- [ ] 季節・行事の語（該当時）を含む
- [ ] 類義語・俗称を1〜2つ含む
- [ ] 関連商品の連想語を含む
- [ ] タイトル・bullet 既出語を除外
- [ ] 他社ブランド・最上級・効能語を除外
- [ ] 249バイト以内
