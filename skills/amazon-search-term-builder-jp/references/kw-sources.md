# KW収集の情報源

generic_keywords 設計のためのキーワード収集ルート。

## ルート1：Amazon Brand Analytics（ABA）

Brand Registry 登録ブランドのみ利用可能な最強の情報源。

### 取得できるデータ
- 「検索クエリパフォーマンス（SQP）」：自社商品が表示／クリック／購入されたKW
- 「Top Search Terms」：日次／週次の人気検索KWランキング
- 「商品比較」：競合商品との検索KW比較
- 「カスタマー検索行動」：購入までの検索プロセス

### 活用方法
1. 自社商品が「表示されていない」KWを抽出
2. 競合商品が表示されているが自社は表示されていないKWを抽出
3. これらを generic_keywords に追加候補

### 注意
- Brand Registry 登録が前提
- 過去データ最大1年程度
- 検索ボリュームは概算（カテゴリ別の相対値）

## ルート2：Amazon 検索バーの自動補完

任意のユーザーがアクセス可能な無料情報源。

### 方法
1. Amazon.co.jp 検索バーに商品名・カテゴリ語の頭文字を入力
2. 自動補完される候補を抽出
3. 「あ」「い」「う」…と1文字ずつ追加して候補を網羅

### 例
- 「コードレス掃除機」+ あ → 自動補完
- 「コードレス掃除機」+ ペ → 「コードレス掃除機 ペット」

→ 顧客が実際に検索している頻出KWが分かる。

## ルート3：競合商品のタイトル・bullet・レビュー

### 方法
1. カテゴリ上位3〜5商品のタイトル・bullet・商品仕様欄を読み込み
2. 共通する語・独自の語を抽出
3. レビュー本文に頻出する顧客語を抽出

### 抽出するKW
- 商品仕様欄の「対応規格」「素材」「対象」
- bullet で繰り返される機能語
- ★高評価レビューで頻出する満足要素語
- Q&A で繰り返される質問キーワード

## ルート4：自社顧客レビュー・Q&A

詳細は `amazon-review-qa-mining` スキル参照。

### 抽出ポイント
- 顧客が「商品を表現する言葉」（俗称・口語）
- 「使用シーン」を表す言葉
- 「比較対象」として言及される商品・ブランド
- Q&A で繰り返される質問KW

## ルート5：Google・SNS の検索データ

### Google トレンド
- 季節性のKW
- 関連検索の発見
- 急上昇KW

### Google サジェスト
- 「○○ + Amazon」「○○ 安い」「○○ おすすめ」等のキーワードサジェスト
- ローカルニーズの発見

### SNS（X／Instagram／TikTok）
- 顧客の口語表現
- インフルエンサーが使う形容詞
- ハッシュタグから連想語

## ルート6：Yahoo！知恵袋・OKWAVE 等のQ&A

商品ジャンルに関する一般人のQ&A：
- 顧客が「悩んでいる言葉」
- 商品を探すときに使う表現
- 不安・疑問の典型パターン

## KW候補の整理

集めたKWを以下のシートで整理：

| KW | 収集元 | 検索ボリューム推定 | 競合度 | 採用 |
|---|---|---|---|---|
| ハンディ | 検索予測・ABA | 高 | 高 | ◎ |
| ペット家庭 | レビュー | 中 | 中 | ◎ |
| 一人暮らし | Q&A | 中 | 中 | ◎ |
| 軽量 | タイトル既出 | 高 | 高 | ×（既出） |

## 検索ボリュームの推定方法

公式の正確な数字は取得困難だが、以下で推定：

### 1. Brand Analytics の SQP
- 「Search Query Score」がボリューム指標
- カテゴリ内での相対位置で判定

### 2. Amazon 検索バーの自動補完順
- 上位に出る = 検索回数が多い

### 3. Google キーワードプランナー
- 「KW + Amazon」での検索ボリューム
- ECに偏った検索行動の参考

### 4. 競合商品のレビュー数
- KW が含まれる商品のレビュー数 = 売上 = 検索ボリュームの間接指標

## ロングテールKW の発見

ロングテール ＝ 検索ボリュームは少ないが、競合度が低くCVR が高いKW。

### 発見方法
- 検索予測の3〜5語の組合せ
- 「商品名 + 用途」「商品名 + 顧客属性」「商品名 + シーン」
- 例：「コードレス掃除機 ペット家庭 軽量」「コードレス掃除機 高齢者 母の日」

### メリット
- 競合少なく検索結果1ページ目に入りやすい
- CVR が高い（具体的なニーズが明確）
- ロングテール積み上げで総売上に貢献

## KW収集の頻度

| タイミング | 内容 |
|---|---|
| 新商品登録時 | 全ルートで初期KW群を準備 |
| 月次 | Brand Analytics で流入KWの変動確認 |
| 四半期 | 競合のタイトル・bullet 変化を確認 |
| 半期 | 自社レビューの新着分析、季節KW更新 |
| 年次 | カテゴリトレンド分析、KW全面見直し |

## 競合の generic_keywords を見る方法

- **直接は見られない**（非表示フィールド）
- ただし、競合のタイトル・bullet・商品仕様欄を観察することで「拾っているKW」を推測可能
- Brand Analytics で「競合に流入しているKW」を確認

## KW収集時の注意

### 避けるべきKW
- 他社ブランド名（ポリシー違反）
- 他社商品の型番（同上）
- 商標登録された語（無断使用）
- 「最高」「No.1」「絶対」（景表法）
- 効能誇大表現（薬機）

### 採用判断の優先順位
1. 自社商品の特性に合致
2. 顧客が実際に使う言葉
3. 検索ボリュームがある
4. 競合度がそれほど高くない
5. タイトル・bullet に既出していない
