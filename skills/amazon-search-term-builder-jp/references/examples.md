### タイトル
「[ブランド] コードレス掃除機 1.2kg 片手対応 LED搭載 20kPa強力吸引 国内2年保証」

### generic_keywords 候補
```text
ハンディ クリーナー サイクロン マンション 賃貸 一人暮らし 高齢者 ペット 畳 車内 新生活 引っ越し 父の日 プレゼント
```

### バイト計算
- 全角文字：約45字 × 3 = 135バイト
- スペース13個 = 13バイト
- 合計：約148バイト → 249バイト以内 ✅

## 共通の検証ポイント

| 検証項目 | 5商品共通 |
|---|---|
| タイトル既出語を除外 | ✅ |
| bullet既出語を除外 | ✅ |
| 249バイト以内 | ✅ |
| 顧客の実用語ベース | ✅ |
| 他社ブランド名なし | ✅ |
| 最上級表現なし | ✅ |
| 効能誇大表現なし（要修正例ペットの「病気予防」のみ修正後OK） | ✅ |

## 採用優先度の見直し

generic_keywords は 1〜3 ヶ月運用後、Brand Analytics で見直し：
- 流入実績の少ないKW → 削除
- 競合のみ流入のKW → 追加
- 季節KW → 時期に応じて入れ替え
