# 英語ライティング：タイトル・bullet・米国SEO

米国Amazon リスティングの英語ライティングの実務ポイント。

## 英語タイトルの構造

### 基本フォーマット
```text
[Brand] [Product Name], [Key Attribute 1] [Key Attribute 2] [Variation], [Quantity]
```

### 例
```text
[Brand] Cordless Vacuum Cleaner, 2.6 lb Lightweight, LED Headlight, 20 kPa Strong Suction, 40-min Runtime, 2-Year US Warranty
```

### 米国Amazon タイトル仕様
- カテゴリ別文字数（多くは150〜200字）
- 推奨：60〜80字（検索結果表示分）
- 大文字小文字：Title Case（各単語の頭文字を大文字）or 一部UPPERCASE

### Title Case のルール
- 主要な語（名詞・動詞・形容詞）：頭文字大文字
- 冠詞・前置詞・接続詞：小文字（先頭・末尾以外）
- 例：「The Quick Brown Fox Jumps Over the Lazy Dog」

### 一部UPPERCASE（一般的な書き方）
- 製品名・ブランド名・規格・属性：UPPERCASE で強調
- 例：「VACUUM CLEANER」「2.6 LB」「LED」「2-YEAR WARRANTY」
- ただし、Amazon のスタイルガイドで「全大文字は不可」とされる項目もあるので慎重に

## 英語 bullet の構造

### 基本フォーマット
```text
KEY ATTRIBUTE: Benefit description in 1-2 sentences. Additional context or specifics.
```

### 例
```text
LIGHTWEIGHT 2.6 LB DESIGN: Weighing just 2.6 pounds, this cordless vacuum can be operated with one hand, reaching ceiling dust and high corners with ease. Designed for everyone in the family, including seniors who find traditional vacuums too heavy.
```

### 米国 bullet の特徴
- 冒頭に「KEY ATTRIBUTE」を UPPERCASE で強調
- コロン「：」で属性とベネフィットを区切る
- 直接的・断定的（「Helps reduce」より「Reduces」）
- 数字・規格を明示
- 約250〜500文字（英語）

## 英語表現の現地化ポイント

### 1. 直接的な表現

| 日本的表現（直訳） | 米国的表現 |
|---|---|
| Helps support healthy skin | Supports healthy skin |
| Designed to help reduce | Reduces |
| May contribute to | Contributes to |
| Aims to provide | Provides |

### 2. メリット先行

| 日本順 | 米国順 |
|---|---|
| 「○○成分配合の保湿クリーム」 | 「Moisturizing Cream with ○○」 |
| 「軽量で持ち運びやすい掃除機」 | 「Lightweight Vacuum for Easy Carrying」 |

### 3. 数字の活用

米国は数字で説得：
- 「Strong suction」より「20 kPa Suction Power」
- 「Long battery life」より「40-min Continuous Runtime」
- 「Many sizes」より「Available in 4 Sizes」

### 4. 米国の単位

- ml → fl oz（化粧品・液体）
- g → oz、kg → lb（重量）
- cm → inch、m → ft（長さ）
- ℃ → ℉（温度）

すべての数字は米国単位優先、日本単位は括弧書きでサブ表記。

### 5. 文化的配慮

| 日本的 | 米国的 |
|---|---|
| 「お客様の安心」 | 「Customer Trust」「Customer Satisfaction」 |
| 「家族のため」 | 「For the whole family」「For everyone」 |
| 「謙虚な品質訴求」 | 「Confidently engineered」「Premium quality」 |
| 「敬語的丁寧表現」 | 「Direct, professional」 |

### 6. 米国市場で響く価値

- Convenience（便利さ）
- Time-saving（時短）
- Family-friendly（家族向け）
- Eco-friendly（環境配慮）
- Made in USA / FDA-approved / FCC-certified（信頼感）
- Premium quality / Professional grade（質感）

## 英語SEO KW

### 米国Amazon の検索KW収集ルート

1. **Amazon US の検索バーの自動補完**
   - 商品名 + a, b, c... で順次試す

2. **Brand Analytics（US）**
   - Top Search Terms
   - Search Query Performance

3. **競合のタイトル・bullet**
   - 米国上位商品の英語KW

4. **Google Keyword Planner**
   - 「product name + Amazon」での検索ボリューム

### 米国 generic_keywords の特徴

| 項目 | 仕様 |
|---|---|
| 上限 | 249バイト（多くの場合英字のみで250字相当） |
| 区切り | スペース |
| 順番 | 重要なものを先頭 |

### 英語ロングテールの典型

| 軸 | 例 |
|---|---|
| 用途 | for kitchen, for office, for travel |
| 顧客属性 | for seniors, for women, for kids, for college students |
| シーン | for daily use, for camping, for commuting |
| 特性 | lightweight, compact, washable, foldable |
| 季節 | summer, winter, holiday |

### 例：コードレス掃除機の英語 KW
```text
handheld vacuum, lightweight vacuum, vacuum for car, vacuum for pet hair, cordless vacuum for senior, mini vacuum, portable vacuum
```

## 一般的な英語表現の落とし穴

### 1. 「For ○○ people」
- 「For sensitive skin people」（不自然、ピジン英語）
- 正：「For sensitive skin」or「For those with sensitive skin」

### 2. 過度な敬語表現
- 「We humbly ask you to consider...」（卑屈すぎる）
- 正：「We invite you to discover...」

### 3. 重複・冗長
- 「In order to」→「To」
- 「Due to the fact that」→「Because」
- 「At this point in time」→「Now」

### 4. 受動態の多用
- 「Our product was designed to」→「We designed our product to」
- 米国は能動態が好まれる

### 5. 主語の曖昧化
- 「It is recommended that」→「We recommend」or「Try」
- 主語を明確に

## ネイティブチェックの重要性

### 必ずネイティブにチェックさせる項目
1. タイトル
2. bullet 5箇条
3. A+ コンテンツ
4. 商品説明文
5. ブランドストア

### チェック観点
- 自然な英語表現
- 文化的不適切表現の有無
- スペリング・文法
- 米国でのカテゴリ別期待値
- SEO 効果

### ネイティブチェッカーの選定
- 米国出身・英語ネイティブ
- 該当カテゴリの知識
- Amazon マーケティングの経験

## A+ コンテンツの英語化

### 日本版の直訳ではなく、米国版を作り直し

| 要素 | 日本版 | 米国版 |
|---|---|---|
| ヒーロー画像 | 日本人モデル | 米国市場に合うモデル（多様性配慮） |
| ストーリー | 蔵元の歴史 | 「家族経営の品質」「Time-tested」 |
| FAQ | 日本顧客の不安 | 米国顧客の不安（配送・保証・互換性） |
| 安心要素 | 国内サポート | US Warranty, FCC, UL certified |
| カラートーン | 日本的（ベージュ・グリーン） | 米国受けする（明るい・ポップ） |

## US 顧客の期待値

### プライム配送
- 2日配送以内が期待値
- FBA 利用が事実上の標準

### 返品ポリシー
- 30日以内の返品が標準
- 「No questions asked」が顧客期待

### カスタマーサポート
- 英語対応必須
- 24時間以内の返信
- 米国時間帯での営業

### 保証
- 1年〜2年保証が標準
- 「Lifetime warranty」を訴求するなら本当に対応できる体制を

## 翻訳ツールの限界

### Google Translate / DeepL
- 基本翻訳には使えるが、Amazon マーケティング英語としては不十分
- ネイティブチェック必須

### ChatGPT・Claude
- 文脈理解は良いが、Amazon SEO や米国マーケティングの専門性は限定的
- ドラフト→ネイティブチェックの併用

### 専門翻訳業者
- Amazon リスティング翻訳専門の業者がある
- 1リスティング 200〜500ドル程度
- 品質保証あり

## 翻訳後のチェック項目

- [ ] 全ての数字が米国単位
- [ ] 規制・規格が米国対応
- [ ] 効能訴求が FDA / FTC 基準内
- [ ] スペリング・文法エラーなし
- [ ] 自然な英語表現
- [ ] ネイティブチェック完了
- [ ] SEO KW が米国市場向け
- [ ] 文化的不適切表現なし

## 文化的な配慮

### 多様性の尊重
- モデル・イラストは多様な人種・年齢・性別を意識
- 「For everyone」「Family-friendly」

### 政治的・宗教的配慮
- 商品ページに政治的言及をしない
- 特定宗教を前提とした表現を避ける

### ジョーク・スラング
- 米国のジョーク・スラングは商品ページで使わない
- フォーマルで安定した英語

## 結びの定型表現

bullet や A+ の末尾でよく使う：
- 「Built to last」（耐久性）
- 「Backed by our warranty」（保証付き）
- 「Designed for everyday use」（日常使い）
- 「Trusted by [X] customers」（信頼感）
- 「Free shipping with Prime」（配送）
