# レビュー論点分類と対応テンプレ

---

## 1. 論点別の対応方針

### 配送関連
- **遅延**：謝罪／原因（言い訳にしない）／改善策（出荷管理・連絡体制）
- **不在票・受取不能**：配送業者連携、受取方法の選択肢案内
- **追跡番号不明**：自動通知への移行、個別追跡対応
- **梱包破損**：謝罪、無料交換／返金、梱包改善表明

### 商品品質
- **不良品（初期不良）**：謝罪、即対応、原因調査、無料交換／返金
- **イメージ違い**：色味・サイズ感の表記改善、返品条件の案内
- **サイズ違い**：サイズ表示・採寸方法の改善、交換対応
- **耐久性**：使用条件確認、メーカー対応、改善検討

### 梱包
- **破損あり**：謝罪、無料交換、梱包資材見直し
- **簡素すぎる**：エコ／コスト面の理由を簡潔に＋改善検討
- **過剰**：エコ取り組みへの転換を表明

### 対応
- **対応良い（5星）**：感謝、担当者にフィードバック
- **対応悪い（1〜2星）**：謝罪、責任者の言葉、研修強化表明
- **連絡が遅い**：体制改善、自動通知導入

### 価格・送料
- **高い**：価格設定の理由を簡潔に（言い訳にしない）、クーポンの案内（露骨でなく）
- **送料が高い**：地域別送料の明示・送料無料閾値の案内
- **クーポンが使えなかった**：併用条件確認、申し訳ない姿勢

### その他
- **無関係**：丁寧に謝意、具体内容に踏み込まず
- **誹謗中傷**：冷静に短く、必要ならYahoo!運営通報

## 2. 星評価別 標準フレーズ集

### 5星（最高評価）
- 「お喜びいただけたご様子、私どもも大変嬉しく拝読いたしました」
- 「ご期待にお応えできましたこと、何よりの励みでございます」
- 「お忙しい中、温かいお言葉をお寄せいただき、誠にありがとうございます」

避ける：「他のお客様もご満足いただいています」（テンプレ感）

### 4星（小さな指摘あり）
- 「ご満足いただけました点、ありがとうございます」
- 「○○の点につきまして、貴重なご指摘として承りました」
- 「より良い商品・サービスのために、引き続き改善に努めてまいります」

### 3星（中立・改善要望）
- 「ご利用いただき、誠にありがとうございます」
- 「○○の点につきましては、ご期待に沿えませず申し訳ございませんでした」
- 「ご指摘を真摯に受け止め、改善に取り組んでまいります」

### 2星（不満強い）
- 「この度はご不快な思いをおかけし、心よりお詫び申し上げます」
- 「○○についてのご指摘、誠に申し訳ございません」
- 「個別にご連絡を差し上げ、対応させていただきたく存じます」

### 1星（最悪評価）
- 「この度は、当店のご利用において深くご迷惑をおかけしましたこと、心よりお詫び申し上げます」
- 「ご指摘いただきました内容を重く受け止め、責任を持って対応させていただきます」
- 「すでに別途メールにてご連絡を差し上げております」

## 3. 構成テンプレ（標準版・400〜500字）

```
【挨拶】
○○様

この度は当店をご利用いただき、誠にありがとうございます。

【受け止め】
ご評価とご感想をお寄せいただき、感謝申し上げます。
○○についてご満足いただけました／ご不便をおかけしましたこと、〜〜の状況でございました。

【共感／謝意】
（高評価の場合）私どもも大変嬉しく〜〜
（低評価の場合）ご不快なお気持ちにさせてしまいましたこと、心よりお詫び申し上げます

【改善・対応表明】
（高評価の場合）今後とも品質向上に努めてまいります
（低評価の場合）以下の改善に取り組んでまいります：〜〜

【個別対応導線（必要時）】
別途メールにて詳細のご案内を差し上げております。
ご不明な点はストア情報のお問い合わせフォームよりご連絡ください。

【結び】
貴重なご意見を賜り、誠にありがとうございました。
今後ともどうぞよろしくお願い申し上げます。

○○ストア
```

【改善への取り組み】
頂戴したご指摘を受け、以下の改善に取り組んでまいります：
・〜〜
・〜〜
・〜〜

【個別対応】
すでに別途メールにて、〜〜の対応についてご連絡を差し上げております。
ご確認のほど、何卒よろしくお願い申し上げます。

【結び】

## 6. 避けるべき表現

| NG | 理由 |
|---|---|
| 「お客様のご使用方法が誤っております」 | 責任転嫁 |
| 「ご確認の上、お申し付けください」（最初の窓口で） | 不親切 |
| 「すべてのお客様からご満足いただいております」 | テンプレ感 |
| 「次回のお買い物にぜひクーポンを」 | レビュー特典感 |
| 「他のお客様にもご好評です」 | 不満を持つ人に逆効果 |
| 「弊社の規約上、対応できません」 | 冷たい・規約逃げ |
| 「お忙しい中、誠にお手数をおかけいたしまして」 | 意味重複 |

## 7. 「言い訳」と「事実説明」の境界

NG（言い訳）：「物流業者の遅延のため、当店ではどうしようもありませんでした」

OK（事実説明＋自社責任）：「物流に予期せぬ遅延が発生いたしました。お客様への事前のご連絡を当店から行うべきところ、それが行き届かず申し訳ございませんでした。今後は連絡体制を強化してまいります。」

→ **第三者の責任に転嫁せず、自社で取りうる対応**に焦点を当てる。
