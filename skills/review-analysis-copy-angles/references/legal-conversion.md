# 法令範囲内への変換ルール

## レビュー転載の基本ルール

### 転載NG

以下のようなレビュー記述を商品ページに転載すると事業者表示扱いになり、薬機法・景表法違反のリスク。

- 「シミが消えました！」（化粧品では効能標榜不可）
- 「肩こりが治った」（雑貨では医薬部外品の領域）
- 「3kg痩せました」（健食では効能標榜不可）
- 「アトピーが改善」（医薬品の領域）
- 「血圧が下がった」（食品では標榜不可）
- 「絶対おすすめ」「100%効きます」（最上級表現）
- 「他のどの商品より優れている」（比較訴求、根拠必要）

### 転載OK

以下のような感想・体験ベースの記述は転載可能。ただし誇大表現にならないこと。

- 「香りが好み」
- 「使い心地が良い」
- 「手触りがなめらか」
- 「気に入っている」
- 「リピートしています」
- 「贈り物に喜ばれた」
- 「梱包が丁寧だった」

## 効能訴求の変換ルール

### 化粧品

| 顧客の言葉 | 変換例 |
|---|---|
| 「シミが薄くなった」 | 化粧品では転載NG。「日やけによるシミ・ソバカスを防ぐ」（医薬部外品の承認効能のみ） |
| 「シワが目立たなくなった」 | 「乾燥による小ジワを目立たなくする」（試験データがある化粧品のみ） |
| 「肌が白くなった」 | 「明るい肌印象に」（感想ベース、効能訴求にならない範囲） |
| 「ハリが出た」 | 「肌にはりを与える」（化粧品56項目） |
| 「化粧ノリが良い」 | そのまま転載OK（効能訴求ではない感想） |

### 健康食品

| 顧客の言葉 | 変換例 |
|---|---|
| 「肩こりが治った」 | 一般食品では転載NG |
| 「便秘が改善」 | 一般食品では転載NG |
| 「痩せた」 | 機能性表示食品で届出文言ある場合のみ届出文言を使う |
| 「朝スッキリ」 | 感想ベースなら可（効能訴求にならないように） |
| 「家族で続けている」 | そのまま転載OK |

### 雑貨

| 顧客の言葉 | 変換例 |
|---|---|
| 「肩こりに効く」 | 雑貨では転載NG（医療機器の領域） |
| 「血行が良くなった」 | 雑貨では転載NG（医薬部外品の領域） |
| 「使いやすい」 | そのまま転載OK |
| 「軽くて持ちやすい」 | そのまま転載OK |

## 最上級表現の変換

| NG表現 | 変換例 |
|---|---|
| 「No.1」 | 「○○月楽天売上ランキング1位」（具体的期間・カテゴリ） |
| 「最安」 | 「お得な価格で」 |
| 「業界最大」 | 「○○容量」（具体的数値） |
| 「世界一」 | 「○○認証取得」 |
| 「絶対」 | 「○○率○○%」（具体的データ） |
| 「完全」 | 「○○に対応」（具体的範囲） |

## 比較訴求の変換

| NG表現 | 変換例 |
|---|---|
| 「他社より優れている」 | 「○○認証取得（他社品にはなし）」 |
| 「あの有名ブランドより安い」 | 削除、または「お求めやすい価格で」 |
| 「最も売れている」 | 「○○月のランキング○位」 |

比較訴求を残す場合、比較根拠（公正な選定方法・公平な調査）が必要。

## 二重価格表示の確認

「通常価格○○円のところ、特別価格○○円」と表示する場合：
- 「通常価格」がセール開始直前の8週間のうち過半（4週間以上）で実販売されていること
- 違反は景表法上の有利誤認、措置命令・課徴金リスク

## No.1表記の必須5項目

「No.1」「業界1位」等を使う場合：
1. 調査主体
2. 調査期間
3. 調査対象
4. 調査方法
5. 出典

これら5項目すべて明示し、4要件（適切な選定・対象・方法・対応）を満たす必要。

## 打消し表示の7原則

「※個人の感想です」「※効果には個人差があります」を書いても：
- 文字サイズが小さすぎる
- 色が薄すぎる
- 配置が離れすぎている
- 表示時間が短すぎる
- 主張との関連性が薄い
- 誤認を排除できない
- 明確でない

→ これらの場合、打消し表示として機能しない。

## ステマ規制対応

- インフルエンサー・モニター投稿で「広告」「PR」を明示しないと違反
- 投稿冒頭または常時表示
- タグ末尾埋め込み・極小文字はNG
- 規制対象は事業者（広告主）。インフルエンサーではない

## 「お客様の声」として転載する場合

商品ページに「お客様の声」セクションを設ける場合：
- 帰属表記（イニシャル・年代・性別）が望ましい
- 効能訴求にならないレビューを選ぶ
- 評価のばらつきがある（5星のみ集中はやらせ疑惑）
- 「※個人の感想です」は打消しにならない点を意識
- 全体として誇大表現でないか

## 法令変換の流れ

1. レビュー収集
2. 効能訴求・最上級・比較を識別
3. NG表現を変換 or 削除
4. 感想ベースのものをそのまま選択
5. 帰属表記をつける
6. 商品ページに転載
7. 詳細チェックは別スキル yakki-keihyo-expression-check

## チェック早見表

| カテゴリ | 言える | 言えない |
|---|---|---|
| 化粧品 | 化粧品56項目内（うるおい、肌のキメ等） | 効能効果（シミ消える、シワ消える） |
| 医薬部外品 | 承認効能（美白、肌荒れ防止等） | 承認外効能 |
| 機能性表示食品 | 届出文言（一字一句） | 届出外、改変、強化表現 |
| 健食（一般食品） | 美味しさ・原材料・産地 | 効能効果（治る、予防、改善） |
| 食品 | 同上 | 同上 |
| 家電 | 機能・スペック | 健康効果（リフトアップ等） |
| 雑貨 | 物理的効果・機能 | 身体への効果（血行促進・肩こり） |
| アパレル | 素材・着心地 | 過剰な耐久性・健康効果 |
