# ジャンル別 レビュー分析実例6パターン

## 例1：化粧品 美容液 レビュー150件

**評価分布**：5星40% / 4星33% / 3星17% / 2星7% / 1星3%（平均4.0）

**頻出キーワード上位10**：
1. 使いやすい 42件
2. 乾燥 38件
3. 肌触り 35件
4. 香り 30件（無香料）
5. ベタつかない 28件
6. 化粧ノリ 22件
7. リピート 18件
8. コスパ 15件
9. 贈り物 12件
10. 期待外れ 8件

**抽出された訴求軸**：
| 軸 | 顧客の言葉 | コピー案 |
|---|---|---|
| 使い心地 | ベタつかず、肌になじむ | ベタつかない使い心地 |
| 乾燥対策 | 夕方の乾燥が気にならない | 乾燥を感じる夕方も気にならない |
| 無香料 | 香りに敏感だけど大丈夫 | 香りに敏感な方にも |
| 化粧ノリ | 化粧崩れしにくくなった | 化粧ノリの良い肌印象 |
| リピート | 3回目のリピート | リピーター多数 |
| 贈り物 | プレゼントしたら喜ばれた | ギフトにも選ばれている |

**ペルソナ**：30〜40代女性、平日働く、夕方の乾燥・化粧崩れに悩む、添加物に敏感、月5,000〜10,000円スキンケア投資

**ネガティブからの改善**：
- 「期待外れ」8件 → ページで効果実感までの期間を明示「3ヶ月以上の継続使用を推奨」
- 「容器が使いにくい」3件 → 使い方ステップ画像追加

**法令変換例**：
- 「シミが薄くなった」レビュー → 転載NG（化粧品では効能訴求）
- 「ハリが出た」レビュー → 「肌にはりを与える」（化粧品56項目内なら可）

## 例2：健食 サプリ レビュー80件

**評価分布**：5星35% / 4星40% / 3星15% / 2星5% / 1星5%（平均3.95）

**頻出キーワード**：
1. 続けやすい 25件
2. 飲みやすい 22件
3. 朝スッキリ 18件
4. 家族で続けている 15件
5. 大きい 8件（粒のサイズへの不満）
6. 高い 5件

**機能性表示食品の場合**：
- 届出文言「○○の機能が報告されています」を商品ページに明示（一字一句改変NG）
- 「血糖値が下がった」「痩せた」等のレビューは転載NG

**訴求軸**：
- 「続けやすさ」（飲みやすい・粒の大きさ）
- 「忙しい日々のサポート」（朝スッキリ等）
- 「家族で続けられる」

**ネガティブから**：
- 「粒が大きい」 → 商品ページに実寸表示
- 「高い」 → 月額換算でコスパ訴求

## 例3：食品 焼き菓子 レビュー200件

**評価分布**：5星55% / 4星30% / 3星10% / 2星3% / 1星2%（平均4.3）

**頻出キーワード**：
1. 美味しい 80件
2. 贈り物 65件
3. 包装が良い 50件
4. 個包装 45件
5. 老舗 30件
6. 配送が早い 25件
7. 賞味期限が短い 10件

**訴求軸**：
- 「贈答の選ばれる理由」（包装・個包装・老舗）
- 「自宅でのお茶請けにも」
- 「配送・梱包の安心感」

**ペルソナ**：贈答用途が多い、品質重視、口コミで知った

**ネガティブから**：
- 「賞味期限が短い」 → ページで賞味期限・保存方法を明示

## 例4：家電 ハンディクリーナー レビュー300件

**評価分布**：5星40% / 4星30% / 3星15% / 2星10% / 1星5%（平均3.9）

**頻出キーワード**：
1. 軽い 90件
2. 吸引力 75件
3. 充電時間 50件
4. 取り回し 45件
5. 騒音 30件（不満）
6. バッテリー 25件（持続時間への不満）

**訴求軸**：
- 「軽さ」（重量0.6kg・片手で使える）
- 「吸引力」（HEPA フィルター）
- 「取り回しの良さ」（コードレス・ハンドル設計）

**ネガティブから**：
- 「騒音」 → ページに「dB値」表示、防音モード説明
- 「バッテリー持続時間」 → ページに実使用時間を明示「強モード15分・弱モード30分」

## 例5：アパレル Tシャツ レビュー500件

**評価分布**：5星35% / 4星35% / 3星20% / 2星7% / 1星3%（平均4.0）

**頻出キーワード**：
1. 着心地 120件
2. サイズ 100件（不満含む）
3. 色味 80件
4. 素材 70件
5. シワになりにくい 60件
6. 洗濯後 50件

**訴求軸**：
- 「しなやかな着心地」（綿95% ストレッチ）
- 「シワになりにくい」
- 「洗濯後の形状維持」

**ネガティブから**：
- 「サイズが思ったより大きい/小さい」 → ページに実寸サイズ表、モデル着用写真、サイズガイド
- 「色味が画像と違う」 → 着用画像を複数掲載、色見本

**ペルソナ**：
- 5星：30代女性、ヘビーローテーション用
- 1〜2星：サイズ・色味のミスマッチ

## 例6：雑貨 ヨガマット レビュー120件

**評価分布**：5星45% / 4星30% / 3星15% / 2星7% / 1星3%（平均4.1）

**頻出キーワード**：
1. 厚さ 50件
2. 滑り止め 45件
3. 軽い 30件
4. キャリーバッグ 25件
5. 匂い 15件（新品時のゴム臭）
6. 折りたたみ 10件

**訴求軸**：
- 「厚さ6mmで膝・手首への負担軽減」
- 「滑り止めで体勢安定」
- 「1.2kgの軽さ＋キャリーバッグ付き」

**ネガティブから**：
- 「匂い」 → ページに「開封後2〜3日陰干しで匂い軽減」と明示

**法令変換例**：
- 「腰痛が改善」レビュー → 雑貨では転載NG（医薬部外品・医療機器の領域）
- 「ヨガが楽しくなった」 → 転載OK（感想ベース）

## 共通の運用ポイント

1. **レビュー件数30件以上**で本格分析
2. **複数モール横断**でバイアス除去
3. **量的＋質的分析**を必ず両方
4. **ネガティブから改善ヒント**を必ず抽出
5. **効能訴求のレビュー転載NG**
6. **「お客様の声」セクション**は4〜5星の感想ベースのみ
7. **やらせ感を出さない**（ばらつきを残す）
8. **詳細法令チェック**は別スキル yakki-keihyo-expression-check
