# 楽天 季節イベントカレンダーとカテゴリページ向けキーワード

カテゴリページに季節要素を入れる場合は、**終了日とセットで運用**（イベント後に文言を残置すると信用低下）。

## 楽天スーパーSALE（SS）

- 年4回（3月・6月・9月・12月）
- 開催期間：4日 20:00 〜 11日 01:59
- 買いまわり：1ショップ1,000円以上で最大10倍
- ポイント上限：通常7,000pt（条件で変動）
- カテゴリ文では **「楽天スーパーSALE期間中はポイント還元アップ」「半額商品多数」** 等の訴求が定番。終了後の文言差し替えは必須

## お買い物マラソン

- ほぼ毎月開催（時期はRMSの店舗運営Naviで確認）
- 買いまわりルールはSSと同様

## 各種ギフトイベントのコピー素材

### 母の日（5月第2日曜）
- 訴求語：「ありがとう」「いつもの感謝」「カーネーション」「フラワーギフト」
- 鉄板商品：花、スイーツ、健康食品、雑貨、健康器具

### 父の日（6月第3日曜）
- 訴求語：「お父さんへ」「日頃の感謝」「お酒」「健康」
- 鉄板商品：日本酒・焼酎、ビジネス雑貨、健康グッズ

### 敬老の日（9月第3月曜）
- 訴求語：「祖父」「祖母」「健康」「長寿」「孫」
- 鉄板商品：健康食品、お菓子、雑貨、健康器具

### お中元（7月）／お歳暮（12月）
- 訴求語：「のし」「ラッピング」「メッセージカード」「目上の方へ」
- 鉄板：高級食品、調味料セット、酒、産直

### 内祝い・出産祝い・結婚祝い
- 訴求語：「内祝い」「出産祝い」「結婚祝い」「お返し」「のし対応」
- 鉄板：タオル、食品、カタログギフト

## 季節商品のコピー切り替えタイミング

| カテゴリ | 文言切替の目安 |
|---|---|
| 春物 | 2月下旬〜3月から訴求開始、6月上旬で「夏物」へ |
| 夏物 | 5月中旬から訴求、お盆明けに「秋物」へ |
| 秋物 | 8月下旬から、11月で「冬物」へ |
| 冬物 | 10月から、1月セール後に「春物」へ |
| クリスマス | 11月中旬から、12月25日終了で即座に「お正月」へ |
| お正月 | 12月下旬から、松の内（1/7）まで |

## カテゴリページ向け季節文言テンプレート

### 春夏向け（5月〜7月）
> 軽やかな素材と涼やかなカラー。気温が上がる季節に毎日着られる、扱いやすい○○を集めました。母の日のギフトや、初夏の新調にも。

### 秋冬向け（10月〜1月）
> 寒い季節を快適に。あったか素材と機能性を両立した○○の品揃え。クリスマス・お歳暮ギフトとしても人気です。

### 通年カテゴリ
> 季節を問わず使える定番の○○。サイズ・色・素材で絞り込んでお選びいただけます。

切替終了後の文言は **必ず通年版に差し替え**。「クリスマス限定」が1月に残っているのは典型的な信用低下要因。
