# Amazon 出品停止・検索対象外 復旧

## 概要

Amazon.co.jp の異常状態（検索非表示／出品停止／ポリシー警告／アカウントヘルス悪化／ASINサスペンド／アカウントサスペンド）を症状から正しく診断し、適切な復旧手順とPOA（Plan of Action／是正計画書）を作成するスキル。

異常状態は症状によって対応難易度・期間・必要書類が大きく異なる。誤った対応（ポリシー違反系に「再アップロードのみ」など）はかえって悪化させる。本スキルは症状診断フローチャートで正しく分類してから処方箋を出す。

## ★最重要原則：「症状を6段階で正しく診断」→「POAは3点セット（問題認識・是正措置・再発防止策）」

異常状態の6段階：

1. 検索結果から非表示（Suppressed Listing） - 必須属性・画像不備
2. 出品停止（Listing Inactive） - 在庫・価格・ポリシー
3. ポリシー違反警告 - 期限付き是正要求
4. アカウントヘルス低下 - ODR・配送遅延等の指標
5. ASIN サスペンド - 真贋・知財・重大ポリシー
6. アカウント サスペンド - 重大違反累積・組織的問題

各段階で対応手順・難易度・期間が違う。混同すると致命的。

POA作成時は必ず3点セット：
1. **問題の特定**（指摘を否定せず客観的に認める）
2. **是正措置**（具体的・数値・期間・担当）
3. **再発防止策**（個人努力ではなく仕組み）

「努力します」「気をつけます」だけのPOAは却下される。

入力情報が不足している場合（症状が複合的・通知文未確認など）でも止まらず、最も可能性が高い症状を仮定して暫定対応を出し、「最終判断にはセラーセントラル通知文の確認が必要」を冒頭明示するハイブリッド対応。

### 6段階のサマリー

| 段階 | 症状 | 復旧難易度 | 期間目安 |
|---|---|---|---|
| 1. 検索非表示 | URLは開くが検索結果に出ない | 低〜中 | 1〜7日 |
| 2. 出品停止 | カート投入不可 | 低〜高 | 即時〜30日 |
| 3. ポリシー警告 | 期限付き是正要求 | 中〜高 | 14〜30日 |
| 4. アカウントヘルス | 指標悪化 | 中〜高 | 60〜180日 |
| 5. ASINサスペンド | 商品ページ閲覧不可 | 高 | 14〜60日 |
| 6. アカウントサスペンド | ログイン警告／出品権停止 | 最高 | 30日〜永久 |

## 処理フロー

### Step 1：症状の正確な診断

セラーセントラルの3画面を必ず確認：

1. **在庫管理＞ステータス**：在庫切れ／検索非表示／販売停止／一時停止
2. **パフォーマンス＞アカウントヘルス**：ODR・配送遅延・キャンセル
3. **メッセージセンター／パフォーマンス通知**：警告・期限付き要求

商品ページのフロントエンド確認：
- URL直叩きで閲覧可？
- 検索結果に表示？
- カート投入可？

診断フローチャート（`references/issue-types.md`）：

```text
商品ページ閲覧可能？
├─ Yes → 検索結果に出る？
│         ├─ Yes → カート投入可？
│         │         ├─ Yes → 通常販売中（or 警告中）
│         │         └─ No → 出品停止（在庫・価格・ポリシー確認）
│         └─ No → 検索非表示（必須属性・画像確認）
└─ No → ASINサスペンド（POA 必要）

セラーセントラル ログイン可能？
├─ No → アカウントサスペンド（緊急対応）
└─ Yes → ヘルスダッシュボード確認
```

### Step 2：原因の分類

セラーセントラル通知文・suppressed reason・パフォーマンス通知の文言から原因を分類：

| 大分類 | 詳細 | 主な解決方法 |
|---|---|---|
| 画像不備 | メイン画像規定違反・未登録 | 画像差替え（`amazon-main-image-checker`） |
| 必須属性欠落 | カテゴリ別必須項目未入力 | フラットファイル再登録 |
| 商品説明・タイトル | 長さ・形式違反 | 修正・再アップロード |
| 価格範囲外 | Amazon参考価格と乖離大 | 価格修正 |
| 在庫切れ | quantity=0 | 補充 |
| ポリシー違反 | 誇大表現・禁止商品 | POA＋修正 |
| 真贋苦情 | 偽物通報 | POA＋仕入証明 |
| 知財侵害 | 商標・著作権通報 | POA＋ライセンス確認／Brand Registry対応 |
| 安全性 | リコール対象・PSE未取得等 | POA＋認証取得 |

### Step 3：自己解決可否の判定

- **自己解決可**：商品ページ修正で復旧（検索非表示・在庫・価格）
- **POA必要**：ポリシー違反・サスペンド系
- **専門家相談**：アカウントサスペンド・重大知財侵害

### Step 4：修正手順の作成

原因別の具体手順（`references/remediation-steps.md`）：

- **画像差替え**：純白背景・85%占有率・1000px以上ZOOM・テキストロゴ枠なし
- **属性補完**：カテゴリ別必須項目をフラットファイル or 商品編集で埋める
- **タイトル修正**：カテゴリ別文字数（一般200／アパレル130／カメラ50）内、禁止語除去
- **価格調整**：Amazon自動価格制御を解除 or 範囲内に修正
- **薬機・景表表現の修正**：禁止語リストで全文スキャン（`yakki-keihyo-expression-check`）

### Step 5：POA作成（ポリシー違反・サスペンド系）

POA 3点セットを `references/poa-template.md` のテンプレートで作成：

````text
ASIN:B0XXXXXXXX [症状] に関する是正計画

【問題】
[Amazonの指摘内容を要約・自社認識を客観的に記載]

【是正措置】
1. [具体的措置1]：[何をしたか・いつ・誰が]
2. [具体的措置2]：
3. [具体的措置3]：

【再発防止策】
1. [仕組み1]：[いつから・誰が・どう運用]
2. [仕組み2]：
3. [仕組み3]：

【添付資料】
1. [仕入請求書／製造証明／認証書／社内マニュアル等]
````

長さ目安：500〜1,500字。短すぎ（300字未満）は説得力不足、長すぎ（3,000字超）は重要点埋没。

### Step 6：サポート問い合わせ文面

セラーサポート向けの問い合わせ文面を症状別に作成：

- 件名：「ASIN:B0XXXXXXXX [症状] の解除依頼」
- 本文構成：自社情報・問題認識・是正完了内容・添付資料・確認依頼

### Step 7：再発防止チェックリスト

社内で運用する再発防止チェックリストを作成。POA の再発防止策をチェック項目化。

## 代表例（検索非表示・画像不備）

| 段階 | 内容 |
|---|---|
| 症状 | 検索結果に出ない、URL直叩きで閲覧可 |
| 確認 | 在庫＞検索結果から非表示の商品 → Suppressed Reason「メイン画像の規定違反」 |
| 原因 | メイン画像に商品以外のオブジェクト（背景小物）が映り込み |
| 修正 | 純白背景＋商品占有85%以上＋1000px以上の画像に差替え |
| 期間 | 修正後24〜48時間で再表示 |
| POA | 不要（自己解決） |

詳細ケース集（軽症〜重症）は `references/recovery-cases.md`。

## 品質ゲート

- 症状を6段階のいずれかに正確に分類している（混同していない）
- セラーセントラルの3画面（在庫管理／アカウントヘルス／メッセージ）を全て確認している
- 自己解決可とPOA必要を正しく振り分けている
- POAは3点セット（問題認識・是正措置・再発防止策）を全て含む
- POAの是正措置に「具体的な数値・期間・担当」が明記されている
- 再発防止策が「個人の注意」ではなく「仕組み」になっている
- 添付資料リストが具体的（仕入請求書・認証書・社内マニュアル等）
- サポート文面に件名・ASIN・是正措置・添付資料が含まれる
- アカウントサスペンド等の重大ケースで「専門家相談」を提案している

## エッジケース

- **複数ASINで同時発生**：根本原因（カテゴリ共通の属性ミス・仕入元の共通問題）を疑い、横展開で全件チェック
- **POA提出後にリジェクト**：追加の証拠資料・より具体的な再発防止策を準備して再提出。3回以上のリジェクトは弁護士相談
- **真贋苦情で正規品の場合**：仕入請求書・メーカー証明書・Brand Registry 連携で証明。「正規品です」だけの主張はNG
- **知財侵害通報で身に覚えなし**：通報者連絡・Amazon TRC（知財侵害テイクダウン）への異議申立
- **アカウントヘルス指標は緑だが警告あり**：ASIN固有の問題。アカウント全体を巻き込まないよう個別ASIN対応
- **アカウントサスペンドで永久停止判断**：他販路（楽天・Yahoo・自社EC）への移行を並行検討
- **症状が複合（検索非表示＋ポリシー警告）**：警告対応を優先（期限超過でサスペンド昇格を回避）

## 注意事項

- ポリシー違反系を「再アップロードのみ」で済ませると悪化する。POA提出が必要
- POAを「Amazonの指摘は不当」と否定する書き方はNG。客観的に問題を認める
- アカウントサスペンドは復活率40〜50%程度。一発で復活させるため弁護士・専門家相談を推奨
- 重複アカウント運営は重大違反。家族・会社名義の重複も注意
- 仕入請求書・製造証明・認証書は最低3年保管（POA作成時に即出せるように）
- 仕様（指標基準・期限・POA要求事項）は変動。最新はセラーセントラル「アカウントヘルス」ヘルプで確認
