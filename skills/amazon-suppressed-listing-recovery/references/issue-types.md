# 非表示／出品停止／サスペンドの判別

Amazon リスティングが何らかの異常状態にあるとき、症状を正確に判別するためのガイド。

## 1. 検索結果から非表示（Suppressed Listing）

### 症状
- 検索結果には表示されない
- 商品ページのURLを直接開けば閲覧可能
- 購入可能（カート投入可）
- セラーセントラルでは「修正が必要」「検索結果から非表示」と表示

### 確認場所
- セラーセントラル「在庫＞検索結果から非表示の商品」
- ASIN 毎に「Suppressed Reason」が表示される

### 主な原因
- 必須属性の欠落（カテゴリ別必須項目）
- メイン画像の未登録 or 規定違反
- 商品説明文の長さ違反・形式違反
- タイトル文字数違反
- 出品許可カテゴリでない（医薬品・酒類等）

### 復旧難易度：低〜中
- 多くは自己解決可能
- 必要情報を埋めるだけで再表示されることが多い

## 2. 出品停止（Listing Inactive）

### 症状
- 商品ページに「現在お取り扱いできません」表示
- 検索結果に表示されない
- カート投入不可
- セラーセントラル在庫管理では「在庫切れ」「出品停止中」と表示

### 確認場所
- セラーセントラル「在庫＞在庫管理＞ステータス」
- 「アクティブ」以外のステータスを確認

### 主なステータスと原因

| ステータス | 原因 |
|---|---|
| 在庫切れ | quantity=0 |
| 価格範囲外 | Amazon の参考価格と乖離大 |
| 検索結果から非表示 | 上記1の状態 |
| 販売停止中 | ポリシー違反 |
| 一時停止中 | アカウント問題 |

### 復旧難易度：低〜高
- 在庫切れ：補充で復旧
- 価格範囲外：価格修正で復旧
- ポリシー違反：POA 必要

## 3. ポリシー違反警告

### 症状
- セラーセントラル「メッセージ」「パフォーマンス通知」に警告
- ASIN 自体は販売継続中の場合あり
- 「○月○日までに対応必要」のような期限付き

### 確認場所
- セラーセントラル「メッセージセンター」
- 「パフォーマンス＞アカウントヘルス」

### 主な警告内容
- 商品の真贋に関する苦情
- 商品の状態に関する苦情（破損・期限切れ）
- 知的財産権侵害の通報
- 出品ポリシー違反（誇大表現・禁止商品）

### 復旧難易度：中〜高
- 期限内にPOA 提出で復旧
- 放置すると ASIN サスペンド or アカウントサスペンドへ悪化

## 4. アカウントヘルス低下

### 症状
- ヘルスダッシュボードの指標が黄色／赤
- メッセージで「アカウントの状況改善が必要」通知
- ASIN 自体は販売継続

### 確認場所
- セラーセントラル「パフォーマンス＞アカウントヘルス」
- 各指標（ODR、配送遅延率、注文キャンセル率など）

### 主な指標と基準（最新は要確認）

| 指標 | Amazon 基準 |
|---|---|
| 注文不良率（ODR） | 1%以下 |
| 配送遅延率 | 4%以下 |
| 注文キャンセル率 | 2.5%以下 |
| 出品停止率 | 規定値以内 |
| 有効な追跡率 | 規定値以上 |

### 復旧難易度：中〜高
- 指標改善には時間がかかる（60〜180日）
- 全ASIN・全注文に影響する根本対応

## 5. ASIN サスペンド

### 症状
- 商品ページが完全閲覧不可
- 「この商品は現在お取り扱いできません」
- セラーセントラル在庫管理で「販売停止」

### 主な原因
- 偽物通報
- 知的財産権侵害（商標・著作権）
- 重大なポリシー違反
- 安全性問題（リコール対象）

### 復旧難易度：高
- POA + 証拠書類が必須
- 商標権者の場合は Brand Registry テイクダウン
- 偽物疑いは仕入証明・真贋鑑定

## 6. アカウントサスペンド

### 症状
- セラーセントラルログイン時に警告表示
- 出品権の停止
- 既存注文の処理は継続される場合あり

### 確認場所
- ログイン直後の警告画面
- メッセージセンターの「アカウント停止通知」

### 主な原因
- 重大なポリシー違反の累積
- 安全性問題（複数ASINで）
- 偽物販売の組織的疑い
- 重複アカウント運営
- 規約違反による永久停止判断

### 復旧難易度：最高
- 復活率は低い（40〜50%程度）
- POA + 法的書類（弁護士関与）が必要なケース
- 永久停止の場合は復活不可

## 症状診断フローチャート

```text
商品ページ閲覧可能？
├─ Yes → 検索結果に出る？
│         ├─ Yes → カート投入可？
│         │         ├─ Yes → 通常販売中（問題なし or 警告中）
│         │         └─ No → 出品停止（在庫・価格・ポリシー確認）
│         └─ No → 検索非表示（必須属性・画像確認）
└─ No → ASIN サスペンド（POA 必要）

セラーセントラル ログイン可能？
├─ No → アカウントサスペンド（緊急対応）
└─ Yes → ヘルスダッシュボード確認
          └─ 警告あり → アカウントヘルス改善
```

## 各症状への初期対応

### 検索非表示
1. セラーセントラル「在庫＞検索非表示」で具体的原因確認
2. 該当属性を補完
3. 24〜48時間で再インデックスを待つ

### 出品停止
1. 在庫管理で詳細ステータス確認
2. 原因（在庫・価格・ポリシー）に応じた対応
3. ポリシー違反系はPOA作成

### ポリシー警告
1. 通知文を完全に読む
2. 期限内にPOA作成・提出
3. 期限超えると ASIN／アカウントサスペンドに発展

### アカウントヘルス
1. 全指標確認
2. 悪化指標の根本原因（FBM か FBA、商品カテゴリ）特定
3. 中長期改善計画

### ASIN サスペンド
1. 通知内容と添付書類確認
2. 是正と証拠資料準備
3. POA 作成・提出
4. リジェクト時は追加資料で再提出

### アカウントサスペンド
1. 緊急対応：原因特定
2. 重大ケースは弁護士相談
3. POA 作成・提出
4. 並行で他販路への影響軽減

## 復旧期間の目安

| 症状 | 復旧期間目安 |
|---|---|
| 検索非表示 | 1〜7日 |
| 出品停止（在庫切れ） | 即時（補充後） |
| 出品停止（価格） | 即時（価格修正後） |
| 出品停止（ポリシー） | 7〜30日 |
| ポリシー警告 | 14〜30日 |
| アカウントヘルス | 60〜180日 |
| ASIN サスペンド | 14〜60日 |
| アカウントサスペンド | 30日〜永久（不可も） |

## 緊急対応の優先順位

1. アカウントサスペンド（即時、専門家相談）
2. ASIN サスペンド（24時間以内のPOA）
3. ポリシー警告（期限内対応）
4. アカウントヘルス悪化（1週間以内の改善計画）
5. 出品停止（数時間〜1日）
6. 検索非表示（数日）

## 予防策

### 商品ページの品質
- カテゴリ別必須属性を全埋め
- メイン画像の規定遵守
- 禁止語チェック

### 仕入管理
- 正規ルート仕入のみ
- 仕入請求書の保管
- メーカー証明書の取得

### アカウント運用
- 重複アカウントなし
- 規約改定の定期チェック
- パフォーマンス指標の月次モニタリング

### 法務
- 商標登録・Brand Registry
- 法令遵守（薬機・景表・特商法）
- 弁護士・顧問の常設
