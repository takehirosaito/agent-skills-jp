# POA（Plan of Action / 是正計画）の書き方

Amazon にリスティング復旧をアピールするための POA（是正計画書）の構成と書き方。

## POA の3点セット

POA は以下の3点を明確に：

| 項目 | 内容 | 重要度 |
|---|---|---|
| 1. 問題の特定 | 何が問題だったか | ◎ |
| 2. 是正措置（Root Cause Analysis） | 具体的に何を直したか | ◎ |
| 3. 再発防止策（Long-term Plan） | 同じ問題を起こさない仕組み | ◎ |

3点が揃わないと却下される傾向が強い。

## POA の長さ目安

- 短すぎ：300字未満 → 説得力不足
- 適切：500〜1,500字
- 長すぎ：3,000字以上 → 重要点が埋没

## POA の構成（推奨）

### 件名
```text
ASIN:B0XXXXXXXX [症状] に関する是正計画
```

### 冒頭の挨拶
```text
お世話になっております。
下記ASINの[症状]について、原因特定と是正、再発防止策をご報告いたします。
```

### 【問題】
```text
（Amazon の指摘内容を踏まえて、自社として問題を認識）

[Amazonからの通知内容を要約]
[自社の認識]
```

ポイント：
- Amazonの指摘を否定しない
- 「指摘は不当」のような表現は避ける
- 客観的に問題を認める

### 【是正措置】
```text
1. [措置1]：[具体的に何をしたか]
2. [措置2]：[具体的に何をしたか]
3. [措置3]：[具体的に何をしたか]
```

ポイント：
- 抽象的でなく具体的に
- 「努力します」「今後は気をつけます」だけはNG
- 数値・期間・担当を明記
- 証拠資料を必ず添付

### 【再発防止策】
```text
1. [仕組み1]：[いつから・誰が・どう]
2. [仕組み2]：[いつから・誰が・どう]
3. [仕組み3]：[いつから・誰が・どう]
```

ポイント：
- 個人の注意ではなく「仕組み」を提示
- 社内マニュアル・チェックリスト整備
- 第三者チェック・承認フロー
- 定期点検・教育

### 添付資料リスト
```text
1. [資料1]：[内容説明]
2. [資料2]
3. [資料3]
```

### 結び
```text
上記の通り是正と再発防止策を整備いたしました。
[ASINの販売再開／検索結果への再表示／警告解除]をお願いいたします。
追加で必要な情報がございましたら、お知らせください。

よろしくお願いいたします。
```

## POA テンプレート集

### テンプレ1：検索非表示（必須属性欠落）

```text
件名：ASIN:B0XXXXXXXX 検索非表示の是正計画

お世話になっております。
下記ASINの検索結果から非表示状態について、原因特定と是正・再発防止策を
ご報告いたします。

【問題】
電化製品カテゴリの必須属性「voltage（電圧）」「wattage（消費電力）」が
空欄でした。これにより検索結果から非表示扱いとなりました。

【是正措置】
1. メーカー仕様書を確認し、正しい値を取得
   - voltage: 100V
   - wattage: 60W
2. 関連属性も同時に補完
   - power_source_type: ac
   - wattage_unit: watts
3. 2025年X月X日 [時刻] に登録完了

【再発防止策】
1. 新商品登録時のチェックリストを整備
   - カテゴリ別必須属性リストを社内マスタ化
   - 登録前にメーカー仕様書から必須属性を埋めるフローを義務化
2. 月次の在庫管理「修正が必要」項目を社内モニタリング
   - カタログ担当者が毎月1日に確認、即時対応
3. 既存ASINの全件監査
   - 同一カテゴリ商品の必須属性を全件確認、欠落があれば即補完

【添付資料】
1. メーカー仕様書（PDF）
2. 修正前後の商品ページスクショ
3. 社内チェックリスト（PDF）

検索結果への再表示をお願いいたします。
よろしくお願いいたします。
```

### テンプレ2：偽物疑いによるサスペンド

```text
件名：ASIN:B0XXXXXXXX 出品停止に関する是正計画

お世話になっております。
下記ASINの出品停止について、正規流通品である証明と再発防止策を
ご報告いたします。

【問題】
偽物疑いによる出品停止のご通知をいただきました。
本商品は弊社が正規ルートで仕入れた正規品ですが、ご指摘を真摯に受け止め、
仕入経路・流通権の証明と社内体制強化をご報告いたします。

【是正措置・証拠資料】
1. 正規仕入の証明
   - メーカー[製造元名]からの直近90日分の請求書（添付1）
   - メーカー流通権証明書（添付2）
2. 製品の真贋証明
   - 弊社品質保証部発行の真贋鑑定書（添付3）
   - 製造ロット番号と仕入記録の対応表（添付4）
3. Brand Registry 申請（手続中）
   - 商標登録第○○号に基づくブランド登録申請書（添付5）

【再発防止策】
1. 仕入管理の徹底
   - 仕入先の正規流通権を毎年確認、契約書保管
   - ロット番号管理の電子化
2. 真贋確認フロー
   - 入荷時の検品で真贋確認、抜取検査を実施
3. Brand Registry 完了後の権利保護
   - 完了次第、テイクダウン申請による偽物排除を開始

【結び】
正規ルート品であることをご確認の上、出品再開をお願いいたします。
追加情報が必要な場合はご指示ください。

よろしくお願いいたします。
```

### テンプレ3：注文不良率（ODR）悪化

```text
件名：アカウントヘルス改善計画（ODR）

お世話になっております。
注文不良率（ODR）が基準を上回ったことについて、原因分析と改善計画を
ご報告いたします。

【問題】
過去60日のODRが [X]% となり、Amazon の基準1%を上回りました。
構成要素を分析した結果、以下が主要因と特定しました：
- A-to-z申し立て率：[X]%（増加要因A）
- マイナスフィードバック率：[X]%（増加要因B）

【是正措置】
1. 主要因Aへの対応
   - [具体的施策]
2. 主要因Bへの対応
   - [具体的施策]
3. 既存問題注文への個別対応
   - 該当顧客への返金・商品再送・お詫び連絡を完了

【再発防止策】
1. オペレーション改善
   - 商品ページ品質チェックを月次レビューに組み込み
   - カスタマーサポートのSLA設定（24時間以内返信）
2. 配送品質向上
   - FBA活用比率を [X]%から[Y]%へ引き上げ
   - 自社発送商品の梱包改善
3. 月次モニタリング
   - アカウントヘルス指標を月次会議で確認
   - 基準値接近時に即座にアラート

【目標】
- 30日：ODR [現状]% → [中間目標]%
- 60日：[最終目標]% 以下を継続

【添付資料】
1. 過去60日の問題注文一覧と原因分析
2. 是正措置の実行記録
3. 新オペレーションマニュアル

よろしくお願いいたします。
```

## POA で避けるべき表現

### NG表現
- 「Amazon の指摘は誤りです」
- 「弊社に問題はありません」
- 「他社も同じことをしている」
- 「努力します」「気をつけます」（具体性なし）
- 「二度と起こしません」（仕組み不在の宣言）

### OK表現
- 「ご指摘を真摯に受け止め」
- 「具体的に[X]を実施しました」
- 「[期日]までに[施策]を完了予定」
- 「再発防止のため[仕組み]を整備しました」

## POA の検証ポイント

提出前に以下をチェック：

- [ ] Amazonの指摘内容が正確に反映されている
- [ ] 「問題・是正・再発防止」の3点セットが揃っている
- [ ] 是正措置が具体的（数値・期日・担当）
- [ ] 再発防止が「仕組み」である（個人努力でない）
- [ ] 添付資料が揃っている
- [ ] 500〜1,500字に収まっている
- [ ] 否定的・反論的な表現がない
- [ ] 件名がASIN・問題種別を明示

## 提出ルート

| 状況 | 提出ルート |
|---|---|
| 検索非表示 | セラーセントラル「在庫＞検索非表示」から修正後、自動再評価 |
| 出品停止（ポリシー） | パフォーマンス通知から「アピール」 |
| ポリシー警告 | 通知メールへの返信 or アカウントヘルスの「再審査依頼」 |
| ASIN サスペンド | パフォーマンス＞アカウントヘルス＞「アピール」 |
| アカウントサスペンド | 同上、緊急 |

## 提出後の対応

### 24〜72時間
- 自動応答メール受信
- 詳細審査開始

### 5営業日
- 結果通知 or 追加情報依頼
- 5営業日経過しても返答なければ催促

### 追加情報依頼
- 求められた情報を具体的に提供
- 元のPOAを補強する形

### 却下時
- 却下理由を読み、根本原因を再特定
- 新しい情報・証拠を追加して再提出
- 同じ内容での再提出は逆効果

## POA の効果検証

復旧後も注意：
- 同じ問題の再発しないか3ヶ月モニタリング
- 別ASINで同種問題が起きないか全件チェック
- 社内仕組みが実運用されているか確認

## POA作成の社内体制

1. **緊急対応チーム**：警告受信時の初動24時間以内
2. **担当者・上長承認**：POA は上長レビュー必須
3. **法務確認**：重大ケース（サスペンド・知財）は法務確認
4. **証拠資料の保管**：過去POAと添付資料を社内アーカイブ
5. **教育**：新人に POA 作成スキルの教育
