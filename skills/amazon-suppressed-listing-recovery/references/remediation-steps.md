# 原因別の是正措置

リスティング異常の原因別に、具体的な是正手順を整理。

## 1. 必須属性欠落

### 確認
- セラーセントラル「在庫＞検索非表示」で具体的に欠落属性を表示
- 該当ASINの「修正が必要」マーク

### 是正
1. 該当属性をメーカー仕様書から取得
2. セラーセントラル「商品の編集＞詳細＞[該当属性]」に入力
3. 関連属性も同時に補完（例：`voltage` だけでなく `wattage`, `power_source_type`）
4. 保存

### 想定属性（カテゴリ別）
- 家電：voltage, wattage, power_source_type
- 食品：expiration_date, food_ingredients, country_of_origin
- 化粧品：volume_capacity_name, ingredients
- アパレル：apparel_size, apparel_color, material_composition

詳細：`amazon-flat-file-validator-jp` スキル参照

## 2. メイン画像の規定違反

### 確認
- 「修正が必要」マークで「画像の問題」表示

### 是正
1. メイン画像の規定（純白RGB(255,255,255)・85%占有・1000px以上）を確認
2. 規定遵守の画像を準備
3. セラーセントラル「商品の編集＞画像」で差し替え
4. 反映に24時間程度

詳細：`amazon-main-image-checker` スキル参照

## 3. タイトル文字数違反

### 確認
- 「タイトルが長すぎ／短すぎ」アラート

### 是正
1. カテゴリ別の文字数制限（一般200字／アパレル130字／カメラ50字）を確認
2. タイトルを規定内に修正
3. 同時に SEO 観点で主要KW・差別化属性を保持
4. 詳細：`amazon-title-bullet-rewriter-jp` スキル

## 4. 商品説明の問題

### 確認
- 「商品説明が空欄／規定違反」

### 是正
1. 商品説明欄に2,000字以内で記載
2. HTML タグ・改行は仕様に従う（カテゴリ別）
3. 禁止語（誇大表現・薬機抵触語）チェック

## 5. キーワード規定違反

### 確認
- 「禁止キーワードを含む」

### 是正
1. タイトル・bullet・generic_keywords から禁止語を除去
2. 他社ブランド名・最上級表現・薬機抵触語を確認
3. 詳細：`amazon-search-term-builder-jp` スキル

## 6. 価格範囲外

### 確認
- 「価格範囲外」「Amazon標準価格と乖離」

### 是正
1. 競合商品の価格を確認
2. 「最大価格／最小価格」フィルタを設定し直す
3. 必要なら一時的に価格を調整して販売開始

### 価格設定の注意
- 競合より極端に高い／安いとアラート
- 二重価格表示の景表法準拠（8週間ルール）

## 7. 出品許可カテゴリでない

### 確認
- 「このカテゴリで出品するには承認が必要」

### 是正
1. セラーセントラル「在庫＞商品登録＞カテゴリ承認」
2. 申請に必要な書類（請求書・メーカー証明等）を準備
3. 申請提出
4. 承認後（数日〜数週間）に再登録

### 承認が必要な代表カテゴリ
- 医薬品
- 酒類
- 食品（一部）
- ブランド商品（Brand Registry）
- 美術品
- 時計（高級）

## 8. 偽物疑い

### 確認
- 「真贋に関する苦情」「販売者から偽物の報告」通知

### 是正（POA + 証拠書類）
1. 仕入先からの請求書（直近90日分）
2. メーカー or 代理店証明書
3. 商品の真贋鑑定書（自社品質保証部 or 第三者機関）
4. 製造ロット番号と仕入記録の対応
5. Brand Registry 申請（あれば）

### 並行アクション
- 該当ASINの商品ページを「正規品証明」を明示する形で改善
- 同種商品の販売停止・全商品の真贋確認

## 9. 知的財産権侵害

### 確認
- 「商標権／著作権侵害の通報」

### 是正
1. 通報内容を確認（誰の何の権利を侵害したとされているか）
2. 自社の権利状況を確認（商標登録・ライセンス契約）
3. 権利者と直接交渉（誤通報の場合）
4. 該当ASINの販売停止または記述修正
5. 弁護士相談（重大ケース）

## 10. 配送遅延率の悪化

### 確認
- アカウントヘルスダッシュボードの「配送遅延率」が4%超

### 是正
1. 過去30〜60日の遅延注文を分析
2. 遅延原因（在庫管理・出荷遅れ・配送業者）の特定
3. 改善策（FBA活用・出荷手順見直し）
4. 配送業者との契約見直し

### POA
- 配送遅延が起きた原因
- 是正策（具体的施策）
- 再発防止（オペレーション改善）

## 11. 注文不良率（ODR）の悪化

### 確認
- ODR が1%超

### 是正
1. ODR の構成要素（A-to-z申し立て率・チャージバック率・マイナスフィードバック率）を分解
2. 各要素の根本原因特定
3. 商品ページの誤認解消（実態と一致するコピー）
4. カスタマーサポートの応答品質改善

## 12. 注文キャンセル率の悪化

### 確認
- キャンセル率 2.5%超

### 是正
1. キャンセル理由の分析
2. 在庫管理の精度向上（リアルタイム在庫連携）
3. 価格設定ミスの防止

## 13. ブランドオーナーからの異議

### 確認
- 「ブランドオーナーから許可されていない販売者として通報」

### 是正
1. ブランドオーナーとの正規流通契約の有無確認
2. 仕入経路の証明
3. 並行輸入の場合の正当性主張（日本の法律で並行輸入は原則合法）
4. ブランドオーナーとの直接交渉

## 14. ステマ規制違反

### 確認
- 「ステルスマーケティング規制違反の通報」

### 是正
1. レビュー操作（自社・知人による★5投稿）の確認・停止
2. インフルエンサー投稿の「PR」「広告」表記確認
3. 関連法令（ステマ規制 2023.10〜）の社内教育

詳細：`yakki-keihyo-expression-check` スキルの`references/stealth-marketing.md`

## 15. 安全性・リコール対応

### 確認
- 製品の安全性問題（破損・発火・健康被害）

### 是正
1. 該当商品の即座販売停止
2. 既存購入者への通知
3. リコール対応（製品改良 or 全回収）
4. メーカー・販売元との連携

## 16. 規制商品の許可違反

### 確認
- 医薬品・酒類・電化製品の許可なし販売

### 是正
1. 該当法令の許可・認証取得
2. 取得まで該当ASINを販売停止
3. 該当カテゴリの出品申請

## 是正措置の優先順位

| 重大度 | 例 | 対応 |
|---|---|---|
| 最高 | 安全性問題・偽物・知財侵害 | 即座対応・販売停止 |
| 高 | 配送遅延・ODR悪化 | 1週間以内に改善開始 |
| 中 | 必須属性欠落・画像規定 | 数日以内に修正 |
| 低 | キーワード調整・タイトル微調整 | 2週間以内に修正 |

## 是正措置の証拠保管

すべての是正措置で証拠を保管：
- 修正前後のスクショ
- 関連書類（請求書・証明書）
- 社内議事録・運用変更通知
- 提出した POA とAmazonからの返答

→ 後日「同じ問題で再警告」を受けたときに「前回はこう改善した」と説明できる。

## 是正措置の社内仕組み化

1. **チェックリスト**：商品登録時の必須チェック項目
2. **承認フロー**：上長承認後にアップロード
3. **定期点検**：月次でASIN状況確認
4. **教育**：新人にリスティング規定教育
5. **緊急対応マニュアル**：警告受信時の手順書

→ POA に「再発防止策として上記を整備した」と記載できる。
