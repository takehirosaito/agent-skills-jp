実際の復旧事例5パターン。

## 事例1：検索結果から非表示（必須属性欠落）

### 状況
- ASIN：B0XXXXXXXX（家電・コードレス掃除機）
- 検索結果に表示されない、商品ページは閲覧可能
- セラーセントラル「修正が必要」マーク

### 原因
- 「voltage（電圧）」「wattage（消費電力）」が空欄
- カテゴリ「電化製品」の必須属性

### 是正
1. メーカー仕様書を取得：voltage=100V、wattage=60W
2. セラーセントラル「商品の編集＞詳細」に入力
3. 関連属性も補完：power_source_type=ac、wattage_unit=watts
4. 保存

### 結果
- 24時間以内に検索結果に再表示
- 売上回復

### 教訓
- カテゴリ別必須属性のチェックリスト整備
- 新商品登録時のフローに組み込み

## 事例2：偽物疑いによるサスペンド（並行輸入品）

### 状況
- ASIN：B0XXXXXXXX（化粧品）
- 「販売者から偽物の報告」通知
- ASIN サスペンド

### 原因
- 並行輸入品で正規流通権の証明不足
- Brand Registry 未登録

### 是正
1. 仕入先からの請求書（過去6ヶ月分）を準備
2. メーカー流通権証明書を取得
3. 製品の真贋確認（弊社品質保証部）
4. POA + 添付資料5点で再審査依頼
5. 並行で Brand Registry 申請

### 結果
- 14営業日後にASIN復活
- Brand Registry 登録完了
- 以降の偽物通報対応がスムーズに

### 教訓
- 正規仕入の証明を常時用意
- Brand Registry は早期完了
- 並行輸入は法的に合法でも、Amazon 上の証明が重要

## 事例3：メイン画像規定違反による検索非表示

### 状況
- ASIN：B0XXXXXXXX（食品・お茶）
- 「画像の問題」アラート
- 検索非表示

### 原因
- メイン画像が「木目テーブル背景＋茶葉を入れた茶碗」
- 純白背景・85%占有・テキストなし の規定違反

### 是正
1. 純白背景でパッケージ単体撮影
2. 占有率85%以上で構図
3. テキスト・小道具を削除
4. 1500×1500px、sRGB、JPGで書き出し
5. セラーセントラルで画像差し替え

### 結果
- 48時間以内に検索結果再表示
- 中身（茶碗）はサブ画像に移動でCVR維持

### 教訓
- メイン画像規定の厳守
- 中身・使用シーンはサブ画像で
- 詳細：`amazon-main-image-checker` スキル

## 事例4：注文不良率（ODR）悪化

### 状況
- ODR が 1.5%（基準1%超過）
- 警告メール「30日以内に改善必要」
- 構成要素：A-to-z 申し立て率が増加

### 原因
- 商品ページで「翌日配送」と記載したが、自社発送で出荷が間に合わず
- A-to-z 申し立てが頻発

### 是正
1. 商品ページの「翌日配送」記載を削除
2. 出荷準備日数を「翌営業日発送」→「3営業日以内発送」へ修正
3. 既存の問題注文10件に個別対応（返金・補償）
4. FBA への切替準備
5. POA でアカウントヘルス改善計画を提出

### 中期改善
- FBA に切替（30日でFBAへ移行）
- 配送品質向上
- カスタマーサポート24時間対応

### 結果
- 60日後：ODR 0.6% に改善
- 90日後：0.4% で安定
- アカウント停止リスク解消

### 教訓
- 「翌日配送」等の配送スピード約束は慎重に
- 配送指標悪化は商品ページの正確性から
- FBA活用で根本改善

## 事例5：ブランドオーナーからの異議（並行輸入禁止）

### 状況
- ASIN：B0XXXXXXXX（コスメ・海外ブランド）
- 「ブランドオーナーから許可されていない販売者として通報」
- ASIN サスペンド

### 原因
- 海外ブランドの正規日本代理店から異議申し立て
- 並行輸入品で日本での正規販売権なし

### 是正方向の検討
1. 日本代理店との交渉
2. 並行輸入品の合法性主張（日本の独禁法上、並行輸入は原則合法）
3. ただし、Amazon 上では Brand Registry 権利者の意向が優先

### 実際の対応
- Amazon 内では復活困難と判断
- 該当ASINの販売停止
- 他販路（自社ECなど）で並行販売継続
- 法的措置は損益分岐に合わず断念

### 結果
- 該当ASINのAmazon販売停止
- 在庫を他販路で消化

### 教訓
- 並行輸入品はAmazon上で Brand Registry 権利者と衝突する可能性
- 仕入時にブランドオーナーの意向を確認
- 法的に正当でも Amazon 上の判断は別物
- 代替販路の確保が重要

## 共通の教訓

### 復旧成功要因
1. **Amazonの通知文を正確に読む**
2. **POA を3点セット（問題・是正・再発防止）で**
3. **証拠資料を充実**
4. **再発防止を「仕組み」レベルで**
5. **5営業日経過時の催促**

### 復旧失敗要因
1. **通知文の精読不足**
2. **抽象的な「努力します」POA**
3. **証拠資料の不足**
4. **個人の注意レベルの再発防止**
5. **複数原因のうち一部しか対応しない**

### 緊急対応のコツ
- アカウントサスペンドは48時間以内のPOA提出が成功率高い
- 重大ケースは Amazon コンサル・弁護士に早期相談
- 並行で他販路への影響軽減（在庫移管・自社EC強化）

### 予防のコツ
- 商品ページ品質チェック（月次）
- アカウントヘルス指標モニタリング（週次）
- 仕入証拠・流通権の常時保管
- Brand Registry の早期完了
- 法令遵守の社内教育

## 復旧プロジェクト管理

復旧プロジェクトの社内管理：

| フェーズ | 期間 | アクション |
|---|---|---|
| 緊急対応 | 24時間 | 状況把握、初動 |
| 是正実施 | 2〜7日 | 修正・証拠収集 |
| POA 作成 | 1〜3日 | 文面作成・上長承認 |
| 提出 | 1日 | Amazon へ送付 |
| フォロー | 14〜30日 | Amazon からの返答対応 |
| 復旧後検証 | 30〜90日 | 再発防止策の実運用確認 |

## チーム体制

復旧プロジェクトの社内体制：
- **責任者**：上長レベル
- **担当者**：カタログ・アカウント運用
- **法務**：重大ケース
- **製造**：商品改良が必要なケース
- **CS**：カスタマー個別対応

各部門が連携して短期で対応する。
