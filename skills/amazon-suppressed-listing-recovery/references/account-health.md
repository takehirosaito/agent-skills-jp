# アカウントヘルスの主要指標

Amazon セラーセントラルの「パフォーマンス＞アカウントヘルス」で計測される主要指標。これらが悪化するとアカウント自体に影響する。

## 主要指標（最新は Amazon ヘルプで確認）

### 1. 注文不良率（ODR / Order Defect Rate）

| 構成要素 | 説明 |
|---|---|
| A-to-z 申し立て率 | 顧客が「保証申し立て」した割合 |
| マイナスフィードバック率 | 1-2★のフィードバック割合 |
| チャージバック率 | クレジットカード会社経由のチャージバック |

**Amazon 基準**：1%以下

ODR が1%を超えると、出品停止リスク。

### 2. 配送遅延率

定義：注文確認から発送までの「予定日」を超えた注文の割合。

**Amazon 基準**：4%以下

### 3. 注文キャンセル率

定義：出品者起因のキャンセル割合（顧客起因は含まない）。

**Amazon 基準**：2.5%以下

### 4. 出荷前キャンセル率

出荷準備期間内のキャンセル割合。在庫切れ・価格ミスで増加。

### 5. 有効な追跡率

追跡情報を提供している配送の割合（FBM時）。

**Amazon 基準**：高めの設定

### 6. レビュー応答率

顧客レビュー・Q&A への応答実績。

### 7. 出品停止率

非アクティブ／停止ASINの割合（カタログ管理品質）。

### 8. ポリシー違反件数

メッセージで通知されるポリシー違反警告の累計。

## ODR の構成要素別の分析

### A-to-z 申し立てが多い場合

原因：
- 商品が説明と違う
- 配送遅延・未着
- 破損・初期不良

対応：
- 商品ページの正確性向上
- 配送品質向上
- 検品強化

### マイナスフィードバックが多い場合

原因：
- 出品者対応の不満
- 商品品質
- 期待ギャップ

対応：
- カスタマーサポート品質向上
- 商品改良
- 商品ページの期待値調整

### チャージバックが多い場合

原因：
- 不正使用（顧客側）
- 詐欺的取引
- 配送遅延での顧客クレーム

対応：
- 不正検知の強化
- A-to-z 申し立てへの早期対応
- 配送・サポート品質

## 配送指標の改善

### 配送遅延率の改善

| 原因 | 対応 |
|---|---|
| 出荷準備日数の見積誤 | 設定の見直し（実態に合わせる） |
| 在庫管理の混乱 | 在庫システムの改善 |
| 配送業者の遅延 | 業者見直し・複数業者活用 |
| 季節要因（年末・GW） | 出荷準備日数の一時的延長 |

### キャンセル率の改善

| 原因 | 対応 |
|---|---|
| 在庫切れキャンセル | 在庫管理の精度向上、安全在庫の確保 |
| 価格設定ミス | 価格チェックフローの強化 |
| 出荷不可商品の登録 | 商品マスタの精査 |

## アカウントヘルス低下時のリスク

### 段階別の Amazon の対応

| 状態 | Amazon の対応 |
|---|---|
| 指標悪化（基準内） | 黄色アラート、改善要請 |
| 基準を超過（軽度） | 赤色アラート、改善計画要請 |
| 基準を超過（重度・継続） | 出品権の制限、サスペンド予告 |
| サスペンド | 出品停止 |

### サスペンドからの復活率

統計的に：
- 1回目のサスペンド：60〜70%復活
- 2回目以降：復活率は大幅低下
- アカウント永久停止：復活不可

## 改善計画（POA）の作成

アカウントヘルス指標悪化に対する POA：

```text
件名：アカウントヘルス改善計画（[指標名]）

【現状】
- 該当指標：[ODR / 配送遅延率 / キャンセル率]
- 現在の数値：[X]%
- Amazon 基準：[Y]%
- 期間：[過去X日間]

【原因分析】
構成要素別の分析（例：ODRなら A-to-z申し立て率／フィードバック率／チャージバック率）：
- 主要因：[X]
- 副要因：[Y]

【是正措置（短期：30日以内）】
1. [具体的施策]
2. [具体的施策]
3. [具体的施策]

【改善計画（中期：60〜90日）】
1. [仕組み改善]
2. [仕組み改善]

【目標】
- 30日：[現状]% → [中間目標]%
- 60日：[基準]% 以下を達成
- 90日：[基準]% 以下を継続

【添付資料】
1. 構成要素別の詳細分析
2. 過去問題注文の一覧
3. 改善後の新オペレーションマニュアル
4. 月次モニタリング体制
```

## アカウントヘルスのモニタリング

### 日次
- ヘルスダッシュボードの確認
- 当日のメッセージ・通知確認

### 週次
- 構成要素別の指標推移
- 異常値の早期検知

### 月次
- 月次レポート作成
- 経営会議での共有
- 改善施策の効果検証

## カスタマーサポートの品質向上

ODR・マイナスフィードバック改善の中核：

### 応答時間
- 営業日24時間以内の初回応答
- 複雑な案件は48時間以内に解決方針提示
- 緊急案件（配送中破損等）は同日対応

### 応答品質
- 顧客の問題を最初に共感
- 事実関係の確認
- 解決策の提示（複数オプション）
- 補償（必要に応じて）

### 返品・返金ポリシー
- 明確で分かりやすい
- 顧客の負担を最小化
- 迅速な処理

## FBA への切替

配送指標悪化時の根本対応：
- FBA に切り替えることで配送品質・追跡情報は Amazon が担当
- 配送遅延率・キャンセル率の改善に直結
- ただしFBA手数料が発生する

詳細：`amazon-profit-fee-checker` スキル

## アカウント保全の予防策

1. **商品ページの正確性**
   - 説明と実物の一致
   - サイズ・色・成分の正確記載

2. **在庫管理の精度**
   - 在庫切れキャンセル防止
   - 複数モール出店時の在庫連携

3. **配送品質**
   - 出荷準備日数の現実的設定
   - 配送業者の品質管理

4. **カスタマーサポート**
   - 24時間以内応答
   - 問題早期解決

5. **法令遵守**
   - ポリシー違反の予防
   - 薬機・景表・特商法

## 海外Amazon との比較

US Amazon との違い：
- 日本のアカウントヘルス指標基準は同じだが、文化的な期待値（応答スピード・梱包品質）は高い
- 顧客の権利意識が高い（A-to-z 申し立てしやすい傾向）
- 価格に対する品質期待が高い
- 配送スピードへの期待が高い

## 専門家相談

以下のケースは Amazon コンサルタント・専門家への相談を：
- 複数指標が同時悪化
- 既に1度サスペンド経験あり
- 重大なポリシー違反通報
- 知財侵害通報
- アカウント永久停止リスク

## 法的対応の必要性

以下のケースは弁護士相談：
- 商標権侵害の通報
- 偽物販売の累積疑い
- アカウント永久停止
- 数千万円規模の在庫が凍結
- ブランドオーナーとの紛争
