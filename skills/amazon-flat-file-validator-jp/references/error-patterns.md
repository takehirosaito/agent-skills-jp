# フラットファイル よくあるエラーパターン

Amazon セラーセントラルのフラットファイルアップロード後のエラーレポートに出るエラー番号・パターン・対処。

## エラー番号の代表例（変動するため最新はセラーセントラルヘルプで確認）

### 必須列・データ型関連

| エラー番号（例） | 内容 | 対処 |
|---|---|---|
| 8541 | 必須列の欠落 | 該当列を埋める |
| 8013 | ENUM違反（item_typeなど） | カテゴリのValid Valuesから取得 |
| 8052 | 文字種違反（半角英数のみ等） | 該当列の文字種チェック |
| 8087 | バイト数超過（item_name等） | カテゴリ別上限まで短縮 |
| 8112 | external_product_id不一致 | CDチェック・GTIN種別確認 |

### バリエーション関連

| 内容 | 対処 |
|---|---|
| parent_skuが存在しない | 同一ファイル内に親行を追加 |
| variation_themeが親子で不一致 | 親と子のvariation_themeを揃える |
| 子の組合せ重複 | 色×サイズ等の組合せをユニーク化 |

### 画像関連

| 内容 | 対処 |
|---|---|
| メイン画像がHTTPSでない | HTTPSのURLに変更 |
| 解像度不足 | 1000px以上の画像を用意 |
| 純白背景でない | 背景修正（`amazon-main-image-checker` 参照） |

### 法令・ポリシー関連

| 内容 | 対処 |
|---|---|
| 制限カテゴリ（医薬品・酒類等）の出品申請未承認 | カテゴリ出品申請を完了 |
| 禁止表現の検出（タイトル） | タイトル修正（`amazon-title-bullet-rewriter-jp` 参照） |

## 文字コード・フォーマット系

| 症状 | 原因 | 対処 |
|---|---|---|
| 文字化け | エンコード不一致 | UTF-8（BOMなし）または Shift_JIS に統一 |
| 列ズレ | タブとカンマの混在 | TSV（タブ区切り）に統一 |
| Excel開いて先頭0落ち | 列型が数値 | テキストエディタで開く／列型を文字列に |
| JANが「4.90E+12」化 | Excel自動変換 | テキスト型でセル設定 |
| 改行コード不一致 | LF・CR・CR+LF混在 | CR+LF に統一 |

## カテゴリ別の固有エラー

### 食品
- `expiration_date` が「YYYY-MM-DD」形式でないとエラー
- `food_allergen_information` 必須（特定原材料8品目）
- `country_of_origin` 必須

### 化粧品
- `ingredients` の列順序・記述形式が厳密
- 全成分表示が義務

### 家電
- `voltage`, `wattage`, `power_source_type` が必須カテゴリあり
- PSEマーク該当商品で取得証明が必要なケース

### アパレル
- `apparel_size`, `apparel_color` がvariation時必須
- `material_composition` の列が必須

### 医薬品（要承認）
- 一般出品者は出品不可
- 医薬品出品申請＋承認後のみ

## エラー対処のフロー

### Step 1：エラーレポートの取得
- セラーセントラル「在庫＞アップロードによる一括商品登録＞アップロード履歴」
- 「処理レポートのダウンロード」をクリック

### Step 2：エラー行の特定
- レポート内のエラー番号と該当行（SKU）を紐付け
- エラー番号の意味を本ファイル or セラーセントラルヘルプで確認

### Step 3：エラー種別の集計
- 同じエラー番号で複数SKUあり → 一括修正のチャンス
- 単独エラー → 個別修正

### Step 4：修正用ファイルの作成
- エラーSKUのみ抽出した修正ファイル
- 修正部分のみ更新（無関係列は変更しない）

### Step 5：再アップロード
- 修正ファイルのみアップロード
- 全件再アップロードは時間とリスクが高い

## 警告（赤エラーではない）の扱い

警告（推奨・SEO関連）は登録自体は成功するが、商品ページ品質に影響：

- 「商品説明が短い」「画像点数が少ない」 → 後日追加可能
- 「キーワードが推奨数より少ない」 → SEO観点で追加推奨
- 「サブ画像が空欄」 → 順次追加

## 「警告は無視できるか」

- 短期的には登録できるので無視できる
- 中長期では、警告対応した商品の方が表示順位・CVRが良い傾向
- 1週間以内に対応する社内ルール推奨

## エラーが解消しないとき

1. **再アップロードでも同じエラー**：
   - フラットファイル列の表記揺れ（`item_name` vs `item-name`）
   - 文字コード問題（BOM付き／なし）
   - テンプレートのバージョン違い

2. **エラー番号が見覚えない**：
   - セラーセントラルヘルプで検索
   - セラーサポートにケース起票（`amazon-catalog-conflict-ticket-builder` 参照）

3. **エラーは消えたが商品ページが意図通りでない**：
   - カテゴリサポートに修正依頼（同上スキル参照）

## アップロード後の異常検知

登録後、以下のような異常が起きていないか確認：

- 商品が「販売停止」ステータスになっている → ポリシー違反疑い
- 商品ページが「準備中」のまま24時間以上 → カタログ生成エラー
- 検索結果に表示されない → カテゴリ・索引エラー
- バリエーション選択UIが機能しない → 親子設定エラー
- 画像が表示されない → 画像URLの参照エラー

24時間以内に確認し、問題があれば即修正をセラーサポートへ依頼する。
