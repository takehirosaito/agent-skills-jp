# GMC ポリシー違反

Google Merchant Center は Google Shopping 広告のポリシー・無料リスティングのポリシーに違反する商品を不承認にする。**ポリシー違反は通常のエラーより重く、アカウント停止のリスクもある**。

最新の正確なポリシーは Google Merchant Center ヘルプ「Shopping 広告のポリシー」で確認。本書は2025-2026年時点の概要。

## 禁止商品カテゴリ

### 完全に禁止（出品不可）

- **偽造品**（コピー品、模倣ブランド）
- **危険な商品**（爆発物、銃器、武器、特定ナイフ）
- **不正取引を助長する商品**（鍵開け工具、海賊版、改造機器）
- **違法な薬物・関連商品**
- **タバコ・タバコ関連商品**（カテゴリにより厳しく規制）
- **特定の医薬品**（処方薬の一部）

### 制限あり（条件付き）

- **アルコール飲料**：年齢確認、地域制限
- **ギャンブル関連**：許可された地域のみ
- **ヘルスケア・医療機器**：認証必要
- **金融商品・サービス**
- **政治広告**
- **アダルト商品**：別フィードとして登録、特定地域のみ

## タイトル・説明の表現規制

### 完全禁止（不承認直結）

- **誇大表現**：「No.1」「最安」「絶対」「完全」「100%」（根拠なし）
- **医療・健康効果の主張**：「治る」「効く」「免疫力UP」「ガン予防」等
- **緊急性を煽る**：「今すぐ」「残り○個！」（タイトル内）
- **大文字の濫用**：`AMAZING DEAL!!!`
- **絵文字の濫用**：🎁🔥⭐ などタイトル内多用
- **テキスト記号**：`★★★`, `≪≫`, `【】` の過度な使用
- **プロモーション情報**：「送料無料」「セール中」「期間限定」（タイトル内）
- **連絡先**：電話番号・メール・URL（タイトル・説明内）
- **価格情報**：価格・通貨（タイトル内、説明内も非推奨）

### 制限あり

- 競合他社名の言及
- 比較表現（「○○より優れた」）
- 商標の濫用

## 医薬品・健康食品の特別規制

### 薬機法・景表法に違反する表現

日本では薬機法（医薬品医療機器等法）と景品表示法に従う必要がある：

- 「治る」「効果がある」「治療する」（医薬品的効能効果の標榜）
- 「副作用なし」「安全」（断定）
- 「医師推薦」「臨床試験で実証」（根拠表示）
- 化粧品で承認外効能の主張（シミが消える、シワがなくなる）
- 健康食品で疾病治療効果の主張

→ 別スキル `yakki-keihyo-expression-check` で詳細検査。GMCはこれらの表現を含む商品を不承認にする。

### 健康食品の機能性表示

- トクホ／機能性表示食品の届出範囲内なら表現可
- 範囲外の表現は不可
- 詳細は薬機法スキル参照

## 画像のポリシー違反

### 禁止内容

- **テキストオーバーレイ**：価格・送料・キャッチコピー
- **ロゴ・透かし**：自社ロゴ、ブランドロゴ大きく
- **枠・装飾**：派手な装飾枠
- **複数商品の合成**（メイン画像）
- **プレースホルダー画像**（「画像準備中」等）
- **裸体・性的内容**（成人向け以外）

### 推奨

- 商品本体のみ
- 純白背景
- 高解像度
- 自然光・均一照明

## 偽造品・知的財産権

### 偽造品（厳禁）

- ブランドコピー品（ノーブランドだが見た目はブランド品）
- 海賊版ソフトウェア・メディア
- 商標を無断使用した商品

→ アカウント停止リスク大

### 並行輸入

- 並行輸入自体は違法ではない
- ただし商標権者の許可がない場合、商品ページの表現に注意
- 「正規品」の主張は慎重に

## 偽ストア・詐欺

### 不承認の対象

- ストアの所在地・連絡先が不明
- 返品ポリシーがない
- 個人情報の取扱が不明
- 価格が極端に安い（市場価格の50%未満等）
- 商品画像と内容の不一致

### 推奨

- ストア情報の明示（特商法表記）
- 返品・交換ポリシーの明記
- プライバシーポリシーの設置
- HTTPS化
- 連絡先の電話・メール

## アカウント健全性

### 不承認商品が多いと

- アカウント全体の表示優先度低下
- 警告メール
- 警告無視で最終的にアカウント停止

### 維持するために

- 月次でエラー・警告を確認
- 不承認商品を放置しない（修正または削除）
- ポリシー違反は即除外
- 商品ページの品質維持

## 違反検出と対応フロー

### 1. GMCで不承認通知を受信

### 2. 違反内容の確認

- どの商品で、どのポリシーに違反したか
- GMC UI に詳細表示

### 3. 違反の修正

- フィードの該当属性を修正
- 商品ページの該当表現を修正
- 画像を作り直し

### 4. 再審査リクエスト

- 修正後、フィード再アップロード
- ポリシー違反は手動審査が必要な場合あり（1-7日）

### 5. 改善できないなら除外

- 禁止商品カテゴリならフィードから除外
- 別チャネル（自社EC等）で販売

## 違反を未然防止する運用

### 商品登録時のチェックリスト

- [ ] 禁止カテゴリでないか
- [ ] タイトルにプロモテキスト・誇大表現が含まれていないか
- [ ] 説明文に医療効果効能の主張がないか（化粧品・健康食品）
- [ ] 画像にテキスト・ロゴ・枠が混入していないか
- [ ] GTIN/MPN/ブランドが揃っているか
- [ ] 価格・在庫・送料がランディングページと一致するか

### 月次の運用

- GMCのエラー・警告レポート確認
- ポリシー違反の傾向分析
- 該当する商品の修正or除外
- 業務フロー改善

## 表現修正の具体例

### NG → OK

| NG | OK |
|---|---|
| 業界No.1の人気商品 | 人気の○○商品 |
| 必ず痩せる！ | 健康的なダイエットをサポート |
| 効果絶大！3日で実感 | 多くのユーザーにご利用いただいています |
| シミが消える化粧品 | （化粧品の承認効能内の表現に） |
| 完全防水 | 防水仕様（IPX7等の規格に基づく） |
| 送料無料！半額セール！軽量Tシャツ | 軽量 Tシャツ |
| 【期間限定】今すぐ買え！スマホケース | スマートフォンケース iPhone15 |

### 化粧品・健康食品の表現

- 詳細は `yakki-keihyo-expression-check` スキル参照
- 承認効能の範囲内で表現
- 機能性表示食品は届出範囲内

## アカウント停止後の対応

### Suspension（停止）

- アカウント全体が広告配信停止
- 全商品が無料リスティングから除外
- 重大な違反（偽造品、安全性問題等）

### 復旧手順

1. 違反内容の確認
2. 全商品の総点検
3. 違反商品の削除
4. 商品ページ・フィード・画像の全面改善
5. 再申請（appeal）
6. Google審査（数日～数週間）

→ アカウント停止は復旧困難。**未然防止が最重要**。

## まとめ

- 禁止カテゴリは出品しない
- タイトル・説明に**プロモテキスト・誇大表現を入れない**
- 化粧品・健康食品は**薬機法・景表法準拠**
- 画像は**商品本体のみ・純白背景・テキストロゴなし**
- 偽造品・知財侵害は厳禁
- ストア情報・返品ポリシーを整備
- 月次でポリシー違反を点検
- 違反は即修正、修正できないなら除外
