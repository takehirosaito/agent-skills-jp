# 楽天SS／マラソン準備 実例パターン

## 例1：6月SS の準備スケジュール（5月から開始）

### 期間
- 6月SS：6/4 20:00 〜 6/11 01:59
- 準備開始：5/1（1ヶ月前）

### スケジュール

#### 5/1-5/7（1ヶ月前）
- 5/1：月初ミーティング、6月SS準備キックオフ
- 5/2-5/4：対象商品選定
  - 主力商品10品リストアップ
  - 半額対象3品選定（在庫処分品中心）
  - バンドル商品10品（1,000円台）
- 5/5-5/7：価格戦略
  - 8週間ルール根拠の確認（過去販売実績）
  - 競合価格リサーチ
  - 実質単価シミュレーション

#### 5/8-5/14（3週間前）
- 商品ページ準備
  - イベントバナー作成
  - 価格表示の見直し
  - 「ポイント10倍」「半額」訴求の追加
- 在庫確保
  - 主要商品の追加発注（前回比1.5倍想定）
  - 配送業者との打合せ

#### 5/15-5/21（2週間前）
- 5/15：早割商品ページのオープン
- 5/17：第1報メルマガ配信（早割案内）
- 5/20：RPP予算追加申請
  - 月予算30万円 → イベント月50万円
  - 重点商品の入札強化

#### 5/22-5/28（1週間前）
- 5/22：クーポン最終設定
  - 店舗クーポン：5,000円以上500円OFF（5,000枚）
  - 商品別クーポン：半額商品向け300円OFF
- 5/25：第2報メルマガ配信（開始予告）
- 5/27：商品ページ最終チェック
- 5/28：スタッフブリーフィング

#### 5/29-6/3（直前）
- 5/29-5/31：最終確認
  - 在庫の最新化
  - クーポン適用テスト
  - バナー表示確認
- 6/3：開始前日、緊急連絡網確認

#### 6/4（開始当日）
- 18:00：商品ページ最終チェック、スタッフ待機
- 20:00：SS開始、第3報メルマガ配信（開始告知）
- 22:00：初動売上確認、在庫切れ対応

#### 6/5-6/10（期間中）
- 毎朝：日次パトロール
- 中間日（6/7）：中間集計、計画乖離確認
- 6/10 22:00：最終告知メルマガ
- 6/11 01:59：終了

#### 6/11（終了後）
- 即時：バナー・期間表示の削除
- 配送遅延対応開始
- 6/12-6/14：レビュー対応、お問い合わせ対応

#### 6/15-6/18（1週間後）
- 売上・粗利集計
- 振り返りミーティング
- 改善点の整理

### KPI実績例

| 指標 | 目標 | 実績 |
|---|---|---|
| 売上 | 500万円 | 580万円 |
| CV数 | 800件 | 920件 |
| 平均客単価 | 6,250円 | 6,300円 |
| 広告費 | 50万円 | 55万円 |
| ROAS | 10倍 | 10.5倍 |
| 在庫切れ | 0件 | 2件 |
| 配送遅延クレーム | 5件以下 | 8件 |

### 振り返りで出た改善点
1. 在庫切れ2件 → 安全在庫を厚めに（前回比2倍想定）
2. 配送遅延クレーム8件 → 配送業者の増員協議
3. 中間日の調整が遅れた → 中間日のチェック頻度増（朝・昼・夜）

## 例2：12月マラソン準備（11月初旬から）

### 期間
- 12月マラソン：12/4 20:00 〜 12/11 01:59（仮定）
- 12月SSと別開催の場合

### 重点

#### クリスマスギフト需要との連動
- 12/4-12/11 はクリスマスプレゼント需要のピーク前
- マラソン買いまわりとギフト購入の重ね合わせ

#### 商品選定

**主力商品**：
- クリスマスギフト向け（化粧品セット、家電、ファッション）
- 価格帯3,000-10,000円

**集客商品**：
- 在庫処分（クリスマス前後で終売予定品）
- 半額対象

**バンドル商品**：
- クリスマス用ラッピング対応の小型ギフト
- 1,000円台で多数

#### 配送考慮

- 12/24-25のクリスマスお届け希望が殺到
- 配送日指定の制限・受付期限を明示
- あす楽対応商品の在庫を厚めに

## 例3：3月SS（卒業・新生活シーズン）

### 期間
- 3月SS：3/4 20:00 〜 3/11 01:59（仮定）

### 重点

#### 新生活需要との連動
- 4月の新生活に向けた家電・インテリア・雑貨の需要
- 一人暮らし新生活セットの組み合わせ販売

#### 商品選定

**主力商品**：
- 一人暮らし家電（電子レンジ・冷蔵庫・洗濯機）
- 新生活用インテリア（カーテン・ベッド・収納）

**集客商品**：
- 旧モデルの家電半額
- 在庫処分の家具

**バンドル商品**：
- 食器・キッチン雑貨（1,000-2,000円）
- 日用品セット

#### メルマガ訴求

「新生活応援」「一人暮らし応援」のキーワード強化

## 例5：シミュレーション

### 前提
- 主力商品20品、半額対象3品、バンドル10品
- 月予算：通常30万円、SS期間50万円
- 想定CV数：通常500/月、SS期間1,000

### 売上シミュレーション

| 商品カテゴリ | 商品数 | 平均単価 | CV数 | 売上 |
|---|---|---|---|---|
| 主力 | 20 | 5,000 | 600 | 300万円 |
| 半額 | 3 | 2,500 | 150 | 37.5万円 |
| バンドル | 10 | 1,500 | 250 | 37.5万円 |
| **合計** | | | **1,000** | **375万円** |

### 粗利シミュレーション

| カテゴリ | 売上 | 粗利率 | 粗利 |
|---|---|---|---|
| 主力 | 300万円 | 30% | 90万円 |
| 半額 | 37.5万円 | -10%（赤字） | -3.75万円 |
| バンドル | 37.5万円 | 25% | 9.4万円 |
| **粗利合計** | | | **95.65万円** |
| **広告費** | 50万円 | | |
| **ネット粗利** | | | **45.65万円** |

→ 単月のネット粗利45万円台。通常月（粗利30%・売上150万円・広告費20万円 → ネット25万円）の倍程度。

### KPI目標
- 売上 +150%（通常比）
- CV数 +100%
- 平均客単価 +20%
- 広告費 +100%
- ネット粗利 +80%
