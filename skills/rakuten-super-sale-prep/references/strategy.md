# 半額対象・買いまわり1,000円ライン戦略

## 半額対象商品の戦略

### 半額商品の役割
- 強力な集客力
- 楽天検索結果の上位表示
- 「お得感」の演出
- 関連商品のクロスセル

### 半額対象選定の基準

| 商品 | 適性 |
|---|---|
| 在庫処分品 | 適（採算度外視OK） |
| 終売予定品 | 適（在庫評価損回避） |
| 売れ筋の旧モデル | 適 |
| 新商品 | 不適（評価期間中） |
| 高粗利商品 | やや適（半額でも採算可） |
| 低粗利商品 | 不適（赤字確定） |

### 半額の採算計算

例：粗利率40%の商品（売価10,000円・原価6,000円）を50%OFF

- 売価：5,000円
- 原価：6,000円
- 単品粗利：-1,000円（赤字）
- 50個販売 → 赤字総額50,000円

→ 損失を関連商品のクロスセルで回収できるかが勝負。

### 半額商品の戦略

1. **集客力極大化型**
   - 認知度の高い定番品を半額
   - 強い検索流入
   - 関連商品クロスセルで回収

2. **在庫処分型**
   - 売れない在庫を半額で処分
   - 在庫評価損回避
   - 関連商品狙わない

3. **シリーズ販売型**
   - シリーズの1商品を半額
   - 他シリーズ商品の同時購入を狙う

## 買いまわり1,000円ラインの活用

### 買いまわりの仕組み

| ショップ数 | 倍率 |
|---|---|
| 1 | 1倍（楽天通常） |
| 2 | +1倍 |
| 3 | +2倍 |
| ... | ... |
| 10 | +9倍（合計10倍） |

- 1ショップあたり **1,000円以上** の購入で倍率カウント
- 10ショップ買いまわりで最大10倍ポイント

### 顧客の行動パターン

買いまわり狙いの顧客は：
- 各ショップで **1,000円台** の商品を1点ずつ買う
- 「1,000円以上」を満たす最小限の購入で買いまわり完了
- 10ショップ達成でポイント10倍

### 1,000円台商品の重要性

自店が「1,000円台で買いまわり対象になる」商品を持っているか：

| 価格帯 | 買いまわり吸引力 |
|---|---|
| 〜999円 | NG（買いまわり対象外） |
| 1,000-1,500円 | **最強**（買いまわり最小限） |
| 1,500-3,000円 | 強い |
| 3,000-5,000円 | 標準 |
| 5,000円以上 | 弱い（買いまわり以外の動機が必要） |

### 1,000円台商品の設計

#### パターン1：単品で1,000-1,500円
- 小型商品（化粧水サンプル・お試し品）
- 食品の単品（お菓子・調味料）
- 雑貨単品

#### パターン2：少量セット
- 「お試し2点セット 1,200円」
- 「3個入り 1,500円」

#### パターン3：消耗品まとめ買い
- 「ボディソープ詰め替え 1,200円」
- 「お米2kg 1,300円」

### 戦略
- 1,000円台商品を **集客用** に複数準備
- 「買いまわり1,000円ライン狙い」を商品名・キャッチに明示
- 「楽天SS／マラソンに使える商品」訴求

## 主力・集客・バンドルの組合せ戦略

### 3カテゴリの並行展開

#### A. 主力商品（5-10品）
- 高粗利・売れ筋
- 通常価格 or 軽い値引き
- 利益確保が目的
- 価格帯：3,000-10,000円

#### B. 集客商品（半額・在庫処分）
- 半額〜80%OFF
- 採算度外視
- 楽天検索流入を獲得
- 関連商品クロスセル狙い
- 価格帯：500-3,000円（半額後）

#### C. バンドル商品（1,000円ライン）
- 1,000-2,000円
- 買いまわり狙い顧客の獲得
- 単品で完結する商品
- 価格帯：1,000-2,000円

### 期待効果

| カテゴリ | 期待効果 |
|---|---|
| A（主力） | 売上・粗利の柱 |
| B（集客） | アクセス急増、ランキング上昇 |
| C（バンドル） | 新規顧客獲得、LTV起点 |

## クーポンとポイントの併用

### 設計例
- 店舗クーポン：5,000円以上で500円OFF
- 店舗独自ポイント：通常+2%（合計3%）
- 楽天買いまわり：1,000円以上で対象

### 実質単価への影響

商品価格5,000円の場合：
- 顧客支払：5,000 - 500（クーポン）= 4,500円
- 獲得ポイント：
  - 楽天通常 1% + SPU想定 4% + 買いまわり想定5% + 店舗独自 2% = 12%
  - 4,500 × 12% = 540pt
- 実質単価：4,500 - 540 = **3,960円**

→ 「定価5,000円」が実質3,960円（20%OFF相当）。集客力大。

## 期間中の価格・在庫モニタリング

### 毎日チェック

| 項目 | 確認 |
|---|---|
| 売上 | 前日比、計画比 |
| 在庫 | 主要商品の残量 |
| RPP予算 | 消化率 |
| 注文数 | 配送キャパとの整合 |
| お問い合わせ | 配送遅延クレーム等 |

### 中間調整

| 状況 | 対応 |
|---|---|
| 売上が計画下回り | クーポン強化、メルマガ追加配信 |
| 売上が計画大幅上回り | 在庫追加発注、配送体制強化 |
| 特定商品の在庫切れ | 入荷待ち表示、関連商品誘導 |
| 配送遅延の発生 | お詫び・連絡、補償検討 |

## 終了後の戦略

### 終了直後

- バナー・期間表示の即切替（残置は信用低下）
- クーポン適用期間の確認
- 配送遅延対応

### 1週間後

- 売上・粗利の集計
- 商品別の販売数分析
- 配送遅延クレームの対応
- レビュー対応

### 1ヶ月後

- 全体振り返り
- 改善点の実装
- 次回イベントへの引き継ぎ

## NG戦略

### やってはいけない

1. **採算度外視の半額連発**
   - 集客はできても粗利激減
   - クロスセルの戦略がないと赤字

2. **8週間ルール無視の二重価格**
   - 「通常価格→セール価格」表記の根拠なし
   - 景表法違反、楽天独自審査でNG

3. **無計画な在庫**
   - 想定の3倍売れて即在庫切れ
   - 機会損失＋顧客クレーム

4. **「最安」「No.1」根拠なし**
   - 違反点数累積リスク

5. **イベント終了後の文言残置**
   - 「クリスマス特集」が1月に残置等
   - 信用低下、検索流入も無駄に
