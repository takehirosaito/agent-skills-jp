# 楽天SS／マラソン 仕様

最新仕様は RMS の店舗運営Navi で確認。

## 楽天スーパーSALE（SS）

### 概要
- 楽天市場最大級のセールイベント
- 年4回開催（3月・6月・9月・12月）
- 期間：4日 20:00 〜 11日 01:59（約7日間）

### 主要キャンペーン

| キャンペーン | 内容 |
|---|---|
| 半額商品 | 一部商品が半額〜80%OFFで提供 |
| 買いまわり倍率 | 1ショップ1,000円以上で最大10倍 |
| クーポン | 楽天主催・店舗主催の各種クーポン |
| 限定セール | カテゴリ別の特別キャンペーン |
| イベント特設ページ | 楽天が特集ページを展開 |

### 買いまわり倍率

| ショップ数 | 倍率 |
|---|---|
| 1ショップ目 | 1倍 |
| 2ショップ目 | +1倍 |
| ... | ... |
| 10ショップ目 | +9倍（合計10倍） |

- 1ショップあたり1,000円以上の購入で倍率カウント
- 最大10倍まで
- ポイント上限：通常7,000pt（条件で変動）

### 集客効果
- 全期間で楽天市場全体の売上が通常の2-3倍
- カテゴリによっては5-10倍

## お買い物マラソン

### 概要
- ほぼ毎月開催（時期はRMS確認）
- 買いまわりルールは SS と同様
- 一部キャンペーンは SS と異なる

### SS との違い

| 項目 | SS | マラソン |
|---|---|---|
| 開催頻度 | 年4回 | ほぼ毎月 |
| 半額商品 | 強調される | 通常規模 |
| 楽天負担クーポン | 大規模 | 標準 |
| 認知度 | 極めて高い | 高い |
| 集客力 | 最大級 | 大 |

## イベント期間中のスケジュール

### 開始時間
- 通常 4日 20:00（SS）
- マラソンも夜20:00開始が定石

### 終了時間
- 通常 11日 01:59（SS）
- 開始から約7日間

### ピーク時間帯
- 開始直後（20:00-23:00）：第1のピーク
- 期間中：終了直前の数日（特に終日2日間）
- 終了直前：22:00-01:59 のラストスパート

## イベント中の楽天施策

### 楽天独自のクーポン
- 「全店共通500円OFFクーポン」など
- 全店舗の商品に適用可能
- 楽天負担、店舗負担なし

### ポイントキャンペーン
- 「5のつく日」「ゾロ目の日」「お買い物マラソン」の重複
- SPU倍率の一時的アップ
- 楽天負担

### イベント特設ページ
- カテゴリ別の特集ページ
- 楽天が選定した店舗・商品の露出
- 出稿審査あり

## イベント前後の検索行動

### 開始2-3週間前
- 「楽天スーパーSALE」「お買い物マラソン」検索急増
- 楽天e-Naviで予告メール
- 早割商品の検索

### 開始直後
- 「半額」「ポイント10倍」検索急増
- 半額商品が即時完売
- カート投入急増

### 期間中
- 「買いまわり」「ポイント上限」の検索
- 1,000円台商品の検索（買いまわり狙い）

### 終了直前
- 「ラストスパート」「最終日」検索
- 期間限定の最終購入

### 終了後
- 「次回のスーパーSALE」検索
- レビュー投稿
- 配送遅延の問い合わせ急増

## 法令・規約の注意

### 二重価格（景表法）
- 「通常価格○○円→セール○○円」表記には8週間ルール根拠
- 詳細：`rakuten-price-compare-audit` スキル参照

### 最上級表現（景表法）
- 「業界最安」「日本一」「No.1」には根拠5項目必須
- 根拠なしの最上級は違反

### レビュー特典規制（楽天）
- 「レビュー投稿でクーポン」の事前告知はNG（違反点数35点）
- 投稿後のお礼としての別送おまけはOK

### 違反点数
- イベント期間中は監視が強化される可能性
- 違反点数累積でレベル上昇、最悪契約解除
