# 競合商品ページ比較・要約

## 概要

楽天市場・Amazon・Yahoo!ショッピング・自社EC（Shopify）の競合商品ページを、価格／オファー／訴求軸／見出し構造／画像／動画／レビュー／権威性／配送／法的整備の10軸で観測し、自社が「真似るべき定石」「追従強化すべき項目」「差別化で攻める軸」の3層に整理する。

最終出力は社内戦略資料としてそのまま使える比較表＋勝ち筋ステートメント＋アクションプランで、商品ページ／広告／画像／LPへの反映指示まで分解する。比較広告ガイドライン・薬機法・景表法のリスクを切り分けるため、「社内分析として観測した事実」と「公開広告で出せる比較表現」は必ず別物として扱う。

## 最重要原則

**競合分析の出力は「客観事実の観測」「定石／追従／差別化の3層分類」「自社アクションへの翻訳」を分離する。**

10軸で観測した事実をそのまま広告コピーに使うと、誹謗中傷／二重価格／No.1表記要件違反／薬機法違反になりやすい。観測フェーズと出力フェーズを明確に分け、「比較広告として公開できる表現」と「社内のみで使う観測」を分けて整理する。

## 処理フロー

### Step 1：入力情報の整理と前提確認

ユーザーから受け取る情報：
- 自社商品の基本情報（URL、価格、ジャンル、JANなど）
- 競合URL（最低2-3社、理想は売上1位・同価格帯・特殊訴求の3社）
- 自社の課題（CVR低下／離脱率高／広告効率悪化など）

不足している場合は、最も可能性の高い前提を1つ仮置きしたうえで暫定分析を出し、冒頭に「最終確定にはXXの確認が必要」を明示する。

### Step 2：10軸での観測（事実のみ）

`references/analysis-axes.md` の観測項目に従い、自社・競合A・競合B・競合Cを横並びで観測する。観測フェーズでは**主観を入れない**。

- 数値は実数で（「高い」「安い」ではなく「4,980円」「5,980円」）
- 訴求は実コピーを引用
- 画像は枚数と種類を記録

### Step 3：法務リスクの洗い出し

観測した競合の表現に法務リスクがあれば、自社で**真似ない**判断を明示する：
- 化粧品で「皮膚科医推薦」「シミに効く」→ 化粧品適正広告ガイドライン違反／薬機法違反、追従しない
- 二重価格8週間ルール違反の「通常価格」表記 → 真似ない
- 根拠不明の「No.1」「最安」 → 真似ない
- before/after（化粧品）→ メーキャップ・物理効果以外は不可

### Step 4：3層分類

10軸それぞれを以下に振り分ける：

- **定石（真似る）**：業界標準。やっていないと負ける項目
- **追従（強化する）**：競合が一歩先行している項目で、追いつく余地がある
- **差別化（攻める）**：自社にしかない／競合がやっていない項目で、勝ち筋になる軸

### Step 5：勝ち筋ステートメント

3層分類から、自社の勝ち筋を1文に圧縮する：

> 【ターゲット】に対して、競合Aの【強み】を、自社の【差別化要素】で【勝てる形】に進化させた【商品】

### Step 6：アクションへの翻訳

商品ページ／広告／画像／LP／レビュー獲得策／配送オペレーション、それぞれに反映アクションを出す。優先度（高／中／低）と工数（即日／3日／要制作）を併記。

### Step 7：公開可能な比較表現の分離

社内分析の事実と、公開広告で出せる比較表現は別物。出力には「公開OKな比較表現」「社内のみの観測」のセクションを設ける。比較広告として出すなら、客観的実証・正確な引用・公正な方法の3要件を満たすこと。

## 品質ゲート

- [ ] 観測フェーズで主観・推測を入れず、数値・実コピーで記録した
- [ ] 法務リスク表現を「真似ない」と明示した（特に化粧品の医薬関係者推薦／薬機法56項目外／No.1根拠不備／二重価格8週間ルール違反）

- [ ] 3層分類で「定石／追従／差別化」のいずれかに必ず分類した
- [ ] 勝ち筋ステートメントが1文に圧縮されている（ターゲット・商品・ベネフィット・差別化の4要素）
- [ ] アクションプランに優先度と工数を併記した

- [ ] 比較広告として公開する表現は「客観的実証・正確な引用・公正な方法」を満たす
- [ ] レビュー特典規制（楽天）／純白RGB(255,255,255)（Amazonメイン画像）／テキスト占有率20%（楽天画像）などモール固有の規制を踏まえている

## エッジケース

1. **競合URLが取得できない**：ユーザーから手元の情報（スクショ・コピー）だけで観測。「URLによる再観測が望ましい」と注記
2. **競合のレビュー数が桁違いに多い**：単純追従ではなく、レビュー獲得の運用設計（投稿確認後クーポン送付・写真付きレビュー誘導）を別タスクとして提案
3. **競合の「皮膚科医推薦」「No.1」表示が違反的**：「真似ない」明示。自社が同じことをして措置命令を受けるリスクを警告
4. **モール横断比較（楽天競合 vs Amazon自社）**：モールごとに購入動機・価格感が違うため、単純価格比較ではなく「ポイント込み実質価格」で揃える
5. **ジャンルが医薬部外品／機能性表示食品**：効能表現は承認文言／届出文言に限定。詳細は `yakki-keihyo-expression-check` スキルを併用

## 注意事項

- 各モールの仕様（楽天画像規定2024.6改定／Amazon A+モジュール／Yahoo!優良配送2025.11評価基準変更）は変動するため、出力前に各モール公式ヘルプの最新版を確認する
- ステマ規制（2023.10〜）対象は広告主のみ。自社のレビュー獲得策で「依頼・対価関係のある体験談」を扱う場合はPR表記必須
- 二重価格表示は8週間ルール（セール直前8週間のうち4週間以上の実販売実績）
- No.1表記には調査主体・期間・対象・方法・出典の5項目併記が必須
- 比較広告で競合社名・商品名を出す場合は客観的実証・正確な引用・公正な方法の3要件を満たすこと
