# ネガティブKW（除外）判定の基準

検索語句レポートから「広告費が無駄になっている」KWを除外する判定基準。

## ネガティブの意義

無駄なクリックを排除：
- 商品と無関係な検索意図を排除
- 競合検索意図（他社ブランドを探している人）を排除
- 重複配信を防止
- 広告予算を効率化

## ネガティブの3つのマッチタイプ

### Negative Exact（完全一致除外）
- そのKWと**完全一致**する検索を除外
- 例：「ダイソン」を除外 → 「ダイソン」のみ除外、「ダイソン V11」は配信される

### Negative Phrase（フレーズ除外）
- そのKWを**含む**検索を除外
- 例：「ダイソン」を除外 → 「ダイソン」「ダイソン V11」「ダイソン 互換」すべて除外

### Negative Product（商品除外）
- 特定の競合ASIN・カテゴリを除外
- マニュアル商品ターゲティングで使う

## ネガティブ判定の主要基準

### 基準1：クリックあり、注文ゼロ

| クリック数 | 注文 | 判定 |
|---|---|---|
| 5以上 | 0 | ネガティブ検討 |
| 10以上 | 0 | ネガティブ確定 |
| 20以上 | 0 | 即ネガティブ |

### 基準2：ACOS が異常に高い

| ACOS | 判定 |
|---|---|
| 目標の2倍超（例：目標30%なら60%超） | ネガティブ検討 |
| 100%超 | ネガティブ確定（赤字配信） |
| 持続的に200%超 | 即ネガティブ |

### 基準3：商品と無関係な検索意図

検索語句が以下に該当：
- 他社ブランド名・他社商品名（「ダイソン」「ルンバ」等）
- 別カテゴリの商品（掃除機ASINに「冷蔵庫」の検索）
- 修理・部品検索（「掃除機 修理」「替えバッテリー」）
- 中古・買取検索（「中古 掃除機」「掃除機 買取」）
- 情報検索（「掃除機 仕組み」「掃除機 比較」）

## 商品ごとの典型的なネガティブKW

### 家電（コードレス掃除機）の例
- 他社ブランド：「ダイソン」「マキタ」「シャーク」
- 別商品：「冷蔵庫」「洗濯機」「エアコン」（カテゴリ違い）
- 修理：「修理」「部品」「故障」「替えバッテリー」
- 情報：「ランキング」「比較」「仕組み」
- 別タイプ：「業務用」（家庭用商品の場合）

### コスメ（保湿クリーム）の例
- 他社ブランド：「DHC」「資生堂」「コスメデコルテ」
- 別カテゴリ：「化粧水」「美容液」（クリームのみ売る場合）
- 別年齢層：「ベビー」（大人用商品の場合）
- 効能訴求別：「医薬部外品」（化粧品のみ売る場合）

### 食品（醤油）の例
- 別調味料：「味噌」「みりん」「酒」
- 別ブランド：「キッコーマン」「ヤマサ」
- 業務用：「業務用」「大容量」（家庭用の場合）

### アパレル（ワイドパンツ）の例
- 別アイテム：「スカート」「Tシャツ」
- 別ジェンダー：「メンズ」（レディースの場合）
- 別サイズ：「キッズ」「子供」（大人用の場合）

### ベビー（ベビーカー）の例
- 別月齢：「新生児」（生後3ヶ月以上対象の場合）
- 別商品：「チャイルドシート」「抱っこ紐」
- 中古：「中古」「お下がり」

## ネガティブ適用範囲の判断

### キャンペーンレベルで除外
- そのキャンペーンに特化したネガティブ
- 例：マニュアル「軽量・ハンディ」キャンペーンの「業務用」除外

### 広告グループレベルで除外
- 広告グループ単位
- 商品単位の細かい制御

### ポートフォリオレベル / 全キャンペーン
- 全商品に共通する除外
- 他社ブランド名は通常全キャンペーンで除外

## ネガティブ設定の優先順位

1. **他社ブランド名**：即座に全キャンペーン除外
2. **無関係カテゴリ**：即座に全キャンペーン除外
3. **修理・部品・中古検索**：即座に該当キャンペーン除外
4. **ACOS 100%超**：観察1〜2週間 → 改善なければ除外
5. **クリック多／注文ゼロ**：観察2〜4週間 → 改善なければ除外

## 誤適用の回避

### 同一語の別意味

| 語 | 文脈A | 文脈B |
|---|---|---|
| リング | 指輪 | 着信音 |
| マウス | PC周辺 | ネズミ |
| アップル | 果物 | Apple社 |
| カメラ | カメラ機器 | カメラのレンタル |

検索語句の前後にどんな語が併用されているかを確認してから判断。

### Negative Exact と Negative Phrase の使い分け

例：「掃除機 修理」を除外したい

- Negative Exact「掃除機 修理」：このフレーズと完全一致のみ除外（「掃除機の修理」は配信）
- Negative Phrase「修理」：「修理」を含む検索全部除外（「コードレス掃除機 修理 業者」も除外）

「修理」のような汎用ネガティブ語はフレーズ一致で広く除外する方が効率的。

## ネガティブの過剰適用の弊害

ネガティブを増やしすぎると：
- 配信機会が減ってインプレッション低下
- 売上機会の損失
- 「除外されているが顧客は買いたかった」KWを取り逃がす

→ ネガティブは慎重に。データが揃ってから（クリック10以上）追加。

## ネガティブの整理

### 定期見直し
- 月次でネガティブ一覧を確認
- 「過去のネガティブを今でも適用すべきか」を再評価
- 商品改良・カテゴリ変更で意味が変わったKWを更新

### ネガティブ削除の判断
- 「今ならこのKWで買ってくれる」と判断できる時
- 商品ラインナップが変わって関連性が出てきた時
- 季節変化で意味が変わった時

## ネガティブ運用の落とし穴

### 1. 部分一致キャンペーンに含めた他社ブランド名
- 「掃除機」の部分一致 → 「ダイソン 掃除機」にも配信
- 解決：他社ブランドをネガティブフレーズ追加

### 2. 完全一致と部分一致の重複配信
- 「コードレス掃除機」を完全一致 + 部分一致で両方運用
- 部分一致が完全一致を食う（CPC上昇）
- 解決：部分一致に完全一致と同じKWをネガティブ追加

### 3. ブランドKWで広告
- 「[自社ブランド名] 掃除機」で広告を出すかは戦略次第
- ブランド検索＝既に買う気のある顧客 → 広告ROIは高い
- ただし「広告で出さなくてもオーガニックで来る」なら不要

## 効果検証

ネガティブ追加後の検証：
- 該当キャンペーンの ACOS 推移
- インプレッション・クリックの減少幅
- 売上の維持／低下
- 2〜4週間で判断
