# 昇格KW判定の基準

オートキャンペーンの検索語句をマニュアルキャンペーンに昇格させる判断基準。

## 昇格の意義

オートで好成績のKWをマニュアル（完全一致 or フレーズ）に昇格させると：
- 入札を最適化できる（オートより細かく制御）
- 予算配分を効率化（高ACOS KWに優先的に予算を）
- 競合の入札変動に素早く対応
- 検索結果での順位安定

## 昇格判定の主要基準

### 基本3条件

| 条件 | 推奨値 |
|---|---|
| クリック数 | 5以上（できれば10以上） |
| 注文数 | 2以上 |
| ACOS | 目標ACOS以下 |
| CVR | 3〜5%以上（カテゴリ依存） |

すべて満たすKWを昇格候補とする。

### 厳格な閾値
高単価・低回転商品：
- クリック10以上
- 注文3以上
- ACOS 目標の80%以下

### 緩い閾値
新商品・データ蓄積期：
- クリック3以上
- 注文1以上
- ACOS 目標の130%以下（将来改善見込み）

## 段階別の昇格戦略

### Stage 1：完全一致（exact）で昇格
- 厳密に一致する検索のみマッチ
- 入札・予算を最も効率化できる
- 検索語句が3〜5語の具体的フレーズに適する

### Stage 2：フレーズ一致（phrase）で昇格
- 検索語句に追加語が含まれてもマッチ
- 関連検索もカバー
- ロングテール展開に適する

### Stage 3：部分一致（broad）で昇格
- 類似・関連語にも広く配信
- 新たな検索パターン発見に使う
- ACOS高めになりがち

## マッチタイプの併用戦略

同じKWを複数マッチタイプで運用するときの定石：

| マッチタイプ | 入札 | 役割 |
|---|---|---|
| 完全一致 | 高 | 確実な購入を捕捉 |
| フレーズ | 中 | ロングテール拡張 |
| 部分一致 | 低 | 新KW発見 |

完全一致＞フレーズ＞部分一致 の優先順位で予算配分。

## CVR を基準にした分類

| CVR | 判定 | 推奨アクション |
|---|---|---|
| 10%以上 | 最優先KW | 完全一致 + 高入札 |
| 5〜10% | 主力KW | 完全一致 + 中入札 |
| 3〜5% | 育成KW | フレーズ + 中入札 |
| 1〜3% | 監視KW | 部分一致 + 低入札、改善見込みあれば継続 |
| 1%未満 | 改善対象 | 入札削減 or ネガティブ検討 |

## ACOS を基準にした分類

目標ACOS 30% の場合：

| ACOS | 判定 | 推奨アクション |
|---|---|---|
| 〜15% | 攻めるKW | 入札 +30〜50% |
| 15〜25% | 健全 | 現状維持 |
| 25〜30% | 注意 | 現状維持・観察 |
| 30〜50% | 改善対象 | 入札 -10〜20% |
| 50〜100% | 厳重監視 | 入札大幅削減 or ネガティブ |
| 100%+ | 赤字 | 即座にネガティブ |

目標ACOS は商品の粗利率次第。粗利40%なら ACOS 40%まで黒字。

## 昇格の優先順位

複数の昇格候補がある場合の優先順位：

1. **注文数の多いKW**（実績重視）
2. **CVRが高いKW**（効率重視）
3. **検索ボリュームが大きいKW**（インプレッション多）
4. **ACOSが低いKW**（利益効率）

## 昇格後の運用

### 開始入札の設定
```text
開始入札 = オート時の平均CPC × 1.0〜1.2
```
+20%程度高めから始めて、順位を見ながら調整。

### 日予算の設定
```text
新キャンペーンの日予算 = 想定クリック数 × 平均CPC × 1.5
```
日予算切れで配信停止しないよう余裕を持つ。

### 観察期間
- 最初の2週間は数値を観察、調整は最小限
- 3週目以降に本格的な入札調整

## 昇格しないKW（オートに残す）

以下は昇格せずオートに残す方が良い：
- クリック数が少なすぎる（5未満）
- 検索意図が広すぎる（「掃除機」のみ等）
- 競合性が高すぎてACOSが目標超え
- 新規発見されたばかりで評価期間が短い

## 既存マニュアルキャンペーンへの追加 vs 新キャンペーン

### 既存に追加する場合
- 同じテーマ・商品グループのKW
- 入札水準が既存と類似
- 予算が既存に余裕あり

### 新キャンペーン新設する場合
- 異なるテーマ・顧客属性
- 入札水準が大きく異なる（高 / 低）
- 予算を別管理したい

## 昇格時のネガティブKW設定

昇格と同時にネガティブKWも設定：
- 完全一致で昇格 → そのKWを部分一致／フレーズキャンペーンのネガティブに追加
  - 理由：重複配信防止、入札競合防止
- フレーズで昇格 → そのKWを部分一致キャンペーンのネガティブに追加

## 効果検証

昇格後の検証ポイント：
- ACOS の改善
- CVR の維持
- インプレッション・クリックの増減
- オートキャンペーンの実績への影響（KWが減って実績低下するか）

2〜4週間の検証で判断。

## 失敗パターン

### 1. 入札を上げすぎる
- 完全一致だからと言って高入札にしすぎ
- 結果：CPC高騰、ACOS悪化

### 2. オートキャンペーンを止める
- 昇格後にオートを止めると、新KW発見ができなくなる
- オートとマニュアルは並行運用

### 3. 短期間で判断
- 1週間のデータで昇格判断 → ノイズに惑わされる
- 最低2〜4週間のデータで判断

### 4. ネガティブ設定漏れ
- 完全一致で昇格したのに、部分一致でも同じKWに広告配信される
- 結果：自社内でACOS悪化

## 昇格のサイクル

| 頻度 | 内容 |
|---|---|
| 週次 | 検索語句レポート確認 |
| 月次 | 昇格候補の精査・実行 |
| 四半期 | 昇格後の効果検証 |
| 半期 | キャンペーン構造の見直し |
