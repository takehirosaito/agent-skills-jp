# 検索語句レポートの主要列

Amazon 広告コンソールから出力できる「検索語句レポート（Search Term Report）」の主要列とその意味。

## 主要列一覧

| 列名 | 意味 |
|---|---|
| 日付 / Date | 期間 |
| ポートフォリオ名 / Portfolio | キャンペーンの所属ポートフォリオ |
| 通貨 / Currency | JPY |
| キャンペーン名 / Campaign Name | キャンペーン名 |
| 広告グループ名 / Ad Group Name | 広告グループ名 |
| ターゲティング / Targeting | キャンペーンのターゲティング設定 |
| マッチタイプ / Match Type | broad / phrase / exact / auto-target |
| 検索語句 / Customer Search Term | 顧客が実際に検索した文字列 |
| 入札額 / Bid | 設定入札額 |
| インプレッション / Impressions | 表示回数 |
| クリック数 / Clicks | クリック数 |
| CTR | クリック率 |
| 平均CPC | 平均クリック単価 |
| 広告費 / Spend | 支出額 |
| 売上 / 7-Day Total Sales | 広告経由7日間売上 |
| ACOS | 広告費 ÷ 売上 × 100 |
| ROAS | 売上 ÷ 広告費 |
| 注文数 / 7-Day Total Orders | 広告経由7日間注文数 |
| 単位数 / 7-Day Total Units | 広告経由7日間販売単位数 |
| コンバージョン率 / Conversion Rate | CVR ＝ 注文数 ÷ クリック数 |

## 「検索語句」と「キーワード／ターゲット」の違い

### キーワード／ターゲット
- 自分が設定したもの（マニュアル時）
- もしくは「auto-target」（オート時）

### 検索語句
- 顧客が実際に検索した文字列
- マッチタイプによってターゲットとの一致度が異なる
  - 完全一致：ターゲット = 検索語句（ほぼ同じ）
  - フレーズ一致：検索語句に追加語が含まれる
  - 部分一致：ターゲットと類似・関連語

### オートキャンペーンの検索語句
- 顧客が検索したKW
- Amazon のアルゴリズムが類似商品ページに自動配信した結果
- マニュアルではカバーしきれないロングテールが発見できる

## 指標の意味と計算式

### CTR（クリック率）
```text
CTR = クリック数 ÷ インプレッション × 100
```
- 0.3%以上が健全
- 0.1%未満は商品ページ・広告クリエイティブの見直し

### 平均CPC
```text
平均CPC = 広告費 ÷ クリック数
```
- カテゴリ別の相場と比較
- 高すぎる場合は入札見直し

### CVR（コンバージョン率）
```text
CVR = 注文数 ÷ クリック数 × 100
```
- 5%以上が健全（カテゴリ依存）
- 1%未満は商品ページCVR問題（タイトル・画像・bullet・レビュー）

### ACOS
```text
ACOS = 広告費 ÷ 売上 × 100
```
- 目標ACOS以下が健全
- 目標ACOSは商品の粗利率次第（粗利40%なら ACOS 40%まで許容）

### ROAS
```text
ROAS = 売上 ÷ 広告費 × 100
```
- ACOSの逆数
- 200%以上が健全（ACOS 50%以下）

## 「7-Day」「14-Day」の意味

- Amazon の広告効果は「クリックから14日以内の注文」までを広告経由として計上
- 「7-Day Total Sales」：クリックから7日以内
- 「14-Day Total Sales」：クリックから14日以内
- 短い指標ほど即効性、長い指標ほど検討期間長い商品の効果が見える

## 期間の選び方

| 期間 | 用途 |
|---|---|
| 7日 | 短期トレンド・即効施策の効果検証 |
| 30日 | 標準的な分析期間 |
| 60〜90日 | 季節要因の排除・安定した傾向把握 |
| 180日 | 中長期トレンド・年単位の動き |

新キャンペーンは2週間程度のデータが揃ってから本格分析。

## ターゲティング列の見分け方

### オートキャンペーンの場合
- Targeting: `loose-match`, `close-match`, `complements`, `substitutes`
- マッチタイプ: `auto-target`

### マニュアルキャンペーンの場合
- Targeting: 自分が設定したKW
- マッチタイプ: `broad`, `phrase`, `exact`

## オートの4種マッチング

| 種類 | 内容 |
|---|---|
| close-match | 検索意図が近いKW（同義語・関連語） |
| loose-match | 検索意図が遠いKW（広い関連語） |
| complements | 補完商品（一緒に買われる商品ページ） |
| substitutes | 代替商品（似ている商品ページ） |

それぞれ別の入札設定ができる。close-match の入札を高め、loose-match を低めに設定するのが定石。

## CSVの取り扱い

### エンコード
- UTF-8 BOM付きで配布される場合あり
- 日本語が文字化けする場合は Shift_JIS で開き直し

### Excel開封時
- 「データ＞テキストまたはCSVから」でインポート
- 列ごとに型を指定（数値・文字列）

### 大量データの取扱い
- 1000行を超える場合は Excel より Google Sheets / Power BI
- pivot table で集計分析

## 「無効なクリック」の扱い

- ボット・不正クリックを Amazon が検知して除外
- 実クリックのみ表示
- 課金も除外後のもの

## 「無在庫時の広告」

- 在庫切れ商品の広告は自動停止される
- 停止前の実績のみ表示

## 競合との比較データ

Brand Analytics（Brand Registry 必要）：
- 「Search Query Performance」
- 自社／競合の検索KW別のクリック・購入シェア
- 検索語句レポートと組合せると深い分析が可能

## 分析時の注意

- 1回の分析だけで判断せず、複数期間で傾向を見る
- 商品変更・価格変更・在庫切れ・季節要因を考慮
- 1KWでのデータ量が少ない場合は信頼性低
- 検索語句が長い（5語以上）は超ロングテール・小ボリューム
