# ジャンル別 コレクションSEO 実例集

## 例1：敏感肌向け美容液（化粧品）

### 基本情報
- handle：`sensitive-skin-serum`
- 種別：Smart Collection
- 条件：`Product type = "Serum"` AND `tag contains "sensitive-skin"`

### SEO テキスト

| 項目 | 値 | 全角換算 |
|---|---|---|
| SEO title | 敏感肌向け美容液 厳選○点｜低刺激処方の人気アイテム | 30 |
| Meta description | 敏感肌のための低刺激美容液を厳選。アルコール／香料／パラベンフリーから選べる。送料無料・30日返品OK。 | 80 |

### 上部説明
> ピリピリしがちな敏感肌でも使える、刺激の少ない美容液を厳選しました。下の絞り込みでお好みの成分・仕上がりを選べます。

### 見出し構造

- H1：敏感肌向け美容液
- H2：選び方
- H2：成分の見方
- H2：シーン別おすすめ
- H2：よくあるご質問
- H2：関連カテゴリ

### Search & Discovery フィルタ

| フィルタ | 紐付け |
|---|---|
| 価格 | price |
| ブランド | vendor |
| 容量 | variant.weight |
| 主要成分 | metafield: custom.key_ingredients |
| 仕上がり | metafield: custom.finish_type |

**注意**：化粧品カテゴリのため「シミに効く」「シワが改善」「美白（化粧品ではNG）」等を下部説明に含めないこと。

## 例3：機能性表示食品（健康食品）

### 基本情報
- handle：`functional-foods`
- 種別：Smart Collection
- 条件：`Product type = "Functional Food"`

### SEO テキスト

| 項目 | 値 |
|---|---|
| SEO title | 機能性表示食品 一覧｜届出番号付きの機能性食品 |
| Meta description | 消費者庁に届出された機能性表示食品の一覧。中性脂肪・血圧・睡眠など、目的別にお選びいただけます。 |

### 上部説明
> 消費者庁に届出された機能性表示食品の一覧です。各商品には届出番号と機能性関与成分の表示があります。下の絞り込みで目的別に選べます。

### 下部説明（注意点）

```
## 機能性表示食品とは
事業者が機能性と安全性を消費者庁に届出した食品。
特定保健用食品（トクホ）とは異なり、国の個別審査はありません。

## ご利用上の注意
- 多量摂取により疾病が治癒したり、より健康が増進するものではありません
- 1日の摂取目安量を守ってください
- 疾病の診断、治療、予防を目的としたものではありません
- 食生活は、主食、主菜、副菜を基本に、食事のバランスを
```

**重要**：届出文言の改変は厳禁。各商品ページの届出文言を一字一句守ること。

## 例5：夏の限定セール（キャンペーン）

### 基本情報
- handle：`summer-sale-2025`
- 種別：Smart Collection
- 条件：`tag = "summer-sale-2025"` AND `compare_at_price > price`

### SEO テキスト

| 項目 | 値 |
|---|---|
| SEO title | 夏の限定セール 最大50%OFF｜7/1〜7/31期間限定 |
| Meta description | 7月限定の夏セール開催中。日焼け止め・夏物アパレル・冷たい飲み物が最大50%OFF。在庫がなくなり次第終了。 |

### 上部説明
> 期間限定！夏のスペシャルセール開催中。対象商品が最大50%OFF。
> セール期間：7/1（火）〜7/31（木）23:59

### 下部説明

```
## セール期間
2025年7月1日（火）〜7月31日（木）23:59

## 注意事項
- セール終了後、価格は通常価格に戻ります
- 在庫がなくなり次第、終了する場合があります
- 表示価格は税込みです
- 他のクーポンと併用不可

## 関連カテゴリ
- [通常価格商品](/collections/all)
```

**景表法注意**：
- 「通常価格→セール価格」の表記には**8週間ルール**適用（直近8週間のうち過半で実販売されていた価格であること）
- 「最大50%OFF」は商品ごとに割引率が異なる場合、その旨を明示
- 「最安値」「業界最低価格」などの最上級は根拠が必要

### キャンペーン終了後

- 期間終了後は 301 リダイレクトで関連カテゴリへ：`/collections/summer-sale-2025` → `/collections/all`
- または noindex メタタグを動的付与（`metafield: custom.is_active = false` 等で）
- 商品の `compare_at_price` を解除して通常価格に戻す

## ジャンル横断の注意点

| ジャンル | 主な注意 |
|---|---|
| 化粧品 | 薬機法（56項目）、医薬部外品との混同 |
| 健康食品 | 健康増進法、機能性表示食品の届出文言厳守 |
| アパレル | サイズ・素材の誤認、家庭用品品質表示法 |
| 食品 | JAS認証、原産地、健康増進法 |
| ギフト | のし対応・配送日指定・メッセージカード |
| セール | 景表法（二重価格8週間ルール）、終了後の表示 |
