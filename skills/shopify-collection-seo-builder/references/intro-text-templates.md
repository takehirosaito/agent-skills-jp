# 上部／下部説明文テンプレート

## 基本構造

### 上部（H1直下、短い）：50-100字

```
[誰の／何の悩みに] [何を厳選したか] [下の絞り込みで自分に合うものが見つかる旨]
```

### 下部（商品リスト下、長い）：500-1500字

```
H2: ○○の選び方
[3-5項目を箇条書きで]

H2: 用語解説
[専門用語の意味]

H2: シーン別おすすめ
[シーンと適した商品タイプの対応]

H2: よくあるご質問
[3-5件のQ&A]

H2: 関連カテゴリ
[内部リンク]
```

## ジャンル別テンプレ

### 化粧品（敏感肌向け美容液）

**上部**：
> ピリピリしがちな敏感肌でも使える、刺激の少ない美容液を厳選しました。下の絞り込みでお好みの成分・仕上がりを選べます。

**下部**：

```
## 敏感肌向け美容液の選び方
- アルコール（エタノール）フリー
- 香料・着色料フリー
- パッチテスト済みかどうか
- 保湿成分（セラミド・ヒアルロン酸）

## よくある不安と対策
- ピリピリする → アルコールフリーを選ぶ
- 赤くなる → 香料・着色料フリーを
- 効果を感じない → 4週間の継続を

## シーン別おすすめ
- 朝の保湿：軽い使い心地のジェル系
- 夜のスペシャルケア：濃厚なクリーム系

## よくあるご質問
Q. 化粧水と美容液の違いは？
A. 化粧水は肌を整え、美容液は集中的に成分を届けます。

## 関連カテゴリ
- [敏感肌向け化粧水](/collections/sensitive-skin-toner)
- [敏感肌向けクリーム](/collections/sensitive-skin-cream)
```

**薬機法注意**：化粧品カテゴリのため「シミに効く」「シワを改善」は不可。`yakki-keihyo-expression-check` 併用推奨。

## 文章作成のコツ

### KW詰め込みを避ける

NG：「敏感肌 美容液 高濃度 ビタミンC 美容液 おすすめ 美容液 ランキング」

OK：「敏感肌でも安心して使える美容液を厳選。低刺激処方で、ビタミンCなど人気成分から選べます。」

### 「選び方」を入れる

ユーザーは「どれを買えばいいか」を知りたい。選び方を提示するとSEO・CVR の両方に効く。

### FAQで関連KWを取り込む

「Q. ○○とは？」「Q. ○○と○○の違いは？」のような疑問形は、検索クエリと一致しやすい。

### 関連コレクションへの内部リンク

下部の最後に必ず関連カテゴリへのリンク。アンカーテキストにKWを含む（`こちら` ではなく `敏感肌向け化粧水`）。
