# Amazonブランドストア 設計

## 概要

Amazon ブランドストアは Brand Registry 登録ブランドが無料で持てる「Amazon内のブランド専用サイト」。ホーム＋カテゴリ＋特集の複数ページで構成され、外部広告（Sponsored Brands）の遷移先にもなる。

本スキルは、商品ラインアップ・商品数・モバイル前提を踏まえて、サイトマップ・ナビゲーション・各ページのタイル配列・コピー文言・撮影発注までを一気通貫で設計する。A+コンテンツが「単一ASINの説得力強化」であるのに対し、ブランドストアは「ブランド全体の世界観と回遊」が目的。

## ★最重要原則：「ホームは滞在・カテゴリは選び分け・モバイル前提で6項目ナビ」

ホームページで商品を売ろうとせず、**滞在時間を伸ばしてカテゴリページに送る**。カテゴリページで「選び分け」を提示し、個別商品ページに遷移させる。ナビは**6項目以内**、各項目名は10文字以内、ホームのファーストビューは**モバイル縦1画面**で完結させる。

商品数が確定していない／撮影素材が不揃いといった不完全情報の場合は、止まらず「仮定」と「不足情報」を冒頭にまとめ、まず仮定ベースの初稿サイトマップを出す。

### 商品数別の推奨構造（要点）

| 商品数 | 推奨階層 |
|---|---|
| 5未満 | ホーム＋商品グリッド（1ページ） |
| 5〜20 | ホーム＋カテゴリ2〜3（2階層） |
| 20〜50 | ホーム＋カテゴリ4〜5＋特集 |
| 50〜100 | ホーム＋カテゴリ5＋一部サブカテゴリ＋特集（3階層） |
| 100以上 | ホーム＋カテゴリ5＋サブカテゴリ全展開＋特集 |

### 主要タイル（要点）

| タイル | 用途 |
|---|---|
| フルワイド画像 | ヒーロー、ブランドステートメント |
| 画像タイル（リンク付き） | カテゴリ誘導 |
| 動画タイル | ブランドフィルム・商品デモ |
| ショッパブル画像 | 1画像内に複数商品リンク（ルーティン・コーデ）|
| 商品タイル／商品グリッド | 個別商品への遷移 |
| テキストタイル | ステートメント・FAQ |
| ベストセラータイル | 自動更新の人気商品 |

## 処理フロー

### Step 1：入力情報の確認と仮定設定

最低限揃えたい情報：
- ブランド名、対象市場（Amazon.co.jp前提）
- 取り扱い商品数と商品ラインの構造
- 主要商品ライン（用途別／対象別／成分別／シリーズ別）
- 撮影済み素材／動画素材の有無
- 季節商材・特集企画の有無
- KPI（滞在時間／カテゴリ遷移率／売上）

不足情報がある場合は仮定を明記して止まらず進める。

### Step 2：サイトマップの組立

商品数別の推奨構造（上表）を当てる。ナビ項目は6個以内（「ホーム」＋カテゴリ4〜5＋特集／新作）。
- 2階層なのにナビ10項目超 → 集約しなおす
- 3階層を超える → 訪問者が1〜2クリックで辿り着けず離脱
- 季節特集は公開／非公開の切替運用ルールも記載

### Step 3：各ページのタイル配列

#### ホームページ（典型構成）
1. ヒーロー（フルワイド画像 or 動画）
2. ブランドステートメント（テキストタイル）
3. カテゴリ誘導タイル4〜6
4. 動画（任意）
5. 特集／新作（任意）
6. ベストセラー（任意）
7. ブランドの取り組み（任意）

合計7〜12タイル以内。

#### カテゴリページ
1. カテゴリヒーロー（カテゴリ名＋世界観）
2. カテゴリ説明文
3. 商品グリッド（4〜12）or ショッパブル画像
4. サブカテゴリ誘導（あれば）
5. 関連カテゴリ誘導

#### 特集ページ
- 公開期間明示（運用ルール）
- 季節・コラボ・キャンペーン専用構成

### Step 4：ナビゲーション・項目名の決定

各項目名は10文字以内、明確な命名（曖昧な「ラインナップ」「COLLECTION」より「スキンケア」「キッチン」のような具体的な日本語）。

詳細は `references/navigation-design.md`。

### Step 5：タイル別の画像・コピー指示

タイルごとに以下を明記：
- タイル種類
- 推奨解像度
- 被写体・構図
- カラートーン
- テキスト要素（焼き込みか別タイルか）
- リンク先（カテゴリページURL or ASIN）

### Step 6：公開前NGチェック

`references/review-checklist.md` の禁止項目で照合：
- 外部URL／SNS／メール／電話／QRコード
- 「○月○日まで」「セール中」等の期限表現
- 価格表記
- 競合企業・他媒体ランキング
- 「No.1」「絶対」「100%」等の根拠なき最上級・断定
- 医薬品的・誇大効能
- 「Amazon限定」「Prime対象」等の Amazon 関連の不適切言及

### Step 7：モバイル前提の最終確認

- ホームのファーストビューがスマホ縦1画面に収まる
- カテゴリ誘導タイルがスマホ2列で見やすい
- 動画はミュート再生でも理解できる
- ナビ項目が長すぎて折り返さない

## 代表例（コスメブランド・商品25SKU・3シリーズ）

### サイトマップ
```text
ホーム
├── カテゴリ：スキンケア（10SKU）
│   ├── 朝のお手入れ
│   └── 夜のお手入れ
├── カテゴリ：ヘアケア（8SKU）
├── カテゴリ：ボディケア（7SKU）
├── 特集：季節（夏のUV対策）
└── ストーリー（ブランド由来）
```

### ナビ
ホーム ／ スキンケア ／ ヘアケア ／ ボディケア ／ 季節特集 ／ ストーリー

### ホームのタイル配列
1. フルワイド画像（朝の自然光、ブランドステートメント焼き込み）
2. テキストタイル（敏感肌のための処方を○年）
3. カテゴリ誘導タイル × 3（スキンケア／ヘアケア／ボディケア）
4. ショッパブル画像（朝のスキンケアルーティン5商品）
5. 動画タイル（30秒ブランドフィルム）
6. ベストセラータイル（自動更新）
7. ブランドの取り組み（テキスト＋画像）

他ジャンル例は `references/examples.md`。

## 品質ゲート

- ナビ項目数が6以内、各項目名が10文字以内
- ホームのタイル数が7〜12、カテゴリページが5〜10、特集が5〜8
- 商品数とストア階層が対応している（5SKUで3階層など過剰設計なし）
- ホームのファーストビューがモバイル縦1画面で完結
- 全文に外部URL／SNS／メール／電話／QRコード／期間限定文言／価格／競合社名・他媒体言及がない
- 全タイルにサイズ・被写体・テキスト要素の有無が明記
- 季節特集は公開／非公開の切替運用ルールがある

## エッジケース

- **商品数が3SKU以下**：1ページ完結のシンプル構成。ナビは「ホーム」のみ、または「ホーム／ストーリー」の2項目
- **撮影素材ゼロ**：撮影発注書として機能させる。各タイルの画像指示を発注ベースで詳細化
- **動画素材が低クオリティ**：無理に動画タイルを入れない。動画なしで世界観を伝える
- **多言語ブランド**：日本市場向けは日本語ベース。英語コピー流用はせず、現地化したコピーで再構成
- **季節商材中心**：常設カテゴリと季節カテゴリの公開／非公開運用ルールを明記。「クリスマス特集が3月まで表示」を防ぐ

## 注意事項

- ブランドストアは Brand Registry 登録ブランドのみ作成可能
- ストアビルダーのタイル仕様・解像度・上限は更新の可能性あり。最新は Amazon セラーセントラル「ストア」ヘルプを確認
- 公開後はストアアナリティクスで PV／訪問者数／カテゴリ遷移率／直帰率／滞在時間を月次確認
- 効能・薬機・景表の表現チェックは別スキル `yakki-keihyo-expression-check` でクロス確認
