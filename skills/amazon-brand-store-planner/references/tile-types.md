# ブランドストア タイル種類と用途

Amazon ストアビルダーで利用できる主要なタイル（モジュール）の種類と使い分け。仕様は更新されるため最新は Amazon セラーセントラル「ストア」ヘルプを確認。

## 主要タイル一覧

| タイル種類 | 主用途 | 推奨配置 |
|---|---|---|
| フルワイド画像 | ヒーロー、ブランドステートメント | ホーム上部 |
| 画像タイル（リンク付き） | カテゴリへの誘導 | ホーム中段 |
| グリッド（複数タイル並列） | カテゴリ／商品の並列 | ホーム・カテゴリ |
| 動画タイル | ブランド／商品デモ | ホーム上中段、カテゴリ上部 |
| 商品タイル | 個別商品への遷移 | カテゴリ・特集 |
| テキストタイル | 見出し・コピー・ブランドステートメント | ホーム・カテゴリ冒頭 |
| ショッパブル画像 | 1枚の画像内で複数商品リンク | コーディネート・ルーティン提案 |
| ベストセラータイル | 自動更新の人気商品 | ホーム下部 |
| 商品グリッド | カテゴリ商品一覧 | カテゴリ |
| 余白タイル | レイアウト調整 | 全体 |
| 背景タイル | カラーパレット適用 | カテゴリ・特集 |

## タイル詳細

### フルワイド画像
- ストア表示幅いっぱいの大きな画像
- 推奨：3000×1500 px 程度（ストア仕様の最新は要確認）
- テキストは画像内に焼き込むか、テキストタイルで重ねる
- ヒーロー、特集冒頭、季節キャンペーンに有効

### 画像タイル（リンク付き）
- カテゴリページや特集ページへの誘導
- 1枚で1リンク
- ホームのカテゴリ誘導でグリッド状に並べて使う

### グリッド
- 複数のタイルを横並び（2列／3列／4列）
- 商品グリッド／カテゴリ誘導グリッド／コンセプトグリッドなど
- モバイルでは2列表示が基本

### 動画タイル
- MP4（H.264）推奨
- 推奨尺：15〜45秒、長くても60秒程度
- ミュート再生でも理解できる字幕付き or 焼き込みテロップ
- 用途：ブランドフィルム、商品の使用デモ、開発ストーリー

### 商品タイル
- 個別ASINへ直接遷移
- 商品画像・タイトル・価格が自動表示
- カテゴリページでグリッド化することが多い

### テキストタイル
- 見出し・本文を入力
- ブランドステートメント／カテゴリ説明文／FAQ／ストーリーテキスト
- 画像なしで世界観を伝える

### ショッパブル画像
- 1枚のシーン画像内に複数のホットスポット
- 各ホットスポットから個別商品ページへ遷移
- 用途：
  - 「朝のスキンケアルーティン」5商品
  - 「秋の着回しコーディネート」着用商品3点
  - 「キッチン収納セット」関連商品4点
- 撮影段階から「ホットスポット位置に商品が映る」前提で構図を作る

### ベストセラータイル
- 自動的に売上上位を表示
- 自分でASINを選べないため、流動的
- カテゴリの最下部に置くのが定番

### 商品グリッド
- 指定したASIN群を均等に並べる
- カテゴリページのメインコンテンツ
- 4〜12商品が見やすい上限

## タイル選定の判断軸

### 訪問者がそのページで何をするか
- 「初めて見る」→ フルワイド画像／動画／テキスト（ブランド体験）
- 「探す」→ カテゴリ誘導タイル／グリッド／ナビ
- 「比較する」→ 商品グリッド／ショッパブル画像
- 「買う」→ 商品タイル

### 滞在時間を伸ばすか・即決させるか
- 滞在重視（高関与商品）→ 動画／フルワイド画像／ストーリーテキスト多め
- 即決重視（リピート商品）→ 商品タイル／ベストセラー／検索的なグリッド

### モバイル可読性
- フルワイド画像は縦長スマホで上下に切れる可能性 → 重要要素は中央寄せ
- グリッド3列／4列はスマホで縦並びになる → 順序を意識
- 動画は縦動画／正方形動画も検討

## タイル数の上限

ストアビルダー上の1ページあたりタイル数の上限はあるが仕様変動する。実用的には：

- ホーム：7〜12タイル
- カテゴリ：5〜10タイル
- 特集：5〜8タイル

過剰に多いと読み込み時間と離脱率が悪化する。

## 制作素材の発注時に決めること

タイルごとに、ブリーフへ以下を明記：

| 項目 | 例 |
|---|---|
| タイル種類 | フルワイド画像 |
| 推奨解像度 | 3000×1500 px |
| 被写体 | 商品＋使用シーン |
| 構図 | センター／2:3 |
| カラートーン | 暖色／ベージュ系 |
| テキスト要素 | 見出し2行 |
| リンク先 | （カテゴリページURL or ASIN）|
