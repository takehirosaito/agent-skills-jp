# ブランドストア構造

Amazon ブランドストアは階層構造を持つマルチページ構成。各ページ種別の役割を整理する。

## 階層の基本

```text
ホームページ（1）
├── カテゴリページ（最大5〜6を目安）
│   ├── サブカテゴリページ（必要に応じて）
│   └── 商品グループページ
├── 特集ページ（季節・新作・コラボ）
└── ストーリー／About ページ
```

## 各ページ種別の役割

### ホームページ
- ブランドの第一印象
- ストア訪問者の最初の着地点
- 目的：滞在時間を伸ばし、カテゴリページへ遷移させる
- 商品個別のリストは置きすぎない（カテゴリへ誘導）

構成要素の典型：
1. ヒーロー（フルワイド画像 or 動画）
2. ブランドステートメント（テキスト）
3. カテゴリへの誘導タイル（4〜6）
4. 動画モジュール（任意）
5. 特集／新作（任意）
6. ベストセラー（任意）
7. ブランドの取り組み（任意）

### カテゴリページ
- 商品の用途／対象顧客／成分などで括ったグループ
- 目的：訪問者に「自分に合う商品はどれか」を提示
- 商品4〜12をグリッドで並べる構成が中心

構成要素：
1. カテゴリヒーロー（カテゴリ名＋世界観イメージ）
2. カテゴリ説明文
3. 商品グリッド（or ショッパブル画像）
4. サブカテゴリへの誘導（あれば）
5. 関連カテゴリへの誘導

### サブカテゴリページ
- カテゴリをさらに細分化（保湿／美白／日焼け対策など）
- 3階層目になるため、設置するかは商品数次第（30以上で検討）

### 商品グループページ
- 「セット買い」「ルーティン」など特定の組合せを推す独立ページ
- ショッパブル画像を中心に構成

### 特集ページ
- 季節（夏・冬）／新作／コラボ／キャンペーン
- 期間限定で公開／非公開を切り替える運用に向く
- ナビには「特集」タブとして配置

### ストーリー／About ページ
- ブランド由来・思想・産地・職人・取り組み
- ホームの一部に組み込む or 独立ページ化
- 直接購入には繋がらないが滞在時間・ブランドエンゲージメントに寄与

## 階層設計の指針

### 商品数別の推奨

| 商品数 | 推奨構造 |
|---|---|
| 5商品未満 | ホーム＋商品グリッドのみ（1ページ） |
| 5〜20商品 | ホーム＋カテゴリ2〜3（2階層） |
| 20〜50商品 | ホーム＋カテゴリ4〜5＋特集（2階層＋特集） |
| 50〜100商品 | ホーム＋カテゴリ5＋一部サブカテゴリ＋特集（3階層） |
| 100商品以上 | ホーム＋カテゴリ5＋サブカテゴリ全展開＋特集（3階層） |

### よくある失敗

- **2階層なのにナビ項目が10超**：ナビは6項目以内が原則
- **3階層を超えてしまう**：訪問者は1〜2クリックで目当てに辿り着けないと離脱
- **ホームに全カテゴリの商品グリッドを並べる**：情報過多でカテゴリページに行かない
- **カテゴリ間の商品が大量に重複**：同じ商品が3カテゴリに登場するなど → 軸の取り直し
- **季節特集が古いまま残る**：「クリスマス特集」が3月まで表示など → 公開／非公開切替の運用ルール化

## モバイル前提の設計

ストア訪問の過半数はモバイル。ホームページの「ファーストビュー」はモバイル基準で：

- スマホ縦画面1画面内にヒーロー＋ステートメントが収まる
- カテゴリ誘導タイルはスマホで2列表示が見やすい
- 動画はミュート再生（音声前提にしない）

## ストアアナリティクスで見る指標

公開後、Amazon のストアアナリティクスで以下を確認：

- 訪問者数（PV／UU）
- ホームページからカテゴリへの遷移率
- カテゴリページから商品ページへの遷移率
- 商品ページからの売上
- 平均滞在時間
- 直帰率

ホームの直帰率が高い → ヒーロー／ステートメントを見直す
カテゴリ遷移後の直帰 → カテゴリページの説明文や商品グリッドを見直す
