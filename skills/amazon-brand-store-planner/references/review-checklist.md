# ブランドストア 公開前チェック

Amazon が審査でリジェクトする代表的な項目と、公開前に確認するチェックリスト。

## 必ず除外する要素

### 1. 外部誘導
- 自社ECサイト・ブログ・SNSへのリンク
- メールアドレス、電話番号
- QRコード
- 「○○で検索」など Amazon 外への誘導表現

### 2. 競合・他媒体への言及
- 競合企業名・商品名・ロゴ
- 「他社製品より優れています」「A社比○%」の直接比較
- 「楽天で人気No.1」など他モール／他媒体ランキング
- 著作権・商標権侵害（無断使用したロゴ・キャラクター）

### 3. 価格／プロモーション期限
- 「○月○日まで」「セール中」「期間限定」「在庫限り」
- 価格表記（円・OFF・割引）
- ストアは永続表示のため、固定の期間限定表現はリジェクト対象になりやすい

### 4. 根拠なき最上級・断定
- 「No.1」「最高」「世界初」「業界唯一」
- 「絶対」「必ず」「100%」
- No.1表記は景表法・Amazon両面で根拠5項目（主体／期間／対象／方法／出典）が必要

### 5. 法規制抵触表現
- 医薬品的効能（治る／予防／治療）
- 化粧品56項目外の効能訴求
- 健康食品の効能標榜（届出外）
- 景表法の優良誤認・有利誤認

### 6. Amazon 関連の言及
- 「Amazon限定」「Amazonで購入」「Prime対象」
- Amazon／Amazon ロゴの不適切使用
- Amazon ランキングのスクショ転載

### 7. レビュー転載
- お客様の声をストア画像内に焼き込み
- 「★4.5」「99%が満足」を画像内に配置（根拠示せない）

### 8. 不適切な画像
- 1000px未満の低解像度
- CMYKカラープロファイル
- ぼやけた・手ブレ画像
- 視覚的に過激／不快／差別的な要素
- 警告ラベルなしの危険使用シーン

### 9. 動画素材のNG
- 音楽の著作権侵害
- 字幕なしで音声前提の説明
- 解像度不足・低品質
- Amazon ロゴ・他社ロゴが映り込む
- 効能効果の口頭での誇大訴求

## 公開前チェックリスト

### コンテンツ
- [ ] 外部URL／SNSリンクが含まれていない
- [ ] 競合企業の名前・ロゴが含まれていない
- [ ] 価格表記がない
- [ ] 期間限定固定の文言がない
- [ ] 薬機・景表抵触表現がない
- [ ] No.1／最上級表現に根拠5項目がある（該当時）
- [ ] レビュー転載がない
- [ ] Amazon ロゴ・Amazon言及が適切

### 構造
- [ ] サイトマップが3階層以内
- [ ] メインナビが6項目以内
- [ ] 各ページに最低1つのリンク（行き止まりがない）
- [ ] ナビゲーション項目名が10文字以内
- [ ] 季節特集ページの公開／非公開切替ルールが社内で明確

### 画像
- [ ] 全画像がsRGBカラー
- [ ] フルワイド画像が3000×1500 px 以上
- [ ] 画像内テキスト占有率が過剰でない
- [ ] 解像度不足の画像がない
- [ ] 透過PNGの背景処理が正しい

### 動画
- [ ] MP4（H.264）形式
- [ ] 字幕 or 焼き込みテロップでミュート再生でも理解可能
- [ ] 音楽の著作権が適正
- [ ] 60秒以内（推奨）
- [ ] Amazon ロゴ・他社ロゴが映り込んでいない

### モバイル動作
- [ ] スマホでヒーローが収まる
- [ ] グリッドが見やすく折り返している
- [ ] ナビゲーション（ハンバーガー）が機能する
- [ ] 動画がモバイルでも再生できる
- [ ] タップ可能領域（タイル）が十分な大きさ

### リンク先
- [ ] 全タイルのリンク先ASIN／カテゴリページが有効
- [ ] 削除されたASIN・在庫切れASINが含まれていない
- [ ] 外部URLへのリンクがない

### 整合性
- [ ] A+コンテンツとの世界観／コピーの整合
- [ ] 商品ページのbullet／タイトルと矛盾しない
- [ ] スポンサーブランド広告のランディング先と整合

## リジェクトされた場合

- リジェクト理由メッセージを必ず保存
- 該当箇所を特定して修正
- 再提出は12〜24時間後を推奨
- 何度もリジェクトされる場合はセラーサポートにケース起票して具体的なフィードバックを得る

## 公開後の運用

- ストアアナリティクスで「直帰率」「カテゴリ遷移率」「滞在時間」を月次で点検
- 季節特集は公開／非公開を切替（古い季節タブが残らない）
- スポンサーブランド広告のランディング先と連動して、特集ページの公開期間と広告期間を合わせる
- A+コンテンツ・商品ページのリニューアルがあれば、ストアのコピーも整合させる
