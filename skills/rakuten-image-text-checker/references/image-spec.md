# 楽天画像規定（2024.6改定版）

最新は RMS 店舗運営Navi の「商品画像登録ガイドライン」で確認。

## 基本要件

| 項目 | 内容 |
|---|---|
| サイズ | 700×700px以上推奨（500×500pxが最小要件の時期あり） |
| ファイル形式 | JPG、PNG、GIF |
| 縦横比 | 正方形推奨 |
| ファイルサイズ | 個別の上限値はモール仕様確認 |

## 背景（2024.6改定で3種OKに）

| 背景タイプ | OK／NG | 例 |
|---|---|---|
| 白基調背景 | OK | 白／オフホワイト／薄グレー |
| 合成背景 | OK | グラデーション、抽象パターン、図形 |
| 写真背景 | OK | 自然・室内・スタジオ撮影 |

改定前は「白基調」のみが原則だったが、2024.6から合成・写真背景もOKに。

## 枠

- **枠線禁止**：画像外周に枠線（罫線・装飾）を入れない
- 内側のレイアウト要素として枠を使うのも避ける
- フレーム風加工も対象になる場合あり

## テキスト占有率

- **20%以内**（画像全体の面積に対するテキスト面積比）
- 目安：10×10マスに分割し、テキスト要素が **20マス以内**
- 文字だけでなく文字背景の色面も含めて計算する場合がある

## メイン画像（1枚目）の要件

- 商品本体が明確に視認できる
- 商品占有率：高い割合（楽天では明確な数値基準が示されにくいが、Amazonの「商品占有率85%以上」を参考にする店舗が多い）
- 過大な装飾・ロゴ・透かしを避ける
- 「セール」「ポイント10倍」等の販促バナーは商品が霞まない範囲で

## サブ画像（2枚目以降）

- 商品の異なる角度・使用シーン・サイズ感・スペック・比較表
- テキスト訴求はサブ画像で行うのが基本
- ただしサブ画像でも占有率20%以内・枠禁止は同じ

## スマホ表示の制約

- スマホ商品ページの一覧表示で正方形に切り抜かれる
- 端のテキストや装飾が切れる可能性 → 安全領域は中央寄りに配置
- 文字サイズはスマホ視認性を確保（実機確認）

## 動画キャプチャの静止画

- 動画のサムネイル画像は通常画像と同じ規定
- 動画内のテキスト・字幕はモール独自審査の対象になる場合あり

## やってはいけない加工

- 過度な色補正で実物と異なる印象を与える
- 商品の傷・汚れを隠す加工
- サイズ感を実物より大きく／小さく見せる加工
- 「使用後の効果」を演出する加工（特に化粧品のbefore-after）

## ジャンル別の追加注意

### 化粧品（100939）
- before-after画像はNG（スキンケアの場合）
- メーキャップ・物理効果（化粧崩れ防止等）はOK
- 「医薬部外品」の表示は商品仕様に基づく
- 56効能を超える訴求はNG

### 健食（100938）
- 機能性表示食品は届出文言と一致
- 一般食品で「痩せる」「効く」等の医薬品的表現はNG
- 体験談を効能訴求として使うのはNG

### 食品（100227）
- アレルゲン表記（特定原材料8品目）
- 賞味期限・保存方法
- 原産地表示

### 家電（562637）
- 消費電力・サイズ等のスペック表示
- 「壊れない」「永久保証」等の断定NG

### ファッション（100371／551177）
- モデル着用時はサイズ感の誤認を招かない
- 色・素材の実物と画像の差異に注意（モニター差は表記）

## 規定違反時の影響

- 検索結果から非表示／表示順位低下
- スマホ一覧表示制限
- モールからの修正要請、最悪掲載停止
- 違反点数の蓄積（楽天は違反点数制）

## 改定タイミングの把握

楽天は画像規定を定期的に改定する。改定情報は：
1. RMS 店舗運営Navi のお知らせ
2. 楽天e-Naviのメール通知
3. RMSサポート問い合わせ

過去の改定で「白背景必須」「白背景＋合成」「3種OK」と段階的に変化している。最新版を確認する習慣を持つこと。
