# 楽天画像内テキストチェック

## 概要

楽天市場の商品画像は規定が厳しく（テキスト占有率20%以内、枠線禁止、サイズ700×700px以上、背景3種類のみ）、加えて画像内テキストには薬機法・景表法のリスクが潜みます。本スキルは画像内テキストの一次チェックを行い、規定違反・法令リスク・修正案を整理します。

判定は画像が見えない場合も含めて、ユーザーから提供される「画像内テキストの転記」「画像の説明」「商品カテゴリ」に基づき暫定判定する設計です。

## 最重要原則

**「テキスト占有率20%が上限／枠禁止／背景3種以外NG／画像内の効能訴求・最大級は薬機景表違反」**。占有率と法令リスクを必ず両方チェックする。

## 知識ベース

楽天画像規定（2024.6改定版）：

| 項目 | 規定 |
|---|---|
| サイズ | 700×700px以上推奨 |
| 形式 | JPG／PNG／GIF |
| 縦横比 | 正方形推奨 |
| 背景 | 白基調／合成／写真（3種のみOK） |
| 枠 | 禁止（外周罫線・装飾枠） |
| テキスト占有率 | 20%以内（10×10マスで20マス以内） |

詳細：
- 画像規定の詳細（背景・枠・占有率）：`references/image-spec.md`
- 画像内テキストのNG／OKルール：`references/text-rules.md`
- カテゴリ別チェックポイント（化粧品・健食・家電など）：`references/category-checks.md`
- チェック実例：`references/examples.md`

楽天独自の重要数値：
- メイン画像のテキスト占有率超過 → ガイドライン違反指摘
- 枠線入り画像 → 違反点数リスク
- 「効能訴求」「最大級」「No.1根拠なし」 → 薬機景表違反点数（最大35点）

## 処理フロー

### Step 1：画像情報の収集

- 画像内テキスト（文字起こし）
- 画像の用途（メイン／サブ何枚目）
- 商品カテゴリ
- 背景タイプ
- 枠・装飾の有無
- サイズ（数値）

不明な場合は「メイン画像／700×700px／白基調背景」と仮定して進める。

### Step 2：規定チェック（占有率・枠・背景・サイズ）

| 項目 | 判定基準 |
|---|---|
| テキスト占有率 | 文字＋文字背景色面の合計 ≤ 全体の20% |
| 枠 | 外周罫線・装飾枠なし |
| 背景 | 白基調／合成／写真のいずれか |
| サイズ | 700×700px以上 |

占有率は画像が見えない場合、「10×10マスのうち何マスにテキストがあるか」で見積もる（20マス＝20%）。

### Step 3：法令リスクチェック（薬機法／景表法）

| カテゴリ | NG表現例 | 違反 |
|---|---|---|
| 化粧品 | 「シミに効く」「シワを消す」「アンチエイジング」 | 薬機法 |
| 健食 | 「ダイエット効果」「○○病が治る」 | 薬機法 |
| 全般 | 「No.1」「最安」「業界初」根拠なし | 景表法 |
| 全般 | 「絶対」「100%」「必ず」 | 景表法 |
| 全般 | 二重価格根拠なし | 景表法 |

`references/category-checks.md` でカテゴリ別の詳細を参照。

### Step 4：スマホ視認性チェック

- 中央寄りに重要テキスト配置（スマホ正方形切り抜き対策）
- 文字サイズが小さすぎないか
- 端のテキストが切れていないか

### Step 5：修正案の作成

各リスク項目に「現状」「リスク」「修正案」を3点セットで提示。

### Step 6：優先度づけ

- 緊急（即修正）：法令違反、枠線、占有率大幅超過
- 高（当日中）：占有率軽微超過、サイズ不足
- 中（次の更新時）：スマホ視認性、デザイン改善

## 代表例

### 例：化粧水のメイン画像（テキスト多め）

提供情報：「画像内テキスト『シミに効く！医師も推奨！No.1』、白背景、枠なし、700×700px」

判定：

| 項目 | 結果 | リスク |
|---|---|---|
| 占有率 | テキスト密度高、推定30-40% | ガイドライン違反 |
| 枠 | なし | OK |
| 背景 | 白基調 | OK |
| サイズ | 700px | OK |
| 法令 | 「シミに効く」薬機法違反、「医師も推奨」景表法（医師の推奨は要根拠）、「No.1」根拠不明景表法 | 違反点数リスク（最大35点） |

修正案：
- 「シミに効く」→「乾燥肌をしっとり整える」（化粧品の56効能の範囲内）
- 「医師も推奨」→ 削除、または「医師監修」（実態がある場合のみ・根拠提示）
- 「No.1」→ 削除、またはNo.1根拠（調査主体・期間・対象）併記
- 占有率削減：訴求を2-3項目に絞る

完全な例集：`references/examples.md`

## 品質ゲート

- テキスト占有率の数値見積もりがあるか（「20マス以内」等の具体表現）
- 枠の有無を必ずチェックしているか
- 背景タイプが3種（白基調／合成／写真）のいずれかであるか確認しているか
- 薬機法・景表法のNG表現を抽出しているか
- 各リスクに「修正案」がセットで提示されているか
- スマホ表示時の中央寄り配置が考慮されているか

## エッジケース

- **画像が見えない（テキスト転記のみ）**：暫定判定で「画像実物確認が必要」と冒頭明示
- **化粧品・健食**：効能訴求の判定は薬機法専門スキル `yakki-keihyo-expression-check` 併用
- **ランキング表現**：根拠（調査主体・期間・対象）併記が必須、なければ削除
- **二重価格**：8週間ルールの根拠なき通常価格は景表法違反
- **動画キャプチャ**：動画の静止画も画像規定が適用される

## 注意事項

- 楽天画像規定は管理画面・店舗運営Naviで随時改定される、最新版で確認
- 本スキルは一次チェック、最終判定は楽天側ガイドラインと法務確認
- 画像内テキストの薬機法・景表法判定は法律判断ではない、専門家確認推奨
- 競合ブランド名・他社商標を画像に含めない
- 顧客の実名・個人情報・取引先情報を画像に含めない
