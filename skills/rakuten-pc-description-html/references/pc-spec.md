# PC用商品説明文の仕様・許可HTMLタグ

## CSV列と仕様

| 項目 | 仕様 |
|---|---|
| 列名 | normal-item.csv の `pc-description`（仕様により列名は変動） |
| 容量 | 10,240byte（全角約5,120字） |
| 文字コード | Shift_JIS（CP932） |
| 改行 | CR+LF（HTMLの改行は `<br>` 推奨） |
| 画像 | 楽天R-Cabinet（社内CDN）に置くのが原則 |

## SP用説明文との違い

PC用は許容HTMLタグが広く、より自由なレイアウトが可能。ただし楽天独自のCSS制約・スマホ閲覧時の表示崩れリスクがあるため、過度に複雑なレイアウトは避ける。

| タグ | PC可 | SP可 |
|---|---|---|
| `<table>`/`<tr>`/`<td>` | ◎ | ◎ |
| `<h2>`/`<h3>`/`<h4>` | ◎ | ◎ |
| `<p>`/`<br>` | ◎ | ◎ |
| `<strong>`/`<b>`/`<em>` | ◎ | ◎ |
| `<ul>`/`<ol>`/`<li>` | ◎ | ◎ |
| `<a>`/`<img>` | ◎ | ◎ |
| `<span style="…">` | ○（制限あり） | △ |
| `<div>` | △（避ける推奨） | ❌ |
| `<style>` | ❌ | ❌ |
| `<script>` | ❌ | ❌ |
| `<iframe>` | ❌ | ❌ |
| `<form>`/`<input>` | ❌ | ❌ |
| 外部CSS/JS | ❌ | ❌ |

## Shift_JISで文字化けする文字

- 一部の絵文字
- ㈱ などの機種依存文字
- 一部の中国語簡体字・繁体字
- 機種依存記号①②③など

→ 商品説明には基本的な日本語＋ASCII＋一般記号に限定。

## 画像URLの扱い

- 楽天R-Cabinet：`https://image.rakuten.co.jp/[ショップURL]/cabinet/...` が標準
- 外部画像（CDN／自社サーバ）：可能だが速度・信頼性低下リスク
- 画像URLには `https://` を使う（http はブラウザ警告）

## CSS style属性の使用

PC版では `style="..."` 属性が部分的に使える（楽天の独自CSS表記）：

- `style="color: #FF0000;"`：文字色
- `style="text-align: center;"`：中央寄せ
- `style="font-size: 18px;"`：文字サイズ

ただし：
- 過度な `style` は楽天独自審査で警告対象
- 重要訴求は画像内に埋め込むのが安全
- スマホ閲覧時に崩れることがあるため、必須スタイルは最小限に

## ファーストビュー（先頭表示）

商品ページのPC版は、説明文の **先頭1000文字程度** がファーストビューに該当（ブラウザ縦幅次第）。

- 重要訴求（USP・スペック要約）を先頭に
- 画像は1枚目を大きく、見出しと併用
- 「商品の選び方」「使い方」等の補助情報は後半に

## byte数の数え方

| 文字 | byte |
|---|---|
| 半角英数（A、1） | 1 |
| 半角記号（!@#$） | 1 |
| 全角ひらがな・カタカナ・漢字 | 2 |
| HTMLタグ（半角文字） | タグ文字数分 |

簡易計算例：
- `<table>` = 7byte
- `<tr><td>商品名</td></tr>` = 半角14 + 全角6 = 14 + 12 = 26byte

10,240byte枠の使い方：
- HTMLタグ：2,000-3,000byte
- 本文・テキスト：6,000-7,500byte
- 画像URL：500-1,000byte（複数）
- 余裕：500byte（更新時のバッファ）

## NG装飾

- 過剰な `<font color>` 装飾（楽天独自審査）
- 大量の `<br>` 連打（縦長になりすぎる）
- 装飾だけの空テーブル
- 中身が薄い `<h2>` の連発

## 推奨される情報密度

1ページに以下が含まれているとファーストビュー〜詳細まで揃う：

- ファーストビュー：USP3行＋メイン画像1枚
- スペック表：必須属性10〜15項目
- 特徴セクション：USP 3-5個（各2-3行）
- 比較表：1表（自社バリエ or 競合）
- 使用シーン：3-5画像
- FAQ：3-5問
- 送料・配送：必須情報
- 保証：必須情報

→ 合計で10,240byte以内に収まる。

## 公開前のテスト

| 確認項目 | 方法 |
|---|---|
| byte数 | テキストエディタで保存時のbyte確認、または `python -c "print(len(s.encode('shift_jis')))"` |
| 文字化け | Shift_JISで保存し、楽天プレビューで確認 |
| HTMLレイアウト | 楽天RMSのプレビュー |
| 画像表示 | R-Cabinet URLでアクセス確認 |
| スマホ閲覧 | スマホ実機で表示崩れ確認 |
