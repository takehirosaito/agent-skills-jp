# 推奨HTMLブロック構造とテンプレート

## ブロック1：ファーストビュー強調

````html
<h2>[USPコピー：商品の最大の強みを1行で]</h2>
<p>[補足コピー：1-2行]</p>
<p><img src="[メイン画像URL]" alt="[商品名] メインビジュアル"></p>
````

例：
````html
<h2>1.0L大容量・7段階温度調整・1年メーカー保証</h2>
<p>毎朝のコーヒー・紅茶を最適温度で。お手入れも簡単な広口設計。</p>
<p><img src="https://image.rakuten.co.jp/example/cabinet/kettle/main.jpg" alt="電気ケトル メインビジュアル"></p>
````

## ブロック4：比較表

### 自社バリエーション比較
````html
<h3>モデル比較</h3>
<table border="1" cellpadding="8">
  <thead>
    <tr>
      <th>項目</th>
      <th>本商品（標準モデル）</th>
      <th>上位モデル</th>
    </tr>
  </thead>
  <tbody>
    <tr><th>容量</th><td>1.0L</td><td>1.5L</td></tr>
    <tr><th>温度調整</th><td>7段階</td><td>無段階</td></tr>
    <tr><th>保温機能</th><td>なし</td><td>あり</td></tr>
    <tr><th>価格</th><td>5,000円</td><td>8,000円</td></tr>
  </tbody>
</table>
````

### 競合との比較は法令配慮
- 「他社」と直接書かず「一般的な電気ケトル」「同価格帯製品」など
- 競合の固有名詞は商標問題

## ブロック構成のテンプレート（10,240byte目安）

```
1. ファーストビュー強調（300byte）
2. スペック表（1,000byte）
3. 特徴・USP（1,500byte）
4. 比較表（800byte）
5. 使用シーン画像（500byte ※URLのみ）
6. FAQ（1,500byte）
7. 送料・配送（400byte）
8. 保証・返品（400byte）
9. レビュー誘導（200byte）
10. 会社情報（300byte）

合計 6,900byte（残り3,000byte以上で余裕）
```

byte数は装飾の有無で大きく変わるため、実測必須。

## 装飾を控えめにする理由

- 過度な `<font color>` `<strong>` の連打 → 読みにくくなる
- 装飾だけの空テーブル → 楽天独自審査でNGになることあり
- 派手な画像 → 占有率20%規定違反のリスク

「読みやすく、必要な情報が網羅されている」のが最重要。
