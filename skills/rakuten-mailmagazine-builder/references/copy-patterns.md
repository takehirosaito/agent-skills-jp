# 件名・本文の構成パターン

## 件名の型（40字以内）

### 型1：数字＋期日型
- 「【3日間限定】全品10%OFFクーポン配布中」
- 「今夜23:59まで！500円OFFクーポン」

### 型2：イベント連動型
- 「【お買い物マラソン】店舗内全品ポイント10倍」
- 「楽天スーパーSALE｜半額商品多数」

### 型3：会員ランク型
- 「【ゴールド会員様限定】5%OFFクーポン配布」
- 「お得意様限定 先行販売のお知らせ」

### 型4：希少性型
- 「【先着100名】限定セット販売開始」
- 「残りわずか！人気○○の再入荷」

### 型5：再入荷・新商品型
- 「【再入荷】お待たせしました！○○入荷」
- 「新商品入荷｜○○シリーズ販売開始」

### 型6：理由訴求型
- 「○○周年セールで500円OFF配布中」
- 「決算セール｜在庫処分価格」

### 件名で避けるべき

| NG | 理由 |
|---|---|
| 「お知らせ」「ご案内」 | 開封されない |
| 「★★★お得情報★★★」 | スパム判定リスク、過剰装飾 |
| 「!!!! 緊急 !!!!」 | スパム判定リスク |
| 「○○様限定」だけ | 内容不明、クリック動機が弱い |
| 全部大文字「SALE OFF」 | スパム判定リスク |
| 絵文字過多 | スマホ環境次第で文字化け |

## 本文構成テンプレート

### A. シンプル告知型（短文）

```
[挨拶 1行]

[本文冒頭3行：訴求＋メインCTAリンク]

▼ご覧いただく
https://...

[二次CTA：別の関連訴求]

[フッタ：会社情報・配信解除]
```

```

▼ご覧いただく
https://...
```

## 本文の書き方ポイント

### 冒頭3行ルール

- 1行目：挨拶（短く）
- 2行目：本日の主要訴求
- 3行目：メインCTAリンク

**例**：
> ○○店をご利用いただきありがとうございます。
> 本日20:00から、お買い物マラソン限定500円OFFクーポンを配布いたします（5,000円以上）。
> ▼クーポン取得・お買い物 https://...

### リンクは目立たせる

- `▼ ご覧いただく` のような誘導記号
- URLは短く（楽天のリンクはそのまま貼ると長い）
- 同じURLを複数箇所に置く（冒頭・中盤・末尾の3箇所）

### 段落と空行

- 1段落 = 1〜3行
- 段落間に空行を入れる（読みやすい）
- 長すぎる段落は離脱要因

### CTAボタンの言葉

| OK | NG |
|---|---|
| クーポンを取得する | お得 |
| 商品を見る | リンク |
| カートに入れる | こちら |
| 詳細を見る | クリック |

## HTMLメール vs テキストメール

| 項目 | テキスト | HTML |
|---|---|---|
| 開封率 | やや高い | やや低い |
| CTR | 中 | 高 |
| 制作コスト | 低 | 中〜高 |
| スマホ最適化 | 自動 | 要設計 |
| 画像オフ対応 | 不要 | 必要 |

楽天メルマガはHTML可能。ただし画像オフ環境を想定し、テキストでも訴求が成立する設計が必須。

## 装飾と絵文字

### 使ってOKな装飾
- ▼ ▽（誘導）
- ★（評価表示など、節度ある使用）
- 【】（重要部分の囲み）
- 半角スペースによる視覚的区切り

### 避けるべき装飾
- ★★★★★（過剰）
- !!!!（過剰）
- 絵文字を1行に多数（スパム判定）
- 罫線記号（────── 等）の連発

## 件名のA/B案を必ず2つ以上出す

メルマガは件名でほぼ開封率が決まる。1案で確定せず、A/B両方をクライアントに見せて選んでもらう運用が良い。

例（同じセール告知）：
- 件名A「【今夜開始】お買い物マラソン｜全品500円OFFクーポン」
- 件名B「もうすぐ20:00！マラソン限定クーポン配布｜500円OFF」

A/B案の差分：
- 時刻表記（今夜開始 / もうすぐ20:00）
- 順序（イベント名先 / 緊急性先）
