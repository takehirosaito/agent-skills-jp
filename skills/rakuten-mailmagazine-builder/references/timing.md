# 配信タイミング・頻度設計

## 一般的な高開封率時間帯

| 時間帯 | 開封率傾向 | 用途 |
|---|---|---|
| 平日 朝7-9時 | 高 | 通勤時間スマホチェック |
| 平日 昼12-13時 | 中 | 昼休みスマホチェック |
| 平日 夕方17-19時 | 中〜高 | 退勤時のチェック |
| 平日 夜20-22時 | 高 | 家でゆっくりタイム |
| 平日 夜23時以降 | 低 | 就寝前は離脱 |
| 土日 午前10-12時 | 高 | 起床後にチェック |
| 土日 午後14-18時 | 中 | お出かけ・買い物時間 |
| 土日 夜20-22時 | 高 | 家族時間のあとチェック |

※業種・読者層で変動。化粧品・ファッションは女性向け＝夜時間に強い、家電・PC周辺機器は男性向け＝昼休みや夜に強い等。

## 配信頻度

### 一般的な目安

| 頻度 | 影響 |
|---|---|
| 週1回 | 安全。記憶定着・配信解除リスク低 |
| 週2回 | 一般的なペース |
| 週3回 | やや多め。読者属性次第 |
| 週4回以上 | 配信解除率上昇のリスク |
| 1日2回以上 | スパム判定・解除急増 |

### イベント期間中の例外

- 楽天SS／マラソンなど大型イベントは1日2回配信もあり（開始告知＋終了告知）
- ただし通常期に戻ったら頻度も戻す

### 配信解除率の目安

- 1配信あたり 0.1〜0.5% が一般的
- 1%超えたら配信内容・頻度の見直し必要

## セグメント別の配信頻度

| セグメント | 推奨頻度 |
|---|---|
| 全配信 | 週1-2回 |
| 会員（購入経験あり） | 週2-3回 |
| ゴールド以上 | 週2-3回（特別感のある内容） |
| 過去90日購入者 | 週1-2回 |
| 休眠（180日以上未購入） | 月1-2回（リテンション特化） |
| 高頻度購入者（月3回以上） | 週3回まで可（嫌悪感の様子見） |

## 配信前のテスト送信

| チェック | 確認内容 |
|---|---|
| 件名 | スマホ／PC両方で表示確認 |
| 本文表示 | テキスト版・HTML版両方 |
| リンク | 全リンクのクリック動作 |
| 画像 | 画像オフ環境でも訴求が成立 |
| 配信解除リンク | ワンクリックで完了するか |
| スマホ表示 | 改行位置・縦長度合い |

## 配信後のモニタリング

| 指標 | 計算 | 目安 |
|---|---|---|
| 開封率 | 開封数 / 配信数 | 3-10%（業種・読者層次第） |
| クリック率（CTR） | クリック数 / 配信数 | 0.5-3% |
| 開封→クリック率 | クリック数 / 開封数 | 10-30% |
| 配信解除率 | 解除数 / 配信数 | 0.1-0.5% |
| コンバージョン率 | 注文数 / 配信数 | 0.05-0.5% |

## 配信日と曜日の選び方

### 楽天モール公式イベントと避けるべき日

- SS／マラソン開始日：自社の通常告知は避け、イベント告知に集中
- 楽天主催のクーポン日：自社クーポンと競合

### 自社のイベントを設定する場合

- 月末月初：給与日付近で購入意欲が高い
- 五十日（5・10・15・20・25・30）：法人取引と給与日が重なる
- 五のつく日：楽天独自のキャンペーンと重なるため自社告知は控えめに
- ゾロ目の日（11、22）：Yahoo!ショッピングのキャンペーン日。楽天より弱いが念のため

## 配信頻度を上げたい時の判断軸

1. 過去の同条件配信で配信解除率が低い（0.2%未満）
2. CTRが業界平均より高い
3. 配信内容が読者にとって新鮮（同じ訴求の繰り返しではない）

これらが満たされたら段階的に頻度を増やせる。逆に解除率が0.5%を超え始めたら頻度を下げる。
