# 配信目的別 メルマガ実例6パターン

各例は楽天市場のメルマガを想定。送信者情報・配信停止リンクは雛形を [プレースホルダ] で示す。

- A：「【今夜20:00開始】お買い物マラソン｜全品500円OFFクーポン配布」（37字）

```

本日20:00から開催の楽天お買い物マラソンに合わせ、
店舗内全商品で使える500円OFFクーポン（5,000円以上）を配布いたします。

▼クーポン取得・お買い物
https://item.rakuten.co.jp/[ショップURL]/

【特典内容】
・店舗内全品で使える500円OFFクーポン
・お買い物マラソンで買いまわり最大10倍
・送料無料商品多数

【利用条件】
・期間：○月○日 20:00 〜 ○月○日 01:59
・対象：5,000円以上のお買い物
・利用枚数：お一人様1回限り

▼人気商品はこちら
https://item.rakuten.co.jp/[ショップURL]/category/

最後までお読みいただきありがとうございます。

----
○○店
[法人名][代表者氏名]
[住所]

配信停止：[配信停止URL]
```

## 件名作成のコツ（まとめ）

1. **数字を入れる**（500円OFF、5%OFF、3日間、先着100名）
2. **期日を入れる**（今夜23:59、明日まで、5月10日）
3. **対象を明示**（会員限定、ゴールド以上、過去購入者）
4. **スマホ表示で見える先頭25-30字に重要語**
5. **過剰装飾は避ける**（!!! ★★★）
6. **A/B案を必ず2つ以上出す**
