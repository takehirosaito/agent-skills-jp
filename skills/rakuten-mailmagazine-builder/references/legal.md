# 特定電子メール法・景表法・薬機法 配慮

## 特定電子メール法（必須）

### オプトイン規制

- 受信者の **事前同意** が必要
- 同意の取得方法：
  - 商品購入時のメルマガ登録チェックボックス（デフォルトオフ）
  - 会員登録時のメルマガ希望チェック
  - 楽天ID連動で楽天上の同意状況を継承

### 必須記載事項

メルマガフッタに以下を必ず明記：

1. **送信者の氏名／法人名**
2. **送信者の住所**
3. **配信停止の方法**（URLでワンクリック実行可能に）
4. **送信者への問い合わせ先**（メールアドレス／電話）

### NG例
- 配信停止リンクがない／機能しない
- 配信停止に複数ステップ・ログイン必須
- 送信者情報が不完全（メールアドレスだけ等）

### 違反時のペナルティ

- 総務省／消費者庁から行政処分
- 1年以下の懲役または100万円以下の罰金（法人は3,000万円以下）

## 景表法（不当景品類及び不当表示防止法）

### 優良誤認・有利誤認の防止

メルマガでも商品ページと同じ規制：

- 「最安」「No.1」「業界初」 → 根拠なしの最上級表現NG
- 「全員にプレゼント」と書いて条件あり → 有利誤認
- 「通常価格5,000円→今だけ3,000円」 → 8週間ルール根拠必須

### No.1表記の4要件＋出典

メルマガで「○○調査No.1」を訴求する場合：

1. 比較する商品等が適切に選定
2. 調査対象者が適切に選定
3. 調査が公平な方法で実施
4. 表示内容と調査結果が適切に対応
+ 調査主体／期間／対象／方法／出典を明示

### 二重価格表示の8週間ルール

「通常価格○○円→セール価格○○円」と訴求する場合、通常価格は **開始直前8週間のうち過半（4週間以上）で実販売されていた価格** であること。

### 打消し表示の7原則

「※○○の場合があります」「※個人の感想です」等の打消し表示は以下を満たさないと機能しない：

1. 主要訴求と同じ画面内
2. 主要訴求の近接位置
3. 主要訴求と同等以上の視認性
4. 主要訴求と矛盾しない
5. 表示時間（動画の場合）
6. 通常注視する場所
7. 消費者の判断に必要十分な内容

メルマガでの「※」は本文同程度のフォントサイズで明記。フッタの薄文字は機能しない。

## 薬機法（化粧品・健康食品メルマガ）

### 化粧品

- 効能効果は **56項目内** のみ
- 「シミに効く」「シワが消える」「アンチエイジング」「リフトアップ」はNG
- メルマガ件名・本文・画像すべて対象

### 医薬部外品

- 承認された効能効果のみ
- 「医薬部外品」の表示が必要

### 健康食品

| 区分 | メルマガで言える範囲 |
|---|---|
| 一般食品 | 効能効果は不可。一般的表現のみ |
| 栄養機能食品 | 国の定型文のみ（改変不可） |
| 機能性表示食品 | 届出した機能性表示（一字一句一致） |
| 特定保健用食品 | 許可された保健の用途 |

### NG表現

- 「痩せる」「便秘解消」「免疫力UP」「視力回復」「関節痛が治る」
- 体験談を効能訴求として使う
- 医師・薬剤師の推薦

## 健康増進法

食品の誇大表示禁止：

- 「世界が認めた健康効果」（根拠なし）
- 「○○病予防」「○○の症状改善」
- 「医療現場でも使用」（事実でも誤認を招く）

## ステマ規制（2023.10.1〜）

メルマガでインフルエンサー・モニターの感想を載せる場合：

- **広告主が依頼している場合**：本文に「PR」「広告」「プロモーション」を明示
- 「お客様の声」として体験談を載せる場合、効能訴求として使うとNG（化粧品・健食）

## 個人情報保護

- 配信先リストはメルマガ目的の利用に限定
- 第三者提供は原則禁止
- 漏洩時は個人情報保護委員会への報告義務

## チェックリスト

メルマガ配信前：

- [ ] 送信者名・住所がフッタにある
- [ ] 配信停止リンクがワンクリックで完了する
- [ ] テスト送信で配信停止リンク動作確認
- [ ] 「最安」「No.1」「業界初」等の根拠を併記
- [ ] 二重価格の8週間ルール根拠を保管
- [ ] 化粧品の56項目外表現を含まない
- [ ] 健康食品の医薬品的表現を含まない
- [ ] インフルエンサー協賛時はPR表記
- [ ] 過剰装飾・スパム判定キーワードを避けた
