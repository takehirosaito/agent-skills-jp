# レビュー × トーンの組合せ実例8パターン

## 例1：高評価感謝レビュー × 親しみトーン

### レビュー（★5）
「サイズもピッタリで生地もしっかり！想像以上に良かったです。また買います！」

### 返信
```
○○様

ご購入ありがとうございます！
「サイズもピッタリ、生地もしっかり」とのお言葉、私たちもとても嬉しいです。

実はこのTシャツ、生地の選定にかなりこだわって、何種類もサンプルを試した末に
今の素材に決めました。○○様に気に入っていただけて、本当に作って良かったなあと思います。

新作も近々ご紹介しますので、ぜひまた覗いてみてくださいね。
重ねてありがとうございました！

○○ショップ
```

### 工夫
- 「サイズ・生地」という具体的言及
- 開発エピソードで人間味
- セールス押し付けにならず、新作の案内のみ
- カジュアル過ぎず、敬語の柔らかさを保つ

## 例2：低評価クレーム × 標準丁寧トーン

### レビュー（★1）
「最悪。色が写真と全然違う。これじゃ使えない。返品もできないし二度と買いません。」

### 返信
```
○○様

このたびはご購入いただき、また貴重なご意見をいただきありがとうございます。
お写真とお手元の商品で色味が異なり、ご期待に添えなかったことを深くお詫び申し上げます。

撮影環境やモニターによる色差はあるものの、それを踏まえても説明が十分でなかったかと
真摯に受け止めております。
商品ページの色見本・画像説明について、より分かりやすく改善してまいります。

ご返品については、商品到着後7日以内・未使用のものに限り承っております。
お手数ですが、下記のお問い合わせフォームよりご連絡いただけますでしょうか。
個別に対応させていただきます。

[お問い合わせフォームURL]

ご意見、誠にありがとうございました。
```

### 工夫
- まず謝罪・共感
- 言い訳せず（色差は事実だが、説明不足を認める）
- 改善姿勢の明示
- 返品ポリシーは正しく案内（嘘の約束をしない）
- 個別対応へオフライン誘導

## 例3：質問レビュー × 専門トーン

### レビュー（★4）
「使い心地は良いです。ところで、これってMacBook Pro 14インチでも使えますか？」

### 返信
```
○○様

ご質問いただきありがとうございます。

ご質問の MacBook Pro 14インチ（M1 Pro/M2 Pro/M3 Pro搭載モデル）への対応についてですが、
本製品はUSB-C/Thunderbolt 3対応のすべての機種でご利用いただけます。

MacBook Pro 14インチは Thunderbolt 4規格のUSB-Cポートを搭載しており、
本製品の伝送速度（最大10Gbps）にも対応しております。

ただし、給電については本製品単体では最大65Wまでとなりますので、
14インチモデルでの長時間高負荷使用時は別途電源アダプタの併用を推奨いたします。

商品ページに対応機種一覧と仕様詳細を掲載しております。
ご不明な点があればお気軽にお問い合わせください。

○○ショップ 技術担当
```

### 工夫
- 質問への具体的・正確な回答
- 機種名・規格を正確に
- 制約条件も明示（責任ある専門家姿勢）
- 商品ページへの誘導
- 「技術担当」の署名で専門性

## 例5：誤情報を含むレビュー × 標準丁寧トーン

### レビュー（★2）
「組立に1時間以上かかった。商品ページに30分って書いてあったのに嘘。」

### 返信（実際は商品ページに「目安60-90分」と記載されていた場合）
```
○○様

ご購入いただきありがとうございます。
組立にお時間がかかり、お疲れになられたこと、心苦しく感じております。

商品ページには「組立の目安：60-90分」と掲載しておりますが、
工具のご準備や慣れによっても所要時間が変わるため、もう少し丁寧にご案内する余地が
あるかもしれません。組立動画や手順説明の充実を検討してまいります。

もし組立過程でご不明点がございましたら、下記までお気軽にお問い合わせください。
[サポート連絡先]

ご意見ありがとうございました。

○○ショップ
```

### 工夫
- 「誤情報です」と直接否定しない
- 正しい情報を **補足** する形で訂正
- 顧客の負担に共感
- 改善姿勢を示す
- 攻撃的にならない

## 例8：法的問題を含むクレーム × 即エスカレーション対応

### レビュー（★1）
「使用後にアレルギー症状が出た。皮膚科に行きました。商品成分の表示が不十分です。」

### 返信（公開）
```
○○様

ご使用にあたりお身体に不調が出られたこと、深くお詫び申し上げます。
ご体調を最優先にお考えいただきたく、まずはご快復をお祈りいたします。

成分表示につきましては、ご指摘の点を真摯に受け止め、表記の見直しを検討してまいります。
本件、誠に恐れ入りますが、個別に状況をお伺いさせていただきたく、
下記の連絡先までお問い合わせいただけますでしょうか。
[CS連絡先]

○○ショップ
お客様サポート担当
```

### 並行して社内対応
- 法務・薬機法担当に **即エスカレーション**
- PL法に基づく対応（製造物責任）
- 成分表示の見直し
- 同種クレームの全件調査
- 公開返信は **慎重に・対応姿勢のみ**、具体的補償は明言しない

## 共通の工夫ポイント

### 1. テンプレ感の排除
- 個別の言及（商品名・感想内容）
- 言い回しのバリエーション

### 2. ブランドトーンの一貫性
- 商品ページ・SNS・他レビュー返信と統一

### 3. 法的・規約上のリスク回避
- 過剰な約束をしない
- 個人情報を出さない
- 競合への言及を避ける
- モール規約遵守

### 4. 改善姿勢
- 言い訳より改善を示す
- 構造的問題（同種クレーム多発）は別スキル `complaint-root-cause-cluster` で対応

### 5. オフライン誘導
- 個別対応が必要な場合は問合せフォーム等へ
- 公開返信で詳細対応しない（個人情報・法的問題）
