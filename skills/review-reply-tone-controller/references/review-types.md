# レビュー4分類と返信原則

## 1. クレーム

### 判定の目安
- 星評価1-2点
- 「最悪」「ひどい」「がっかり」等のネガティブ感情表現
- 具体的な不満（商品・配送・対応）
- 返金・交換の要求
- SNS拡散の示唆

### 返信の主目的
1. **共感**を示す（同じ立場ならどう感じるかを表明）
2. **謝罪**する（明らかに事業者責任なら明確に）
3. **対応案**を提示（交換・返金・修理・調査）
4. **再発防止**の姿勢を示す
5. **個別対応**への誘導（オフラインで詳細対応）

### 返信構成（推奨）

```
（共感・謝罪）
○○様、このたびはご不便をおかけし大変申し訳ございません。

（事実への言及）
ご指摘の□□について、私どもとしても△△と受け止めております。

（対応案）
ご希望に応じて、新品との交換またはご返金にて対応させていただきます。
お手数ですが、下記の問合せフォームよりご連絡をお願いいたします。
[フォームURL]

（再発防止）
今回いただいたご意見をもとに、◇◇を改善してまいります。

（締め）
貴重なご意見、誠にありがとうございました。
```

### NG例
- 「ご使用方法が間違っているのではないでしょうか」（責任転嫁）
- 「商品ページには記載しております」（言い訳）
- 「絶対に二度と起こしません」（過剰約束）
- 「○○様の注文番号#12345の件」（個人情報）

---

## 2. 質問

### 判定の目安
- 星評価は問わず（高評価でも質問はある）
- 疑問形（「〜ですか？」「〜できますか？」）
- 使用法・サイズ・組合せ・互換性の問合せ
- 関連商品への興味

### 返信の主目的
1. **お問合せのお礼**
2. **質問への回答**（正確に・分かりやすく）
3. **補足情報**（関連する役立つ情報）
4. **追加問合せの案内**（不明点があれば再度連絡）

### 返信構成

```
（お礼）
○○様、ご質問いただきありがとうございます。

（回答）
□□についてですが、〜です。
（具体的な数値・条件・例があれば添える）

（補足）
また、関連して△△もご検討いただくと、より使いやすくなります。

（追加問合せ）
他にもご不明な点がございましたら、お気軽にお問い合わせください。
```

### 注意
- 質問が **商品ページの情報不足** を示している場合、社内メモに記録
- 同じ質問が複数あれば **商品ページ・FAQ充実** で根本対応

---

## 3. 感謝

### 判定の目安
- 星評価4-5点
- 「ありがとう」「気に入った」「また買いたい」等
- 商品の良さへの具体的な言及
- リピート購入の示唆

### 返信の主目的
1. **お礼**（具体的な感謝）
2. **商品への思いや開発背景**（ブランドストーリー）
3. **継続的な関係**（次回の購入・新商品案内）

### 返信構成

```
（お礼）
○○様、嬉しいご感想をお寄せいただきありがとうございます。

（商品への思い）
□□は、〜という思いで作りました。○○様のお手元で気に入っていただけて、
私どもも本当に嬉しく思います。

（継続的な関係）
新作も随時ご紹介してまいりますので、ぜひまた弊店をご利用ください。
お気に入りリストへの登録、フォロー等も歓迎しております。
```

### 注意
- テンプレ感が出やすいので **個別の感想に触れる**
- 商品の特定の特徴（色・素材・使い心地）に言及
- 過度なセールス（次回購入の押し付け）は避ける

---

## 4. 中立

### 判定の目安
- 星評価3点前後
- 「普通」「期待通り」「可もなく不可もなく」
- 良い点と悪い点の両方
- 具体的な改善要望が混じる

### 返信の主目的
1. **お礼**
2. **改善ポイントの受容**（指摘を真摯に受け止める）
3. **ブランドの強み**（自社の良さも控えめに）
4. **継続的な関係**

### 返信構成

```
（お礼）
○○様、ご購入ならびにご感想をお寄せいただきありがとうございます。

（改善ポイント受容）
□□についてのご意見、参考にさせていただきます。
今後の改善に活かしてまいります。

（自社の強み）
弊店では△△に力を入れており、今後も◇◇を心がけてまいります。

（継続的な関係）
新商品や改善版もご紹介してまいりますので、引き続きご愛顧いただけますと幸いです。
```

### 注意
- 中立レビューは **改善のヒント** が多く含まれる
- 改善実行できる場合は具体的に言及（「実は来月リニューアル予定です」など）
- 反論せず、受容の姿勢を示す

---

## 5. 複合的なレビュー

実際のレビューは複数の要素を含む：

### 例：「商品は良かったけど、届くのが遅かった。改善してほしい」
- **主軸**：感謝（商品の良さ）
- **副軸**：中立（配送への改善要望）
- 両方に触れる返信が望ましい

### 例：「最悪。サイズが違う。ところで他の色もありますか？」
- **主軸**：クレーム（サイズ違い）
- **副軸**：質問（他の色）
- まずクレーム対応、そのうえで質問にも回答

### 複合レビューの返信構成
1. 主軸への対応（クレームなら謝罪、感謝なら感謝）
2. 副軸への対応（質問なら回答、改善要望なら受容）
3. オフラインでの個別対応へ誘導（必要なら）

---

## 6. 分類が難しいレビュー

### 短文・絵文字のみ
- 「★★★★★」「😊」「good」のみ
- 返信は **シンプルに感謝**

### 文脈不明・意味不明
- 翻訳機経由で日本語が不自然
- 返信前にCS担当者で **意図確認** が望ましい
- 公開前にチェック必須

### 商品と無関係なレビュー
- 配送業者への不満のみ
- 全く別商品の話
- 返信せず、モール側に通報・削除依頼も選択肢

---

## 7. 返信タイミング

### 推奨タイミング
- **24-48時間以内**：顧客の関心が新しいうち
- 遅すぎると「無視されている」感
- 早すぎる（数分以内）と「機械的」感

### モール別の特性
- 楽天：レビューに頻繁に返信する店舗が評価される
- Amazon：返信文化はやや控えめ、簡潔に
- Yahoo!：返信機能の活用率は店舗による
- 自社EC：完全に自由

---

## 8. 返信しない選択

### 返信しない方が良いケース
- 明らかな悪意・工作レビュー
- 法的問題が複雑で、公開返信で対応すべきでない案件
- 顧客が「返信不要」と明示
- 内容が誹謗中傷・差別的・違法

### 通報・削除依頼
- モールの「不適切レビュー」通報機能を活用
- 公序良俗違反は削除対象

---

## 9. レビュー返信の社内ワークフロー

1. **収集**：モール・自社EC のレビューを集約
2. **分類**：4分類のいずれか
3. **返信案作成**：本スキルを活用
4. **社内チェック**：法務・品質・CS で確認
5. **公開**：モール返信機能で投稿
6. **記録**：改善示唆を社内に蓄積

---

## 10. レビューから得られる示唆

レビュー返信は **改善のヒントの宝庫**：

- 商品ページの情報不足
- CS対応の課題
- 物流・配送の問題
- 期待値ズレ・誇大表現
- 競合との比較ポイント

定期的に集計し、別スキル `complaint-root-cause-cluster` で根本対策を検討する。
