# 健康食品・サプリ・美容雑貨の NG / OK 表現

## 健康食品の4分類とそれぞれの言える範囲

| カテゴリ | 国の関与 | 言える範囲 |
|---|---|---|
| **特定保健用食品（トクホ）** | 消費者庁長官の個別許可 | 許可された保健の用途（例「血圧が高めの方に適する」） |
| **機能性表示食品** | 事業者の届出制（販売60日前） | 届出した機能性表示（例「脂肪の吸収を抑える」）。**届出番号併記必須** |
| **栄養機能食品** | 規格基準型（届出不要） | 国が定めた栄養素機能の定型文のみ |
| **いわゆる健康食品（一般食品）** | なし | 効能効果の標榜不可。「健康維持」「栄養補給」等の一般的表現のみ |

## 一般健康食品の NG → OK 置換表

| NG表現 | リスク | OK代替 |
|---|---|---|
| 痩せる／脂肪燃焼／脂肪が落ちる | 医薬品的 | 美しいスタイルを目指す方に／毎日のキレイをサポート |
| 血圧を下げる／血糖値を下げる | 医薬品的 | （トクホ／機能性表示で届出済みなら言える） |
| 疲労回復／免疫力アップ／集中力向上 | 医薬品的 | 元気な毎日をサポート／健やかな毎日に |
| 便秘解消／お通じを良くする | 医薬品的 | 毎日のスッキリをサポート／お腹の調子を整える（届出があれば届出文言で） |
| デトックス／毒素排出 | 医薬品的 | （健食では使用不可） |
| 不眠が治る／よく眠れる | 医薬品的 | 休息サポート／（機能性表示なら届出範囲で） |
| ガン予防／生活習慣病予防／治療 | 医薬品的・トクホでも不可 | （健食では使用不可） |
| 関節痛が改善／膝の痛みが取れる | 医薬品的 | （機能性表示で届出されていれば届出範囲で） |
| 美肌になる／肌が綺麗になる | 医薬品的・化粧品的 | （食品では肌効果はNG） |
| 育毛効果／薄毛改善 | 医薬品的 | （健食では使用不可） |

## 機能性表示食品の必須条件

1. **届出番号**（消費者庁データベース「機能性表示食品の届出情報検索」で確認可能）の併記
2. 届出された機能性表示の**文言を変えずに**使用
3. パッケージ・販売ページ・広告で同一表記
4. 以下の注釈を併記：
   - 「本品は、事業者の責任において特定の保健の目的が期待できる旨を表示するものとして、消費者庁長官に届出されたものです。ただし、特定保健用食品と異なり、消費者庁長官による個別審査を受けたものではありません。」
   - 「本品は、疾病の診断、治療、予防を目的としたものではありません。」
   - 「食生活は、主食、主菜、副菜を基本に、食事のバランスを。」

## 栄養機能食品の定型文（規格基準）

栄養機能食品では国が定めた定型文をそのまま使う（改変NG）：

| 栄養素 | 定型文 |
|---|---|
| ビタミンC | ビタミンCは、皮膚や粘膜の健康維持を助けるとともに、抗酸化作用を持つ栄養素です。 |
| ビタミンE | ビタミンEは、抗酸化作用により、体内の脂質を酸化から守り、細胞の健康維持を助ける栄養素です。 |
| カルシウム | カルシウムは、骨や歯の形成に必要な栄養素です。 |
| 鉄 | 鉄は、赤血球を作るのに必要な栄養素です。 |
| 亜鉛 | 亜鉛は、味覚を正常に保つのに必要、皮膚や粘膜の健康維持を助ける、たんぱく質・核酸の代謝に関与して健康の維持に役立つ栄養素です。 |
| ビタミンB1 | ビタミンB1は、炭水化物からのエネルギー産生と皮膚や粘膜の健康維持を助ける栄養素です。 |
| ビタミンB2 | ビタミンB2は、皮膚や粘膜の健康維持を助ける栄養素です。 |
| ビタミンB6 | ビタミンB6は、たんぱく質からのエネルギーの産生と皮膚や粘膜の健康維持を助ける栄養素です。 |
| ビタミンB12 | ビタミンB12は、赤血球の形成を助ける栄養素です。 |
| ビタミンA | ビタミンAは、夜間の視力の維持を助ける栄養素です。ビタミンAは、皮膚や粘膜の健康維持を助ける栄養素です。 |
| ビタミンD | ビタミンDは、腸管でのカルシウムの吸収を促進し、骨の形成を助ける栄養素です。 |
| 葉酸 | 葉酸は、赤血球の形成を助ける栄養素です。葉酸は、胎児の正常な発育に寄与する栄養素です。 |
| n-3系脂肪酸 | n-3系脂肪酸は、皮膚の健康維持を助ける栄養素です。 |

定型文を改変したり、定型文以外の効能を加えたりするとNG。

## 美容雑貨・健康器具（医療機器未承認のもの）

LED美顔器・美容ローラー・電気バリブラシ・EMSマシン・ヘッドスパ機・ハイフ風機など、医療機器として承認されていない製品は「身体の構造機能への影響」を標榜するとNG（未承認医療機器扱い）。

### NG表現（雑貨で使えない）

| NG表現 | 理由 |
|---|---|
| リフトアップ／たるみ改善／フェイスライン引き締め | 身体の構造機能への影響 |
| シワ改善／シミ消し／毛穴消し | 同上 |
| 血行促進／血流改善／代謝アップ | 同上 |
| 肩こり改善／腰痛改善／むくみ解消 | 同上 |
| 脂肪燃焼／痩身／脂肪分解／キャビテーション | 同上 |
| マイクロカレント／EMS／RF／LEDが○○に効く | 効能効果を言うと未承認医療機器 |
| 医療レベル／医療現場でも使用 | 医療機器と誤認 |

### OK表現（雑貨範囲）

| OK表現 | 範囲 |
|---|---|
| マッサージ／お手入れ／ケア | 物理的行為のみ |
| 使用感がよい／心地よい刺激／ハリのある肌印象 | 使用感・主観評価のみ |
| メイク前の肌を整える／ハリ感を演出 | メーキャップ効果・主観 |
| お手入れ後の肌印象 | 主観評価 |
| 1日3分のセルフケア／自宅で気軽に | 機能性ではなく使用シーン |

「※本機は美容雑貨であり、医療機器ではありません。疾病の治療・予防、身体の構造または機能に影響を及ぼすことを目的とした製品ではありません。」の注釈を商品ページに明記するのが安全。
