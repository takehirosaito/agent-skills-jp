# ステルスマーケティング規制（2023年10月1日施行）

景品表示法5条3号 / 内閣総理大臣告示「一般消費者が事業者の表示であることを判別することが困難である表示」。

## 規制対象と責任

- **規制対象**：商品・サービスを供給する**事業者（広告主）のみ**
- インフルエンサー等の第三者は**規制対象外**だが、広告主が責任を負う
- 違反した場合の措置命令は広告主に対して行われる

## 「事業者の表示」と判断される条件

以下のいずれかに該当すると、第三者の投稿でも「事業者の表示」とみなされる：

- 事業者がインフルエンサーに依頼・指示している
- 対価関係（金銭・商品提供・割引・将来の取引示唆）がある
- 投稿原稿の事前確認・修正依頼が行われている
- 投稿アカウントを事業者が指定している

## 明瞭な広告表示（OK例）

- 投稿冒頭または常時表示で「広告」「PR」「プロモーション」「Sponsored」と明示
- 「A社から商品の提供を受けて投稿しています」等の文章
- 動画は冒頭・終盤ともに表示、または常時表示
- インスタのタイアップ投稿機能（Paid Partnership ラベル）
- YouTubeの「有料プロモーションを含みます」表示

## NG例（不明瞭）

| パターン | NG理由 |
|---|---|
| 投稿末尾に大量ハッシュタグ「#コーデ #今日服 ... #PR」と紛れ込ませる | PRが他のタグに埋没 |
| 「もっと見る」を押さないと表示されない位置 | 一見して判別不能 |
| リプライ（ツリー）にのみ「広告」と記載 | 元投稿で判別不能 |
| 動画の冒頭のみ・極小フォント・背景同化色 | 視認できない |
| アフィリエイトサイトでトップに小さく「アフィリエイト広告を利用しています」だけ | 個別記事の事業者依頼部分には別途明示が必要 |
| 「これすごく良かった！」とだけ書き、依頼関係を非開示 | 依頼関係の隠蔽 |

## EC事業者がインフルエンサー起用時に行うべきこと

1. **契約書／指示書でPR表記を義務化**
   - 「投稿の冒頭または常時表示で『#PR』『広告』『プロモーション』のいずれかを明示すること」を契約に明記
2. **投稿前の事前確認**
   - PR表記の位置・サイズ・コントラストを目視チェック
3. **過去投稿の継続表示確認**
   - 2023年10月施行前の投稿も、継続表示中なら表記必須
4. **ガイドライン明文化**
   - 自社の「インフルエンサー起用ガイドライン」を整備し、起用前に配布

## 違反時

- 措置命令（差止・公示・再発防止）
- ステマ規制違反**単体では課徴金対象外**（ただし優良誤認・有利誤認に該当すれば課徴金対象）
- 公正取引委員会のステマ規制違反事業者として公表（風評リスク）

## 自社EC・自社サイトの場合

- 自社サイト上の商品紹介は明らかに事業者の表示なので、ステマ規制の対象外（広告と認識される前提）
- ただし、自社サイトに「お客様の声」「レビュー」として掲載する場合、事業者が依頼・対価関係がある体験談なら**事業者の表示**になる
- 「事業者が依頼して作成させた体験談を、第三者の口コミのように見せる」は典型的なNGパターン

## アフィリエイト広告との関係

- アフィリエイトサイト自体は媒体の判断でPR表記する
- ただし広告主（EC事業者）がアフィリエイターに具体的に投稿原稿・表現を指示している場合、「事業者の表示」となり、広告主に責任が及ぶ
- アフィリエイターに渡す素材・原稿・テンプレに「#PR を含めること」「具体的な訴求は依頼に基づくこと」等を明記しておく
