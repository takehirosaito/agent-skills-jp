# 景品表示法・健康増進法 チェックポイント詳細

## 1. 優良誤認（景表法5条1号）

「実際よりも著しく優良」「競争事業者より著しく優良」と誤認させる表示。

| NG例 | 該当事由 |
|---|---|
| 走行距離10万kmの中古車を3万kmと表示 | 実際と異なる |
| 通常豚肉を「黒毛和牛」と表示 | 実際と異なる |
| 医師の推奨を装う／無関係な著名人の推薦 | 根拠なき優良性 |
| 「業界唯一」「世界初」表記で実際は既存技術 | 客観的事実と異なる |
| 効能効果を強調するが実証データ無し | 根拠不明確 |

## 2. 有利誤認（景表法5条2号）

価格・取引条件が「実際よりも著しく有利」と誤認させる表示。

| NG例 | 該当事由 |
|---|---|
| 常時同価格を「今だけ半額」 | 通常価格の不当表示（二重価格） |
| 単品同価格を「お徳用」と表示 | 量・条件が同じなのに有利を装う |
| 「送料無料」と表示し実は商品代に上乗せ | 実質の負担を隠蔽 |
| 「先着100名」を常時表示 | 限定性の偽装 |
| 「初回0円」を強調し定期購入を小さく表示 | ダークパターン |

## 3. 二重価格表示の 8週間ルール

公正取引委員会「不当な価格表示についての景品表示法上の考え方」（価格表示ガイドライン）。

| 比較対照価格 | 適切な使用条件 |
|---|---|
| **過去の販売価格** | セール開始直前**8週間**のうち、**過半（4週間以上）**で実際に販売されていた価格であること。かつ販売終了から**2週間以内**であること |
| **メーカー希望小売価格** | 製造業者がカタログ・新聞広告・商品本体印字等で**事前公表**している価格に限る。撤廃済み・存在しない価格を勝手に設定するのはNG |
| **競争事業者の販売価格** | 同一地域の競合の実販売価格を**実地調査**で確認した上で使用。古いデータ・推定値はNG |
| **当社通常価格／参考価格** | 出所が明確でない場合は使用回避。根拠資料の保管必須 |

### EC実務での確認手順

1. 二重価格を出したい商品の販売価格履歴を確認
2. 直近8週間の販売実績を抽出（モール側の販売履歴・社内ERP）
3. その8週間のうち4週間以上で「通常価格」が実販売価格として表示・成約されていたかを検証
4. NGならば「セール価格」のみを表示し、二重価格は使わない

## 4. 打消し表示 7原則

消費者庁「打消し表示に関する実態調査報告書」（2017-2018）。「※個人の感想です」「※効果には個人差があります」等の打消し表示は、以下を**全て**満たさないと機能しない。

1. **強調表示と打消し表示は同一視野に配置**（離さない、ページ遷移させない）
2. **文字サイズは強調表示と比較して十分大きく**（小さい注釈で否定するのはNG）
3. **背景色と文字色のコントラストを確保**（薄色背景に薄色文字NG）
4. **動画では十分な表示時間を確保**（一瞬表示NG、視聴者が読める秒数）
5. **表示位置は強調表示の近く**（ページ最下部・別タブ・モーダルNG）
6. **打消しの内容自体が、強調表示の例外であることを明確に**
7. **そもそも強調表示が実際と乖離していれば、打消し表示があっても不当表示**

## 5. No.1・最安・業界初表記の根拠要件

消費者庁「No.1表示に関する実態調査報告書」（2024年9月）。

### 主観評価No.1（満足度No.1・人気No.1・売れ筋No.1等）の4要件

1. **比較する商品等が適切に選定**されている（恣意的選定NG）
2. **調査対象者が適切に選定**されている（自社顧客のみ・関係者のみNG）
3. **調査が公平な方法**で実施（誘導質問NG）
4. **表示内容と調査結果が適切に対応**している

### 必須明示事項

- 調査主体（リサーチ会社）
- 調査期間
- 調査対象（範囲・人数）
- 調査方法（インターネット調査／街頭調査／POS集計）
- 出典

これらが明示されていないNo.1表示は違反リスク。

### 「業界初」「日本初」

- 範囲（業界の定義・地域・期間）
- 出典
- 反証可能性（他に該当する事例がないかの調査）

不明確だと違反リスク。

## 6. 合理的根拠資料・不実証広告規制（景表法7条2項）

- 消費者庁長官は優良誤認の疑いがある場合、事業者に**15日以内**に合理的根拠資料の提出を求められる
- 要件：(1) 客観的に実証された内容、(2) 表示と実証内容の適切な対応
- 提出できない場合、優良誤認表示と**みなされる**

## 7. 課徴金（景表法8条／2024年改正後）

- 算定：**不当表示期間中の対象商品売上額 × 3%**（最大3年遡及）
- 不適用閾値：売上5,000万円未満（課徴金150万円未満）
- **2024年改正で繰返し違反（3年以内）は1.5倍＝4.5%**
- 優良誤認・有利誤認に**直罰規定**（100万円以下罰金）が新設
- 自主返金による減額制度あり

## 8. 健康増進法 誇大表示禁止（31条）

EC事業者が食品を販売する際、健康保持増進の効果について事実と異なる、または著しく誇大な表示をすると違反。

| NG例 | 該当事由 |
|---|---|
| 「これを飲めば○kg痩せる」 | 効果の誇大表示 |
| 「○○病が治った」（体験談含む） | 治療効果の標榜 |
| 「医師も愛用」（根拠なし） | 推薦の偽装 |

## 9. 演出表現の規制

### ビフォーアフター
- 効能効果や安全性の保証となる画像はNG
- 化粧品適正広告ガイドライン2020以降、**メーキャップ効果・物理的効果・使用感**の範囲のみ可（化粧くずれ防止スプレー前後、口紅塗布前後等）
- 「化粧水使用前後の比較」で肌のシミが消えた絵はNG

### 体験談
- **効能効果・安全性に関する体験談はNG**（「個人の感想です」の打消しがあっても不可）
- OKは使用感・香り・使用方法の感想のみ

### モニター調査結果
- 「○%が満足」等のグラフ表示は、効能効果の保証と取られると違反
- 調査方法・対象・期間の明示必須

### ランキング
- 商品自体の効能効果ランキングは56項目の範囲を超えるとNG
- 「売上No.1」「満足度No.1」は景表法のNo.1表示根拠要件を満たす必要

### 医師・専門家の推薦
- 化粧品適正広告ガイドラインで**医薬関係者の推薦は原則NG**
- 「皮膚科医監修」「研究員推奨」も標榜内容次第で違反リスク
- 健康食品でも医療関係者の名前で効能をうたうのは違反リスク
