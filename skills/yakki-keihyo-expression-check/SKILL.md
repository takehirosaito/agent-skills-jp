# 薬機法・景表法 表現一次チェック

## 概要

化粧品・健康食品・美容雑貨・健康器具の商品ページ、広告コピー、LP、SNS投稿、メルマガ等の文章を、薬機法（医薬品医療機器等法）／景品表示法／健康増進法／ステマ規制（2023.10.1〜）の4つの観点で一次チェックし、リスクの高い表現の検出・代替表現の提案・媒体別の出し分け指示までを行う。

本スキルは法律上の最終判断を代替するものではなく、社内一次スクリーニング用。最終判断は薬事コンサル・弁護士・各モールの審査窓口に確認することを前提に運用する。

## ★最重要原則

**カテゴリ前提が判定を決める。** 同じ「肌の調子を整える」表現でも、化粧品なら効能56項目内、健食ならアウト、医薬部外品なら承認範囲次第。**最初にカテゴリを確定させる**ことが最大の精度向上要因。カテゴリが不明な場合は「仮カテゴリ」を明示して暫定判定を出し、冒頭で「最終判断にはカテゴリ確認が必要」を表示する（止まらず使う設計）。

要点（本ファイルに留めるもの）：

| 分類 | 言える範囲 |
|---|---|
| 化粧品 | 効能効果56項目の範囲内のみ。「シワが消える」「アンチエイジング」は不可 |
| 医薬部外品 | 承認された効能（例：薬用化粧品の「メラニンの生成を抑え、シミ・そばかすを防ぐ」） |
| 機能性表示食品 | 届出した機能性表示のみ。届出番号併記必須 |
| トクホ | 個別許可の保健用途のみ |
| 栄養機能食品 | 国が定めた規格基準型の定型文のみ |
| 一般食品（いわゆる健康食品） | 効能効果の標榜不可。「健康維持」「栄養補給」等の一般表現のみ |
| 雑貨（健康器具・美容器具） | 身体への効能効果を標榜すると医療機器扱いに。「リラックス」「使い心地」等の物性表現のみ |

景表法の必須注意（詳細は `references/keihyo-law-checkpoints.md`）：

- **No.1表記4要件**：比較対象が適切／調査対象者が適切／公平な方法／表示と結果が対応。明示要素は調査主体／期間／対象／方法／出典の5点
- **二重価格8週間ルール**：セール直前8週間のうち過半（4週間以上）で実販売されていた価格であること、かつ販売終了から2週間以内
- **打消し表示7原則**：強調表示と同一視野／文字サイズが十分／背景色のコントラスト等
- **課徴金**：売上の3%、最大3年遡及、5,000万円未満不適用、繰返し違反4.5%（2024改正）

ステマ規制（2023.10.1〜）：規制対象は広告主のみ、投稿冒頭または常時表示で「広告」「PR」「プロモーション」「Sponsored」を明示。極小文字・タグ末尾埋め込みは違反。

## 処理フロー

### Step 1：カテゴリの確定

ユーザー入力から商品カテゴリを確定する。曖昧な場合は明示的に確認するか、もっとも可能性の高い仮カテゴリを置く。

- 「化粧品です」 → 化粧品（医薬部外品でないことを確認）
- 「サプリ／健康食品」 → 4分類のどれか（届出番号の有無を確認）
- 「美容器具／健康器具／雑貨」 → 医療機器の認可がないかを確認

### Step 2：リスク表現の抽出

文章から以下のNGトリガー語を機械的に抽出：

- 効能効果断定：治る／改善する／効く／消える／予防する／治療
- 医薬品的部位＋作用：「○○に効く」「○○を治す」
- 最大級・絶対：最高／最強／世界一／業界No.1／完全／絶対／必ず／永久
- 体験談・ビフォーアフター：「3kg痩せました」「シワが消えました」
- 医師・専門家推薦：「医師推奨」「皮膚科医監修」（無関係な推薦は優良誤認）
- 価格表示：「通常価格」「定価」「メーカー希望小売」「他社比較」
- ステマ要素：PR表記なしのインフルエンサー投稿、口コミ装い

### Step 3：危険度の3段階分類

| 危険度 | 定義 | 対応 |
|---|---|---|
| 高 | 行政指導・課徴金・モール削除のリスクが高い。客観的に違反 | 即時修正必須 |
| 中 | 根拠資料があれば許容されるが、現状の表記では危険 | 根拠確認 or 表現修正 |
| 低 | 解釈次第。グレー。安全寄りに直す候補 | 任意修正 |

### Step 4：代替表現の生成

`references/health-food-ng-ok.md` および `references/cosmetics-56-effects.md` の置換表をベースに、文脈を保ったまま安全寄りの言い回しを2〜3案生成する。

### Step 5：媒体別の出し分け指示

- 商品ページ（モール内）：モールの審査ガイドラインの方が厳しい場合あり
- 広告（リスティング・SNS広告）：媒体側の審査基準（特に薬機系は厳格）
- 画像内テキスト：画像はテキスト化されないが、薬機・景表は画像内文言も対象
- メルマガ：開封後の本文も媒体審査対象外だが法規制は同じ

### Step 6：専門家確認が必要な箇所の明示

「届出番号未確認」「機能性表示の届出文言の原文確認」「医薬部外品の承認効能の確認」など、社内で判定不能な箇所は確認先と確認方法を明示する。

## 品質ゲート

- [ ] 法的最終判断はせず「一次チェック／専門家確認推奨」を明記している
- [ ] カテゴリを確定 or 仮置き明示している
- [ ] 危険度が高／中／低の3段階で分類されている
- [ ] 代替表現が文脈を保ち、機械的な置換になっていない
- [ ] No.1・最大級・効能断定の根拠資料の有無を必ず聞いている
- [ ] 媒体別の出し分けが具体的に書かれている
- [ ] 「断定」「保証」「治る」「絶対」「完全」「永久」が代替案に紛れ込んでいない

## エッジケース

- **医薬部外品か化粧品か曖昧** → パッケージの薬事区分表記を確認。薬用化粧品＝医薬部外品
- **海外OEM／並行輸入** → 化粧品製造販売届の有無を確認
- **届出番号が見当たらない機能性表示食品** → 「届出済み」と称している場合は番号確認まで凍結
- **「医師監修」表記** → 関与の事実が確認できる文書（監修契約・監修者の関与記録）が必須
- **クチコミ・レビューを商品ページに転載** → 個別レビューに「個人の感想」を付しても、抽出して目立つ位置に置くと事業者の表示扱いとなり景表法対象

詳細は `references/examples.md` に化粧品／健食／医薬部外品／雑貨のジャンル別実例を収録。

## 注意事項

- 本スキルは社内の一次スクリーニング用であり、法的・行政的判断を代替しない
- 法令・ガイドライン・モール審査基準は改定される。最新の公式情報を必ず確認
- 顧客の個人情報・契約情報・社外秘の根拠資料は出力に含めない
- 化粧品56効能・機能性表示届出文言は「変えずに」使う原則を破らない
