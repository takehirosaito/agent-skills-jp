# 送料原価の構造

実際の送料原価を把握しないと閾値計算ができない。各配送手段の典型的なコスト構造を整理する。

## 主要配送手段

### 宅配便（ヤマト運輸・佐川急便・日本郵便）

**サイズ区分（ヤマト宅急便の例）**：
- 60サイズ（縦＋横＋高さ60cm以内、2kgまで）
- 80サイズ（80cm以内、5kgまで）
- 100サイズ（100cm以内、10kgまで）
- 120サイズ（120cm以内、15kgまで）
- 140サイズ
- 160サイズ
- 180サイズ
- 200サイズ

**原価目安（契約料金次第・関東〜関東間）**：
- 60サイズ：500〜700円
- 80サイズ：600〜850円
- 100サイズ：700〜1,000円
- 120サイズ：800〜1,200円

**地域加算**：
- 北海道・沖縄・離島：+500〜2,000円
- 同一県内：割引適用ある場合あり

**法人契約割引**：
- 月間出荷量1,000個以上で20〜40%引きの大口契約が可能
- 上記原価目安はあくまで参考。実契約料金を必ず確認

### メール便（クロネコDM便・日本郵便ゆうパケット・ネコポス）

**主要サイズ・料金**：
- ネコポス：A4サイズ・厚さ3cm以内・1kgまで：290〜350円（契約による）
- クロネコDM便：A4・厚さ2cm以内：200〜300円
- ゆうパケット：A4・厚さ3cm以内：270〜400円
- ゆうパケットポスト：250〜310円

**メリット**：
- 安価
- ポスト投函で配送効率高い
- 小物・薄物商品向け

**デメリット**：
- 厚さ制限
- 追跡機能が弱い
- 代引・日時指定不可

### 配送業者の選定基準

| 商品特性 | 推奨配送 |
|---|---|
| 厚さ3cm以内・小物 | メール便系（ネコポス・ゆうパケット） |
| 一般的な日用品 | 宅配便60〜80サイズ |
| 衣類・布団等の軽い大物 | 宅配便100〜120サイズ |
| 家具・家電 | 軽貨物・チャーター便 |
| 食品（冷蔵・冷凍） | クール便 |
| 時計・宝飾品 | セキュリティ便 |

### クール便（冷蔵・冷凍）

通常宅配便＋200〜300円が一般的。
- 冷蔵：通常宅配便＋220円〜
- 冷凍：通常宅配便＋220〜300円
- 食品EC・スイーツECは送料原価が大きい

### 軽貨物・大型配送

家具・家電・大型雑貨：
- 軽貨物便：2,000〜5,000円
- チャーター便（一般家庭への家具搬入）：3,000〜10,000円
- 設置・組立込み：10,000〜30,000円

### Amazon FBA

FBA手数料は商品サイズ・重量で変動：
- 小型/標準：300〜600円程度
- 大型：800〜2,500円程度
- 特大型：1,500〜5,000円程度

詳細はAmazon公式FBA料金表で確認。FBAは「配送費＋保管費＋手数料」が一体化しており、純粋な送料計算は難しい。

## 送料原価の算出方法

### 実績ベース
```
平均送料原価 = (年間配送料総額) ÷ (年間出荷件数)
```

これが最も正確。会計データ・配送業者の月次請求から算出。

### サイズ別平均
商品ジャンルごとにサイズ分布を取り、加重平均：
```
平均送料原価 = Σ (サイズ別件数 × サイズ別単価) ÷ 総件数
```

### 地域別平均
関東中心の場合と、全国均等の場合で大きく差が出る。県別出荷数で加重平均。

## 送料設定でよくあるトラブル

### 1. 商品サイズ申告と実サイズの乖離
- 商品マスタで「60サイズ」と申告していたが、緩衝材込みで実は80サイズ
- 配送会社から差額請求される
- 解決：実梱包サイズで申告、または定期的に実測

### 2. 一律送料設定の落とし穴
- 「全国一律700円」と設定し、北海道・沖縄で大幅赤字
- 解決：地域別送料設定、または「沖縄・離島は別途見積」表記

### 3. クール便の見落とし
- 食品商品で「冷蔵便」を顧客が指定→通常便より高い
- 解決：クール便対応商品は別送料設定、または商品価格に上乗せ

### 4. 同梱割引の計算
- 複数商品同時購入でも個別送料設定だと多重請求になる
- 解決：「同梱可能」「同梱不可」フラグを商品マスタに、注文時に同梱判定ロジック

### 5. 配送業者の運賃改定
- 2024年に複数の配送会社で大幅値上げ
- 燃油サーチャージの導入
- 解決：年1回は送料設定を見直し

## 送料を下げる手段

### 配送業者の見直し
- 月間出荷量を増やして大口契約交渉
- 複数業者を比較
- 主要業者：ヤマト、佐川、日本郵便、近場の配送業者

### 梱包の最適化
- 緩衝材を減らしてサイズダウン
- 折りたたみ可能な梱包
- 軽量パッケージ
- 80サイズ→60サイズへのサイズダウンで1個あたり100〜200円削減

### 倉庫の最適化
- 主要顧客の集中エリアに倉庫を配置
- 複数倉庫運用（東日本・西日本）
- 3PL（外部倉庫）の利用

### 配送効率化
- 出荷時間帯の集約
- 同一住所への複数注文の同梱
- 注文締切時間の見直し

## モール別の送料制度

### 楽天市場
- 「3,980円以上送料無料」ラインを楽天が推奨（事業者は加入義務なし）
- 加入店舗には検索順位優遇あり
- 北海道・沖縄・離島は別途設定可

### Amazon
- プライム会員は基本全件送料無料
- 非プライムは2,000円以上送料無料（仕様変動）
- FBA利用商品は自動的にプライム対応

### Yahoo!ショッピング
- ストア独自の送料設定
- 「優良配送」「あすつく」等のオプション

### Shopify
- 完全自由設定
- 国別・地域別・重量別・金額別設定が柔軟

## 送料込みプランの注意点

送料込みで商品価格に上乗せする場合：
- モール手数料が上乗せ部分にもかかる
- 広告費率の計算ベースが上がる
- 比較サイト・ショッピング検索で「高い」と見られる
- 「送料無料」は強い訴求だが、商品検索結果のソート（価格昇順）で不利になる場合あり

### 計算上の正味送料負担
```
送料込みプランの実質負担 = 送料原価 × (1 + モール手数料率 + 広告費率)
```

例：送料500円、モール手数料10%、広告費5% → 実質負担 = 500 × 1.15 = **575円**

→ 「送料分だけ上乗せ」では足りないことに注意。
