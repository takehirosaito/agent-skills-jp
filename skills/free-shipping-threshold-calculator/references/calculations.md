# 送料無料閾値の計算式と検算例

## 基本式

### 1. 損益分岐閾値AOV
```
損益分岐閾値AOV = 送料原価 ÷ 商品粗利率
```

送料無料化したとき、AOVがこの値を超えていれば赤字にならない最小ライン。
ただしモール手数料・広告費を考慮した「実質粗利率」で計算するのが正確。

### 2. 実質粗利率（実務的）
```
実質粗利率 = 1 − 原価率 − モール手数料率 − 広告費率
```

例：原価率50%、モール手数料率10%、広告費率5%
実質粗利率 = 1 − 0.50 − 0.10 − 0.05 = **0.35（35%）**

### 3. 送料込み実質粗利
```
送料込み実質粗利 = AOV × 実質粗利率 − 送料原価
```

### 4. 損益分岐閾値（実質粗利率版）
```
損益分岐閾値AOV = 送料原価 ÷ 実質粗利率
```

### 5. 送料込みプランの上乗せ額
全件送料無料にする際、商品価格に送料を上乗せして実質粗利を維持する場合：
```
上乗せ後の販売価格 = 元の販売価格 + 送料原価 ÷ (1 − モール手数料率 − 広告費率)
```

モール手数料も上乗せ部分にかかるため、単純に送料分を足すだけでは足りない。

## 検算例A：化粧品ブランドの閾値判定

**前提**：
- AOV：4,200円
- 商品粗利率（原価控除のみ）：50%（化粧品は高粗利）
- 送料原価：600円
- モール手数料率：10%
- 広告費率：5%
- 現状閾値：5,500円以上 送料無料

**実質粗利率**：
- 1 − 0.50 − 0.10 − 0.05 = **0.35**

**損益分岐閾値**：
- 600 ÷ 0.35 = **1,714円**

→ 現在AOV 4,200円は損益分岐の約2.4倍。閾値5,500円は十分なマージンを取れている。

**現状運用での送料負担シミュレーション**（年間注文10,000件と仮定）：
- 5,500円以上の注文比率：仮に30%（3,000件）
- 年間送料負担：600 × 3,000 = **180万円**
- 年間売上：4,200 × 10,000 = 4,200万円
- 年間粗利（送料控除前）：4,200万 × 0.35 = 1,470万円
- 年間粗利（送料控除後）：1,470万 − 180万 = **1,290万円**

**シナリオB：閾値を3,980円に下げる**：
- 3,980円以上注文比率：55%（5,500件）と想定
- AOV駆け込み効果：4,200円 → 4,400円（仮）
- 年間送料負担：600 × 5,500 = 330万円
- 年間売上：4,400 × 10,000 = 4,400万円
- 年間粗利：4,400万 × 0.35 = 1,540万円
- 送料控除後：1,540万 − 330万 = **1,210万円**

→ シナリオAの方が**80万円多く粗利が出る**。

ただしCVRが10%上がる前提なら：
- 年間注文：10,000 → 11,000件
- 年間送料負担：600 × 6,050 = 363万円
- 年間売上：4,400 × 11,000 = 4,840万円
- 年間粗利：4,840万 × 0.35 = 1,694万円
- 送料控除後：1,694万 − 363万 = **1,331万円**

→ CVR10%UPすればシナリオBの方が41万円多い。CVR上昇予測が鍵。

## 検算例B：低単価雑貨

**前提**：
- AOV：1,800円
- 商品粗利率：35%
- 送料原価：500円
- モール手数料率：10%
- 広告費率：8%

**実質粗利率**：1 − 0.65 − 0.10 − 0.08 = **0.17（17%）**

→ あれ、原価率35%ではなく粗利率35%なので、原価率は65%。

訂正：粗利率35%は商品単体粗利。これにモール手数料・広告費を引くと実質粗利率＝17%。

**損益分岐閾値**：500 ÷ 0.17 = **2,941円**

→ AOV 1,800円は損益分岐を大きく下回るため、送料無料化すると赤字。

**取れる施策**：
- 閾値3,500円以上を設定（駆け込み購入で2点購入を促す）
- 商品単価を上げる（バンドル化・容量UP）
- 送料原価を下げる（メール便対応／配送会社の見直し）
- 送料込みプランで商品価格に上乗せ（ただしAOVがその分上がるだけ）

**シナリオ：3,500円以上送料無料、2点購入促進**：
- AOV 1,800 → 3,000円（2点購入率UP）と想定
- 3,500円以上注文比率：40%
- 年間注文5,000件想定
- 年間送料負担：500 × 2,000 = 100万円
- 年間売上：3,000 × 5,000 = 1,500万円
- 年間粗利：1,500万 × 0.17 = 255万円
- 送料控除後：255万 − 100万 = **155万円**

vs 現状（送料別、AOV 1,800円、CVR低い・離脱多い）：
- 年間売上：1,800 × 4,000（CVR低下想定）= 720万円
- 年間粗利：720万 × 0.17 = 122.4万円
- 送料負担：0
- 結果：**122.4万円**

→ 閾値3,500円送料無料の方が30万円多い。

## 検算例C：高単価家電

**前提**：
- AOV：18,000円
- 商品粗利率：25%（家電は低粗利）
- 送料原価：1,500円（大型サイズ）
- モール手数料率：8%
- 広告費率：3%

**実質粗利率**：1 − 0.75 − 0.08 − 0.03 = **0.14**

**損益分岐閾値**：1,500 ÷ 0.14 = **10,714円**

→ AOV 18,000円は損益分岐の1.7倍。**全件送料無料化が機能する**。

**全件送料無料シナリオ**（年間2,000件と仮定）：
- 年間送料負担：1,500 × 2,000 = 300万円
- 年間売上：18,000 × 2,000 = 3,600万円
- 年間粗利：3,600万 × 0.14 = 504万円
- 送料控除後：504万 − 300万 = **204万円**

vs 送料別運用：
- AOVが17,000円に下がる（送料考慮で購入抑制）
- 年間注文1,800件
- 年間売上：17,000 × 1,800 = 3,060万円
- 年間粗利：3,060万 × 0.14 = 428万円
- 送料控除：0
- 結果：**428万円**

→ あれ、送料別の方が224万円多い。高単価でも粗利率が低いと送料負担が大きく効く。

CVR・AOV影響の見積もりを実データで検証する必要がある。

## 検算例D：定期購入の送料無料化

**前提**：
- 月額バンドル価格：5,800円
- 構成品原価：1,800円（原価率31%）
- 送料原価：600円
- モール手数料率：10%

**1回粗利**（現状送料込み運用）：
- 5,800 − 1,800 − 600 − 580 = **2,820円/回**

**送料を別途請求する場合**：
- 商品代5,800円＋送料600円（顧客負担）
- 1回粗利：5,800 − 1,800 − 580 = **3,420円**

→ 送料込みより1回あたり600円粗利改善。ただし「送料無料」訴求が無くなるとCVRが下がる可能性。

**判断軸**：
- 継続率が高い商材：送料込みでLTVを最大化
- 1ヶ月解約が多い商材：送料別で初回粗利を確保

## 検算例E：送料込みプランの価格上乗せ

**前提**：
- 元の販売価格：3,000円
- 送料原価：500円
- モール手数料率：10%
- 広告費率：5%

**送料込みプランで実質粗利を維持するための上乗せ額**：
```
上乗せ額 = 500 ÷ (1 − 0.10 − 0.05) = 500 ÷ 0.85 ≈ 588円
```

→ 販売価格を3,588円に設定すれば、送料原価＋上乗せ部分のモール手数料・広告費を加味しても粗利は維持される。

**検算**：
- 販売価格：3,588円
- 送料原価（事業者負担）：500円
- モール手数料：358.8円
- 広告費：179.4円
- 仕入原価（仮）：1,200円（原価率33%）
- 粗利：3,588 − 1,200 − 500 − 358.8 − 179.4 = **1,349.8円**

vs 元の販売価格3,000円＋送料別：
- 売上3,000 − 1,200 − 300 − 150 = **1,350円**

→ ほぼ同等。送料込みプランの上乗せ式が正しく機能。

## CVR上昇効果の見積もり

業界平均的に送料無料化はCVRを5〜15%押し上げると言われるが、ジャンル・客層・商品単価で大きく変動。**自社データでA/Bテストする**ことが必須。

### 簡易ROI計算
```
送料無料化のROI = (CVR上昇後の年間粗利増分) ÷ (年間追加送料負担)
```

ROIが100%超なら粗利的にプラス、未満なら粗利的にマイナス。

### 損益分岐CVR上昇率
```
損益分岐CVR上昇率 = 追加送料負担 ÷ 既存粗利
```

例：年間追加送料負担180万円、既存年間粗利1,290万円
→ 損益分岐CVR上昇率 = 180 ÷ 1,290 = **約14%**

CVRが14%以上上がれば送料無料化はプラス。それ未満ならマイナス。
