# 納期短縮・リードタイム改善 設計

## 概要

EC・通販の納期（受注から出荷・到着まで）短縮とリードタイム改善を設計するスキル。受注処理・在庫引当・ピッキング/梱包・出荷締め・配送の各工程を分解し、ボトルネックを特定して当日出荷率を上げる打ち手と、調達リードタイム（仕入れ）短縮までを整理する。「発送が遅い」を感覚でなく工程別の時間で捉え、効果の高い順に手を打つ。

## 最重要原則

**「工程を分解して時間を測る／ボトルネックから直す／出荷締め時刻と配送便の締めを揃える／在庫があるものは当日出荷を最大化／打ち手は効果×難易度で優先順位」**。全工程を一律に速くしようとすると疲弊する。律速工程を1つ直すと全体が動く。出荷締めと配送便締めのズレは「1日遅れ」を生む典型。

## 知識ベース

リードタイムの構成：

| 工程 | 短縮の着眼 |
|---|---|
| 受注処理 | 受注取込・与信・確認の自動化、手作業の削減 |
| 在庫引当 | 欠品・引当待ちの削減、在庫配置（近接） |
| ピッキング/梱包 | 動線・ロケーション最適化、資材標準化、トータルピッキング |
| 出荷締め | 締め時刻と配送便集荷時刻の整合、当日出荷枠 |
| 配送 | 配送方法・拠点近接（`shipping-carrier-rate-optimizer`/`multi-warehouse-allocation-planner`連携） |
| 調達 | 仕入先リードタイム、発注頻度、安全在庫 |

注文〜到着のリードタイム＝社内処理時間＋配送日数。社内処理（出荷リードタイム）はコントロールしやすく、まずここを詰める。

## 処理フロー

### Step 1：現状の工程時間を把握
- 各工程の所要時間、当日出荷率、出荷締め時刻、配送便集荷、欠品率、調達リードタイム
不明時は仮定を置いて明示し、計測を促す。

### Step 2：ボトルネック特定
- 工程別の時間からボトルネック（律速）を特定。

### Step 3：打ち手の洗い出し
- 受注自動化・ロケーション最適化・出荷締め見直し・在庫近接・資材標準化などを列挙。

### Step 4：優先順位づけ
- 効果（短縮日数/件数）×難易度（コスト/工数）でマトリクス化し、着手順を提示。

### Step 5：当日出荷率・調達の改善計画
- 当日出荷枠の拡大、配送便締めとの整合、仕入先リードタイム短縮の交渉ポイント。

## 出力フォーマット

```
# 納期短縮・リードタイム改善：[事業者]

## 0. 前提（工程時間/当日出荷率・仮定）
## 1. 工程別リードタイム分解
   | 工程 | 所要時間 | 課題 |
## 2. ボトルネック特定
## 3. 打ち手一覧
## 4. 優先順位マトリクス（効果×難易度）
## 5. 当日出荷率・調達改善計画
```

## 品質ゲート
- 工程を分解して時間で捉えているか
- ボトルネックから手を打つ順になっているか
- 出荷締めと配送便締めの整合を確認したか
- 打ち手を効果×難易度で優先順位づけしたか

## 注意事項
- 改善は現場の計測データが前提。仮定は明示し計測を促す。
- 過度な当日出荷要求は現場負荷・品質低下を招く。無理のない設計にする。
- 繁忙期（セール）は別途キャパ計画が必要。
