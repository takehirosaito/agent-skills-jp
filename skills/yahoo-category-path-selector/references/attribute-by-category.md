# カテゴリ別の属性必須項目（傾向）

**注意**：以下は**過去の傾向に基づく目安**。最新は ストアクリエイターProの「プロダクトカテゴリ別 属性項目」で必ず確認。

---

## 1. ファッション系 共通属性

| 属性 | 典型値 |
|---|---|
| 対象 | メンズ／レディース／ユニセックス／キッズ |
| サイズ | XS/S/M/L/XL/XXL、cm表記、靴サイズ |
| 色（カラー） | 主要1色＋バリエーション |
| 素材 | 綿100%／本革／ポリエステル |
| 季節 | 春夏／秋冬／オールシーズン |
| シーン | カジュアル／フォーマル／スポーツ |

### 靴・バッグ・小物 追加属性
- 形状（ショルダー／トート／二つ折り）
- 留め具（ファスナー／マグネット／ボタン）
- 機能（撥水／防水／盗難防止）

### 時計
- ムーブメント（クォーツ／自動巻き／ソーラー）
- 防水等級（30m／100m／200m）
- バンド素材（革／メタル／ナイロン）

## 10. 属性未入力のリスク

選んだプロダクトカテゴリで**必須属性が空欄**だと：

- 検索フィルタにヒットしない（例：「メンズ」フィルタで除外）
- カテゴリランキングの順位が下がる
- 関連商品表示の精度が落ちる
- スマホアプリの絞り込みからも除外

→ **空欄は機会損失**。すべての必須属性を入力する。
