# Yahoo!ショッピング カテゴリ構造の基礎

---

## 1. ストアカテゴリ vs プロダクトカテゴリ

### ストアカテゴリ（CSV列：`path`）
- **ストアが任意に設計**する自店内のナビゲーション
- ストアトップの「カテゴリツリー」として表示
- 商品データCSVの `path` 列で指定
- 階層は自由：「メンズ > 財布 > 二つ折り」「春の新作」「父の日ギフト」など
- 1商品1カテゴリ（path 1つ）

### プロダクトカテゴリ（CSV列：`product-category`）
- **Yahoo!が共通定義**する商品分類
- 数字ID（例：2495 等）で指定
- Yahoo!の検索フィルタ・カテゴリランキング・売れ筋ランキング・関連商品の根拠
- 階層構造（大分類→中分類→小分類）が公式に存在
- 1商品1カテゴリID

### 比較

| 項目 | ストアカテゴリ | プロダクトカテゴリ |
|---|---|---|
| 設定者 | ストア | Yahoo! |
| 表示 | ストアトップ | Yahoo!全体検索／カテゴリトップ |
| 必須 | 必須（path） | 推奨（強く） |
| 検索影響 | ストア内検索 | Yahoo!全体検索 |
| 変更難易度 | ストアで自由 | カテゴリ構造はYahoo!次第 |

## 2. プロダクトカテゴリの調べ方

### 方法1：ストアクリエイターProの「プロダクトカテゴリ検索」
- 管理画面で商品名・キーワード入力
- 候補カテゴリが提示される
- IDをコピーしてCSVに転記

### 方法2：競合商品から逆算
- Yahoo!検索で類似商品を検索
- 上位商品の商品ページに表示される「カテゴリリンク」を辿る
- パンくず（ファッション > メンズ > ...）から階層を確認
- ストア・商品IDから推定（管理画面で確認）

### 方法3：カテゴリトップから探す
- Yahoo!ショッピング → カテゴリ一覧 → 大分類 → 中分類 → 小分類 まで辿る
- 末端カテゴリのURLにIDが含まれる場合がある

## 4. ストアカテゴリの設計指針

### 設計の3軸
1. **商品タイプ別**：「メンズ財布」「レディースバッグ」
2. **シーン別**：「父の日ギフト」「母の日」「クリスマス」
3. **特集別**：「新作」「セール」「アウトレット」「人気ランキング」

### 階層の深さ
- 3階層まで（深すぎると顧客が迷う）
- 各階層に5〜15商品（少なすぎ・多すぎを避ける）

### ナビゲーション
- ストアトップにメインカテゴリ大分類5〜10個
- ヘッダー or サイドバーにアクセス
- パンくずでカテゴリ階層を表示

## 5. 1商品 path 1つの制約への対処

`path` は 1商品1カテゴリのため、複数カテゴリでアピールしたい商品は：

- **特集ページ**を作る（特集ページにはストアの商品を任意で並べられる）
- **メインのカテゴリ**にはタイプ別を入れる
- **季節・シーン**は特集ページで補完

例：メンズ二つ折り財布
- path：「メンズ > 財布 > 二つ折り」
- 特集：「父の日ギフト特集」ページにも掲載

---

## 6. プロダクトカテゴリの選定ミスのリスク

### よくあるミス
1. **誤分類**：化粧水を「キッチン用品」 → 致命的
2. **過度に汎用**：「その他」 → 検索精度低下
3. **過度に限定**：ニッチ過ぎて該当カテゴリで検索されない
4. **性別誤分類**：レディース商品をメンズに
5. **年齢誤分類**：キッズ商品を大人カテゴリに

### 影響
- 検索精度低下
- 関連商品の表示精度低下
- カテゴリランキングでの順位低下
- CVR低下
- 広告ROAS低下

---

## 7. カテゴリ廃止・統合への対応

Yahoo!側で大規模なカテゴリ改編がある場合：

- 公式アナウンスをウォッチ
- 新カテゴリIDが付与される
- 移行期間中は両方のIDが有効な場合あり
- 移行完了後は新IDのみ
- 自店の商品をすべて新IDに更新

---

## 8. カテゴリID取得のコツ

新規商品登録時：
1. 商品名と特徴を整理
2. ストアクリエイターPro「プロダクトカテゴリ検索」で候補リストを取得
3. 候補3〜5個の中から「最も近い」「最も売れている」を確認
4. 競合商品のカテゴリと比較
5. ID確定 → 商品データCSVに転記

リカテゴライズ時：
1. 既存カテゴリでの流入キーワード・CVRを記録
2. 新カテゴリ候補を上記手順で選定
3. 検索順位への影響を予測
4. 繁忙期を避けて切替
5. 切替後2〜4週間の指標を観察
