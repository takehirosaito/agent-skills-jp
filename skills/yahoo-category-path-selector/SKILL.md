# Yahoo!ショッピング カテゴリパス選定

## 概要

Yahoo!ショッピングのカテゴリは2系統ある。ストアカテゴリ（CSV列 `path`、ストアが自由に設計）と、プロダクトカテゴリ（CSV列 `product-category`、Yahoo!共通定義のID）。前者は店舗内ナビゲーション、後者はYahoo!全体検索・カテゴリランキング・関連商品の根拠となる。誤分類は検索順位とCVRに直接影響するため、新規登録時と既存リカテゴライズ時の判定を慎重に行う必要がある。

本スキルは、商品情報から候補カテゴリを2系統で提示し、競合商品との比較・移行リスク・カテゴリ廃止対応までを一覧で出力する。

## 最重要原則

**プロダクトカテゴリ（数字ID）の精度が、Yahoo!検索・カテゴリランキング・関連商品の露出を決める。「その他」「最上位カテゴリ」のままにせず、必ず末端カテゴリまで指定する。** path の見た目はストア内の話だが、product-category の指定はYahoo!全体での発見可能性を左右する別物。両方を別々に最適化する。

要点：
- `path` は1商品1カテゴリ、ストアが任意設計、3階層までが目安
- `product-category` はYahoo!共通の数字ID、末端カテゴリ指定が原則
- 主要大分類：ファッション／食品・スイーツ／インテリア・寝具／家電／TV・オーディオ・カメラ／パソコン・周辺機器／スマホ・タブレット／ビューティ・コスメ／ダイエット・健康／医薬品・コンタクト（要審査）／ベビー・キッズ・マタニティ／スポーツ・アウトドア／本・雑誌・コミック／ペット用品／キッチン・日用品 など
- 医薬品・コンタクト等は出店審査が別途必要

## 処理フロー

### Step 1：商品情報の整理
- 商品名／商品タイプ／対象（メンズ・レディース・キッズ等）／用途／素材
- ブランド／型番
- 競合上位商品3〜5件のURL

### Step 2：プロダクトカテゴリ候補の抽出
方法は3通り。組み合わせて精度を上げる：
1. ストアクリエイターPro「プロダクトカテゴリ検索」で商品名を入力 → 候補IDを取得
2. 競合上位商品の商品ページから、ページに表示される「カテゴリリンク」「パンくず」を辿る
3. Yahoo!ショッピングのカテゴリトップから大分類→中分類→小分類を辿る

### Step 3：候補3〜5個から最適を選定
| 判定軸 | 確認内容 |
|---|---|
| 最も近い意味 | 商品の本質的なタイプと一致するか |
| 売れている | 競合上位商品が同カテゴリにいるか |
| 末端指定 | 「その他」「○○カテゴリ」止まりでないか |
| 属性整合 | カテゴリで必須となる属性が商品にあるか |
| 性別・対象整合 | メンズ／レディース／キッズ／対象月齢の整合 |

### Step 4：ストアカテゴリ path の設計
3軸で設計：
1. 商品タイプ別（「メンズ > 財布 > 二つ折り」）
2. シーン別（「父の日ギフト」「母の日」）
3. 特集別（「新作」「セール」「人気ランキング」）

階層は3階層まで、各階層に5〜15商品の目安。

### Step 5：1商品1path制約への対処
複数カテゴリでアピールしたい商品は「特集ページ」で補完。メインpathは商品タイプ別、特集ページにシーン軸で並べる。

### Step 6：誤分類リスクの判定
よくあるミス：
- 誤カテゴリ（化粧水を「キッチン用品」等）→ 致命的
- 過度に汎用（「その他」）→ 検索精度低下
- 過度に限定（ニッチ過ぎて該当カテゴリで検索されない）
- 性別誤分類（レディース商品をメンズに）
- 年齢誤分類（キッズ商品を大人カテゴリに）

### Step 7：リカテゴライズの影響予測
既存商品のカテゴリ変更時は `references/migration-impact.md` を参照：
- 既存カテゴリでの流入KW・CVRの記録
- 新カテゴリでの検索順位予測
- 繁忙期を避けた切替計画
- 切替後2〜4週間のKPI監視

## 代表例

### メンズ二つ折り財布（本革・ポーター正規取扱）

**プロダクトカテゴリ候補**：
- ファッション > メンズファッション > 財布・小物 > 財布 > 二つ折り財布（末端）
- ファッション > メンズファッション > 財布・小物 > 財布（中位、避けたい）
→ 末端の「二つ折り財布」を選択。競合上位3商品も同末端カテゴリ

**ストアカテゴリ path**：
- 第1階層：メンズ
- 第2階層：財布
- 第3階層：二つ折り
- path：`メンズ > 財布 > 二つ折り`

**特集ページにも掲載**：
- 「父の日ギフト特集」
- 「ビジネス小物特集」
- 「ポーター 正規取扱コーナー」

**選定理由**：
- 末端カテゴリ指定で検索精度最大化
- 競合上位と同カテゴリ ＝ 同じ検索結果セットに乗る
- 「ブランド・正規取扱」を強調するため特集ページで二次露出

## 品質ゲート

- プロダクトカテゴリは「その他」止まりではなく末端を指定しているか
- 候補3〜5個を提示し、競合との一致度で序列化しているか
- ストアカテゴリは3階層以内に収まっているか
- 性別・年齢・対象の誤分類はないか
- リカテゴライズ時に切替前KPIを記録しているか
- 医薬品・コンタクト・酒類など出店審査が別途必要なカテゴリの場合、審査ステータスを確認したか

## エッジケース

- **新ジャンル商品でカテゴリが曖昧**：候補3〜5個提示し、最終判断はユーザーに委ねる。仮で「最も近いID」で運用し、2〜4週間の検索流入・CVRで再判定
- **カテゴリ廃止・統合**：Yahoo!側のカテゴリ改編アナウンスをウォッチ。新IDが付与され移行期間中は両方有効な場合あり、移行完了後は新IDに統一
- **ギフト商品の扱い**：「父の日ギフト」「クリスマス」はストアカテゴリ・特集ページで運用、プロダクトカテゴリは商品本体の分類を維持
- **複数機能商品（マルチユース）**：最も主要な機能でプロダクトカテゴリを決定。サブ機能は商品名・shopping-search-keywordsで補完
- **正規取扱と並行輸入**：プロダクトカテゴリは同一でよいが、商品名・abstractに正規／並行を明示

## 注意事項

- Yahoo!のプロダクトカテゴリ体系は再編されることがあるため、最新のストアクリエイターProカテゴリツリーで確認する
- 医薬品・コンタクト・酒類・たばこ・古物・銃刀類などのカテゴリは別途出店審査・許認可が必要
- リカテゴライズは検索順位・関連商品表示・カテゴリランキングへ影響するため、繁忙期を避けて切替計画を作る
- 切替後は最低2〜4週間、KPIを観察してから次の調整を行う
