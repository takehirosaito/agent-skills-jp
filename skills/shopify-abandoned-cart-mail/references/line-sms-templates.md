# LINE / SMS 短文テンプレ

メールに加えて LINE / SMS で送ると、開封率が **70-90%** と非常に高い。ただし配信回数を絞らないと嫌悪感を生む。

## LINE 公式アカウント

### 利点
- 開封率：60-80%（メール比 2-3倍）
- 既読確認が可能
- 画像・カルーセル・リッチメニュー
- 1対1チャット（顧客サポート）

### 制限
- 配信単価：プランによる（月15,000通までフリー / それ以上は有料）
- 友だち登録が必要（強制登録不可）

### 連携ツール
- Liny（LINE活用ツール）
- L Message
- Omnisend（一部連携）

### テンプレ：1通目（1時間後）

```
こんにちは、[ニックネーム]さん

先ほどカートに入れていた商品をお忘れではありませんか？

📦 [商品名]
💰 ¥[価格]

▼今すぐ確認する
[ shorten_url ]

ご質問はこのチャットから直接送信ください✨
```

### テンプレ：3通目（72時間後）

```
[ニックネーム]さん、こんにちは

長らくご検討いただきありがとうございます🙏
特別に【24時間限定 10%OFFクーポン】をご用意しました。

クーポンコード：WELCOME10
有効期限：[日時]

▼今すぐ使う
[ shorten_url ]
```

## SMS

### 利点
- 開封率：90%以上
- 携帯番号があれば届く

### 制限
- 1通あたり 全角70字（半角160字）
- 配信単価：1通 3-10円
- 文字数制限が厳しい

### 連携ツール
- SMS Publisher
- 空電プッシュ
- Twilio
- Omnisend（一部対応）

### テンプレ：1通目

```
[ブランド名]
カートに残っている[商品名]、まだ間に合います。
こちらから完了：[ shorten_url ]
配信停止 [ unsubscribe_url ]
```

文字数：約60字

### テンプレ：3通目（割引あり）

```
[ブランド名]
ラスト24時間 10%OFF。クーポン:WELCOME10
完了：[ shorten_url ]
停止：[ unsubscribe_url ]
```

文字数：約55字

## LINE と SMS の使い分け

| シーン | LINE | SMS |
|---|---|---|
| 既存顧客 | ✅ | △ |
| 新規（メールしか持っていない） | - | △ |
| 高単価商品 | ✅（パーソナル感） | - |
| 緊急性（在庫切れ間近） | ✅ | ✅ |
| 法的通知 | - | - |

## URL短縮

LINE / SMS では URL を **短縮** する：

- bit.ly / TinyURL（汎用）
- ストア独自の短縮（`example.com/r/xxx`）

短縮URL は **UTMタグを内包** して計測可能に：

```
https://bit.ly/abc123  →  https://example.com/checkout/xxx?recover=true&utm_source=line&utm_campaign=cart_3h
```

## 配信制限

### 配信頻度

- 同じ顧客に **メール＋LINE＋SMS を同日に複数通** 送らない
- 1チャネルにつき 3通まで
- カゴ落ち→購入完了で全停止

### 配信時刻

- 9-21時のみ（早朝・深夜は避ける）
- 平日昼休み（12-13時）／夜（19-21時）が最適

## 配信停止

### LINE

「ブロック」or「友だち削除」で停止。配信停止リンク不要だが、メッセージ内に「配信停止ご希望の方はブロックしてください」と一文。

### SMS

```
配信停止：[unsubscribe_url]
```

を必ず末尾に。**特定電子メール法は SMS にも適用**。

## 個人情報

LINE/SMS で顧客情報を扱う：
- LINE ID は個人情報
- 携帯番号は個人情報
- 利用目的を明示（プライバシーポリシー）

## トランザクション通知

注文確認・配送通知・在庫入荷通知は **マーケティング配信ではない** ため、配信停止後でも送れる。ただし、内容にマーケティング要素を混ぜると違反扱い。

## 効果指標

| 指標 | LINE 業界平均 | SMS 業界平均 |
|---|---|---|
| 開封率 | 60-80% | 90%+ |
| クリック率 | 10-25% | 5-15% |
| 回復率 | 15-35% | 10-25% |

メール + LINE + SMS の組み合わせで、回復売上を **メール単独の1.5-2倍** に増やせるケースも。
