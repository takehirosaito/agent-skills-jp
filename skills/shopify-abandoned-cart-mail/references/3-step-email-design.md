# 3通ステップメールの役割と設計

## 全体像

| 通数 | タイミング | 目的 | トーン | 訴求要素 | 割引 |
|---|---|---|---|---|---|
| 1通目 | 1時間後 | 思い出し | 軽快 | カート内容のリマインド | なし |
| 2通目 | 24時間後 | 不安解消 | 専門的＋共感 | レビュー・FAQ・送料・返品 | なし |
| 3通目 | 72時間後 | 最終リマインド | 希少性＋限定性 | 在庫切れ間近・限定オファー | あり（10%OFF or 送料無料） |

## 1通目（1時間後）：思い出し

### 心理状態
- カートに入れたことを覚えている
- 別タブを開いた／電話に出たなど、軽い中断
- 購入意欲はまだある

### 訴求
- カートに残っている商品を **そのまま見せる**
- 「在庫あり」「最短翌日発送」など買いやすさを訴求
- 割引や煽りは **使わない**

### 件名例
- A（シンプル）：「カートに残っている商品があります」
- B（フレンドリー）：「気になっていた○○、まだ間に合います」
- C（具体）：「【商品名】 がカートに入ったままです」

### 本文骨子

```
こんにちは、[顧客名] さん

先ほどご覧いただいた[商品名]がカートに残っています。

[商品画像]
[商品名]
[価格]

引き続きご検討の場合はこちらからお買い物を再開いただけます。

[CTAボタン：お買い物を再開する]

📦 送料無料（5,000円以上）
🔄 30日間返品OK
⚡ 在庫あり・最短翌日発送

何かご不明点があればお気軽にお問い合わせください。

—
[ブランド名]
[配信停止リンク]
```

## 2通目（24時間後）：不安解消・社会的証明

### 心理状態
- 1日経って、まだ買っていない＝何らかの躊躇あり
- 「他の人はどう？」「サイズは？」「自分に合う？」などの不安

### 訴求
- **レビュー**を見せる：「○件のレビュー、星4.5」「敏感肌の方からの口コミ」
- **FAQ** で不安解消：返品／配送日／使い方
- **特定のベネフィット**：成分・素材・産地
- 割引は **まだ使わない**（一部のストアは「初回送料無料」程度）

### 件名例
- A（レビュー訴求）：「[商品名] のお客様の声をご紹介」
- B（FAQ）：「[商品名] でよくいただくご質問」
- C（共感）：「敏感肌でも使えるか、心配ですよね」

### 本文骨子

```
こんにちは、[顧客名] さん

[商品名] についてお迷いの方からよくいただくご質問にお答えします。

Q. 敏感肌でも使えますか？
A. はい、パッチテスト済みの低刺激処方です。

Q. どれくらいで効果を感じますか？
A. 個人差はありますが、肌のキメは2-4週間で実感される方が多いです。

—

お客様の声（星4.5 / 312件のレビュー）：
「ヒリヒリせずに使えた」（30代女性）
「肌のうるおいが続く」（40代女性）

—

[CTAボタン：お買い物を再開する]

📦 送料無料／🔄 30日返品／⚡ 最短翌日発送
```

## 3通目（72時間後）：最終リマインド・希少性

### 心理状態
- 3日経っても買っていない＝諦めかけている、または忘れている
- 強い動機が無いと購入しない

### 訴求パターンA（割引なし版）
- **希少性**：「在庫残り少なめです」（事実ベース）
- **新着情報**：「先週入荷したばかりです」「人気のため、ご準備は1点ずつになります」
- 暖かい引き止め

### 訴求パターンB（割引あり版）
- **限定オファー**：「24時間限定 10%OFFクーポン」or 「初回購入限定 送料無料」
- **クーポンコード**：英数字で簡潔（`WELCOME10`）
- 期限と条件を明示

### 件名例
- A（希少性）：「在庫残りわずか：[商品名]」
- B（割引あり）：「【最終ご案内】10%OFFクーポンでお買い物を完了」
- C（フレンドリー）：「あと[商品名] のお迎えだけです」

### 本文骨子（割引なし版）

```
[顧客名] さん、こんにちは。

カートに残っている[商品名] ですが、最近お問い合わせが多く、在庫が残り少なくなっております。

[商品画像]
[商品名]
[価格]

引き続きご検討の場合はこちらから：

[CTAボタン：今すぐカートを確認する]

最近のレビュー：
「結局これに戻ってきました」「リピート3回目です」

何かご質問があればこのメールに直接ご返信ください。

—
[ブランド名]
[配信停止リンク]
```

### 本文骨子（割引あり版）

```
[顧客名] さん

長らくご検討いただき、ありがとうございます。
特別に【24時間限定 10%OFFクーポン】をご用意しました。

【クーポンコード】WELCOME10
【有効期限】[日時]
【対象】カート内すべての商品

[CTAボタン：クーポンを使ってお買い物を完了する]

※他のクーポンとの併用不可
※有効期限後は無効になります

—
[ブランド名]
[配信停止リンク]
```

## 4通目以降は送るべきか

基本は **3通で打ち切り**。

- 4通以上は **嫌悪感** を生み配信停止を増やす
- 顧客が「興味あり」を示すまで、別の自動メール（新商品案内 / メルマガ）へ移行
- **再訪問**したら別の automation（browse abandonment）でフォロー

## A/Bテスト設計

| テスト要素 | A | B |
|---|---|---|
| 件名 | シンプル | 感情系 |
| 1通目本文の長さ | 短文 | 中文 |
| CTAボタンの文言 | 「お買い物を再開する」 | 「今すぐ確認する」 |
| 3通目の割引 | なし | あり |
| 送信時刻 | 朝8時 | 夜20時 |

各テストは 1要素ずつ。複数同時に変えると効果が分離できない。

## 効果指標

| 指標 | 業界平均 | 優秀 |
|---|---|---|
| 開封率（1通目） | 40-50% | 60%+ |
| 開封率（3通目） | 25-35% | 40%+ |
| クリック率 | 5-15% | 20%+ |
| 回復率（クリックから購入） | 10-30% | 40%+ |
| 回復売上 | カゴ落ち額の 5-15% | 20%+ |

## 失敗パターン

- ❌ 1通目から割引クーポン → 将来も割引を待たれる
- ❌ 「最終警告」「絶対お得」など煽る → 信頼低下、配信停止増
- ❌ 同じ件名で3通送る → スパム扱い
- ❌ 配信停止リンクが無い／見えにくい → 法令違反
- ❌ モバイル未対応 → 開封後すぐ離脱

## チェックリスト

- [ ] 3通の役割が異なる（思い出し／不安解消／希少性）
- [ ] 件名がA/B案
- [ ] 1通目から割引を使っていない
- [ ] 配信停止リンクが各通にある
- [ ] 購入完了時の即時停止トリガー
- [ ] モバイル最適化（横600px、フォント14px+、CTA大）
- [ ] 効果指標（開封率／クリック率／回復率）が計測可能
