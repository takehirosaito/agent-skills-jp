# Shopifyカゴ落ちメール作成

## 概要

Shopifyでカート放棄（Abandoned Checkout）した顧客に対する **3通ステップメール／LINE短文／SMS** の文案・件名・配信タイミング・Recovery URL組み込み方法・配信停止対応まで一括設計するスキル。

割引クーポンに依存せず、1通目「思い出し」・2通目「不安解消」・3通目「希少性／限定オファー」という心理段階に沿った設計を基本とする。LINE / SMS は補完チャネルとして本文を圧縮した形で提供する。

## ★最重要原則

**1通目から割引を出さない**。1通目は思い出し、2通目はレビュー・FAQ・送料返品で不安解消、3通目で希少性または限定クーポン。早期割引は将来も割引を待たれる体質をストアに残し、定価販売を破壊する。

### Shopify固有の要点

- カート放棄トリガー：チェックアウト開始→未完了10分以上で「Abandoned Checkout」確定
- 復元URL：`{{ url }}`（Shopify Email）／`{{ event.extra.checkout_url }}`（Klaviyo）等で組み込み、24時間有効
- 配信タイミング標準：1時間後 / 24時間後 / 72時間後
- Shopify Flow：`Cart abandoned` トリガーで自動分岐可（VIP顧客は別経路など）

## 処理フロー

**Step 1. 入力情報の確認（不足は仮定で進める）**
- 商品カテゴリ／単価帯／ブランドトーン（カジュアル／高級／専門的）
- 配信ツール（Shopify Email / Klaviyo / Omnisend / Flow / LINE公式 / SMS）
- 割引可否（不可なら3通目も希少性ベース）
- 送料・返品条件（不安解消の根拠に使う）

不足時は「仮定」「不足情報」「確認したいこと」を明示して進行。

**Step 2. 3通の役割を確定**
- 1通目（1h後）：思い出し・カート内容のリマインド・割引なし
- 2通目（24h後）：レビュー／FAQ／返品条件で不安解消
- 3通目（72h後）：割引なし版（希少性）と割引あり版（10%OFF or 送料無料）の両方を提示

**Step 3. 件名を各2-3案ずつ作成**
- A案：シンプル直接型
- B案：感情・共感型
- C案：商品名／具体性型

**Step 4. 本文骨子を作成**
- ヘッダー：顧客名・カート内容
- ボディ：通ごとの訴求要素
- CTA：Recovery URLボタン
- フッター：送料無料・返品条件・配信停止リンク

**Step 5. LINE / SMS 短文版に圧縮**
- LINE：絵文字＋短文＋URL（120字以内）
- SMS：商品名＋URL（70字以内）

**Step 6. 配信停止リンク・特電法対応の明記**

## 代表例（1パターン）

化粧品ブランド・敏感肌向け美容液5,000円のカゴ落ち：
- 1通目件名「カートに残っている商品があります」／本文：商品画像＋「在庫あり・最短翌日発送」
- 2通目件名「敏感肌でも使えるか、心配ですよね」／本文：パッチテスト済表記＋星4.5レビュー
- 3通目件名「在庫残りわずか：[商品名]」（割引なし版）／「【最終ご案内】10%OFFクーポン」（割引あり版）

他ジャンル（食品・ファッション・サプリ・家電）の実例は `references/examples.md` を参照。

## 品質ゲート

- [ ] 1通目に割引・煽り表現がない
- [ ] 3通の役割が明確に異なる（思い出し／不安解消／希少性）
- [ ] 件名がA/B/Cの3案ずつある
- [ ] Recovery URL の組み込み変数が配信ツールに合致
- [ ] 配信停止リンクが全通にある
- [ ] モバイル前提（横600px / フォント14px+ / CTA大）の指示が入っている
- [ ] 購入完了時の即時停止条件が記載されている
- [ ] 「最終警告」「絶対」「治る」等の煽り・断定表現がない

## エッジケース

- **高単価商材（10万円超）**：3通目も割引せず、専属コンシェルジュ／個別相談のオファーに切替
- **生鮮・予約販売**：在庫切れ／予約期限を1通目で明示、72時間後は手遅れのことがあるため2通目の24h後を12hに前倒し
- **B2B / Markets Pro**：単価が高く割引交渉は別途、メール内で「担当者に相談」のCTAに置き換え
- **配信ツール未確定**：Shopify Email デフォルト構文で書き、Klaviyo / Omnisend 変数を併記
- **複数言語ストア（Markets + Translate & Adapt）**：日本語版を起点に、英語版は同等トーンで別途生成と注記

詳細は `references/examples.md` を参照。

## 注意事項

- 特定電子メール法（オプトイン取得・送信者表示・配信停止）の最終判断は社内法務／公式ガイドで確認
- 個人情報を含むカート情報の差込変数は配信ツールが暗号化していることを前提とする
- 「絶対」「必ず治る」「最大級」「No.1」「完全」等の断定・優良誤認表現を使わない
- Shopify の Abandoned Checkout 仕様・Klaviyo の変数名は変動するため、配信前に管理画面で要確認
- 顧客の同意取得（チェックアウト時のメール受信同意）が無い場合、自動送信できないアカウントがある（GDPR / 日本の特電法）
