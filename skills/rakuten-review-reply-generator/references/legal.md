# 法令配慮（薬機法・景表法・特商法・レビュー特典規制）

## 薬機法

### 化粧品レビュー返信での注意

化粧品（医薬部外品でない一般化粧品）の効能効果は56項目に限定。顧客レビューで以下のような記述があっても、返信で **追認しない**：

| NG レビュー記述 | 追認NG例 |
|---|---|
| 「シミが消えました」 | 「シミが消えて良かったですね」 |
| 「シワが減りました」 | 「シワへの効果を感じていただけて」 |
| 「アンチエイジング効果がありました」 | 「アンチエイジング効果のある商品で」 |
| 「肌が若返りました」 | 「若返り効果を実感いただけて」 |

### 追認しない返信パターン
```
○○様、お使いいただいてのご感想、ありがとうございます。
お肌のお手入れにお役立ていただけたとのこと、嬉しく拝読しました。
※ご使用感には個人差がございます。
```

### 健康食品の場合

「痩せた」「便秘解消」「○○病が治った」「免疫力UP」等の医薬品的効果に追認しない。

### NGパターン
```
○○様、ダイエット成功おめでとうございます！
```
→ 効能の追認

### OKパターン
```
○○様、毎日の健康習慣にお役立ていただけたとのこと、嬉しく拝読しました。
※摂取目安量は商品ラベルをご確認ください。
```

## 景表法

### No.1表記・最上級表現の回避

返信文で「業界一の品質」「最高水準」「絶対安全」等を使わない。

### 二重価格の追認

「あの値段でこの品質はお得」のレビューに対し「定価○○円が今だけ○○円」と返信で書くと、二重価格表示の8週間ルール要件を満たす必要がある。

### 有利誤認

「すべてのお客様にご満足いただいています」「全員が好評」は事実と異なるリスク。

## 特商法

### 補償・返品の表記

返品・交換の案内を返信に含める場合、商品ページの返品特約と齟齬がないか確認。

| OK | NG |
|---|---|
| 「返品・交換のご相談は当店までお気軽にお問い合わせください」 | 「いかなる場合も即返金いたします」（実際の運用と乖離） |
| 「お問い合わせ：[URL]」 | 個別アドレス・電話番号の特商法表記なし |

### 個別対応の確約

「次回○○OFFします」「絶対補償します」のように、店舗運営方針として確定していない確約は避ける。

## レビュー特典規制（2023.10.1〜厳格化）

楽天市場ではレビュー投稿の対価としての特典提供に制限がある。違反点数35点（一発で違反レベル1）、レベル5で契約解除＋違約金300万円。

### OK
- 商品本体に付属する **おまけ**（次回購入時の同梱予告ではない）
- 投稿後の **「お礼」としての別送おまけ**（投稿確認後）
- 次回利用クーポン（投稿確認後）

### NG（違反点数35点）
- 「レビュー投稿者全員にプレゼント」（事前告知）
- 「★5を投稿すると○○」（評価点数とリンク）
- 「レビュー書いてくれた方にクーポン」（事前告知）
- レビュー返信で「次回ご投稿いただければクーポン」（投稿促進）

### 返信文での違反NG例

```
○○様、レビューありがとうございます！
次回ご購入時に使える500円OFFクーポンをお送りします。
```
→ レビューと対価をリンクさせる → 違反

### 安全な返信

```
○○様、ご投稿ありがとうございます。
今後ともよろしくお願いいたします。
```

## ステマ規制（2023.10.1〜）

事業者がレビュアー・インフルエンサーに依頼して投稿させた場合、「広告」「PR」表記が必要。

### 関連する注意
- 「サクラ」と疑われるような偽レビューの投稿依頼NG
- 「自分で書いた」と装ってレビューを書かないこと
- 業者の代行投稿NG

## 個人情報保護法

### 返信文に含めてはいけない情報
- 投稿者の本名（楽天表示名以外）
- 住所・電話番号
- 注文番号・取引履歴の詳細
- 第三者（家族・友人）の特定情報

### OK
```
○○様（楽天表示名）、ご投稿ありがとうございます。
```

### NG
```
○○ ○○様（本名）、[県名]へのお届け○月○日、○○注文番号でお求めいただいた商品の…
```

## 公式に「不要」とされる返信

楽天の利用規約・運営ガイドラインで「禁止」とされる返信内容：

- 投稿者の名誉を傷つける返信
- 第三者の名誉を傷つける返信
- 差別的表現
- 個人情報の暴露
- 競合店舗・商品の誹謗中傷

## レビューの削除依頼

明らかに虚偽・誹謗中傷・個人攻撃の場合、楽天にレビュー削除依頼が可能。

### 削除対象になりうるレビュー
- 商品と無関係な内容
- 第三者への誹謗中傷
- 個人情報の暴露
- 明らかな虚偽・業者投稿

### 削除依頼の流れ
- RMS のレビュー管理画面から
- 楽天運営の審査を経て削除

ただし「悪い評価だから」だけでは削除されない。事実ベースの悪評は受け止めて改善するしかない。
