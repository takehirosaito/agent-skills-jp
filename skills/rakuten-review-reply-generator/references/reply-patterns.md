# 星評価別 返信パターン

## 星5（高評価・好意的）

### 基本トーン
- 感謝の気持ちを率直に
- 具体的レビュー内容に触れる
- リピート誘導・関連商品の自然な紹介
- 親しみある締め

### テンプレ
```
○○様

このたびはご購入と、嬉しいレビューのご投稿、誠にありがとうございます。

[レビュー内容への具体的な反応]とのこと、私たちもとても嬉しく拝読しました。

[商品の使い方提案／関連商品の自然な紹介／継続的な関係への誘い]

今後とも○○店をどうぞよろしくお願いいたします。

○○店
```

### 例
```
○○様

このたびはご購入とレビューのご投稿、誠にありがとうございます。

「沸騰時間が早くて朝の準備が楽になった」とのお声、とても嬉しく拝読しました。
お忙しい朝のひとときが、少しでも快適になればと願っております。

ご家族向けに大容量タイプ（1.5L）もご用意しております。
ぜひ機会がございましたらお試しください。

今後とも○○店をどうぞよろしくお願いいたします。

○○店
```

## トーンの店舗別カスタマイズ

### フォーマル（百貨店・高級ブランド）
- 「ございます」「いたしました」を多用
- 結びは「何卒よろしくお願い申し上げます」
- 「○○様」を多用

### スタンダード（一般小売）
- 「です」「ます」が基本
- 結びは「よろしくお願いいたします」
- 「○○様」適度に使用

### カジュアル（ユース・サブカル）
- 「！」「☆」を控えめに使用
- 顔文字・絵文字は店舗トーンによる
- ※ただし楽天はビジネス基本、過度なカジュアルは避ける

## NG返信パターン

| NG | 理由 |
|---|---|
| 「配送業者のせいです」 | 責任転嫁、顧客印象悪い |
| 「製造元の問題ですので」 | 同上 |
| 「ご使用方法が間違っています」 | 顧客攻撃 |
| 「個人差があります」を強調 | 共感がない |
| 「絶対そのようなことはありません」 | 反論、断定 |
| 「次回ご購入時にクーポン」を確約 | レビュー特典規制違反リスク |
| 「投稿いただけたらクーポン」 | 同上 |
| 「シミに効くと感じていただけて嬉しい」 | 効能訴求の追認（化粧品の場合NG） |

## 文章量の目安

| 星 | 推奨文字数 |
|---|---|
| 5 | 150-250字 |
| 4 | 200-300字 |
| 3 | 250-350字 |
| 2 | 300-400字 |
| 1 | 350-500字（深い対応が必要） |

→ 星が低いほど丁寧に。ただし冗長にならないよう注意。

## レビュー返信の頻度・タイミング

| タイミング | 推奨 |
|---|---|
| 投稿から1週間以内 | 推奨 |
| 投稿から1ヶ月以内 | 一般的 |
| それ以降 | 「お時間が経ってしまいましたが」と前置き |
| 即日返信 | 急ぐ必要なし（質を優先） |

## 全レビューに返信するか

- 星4-5：選択的（特に内容が具体的なものに）
- 星1-3：原則すべて返信
- 業者・ボット疑い：返信せず通報
