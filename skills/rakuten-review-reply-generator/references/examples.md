## 例6：化粧品・効能訴求あり（星5）

### レビュー
> 「この美容液を使ったら、シミがすっかり消えました！本当におすすめです。星5」

### 返信案（効能訴求を追認しない）
```
○○様

このたびはご購入とレビューのご投稿、ありがとうございます。

お使いいただいての嬉しいご感想、私たちも嬉しく拝読しました。
毎日のスキンケアにお役立ていただけたとのこと、何よりです。

※ご使用感には個人差がございます。
お肌の状態を見ながら、お手入れをお続けください。

今後ともよろしくお願いいたします。

○○店
```

### 注意点
- 「シミが消えた」を追認しない（薬機法）
- 「個人差があります」の打消し（控えめに）
- 「効果」「効く」「治る」等の言葉を返信に使わない

## 返信のチェックリスト

返信文を作成したら：

- [ ] 投稿者個人＋他の顧客にも見える前提で読み返した
- [ ] 効能訴求の追認をしていない（化粧品・健食）
- [ ] 「絶対」「必ず」「最高」等の断定を含まない
- [ ] 言い訳・責任転嫁を含まない
- [ ] 第三者（家族・友人）の特定情報を含まない
- [ ] レビュー特典規制違反になっていない（投稿への対価明示なし）
- [ ] 商品ページの返品特約と矛盾しない
- [ ] 補償・返品の確約は店舗ポリシー範囲内
