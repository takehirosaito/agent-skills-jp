# ジャンル別 返信の注意点

## 化粧品（100939）

### 注意
- 効能訴求の追認NG（薬機法）
- 「シミが消えた」「シワが減った」「アンチエイジング効果」等の記述に同調しない

### NGパターン
```
○○様、シミが薄くなったとのこと、嬉しく拝読しました！
```
→ 効能の追認になり薬機法違反

### OKパターン
```
○○様、お使いいただいてのご感想、ありがとうございます。
お肌のお手入れにお役立ていただけたとのこと、嬉しく拝読しました。
※ご使用感には個人差がございますので、お肌に異常を感じた場合は使用を中止してください。
```
→ 効能を追認せず、個人の使用感として受け止める

## 健康食品（100938）

### 注意
- 効能訴求の追認NG（薬機法）
- 「痩せた」「便秘が治った」「免疫力が上がった」等に同調しない
- 機能性表示食品でも届出文言以外の効果に言及しない

### NGパターン
```
○○様、ダイエット効果を実感いただけて嬉しいです！
```
→ 効能の追認

### OKパターン
```
○○様、お続けいただいてのご感想、ありがとうございます。
毎日の習慣としてお役立ていただけたとのこと、嬉しく拝読しました。
※摂取目安量・摂取上の注意は商品ラベルをご確認ください。
```

## 食品（100227）

### 注意
- アレルゲン・賞味期限の問い合わせには真摯に
- 「健康に効く」「○○病予防」等の追認NG（健康増進法）
- 「美味しかった」「家族で楽しめた」は素直に受け止めてOK

### 例（賞味期限の問い合わせ）
```
○○様、ご質問ありがとうございます。
本商品の賞味期限は[期間]となっております。お届け時の残日数は最短[X]日以上を保証しております。
詳細は商品ページにも記載しております。
```

## ファッション（100371）

### 注意
- サイズ感の個人差
- 色味・素材感の主観
- 着丈・身幅の数値情報

### 例（サイズ違いの不満）
```
○○様、ご購入とレビューありがとうございます。
サイズ感がイメージと異なってしまったとのこと、申し訳ございませんでした。
お手元の他のお洋服との実寸比較のため、商品ページの実寸表とモデル着用情報を見直してまいります。
返品・サイズ交換のご希望がございましたら、当店までお問い合わせください。
```

## ベビー用品（100533）

### 注意
- 安全性への深い配慮
- 月齢適合・体格の個人差
- アレルギー・敏感肌への注意喚起

### 例（肌荒れの記述）
```
○○様、ご購入とレビューのご投稿ありがとうございます。
お子様の肌に合わなかったとのこと、ご心配をおかけしました。
お肌の状態には個人差がございますので、ご使用前にパッチテストやご気分での判断をおすすめしております。
返品・交換のご相談は当店までお気軽にお問い合わせください。
```

## 家電（562637）

### 注意
- 故障・初期不良の対応フロー
- 保証範囲の明示
- 操作・取扱の質問

### 例（故障の記述）
```
○○様、ご購入とレビューありがとうございます。
ご使用早々にトラブルが発生したとのこと、誠に申し訳ございません。
保証期間内ですので、修理または交換の対応をさせていただきます。
詳細は別途、当店からご連絡させていただきますので、お時間いただけますと幸いです。
```

## ペット（101213）

### 注意
- 動物への愛情ある対応
- ペットの個体差
- 食いつき・体調変化への配慮

### 例（食いつきの記述）
```
○○様、ご購入とレビューありがとうございます。
○○ちゃんが喜んで食べてくれているとのこと、私たちも嬉しく拝読しました。
ご質問・ご相談がございましたら、いつでも当店までお問い合わせください。
```

### 効能訴求にも注意
- 「健康になった」「病気が治った」の記述に同調しない（薬機法はペット用品にも適用）

## インテリア・家具（100804）

### 注意
- サイズ・組立の不満（採寸ミス等）
- 配送・搬入の問題
- 耐久性への期待

### 例（採寸ミスの記述）
```
○○様、ご購入とレビューありがとうございます。
設置場所のサイズに合わなかったとのこと、ご不便をおかけしました。
ご返品・サイズ違いのご相談は当店までお問い合わせください。
今後、サイズ表記をより分かりやすく掲載できるよう改善してまいります。
```

## 共通の補償・返品対応

### 補償案内のテンプレ
```
返品・交換のご相談は、当店までお気軽にお問い合わせください。
お問い合わせ：[ショップ問い合わせURL]または[電話番号]
```

### 個別連絡誘導
```
詳細につきましては別途、当店からご連絡させていただきますので、お時間いただけますと幸いです。
```

## 注意：レビュー返信で言ってはいけないこと

| NG | 理由 |
|---|---|
| 「次回○○OFFクーポンをお送りします」 | レビュー特典規制（投稿への謝礼として明示は違反） |
| 「ありがとうございます！」（過剰な感謝） | 形式的すぎる |
| 「すべてのお客様にご満足いただいています」 | No.1表記・有利誤認リスク |
| 「業界最高品質」 | 根拠なき最上級 |
| 「化粧品の効能を感じていただけて」 | 効能訴求追認 |
| 「○○病に効く商品ですので」 | 薬機法 |
| 「絶対に安全」「100%保証」 | 断定リスク |

## 投稿者と店舗の関係性別

### 一般顧客
- 標準的なトーン

### リピート顧客
- 「いつもありがとうございます」を冒頭に
- 顧客名を覚えている雰囲気（ただしストーカー的にならない）

### 法人取引
- フォーマル寄り
- 取引継続のニュアンス

### 初回購入顧客
- 歓迎の気持ち
- 店舗の特徴紹介を控えめに
