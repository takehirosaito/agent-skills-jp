# ライブコマース 台本・進行設計

## 概要

ライブコマース（楽天ライブショッピング・TikTok Live・YouTube Live・Instagramライブ等）の配信台本・進行・販促設計を支援するスキル。配信構成・商品の見せ方・特典のタイミング・購入導線・配信前後の集客/振り返りを設計する。ライブは「視聴維持」と「購入の山場」を作れるかで成果が変わる。だらだら配信を防ぎ、各プラットフォーム特性に合わせた進行を設計する。

## 最重要原則

**「冒頭で“今日の得”を提示して離脱を防ぐ／1商品ずつ山場（実演・比較・限定特典）を作る／特典/クーポンと在庫/締切で今買う理由を作る／コメントを拾って双方向に／クロージングで購入導線を明確に／配信前の集客と配信後の振り返りまでを1セットで」**。実演は事実ベースで。効果の断定や誇大な実演（薬機/景表違反）は避ける。

## 知識ベース

配信の基本構成：

| パート | 目的 | 内容 |
|---|---|---|
| オープニング | 離脱防止 | 挨拶・今日の見どころ・限定特典の予告 |
| 商品紹介 | 価値訴求 | 1商品ずつ特徴・利用シーン・誰向けか |
| 実演/比較 | 納得 | 使い方デモ・サイズ感・ビフォーアフター（事実ベース） |
| Q&A | 双方向 | コメントの疑問に回答、不安解消 |
| クロージング | 購入 | 特典/在庫/締切の訴求、購入手順の明示 |

プラットフォーム別の留意（仕様は要確認）：
- 楽天ライブショッピング：楽天会員/購入導線との連携
- TikTok Live / Instagram ライブ：発見型・テンポ・若年層
- YouTube Live：尺を取った実演・説明に向く

購入の山場：限定特典・数量/時間限定・セット提案。今買う理由を作る。

> 各プラットフォームのライブ/販売機能・仕様は変動する。確定は各公式で確認。

## 処理フロー

### Step 1：商材・配信先・目的の確認
- 紹介商品（点数/順番）、配信プラットフォーム、配信尺、特典、目標（販売/認知）
不明時は「主力3商品・30〜45分・限定クーポンあり」を仮置きし明示。

### Step 2：配信構成の設計
- オープニング〜クロージングのタイムライン、各商品の配置と山場。

### Step 3：商品別トークの要点
- 各商品の訴求ポイント・実演内容・想定質問（事実ベース、誇大表現なし）。

### Step 4：特典・購入導線
- 特典/クーポンの出すタイミング、在庫/締切訴求、購入手順の案内。

### Step 5：配信前後
- 配信前の告知/集客、配信後の振り返り（視聴維持・購入の山・改善点）。

## 出力フォーマット

```
# ライブコマース 台本：[配信テーマ]

## 0. 前提（商品/プラットフォーム/尺・仮定）
## 1. タイムライン（パート×時間×目的）
## 2. 商品別トーク要点（訴求/実演/想定Q）
## 3. 特典・購入導線（タイミング/締切/手順）
## 4. 配信前 告知・集客
## 5. 配信後 振り返り指標（視聴維持/購入の山）
```

## 品質ゲート
- 冒頭で離脱を防ぐ“得”を提示しているか
- 1商品ずつ山場（実演/特典）を作ったか
- 今買う理由（限定/締切）と購入導線が明確か
- 実演表現が事実ベースで薬機/景表に反していないか

## 注意事項
- プラットフォーム仕様は変動。確定は各公式で確認。
- 効果の断定・誇大な実演（特に化粧品・健康・食品）は薬機法/景表法違反のリスク。
- 価格/特典の表示は正確に。二重価格・不当表示を避ける。
