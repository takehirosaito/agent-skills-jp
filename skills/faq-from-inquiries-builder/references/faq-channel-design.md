# 公開FAQ／商品ページ／チャットボット／社内マニュアルの書き分け

同じ情報を異なる粒度・文体で4箇所に展開する。読者と利用シーンが違うため、文面を使い回さない。

## 1. 公開FAQ（ヘルプセンター／店舗トップのFAQページ）

### 想定読者
- 既購入者（運用問い合わせ）
- 購入検討者（FAQから商品理解を深めるタイプ）
- リピート顧客

### 文体
- 完結・網羅的
- 検索ヒットを意識したキーワード入り
- 内部リンクで詳細記事へ誘導可能
- 1問1答が原則、複雑な場合は段階的に説明

### 良い例

```
Q. 返品はできますか？

A. 商品到着後7日以内・未使用・タグ付きの状態でしたら、お客様のご都合による返品を承ります。

【返品の手順】
1. 当店カスタマーサポート（support@example.com）へ返品ご希望の旨をご連絡ください
2. 返品先住所・伝票番号をご案内いたします
3. お手元の商品を着払いで送らないようご注意ください（お客様送料負担）
4. 商品確認後、3-5営業日で返金処理を行います

【返品をお受けできない場合】
- ご使用済み、タグなし、商品破損
- セール対象商品（商品ページに明記）
- 食品・化粧品（衛生上の理由）

詳細：[返品ポリシー全文]
````

### 避ける
- 「お問い合わせください」だけで終わる（自己解決にならない）
- 何ステップもまたぐ手順を文章で羅列（番号付きリストにする）
- 古いポリシーを残す

## 2. 商品ページQ&A（離脱阻止向け）

### 想定読者
- 購入直前の検討者
- 「カートに入れる」ボタンの直前にいる人

### 文体
- 短く、不安を取り除く
- 1問につき2-4行
- 「ご安心ください」と明示的に伝える
- 「無料」「無償」「○日以内」など具体数値を入れる

### 良い例（アパレル商品ページの最下部）

```
■ よくある質問

Q. サイズが合わなかったら？
A. 商品到着後7日以内・タグ付きでしたら、サイズ交換を承ります。
   返品送料はお客様負担、交換品の送料は当店負担です。

Q. 配送はいつ届きますか？
A. ご注文確定後、平日は当日または翌営業日に発送いたします。
   関東は1-2日、その他地域は2-3日でお届けします。

Q. ギフトラッピングは可能ですか？
A. 無料で承ります。ご注文時のオプションでお選びください。
   メッセージカードもご用意があります。
```

### 避ける
- 長文（カート画面に行く前に読まれない）
- ネガティブ情報の羅列（「返品できない場合」は別ページへ）
- 商品本体と無関係なQ&A（配送一般・会員情報等は店舗共通FAQへ）

## 3. チャットボットQ&A（短文・自動応答）

### 想定読者
- あらゆる訪問者
- ヘルプを「探す」のが面倒な人
- スマホで親指1本で操作する人

### 文体
- 1問1文
- 回答は1-3文
- 選択肢（チップ）を提示して次の質問に誘導
- 解決しなければ有人チャットへ

### 良い例

```
Trigger: 配送 / いつ届く / 送料

Bot: ご注文後、平日は当日または翌営業日に発送いたします。
   地域別の到着目安をご覧になりますか？

選択肢：
[配送日数を見る] [送料を確認する] [住所変更したい] [担当者に相談する]
```

```
Trigger: 返品 / 返品したい / サイズが違う

Bot: 商品到着後7日以内・未使用なら返品交換を承ります。
   詳しい手順をお伝えしましょうか？

選択肢：
[手順を確認する] [返品先住所を見る] [担当者に相談する]
```

### 避ける
- 長文（読まれない）
- 選択肢なし（行き止まりになる）
- 「FAQをご覧ください」だけで終わる

## 4. 社内対応マニュアル（カスタマーサポート用）

### 想定読者
- カスタマーサポート担当者
- 新人スタッフ
- 責任者・リーダー

### 文体
- 判断基準を明示
- 回答テンプレ（コピペ可能）を含む
- エスカレーション基準を明記
- 過去の悩ましい事例を「個別対応事例」として記録

### 良い例

```
## サイズ違いによる返品交換の対応

### 判断基準
- 到着後7日以内：返品交換可
- 未使用・タグ付き：必須
- セール商品：個別判断（商品ページに「セール返品不可」明記の場合は不可）

### 回答テンプレ
（コピペして調整）

「ご注文いただきました[商品名]について、サイズ交換のご要望承りました。
お手元の商品を以下までご返送ください。
返送送料はお客様にてご負担、交換品の発送送料は当店負担です。
[返送先住所]
商品到着・確認後、[ご希望サイズ]の発送をいたします。」

### エスカレーション基準
- 8日目以降の返品要望：リーダー判断
- ご使用済みの返品要望：原則お断り、ただし高額顧客は責任者相談
- セール返品禁止商品のクレーム：責任者対応

### 過去の個別対応事例
- 2024-XX-XX：身体的事情により試着が困難だったケース → 例外的に交換対応（責任者承認）
- 2024-XX-XX：贈答用で受取人が試着できず、開封後10日経過のケース → 商品状態確認のうえ判断
```

### 避ける
- 「臨機応変に対応」だけで判断基準がない
- エスカレーション基準が不明確で担当者が抱え込む
- 過去事例の蓄積がない（同じ判断を毎回ゼロベースで行う）

## 4成果物のクロスリファレンス

同じトピックでも、4成果物の文体は明確に違う。

| トピック | 公開FAQ | 商品ページ | チャットボット | 社内マニュアル |
|---|---|---|---|---|
| 返品 | 手順・例外を全網羅 | 「7日以内なら可能」と一文 | 「返品可能ですよ」＋手順チップ | 判断基準・テンプレ・エスカレーション |
| 配送日数 | 地域別の表 | 「関東1-2日」を端的に | 地域選択チップで案内 | 配送業者ごとの傾向、繁忙期注意 |
| アレルギー | 商品ごとに詳細 | 「主要原材料：○○」 | 商品名を聞いて成分回答 | アレルゲン対応の社内基準・記録ルール |

## 更新サイクル

| 成果物 | 更新頻度 |
|---|---|
| 公開FAQ | 月次見直し、ポリシー変更時は即時 |
| 商品ページQ&A | 商品追加・改修時に都度 |
| チャットボット | 四半期ごとシナリオ見直し、新顔の質問追加 |
| 社内マニュアル | 月次（個別事例の追加）、ポリシー変更時は即時 |

更新時は4成果物を必ずセットで見直し、齟齬を残さない。
