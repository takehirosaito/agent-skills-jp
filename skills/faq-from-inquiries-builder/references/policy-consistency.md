# ポリシー齟齬・回答ぶれの検出

問い合わせ履歴をFAQ化する際、過去の回答に齟齬がないか・現行ポリシーと矛盾しないかを必ず確認する。

## よくある齟齬パターン

### パターン1：返品期限の齟齬
- 過去回答A：「商品到着後5日以内」
- 過去回答B：「商品到着後7日以内」
- 過去回答C：「お客様都合の返品は不可」
- 現行ポリシー：「7日以内・未使用なら可」

**対応**：
- 最新ポリシー（7日以内・未使用）に統一
- ただし、過去にAやBで対応した顧客への影響は確認
- 古い特商法表示・利用規約も更新

### パターン2：送料負担の齟齬
- 過去回答A：「返品送料はお客様負担」
- 過去回答B：「初期不良なら当店負担」
- 過去回答C：「サイズ交換は当店負担」

**対応**：
- 「お客様都合」と「店舗起因」で分けて統一
- 例：「お客様都合の返品はお客様負担／初期不良・店舗起因は当店負担／サイズ交換は返送送料お客様負担、交換品送料は当店負担」

### パターン3：補償の齟齬
- 過去回答A：「次回利用クーポン500円」
- 過去回答B：「送料分の返金」
- 過去回答C：「商品代金1割の値引き」

**対応**：
- 状況別の補償基準を社内ルール化（`compensation-design.md` 参照）
- FAQには「補償の具体額」は明記せず、「ケースに応じてご対応します」に留めるのが安全
- ただし、配送遅延の補償ルールは明記しても良い（運用が安定している場合）

### パターン4：在庫・入荷時期の齟齬
- 過去回答A：「来週には入荷」
- 過去回答B：「再入荷未定」
- 過去回答C：「廃番」

**対応**：
- 商品ステータスをマスタで一元管理
- FAQには「最新の入荷状況は商品ページをご確認ください」と誘導
- 個別問い合わせには、その時点の最新情報のみで回答

### パターン5：法務的にグレーな回答
- 過去回答A：「シミに効きます」（化粧品）
- 過去回答B：「絶対に痩せます」（健康食品）
- 過去回答C：「業界No.1の品質」

**対応**：
- 即時にFAQから除外、過去回答も内部で訂正記録
- 化粧品は56効能範囲内に修正
- 健康食品はカテゴリ別の言える範囲に修正（トクホ・機能性表示・栄養機能・一般食品）
- No.1表記は根拠（調査主体・期間・対象・方法・出典）がない限り使わない
- 詳細は `yakki-keihyo-expression-check` スキル参照

## 検出手順

### Step 1：問い合わせ履歴を内容軸でクラスタリング
（`prioritization.md` 参照）

### Step 2：同じクラスタ内の過去回答を抽出
担当者A／担当者B／担当者C の回答を並べて比較。

### Step 3：齟齬の有無を判定

| 比較対象 | 齟齬の種類 |
|---|---|
| 返品期限の日数 | 数値齟齬 |
| 補償の金額・内容 | 補償基準齟齬 |
| 商品仕様の言い方 | 表現齟齬 |
| 法務的表現 | 法務齟齬 |

### Step 4：現行ポリシーと突き合わせ
- 利用規約・特商法表示・返品ポリシーを最新確認
- 担当者間で口頭ルール化されている運用も書き起こす

### Step 5：統一案を確定
- 法務面では現行ポリシーが優先
- 顧客対応面では「広く取れる方」が原則安全
- ただし、運用負荷・前例化リスクを考慮

### Step 6：過去回答の対象顧客への影響確認
- 過去にAで対応した顧客が再度問い合わせてきたとき、Bで対応すると不信感
- 「以前と回答が違う」と指摘される可能性
- 対応：「当店の運用ルールを最新化いたしました。今後は○○でご対応いたします」と説明

## 統一案ドキュメント化

検出した齟齬と統一案を以下の形でまとめる：

```
## 統一案：返品期限

### 現行ポリシー
- 期限：商品到着後7日以内
- 条件：未使用・タグ付き
- 送料：お客様都合の場合は返送送料お客様負担

### 過去回答との齟齬
- 2024-03-15：担当者A「5日以内」と回答 → 7日に統一
- 2024-05-22：担当者B「14日以内」と回答 → 7日に統一
- 2024-07-08：担当者C「不可」と回答 → 「条件満たせば可」に統一

### 対応
- FAQ・商品ページ・社内マニュアル・チャットボット全てを7日に統一
- 担当者全員に新ルールを共有・読み合わせ
- 過去のAやBで対応した顧客から再問い合わせがあった場合の対応スクリプトを準備
```

## ポリシー変更時のFAQ更新手順

1. 利用規約・特商法表示の改定タイミングを把握
2. 改定日の前後でFAQ・商品ページ・チャットボット・社内マニュアルを更新
3. 改定日前の注文には旧ポリシーを適用、改定日後は新ポリシーを適用（FAQに併記する場合もある）
4. 大幅変更時はメールマガジンで既存顧客に告知

## ポリシー齟齬を生まないための予防

- カスタマーサポート担当者全員が同じマニュアルを参照する
- 個別判断が必要な案件は責任者・チームへ相談（担当者が独断で口頭ルール化しない）
- 月1回の担当者ミーティングで対応事例を共有
- 新人研修時にFAQ・マニュアルの読み合わせ
- 担当者の回答ログを四半期に1回サンプリング監査

## 法務関連の齟齬は最優先で修正

法務齟齬（薬機法・景表法違反の可能性のある回答）は、他の齟齬より優先して即時修正。

- 化粧品で「治る」「効く」「アンチエイジング」を使った回答
- 健康食品で「痩せる」「血圧が下がる」を使った回答（届出文言外）
- 「No.1」「最安」「絶対」「保証」「完全」を含む回答
- ステマ規制対象（広告主の表示としてPR表記がない投稿の言及）

これらは過去回答も内部で訂正記録を残し、将来のFAQ化候補から除外する。
