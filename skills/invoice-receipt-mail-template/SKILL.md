# 領収書・請求書・インボイス メールテンプレート

## 概要

ECのお客様から届く「領収書発行希望」「インボイス対応してますか」「宛名を変えてほしい」「再発行してほしい」等の依頼に対するメール返信、および社内向けの案内文を、インボイス制度（2023.10.1〜）の6要件・経過措置・電子帳簿保存法（電帳法）を踏まえて作成する。

## ★最重要原則

**「インボイス（適格請求書）」と「領収書／請求書」を混同しない。** 適格請求書は要件を満たした書類で、登録番号（T+13桁）と特定の記載要件が必要。一方、領収書・請求書はこの要件を満たさなくても発行可能。**顧客の依頼内容が「単に領収書がほしい」のか「適格請求書が必要（仕入税額控除のため）」のかを最初に切り分ける**。

- 楽天・Amazon・Yahoo・自社ECのインボイス発行機能の差異：`references/mall-invoice-rules.md`
- メールテンプレート集（発行依頼／再発行／宛名変更／インボイス未対応／免税事業者の説明）：`references/email-templates.md`

要点（本ファイルに留める）：

### 適格請求書の6記載要件

1. **発行事業者の氏名（名称）と登録番号（T+13桁）**
2. **取引年月日**
3. **取引内容**（軽減税率対象は「※」等で明示）
4. **税率ごとの対価額（税抜 or 税込）と適用税率**
5. **税率ごとの消費税額**
6. **書類の交付を受ける事業者の氏名（宛名）**

### 簡易インボイス（EC通販・小売向け）

EC通販・小売・飲食店等の不特定多数を相手とする事業者は、簡易インボイスで足りる：

- **宛名不要**
- 税額または税率の**どちらか一方**でOK
- 上記の他は通常のインボイスと同じ

EC通販では多くの場合、簡易インボイスで運用可能。

### 経過措置（仕入税額控除の段階的減額）

| 期間 | 免税事業者からの仕入の控除率 |
|---|---|
| 2023.10.1 〜 2026.9.30 | 80% |
| 2026.10.1 〜 2029.9.30 | 50% |
| 2029.10.1 〜 | 0%（完全廃止） |

**現在は2026年5月時点で、80%控除期間内**。2026.10からは50%に減額される。

### 免税事業者（インボイス未登録）の対応

- 登録番号がない事業者は適格請求書を発行できない
- 「インボイス対応」とは謳えないが、「領収書／請求書は通常通り発行可能」
- 顧客から仕入税額控除目的で適格請求書を求められた場合は、未登録である旨を率直に伝える

### 電子帳簿保存法（電帳法）との関係

- 2024.1〜電子取引データの電子保存が完全義務化
- EC通販でメール送付するPDF領収書は電帳法上の電子取引データに該当
- 保存期間：原則7年（欠損繰越時10年）
- 検索要件：取引年月日・取引金額・取引先で検索可能

## 処理フロー

### Step 1：依頼内容の正確な切り分け

ユーザー（顧客）の依頼を以下のどれかに分類：

| 依頼種別 | 典型文言 | 必要対応 |
|---|---|---|
| 領収書の発行 | 「領収書ください」「お会社用に」 | 簡易インボイス or 通常領収書 |
| 適格請求書の発行 | 「インボイスで」「適格請求書」「登録番号入りで」 | 簡易インボイスで足りるか確認 |
| 宛名変更 | 「個人名→社名で」 | 既発行分の再発行 |
| 但し書き変更 | 「品代→消耗品費で」 | 但し書き変更の上で再発行 |
| 再発行 | 「紛失したので」「データで」 | 再発行＋電帳法対応 |
| インボイス対応可否 | 「御社はインボイス出せますか」 | 登録番号の有無を返信 |

### Step 2：自社の対応状況の確認

- 自社が適格請求書発行事業者登録済みか
- 登録番号（T+13桁）
- インボイス発行のシステム対応状況（モール側／自社EC側）

### Step 3：モール側の機能確認

`references/mall-invoice-rules.md` 参照：

- 楽天：注文ごとの領収書PDF発行機能、適格請求書発行事業者番号設定欄
- Amazon：購入履歴から領収書ダウンロード、ビジネスアカウント向けの追加機能
- Yahoo：取引ナビ経由の発行
- 自社EC（Shopify／makeshop等）：ストア管理画面の領収書機能、外部サービス連携

### Step 4：返信文の生成

`references/email-templates.md` のテンプレートを選択し、依頼内容・顧客属性（個人／法人）・自社対応状況・モールに応じてカスタマイズ。

含めるべき要素：

- 依頼への回答（発行可・不可）
- 必要な情報（宛名・但し書き・送付先）
- 発行方法（マイページDL／PDF送付／郵送）
- 想定所要時間
- 電帳法対応の案内（電子保存の推奨）
- インボイス未対応の場合は経過措置の説明

### Step 5：法令・実務チェック

- 6要件すべてが記載されているか（簡易インボイスは宛名・税額/税率のいずれかが省略可）
- 登録番号の桁数・形式（T+13桁の数字）が正しいか
- 経過措置の控除率を誤って伝えていないか
- 個人情報（取引履歴・他顧客情報）が混入していないか

## 品質ゲート

- [ ] 依頼内容を「領収書」「インボイス」「宛名変更」「再発行」のどれか明確に判定している
- [ ] 自社の登録番号有無を確認している
- [ ] 簡易インボイスで足りるEC通販ケースで通常インボイス要件を過剰に求めていない
- [ ] 経過措置の控除率（現在80%、2026.10から50%）を正しく説明している
- [ ] 登録番号の表記（T+13桁の数字）が正しい
- [ ] 個人情報・他顧客情報が紛れ込んでいない
- [ ] 電帳法の保存要件（電子保存・検索要件）に触れている

## エッジケース

- **個人事業主顧客が法人成りした** → 旧領収書の宛名変更可否は税務上の論点、税理士確認推奨と案内
- **海外顧客** → インボイスは国内取引向け、輸出取引は別の証憑（インボイスとは別）
- **キャンセル・返品時の処理** → 適格返還請求書（返還インボイス）の発行が必要、扱いは別途
- **クレジットカード明細との関係** → カード明細は領収書扱いではないが、適格請求書要件を満たすかは個別
- **モール側の自動発行PDFが要件不足** → 自社で補完PDF発行 or モールサポートへエスカレ

## 注意事項

- インボイス制度は毎年経過措置の段階が変わる。最新は国税庁のインボイス公式情報を確認
- 電帳法は2024.1完全義務化。電子取引データの紙保存は不可
- 税務判断（仕入税額控除の可否等）は税理士確認を前提に案内
- 顧客の取引履歴・他顧客情報を返信に含めない
