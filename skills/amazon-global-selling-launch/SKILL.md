# Amazon Global Selling 越境出品 立ち上げ設計

## 概要

日本のセラーが Amazon Global Selling を使って海外マーケットプレイス（主に北米 amazon.com、必要に応じて欧州・その他）へ出品を立ち上げる際の、登録〜税務〜物流〜出品オペレーションの全工程を段取り化するスキル。「何から手をつけるか」「どの論点を潰しておくべきか」を抜け漏れなく整理し、立ち上げの手戻りと税務リスクを減らす。

このスキルは**英語の商品文面そのものは作らない**（それは `amazon-us-localization-jp-brand`）。立ち上げの設計・チェックリスト・意思決定の補助に特化する。

## 最重要原則

**「税務とアカウント健全性を最初に設計する／手数料・税率は必ず公式最新値で確認する／FBA輸出か自社発送かを数値で選ぶ／国内の成功パターンをそのまま英訳しない」**。越境は税務（米国売上税ネクサス、各国VAT、EORI、源泉）とアカウント停止リスクの設計を後回しにすると致命傷になる。本スキルが出す数値・税率は一般的な枠組みであり、確定情報は Seller Central と各国税務当局・専門家で確認する。

## 知識ベース

立ち上げの主要レイヤー：

| レイヤー | 主な論点 |
|---|---|
| アカウント | 出品プラン（大口/小口）、北米統合アカウント、本人確認(KYC)、ブランド登録(Brand Registry) |
| 税務 | 米国 売上税ネクサス/マーケットプレイス徴収、W-8BEN-E、欧州VAT・EORI（欧州展開時）、日本側の輸出免税 |
| 決済 | Amazon Currency Converter for Sellers (ACCS) か 現地銀行口座/Payoneer等 |
| 物流 | FBA輸出（日本→海外FC）/ 現地FBA在庫納品 / 自社海外発送(MFN) の選択 |
| 商品 | UPC/GTIN、出品制限カテゴリ、各国の規制・表示(FCC/CE等の対象可否)、ローカライズ計画 |

北米マーケットプレイスは amazon.com（米）/.ca（加）/.com.mx（墨）が**北米統合アカウント**で横断出品可能。欧州は別アカウント体系＋VAT/EORIが絡むため難易度が一段上がる。最初は北米・米国単独から始めるのが定石。

> 数値（手数料率・販売手数料・FBA料金・各国VAT率・ネクサス基準額）は頻繁に改定される。本スキルは「確認すべき項目」を提示し、確定値は必ず公式で取得させる。

## 処理フロー

### Step 1：目的とフェーズの確認
ユーザーから確認（不足は仮定して明示）：
- 進出先（まず米国だけ／北米3カ国／欧州含む）
- 商材カテゴリと規制該当性（食品・化粧品・電気用品・玩具・バッテリー等は要注意）
- ブランド有無・商標（米国/対象国での出願状況）
- 物流の現状（自社倉庫/3PL、海外発送経験）
- 月商目標と在庫数

不明時は「米国単独・一般雑貨・商標未出願・FBA前提・小規模スタート」を仮置きし冒頭で明示。

### Step 2：アカウント設計
- 出品プラン選定（継続出品なら大口）
- KYC 書類（登記/本人確認/クレジットカード/銀行情報）の準備リスト化
- ブランド登録の要否（商標登録番号が前提。未出願なら出願から逆算）

### Step 3：税務論点の洗い出し
- 米国：マーケットプレイス徴収税（Marketplace Facilitator）で多くの州はAmazon側徴収だが、ネクサス・物品税の論点は残る。W-8BEN-E の提出。
- 欧州展開時：国別VAT登録・EORI・IOSS の要否。
- 日本側：輸出免税の要件、消費税還付の可能性。
- → 「専門家確認が必要な項目」を明示してエスカレーション。

### Step 4：物流方式の選択（FBA輸出 vs MFN）
- FBA：手数料は高いが Prime 対象・CV率・カスタマー対応を Amazon が担保。
- MFN（自社海外発送）：送料・関税・配送日数・返品コストを自社負担。
- → 商品重量・単価・回転率で簡易比較表を出す（下記出力フォーマット）。

### Step 5：商品データ準備計画
- UPC/GTIN 手配、カテゴリ出品許可申請の要否
- ローカライズ計画（文面作成は `amazon-us-localization-jp-brand` へ連携）
- 価格設計（為替・手数料・関税・目標粗利からの逆算）

### Step 6：立ち上げチェックリスト＆リスク
- ローンチ前チェック、初期レビュー獲得方針（規約準拠）、アカウント健全性指標(ODR等)の監視計画。

## 出力フォーマット

```
# Amazon Global Selling 立ち上げ設計：[ブランド/商材]

## 0. 前提（確認/仮定）
## 1. フェーズ計画（米国単独→北米→欧州 の段階）
## 2. アカウント・ブランド登録 ToDo
## 3. 税務論点と専門家確認事項（★要確認を明示）
## 4. 物流方式の判断（FBA輸出 / 現地FBA / MFN 比較表）
   | 方式 | 送料/手数料感 | 配送日数 | 返品対応 | 向く商材 |
## 5. 商品データ・価格設計
## 6. ローンチ前チェックリスト
## 7. リスクと監視指標（ODR・在庫・為替）
```

## 品質ゲート
- 税率・手数料を断定していないか（必ず「公式確認」を付す）
- 規制カテゴリ（食品/化粧品/電気/バッテリー等）の該当チェックを促したか
- FBA/MFN を主観でなく商材特性で比較したか
- 商標・ブランド登録の前提条件を明示したか

## 注意事項
- 本スキルは税務・法務の助言を確定するものではない。重要判断は各国税務当局・通関士・弁理士・専門家に確認する。
- 「最安」「必ず売れる」等の断定や誇大表現は使わない。
- 日本国内向けの表現規制（景表法・薬機法）に加え、進出先の表示規制も別途確認が必要。
