# クレームエスカレーション判定基準

担当者が単独判断してよいか、責任者・経営・法務に上げるかの目安。

## 3段階レベル

### レベル1：担当者完結
- 軽微な質問
- 規約内で完結する返品・交換
- 配送状況の問い合わせ
- 初期不良（明らかな不良で交換・返金が規約に沿う）
- サイズ違い・色違い（規約に沿う返品交換）

担当者は記録（CRM・問い合わせ管理）を残し、自分の判断で完結させる。

### レベル2：責任者確認
- 補償が規約を超える可能性（送料・キャンセル料の例外負担）
- 同一顧客から繰り返しクレーム（過去履歴の確認必要）
- 商品の本質的不満（味・香り・サイズ感などの主観的クレーム）
- 配送遅延が長期化（3日以上）
- レビュー投稿前のクレーム
- 他社競合商品との比較を含むクレーム
- 価格表示・キャンペーン解釈の食い違い

責任者の決裁を仰ぎ、返信前に内容確認。

### レベル3：経営／法務エスカレーション
- 健康被害・人身事故の訴え（PL責任の可能性）
- 訴訟・弁護士介入の示唆
- SNS拡散・メディア露出の脅し
- 消費者センター・国民生活センターに通報したとの連絡
- 個人情報漏えい・誤配送による情報流出疑い
- ハラスメント・恫喝・継続的迷惑行為
- 規約違反（転売目的の大量購入後の返品要求 等）
- 警察・行政機関からの照会

経営層・法務（顧問弁護士／薬事コンサル）・必要に応じてPL保険会社に連絡。担当者は単独で返信せず、対応方針確定後にスクリプト読みで対応。

## PL責任の判断軸

「健康被害があった」「使用してケガをした」等の訴えがあった場合：

1. **即時：使用中止と医師受診の案内**（法的判断は別として、安全優先）
2. **事実関係の聞き取り**：使用方法・状況・症状・受診の有無
3. **記録保全**：問い合わせ内容・商品ロット番号・配送日
4. **責任者・法務・PL保険会社へ即時報告**
5. **担当者単独で「補償します」「責任を認めます」と返答しない**
6. **同時に「責任を認めません」とも言わない**。事実確認中の段階に留める

返信例（初動）：
```
このたびは[症状の概要]とのこと、心よりお見舞い申し上げます。
まずはご無理をなさらず、必要に応じて医療機関へご相談いただけますと幸いです。

ご使用の状況および商品ロットを確認のうえ、社内でしかるべき対応を
検討させていただきます。事実関係の確認のため、お手数ですが
以下の点についてお知らせいただけますでしょうか。

- 商品の購入日・ご使用開始日
- 商品本体ラベルのロット番号
- ご症状の発生日と現在の状況
- 医療機関のご受診有無

ご返信いただきました内容は、責任者にて確認のうえ、改めてご連絡いたします。
```

## SNS拡散・脅迫の対応

### パターン1：レビュー投稿前提のクレーム
- 「対応次第でレビューを書きます」
- 規約に沿った範囲で対応し、レビューを理由に補償を拡大しない
- 楽天・Amazon等のレビュー誘導禁止規約に抵触する応答（レビュー削除依頼・特典提供）は絶対にしない

### パターン2：SNS拡散の示唆
- 「Twitter／Xに書きます」「Googleレビューに書きます」
- 感情的にならず、規約と事実に沿った対応に終始
- 責任者にエスカレーション、必要に応じて拡散時の準備（声明文ドラフト・モニタリング）

### パターン3：恫喝・継続的迷惑行為
- 過剰要求・人格攻撃・電話の繰り返し
- 担当者を交代せず、責任者に切り替え
- 「お客様からのご要望は承りましたが、当店としては規約に沿った対応となります」で一貫
- 業務妨害に発展する場合は警察・弁護士相談

## 補償判断のフレーム

| 状況 | 暫定方針 | エスカレーション |
|---|---|---|
| 初期不良（明確） | 交換または返金、送料当店負担 | レベル1 |
| 配送中破損 | 配送業者損害賠償の有無確認後に交換 | レベル1〜2 |
| 配送遅延（運送会社起因） | 状況確認・キャンセル可否案内 | レベル1 |
| 配送遅延（店舗側起因） | お詫び＋クーポン等の補償検討 | レベル2 |
| 誤配送（個人情報含む） | 即時回収・謝罪・情報漏洩判断 | レベル3 |
| サイズ・イメージ違い（規約内返品） | 規約どおり対応 | レベル1 |
| サイズ・イメージ違い（規約外） | 個別判断 | レベル2 |
| 健康被害の訴え | 受診案内＋事実確認 | レベル3 |
| 価格表示ミス | 表示価格で販売するか取引解除（民法上の意思表示の錯誤も検討） | レベル2〜3 |

## 過去履歴を確認すべきサイン

- 同一顧客から3回以上の苦情
- 過去にキャンセル・返品が極端に多い顧客
- 高額商品の連続返品
- 競合店舗にも同種クレームを入れている噂

特定商取引法・古物営業法の観点で「悪質な転売・常習返品」と判定できる場合は、規約上の出荷拒否（取引お断り）も検討対象。判断は責任者へ。

## 記録すべき項目（CRM・問い合わせ管理）

- 受信日時／チャネル／注文番号
- 顧客名（モール上の表示名）
- クレーム内容の要約
- 確認した事実（配送追跡・在庫状況・過去履歴）
- 返信内容のスナップショット
- エスカレーションレベル
- 補償の有無・金額
- 完了日時

これにより、再発防止と過去履歴の参照が可能になる。
