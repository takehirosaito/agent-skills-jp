# 返信文テンプレ集

代表的な5シーンの文面テンプレ。`[ ]` 部は実情に応じて置換。

## 1. 受注前質問（在庫・サイズ・素材）

````
件名：【○○ショップ】[商品名] についてのお問い合わせ

[お客様名]様

お問い合わせいただきまして誠にありがとうございます。
[商品名]についてご質問の件、以下のとおりご回答いたします。

■ [質問の要点]
[回答]

■ 補足
[サイズ感／素材／使用感／お手入れ方法など、関連情報]

ご不明な点がございましたら、お気軽にお問い合わせください。
ご検討のほどよろしくお願いいたします。

○○ショップ
担当：[担当者名]
````

## 2. 在庫切れ・再入荷時期未定

````
件名：【○○ショップ】[商品名] の在庫状況につきまして

[お客様名]様

お問い合わせいただきありがとうございます。
[商品名]の在庫状況についてご案内いたします。

現在、[商品名/サイズ/カラー]につきましては在庫を切らしており、次回入荷時期も未定となっております。
お待たせしておりますお客様にご案内できず、誠に申し訳ございません。

【ご提案】
1. 入荷次第のメール通知（ご希望の場合は当アドレスへご返信ください）
2. 同等品 [類似商品名] のご案内：[URL/商品コード]
3. ご要望が多数いただけている旨は、メーカーへ追加生産の打診をさせていただきます

恐れ入りますが、上記いずれかでご検討いただけますと幸いです。

○○ショップ
店長 □□
````

## 3. 配送遅延（運送会社側の理由）

````
件名：【○○ショップ】ご注文商品の配送状況につきまして（注文番号：[xxxxx]）

[お客様名]様

いつもありがとうございます。
ご注文番号 [xxxxx] の[商品名]の配送につきまして、お届けが遅れており大変申し訳ございません。

■ 現在の状況
配送業者（[△△運輸]）に確認しましたところ、
「[最終追跡情報・通過センター]」となっております。
[原因：天候／物量集中／システム不具合 等を簡潔に]

■ 当店の対応
1. 配送業者へ追跡継続を依頼しており、最新の見込みが分かり次第ご連絡いたします
2. お急ぎの場合は、以下のいずれかをお選びいただけます
   ・受け取り辞退・キャンセル（送料当店負担、返金まで[○]営業日）
   ・同等商品の優先発送（在庫確認のうえ手配）

ご希望をお知らせいただけますと、すぐに手配いたします。
ご不便をおかけし、重ねてお詫び申し上げます。

○○ショップ 店長 □□
````

## 4. 初期不良・破損（返品交換）

````
件名：【○○ショップ】[商品名] の不具合につきまして（注文番号：[xxxxx]）

[お客様名]様

このたびはご注文いただきました[商品名]に不具合があったとのこと、
ご不便をおかけし誠に申し訳ございません。
状況をご連絡いただきありがとうございます。

【ご対応について】
初期不良として、以下のとおり対応させていただきます。

1. 同一商品の交換品を本日[または日付]発送
2. お手元の商品は、同梱の着払い伝票にて[配送業者]へお返却ください
3. 返送送料は当店負担とさせていただきます

【お願い】
お手数ですが、可能でしたら不具合箇所の写真を1〜2枚お送りいただけますでしょうか。
今後の品質管理に活用させていただきます（任意です）。

ご迷惑をおかけし重ねてお詫び申し上げます。

○○ショップ
カスタマーサポート □□
````

## 5. クレーム初動（事実関係未確認）

````
件名：【○○ショップ】[商品名] についていただきましたご指摘につきまして

[お客様名]様

このたびはご不快な思いをおかけし、誠に申し訳ございません。
お知らせいただきました件、店舗内で事実関係を確認のうえ、
責任を持って改めてご連絡を差し上げます。

■ ご返答までの期限
[○月○日]までに、確認結果と当店からのご提案をお送りいたします。

■ 確認のためお伺いしたい点
- [配送状況／到着時の状態／使用状況 等、必要最小限のみ]

恐れ入りますが、上記についてご返信いただけますと幸いです。
ご迷惑をおかけし、心よりお詫び申し上げます。

○○ショップ 店長 □□
````

クレーム本対応は責任者の判断を仰いだうえで、補償範囲を明示して送る。`references/escalation-criteria.md` を参照。

## 6. 規約根拠でのお断り（やや強め）

````
件名：【○○ショップ】[商品名] の返品ご要望につきまして（注文番号：[xxxxx]）

[お客様名]様

このたびはお問い合わせいただきありがとうございます。
ご要望いただきました返品の件、以下のとおりご案内いたします。

【当店の返品規定】
当店では、お客様のご都合による返品は商品到着後[○日]以内、
かつ未開封・未使用に限りお受けしております（送料はお客様ご負担）。

今回ご相談の[商品名]は、[ご使用後／到着から○日経過／開封済み 等]のため、
誠に恐れ入りますが、返品はお受けいたしかねます。

ご希望に沿えず申し訳ございませんが、何卒ご理解いただきますようお願い申し上げます。
なお、商品自体の不具合（初期不良）でしたら、別途ご対応させていただきますので
お知らせください。

○○ショップ 店長 □□
````

## 短文版（チャット／モール内メッセージ用）

### 在庫切れ
```
お問い合わせありがとうございます。○○は現在在庫を切らしており、
次回入荷は未定です。再入荷のメール通知をご希望でしたらお知らせください。
類似品として△△もございます。
```

### 配送遅延
```
ご連絡ありがとうございます。配送業者に確認のうえ、本日中に追跡状況を
ご報告いたします。お待たせし申し訳ございません。
```

### 受注後変更（出荷前）
```
ご連絡ありがとうございます。現在出荷前のため、ご希望の[サイズ／住所等]
変更を承りました。発送時に改めてご連絡いたします。
```
