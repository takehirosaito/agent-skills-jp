# チャネル別トーン使い分けガイド

EC問い合わせ返信は、購入チャネルごとに買い手の期待値と運営側の名乗り方が異なる。返信文の冒頭・署名・敬語レベルをチャネルで切り替えるのが基本。

## 楽天市場

### 期待されるトーン
- 「店長」名義の親近感
- 「いつもありがとうございます」「またのご利用をお待ちしております」のリピート前提
- お祭り・キャンペーンの空気感を引き継ぐ

### 冒頭定型
- 「いつも○○ショップをご利用いただき誠にありがとうございます。」
- 「お問い合わせいただきまして誠にありがとうございます。」
- 「店長の□□でございます。」（クレーム時・大型対応時は責任者名で）

### 署名
```
○○ショップ
店長 □□（または担当 △△）
営業時間：平日10:00-17:00
楽天市場店：https://www.rakuten.co.jp/xxx/
```

### 注意
- 「ご注文番号」は楽天の表記に合わせる
- レビュー特典・ポイント還元の約束は規約違反になる場合がある（次回利用クーポン等の許容範囲のみ）
- 違反点数制度（35点で違反レベル1、レベル5で契約解除）があるため、過剰な値引き・補償の安易な約束はリスク

## Amazon.co.jp（セラーセントラル経由）

### 期待されるトーン
- 事務的・簡潔・必要情報のみ
- 個人名は出さない店舗が多い（店舗名のみで完結）
- 「Amazon.co.jpでご注文いただいた」と明示

### 冒頭定型
- 「Amazon.co.jp でご注文いただいた商品について、ご連絡いたします。」
- 「お問い合わせいただきありがとうございます。」

### 署名
```
○○ストア
（カスタマーサポート窓口）
```

### 注意
- A-to-z 保証申請・チャージバックに発展する案件は購入者保護が優先される
- メッセージ内に外部URL・電話番号・メールアドレスを記載することは原則禁止（規約で制限あり）
- 24時間以内の初回返信がメトリクスに影響する
- 商品レビュー誘導・否定的レビュー削除依頼は禁止

## Yahoo!ショッピング

### 期待されるトーン
- 楽天と自社ECの中間
- 親しみやすさは保ちつつ、楽天ほど店長色を強調しない

### 冒頭定型
- 「ご注文いただきありがとうございます。」
- 「○○ストアでございます。」

### 署名
```
○○ストア
担当：△△
営業時間：平日10:00-17:00
```

### 注意
- 優良配送・PayPayステップを意識した運用が必要（注文+2日以内着、出荷遅延率5%未満、ストア都合キャンセル率2.5%未満）
- 評価依頼の文言は規約に従う

## 自社EC（Shopify／futureshop／MakeShop／BASE 等）

### 期待されるトーン
- ブランドの世界観に揃える
- 一人称（弊社／私ども／スタッフ一同）と語尾を統一
- リピート前提のブランドは「お客様」より「○○様」を選ぶ

### 冒頭定型（ブランド調・例）
- 「いつも○○をご愛顧いただき、誠にありがとうございます。」
- 「○○カスタマーサポートの□□です。」

### 署名
```
○○ オンラインストア
カスタマーサポート □□
support@example.com
営業時間：平日10:00-17:00
```

### 注意
- 自社EC は問い合わせフォーム・公式LINE・メール窓口の窓口統一が崩れやすい。返信時にどの窓口経由かを記録
- ブランドのトーン＆マナーガイドがある場合はそれに従う
- リピーター向けと新規向けで冒頭を切り替えると満足度が上がる

## メルカリShops／BASE／STORES

### 期待されるトーン
- 個人事業主・小規模ブランドが多く、フランクすぎず固すぎず
- 「ショップオーナーの○○です」の名乗りでOK

### 注意
- 個人売買色が強いため、返金・交換の規約整備が不十分なケースが多い。安易な約束はトラブルの元

## 共通：避けるべき表現

| 避ける | 理由 | 代替 |
|---|---|---|
| 「ご認識違い」 | 顧客の落ち度を匂わせる | 「情報の行き違いがあり申し訳ございません」 |
| 「お客様の都合」 | 突き放した印象 | 「ご都合により」「ご事情により」 |
| 「確認のうえご連絡ください」 | 顧客に丸投げ | 「お手数ですが、○○についてお知らせいただけますでしょうか」 |
| 「対応できません」だけ | 代替案がない | 「ご希望に沿えず申し訳ございません。代替として○○をご提案いたします」 |
| 「必ず」「絶対」「保証」 | 確約できないものを断定 | 「現時点では○○の予定です」「○○次第ですが」 |
| 「個人の感想です」 | 法的根拠にならず | 効能訴求自体を避ける |

## 敬語レベルの目安

| シーン | レベル |
|---|---|
| 受注前質問・軽い確認 | 丁寧語＋謙譲語 |
| 配送遅延・在庫切れ謝罪 | 二重敬語にならない程度の丁重語 |
| クレーム初動 | 最丁重（「ご迷惑をおかけし」「謹んでお詫び」） |
| 規約根拠でのお断り | 丁寧かつ毅然（「ご要望には沿いかねます」） |

二重敬語（「お伺いさせていただきます」「ご拝読ください」等）は避ける。
