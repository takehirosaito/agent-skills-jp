# eBay 出品最適化（日本セラー向け）

## 概要

日本のセラーが eBay で越境販売する際の出品（リスティング）最適化を設計するスキル。eBayの検索（Best Match / 旧称 Cassini）で評価される要素——タイトルのキーワード、Item Specifics、カテゴリ、価格・送料・返品・ハンドリングタイム・セラー評価——を、日本からの発送実務（関税・配送日数・トラブル対応）まで含めて設計する。

## 最重要原則

**「タイトル80字を英語キーワードで埋め切る／Item Specifics は可能な限り全部埋める／検索順位は出品要素＋取引実績(評価・配送遵守)の総合で決まる／送料と関税の方針を明確にしてトラブルを防ぐ」**。eBayは Item Specifics の充足と取引品質を重く見る。日本セラーは「配送日数の長さ」「関税」「英語対応」で評価を落としやすいので、ポリシー設計で先回りする。

## 知識ベース

最適化の主要要素：

| 要素 | ポイント |
|---|---|
| タイトル(80字) | ブランド・型番・主要属性・用途キーワードを英語で。記号の乱用や無関係語は避ける |
| Item Specifics | Brand/Type/Color/Size/Material/MPN 等を最大限埋める（検索フィルタの母数になる） |
| カテゴリ | 最適カテゴリを選ぶ。誤カテゴリは露出減・違反リスク |
| 価格形式 | Buy It Now（固定）/ Auction（競り）/ Best Offer の使い分け |
| 送料/関税 | eBay International Shipping(eIS) 等の活用、DDU/DDPの考え方、配送日数明示 |
| ポリシー | 返品可否・ハンドリングタイム短縮（発送遵守率に直結） |
| 評価(Feedback) | 初期評価の積み上げ、取消・遅延を出さない運用 |

> 手数料(Final Value Fee)、ストア(Store)プラン、eIS等の仕様・名称は改定される。確定は eBay 公式で確認。

## 処理フロー

### Step 1：商材と現状の確認
- 商材（ブランド品/型番品/ハンドメイド/中古 等）、対象国、現在の出品数・評価・販売制限(Selling Limits)
- 既存リスティングの有無（改善か新規か）
不明時は「型番ありの新品・米国中心・固定価格・eIS利用」を仮置きし明示。

### Step 2：タイトル設計（80字）
- 構文例：`Brand + Model/MPN + 主要属性(色/サイズ/素材) + 用途/対象 + 状態`
- 検索ボリュームのある英語語を前方に。スパム的羅列・全大文字は避ける。

### Step 3：Item Specifics 充足
- カテゴリ別の必須/推奨 Specifics をリスト化し、未入力を潰す。MPN/GTINがあれば必ず入れる。

### Step 4：価格・送料・関税方針
- 価格形式の選択、送料は実費反映 or 送料込み、関税はDDU（受取人負担）を基本に説明文で明示。
- 高単価はeIS等でトラッキング・補償を確保。

### Step 5：ポリシー・評価対策
- ハンドリングタイム短縮、返品ポリシー、INR(未着)/SNAD(不一致)を防ぐ説明と梱包。

### Step 6：チェックリスト
- 出品前チェック、Selling Limits の余裕、禁止/制限品の確認。

## 出力フォーマット

```
# eBay リスティング最適化：[商材]

## 0. 前提（確認/仮定）
## 1. タイトル案（80字以内・複数案＋字数）
## 2. Item Specifics 充足表（項目→入力値→未入力リスク）
## 3. カテゴリ選定
## 4. 価格・送料・関税方針（DDU/DDP・配送日数明示）
## 5. ポリシー（返品/ハンドリング）と評価対策
## 6. 出品前チェックリスト
```

## 品質ゲート
- タイトルが80字を有効に使い、スパム語/無関係語が無いか
- Item Specifics の必須項目が埋まっているか
- 送料・関税・配送日数を説明文で明示し、トラブルを先回りしているか
- 禁止/制限品・Selling Limits を確認したか

## 注意事項
- 偽ブランド・知財侵害・規制品の出品は不可。真贋・権利を必ず確認。
- 手数料・ポリシー・機能名は変動するため公式で確認する。
- 「世界最安」「確実に高評価」等の断定はしない。
