# LTV計算とコホート分析

EC事業のリピート性能を測る指標。月次レポートでは月単位のスナップショット、四半期で深堀り。

## LTV（Lifetime Value）の基本式

### シンプル式
```
LTV = 平均購買単価 × 購買頻度 × 継続期間
```

例：
- 平均購買単価 10,000円
- 購買頻度 4回／年
- 継続期間 2年
- LTV = 10,000 × 4 × 2 = **80,000円**

### 粗利ベースのLTV
```
LTV（粗利ベース） = 平均購買単価 × 購買頻度 × 継続期間 × 粗利率
```

上の例で粗利率40%なら：
- 80,000 × 0.4 = **32,000円**

### 期間限定LTV（3ヶ月LTV／12ヶ月LTV）
```
3ヶ月LTV = 初回購入後3ヶ月以内の累計購入金額の平均
```

短期で観測しやすいが、長期顧客の実力を見るには物足りない。

### CAC回収期間（Payback Period）
```
CAC回収期間 = CAC ÷ 月次LTV
```
- 単位：ヶ月
- 12ヶ月以内回収が健全（業種で変動）

## LTV/CAC比

```
LTV/CAC比 = LTV ÷ CAC
```

| LTV/CAC比 | 評価 |
|---|---|
| 1倍未満 | 赤字、急務で対策 |
| 1-3倍 | 改善余地大、CAC削減 or LTV向上 |
| 3倍 | 業界目安、健全水準 |
| 3-5倍 | 良好 |
| 5倍超 | CAC上げて新規獲得加速の余地 |

## コホート分析

### コホート（Cohort）とは
同じ時期に初購入した顧客グループ。「2024年4月初購入グループ」「2024年5月初購入グループ」のように区切る。

### コホート別リピート率テーブル

```
| 初購入月 | 顧客数 | 1ヶ月後 | 2ヶ月後 | 3ヶ月後 | 6ヶ月後 | 12ヶ月後 |
|---|---|---|---|---|---|---|
| 2024-01 | 200 | 25% | 18% | 15% | 12% | 10% |
| 2024-02 | 220 | 28% | 20% | 16% | 13% | 11% |
| 2024-03 | 250 | 30% | 22% | 17% | 14% | 12% |
| 2024-04 | 240 | 32% | 24% | 18% | 15% | - |
| 2024-05 | 260 | 30% | 23% | - | - | - |
```

- 縦方向：時系列で初購入コホートが並ぶ
- 横方向：そのコホートが各経過期間にリピートした割合

### コホート分析で見るもの

1. **新しいコホートのリピート率が改善しているか**
   - 縦に見て改善していれば、新規流入の質が良くなっている
   - 悪化していれば、新規獲得の質低下（広告ターゲティング・LP・初回体験）

2. **特定の経過期間で離脱が大きいか**
   - 横に見て、初回〜1ヶ月の離脱が大きければ初回体験の改善
   - 6-12ヶ月で離脱が大きければリピート施策の見直し

3. **コホート別の累積購入金額（コホート別LTV）**
   - 同じ期間経過時点での累積購入金額をコホート別に比較

### コホート別LTVテーブル
```
| 初購入月 | 1ヶ月累計 | 3ヶ月累計 | 6ヶ月累計 | 12ヶ月累計 |
|---|---|---|---|---|
| 2024-01 | 8,000 | 15,000 | 22,000 | 32,000 |
| 2024-02 | 8,500 | 16,000 | 24,000 | 35,000 |
| 2024-03 | 9,000 | 17,500 | 25,000 | - |
```

新しいコホートほど数値が上がっていれば、施策が成功している。

## リピート率の改善施策

### 初回〜1ヶ月の離脱対策
- 購入直後のサンキューメール（規約内）
- 商品到着の翌日に使い方ガイドを送る
- 開封・使用時の感動体験設計（同梱・パッケージング）
- 2回目購入特典（次回○%OFFクーポン）

### 1-3ヶ月の離脱対策
- リマインダーメール／LINE（前回購入から1ヶ月）
- 関連商品の提案
- 顧客の購買周期に合わせた配信タイミング

### 6-12ヶ月の離脱対策
- 季節商品の案内
- 周年メッセージ
- ロイヤルティプログラム（会員ステージアップ）

### 12ヶ月以降の離脱対策
- 休眠復活キャンペーン（クーポン）
- 過去の購買履歴に基づくパーソナル提案
- LINE登録誘導でリーチ手段を増やす

```
- ただしCAC（CPA）上昇により LTV/CAC比は8.9→8.0に悪化

```

## コホート分析の落とし穴

### 落とし穴1：データ期間の偏り
新しいコホートはまだ十分な観測期間がない。「2024-11コホートの3ヶ月後リピート率は10%」という数字が真の傾向ではなく観測期間不足のケース。

### 落とし穴2：季節性の混在
クリスマス商戦・お盆・新生活シーズン等で初購入したコホートは商品ジャンルが偏る。リピート行動が他コホートと異なる。

### 落とし穴3：キャンペーン由来コホート
大型セール・初回特典キャンペーンで獲得したコホートは「初回特典目当て」が多く、リピート率が低い傾向。獲得手段別にコホートを分けて見る必要がある。

### 落とし穴4：「初購入」の定義揺れ
ECで「会員登録時 = 初購入」とするか、「最初の注文確定 = 初購入」とするか統一。

## LTV予測モデル（簡易）

過去のコホート別リピート率から、将来のLTVを予測する：

```
推定12ヶ月LTV = 過去コホートの12ヶ月平均累計購入金額
```

新規顧客獲得時、推定LTVと比較して広告費の妥当性を判断：

```
広告費許容上限 = 推定LTV × 粗利率 × 投資回収係数
```

例：
- 推定LTV：30,000円
- 粗利率：40%
- 投資回収係数：0.5（粗利の半分まで広告投資許容）
- 広告費許容上限 = 30,000 × 0.4 × 0.5 = **6,000円**

CPA 6,000円までなら採算合致。

## LTV改善のロードマップ

### 短期（1-3ヶ月）
- 2回目購入特典の設計
- カート放棄リマインド
- ステップメールの最適化

### 中期（3-6ヶ月）
- 商品ラインナップの拡充（クロスセル素材を増やす）
- 定期購入プログラム導入
- ロイヤルティプログラム（ポイント・会員ステージ）

### 長期（6ヶ月以上）
- ブランド体験の強化（同梱物・梱包・ノベルティ）
- コミュニティ形成（ユーザー会・SNSグループ）
- パーソナライズ施策（過去購買履歴に基づく提案）

## チャネル別LTVの違い

| チャネル | LTV傾向 |
|---|---|
| 自社EC | 顧客データ蓄積でリピート促進が容易、LTV高い |
| 楽天 | 楽天会員のLTV計測は楽天内で完結、店舗からのリピート促進限定的 |
| Amazon | リピート促進が困難、LTV低い傾向、ただし Subscribe & Save 等の定期 |
| Yahoo! | LYP会員のロイヤルティ高、リピート率は楽天並み |

自社ECに比べモールはLTV計測・促進が制限される。自社EC比率を上げることはLTV向上戦略でもある。

## 月次レポートでのLTV観測サイクル

| サイクル | 観測内容 |
|---|---|
| 月次 | 全体LTV（直近12ヶ月）、コホート別リピート率（1ヶ月後） |
