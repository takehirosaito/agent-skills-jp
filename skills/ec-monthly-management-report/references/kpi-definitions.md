# KPI完全定義集

EC月次レポートで使う主要KPIの計算式・解釈・典型値・落とし穴。

## 売上系

### 売上高（GMV／Sales）
```
売上高 = 確定注文金額の合計
```
- 単位：円（税込／税抜は社内で統一）
- 集計：注文確定日／出荷日／決済日 のいずれを基準にするか統一
- キャンセル・返品の処理：当月発生分を当月から差し引く／翌月処理 を社内で統一
- 送料：含む／除く を統一

### 注文件数
```
注文件数 = 確定注文数（キャンセル除く）
```
- 単位：件
- 同一顧客の同日複数注文は1件か複数件か社内で統一

### AOV（Average Order Value／平均注文単価）
```
AOV = 売上高 ÷ 注文件数
```
- 単位：円／件
- 解釈：1注文あたりの平均金額
- AOV上昇＝アップセル成功 or 高額商品の比率増
- AOV低下＝低単価商品のセール時、新規層の関心商品の単価が下がっている可能性

### 客単価（カスタマー単価）
```
客単価 = 売上高 ÷ ユニーク顧客数
```
- 単位：円／人
- AOVとの違い：客単価は同一顧客の複数注文を合算

### 平均購入頻度
```
平均購入頻度 = 注文件数 ÷ ユニーク顧客数
```
- 単位：回／人
- LTV計算の前提

## 利益系

### 粗利（Gross Profit）
```
粗利 = 売上高 − 売上原価
```
- 売上原価＝仕入原価＋直接配送費（社内ルールで決める）

### 粗利率（Gross Margin）
```
粗利率 = 粗利 ÷ 売上高 × 100
```
- 単位：%
- EC平均：40-60%（業種で大きく変動）
- アパレル自社EC：50-65%
- 食品EC：20-40%
- 家電EC：15-25%
- コスメ自社EC：60-80%

### 営業利益（営業利益相当）
```
営業利益 = 粗利 − 販管費（広告費・人件費・送料・手数料 等）
```
- 詳細な販管費分解は本スキル対象外、経理側で集計

### 限界利益
```
限界利益 = 売上 − 変動費（売上原価＋変動的販管費）
```
- 固定費の回収余力を見るのに使う

## トラフィック系

### セッション数
```
セッション数 = Google Analytics 等で計測されるセッション合計
```
- ユーザー数とは別（同一ユーザーの複数訪問が複数セッション）
- 計測ツールによって定義が異なる（GA4／GA UA／自社計測）

### ユニークユーザー数（UU）
```
UU = 計測期間内のユニーク訪問者数
```

### ページビュー（PV）
```
PV = ページ表示の合計
```

### CVR（Conversion Rate／転換率）
```
CVR = 注文件数 ÷ セッション数 × 100
```
- 単位：%
- EC平均：1-3%（業種で変動）
- アパレル：1-2%
- 食品（リピート性高）：2-5%
- 化粧品：1-3%
- 高単価品：0.5-1.5%

### 直帰率（Bounce Rate）
```
直帰率 = 直帰したセッション ÷ 全セッション × 100
```
- 単位：%
- 商品ページから即離脱の割合

### 平均滞在時間
```
平均滞在時間 = セッション滞在時間の合計 ÷ セッション数
```

## 広告系

### 広告費（Ad Spend）
```
広告費 = 月間広告費合計（媒体別）
```
- 媒体例：楽天RPP、Amazon SP/SB/SD、Google広告、Meta広告、Yahoo!広告
- 媒体別に分解して集計
- 請求サイクルが異なる場合、計上タイミングを統一

### ROAS（Return On Ad Spend／広告費用対効果）
```
ROAS = 売上 ÷ 広告費
```
- 単位：倍（または%）
- 例：ROAS 5倍＝広告費1円あたり売上5円
- EC平均：5-10倍（業種・成熟度で変動）
- 新規獲得広告：ROAS 1-3倍が多い
- リターゲティング・指名検索：ROAS 10倍以上

### CPA（Cost Per Acquisition／新規獲得単価）
```
CPA = 広告費 ÷ 新規顧客数
```
- 単位：円
- 解釈：1人の新規顧客を獲得するために必要な広告費
- LTV と比較する。CPA < LTV なら採算合致

### CPC（Cost Per Click）
```
CPC = 広告費 ÷ クリック数
```
- 単位：円
- 媒体・キーワード別に観測

### CPM（Cost Per Mille／1,000インプレッション単価）
```
CPM = 広告費 ÷ インプレッション × 1,000
```
- 単位：円

### CTR（Click Through Rate）
```
CTR = クリック数 ÷ インプレッション × 100
```
- 単位：%

### CVR（広告経由の転換率）
```
広告CVR = 広告経由注文件数 ÷ 広告経由クリック数 × 100
```
- 単位：%

### ACOS（Amazon広告固有）
```
ACOS = 広告費 ÷ 広告経由売上 × 100
```
- 単位：%
- ROASの逆数（ROAS 5倍 → ACOS 20%）

## 顧客系

### LTV（Lifetime Value／顧客生涯価値）
```
LTV = 平均購買単価 × 購買頻度 × 継続期間
```

例：
- 平均購買単価 10,000円
- 購買頻度 4回／年
- 継続期間 2年
- LTV = 10,000 × 4 × 2 = **80,000円**

### LTV（より精密な式）
```
LTV = (平均購買単価 × 購買頻度 × 継続期間) × 粗利率
```
LTVを粗利ベースで見る場合。

### CAC（Customer Acquisition Cost）
```
CAC = 新規顧客獲得にかかった総コスト ÷ 新規顧客数
```
CPAより広い範囲（広告費＋人件費等）を含めることがある。

### LTV/CAC
```
LTV/CAC比 = LTV ÷ CAC
```
- 単位：倍
- 3倍以上が健全とされる（業界の経験則）
- 1倍未満は赤字、急務で対策

### リピート率
```
リピート率 = 期間内に2回以上購入した顧客 ÷ 期間内ユニーク顧客 × 100
```
- 単位：%

### 離反率（チャーン率）
```
離反率 = ある期間に離反した顧客 ÷ 期間開始時の顧客数 × 100
```
- 定期購入の場合は明確に測れる
- 単発購入の場合は「最終購入から○ヶ月経過」で離反と定義

## 在庫系

### 在庫金額
```
在庫金額 = 在庫数量 × 在庫単価（原価）
```

### 在庫回転率（月次）
```
在庫回転率 = 月間売上原価 ÷ 平均在庫金額
```
- 単位：回／月
- 高いほど在庫が早く現金化されている
- アパレル：0.5-1.0回／月
- 食品（賞味期限あり）：2-4回／月
- 家電：0.3-0.8回／月

### 在庫日数（在庫消化日数）
```
在庫日数 = 平均在庫金額 ÷ 日次売上原価
```
- 単位：日
- 低いほど在庫が早く現金化

### 滞留在庫
```
滞留在庫 = 一定期間（例：90日）以上動きのない在庫
```
- 単位：円
- 増加は処分計画の必要性

### 欠品損失
```
欠品損失 = (欠品期間中の機会売上推計) − (代替購入された分)
```
- 単位：円
- 正確な算出は難しいが、推計でも経営判断には重要

## マーケティング系

### メルマガ開封率
```
メルマガ開封率 = 開封数 ÷ 配信成功数 × 100
```
- 単位：%
- EC平均：BtoC 15-25%、BtoB 20-30%

### メルマガクリック率
```
メルマガクリック率 = クリック数 ÷ 配信成功数 × 100
```
- 単位：%
- EC平均：2-5%

### 配信解除率
```
配信解除率 = 解除数 ÷ 配信数 × 100
```
- 単位：%
- 1配信あたり0.1-0.5%が健全

### LINE友だち数
- アクティブ／非アクティブの区別
- ブロック数も別途観測

### SNSフォロワー数
- フォロワー数の絶対値より、エンゲージメント率（いいね・コメント・シェア／フォロワー数）が重要

## チャネル別の混同しやすい指標

### 楽天市場
- ROAS（楽天）：楽天店舗売上 ÷ 楽天広告費（RPP・タグ広告）
- 楽天独自指標：店舗評価・違反点数・あす楽率

### Amazon
- ACOS（Amazon）：Amazon広告費 ÷ Amazon経由売上 × 100
- TACoS（Total ACOS）：Amazon広告費 ÷ Amazon総売上 × 100
- ユニットセッション率（Unit Session Percentage）：注文ユニット数 ÷ セッション数

### Yahoo!
- 優良配送率／ストア都合キャンセル率（運営評価に影響）

### 自社EC
- 自社サイト全体のCVR、媒体別流入CVR

## 数値の異常値検出

| 指標 | 異常検出の目安 |
|---|---|
| 売上 | 前月比 ±30%以上 |
| 粗利率 | 前月比 ±5pt以上 |
| CVR | 前月比 ±0.5pt以上 |
| AOV | 前月比 ±20%以上 |
| 広告費 | 前月比 ±30%以上 |
| ROAS | 前月比 ±30%以上 |
| 在庫金額 | 前月比 ±20%以上 |
| 解除率 | 前月比 ±0.5pt以上 |

異常値検出時は要因分析を必ず実施。タイポ・データ集計ミス・施策の影響・市場変動 のどれかを切り分ける。

## KPI観測の頻度

| KPI | 頻度 |
|---|---|
| 売上・注文件数 | 日次 |
| 広告費・CPA・ROAS | 日次〜週次 |
| 在庫 | 週次 |
| CVR・AOV | 週次〜月次 |
| LTV・リピート率 | 月次〜四半期 |
| メルマガ・LINE指標 | 配信ごと＋月次 |

## レポート上の表記ルール

- 単位を明示（円／件／%／倍／pt）
- パーセント変化は「+10%」「-5%」と符号付き
- ポイント変化は「+0.5pt」と表記（CVR・粗利率等）
- 桁区切りはカンマ（1,000,000）
- 端数処理（小数点以下）を統一（1桁・2桁等）
