# チャネル別の手数料・実質利益率

EC各モール／自社ECの手数料構造と実質利益率の比較。手数料率は変動するため、最新は各サービスのヘルプを確認。

## 楽天市場

### 主要コスト
| 項目 | 目安 |
|---|---|
| システム利用料（売上連動） | 月商に応じて3.5-7% |
| 月額固定費 | プランにより 19,500円〜100,000円 |
| 楽天ポイント原資 | 売上の1-2%（標準1%、ポイント変倍時は増） |
| 楽天アフィリエイト | 売上の2.6-5%（カテゴリ別） |
| 楽天決済手数料 | 2.5-3.5%（決済方法による） |
| 楽天RPP広告費 | 別途、運用次第 |
| その他広告（タグ広告等） | 別途 |

### 実質的な手取り
```
手取り = 売上 - 売上原価 - 楽天への手数料合計 - 広告費 - 送料 - 梱包資材
```

楽天売上100万円のケース（仕入率60%、広告費5万円）：
- 売上：100万円
- 原価：60万円（粗利40万円）
- システム料（5%）：5万円
- ポイント原資（1%）：1万円
- アフィリエイト（3%）：3万円
- 決済手数料（3%）：3万円
- RPP広告費：5万円
- 送料（自社負担分）：仮に5万円
- → 実質手取り：18万円（売上100万に対し18%）

### 楽天独自イベントの影響
- スーパーSALE／お買い物マラソン：売上集中するが、ポイント還元・送料無料施策で粗利率が落ちる
- 年4回（3,6,9,12月）の繁忙期
- 5・10倍ポイント時はポイント原資が増加

### 実質的な手取り
Amazon売上100万円のケース（仕入率60%、ホーム&キッチンFBA利用）：
- 売上：100万円
- 原価：60万円（粗利40万円）
- 販売手数料（15.4%）：15.4万円
- FBA配送代行料（標準サイズ）：注文100件×400円 = 4万円
- FBA保管料：在庫量次第、仮に1万円
- 広告費（SP）：仮に8万円
- → 実質手取り：約11.6万円（売上100万に対し11.6%）

### Amazon独自の落とし穴
- カート（バイボックス）獲得率により広告効率が変わる
- リターン率・FBA返品処理料が積み上がる
- 長期在庫保管料（保管365日超）の追加課金
- A-to-z 保証発動による返金

## Yahoo!ショッピング

### 主要コスト
| 項目 | 目安 |
|---|---|
| 出店料 | 無料（基本プラン） |
| 売上手数料 | 無料（基本プラン） |
| ストアポイント原資 | 1-2%（推奨2%以上で優遇） |
| PayPayステップ原資 | 0.5-1% |
| アフィリエイト | 売上の1%程度 |
| キャンペーン原資 | 5の付く日・LYPプレミアム等で増加 |
| 決済手数料 | 3-3.5% |
| 広告費 | 別途 |

### Yahoo!売上100万円のケース（仕入率60%、広告費3万円）：
- 売上：100万円
- 原価：60万円（粗利40万円）
- ストアポイント（2%）：2万円
- アフィリエイト（1%）：1万円
- 決済手数料（3%）：3万円
- 広告費：3万円
- 送料：5万円
- → 実質手取り：26万円（売上100万に対し26%）

Yahoo!は固定費が低く粗利率は楽天より高いが、売上ボリュームは劣る傾向。

### Yahoo!独自指標
- 優良配送率（注文+2日以内着、出荷遅延率5%未満、ストア都合キャンセル率2.5%未満）
- PayPayステップ・5の付く日（売上集中・原資負担）
- 2025年11月評価基準変更：総合13点→10点

## 自社EC（Shopify／futureshop／MakeShop／BASE 等）

### 主要コスト
| 項目 | 目安 |
|---|---|
| ECプラットフォーム月額 | プランにより数千円〜数万円 |
| 決済手数料 | 3-4%（カード／PayPay／コンビニ） |
| 広告費 | Google／Meta／LINE 等 |
| メール配信ツール | Klaviyo / Mailchimp 等 |
| その他SaaS（レビュー・在庫連携） | 別途 |
| 送料 | 自社負担分 |

### 自社EC売上100万円のケース（仕入率60%、広告費10万円）：
- 売上：100万円
- 原価：60万円（粗利40万円）
- プラットフォーム月額：仮に2万円
- 決済手数料（3.5%）：3.5万円
- 広告費：10万円
- 送料：5万円
- → 実質手取り：19.5万円（売上100万に対し19.5%）

自社ECは固定費（プラットフォーム月額・SaaS）と広告費の比率が大きい。逆にモール手数料がない分、リピート・LTVが伸びれば実質利益率は最も高くなりやすい。

## チャネル別の戦略比較

| 観点 | 楽天 | Amazon | Yahoo! | 自社EC |
|---|---|---|---|---|
| 集客力 | 高 | 高 | 中 | 自前で構築 |
| 手数料 | 高 | 中-高 | 低-中 | 低 |
| ブランド表現 | 制限あり | 制限大 | 制限あり | 自由 |
| 顧客データ | 制限あり | ほぼなし | 制限あり | 全取得 |

| 法務リスク | 楽天独自審査 | 厳格 | 楽天より緩い | 自己管理 |

## チャネル別の戦略的な見方

### 売上構成と粗利構成の乖離
売上構成比と粗利構成比が一致しない場合、手数料の高いチャネルへの偏りがある。

例：売上構成
- 楽天 40% / 自社EC 30% / Amazon 30%

粗利構成
- 楽天 25% / 自社EC 50% / Amazon 25%

→ 楽天は売上量はあるが粗利貢献は低い。「楽天を伸ばす」より「自社ECを伸ばす」のほうが粗利成長に寄与。

### チャネル依存度のリスク

| チャネル | リスク |
|---|---|
| 楽天 | 違反点数制度、契約解除リスク、規約変更 |
| Amazon | アカウント停止、サスペンド、SOS、A+モジュール変更 |
| Yahoo!ショッピング | 評価基準変更、優良配送脱落 |
| 自社EC | 集客力低下、広告高騰、ドメイン認証問題 |

特定チャネル依存度が60%超の場合、リスク分散戦略を検討。

## 実質利益計算の注意

- 表面粗利率（売上 − 原価）と実質粗利率（手数料控除後）を分けて見る
- チャネルごとに送料負担率が異なる場合は別途集計
- 楽天SS／お買い物マラソン期の粗利率は通常時より低下（ポイント増・送料無料施策）
- Amazon FBAの返品率と返品処理料の影響
- 自社ECは固定費が利益を侵食するので売上ボリューム前提

## まとめ

- 売上だけでなく実質粗利率を見る
- チャネル別の構成比と粗利貢献を比較
- 手数料構造を理解した上で価格戦略を立てる
- 過度なチャネル依存を避けつつ、効率の良いチャネルに集中
