# 業界別実例5パターン

## 例1：アパレル自社EC＋楽天店＋Amazon（3チャネル）

### 当月実績概要
- 売上：1,800万円（前月比+20%、前年比+28%）
- 粗利率：40%
- AOV：10,000円
- CVR：2.0%
- 広告費：180万円
- ROAS：10倍
- 新規顧客：450人（CPA 4,000円）
- 在庫金額：1,200万円（前月比+20%）

### 経営サマリー
```
売上は前月比+20%（1,800万円）、計画達成率110%。
楽天セール期間で楽天店が+30%、Amazonも+15%と好調。
ただし、広告費が前月比+25%と売上以上に増加し、ROAS 10倍は維持できているものの、
新規顧客のCPAが前月3,500円→4,000円と上昇。

【意思決定論点】
1. 楽天セール後の客足落ち込みを見越し、休眠復活施策の発動タイミング
2. CPA上昇傾向への対策（媒体配分／クリエイティブ刷新）
3. 在庫金額が増加傾向、夏物終売後の在庫処分計画
```

### 次月施策
| 施策 | 期待効果 | 予算 |
|---|---|---|
| 休眠復活メルマガキャンペーン | 復活率5%、+150万 | 0円 |
| 広告クリエイティブ刷新 | CPA -10% | 既存予算内 |
| 滞留在庫の特価セール | 在庫150万円処分 | 値下げ分の粗利影響 |
| 自社EC LP A/Bテスト | CVR +0.2pt | 制作費30万 |

## 例2：食品EC（地方産お米・産地直送）

### 当月実績概要
- 売上：600万円（前月比+5%、前年比+15%）
- 粗利率：30%
- AOV：5,000円
- CVR：3.5%（食品は高め）
- 広告費：50万円
- ROAS：12倍
- 新規顧客：200人（CPA 2,500円）
- 定期購入会員：800人（前月比+50人）
- リピート率：65%

### 特徴
- リピート率が高いが、AOVが低め（食品の一般傾向）
- 定期購入の比率が高く、安定収益基盤
- 季節商品（新米・お歳暮）の影響大

### 経営サマリー
```
売上は前月比+5%（600万円）、定期購入会員が+50人と増加。
新米シーズンに向けて、新規獲得の質も改善傾向。
ただし、業種特性として粗利率30%、AOV 5,000円は構造的な制約。

【意思決定論点】
1. 新米時期の集中投資（10-11月）
2. 定期購入のスキップ・休止率を抑える施策
3. ギフト需要（お歳暮）への準備状況
```

### 在庫KPI
- 在庫金額：250万円
- 在庫日数：30日（食品は短い）
- 滞留率：5%（賞味期限管理が効いている）
- 廃棄ロス：当月8万円

### 次月施策
| 施策 | 期待効果 | 予算 |
|---|---|---|
| 新米シーズン特設ページ | 11月売上+30% | 制作費20万 |
| 定期購入の自動継続率改善（スキップ機能改善） | 解約率-2pt | 開発10万 |
| お歳暮ギフト商品の早期告知 | 12月売上+20% | 広告費30万 |

## 例3：コスメ自社EC（スキンケア・サブスク中心）

### 当月実績概要
- 売上：1,200万円（前月比+10%、前年比+25%）
- 粗利率：65%
- AOV：8,000円
- CVR：2.5%
- 広告費：300万円
- ROAS：4倍（新規獲得広告中心）
- 新規顧客：800人（CPA 3,750円）
- 定期購入会員：3,500人
- 12ヶ月LTV：35,000円
- LTV/CAC比：9.3倍

### 特徴
- 粗利率が高い（コスメ自社EC典型）
- 広告費が売上の25%と大きいが、LTVが高いため採算合致
- 定期購入の比率が高くストック売上が積み上がる

### 経営サマリー
```
売上は前月比+10%、特に定期購入会員が+200人と新規獲得が好調。
LTV/CAC比 9.3倍と健全水準を大きく上回り、広告投資加速の余地あり。
ただし、新規施策がROASを押し下げており（リターゲ含めると7倍）、
新規依存のリスクを定期化で吸収していく構造。

【意思決定論点】
1. 広告予算をさらに上積みするか（現在の月300万→月400万検討）
2. 定期購入の初回スキップ防止施策
3. 既存顧客のロイヤルティプログラム強化
```

### 法務確認
- 化粧品広告の効能効果は56項目内に限定
- 機能性表示食品（あれば）は届出文言遵守
- 「絶対」「保証」「治る」等の断定表現禁止
- ステマ規制：インフルエンサー協業時のPR表記確認

### 次月施策
| 施策 | 期待効果 | 予算 |
|---|---|---|
| 広告予算+100万円増 | 新規+200人 | +100万 |
| 定期初回1ヶ月の手厚いフォロー（ステップ配信） | スキップ率-3pt | 0円 |
| VIP顧客向けロイヤルティ施策 | 解約率-2pt | 既存予算 |

## 例4：法人BtoB（オフィス用品）

### 当月実績概要
- 売上：3,000万円（前月比+15%、前年比+20%）
- 粗利率：25%（BtoBは粗利率低め）
- AOV：50,000円（BtoB典型）
- CVR：5.0%（BtoBは購入意欲高）
- 広告費：50万円
- ROAS：60倍（BtoBは指名検索中心）
- 新規法人数：50社（CPA 10,000円）
- 既存法人リピート率：85%
- インボイス発行件数：450件

### 特徴
- AOVが高い（数万〜数十万円）
- BtoBは購入決定者と利用者が分かれる
- 法人後払い・請求書払いの比率が高い
- インボイス対応必須

### 経営サマリー
```
売上は前月比+15%、新規法人50社獲得で安定成長。
既存法人のリピート率85%と高く、ストック型ビジネスとして堅調。
インボイス発行件数が前月比+20%、適格請求書発行事業者としての対応が定着。

【意思決定論点】
1. 大口法人（年間100万円超）の囲い込み施策
2. 法人向け請求書PDF自動発行システムの導入検討
3. 新規法人開拓のチャネル拡大（オンライン展示会・業界誌広告）
```

### KPI（法人特有）
- 大口顧客（年間100万円超）数：30社
- 平均与信枠：50万円
- 与信超過件数：3件
- 請求書発行〜入金平均日数：35日

### 次月施策
| 施策 | 期待効果 | 予算 |
|---|---|---|
| 大口顧客向け年間契約割引 | リテンション+5pt | 値引き分の粗利影響 |
| 業界誌Webバナー広告 | 新規法人+15社 | 30万円 |
| 法人向けセミナー開催 | リード50件 | 50万円 |

## 例5：立ち上げ初期EC（自社EC・1年目）

### 当月実績概要
- 売上：80万円（前月比+30%、前年データなし）
- 粗利率：50%
- AOV：6,000円
- CVR：1.2%（立ち上げ初期は低い）
- 広告費：40万円
- ROAS：2倍（立ち上げ期は赤字広告）
- 新規顧客：120人（CPA 3,333円）
- リピート率：30%（観測期間短い）

### 特徴
- 売上規模はまだ小さいが成長率高
- 広告費が売上の50%と重い
- ROAS 2倍で短期的には赤字
- ただし、LTVが推定で30,000円なら、CPA 3,333円は1.1ヶ月で回収可能

### 経営サマリー
```
売上80万円、前月比+30%と成長中。
ROAS 2倍は短期的に赤字だが、推定LTV 30,000円に対しCPA 3,333円なら
12ヶ月で約9倍のリターン見込み、投資期として妥当。
ただし、絶対額（広告費40万円）はキャッシュフロー圧迫要因、
新規獲得とリピート促進のバランスを慎重に。

【意思決定論点】
1. 広告投資の継続可否（キャッシュ残高との兼ね合い）
2. リピート促進施策の優先（初回購入者の2回目購入率向上）
3. 第二チャネル（楽天 or Amazon）の開設検討
```

### 立ち上げ初期に追加で観測すべきKPI

| 指標 | 観測理由 |
|---|---|
| 流入チャネル別CVR | どの集客がCV出やすいか |
| 商品別の販売構成 | 主力商品を絞り込む |
| 顧客の年代・性別分布 | ターゲット仮説の検証 |
| 配送地域分布 | 物流ハブの最適化判断 |
| 問い合わせ件数 | 課題の早期発見 |

### 次月施策
| 施策 | 期待効果 | 予算 |
|---|---|---|
| 既存購入者への2回目購入ステップ配信 | リピート率+10pt | 0円 |
| 広告クリエイティブの再設計 | CVR +0.3pt | 制作費10万 |
| メルマガ会員500人到達まで友だち登録特典 | 会員数+200人 | クーポン原資10万 |
