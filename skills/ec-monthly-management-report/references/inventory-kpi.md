# 在庫KPI

EC事業のキャッシュフローと粗利を直撃する在庫管理のKPI定義と運用。

## 在庫KPI一覧

### 在庫金額
```
在庫金額 = 在庫数量 × 在庫単価（原価）
```
- 月末時点 or 月平均で集計
- 売上規模に対する比率も観測

### 在庫回転率（月次）
```
在庫回転率 = 月間売上原価 ÷ 平均在庫金額
```
- 単位：回／月
- 高いほど在庫が早く現金化
- 業種別の目安：
  - アパレル：0.5-1.0回／月
  - 食品（賞味期限あり）：2-4回／月
  - 家電：0.3-0.8回／月
  - コスメ：0.5-1.5回／月

### 在庫日数（在庫消化日数／DIO）
```
在庫日数 = 平均在庫金額 ÷ 日次売上原価
```
または
```
在庫日数 = 365 ÷ 年間在庫回転率
```
- 単位：日
- 低いほど運転資金効率が良い
- 一般的な目安：30-90日

### 滞留在庫
```
滞留在庫 = 一定期間（例：90日／180日）以上動きのない在庫
```
- 単位：円・点数
- 滞留期間の閾値は社内で決定（90日／180日／365日）

### 滞留率
```
滞留率 = 滞留在庫 ÷ 在庫金額合計 × 100
```
- 単位：%
- 健全：10%以下
- 注意：10-20%
- 要対策：20%超

### 欠品損失
```
欠品損失 = 欠品期間中の機会売上推計
```
- 単位：円
- 推計式の例：
  ```
  欠品損失 = 過去同期間の平均日次売上 × 欠品日数 × 在庫があった場合の購入率推計
  ```
- 正確な算出は難しいが、推計でも経営判断に重要

### 適正在庫
```
適正在庫 = 平均日次売上 × (リードタイム + 安全在庫日数)
```
- 単位：個・円
- リードタイム：発注から納品までの期間
- 安全在庫：需要変動・調達遅延への備え

## 在庫評価の方法

### 評価方法
- 先入先出法（FIFO）：先に仕入れたものから売れたとする
- 移動平均法：仕入のたびに平均単価を再計算
- 個別法：高額品・ロット管理品

各社の経理ルールに従う。月次レポートで使う評価方法は固定して継続的に集計。

### 評価減（棚卸資産評価損）
- 滞留・廃番・季節終了商品は時価評価減
- 評価減の計上タイミングを社内で決める
- 月次レポートで評価減も粗利に反映

## 在庫管理のサイクル

### 月次レビュー項目

| 項目 | 確認内容 |
|---|---|
| 在庫金額の推移 | 前月比・前年比 |
| 在庫回転率 | 業種目安との比較 |
| 滞留在庫の増減 | 90日・180日の滞留 |
| 欠品損失の推計 | 何が欠品し、いくら逃したか |
| 過剰在庫（販売予測超過） | 季節商品の終売リスク |
| 適正在庫からの乖離 | 過剰・過少 |

### ABC分析
売上貢献度で在庫を3区分：

| 区分 | 売上構成 | 在庫構成 | 在庫管理レベル |
|---|---|---|---|
| A | 70% | 10-20% | 精密管理・欠品ゼロ |
| B | 20% | 30% | 通常管理 |
| C | 10% | 50-60% | 緩い管理・整理対象 |

Cランクが在庫の大半を占めているなら、整理・廃番・処分を進める。

## 滞留在庫の処分計画

### 段階的な処分施策

| 滞留日数 | 施策 |
|---|---|
| 60-90日 | 通常価格で継続販売、メルマガ・LINEで露出強化 |
| 90-180日 | 10-20%値引き、セール対象に組み込み |
| 180-365日 | 30-50%値引き、福袋・アウトレットコーナーへ |
| 365日超 | 大幅値引き or 廃棄・寄付 |

### 値引き判断
- 値引き後でも原価割れしない範囲が原則
- ただし、保管料・在庫評価減を考慮すると原価割れでも処分が合理的なケースあり
- 「在庫を持ち続けるコスト vs 処分による損失」を比較

### 値引き計算例
- 仕入原価：5,000円
- 通常販売価格：10,000円（粗利率50%）
- 30%値引き後販売価格：7,000円（粗利2,000円、粗利率28.6%）
- 50%値引き後販売価格：5,000円（粗利0円、粗利率0%）
- 70%値引き後販売価格：3,000円（粗利-2,000円、原価割れ）

70%値引きは粗利マイナスだが、保管料が在庫1点あたり月100円、半年保管していたら600円の保管コストがかかっているなら、廃棄より販売が良い場合も。

### 廃棄／寄付の判断
- 食品：賞味期限切れ間近で廃棄／フードバンク寄付
- 化粧品：開封済み・期限切れは廃棄
- アパレル：シーズン終了品はアウトレット流通／古着販売
- 家電：型落ち品は B2B 卸し／海外販売 / リファビッシュ

## 欠品対策

### 欠品の根本原因
- 需要予測の誤差
- 発注タイミングの遅れ
- メーカー欠品・生産遅延
- システム在庫と実在庫の乖離（盗難・破損・出荷ミス）

### 欠品防止の運用
- 安全在庫日数の設定（リードタイム＋数日）
- 自動発注のしきい値設定
- 月次の在庫精度確認（システム在庫 vs 実地棚卸）
- 主要商品の発注書 / 受注書のダブルチェック

## 在庫KPIのレポート例

```
## 在庫KPI（[YYYY-MM]）

| 指標 | 当月 | 前月 | 前月比 | 前年 | 前年比 |
|---|---|---|---|---|---|
| 在庫金額 | 1,200万 | 1,000万 | +20% | 950万 | +26% |
| 在庫回転率（月次） | 0.6回 | 0.6回 | ±0 | 0.7回 | -14% |
| 在庫日数 | 50日 | 50日 | ±0 | 43日 | +16% |
| 滞留在庫（90日以上） | 200万 | 150万 | +33% | 100万 | +100% |
| 滞留率 | 16.7% | 15.0% | +1.7pt | 10.5% | +6.2pt |
| 欠品損失（推定） | 30万 | 50万 | -40% | 40万 | -25% |

### 解釈
- 在庫金額が増加傾向、特に滞留在庫が前年比2倍
- 在庫回転率は前月維持、前年比はやや悪化
- 欠品損失は改善傾向

### 対策
- 滞留在庫200万円のうち、150万円分を来月末までに30%値引きセールへ
- 主力Aランク商品の発注リードタイム短縮交渉（現在14日→7日目標）
- 月次の実地棚卸を継続、システム在庫精度95%以上を維持
```

## 在庫とキャッシュフローの関係

```
キャッシュ＝売上現金化 − 在庫増加 − その他運転資金
```

在庫が増加するとキャッシュは減る。在庫1,000万円増は現金1,000万円減と同義。

月次レポートで「売上は伸びたが手元現金は減った」場合、在庫増加が原因のことが多い。

## 在庫KPI改善の優先順位

経営リソースが限られている場合の優先順位：

1. **Aランク商品の欠品ゼロ化**（売上機会損失の最小化）
2. **滞留在庫の処分計画**（評価減リスクの低減）
3. **在庫精度の向上**（システム vs 実在庫の乖離縮小）
4. **適正在庫の見直し**（過剰・過少のバランス）
5. **Cランクの整理**（管理コスト削減）

## 在庫データの取得元

| データ | 取得元 |
|---|---|
| 在庫数量 | 在庫管理システム（ネクストエンジン／Logizard／クロスモール 等） |
| 在庫原価 | 仕入管理・会計システム |
| 売上原価 | 経理仕訳 |
| 出荷数 | 受注管理 |
| 入荷数 | 仕入管理・WMS |

複数システムからのデータを月次で突き合わせ、ズレを補正する運用が必要。

## 在庫適正化の指標まとめ

| 指標 | 目標 |
|---|---|
| 在庫回転率（月次） | 業種平均以上 |
| 在庫日数 | 業種平均以下 |
| 滞留率（90日以上） | 10%以下 |
| Aランク欠品率 | 1%以下 |
| 在庫精度（システム vs 実在庫） | 95%以上 |
| 廃棄ロス率 | 業種平均以下 |
