# フリースペース1-10 の構成テンプレ（HTML）

MakeShop の商品ページテンプレートに `<!--MS:フリースペース1-->` のような擬似タグで差し込まれる、フリースペース1〜10 の HTML テンプレートを提示する。

実際の店舗テンプレと整合させるため、テンプレ側のクラス名・構造を確認したうえで使う。

## フリースペース1：キャッチ／導入

商品ページ最上部に表示される。第一印象を決める。

```html
<section class="fs-catch">
  <h2>みずみずしさが続く、毎日の保湿クリーム</h2>
  <p>うるおいを与えながら、肌をすこやかに保つデイリーユースの
  保湿クリームです。朝晩のお手入れの最後にお使いいただけます。</p>
</section>
```

文字数：100〜200字。長くなりすぎないこと。

## フリースペース2：スペック表

`<table>` を使うが、スマホで横スクロールにならないようシンプルに。

```html
<section class="fs-spec">
  <h2>スペック</h2>
  <table class="spec-table">
    <tbody>
      <tr><th>容量</th><td>30g</td></tr>
      <tr><th>使用目安</th><td>約2ヶ月（1日2回）</td></tr>
      <tr><th>対象肌</th><td>全肌質</td></tr>
      <tr><th>主要成分</th><td>○○エキス、××オイル</td></tr>
      <tr><th>原産国</th><td>日本</td></tr>
      <tr><th>製造販売元</th><td>○○株式会社</td></tr>
    </tbody>
  </table>
</section>
```

または `<dl>` リストでスマホフレンドリーに：

```html
<section class="fs-spec">
  <h2>スペック</h2>
  <dl class="spec-list">
    <dt>容量</dt><dd>30g</dd>
    <dt>使用目安</dt><dd>約2ヶ月（1日2回）</dd>
    <dt>対象肌</dt><dd>全肌質</dd>
    <dt>主要成分</dt><dd>○○エキス、××オイル</dd>
    <dt>原産国</dt><dd>日本</dd>
  </dl>
</section>
```

## フリースペース6：レビュー抜粋

**実在のレビュー** を匿名化して引用。誘導的な編集や効能効果断定は不可。

```html
<section class="fs-reviews">
  <h2>お客様の声</h2>
  <blockquote class="review">
    <p>「テクスチャが軽くて朝のお手入れに使いやすい」</p>
    <cite>30代女性・購入後1ヶ月</cite>
  </blockquote>
  <blockquote class="review">
    <p>「冬の乾燥対策に重ねづけしています」</p>
    <cite>40代女性・購入後3ヶ月</cite>
  </blockquote>
  <p><a href="/reviews/item-001/">レビューをすべて見る</a></p>
</section>
```

## フリースペース8：配送・返品（商品個別の特記事項）

特商法表記ページと **表記が一致** すること。

```html
<section class="fs-shipping">
  <h2>配送・返品について</h2>
  <ul>
    <li>発送：注文確定後3営業日以内</li>
    <li>送料：5,000円（税込）以上のご注文で全国無料</li>
    <li>配送業者：[配送業者名]</li>
    <li>到着日：地域により1〜3日</li>
  </ul>
  <p>
    商品の性質上、開封後の返品はお受けできません。
    初期不良の場合は到着後7日以内にお問合せください。
    詳細は<a href="/info/tokushoho/">特定商取引法に基づく表記</a>をご確認ください。
  </p>
</section>
```

## フリースペース9：キャンペーン文言（期間限定のみ）

**販売期間終了日とセットで運用**。残置は信頼低下要因。

```html
<section class="fs-campaign">
  <h2>○月の特別キャンペーン</h2>
  <p>
    ○月15日（金）23:59まで、当商品10%OFF。<br>
    クーポンコード「AUTUMN10」をカート画面でご入力ください。<br>
    ※他クーポンとの併用不可
  </p>
</section>
```

## CSV 流し込み時の注意

各テンプレを CSV のフリースペース列に貼る際：

1. **値全体を `"` で囲む**
2. **内部の `"` を `""` に二重化**
3. **改行を含む場合の挙動は店舗仕様による**：CSV パーサが改行入りに対応していない場合は `<br>` に置換 or 1行化
4. **HTMLタグの閉じ忘れ**を確認
5. **テンプレ側のクラス名と整合**：店舗のテーマCSS に合わせて class 属性を調整
6. **`<script>` `<iframe>` `<style>` の扱い**：店舗のセキュリティポリシーによる
