# 商品ページの薬機法・景表法・特商法チェック

MakeShop の商品ページコピーで特に注意すべき法令ポイント。具体的な表現判定は `yakki-keihyo-expression-check` スキル併用。

## 1. 薬機法（医薬品医療機器等法）

### 化粧品の効能効果56項目

化粧品の広告表現は、厚生労働省が認めた56項目の範囲内のみ。

**OK例**：
- 「肌にうるおいを与える」
- 「肌をすこやかに保つ」
- 「乾燥による小ジワを目立たなくする」（日本香粧品学会ガイドライン試験の裏付け必須）
- 「肌のキメを整える」
- 「肌荒れを防ぐ」
- 「皮膚を保護する」

**NG例**：
- 「シミが消える」
- 「美白できる」（医薬部外品の承認効能があれば別）
- 「アンチエイジング」
- 「ニキビが治る」
- 「シワが消える」
- 「リフトアップ」
- 「ターンオーバーを促進」

詳細：`yakki-keihyo-expression-check` スキル参照（化粧品56効能完全リスト）。

### 健康食品の4分類

| 分類 | 表現範囲 |
|---|---|
| 特定保健用食品（トクホ） | 消費者庁長官の個別許可された保健の用途のみ |
| 機能性表示食品 | 事業者が届出した機能性表示の範囲内 |
| 栄養機能食品 | 国が定めた栄養素の機能のみ |
| いわゆる健康食品（一般食品） | 効能効果の標榜不可、一般的表現のみ |

**NG例（いわゆる健康食品で）**：
- 「痩せる」
- 「血糖値が下がる」
- 「免疫力アップ」
- 「がんに効く」

**OK例（いわゆる健康食品で）**：
- 「毎日の健康習慣に」
- 「○○エキスを含む」
- 「[摂取方法]：1日1〜2粒を目安に」

### 医療機器

医療機器として承認・認証を受けたものは、承認・認証範囲内の効能効果のみ表示可。雑貨扱いの「美容器具」は医療機器的な効能効果（治療・予防）を謳えない。

## 2. 景品表示法（景表法）

### No.1表記の4要件

「業界No.1」「シェアNo.1」「売上No.1」などを使うには次の4要件を満たすこと：

1. 比較する商品等が適切に選定されている
2. 調査対象者が適切に選定されている
3. 調査が公平な方法で実施されている
4. 表示内容と調査結果が適切に対応している

**必須明示**：調査主体・期間・対象・方法・出典

**NG例**：
- 「業界No.1」（根拠なし）
- 「最安」（根拠なし）
- 「お客様満足度No.1」（出典なし）

**OK例**：
- 「○○調査機関調べ、2024年○月〜△月の○○カテゴリ売上シェアNo.1（n=500人）」

### 二重価格表示の8週間ルール

「通常価格2,000円 → セール価格1,500円」のような二重価格表示には条件がある：

- 「通常価格」は **セール開始直前8週間のうち過半（4週間以上）で実販売されていた価格** であること
- 過去に高く付けていただけで最近の実販売実績がない場合はNG
- 「希望小売価格」を実販売実績の代わりに使うのは条件を満たさない場合がある

### 打消し表示

- 「※個人の感想」「※全員に当てはまるものではありません」は **打消しとして機能しない場合がある**
- 主張と打消しが同じ視認性で読める配置にすること
- 文字サイズ・色・位置が極端に異なる打消しは無効

### 課徴金（2024改正）

- 売上の3%（最大3年分）
- 5,000万円未満は適用除外
- 繰返し違反は4.5%

## 3. 特定商取引法（特商法）

通販で必要な記載13+α項目（商品ページ・特商法表記ページのいずれかまたは両方で）：

1. 販売価格
2. 送料
3. 支払時期・方法
4. 引渡時期
5. 申込撤回・解除（返品特約）
6. 事業者氏名・住所・電話番号
7. 責任者氏名
8. 申込有効期限
9. 価格以外の負担
10. 隠れた瑕疵責任
11. ソフトウェア動作環境
12. 定期購入条件（2回以上）
13. 数量制限等

**最終確認画面6項目（2022.6改正）**：
1. 分量（個数・回数・期間）
2. 販売価格／支払総額
3. 支払時期・方法
4. 引渡時期
5. 申込撤回・解除条件
6. 申込期間制限

違反は3年以下懲役・300万円以下罰金（直罰）。

### 商品ページとの整合

商品ページのフリースペース8（配送・返品）に書く内容は、**特商法表記ページとブレないこと**。

NG例：
- 商品ページ「返品OK」、特商法表記「返品不可」
- 商品ページ「全国送料無料」、特商法表記「沖縄・離島は別途送料」（沖縄離島の追加料金を商品ページで省略）

OK：商品ページに簡潔に書き、詳細は特商法表記ページへリンク。

### 定期購入（サブスクリプション）

定期購入条件（2回以上）は特商法の規制対象：

- 契約期間（最低継続回数）
- 解約条件・解約方法
- 総額表示（最低継続回数分の合計）
- 各回の金額・配送頻度・配送日

これらを商品ページ・カート画面・最終確認画面で **必ず表示**。

## 4. ステマ規制（2023.10.1〜）

### 規制対象

広告主（事業者）のみ。インフルエンサー・モデル個人ではない。

### PR表記

インフルエンサー・モデル・第三者のレビューを引用する場合、広告であることを明示：

- 「広告」
- 「PR」
- 「プロモーション」
- 「Sponsored」

### 表記の位置

- 投稿冒頭または常時表示
- 極小文字・タグ末尾埋め込みはNG

### 商品ページでの応用

- インフルエンサーレビューを商品ページに引用する際は「PR表記」「広告タイアップ」と分かるように
- 「お客様の声」と「PR投稿」を **明確に区別**

## 6. 「人気」「定番」「ランキング」の根拠

「人気No.1」「定番商品」「楽天ランキング1位」などを商品ページに書く場合、**根拠の明示** が必要：

- 期間（いつのランキング／人気か）
- 対象（自店内／全カート横断／カテゴリ別）
- 出典（楽天ランキング・Amazon ベストセラー・自社売上）

**NG例**：
- 「人気商品」（漠然）
- 「ランキング1位」（出典なし）
- 「累計○○個販売」（期間・対象なし）

**OK例**：
- 「当店○月度売上1位（2024.09 自社カート内、化粧水カテゴリ）」
- 「楽天市場 ○○ジャンル週間ランキング1位獲得（2024.10.07-13）」

## 7. 全体チェック早見表

| 項目 | OK条件 |
|---|---|
| 化粧品の効能効果 | 厚労省56項目の範囲内 |
| 健康食品の効能効果 | トクホ／機能性表示／栄養機能食品の届出範囲内 |
| 「No.1」「最安」 | 調査主体・期間・対象・方法を本文に明記、または使わない |
| 「通常価格 → セール価格」 | 8週間のうち4週以上で通常価格での実販売 |
| 「ランキング1位」 | 期間・対象・出典を明記 |
| インフルエンサー引用 | 「PR」「広告」表記 |
| 配送・返品 | 特商法表記ページと整合 |
| 定期購入 | 契約期間・解約条件・総額・各回金額を表示 |
| 食品 | 特定原材料の表示 |
| 「個人の感想」 | 主張と同等の視認性で記載 |
