# 商品ページコピー実例（5パターン）

## 例1：高保湿フェイスクリーム（化粧品）

**前提**：D2C スキンケア、30g、客単価4,000円、ブランドトーン「丁寧・落ち着いた敬語」、ターゲット30代女性。

### SEOタイトル（30字）
「高保湿フェイスクリーム30g｜乾燥肌向け｜[ブランド名]」

### メタディスクリプション（98字）
「乾燥が気になる肌をうるおいで満たすフェイスクリーム30g。なじみのよいテクスチャで朝晩のお手入れの最後に。送料無料／レビュー多数。」

### 商品名（短・36字）
「[ブランド名] モイスチャライズクリーム 30g」

### 商品名（ロング・45字）
「[ブランド名] モイスチャライズクリーム 30g／乾燥肌のためのデイリーケア」

### 商品説明（一覧用・180字）
「乾燥が気になる肌をうるおいで満たすフェイスクリーム30g。フランス産○○エキスを配合し、なじみのよいテクスチャで朝晩のお手入れの最後にお使いいただけます。30代・40代の方に多くお選びいただいています。送料無料・初回購入の方にはサンプル付き。」

### フリースペース1（キャッチ）

```html
<section class="fs-catch">
  <h2>みずみずしさが続く、毎日の保湿クリーム</h2>
  <p>うるおいを与えながら、肌をすこやかに保つデイリーユースの保湿クリームです。朝晩のお手入れの最後にお使いいただけます。</p>
</section>
```

### フリースペース2（スペック表）

```html
<section class="fs-spec">
  <h2>スペック</h2>
  <dl>
    <dt>容量</dt><dd>30g</dd>
    <dt>使用目安</dt><dd>約2ヶ月（1日2回）</dd>
    <dt>対象肌</dt><dd>全肌質</dd>
    <dt>主要成分</dt><dd>○○エキス、××オイル</dd>
    <dt>原産国</dt><dd>日本</dd>
  </dl>
</section>
```

### 薬機法注意
- NG：「シミが消える」「美白」「アンチエイジング」「ニキビが治る」
- OK：「肌にうるおいを与える」「肌をすこやかに保つ」「乾燥による小ジワを目立たなくする（試験裏付け必須）」

「信州フロマージュ4種食べ比べセット 化粧箱入り」

```
[h2] 信州の四季をひと箱に

- セミハード（くるみ入り）
```

## 例3：リネンノーカラージャケット（アパレル）

**前提**：セレクトショップ、レディース、客単価10,000円、3カラー・S/M/L。

### SEOタイトル（30字）
「リネン100%ノーカラージャケット｜オールシーズン｜[ブランド名]」

### メタディスクリプション（96字）
「フランス産リネン100%のノーカラージャケット。春夏は涼しく、秋冬はインナーであたたかい。S/M/L／3カラー／送料無料。」

### 商品名（短・38字）
「[ブランド名] リネン100% ノーカラージャケット」

### 商品名（ロング・55字）
「[ブランド名] リネン100% ノーカラージャケット（オールシーズン・3カラー・S/M/L）」

### フリースペース2（スペック表）

```html
<section class="fs-spec">
  <h2>サイズと素材</h2>
  <dl>
    <dt>サイズ</dt><dd>S（着丈58cm／身幅48cm）<br>M（着丈60cm／身幅50cm）<br>L（着丈62cm／身幅52cm）</dd>
    <dt>カラー</dt><dd>オフホワイト／ネイビー／ベージュ</dd>
    <dt>素材</dt><dd>リネン100%（フランス産）</dd>
    <dt>洗濯</dt><dd>手洗い・陰干し推奨（アイロンはスチーム）</dd>
    <dt>原産国</dt><dd>日本</dd>
    <dt>着用モデル</dt><dd>身長160cm／Mサイズ着用</dd>
  </dl>
</section>
```

### 注意点
- 色違い・サイズ違いを別商品にする場合は重複コンテンツ回避
- 「人気No.1」「定番」は根拠（期間・対象・出典）を明記、または使わない

## 例4：手作り陶器マグカップ（ハンドメイド・受注生産）

**前提**：個人作家、ハンドメイド陶器、客単価3,500円、受注生産で発送2-3週間。

### SEOタイトル（29字）
「手作り陶器マグカップ 焼締／白／青｜窯元直送｜[作家名]」

### メタディスクリプション（100字）
「ひとつずつ手作りした焼締の陶器マグカップ。色は焼締／白／青の3種。日常使いにも贈り物にも。窯元から直接お届け。」

### 商品名（短・36字）
「[作家名] 手作り焼締マグカップ（焼締／白／青）」

### フリースペース1（キャッチ）

```html
<section class="fs-catch">
  <h2>ひとつずつ手作りした陶器マグカップ</h2>
  <p>長野の窯元でひとつずつ手作りしている、日常使いの陶器マグカップです。色は焼締／白／青の3種。手のひらにしっくりとなじむ厚みと、ぽってりとした口当たりが特徴です。</p>
</section>
```

### フリースペース8（配送・返品）

```html
<section class="fs-shipping">
  <h2>配送・返品について</h2>
  <ul>
    <li>ご注文確定後、窯元で制作開始</li>
    <li>発送：ご注文から2〜3週間</li>
    <li>配送：宅配便（地域により1〜2日）</li>
    <li>送料：全国一律700円（10,000円以上で無料）</li>
  </ul>
  <p>
    自然素材のため、色味・厚み・形状にひとつずつ個体差があります。
    その個体差を理由とする返品はお受けしておりません。
    破損・初期不良の場合は到着後7日以内にお問合せください。
  </p>
</section>
```

### 注意点
- 受注生産は **発送目安** を商品ページ冒頭に明記
- 個体差・自然素材を理由とする返品不可ポリシーを記載
- 食器用途の場合は耐熱性・電子レンジ・食洗機の可否を明記

## 例5：コードレス電動おろし器（家電）

**前提**：D2C家電ブランド、USB充電式、客単価8,000円。

### SEOタイトル（30字）
「コードレス電動おろし器 USB充電式｜ステンレス｜[ブランド名]」

### メタディスクリプション（108字）
「USB充電で繰り返し使えるコードレス電動おろし器。大根・しょうがを30秒で。ステンレス刃、丸洗い可能、1年保証。送料無料／即日発送。」

### 商品名（短・38字）
「[ブランド名] コードレス電動おろし器 USB充電式」

### 商品名（ロング・47字）
「[ブランド名] コードレス電動おろし器（USB充電式・ステンレス刃・1年保証）」

### 商品説明（詳細・抜粋）

```
[h2] 30秒で完成するコードレスおろし器

USB充電で繰り返し使えるコードレス電動おろし器です。
大根・しょうが・にんじん・チーズなどを30秒程度でおろせます。

[h2] スペック
- 本体サイズ：W○○×D○○×H○○ mm
- 重量：○○g
- 電源：USB Type-C 充電式
- 連続使用時間：約30分（フル充電時）
- 回転数：約○○rpm
- 素材：ABS樹脂／ステンレス（刃）／シリコン（パッキン）

[h2] 同梱物
- 本体
- USB Type-C 充電ケーブル
- 取扱説明書（日本語）
- 保証書（1年保証）

[h2] 使い方
1. 充電（初回は2〜3時間）
2. 食材を投入口に入れる
3. ボタンを押して30秒
4. ご使用後は分解して水洗い

[h2] 保証・修理対応
購入後1年間のメーカー保証。初期不良・通常使用での故障は無料修理または交換。
```

### 注意点
- 仕様表は構造化（テーブル）で記載
- 「業界最軽量」「最強の吸引力」を使う場合は **根拠（測定方法・比較対象・期間）** を明記
- 保証期間・修理対応窓口を商品ページに明記
- 電源・電圧・PSE認証など電気用品安全法対応の有無を明示
