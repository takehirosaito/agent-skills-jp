# 商品ページパーツ別の書き方ガイド

MakeShop の商品ページを構成するパーツごとに、文字数・構造・書き方のポイントを整理する。

## 1. SEOタイトル（28〜32字）

Google 検索結果に表示されるページタイトル。CTR と検索順位の両方に影響。

### 構造

```
[商品の主キーワード] + [差別化軸] + [ブランド名]
```

### OK例
- 「高保湿フェイスクリーム30g｜乾燥肌向け｜[ブランド名]」（30字）
- 「リネン100%ノーカラージャケット｜オールシーズン｜[ブランド名]」（31字）
- 「信州フロマージュ4種食べ比べセット｜化粧箱入り｜[ブランド名]」（29字）

### NG例
- 「商品ページ｜通販ショップ」（11字、抽象的）
- 「[ブランド名] | [ブランド名] | おすすめ | 通販 | 公式 | 最安」（キーワード詰込み・「最安」リスク）

## 2. メタディスクリプション（80〜120字）

Google 検索結果のスニペット。クリック判断に直結。

### 構造

```
[商品の要約] + [差別化] + [CTA色の語尾]
```

### OK例（98字）

「乾燥が気になる肌をうるおいで満たすフェイスクリーム30g。なじみのよいテクスチャで朝晩のお手入れの最後に。送料無料／レビュー多数。」

### NG例
- 全商品で同じテンプレ文（重複コンテンツ）
- 「お客様の声を大切に、誠実に運営しております」（個別商品の情報がない）
- 「シミが消える」「アンチエイジング」（薬機法違反）

## 3. 商品名（短・30〜40字）

商品リスト・カテゴリページ・カート画面・購入完了画面で表示される。**1行で完結する読みやすさ** が最優先。

### 構造

```
[ブランド名] + [商品個性] + [種別]
```

### OK例
- 「[ブランド名] モイスチャライズクリーム 30g」（36字）
- 「[ブランド名] リネン100% ノーカラージャケット」（38字）

### NG例
- 「[ブランド名] 高保湿でしっとり潤う化粧水30mL 全肌質対応 敏感肌 乾燥肌 30代 40代 おすすめ 人気 通販 公式 送料無料」（キーワード詰込み）

## 4. 商品名（ロング・40〜60字）

商品ページの h1 相当。SEOで効くキーワードと訴求軸を1つ含める。

### 構造

```
[ブランド名] + [商品個性] + [種別] + [訴求軸]
```

### OK例
- 「[ブランド名] モイスチャライズクリーム 30g／乾燥肌のためのデイリーケア」（45字）
- 「[ブランド名] リネン100% ノーカラージャケット（オールシーズン・3カラー・S/M/L）」（55字）

## 5. 商品説明（一覧用・200〜400字）

カテゴリページや商品リストで表示される要約。**商品ページに来る前の決め手** になる。

### 構造

1. 1〜2文：商品が何で誰向けか
2. 1〜2文：差別化（素材／機能／産地／こだわり）
3. 1文：信頼要素（送料無料／レビュー数／返品OKなど）

### OK例（180字）

「乾燥が気になる肌をうるおいで満たすフェイスクリーム30g。フランス産○○エキスを配合し、なじみのよいテクスチャで朝晩のお手入れの最後にお使いいただけます。30代・40代の方に多くお選びいただいています。送料無料・初回購入の方にはサンプル付き。」

## 6. 商品説明（詳細・1,500〜3,000字）

商品ページの本文。最も時間をかけて書く部分。

### 構造例（化粧品）

```
[h2] 商品の特徴
（300〜500字：何が良いのか、誰向けか、競合との差）

[h2] こんな方におすすめ
（150〜300字：箇条書き3〜5項目）

[h2] スペック
（テーブルでスッキリ）

[h2] 使い方
（300〜500字：朝・夜・週次ケアの順序）

[h2] 全成分
（全成分表記）

[h2] お客様の声
（200〜400字：実在レビュー抜粋・出典あり）

[h2] よくある質問
（300〜600字：Q&A 5〜10組）

[h2] 配送・返品について
（150〜300字：特商法表記と整合）
```

### スマホ表示優先

- 1段落 3〜5行で改行
- 横幅固定の table を避け、`<dl>` リスト or 縦並びにする
- 画像は幅100%でレスポンシブ

## 7. フリースペース1（キャッチ・100〜200字）

商品ページの最上部・商品名直下に差し込まれる場合が多い。**第一印象** を決める。

### 構造

1. h2 タイトル（10〜20字）
2. キャッチ本文（80〜150字）
3. 必要なら CTA（「カートに入れる」「サイズを選ぶ」）

### OK例

```html
<h2>みずみずしさが続く、毎日の保湿クリーム</h2>
<p>うるおいを与えながら、肌をすこやかに保つ
デイリーユースの保湿クリームです。
朝晩のお手入れの最後にお使いいただけます。</p>
```

## 8. フリースペース2（スペック表）

`<table>` で整理。横幅は固定しないか、`max-width` で。

### OK例

```html
<table class="spec">
  <tr><th>容量</th><td>30g</td></tr>
  <tr><th>使用目安</th><td>約2ヶ月（1日2回）</td></tr>
  <tr><th>対象肌</th><td>全肌質</td></tr>
  <tr><th>主要成分</th><td>○○エキス、××オイル</td></tr>
  <tr><th>原産国</th><td>日本</td></tr>
</table>
```

## 9. フリースペース3（使い方ステップ）

番号付きリスト or 図解。

### OK例

```html
<ol class="step">
  <li>洗顔・化粧水の後、適量（パール粒大）を手に取ります</li>
  <li>顔全体に内側から外側へなじませます</li>
  <li>気になる部分は重ねづけしてください</li>
</ol>
```

## 10. フリースペース4（お手入れ／取扱い）

商品ジャンル別：

- アパレル：洗濯表示・素材ケア
- 食品：保存方法・賞味期限
- コスメ：保管温度・開封後の使用期限
- 家電：清掃・メンテナンス
- 雑貨：耐久性・お手入れ

## 11. フリースペース5（FAQ）

Q&A 5〜10組。**実際に問合せが多い質問** を選ぶ。

### OK構造

```html
<h2>よくある質問</h2>
<dl class="faq">
  <dt>Q. 敏感肌でも使えますか？</dt>
  <dd>A. パッチテストの上、ご使用ください。心配な方は事前にお問合せください。</dd>
  <dt>Q. 妊娠中・授乳中でも使えますか？</dt>
  <dd>A. 配合成分は通常の化粧品基準ですが、ご心配な場合は主治医にご相談ください。</dd>
</dl>
```

## 12. フリースペース6（レビュー抜粋）

実在レビューを匿名化して引用。**誘導的な編集はしない**（ステマ規制・信頼毀損）。

### OK例

```html
<h2>お客様の声</h2>
<blockquote>
  「テクスチャが軽くて朝のお手入れに使いやすい」
  <cite>30代女性・購入後1ヶ月</cite>
</blockquote>
```

### NG例

- マイナス意見だけを削除した編集
- インフルエンサーレビューをPR表記なしで引用
- 「効果テキメン」「シミが消えた」など効能効果断定（薬機法違反）

## 13. フリースペース7（関連商品案内）

「あわせて使うと良い」「同シリーズの他商品」「サイズ違い・色違い」など。

### OK例

```html
<h2>あわせて使う</h2>
<ul>
  <li>同シリーズの化粧水：[商品ページへのリンク]</li>
  <li>同シリーズの美容液：[商品ページへのリンク]</li>
</ul>
```

## 14. フリースペース8（配送・返品）

**特商法表記ページと表記を一致** させる。商品個別の特記事項（冷蔵便・予約発送日など）はここに。

### OK例

```html
<h2>配送・返品について</h2>
<ul>
  <li>発送：注文後3営業日以内</li>
  <li>送料：5,000円以上で無料</li>
  <li>冷蔵便でのお届け（送料に冷蔵代込み）</li>
  <li>返品：開封後の返品はお受けできません（特定商取引法に基づく表記をご確認ください）</li>
</ul>
```

## 15. フリースペース9（キャンペーン文言）

期間限定のみ使う。**終了日とセットで運用** すること。終了後の残置は信頼低下要因。

### OK例

```html
<h2>○月の特別キャンペーン</h2>
<p>○月15日まで、対象商品10%OFF。クーポンコード「AUTUMN10」をご利用ください。</p>
```

## 16. フリースペース10（製造者・産地・ブランドストーリー）

ブランドの世界観を伝える。商品ページのうち**最も自由度が高い** 部分。

### OK例

- 工房・工場の風景
- 産地の歴史
- 作り手のメッセージ
- 素材の調達ストーリー

## CSV エスケープの実務

各パーツのHTML を CSV のフリースペース列に貼る際の典型：

- 列値全体を `"` で囲む
- 内部の `"` を `""` に二重化
- カンマ `,` を含む値は `"` 囲み必須
- 改行を含む値は `"` 囲み内に収める（仕様により `<br>` への置換が必要な場合あり）
