# MakeShop 商品ページコピー作成

## 概要

MakeShop の商品ページは「SEOタイトル／メタディスクリプション／商品名（短）／商品名（ロング・h1）／商品説明（一覧用）／商品説明（詳細）／フリースペース1〜10」のパーツで構成される。本スキルは、各パーツの文字数・構造・役割を踏まえて、商品マスタにそのまま投入できる文案（HTML含む）を出力する。

特徴的なのは **フリースペース1〜10**。商品ページのテンプレに `<!--MS:フリースペース1-->` 等の擬似タグで埋め込まれており、CSV側のフリースペース列を更新すると商品ページに動的に差し込まれる。1〜10をどう使い分けるかが商品ページの読みやすさと回遊率を決める。

## ★最重要原則

**「フリースペース1〜10の役割を店舗で固定し、毎商品で同じ位置に同じ種類のパーツが入るようにする」**。フリースペースは自由度が高いため、商品ごとに「1にスペックが入る商品」と「1にFAQが入る商品」が混在すると、店舗全体の読みやすさと回遊性が破綻する。本スキルは標準的な割り当て（1=キャッチ／2=スペック表／3=使い方／4=お手入れ／5=FAQ／6=レビュー抜粋／7=関連商品／8=配送・返品／9=キャンペーン／10=ブランドストーリー）を提示し、店舗ルールに合わせて調整する。

化粧品・健康食品・医療機器・健康器具を扱う場合は **薬機法（化粧品56効能・健食4分類）** を必ず先に通す。

## 処理フロー

### Step 1：前提整理（仮置きOK）

- 商品ジャンル：化粧品／健康食品／アパレル／食品／雑貨／家電／デジタル等
- 商品の販売形態：単品／セット／定期便／予約／受注生産
- ターゲット：年齢層・性別・利用シーン
- 客単価・流入主軸（自然検索／SNS／広告／既存顧客）
- ブランドトーン
- 現状の商品ページ（あれば改善前テキスト）
- 店舗のフリースペース1-10 の役割割当（標準割当でよいか／既存ルールがあるか）

不明な項目は仮置きし、冒頭で「仮定」として明示。

### Step 2：薬機法・景表法・特商法の事前チェック

ジャンルが化粧品・健康食品・医療機器・健康器具に該当する場合、`references/legal-checkpoints.md` で先にNG/OK境界を確認。化粧品なら厚労省56項目内、健食なら届出範囲内に表現を制限。詳細な表現判定は `yakki-keihyo-expression-check` スキル併用。

### Step 3：SEOタイトル（28〜32字）

構造：`[商品の主キーワード] + [差別化軸] + [ブランド名]`

OK：「高保湿フェイスクリーム30g｜乾燥肌向け｜[ブランド名]」（30字）
NG：「商品ページ｜通販ショップ」（抽象的）、「[ブランド名] | [ブランド名] | おすすめ | 通販 | 公式 | 最安」（詰込み＋景表法）

### Step 4：メタディスクリプション（80〜120字）

構造：`[商品の要約] + [差別化] + [CTA色の語尾]`

全商品で同一テンプレ文を避ける（重複コンテンツ）。薬機法逸脱表現を排除。

### Step 5：商品名（短／ロング）

- 短（30〜40字）：商品リスト・カート画面で1行完結
- ロング（40〜60字）：h1相当、キーワード＋訴求軸を1つ

構造：`[ブランド名] + [商品個性] + [種別]`（短）
構造：`[ブランド名] + [商品個性] + [種別] + [訴求軸]`（ロング）

### Step 6：商品説明（一覧用 200〜400字）

カテゴリページ・商品リストで表示される要約。商品ページに来る前の決め手。

構造：
1. 1〜2文：商品が何で誰向けか
2. 1〜2文：差別化（素材／機能／産地／こだわり）
3. 1文：信頼要素（送料無料／レビュー数／返品OK）

### Step 7：商品説明（詳細 1,500〜3,000字）

商品ページ本文。h2 で区切り、スマホで1段落3〜5行。

化粧品の場合の構造例：
```
[h2] 商品の特徴（300〜500字）
[h2] こんな方におすすめ（150〜300字・箇条書き）
[h2] スペック（テーブル）
[h2] 使い方（300〜500字）
[h2] 全成分
[h2] お客様の声（200〜400字・実在レビュー）
[h2] よくある質問（300〜600字・Q&A 5〜10組）
[h2] 配送・返品について（150〜300字・特商法表記と整合）
```

横幅固定の table は避け、`<dl>` リスト or 縦並びにする。

### Step 8：フリースペース1〜10 を埋める

標準割当：

| # | 役割 | 文字数目安 |
|---|---|---|
| 1 | キャッチ／導入 | 100〜200字 |
| 2 | スペック表（table / dl） | 構造化されたデータ |
| 3 | 使い方ステップ（ol） | 番号付きリスト |
| 4 | お手入れ／取扱い | 箇条書き |
| 5 | FAQ（dl） | Q&A 5〜10組 |
| 6 | レビュー抜粋（blockquote） | 200〜400字 |
| 7 | 関連商品案内（ul + リンク） | 短く |
| 8 | 配送・返品（商品個別の特記事項） | 150〜300字 |
| 9 | 季節キャンペーン（終了日とセット） | 100字程度 |
| 10 | 製造者・産地・ブランドストーリー | 300〜800字 |

各パーツのHTMLテンプレは `references/free-space-templates.md` をそのまま転用可。

### Step 9：CSVエスケープ（CSV側に入れる場合）

- 列値全体を `"` で囲む
- 内部の `"` を `""` に二重化
- カンマ `,` を含む値は `"` で囲み必須
- 改行は `"` 囲み内（仕様で不可なら `<br>` に置換）

詳細は `makeshop-product-csv-validator` スキル併用。

### Step 10：法令・整合の最終チェック

- 薬機法：化粧品56効能内／健食の届出範囲内／医療機器の承認範囲内
- 景表法：「最安」「No.1」（根拠なし）「絶対」「完全」「業界初」（根拠なし）等を排除
- 二重価格：通常価格は直前8週のうち4週以上で実販売実績
- 特商法：定期便は契約期間・解約条件・総額表示の記載
- ステマ規制：インフルエンサー引用に「PR」「広告」表記、レビュー誘導なし
- アレルゲン：食品は特定原材料8品目（えび／かに／くるみ／小麦／そば／卵／乳／落花生）の表示

## 代表例：化粧品（フェイスクリーム・全パーツ）

**SEOタイトル（30字）**：
```
高保湿フェイスクリーム30g｜乾燥肌向け｜[ブランド名]
```

**メタディスクリプション（98字）**：
```
乾燥が気になる肌をうるおいで満たすフェイスクリーム30g。なじみのよいテクスチャで朝晩のお手入れの最後に。送料無料／レビュー多数。
```

**商品名（ロング・45字）**：
```
[ブランド名] モイスチャライズクリーム 30g／乾燥肌のためのデイリーケア
```

**フリースペース1（キャッチ）**：
```html
<section class="fs-catch">
  <h2>みずみずしさが続く、毎日の保湿クリーム</h2>
  <p>うるおいを与えながら、肌をすこやかに保つデイリーユースの
  保湿クリームです。朝晩のお手入れの最後にお使いいただけます。</p>
</section>
```

**フリースペース2（スペック表）**：
```html
<section class="fs-spec">
  <h2>スペック</h2>
  <dl class="spec-list">
    <dt>容量</dt><dd>30g</dd>
    <dt>使用目安</dt><dd>約2ヶ月（1日2回）</dd>
    <dt>対象肌</dt><dd>全肌質</dd>
    <dt>主要成分</dt><dd>○○エキス、××オイル</dd>
    <dt>原産国</dt><dd>日本</dd>
  </dl>
</section>
```

他ジャンル（健康食品／アパレル／食品ギフト／雑貨／家電）の完全例とフリースペース3〜10の全パターンは `references/examples.md` と `references/free-space-templates.md` を参照。

## 品質ゲート

- [ ] SEOタイトル 28〜32字、固有値（全商品同一テンプレ禁止）
- [ ] メタディスクリプション 80〜120字、固有値
- [ ] 商品名（短）が1行で完結する 30〜40字
- [ ] 商品説明（詳細）が h2 で区切られスマホ1段落3〜5行
- [ ] 横幅固定の table を避け `<dl>` か縦並びにしている
- [ ] フリースペース1〜10 の役割が店舗で統一されている
- [ ] 化粧品56効能・健食4分類の薬機法逸脱なし
- [ ] 「最安」「No.1」「絶対」「完全」「業界初」（根拠なし）等の景表法NG表現なし
- [ ] 定期便を扱う場合、特商法の定期購入規制（2回以上）の記載要件を満たす
- [ ] レビュー抜粋・インフルエンサー引用に PR表記／投稿内容の自由度を担保
- [ ] HTMLタグの開閉対応／インラインCSSを最小限に抑えた
- [ ] CSV投入時のエスケープ規則を反映可能な形式

## エッジケース

- **店舗ルールが既に存在しフリースペース割当が異なる**：店舗ルール優先。本スキルの標準割当（1=キャッチ／2=スペック…）は調整して使う
- **テンプレ側で受けない擬似タグがある**：`<!--MS:フリースペース11-->` 等を使ってもテンプレに位置が無ければ表示されない。事前にテンプレ側の擬似タグ位置を確認
- **インラインCSSが暴発してレイアウト崩壊**：スマホ表示で崩れる典型。`max-width` 指定／横幅固定のtable回避／画像は幅100%
- **改行が想定外に残った**（CSV改行と `<br>` の混在）：CSVは1セル内の改行を `"` で囲んで保持するか、すべて `<br>` に置換する運用を統一
- **季節キャンペーン（フリースペース9）の残置**：終了日後に文言が残ると信頼低下。終了日とセットで撤去ルール
- **健康食品で「痩せる」「血糖値が下がる」**：いわゆる健康食品ならNG。トクホ・機能性表示食品で届出があるなら範囲内で

詳細は `references/page-parts-writing-guide.md` と `references/legal-checkpoints.md`。

## 注意事項

- MakeShop の **フリースペース列の上限・対応HTMLタグ・テンプレ側の擬似タグ表記** はプラン・時期で変動する。本ファイルは2026年5月時点の整理であり、最終的に管理画面・テンプレ編集画面で確認すること
- フリースペースに `<script>` `<iframe>` `<style>` を含めるかはセキュリティ上の店舗仕様による（通常サニタイズ）
- 法律・税務・規約の最終判断は **専門家／消費者庁・厚労省・公正取引委員会等の公式ガイドライン** で確認
- CSV投入時の事故防止には `makeshop-product-csv-validator` スキルを併用
- レビュー抜粋は **実在のレビューのみ**。捏造・改変・PR非明示はステマ規制・景表法違反
