# レビュー分類4軸

## 軸1：言及対象

レビューが何について書かれているかの分類。

| 対象 | 例 |
|---|---|
| 商品自体 | 「商品の機能・品質・サイズ・デザイン」 |
| 配送 | 「配送が早い／遅い」「梱包が丁寧／雑」 |
| 顧客対応 | 「メール対応が丁寧」「電話対応が悪い」 |
| 梱包 | 「化粧箱がきれい」「箱が潰れていた」 |
| 販促 | 「ポイント還元が良い」「クーポンが使えた」 |
| 総合 | 「全体的に満足」「ハズレ」 |

複数の対象が言及されることが多い（例：「商品は良いが配送が遅い」）。

## 軸2：感情

| 感情 | 例 |
|---|---|
| ポジティブ | 「満足」「良い」「おすすめ」「リピート」 |
| ネガティブ | 「がっかり」「想像と違う」「失敗」 |
| 中立 | 「普通」「可もなく不可もなく」 |
| 質問・要望 | 「○○について教えてほしい」「○○の対応をお願い」 |

星評価とは必ずしも一致しない：
- 星5でも「○○がもう少しあれば完璧」（要望）
- 星3で「商品は満足だが配送が遅い」（中立＋ネガ）

## 軸3：主要テーマ

商品自体への言及内容の分類。ジャンルにより細分化。

### 共通テーマ

| テーマ | 例 |
|---|---|
| 機能・性能 | 「○○の機能が良い／悪い」 |
| サイズ・容量 | 「思ったより大きい／小さい」 |
| 品質・素材 | 「丈夫」「すぐ壊れた」「素材が良い」 |
| デザイン | 「おしゃれ」「ダサい」「色が違う」 |
| 価格 | 「コスパ良い」「高い／安い」 |
| 使いやすさ | 「操作が簡単／複雑」 |
| 説明書 | 「分かりやすい／分かりにくい」 |
| お手入れ | 「掃除が楽／面倒」 |
| 耐久性 | 「長持ち／すぐダメに」 |

### ジャンル別の追加テーマ

#### 食品
- 味、香り、量、ボリューム、賞味期限、原産地
- 「美味しい」「辛い」「甘い」「家族で楽しめた」

#### 化粧品
- 使用感、テクスチャ、香り、肌への合う／合わない、効果実感
- 注意：効能訴求の記述は広告転載NG

#### ファッション
- サイズ感、素材感、着心地、デザイン、コーディネート
- 「身長○cmで○サイズがちょうど」のようなスペック情報

#### 家電
- 機能、操作性、静音性、消費電力、保証、付属品
- 「思ったより音が大きい」「期待通りの性能」

#### ベビー用品
- 月齢適合、安全性、肌への優しさ、洗濯耐性、デザイン
- 「うちの子はよく使う」「すぐ卒業した」

## 軸4：対処可否

| 区分 | 内容 | 対応 |
|---|---|---|
| 仕様改善可 | 商品の機能・付属品・梱包の改善で対応 | 商品改善・次回ロット |
| ページ改善可 | 説明・サイズ表・FAQ追加で対応 | 説明文・画像の改善 |
| 運用改善可 | 配送・対応・梱包の運用で対応 | オペレーション見直し |
| 個人差 | 主観・体質・好み | 対応不要（または注釈追加） |
| 対応不要 | 誤解・誤読 | 必要に応じてFAQ追加 |

## 分類の実例

### 例：電気ケトルのレビュー

**レビュー文**：
> 「思っていたよりかなり大きかったです。一人暮らしには大きすぎるかも。沸騰速度は早く満足ですが、お手入れが少し面倒。総合的には星3」（星3）

**分類**：
- 言及対象：商品自体（複数）
- 感情：ネガ＋ポジ＋中立
- テーマ：
  - サイズ：ネガ「大きすぎる」
  - 機能・性能：ポジ「沸騰速度が早い」
  - お手入れ：ネガ「面倒」
- 対処可否：
  - サイズ：ページ改善可（サイズ表記・スケール感画像を追加）
  - 機能：USP訴求素材
  - お手入れ：ページ改善可（お手入れ方法のFAQ追加）

## 集計テンプレート

### テーマ別集計表

| テーマ | 件数 | ポジ | ネガ | 中立 | 平均星 | 優先度 |
|---|---|---|---|---|---|---|
| サイズ | 18 | 12 | 6 | 0 | 3.7 | 高 |
| 沸騰速度 | 14 | 13 | 1 | 0 | 4.6 | 中（訴求） |
| 温度調整 | 12 | 11 | 1 | 0 | 4.5 | 中（訴求） |
| お手入れ | 10 | 6 | 4 | 0 | 3.8 | 中 |
| デザイン | 8 | 7 | 1 | 0 | 4.3 | 低 |
| 配送 | 12 | 11 | 1 | 0 | 4.5 | 低 |

### 優先度判定基準

| 優先度 | 条件 |
|---|---|
| 高 | 件数10件以上 ＆ ネガ多数（半数以上） |
| 中 | 件数10件以上 ＆ ポジ多数（USP候補）／件数5-10件のネガ多数 |
| 低 | 件数5件未満 ／ ポジ・ネガ拮抗 |

## レビューの読み方

### 言葉の裏を読む

| レビュー記述 | 本音の可能性 |
|---|---|
| 「期待していたほどではなかった」 | 大失敗ではないが推奨はしない |
| 「リピート確定」 | 強い満足、訴求素材に最適 |
| 「もう少し○○なら」 | 改善要望（仕様変更で対応可） |
| 「○○の人には合わないかも」 | 個人差・特定ターゲット向け |
| 「説明書をよく読めば分かる」 | 説明書が分かりにくいヒント |

### 星評価と本文の乖離

- 星5で文面が淡白：定型的、参考にしにくい
- 星3で文面が詳しい：最も参考になるレビュー（改善ヒント満載）
- 星1で文面が短い：個別対応必要（クレーム）

### 「個人の感想」の扱い

- 化粧品・食品で「効果がありました」「美味しかった」は個人の感想
- これを商品ページに転載すると、広告主の表示とみなされ景表法・薬機法の対象に
- レビュー転載は許諾＋効能訴求として使わない注意

## 顧客特定情報の匿名化

- 投稿者名・地域名・購入経緯を本文中で特定される場合は要注意
- 顧客の声として商品ページに使う場合は完全匿名化

## レビュー分析の頻度

- 新商品：月次（最初の3ヶ月）
- 安定商品：四半期
- ロングセラー：半年
- 競合分析：半期〜年次
