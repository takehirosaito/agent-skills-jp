# 出品プラン比較

Amazon.co.jp の出品プラン（大口／小口）の比較と、損益分岐点の算出。

## プラン概要

### 大口出品プラン
- **月額**：4,900円（税抜）
- **1販売あたり**：販売手数料のみ（成約料は別）
- **販売数制限**：なし
- **広告**：スポンサープロダクト・スポンサーブランド・スポンサーディスプレイすべて利用可
- **A+コンテンツ**：利用可
- **ブランドストア**：利用可
- **一括登録**：可
- **API連携**：可

### 小口出品プラン
- **月額**：0円
- **1販売あたり**：100円＋販売手数料＋成約料
- **販売数制限**：なし
- **広告**：スポンサープロダクトのみ
- **A+コンテンツ**：原則利用不可（プランによる）
- **ブランドストア**：利用不可
- **一括登録**：制限あり
- **API連携**：不可

## 損益分岐：何件売れば大口が有利？

```text
大口の固定費（4,900円）÷ 小口の1件あたり追加コスト（100円）= 49件
```

→ **月間50件以上**販売するなら大口が有利。

## 計算例

### 例1：月10件販売
- 大口：4,900円 ÷ 10 = 1販売あたり490円の月額按分（販売手数料・成約料は別）
- 小口：1販売あたり100円（販売手数料・成約料は別）
- → 小口が有利（差額3,900円）

### 例2：月30件販売
- 大口：4,900円 ÷ 30 = 163円／件
- 小口：100円／件
- → 小口が有利（差額1,900円）

### 例3：月49件販売
- 大口：4,900円 ÷ 49 = 100円／件
- 小口：100円／件
- → ほぼ同等

### 例4：月100件販売
- 大口：4,900円 ÷ 100 = 49円／件
- 小口：100円／件
- → 大口が有利（差額5,100円）

### 例5：月1,000件販売
- 大口：4,900円 ÷ 1,000 = 4.9円／件
- 小口：100円／件
- → 大口が圧倒的に有利（差額95,100円）

## 大口プラン利用の付加価値

販売数による損益分岐とは別に、大口プランでないと利用できない機能の価値：

| 機能 | 価値 |
|---|---|
| 商品ページのコンテンツ管理（A+） | CVR向上 |
| ブランドストア | ブランド体験 |
| スポンサーブランド広告 | ブランド認知 |
| API連携（MWS／SP-API） | 在庫・受注の自動化 |
| 一括登録 | 数百〜数千SKUの効率管理 |
| カテゴリ申請（医薬品・酒類等）の優先 | 制限カテゴリ参入 |

→ 月間販売数が少なくても、戦略的に大口プラン採用するケースあり。

## プラン切替

### 小口 → 大口
- セラーセントラル「設定＞アカウント情報＞出品サービスのアカウントタイプ」
- 即時切替可
- 切替月の月額発生

### 大口 → 小口
- 同上から切替
- 切替月の月額発生（日割計算なし）
- 一部機能（A+・ブランドストア）の利用停止

## プラン選択の意思決定フロー

```text
月間販売数 < 49件
  ↓
  Yes → 機能ニーズ確認
        - A+／ブランドストア要 → 大口
        - 不要 → 小口
  No → 大口
```

## 実務的な推奨

### 個人セラー・副業セラー（月間販売数少）
- 小口プラン
- 利益確保優先

### 中小規模セラー（月間販売数50〜1,000）
- 大口プラン
- A+・スポンサーブランド広告活用

### 大規模セラー（月間販売数1,000以上）
- 大口プラン
- API連携・データドリブン運用

### 法人ブランド出品
- 大口プラン
- ブランドストア・Brand Registry 必須

## 複数アカウントの扱い

- 通常、1社1アカウントが原則（Amazon ポリシー）
- 複数アカウント申請には事前承認が必要
- 1アカウントに集約することで月額4,900円を節約

## 「販売ゼロ月」の月額

- 大口プラン：販売ゼロでも月額4,900円が発生
- 小口プラン：販売ゼロなら0円

長期休業・季節休業時は小口に切替推奨。

## プラン切替の注意

- A+コンテンツが既にある状態で大口→小口にすると、A+表示が消える
- ブランドストアも同様
- スポンサーブランド広告キャンペーンは停止される
- 切替後の影響を確認してから決定

## 月額の按分計算

利益計算では、月額4,900円を1販売あたりに按分：

```text
1販売あたり月額按分 = 4,900円 ÷ 月間販売数（全SKU合計）
```

例：月間総販売数500件 → 4,900円 ÷ 500 = 9.8円／件 を全販売に均等按分

または、SKU別に粗利寄与度で配分する高度な按分方法もあり。

## 損益分岐の他指標

### 大口プランで採算が合うために必要な売上

```text
最低必要売上 = 4,900円 ÷ 平均営業利益率
```

平均営業利益率20%なら：4,900 ÷ 0.20 = 24,500円／月

→ 月24,500円以上の売上があれば、大口プランの月額分を回収できる。

### 大口プランで採算が合うために必要な販売数（平均単価別）

| 平均販売単価 | 必要販売数（月） |
|---|---|
| 500円 | 49件 |
| 1,000円 | 24.5件 |
| 2,000円 | 12.25件 |
| 5,000円 | 4.9件 |
| 10,000円 | 2.45件 |

→ 高単価商品なら月数件でも大口が有利。
