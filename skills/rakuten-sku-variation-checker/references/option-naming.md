# 選択肢名の命名規則

## 基本ルール

1. **表記を統一**：同じ意味の選択肢は同じ表記
2. **論理順に並べる**：サイズはS→M→L、容量は小→大
3. **スマホで読みやすい文字数**：5-10字程度
4. **顧客の検索語と合わせる**：「ピンク」と「Pink」なら「ピンク」が一般的

## サイズ表記

### 服のサイズ

| 表記 | 推奨 |
|---|---|
| アルファベット | S / M / L / LL / 3L / 4L |
| 数値 | 7号 / 9号 / 11号 / 13号 / 15号 |
| インチ | 28 / 30 / 32 / 34 / 36 |
| 子供服 | 90 / 100 / 110 / 120 / 130 / 140 / 150 / 160 |
| ベビー | 60 / 70 / 80 / 90 |

### NG表記
- 半角の「S」と全角の「Ｓ」混在
- 「small」と「S」混在
- 「Sサイズ」と「S」混在（どちらかに統一）

### 順序

| サイズ | 順序 |
|---|---|
| S → M → L → LL → 3L → 4L | 小→大 |
| 7号 → 9号 → 11号 → 13号 → 15号 | 小→大 |
| 90 → 100 → 110 → 120 → 130 → 140 → 150 → 160 | 小→大 |

逆順や混在を避ける。

## 色表記

### 推奨表記

| 標準 | 別表記（避ける） |
|---|---|
| ブラック | Black、黒、BK |
| ホワイト | White、白、WH |
| レッド | Red、赤、RD |
| ブルー | Blue、青、BL |
| グリーン | Green、緑、GR |
| イエロー | Yellow、黄、YL |
| ピンク | Pink、桃、PK |
| ベージュ | Beige、肌色、BE |
| グレー | Gray、灰、GY |
| ネイビー | Navy、紺、NV |
| カーキ | Khaki、KA |

### NG表記
- 「ブラック」「Black」「BK」を混在
- 「茶」「ブラウン」「Brown」を混在

### 色の順序

論理的な順序が無いが、以下が一般的：
1. ブラック・ホワイト（無彩色）
2. 暖色系（レッド・オレンジ・イエロー・ピンク）
3. 寒色系（ブルー・グリーン・ネイビー）
4. グレー・ベージュ等

### 「カラフル」「マルチ」等の混色

- 「マルチカラー」「カラフル」を使う
- 「色1」「色2」のような曖昧表記は避ける

## 容量表記

### 推奨

| 表記 | 単位 |
|---|---|
| 50ml / 100ml / 200ml / 500ml | ml（液体） |
| 50g / 100g / 200g | g（固体・粉末） |
| 1個 / 3個セット / 6個セット | 個数 |
| 30粒 / 60粒 / 90粒 | 粒（サプリ） |

### NG
- 「100ML」「100 mL」「100ml」の混在 → 統一
- 「50g」と「50グラム」の混在

### 順序
- 容量小→大
- 「お試し」「小」「中」「大」より具体的な数値推奨

## セット内容表記

### 推奨

```
3点セット（化粧水＋乳液＋美容液）
5点セット（A＋B＋C＋D＋E）
お試しセット（化粧水30ml＋乳液15ml）
```

### NG
- 「セット1」「セット2」（内容不明）
- 「フルセット」（具体性なし）

## バリエーション軸が複数の場合の表記

### 2軸（サイズ × 色）

| 表記 | 推奨 |
|---|---|
| 「S/ブラック」 | 標準 |
| 「Sサイズ ブラック」 | 標準 |
| 「ブラック / Sサイズ」 | 色→サイズの順序 |

→ 楽天では選択肢を **2つに分ける**（サイズ選択＋色選択）のが基本。1選択肢に「S/ブラック」と書くのではない。

### 3軸（サイズ × 色 × 素材）

- 選択肢を3つに分ける
- スマホで選びにくくなるので、可能なら2軸まで

## 在庫切れSKUの扱い

### オプション1：選択肢に残す
- 「ブラック（在庫切れ）」と表示
- 選択不可
- メリット：商品の存在を顧客に知らせる
- デメリット：選びにくい

### オプション2：選択肢から削除
- 在庫がある色のみ表示
- メリット：シンプル
- デメリット：再入荷時の再登録手間

### 推奨
- 短期欠品：選択肢に残す
- 長期欠品・終売：削除

## 「フリーサイズ」「ワンサイズ」

サイズが1種類しかない商品の表記：

| 表記 | 用途 |
|---|---|
| フリーサイズ | 一般的 |
| ワンサイズ | 同上 |
| F（記号） | 表で混在NG |

→ 「フリーサイズ」が最も検索される語。

## 数量表記

### セット数
- 「1個」「3個セット」「6個セット」
- 「単品」「3個入り」「6個入り」（食品）

### 注意
- 「1袋」と「1個」の混在を避ける（同じ意味なら統一）
- 「○本」「○枚」「○セット」の使い分け

## 配送タイプの表記

| 表記 | 用途 |
|---|---|
| 常温配送 | 一般 |
| 冷蔵配送 | 食品 |
| 冷凍配送 | 食品 |
| あす楽対応 | 配送速度 |

## 名入れ・カスタマイズ

### テキスト入力タイプ

| 表記 | 用途 |
|---|---|
| お名前を入力 | 名入れ |
| メッセージカード文面 | ギフト |
| 刻印文字 | アクセサリー |

### 注意
- 文字数制限を明示
- 半角・全角の指定
- 使えない文字（特殊記号等）の明示

## 選択肢名のチェックリスト

設定時：

- [ ] 表記が統一されている（同じ意味の選択肢は同じ表記）
- [ ] 論理順に並んでいる（サイズ小→大、容量小→大）
- [ ] スマホで読みやすい長さ（5-10字目安）
- [ ] 半角・全角の混在なし
- [ ] 顧客の検索語と合っている
- [ ] 在庫切れSKUの扱いが決まっている
- [ ] 2軸を超える場合は選択肢を分けている

## 表記揺れの検出

CSV上で同じ意味の表記揺れをチェック：

```python
# Pythonの例
import csv
from collections import Counter

options = []
with open('select.csv', 'r', encoding='shift_jis') as f:
    for row in csv.DictReader(f):
        options.append(row['選択肢項目'])

count = Counter(options)
# 似た表記を見つける
for opt, cnt in count.items():
    print(f"{opt}: {cnt}回")
```

→ 「ブラック」「Black」「BK」が混在していると検出される。

## バリエーション表示の見え方

### スマホでの表示

選択肢ボタンが横並びで表示される。一画面に収まらない場合、横スクロール。

- 5-7個までが選びやすい
- それ以上は「すべての選択肢を見る」リンク

### PCでの表示
- 縦並びまたは横並び
- 全選択肢が一覧で見える
