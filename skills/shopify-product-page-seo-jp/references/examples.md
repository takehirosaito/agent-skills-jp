# ジャンル別 商品ページSEO 実例集

## 例1：化粧品（ビタミンC美容液）

### 入力
- 商品名：Bloom Petal セラム 30mL
- ジャンル：化粧品
- 主要KW：ビタミンc 美容液、高濃度、敏感肌
- 商品説明（既存）：「高濃度ビタミンC配合の美容液です。」

### 出力

| 項目 | 値 | 全角換算 |
|---|---|---|
| Product title | Bloom Petal セラム 30mL | 17 |
| SEO title | ビタミンC美容液 高濃度10%｜Bloom Petal セラム | 30 |
| Meta description | 肌に塗る瞬間とろける高濃度ビタミンC10%美容液。低刺激処方で敏感肌にも。送料無料・30日返品OK。 | 79 |
| handle | vitamin-c-serum-30ml | - |
| 画像 alt（メイン） | ビタミンC10%美容液30mL Bloom Petal セラム 正面 | - |

**注意**：化粧品カテゴリのため「シミに効く」「シワが消える」「美白」は不可。`yakki-keihyo-expression-check` 併用推奨。

## 例3：健康食品（機能性表示食品）

### 入力
- 商品名：DHA・EPA サプリメント（機能性表示食品）
- 届出番号：A123
- 届出文言：「本品にはDHA・EPAが含まれます。DHA・EPAには血中中性脂肪を低下させる機能が報告されています。」

### 出力

| 項目 | 値 | 全角換算 |
|---|---|---|
| Product title | DHA・EPA サプリメント [機能性表示食品 A123] | 25 |
| SEO title | DHA・EPA 機能性表示食品 60粒｜中性脂肪が気になる方に | 30 |
| Meta description | 機能性表示食品（届出番号A123）。DHA・EPAには血中中性脂肪を低下させる機能が報告されています。1日2粒・60粒入。 | 80 |
| handle | dha-epa-supplement-60 | - |

**注意**：
- 届出文言は **一字一句改変しない**
- 「血中中性脂肪を下げる」「中性脂肪を減らす」等の改変はNG
- 摂取上の注意（多量摂取で疾病治癒しない、目安量を守る、原材料アレルギー注意）を本文に必ず記載

## 例4：雑貨（美容ローラー）

### 入力
- 商品名：チタン美容ローラー
- ジャンル：雑貨（医療機器ではない）
- 主要KW：美容ローラー、セルフケア、フェイスケア

### 出力

| 項目 | 値 | 全角換算 |
|---|---|---|
| Product title | チタン製 美容ローラー（家庭用） | 17 |
| SEO title | チタン製 美容ローラー 家庭用フェイスケア｜100g軽量 | 30 |
| Meta description | チタン製の家庭用美容ローラー。お顔・首・肩のセルフケアに。重さ約100g。お肌をやさしく転がしてご使用ください。 | 80 |
| handle | titanium-beauty-roller | - |

**注意**：雑貨カテゴリのため以下は不可：
- 「リフトアップ」「血行促進」「むくみが取れる」「小顔」「痩せる」
- 「○○の効果が出る」「皮膚に効く」
- 物理的事実（重さ・素材・使い心地・転がす）のみ訴求

## 例5：食品（有機煎茶）

### 入力
- 商品名：有機緑茶 100g
- ジャンル：食品（一般食品、健康食品ではない）
- 主要KW：緑茶 有機、静岡県産、煎茶

### 出力

| 項目 | 値 | 全角換算 |
|---|---|---|
| Product title | 静岡県産 有機煎茶 100g | 15 |
| SEO title | 有機煎茶 静岡県産 100g｜JAS認証・農薬不使用 | 27 |
| Meta description | 静岡県の有機JAS認証農園で育てた煎茶100g。化学合成農薬・化学肥料不使用。深い甘味とすっきりした後味。 | 76 |
| handle | organic-sencha-100g | - |

**注意**：
- 一般食品のため「健康効果」「血圧を下げる」等は不可（健康増進法）
- 「JAS認証」「有機」表示は **JAS認証取得が前提**。未取得で表示すると違反
- 「最高級」「日本一」など最上級は **客観的根拠** が必要

## ジャンル別の注意点まとめ

| ジャンル | 主リスク | 並行使用推奨スキル |
|---|---|---|
| 化粧品 | 薬機法（56項目外NG）、医薬部外品との混同 | `yakki-keihyo-expression-check` |
| 医薬部外品 | 承認効能の範囲、医薬関係者推薦 | `yakki-keihyo-expression-check` |
| 健康食品（一般） | 健康増進法、効能効果標榜不可 | `yakki-keihyo-expression-check` |
| 機能性表示食品 | 届出文言の改変、注意表示 | `yakki-keihyo-expression-check` |
| 美容雑貨 | 薬機法（未承認医療機器扱い回避） | `yakki-keihyo-expression-check` |
| アパレル | サイズ表示の誤認、素材表示 | （独自） |
| 食品 | JAS認証、原産地、健康増進法 | （独自） |
| 家電 | 電気用品安全法（PSEマーク） | （独自） |
