# 商品説明 HTML テンプレート集

Shopify の商品説明（リッチエディタ）は **HTMLで保存される**。テーマ側で `{{ product.description }}` として展開されるため、見出し階層・リスト・テーブル・dl がそのまま反映される。

## 基本構造（汎用）

```html
<h2>商品の要約</h2>
<p>3行で「誰の」「何を」「どう解決するか」を述べる。</p>

<h2>こんな方におすすめ</h2>
<ul>
  <li>～な悩みの方</li>
  <li>～したい方</li>
  <li>～を求める方</li>
</ul>

<h2>商品の特徴</h2>
<h3>特徴1：見出し</h3>
<p>説明文（裏付け：成分／産地／受賞）</p>
<h3>特徴2：見出し</h3>
<p>...</p>
<h3>特徴3：見出し</h3>
<p>...</p>

<h2>使い方</h2>
<ol>
  <li>ステップ1</li>
  <li>ステップ2</li>
  <li>ステップ3</li>
</ol>

<h2>商品スペック</h2>
<table>
  <tbody>
    <tr><th>容量</th><td>30mL</td></tr>
    <tr><th>主要成分</th><td>ビタミンC10%</td></tr>
    <tr><th>原産国</th><td>日本</td></tr>
    <tr><th>JANコード</th><td>4901234567894</td></tr>
  </tbody>
</table>

<h2>よくあるご質問</h2>
<dl>
  <dt>Q：他社商品と何が違いますか？</dt>
  <dd>A：（差別化点を200字程度）</dd>
  <dt>Q：敏感肌でも使えますか？</dt>
  <dd>A：...</dd>
</dl>

<h2>配送・返品について</h2>
<p>送料無料（全国一律）／最短翌日出荷／30日間返品OK</p>
```

## ジャンル別テンプレ

### 化粧品（薬機法配慮）

```html
<h2>「乾燥による小ジワを目立たなくする※」を体験する美容液</h2>
<p>※乾燥による小ジワを目立たなくする：効能評価試験済み</p>

<h2>こんな方におすすめ</h2>
<ul>
  <li>年齢に応じたお手入れを始めたい方</li>
  <li>乾燥が気になる方</li>
</ul>

<h2>商品の特徴</h2>
<h3>1. 高濃度ビタミンC10%配合</h3>
<p>...</p>
<h3>2. 低刺激処方</h3>
<p>パッチテスト済み（全ての方に肌トラブルが起きないわけではありません）</p>

<h2>使い方</h2>
<ol>
  <li>洗顔後、化粧水で肌を整える</li>
  <li>適量を手に取り、顔全体になじませる</li>
  <li>乳液・クリームでフタをする</li>
</ol>

<h2>全成分</h2>
<p>水、BG、グリセリン、アスコルビン酸、...（全成分を順序通り）</p>
```

**NGワード**：「シミに効く」「シワが消える」「美白（化粧品ではNG、医薬部外品ならOK）」「アンチエイジング」「医療レベル」

## 共通の禁則

- `<font>` `<center>` などHTML4の非推奨タグを使わない（Shopifyリッチエディタが許容しても）
- 画像URLが他ドメインを参照していない（CDNに上げ直す）
- 「絶対」「完全」「日本一」「世界初」など根拠なし最上級を使わない
- 「医師推奨」「皮膚科医監修」を化粧品で使わない（化粧品適正広告ガイドライン）

## Online Store 2.0 のリッチテキスト

Online Store 2.0 のテーマでは、商品説明を**メタフィールドの `rich_text_field` 型に分離**して section に出すケースが増えている。長文の商品説明を section ごと（特徴／使い方／FAQ）に分けたい場合は `shopify-metafields-structure` を参照。
