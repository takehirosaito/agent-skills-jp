# 日本語SEO 文字数ルール

## Shopify の公式上限と実務推奨

| 項目 | Shopify 公式 | 日本語SERP実務推奨 |
|---|---|---|
| Product title（画面表示の商品名） | テーマ依存（概ね255字） | 全角30字以内 |
| SEO title（meta title） | 70字（Shopify管理画面の警告基準） | 全角28-32字 |
| Meta description | 320字（管理画面の入力上限） | 全角70-90字 |

Shopify 管理画面の「Search engine listing preview」は **全角／半角の区別なく文字数カウント** する。実際の Google SERP 表示は **ピクセル幅** で切れるため、文字数ではなく見え方を意識する。

## Google SERP の表示幅（実測ベース）

### PC

- title：おおよそ全角32-35字（または半角約60字）で末尾「…」
- description：おおよそ全角80-120字、または半角160字

### モバイル（より厳しい）

- title：全角28-30字
- description：全角70-90字

→ **モバイル基準で書く**のが安全。

## 文字数換算の感覚

| 文字種 | 換算 |
|---|---|
| ひらがな・カタカナ・漢字 | 全角1字 |
| 全角英数記号 | 全角1字 |
| 半角英数記号 | 半角1字（≒全角0.5字） |

例：「ビタミンC10%美容液30mL」
- 全角換算：ビ(1)タ(1)ミ(1)ン(1) + C(0.5) + 1(0.5)0(0.5)%(0.5) + 美(1)容(1)液(1) + 3(0.5)0(0.5)m(0.5)L(0.5) ＝ 約12全角相当

→ **半角英数は積極的に使ってよい**（表示幅を稼げる）

## 検索意図とキーワード配置

### title の構造（推奨）

```
[コアKW] [属性／差別化] [ブランド名]｜[ストア名（省略可）]
```

例：
- `ビタミンC美容液 高濃度10% 30mL｜Bloom Petal セラム`
- `ローカット スニーカー レディース 23-25cm｜ブランドX`
- `プロテイン ホエイ チョコ味 1kg｜ブランドY`

**禁則**：
- ストア名を先頭に置かない（重要KWを先頭に）
- 「公式」「通販」「送料無料」だけで埋めない
- 同一テンプレを全商品で使い回さない（タイトル重複でクリック率が下がる）

### description の構造（推奨）

```
[誰の何を解決] [差別化／成分・産地・受賞] [CTA／送料・返品・最短発送]
```

例：
- 「肌に塗る瞬間とろける高濃度ビタミンC10%美容液。低刺激処方で敏感肌も使える。送料無料・30日間返品OK。」（全角約78字）

**禁則**：
- 全商品で description が完全同一（カテゴリ全体で重複コンテンツ扱い）
- 詰め込みすぎ（90字を大幅超過すると見えなくなる）
- 「絶対」「完全」「No.1」など根拠なし最上級

## 重複コンテンツとカニバリ

- 同じKWで複数の商品ページが上位を狙うと **内部競合（カニバリ）** が発生
- バリエーション（色・サイズ）を別商品として登録している場合、`title` `description` が酷似 → 1商品＋バリアントに統合 or `<link rel="canonical">` で代表ページを指定

## hreflang（Markets 多言語配信時）

Shopify Markets でドメイン／言語別配信中は、自動で `hreflang` が出力される。手動でJSON-LDやcanonicalを書く場合は、各言語版の URL を相互参照させる。

```html
<link rel="alternate" hreflang="ja" href="https://example.com/ja/products/..." />
<link rel="alternate" hreflang="en" href="https://example.com/en/products/..." />
<link rel="alternate" hreflang="x-default" href="https://example.com/products/..." />
```

## モール検索 vs Google検索（実務メモ）

- Google：ロングテールKW（「ビタミンC美容液 敏感肌 高濃度」のような3-4語）が獲りやすい
- 楽天・Amazon：単語の組み合わせ＋ブランド名で検索される
- Shopify商品ページは**Google向けにロングテール最適化**、モールはモール独自の検索ロジックに合わせる（→ `amazon-search-term-builder-jp` / `rakuten-keyword-map-builder` を別途）
