# セット商品企画スキル

## 概要

複数商品を組み合わせたセット販売・まとめ買い・同梱・定期購入バンドルの企画を立てる。お試しセット／まとめ買い／シーン同梱／ギフト／定期バンドル／詰替セットなど用途別パターンに沿って、構成案・価格設計・粗利検算・商品名・運用注意点まで一気通貫で出力する。

「在庫処分の抱き合わせ」と見られる構成は避け、顧客側の購入動機（節約・贈答・新規お試し・継続）に紐付いた価値ある組み合わせを設計する。

## ★最重要原則

**「単品合計より○○円お得」を打ち出す前に、セット粗利・送料・モール手数料・広告費・CV1回分の運用効率を全て検算する。**

セットは「単品ごとに広告・送料・梱包・CSが必要なところを1回にまとめる」のがビジネスの本質。値引率だけで判断せず、CV1回あたりの実質粗利で見る。

## 処理フロー

### Step 1：入力情報の整理

以下を整理する。不足は「仮定」「不足情報」「確認したいこと」に分けて進める。

- 商品一覧（型番／単品価格／原価／販売数）
- 併売データ（同時購入される組合せ）
- 在庫状況（滞留／適正／薄）
- 送料条件（送料込み or お客様負担）
- モール手数料率・想定広告費率
- 顧客像と購買シーン

### Step 2：セット目的の決定

`references/patterns.md` から目的に合うパターンを選ぶ：

- **新規獲得** → お試しセット（赤字許容、LTV回収設計）
- **客単価UP** → シーン同梱・松竹梅の中段
- **リピートUP** → まとめ買い・詰替セット・定期バンドル
- **贈答需要** → ギフトセット（演出重視、値引きより包装）

### Step 3：構成品の選定

- 売れ筋＋滞留品の抱き合わせはNG
- 主役品＋補完品＋スターター小物の3層が定番
- 構成品全ての在庫整合・賞味期限を確認

### Step 4：価格設計

`references/calculations.md` の式で**必ず検算**：

```
セット粗利 = セット販売価格
          − 構成品原価合計
          − 送料原価
          − モール手数料（販売価格 × 手数料率）
          − 想定広告費（販売価格 × 広告費率）
          − その他コスト
```

値引率の目安：
- まとめ買い：3個=5〜10%／6個=10〜15%／12個=15〜20%
- シーン同梱：10〜15%
- ギフト：0〜5%（演出重視）
- 定期バンドル：10〜15%（初回大幅割引は回収月数を試算）

### Step 5：商品名・ページ構成・モール登録注意点

- 商品名：[ブランド名] [セット名]（構成品3点）の形式
- 画像：1枚目=セット俯瞰／2枚目=使用シーン／3枚目=構成品比較／4枚目=単品との価格差
- JAN：単品JANを流用せずセット用に新規採番
- 在庫管理：構成品連動か別在庫か事前決定

### Step 6：法規・モールポリシー確認

- 「単品で買うより○○円お得」→ 単品価格の販売実績8週間ルール
- 定期バンドル → 特商法 最終確認画面6項目
- 化粧品・健食 → 薬機法表現範囲
- 「No.1」「半額」等 → 根拠5項目（主体・期間・対象・方法・出典）

## 代表例（検算済み）

### 例：化粧品「朝のスキンケア3点セット」

**構成**：化粧水2,000円（原価800）＋美容液3,500円（原価1,400）＋日焼け止め1,800円（原価700）
**単品合計**：7,300円
**セット価格**：6,580円（10%引）
**送料原価**：600円／**手数料率**：10%／**広告費率**：5%

**粗利検算**：
- 販売価格：6,580
- 原価：800＋1,400＋700＝2,900
- 送料：600
- モール手数料：6,580 × 10% = 658
- 広告費：6,580 × 5% = 329
- 粗利：6,580 − 2,900 − 600 − 658 − 329 = **2,093円**
- 粗利率：2,093 ÷ 6,580 = **31.8%**

**単品3点を個別CVした場合の粗利合計**（送料・広告がCV3回分）：1,505円
→ セットの方が588円多く粗利が出る（CV1回で送料・広告効率改善のため）

詳細な他5パターンは `references/examples.md` 参照。

## エッジケース

- **滞留品処分が真の目的** → セット化ではなく「アウトレット」「訳あり」ページで別途分離する。セットで紛れさせない。
- **構成品の在庫が薄い** → セット化を一時停止。または在庫の最少値からセット販売可能数を自動算出する設定に。
- **賞味期限・消費期限が短い** → まとめ買いは消費スピードと期限の整合を顧客視点で確認。
- **包装・熨斗対応の工数が大きい** → 梱包担当の時給×時間を粗利から差し引いた実質粗利で判断。
- **モール手数料率が不明** → 現在契約コース・ジャンルの実手数料率に置き換えるよう促す（参考値での試算であることを明示）。

## 注意事項

- 手数料率・送料・原価は実数に置き換えて再計算すること。本スキルの例示値は仮定。
- 二重価格表示（「通常○○円のところセットなら○○円」）は8週間以上の販売実績が必要。
- 定期購入バンドルは特商法・消費者契約法の最終確認画面6項目を必ず確認。
- 薬機法・景表法のNG表現は別スキル `yakki-keihyo-expression-check` でチェック推奨。
