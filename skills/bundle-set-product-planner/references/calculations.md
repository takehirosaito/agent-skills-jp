# セット商品の計算式と検算例

## 基本式

### セット粗利
```
セット粗利 = セット販売価格
          − 構成品原価合計
          − 送料原価（送料込みプランの場合）
          − モール手数料（販売価格 × 手数料率）
          − 想定広告費（販売価格 × 広告費率）
          − その他コスト（ラッピング・梱包資材・決済手数料等）
```

### セット粗利率
```
セット粗利率 = セット粗利 ÷ セット販売価格
```

### セット値引率
```
値引率 = (単品合計 − セット価格) ÷ 単品合計
```

### 損益分岐数量
```
損益分岐販売数 = 固定費（撮影・LP制作・ページ作成）÷ 1セットあたり粗利
```

## 検算例A：シーン同梱セット（化粧品3点）

**前提**：
- 化粧水：単品2,000円、原価800円（原価率40%）
- 美容液：単品3,500円、原価1,400円（原価率40%）
- 日焼け止め：単品1,800円、原価700円（原価率39%）
- 単品合計：7,300円、構成品原価：2,900円
- セット販売価格：6,580円（10%引）
- 送料原価：600円（送料込みプラン）
- モール手数料率：10%
- 広告費率：5%（想定）

**計算**：
- 販売価格：6,580
- 構成品原価：2,900
- 送料原価：600
- モール手数料：6,580 × 10% = 658
- 広告費：6,580 × 5% = 329
- 粗利：6,580 − 2,900 − 600 − 658 − 329 = **2,093円**
- 粗利率：2,093 ÷ 6,580 = **31.8%**

**単品ベースとの比較**：
- 単品3点合計の粗利（同条件・全て個別CV）：
  - 化粧水：2,000 − 800 − 600 − 200 − 100 = 300円
  - 美容液：3,500 − 1,400 − 600 − 350 − 175 = 975円
  - 日やけ止め：1,800 − 700 − 600 − 180 − 90 = 230円
  - 合計：1,505円
- セットの方が588円多く粗利が出る（送料・広告がCV1回で済むため）

## 検算例B：まとめ買い（同一商品×3）

**前提**：
- サプリ単品：単品3,000円、原価900円（原価率30%）
- 3個まとめ買い：8,100円（10%引）
- 送料原価：500円（送料込み）
- モール手数料率：10%
- 広告費率：8%（健食は広告費高め）

**計算**：
- 販売価格：8,100
- 原価：900 × 3 = 2,700
- 送料：500（複数同梱で1配送）
- モール手数料：8,100 × 10% = 810
- 広告費：8,100 × 8% = 648
- 粗利：8,100 − 2,700 − 500 − 810 − 648 = **3,442円**
- 粗利率：3,442 ÷ 8,100 = **42.5%**

**単品3個別買いとの比較**：
- 単品1個粗利：3,000 − 900 − 500 − 300 − 240 = 1,060円
- 3個別買い合計粗利：3,180円
- まとめ買いの方が262円多く粗利が出る（CV1回で送料・広告が1回分で済む）

## 検算例C：お試しセット（ミニサイズ）

**前提**：
- 化粧水ミニ（30ml、本品150ml）：単品換算500円、原価200円
- 美容液ミニ（5ml、本品30ml）：単品換算800円、原価350円
- 日焼け止めミニ（10ml、本品60ml）：単品換算400円、原価180円
- ミニサイズ合計：1,700円
- お試しセット販売価格：1,980円（送料込み）
- 送料原価：500円
- モール手数料率：10%
- 広告費率：30%（新規獲得用は高め）

**計算**：
- 販売価格：1,980
- 原価：200 + 350 + 180 = 730
- 送料：500
- モール手数料：1,980 × 10% = 198
- 広告費：1,980 × 30% = 594
- 粗利：1,980 − 730 − 500 − 198 − 594 = **−42円**
- 粗利率：**−2.1%**

→ **お試しセットは単発では赤字許容**。本品リピートで回収するLTV設計が前提。3ヶ月以内リピート率と本品粗利から損益分岐回収月を試算する：
- 本品同シリーズの平均粗利（仮）：化粧水800円、美容液1,500円、日焼け止め700円
- 3ヶ月以内本品購入率（仮）：30%
- 1新規あたり期待回収：(800+1,500+700) × 30% = 900円
- 1お試し赤字：42円
- → LTV観点では問題なし。ただし本品リピート率が下振れすると赤字常態化する点を要観測。

## 検算例D：ギフトセット（季節限定・送料別）

**前提**：
- 焼き菓子A：単品1,200円、原価420円
- 焼き菓子B：単品1,000円、原価350円
- 焼き菓子C：単品800円、原価280円
- ギフト箱・包装：100円
- 単品合計：3,000円
- ギフトセット価格：2,980円（演出重視で割引はほぼ無し）
- 送料：別途お客様負担（送料原価0で計算）
- モール手数料率：8%（食品ジャンル想定）
- 広告費率：5%

**計算**：
- 販売価格：2,980
- 原価合計：420 + 350 + 280 + 100 = 1,150
- 送料原価：0（お客様負担）
- モール手数料：2,980 × 8% = 238
- 広告費：2,980 × 5% = 149
- 粗利：2,980 − 1,150 − 0 − 238 − 149 = **1,443円**
- 粗利率：1,443 ÷ 2,980 = **48.4%**

→ ギフトは「値引きより演出」が成立する典型。ただし包装・熨斗対応の追加工数（梱包担当の時給×時間）が乗ると粗利が削れるため別途確認。

## 検算例E：定期購入バンドル（LTV計算）

**前提**：
- 月額バンドル価格：5,800円（定期割15% / 単発6,800円）
- 構成品原価：1,800円
- 送料原価：600円
- モール手数料率：10%
- 広告費率（定期は新規獲得時のみ）：CPA8,000円（全広告費）
- 平均継続月数：4ヶ月

**1回あたり粗利**：
- 5,800 − 1,800 − 600 − 580 = **2,820円/回**

**LTV検算**：
- 4ヶ月継続なら粗利 2,820 × 4 = **11,280円**
- 新規獲得広告費：8,000円
- LTV − CAC = **3,280円**

→ 黒字化には最低3ヶ月継続必要（2,820×3=8,460 > 8,000）。1ヶ月解約が多発する設計（縛りなし・初月大幅割引）は採算割れリスクが高い。

## 損益分岐数量の式

固定費：撮影費＋LP制作費＋ページ作成費＋セット用パッケージ初期費 などプロジェクト単位の費用

```
損益分岐販売数 = 固定費 ÷ セット1個あたり粗利
```

**例**：固定費30万円、セット粗利率33%、販売価格3,000円の場合
- 1セットあたり粗利：3,000 × 0.333 = 999円 ≒ 1,000円
- 損益分岐：300,000 ÷ 1,000 = **300セット**

検算：300セット × 3,000円 × 33.3% = 300,000円（= 固定費）。OK。

## モール手数料率の目安（あくまで参考・最新は各モール公式確認）

| モール | システム利用料率の目安 |
|---|---|
| 楽天市場 | 月額固定＋売上連動2〜7%（コース・ジャンルで変動） |
| Amazon | 販売手数料8〜15%＋FBA手数料 |
| Yahoo!ショッピング | ストアポイント原資・キャンペーン原資・アフィリエイト原資 計5〜10%程度 |
| Shopify（自社） | 決済手数料3〜4%程度 |

セット粗利計算時は、現在契約しているコース・ジャンルの実手数料率を使うこと。
