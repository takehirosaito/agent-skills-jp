# プレースメント入札調整

Amazon SP広告のプレースメント（広告掲載位置）別の入札調整。

## プレースメントの種類

### 1. 検索結果の上部（Top-of-Search）
- 検索結果1ページの上部数枠
- 最もクリック・購入されやすい位置
- CTR・CVR が高い

### 2. 商品ページ（Product Pages）
- 競合商品の詳細ページに表示
- 「関連商品」「他のお客様が購入した商品」枠
- ブランドアウェアネス・比較検討に有効

### 3. 検索結果のその他（Rest of Search）
- 検索結果ページの中段以下、2ページ目以降
- インプレッション稼ぐが CVR は低め

## 入札調整の仕組み

### 設定方法
キャンペーン設定で各プレースメントごとに -100% 〜 +900% の調整：

| プレースメント | 設定範囲 |
|---|---|
| 検索結果の上部 | -100% 〜 +900% |
| 商品ページ | -100% 〜 +900% |
| 検索結果のその他 | 調整不可（デフォルト） |

### 計算例
- 設定入札：30円
- Top-of-Search 入札調整：+100%
- 実入札 for Top：30円 × （1 + 1.00）= 60円

### 入札戦略との組み合わせ
- ダイナミック入札 - 引下げのみ：プレースメント調整＋ダイナミック調整の両方
- ダイナミック入札 - 引上げと引下げ：自動で+50/100%調整される（Top最大100%、Others最大50%）
- 固定入札：プレースメント調整のみ反映

## 推奨入札調整

### Top-of-Search

| 商品の状況 | 推奨調整 |
|---|---|
| 立ち上げ・データ不足 | 0〜+25% |
| 育成・ACOS目標達成 | +50〜100% |
| 成熟・攻め | +100〜200% |
| ブランド検索KW | +100〜300% |

Top枠は CVR が他枠の2〜3倍高い傾向。CPC増加分を吸収できる。

### 商品ページ

| 商品の状況 | 推奨調整 |
|---|---|
| 比較検討重視 | +25〜50% |
| ブランド構築 | +50〜100% |
| 純粋な短期売上重視 | 0〜+25% |

商品ページプレースメントは CVR が低めだが、比較検討段階の顧客に届く。

### 検索結果のその他
- デフォルト（調整不可）

## 入札調整の判断材料

### プレースメントレポート
- セラーセントラル「広告レポート＞プレースメントレポート」で取得
- プレースメント別のインプレッション・クリック・売上・ACOS

### 分析項目
| 指標 | 判定 |
|---|---|
| Top-of-Search の売上比率が高い | Top入札+50%以上 |
| 商品ページからの売上が高い | 商品ページ入札+25%以上 |
| Top の ACOS が低い（効率良い） | Top入札強化 |
| 商品ページの ACOS が高い | 商品ページ入札削減 |

## カテゴリ別の特性

### Top-of-Search の比重が高いカテゴリ
- 消耗品・回転商品（即決購入）
- 認知度の高いブランド商品
- 検索意図が明確な商品

### 商品ページの比重が高いカテゴリ
- 高単価・比較検討商品（家電・カメラ）
- バリエーション多い商品（アパレル）
- ブランド比較されやすい商品（コスメ）

## プレースメント別の入札調整の組み合わせ例

### 攻めるキャンペーン（Manual-Exact 主要KW）
- Top-of-Search：+100%
- 商品ページ：+50%
- 基本入札：高め

### 守るキャンペーン（Auto-探索）
- Top-of-Search：+25%
- 商品ページ：0%
- 基本入札：控えめ

### 商品ターゲティングキャンペーン
- 商品ページが主戦場
- 商品ページ：+50〜100%
- Top-of-Search：0%（検索KWでないので関係薄い）

## 入札調整時の注意

### 1. 設定が複利になる
- 基本入札30円 + Top+100% + ダイナミック+100% = 30 × 2 × 2 = 120円
- 想定外のCPC高騰
- ダイナミック「引上げと引下げ」の自動調整を考慮

### 2. プレースメント別の予算配分
- Top に +100%設定すると、Top消化が増えて全体予算が早く尽きる
- 予算配分の偏りに注意

### 3. プレースメント別 CVR の前提が崩れる場合
- 季節・カテゴリ・商品状態で CVR は変動
- 月次でプレースメントレポートを確認

## プレースメント戦略の見直しサイクル

| 頻度 | 内容 |
|---|---|
| 月次 | プレースメント別 ACOS／CVR 確認 |
| 月次 | 入札調整の微修正 |
| 四半期 | 構造的な入札水準見直し |
| 半期 | カテゴリ別の戦略再構築 |

## 入札調整の実例

### コードレス掃除機の Manual-Exact キャンペーン
- 基本入札：30円
- Top-of-Search +100%：実入札 60円
- 商品ページ +25%：実入札 37.5円
- その他：30円

→ Top でしっかり勝ちつつ、商品ページにも一定の露出を確保。

### 化粧水の Manual-Exact キャンペーン
- 基本入札：50円
- Top-of-Search +75%：実入札 87.5円
- 商品ページ +50%：実入札 75円

→ コスメは商品ページの比較検討比率が高いので商品ページもしっかり調整。

### 食品のAuto-探索キャンペーン
- 基本入札：20円
- Top-of-Search +25%：実入札 25円
- 商品ページ 0%：実入札 20円

→ 食品は単価低めなのでオート時はTop調整も控えめ。

## プレースメント以外の入札調整要素

### Brand Bidding（自社ブランドKW）
- 自社ブランド名の Manual-Exact は CVR 高い → 入札・Top+100%強気

### Competitor Bidding（競合ブランドKW）
- 商品ターゲティングで競合ASIN ターゲット
- Top調整より商品ページ調整が重要

### Seasonal Bidding（季節）
- プライムデー前後：全体 +50〜100%
- オフシーズン：-25%

## プレースメント入札の落とし穴

### 1. Top調整 +900% にする
- 設定可能だが、ACOS悪化リスク大
- 通常 +100〜200%が上限目安

### 2. 商品ページ調整を無視
- 「Top さえあれば良い」と考えて商品ページに調整しない
- 商品ページからの売上機会を逃す

### 3. プレースメント別データを見ない
- 適当な調整は逆効果
- データに基づいた決定が必要
