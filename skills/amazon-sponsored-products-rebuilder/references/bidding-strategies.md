# 入札戦略の使い分け

Amazon SP広告の3つの入札戦略と、状況別の選び方。

## 3つの入札戦略

### 1. ダイナミック入札 - 引き下げのみ（Down only）

#### 仕組み
- Amazon が「コンバージョンの可能性が低い」と判断したオークションで入札を**自動的に引き下げる**
- 引き上げはしない

#### 動作例
- 設定入札：30円
- 高CVRが期待されるオークション：30円のまま
- 低CVRが期待されるオークション：自動で15〜25円に引下げ

#### 用途
- **新商品の立ち上げ期**：データ蓄積中、過剰配信を防ぐ
- **安全運用**：CPC が制御できる
- **ACOS が目標を超えがちな商品**：消化抑制

#### メリット
- 過剰なCPC 発生を防ぐ
- ACOS悪化リスクが小さい

#### デメリット
- 売上機会の取り逃がし
- 売れる商品でも入札を上げないので機会損失

### 2. ダイナミック入札 - 引き上げと引き下げ（Up and down）

#### 仕組み
- 「コンバージョン可能性高」のオークションで自動引き上げ
- 「可能性低」のオークションで自動引き下げ
- 検索結果上部：最大100%引き上げ、その他：最大50%引き上げ

#### 動作例
- 設定入札：30円
- 高CVR期待のオークション：自動で45〜60円に引上げ
- 低CVR期待のオークション：自動で15〜25円に引下げ

#### 用途
- **成熟商品で売上拡大期**：機会を逃さない
- **目標ACOSに余裕があるとき**
- **競合性が高くて完全一致を勝ち取りたいとき**

#### メリット
- 売上機会の最大化
- 高CVRオークションを確実に勝てる

#### デメリット
- 想定以上の CPC が発生する可能性
- 予算消化が早い
- ACOS が一時的に悪化する可能性

### 3. 固定入札（Fixed bid）

#### 仕組み
- 入札額を常に固定
- Amazon の自動調整なし

#### 動作例
- 設定入札：30円
- 全てのオークションで30円のまま入札

#### 用途
- **データ収集・実験**：純粋な入札水準テスト
- **入札額を完全に管理したいとき**
- **オートキャンペーンで初動データ収集**

#### メリット
- 予算予測が容易
- 入札の制御度が最高

#### デメリット
- 機会損失（売れるときに上げない）
- 過剰配信（売れないときに下げない）

## 入札戦略の選び方

### 商品ライフサイクル別

| 段階 | 推奨入札戦略 | 理由 |
|---|---|---|
| 立ち上げ | 引下げのみ or 固定 | 安全・データ収集 |
| 育成 | 引下げのみ → 引上げと引下げ | 効率良くデータ蓄積後、拡大 |
| 成熟 | 引上げと引下げ | 売上機会最大化 |
| 攻め時 | 引上げと引下げ + Top入札+100% | 短期で順位確保 |
| 衰退・終売 | 引下げのみ | コスト最小化 |

### 目標ACOS別

| 状況 | 推奨入札戦略 |
|---|---|
| 目標ACOS厳しい（10〜20%） | 引下げのみ |
| 目標ACOS標準（20〜40%） | 引上げと引下げ |
| 目標ACOS緩い（40%超） | 引上げと引下げ + 高入札 |

### キャンペーンの種類別

| キャンペーン | 推奨入札戦略 |
|---|---|
| Auto-探索 | 引下げのみ（無駄なCPC発生防止） |
| Manual-Exact | 引上げと引下げ（確実な勝率） |
| Manual-Phrase | 引下げのみ |
| Manual-Broad | 引下げのみ |
| Product-競合ASIN | 引上げと引下げ |

## 入札額の決定方法

### 開始入札の目安

```text
開始入札 = カテゴリ平均CPC × 0.8〜1.2
```

カテゴリ平均CPC は Amazon の入札推奨で確認可能。

### 入札額の段階的調整

| 期間 | 調整 |
|---|---|
| 1〜2週目 | 観察、入札変更最小限 |
| 3〜4週目 | データ見て+/-10〜20%調整 |
| 1ヶ月以降 | 月次見直し、+/-20〜50%調整 |

### CVR ベースの入札計算

```text
適正入札 = 売上総利益 × CVR
```

例：
- 売上総利益16,032円
- CVR 5%
- 適正入札 = 16,032 × 0.05 = 801円

ただし、目標ACOS確保のためには：
```text
許容入札 = 売上総利益 × CVR × （1 - 目標利益率／粗利率）
```

## 入札戦略の組み合わせ

### 攻めの組み合わせ
- 入札戦略：引上げと引下げ
- Top入札調整：+100%
- 高入札：適正の1.5倍

→ 攻めるべきKWで使う。ACOS悪化リスクあり。

### 守りの組み合わせ
- 入札戦略：引下げのみ
- Top入札調整：0%
- 中入札：適正と同等

→ 安定運用、機会損失あり。

### バランスの組み合わせ
- 入札戦略：引上げと引下げ
- Top入札調整：+50%
- 入札：適正水準

→ 多くの商品で採用される標準的設計。

## 入札戦略の切替タイミング

### 引下げのみ → 引上げと引下げ
- データ蓄積完了（2〜4週間）
- ACOS が目標以下で安定
- 機会損失が見える（インプレッション少なめ）

### 引上げと引下げ → 引下げのみ
- ACOS が急速に悪化
- 競合の入札高騰
- 予算消化が早すぎる

### 固定 → ダイナミック
- 初期のデータ収集完了
- 入札の動的調整に切り替えたい

## 戦略変更の影響と検証

戦略変更後の検証ポイント：
- ACOS の変化（1〜2週間）
- CPC の変化（即時）
- インプレッション・クリックの変化
- 売上の変化

戦略変更は2週間以上経過してから次の判断。短期で振り回されない。

## 競合の入札変動への対応

競合が入札を上げてきた場合：
1. インプレッションシェアが下がる
2. 自社の表示位置が下がる
3. CTR・CVR が下がる

対応策：
- 同じKWの入札を上げる（攻め）
- 別のKW に予算をシフト（避ける）
- 商品ページCVRを上げて入札効率を確保（中長期）

## 季節・キャンペーン期間の戦略

### プライムデー・ブラックフライデー期間
- 入札戦略：引上げと引下げ
- Top入札：+100%以上
- 通常の1.5〜2倍の予算

### オフシーズン
- 入札戦略：引下げのみ
- 通常の50〜70%の予算

### セール直前
- 1週間前から入札を徐々に上げ、初日に最高入札
- セール後1週間は通常に戻す

## 入札戦略の落とし穴

### 1. 引上げと引下げで急にACOS悪化
- 急に攻めると即予算消化される
- 段階的な入札上昇を

### 2. 引下げのみで売上機会損失
- 「安全第一」で過剰に下げすぎ
- データ揃ったら攻める切り替え

### 3. 固定で柔軟性ゼロ
- データ豊富なのに固定のまま
- 自動最適化の機会を逃す
