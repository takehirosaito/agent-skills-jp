## byte数管理のテンプレ

各例で実際にbyte数を計算：

```python
def check_byte(html_text):
    byte_count = len(html_text.encode('shift_jis'))
    print(f"byte数: {byte_count} / 10,240")
    if byte_count > 10240:
        print("NG: 容量超過")
    elif byte_count > 9500:
        print("注意: 余裕少なめ")
    else:
        print(f"OK: 余裕 {10240 - byte_count}byte")

# サンプル
html = """
<h2>サンプル商品</h2>
<p>説明文...</p>
"""
check_byte(html)
```
