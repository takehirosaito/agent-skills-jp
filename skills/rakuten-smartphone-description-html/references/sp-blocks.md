# スマホ最適化HTMLブロックテンプレ

スマホ縦スクロールで読みやすい構造。禁止タグなしで構築。

## ブロック1：ファーストビュー

````html
<h2>[USPコピー：1行で]</h2>
<p><img src="[メイン画像URL]" alt="[商品名]"></p>
<p>[補足コピー：1-2行]</p>
````

### 例
````html
<h2>1.0L大容量・7段階温度調整・1年保証</h2>
<p><img src="https://image.rakuten.co.jp/example/cabinet/kettle/main.jpg" alt="電気ケトル"></p>
<p>毎朝のコーヒー・紅茶を最適温度で。広口設計でお手入れ簡単。</p>
````

## ブロック2：主要USP（3つの特徴）

````html
<h3>3つの特徴</h3>

<p><strong>1. [タイトル1]</strong></p>
<p>[説明1 2-3行]</p>
<p><img src="[画像1]" alt="特徴1"></p>

<p><strong>2. [タイトル2]</strong></p>
<p>[説明2 2-3行]</p>
<p><img src="[画像2]" alt="特徴2"></p>

<p><strong>3. [タイトル3]</strong></p>
<p>[説明3 2-3行]</p>
<p><img src="[画像3]" alt="特徴3"></p>
````

### スマホで読みやすくするコツ
- 1段落2-3行
- 段落間に空行（実際は `<p>` の閉じタグで）
- 太字は要点だけ

## ブロック3：商品スペック（テーブル）

````html
<h3>商品スペック</h3>
<table border="1" cellpadding="6">
  <tr><th>容量</th><td>1.0L</td></tr>
  <tr><th>消費電力</th><td>1,200W</td></tr>
  <tr><th>本体サイズ</th><td>幅22×奥行16×高さ23cm</td></tr>
  <tr><th>重量</th><td>1.1kg</td></tr>
  <tr><th>素材</th><td>ステンレス/PP樹脂</td></tr>
  <tr><th>電源</th><td>AC100V 50-60Hz</td></tr>
  <tr><th>保証</th><td>1年メーカー保証</td></tr>
</table>
````

### スマホ表示のコツ
- 列を2列まで（th と td）
- セル内のテキストを簡潔に
- 長い値は改行（`<br>`）で

## ブロック5：比較表

````html
<h3>モデル比較</h3>
<table border="1" cellpadding="6">
  <tr>
    <th>項目</th>
    <th>本商品</th>
    <th>プロモデル</th>
  </tr>
  <tr><th>容量</th><td>1.0L</td><td>1.5L</td></tr>
  <tr><th>温度</th><td>7段階</td><td>無段階</td></tr>
  <tr><th>保温</th><td>なし</td><td>あり</td></tr>
  <tr><th>価格</th><td>5,000円</td><td>8,500円</td></tr>
</table>
````

### スマホでの注意
- 比較項目を3列まで
- セル内テキストを短く
- 「本商品」を中央に置くと分かりやすい

## ブロック6：FAQ（よくある質問）

````html
<h3>よくあるご質問</h3>
<dl>
  <dt><strong>Q. お手入れはどうすれば？</strong></dt>
  <dd>A. 内部はクエン酸洗浄を月1回程度。外側は乾いた布で拭いてください。</dd>

  <dt><strong>Q. コーヒー用の最適温度は？</strong></dt>
  <dd>A. ハンドドリップは80-90℃、エスプレッソは90-95℃が一般的です。</dd>

  <dt><strong>Q. 保証期間は？</strong></dt>
  <dd>A. ご購入日から1年メーカー保証。延長保証もご利用いただけます。</dd>
</dl>
````

### スマホ表示の最適化
- 質問と回答の段落分け
- Q. と A. の明示
- 1問あたり2-3行

## スマホ実機での確認ポイント

| 確認 | OK基準 |
|---|---|
| 文字サイズ | 14px以上で読める |
| 画像表示 | 全画像が見える |
| リンクのタップ | 30×30px以上の領域 |
| 縦スクロール | 自然に最後まで読める |
| 表の表示 | 横スクロールなしで見える |
| 改行 | 不自然な箇所なし |
