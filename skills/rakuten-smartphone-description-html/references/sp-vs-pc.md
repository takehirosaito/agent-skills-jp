# SP版とPC版の使い分け

## 基本方針

SP版とPC版は **完全に別の説明文** として登録される。同じ情報を異なる形式で記述。

## 主な違い

| 項目 | PC版 | SP版 |
|---|---|---|
| 容量 | 10,240byte | 10,240byte |
| 禁止タグ | 少ない | 多い（div, style, script等） |
| 推奨レイアウト | 段組み・装飾OK | 縦並びシンプル |
| 画像枚数 | 制約少 | 10枚（一部20枚） |
| CSS | 一部可能 | 不可（style属性も） |
| 閲覧環境 | 大画面 | 小画面 |

## どちらを優先するか

楽天市場の取引は **スマホが80%以上**。

→ **SP版を最優先で設計**、PC版はSP版の情報を元に展開。

ただしカテゴリによってPC比率が高い場合もある：

| カテゴリ | PC比率 |
|---|---|
| 家電 | やや高め |
| パソコン関連 | 高め |
| 一般商品 | 低（SP中心） |

## SP版の制約への対応

### 装飾を画像内に組み込む

PC版では`style="color: red"`で装飾できるが、SP版では不可。

代替：
- 重要訴求は画像内に文字を入れる
- ただし楽天画像規定（占有率20%）に従う

### レイアウト分割を諦める

PC版では`<div class="left/right">`で2列レイアウト可能だが、SP版では不可。

代替：
- 縦並びにする
- どうしても並べたい場合は`<table>`で

### 表組みで構造化

`<div>`が使えないため、構造化したい場合は`<table>`を活用：

```html
<table>
  <tr>
    <th colspan="2">セクション見出し</th>
  </tr>
  <tr>
    <th>項目</th>
    <td>内容</td>
  </tr>
</table>
```

## SP版の作り方の流れ

### 1. SP版を先に作る
- スマホ縦スクロール前提で設計
- 必要情報を網羅
- 禁止タグを使わない

### 2. PC版で拡張
- SP版の情報を元に
- PC版で許可される装飾を追加
- 段組みレイアウトを使う

### NG：PC版をコピーしてSP版に流用
- div、style等の禁止タグがそのまま残る
- アップロードエラーまたは表示崩れ

## 同じ情報の書き分け例

### PC版（許可タグを使った装飾）

```html
<div style="background-color: #f0f0f0; padding: 20px;">
  <h2 style="color: #ff6600;">商品の特徴</h2>
  <div style="display: flex;">
    <div style="width: 50%;">
      <img src="..." />
    </div>
    <div style="width: 50%;">
      <p>説明文</p>
    </div>
  </div>
</div>
```

### SP版（装飾なし・縦並び）

```html
<h2>商品の特徴</h2>
<p><img src="..." alt="特徴画像"></p>
<p>説明文</p>
```

## 情報量の調整

### PC版
- 比較表（多列）
- 詳細スペック
- 専門用語の詳細解説
- 長めのストーリー
- 関連商品の多数紹介

### SP版
- スペック表（2列）
- 主要USPに絞る
- 専門用語は最小限
- 短いキャッチで
- 関連商品は1-2品まで

## 共通する内容

両方に含めるべき：

- 商品スペック（フォーマットは違うが内容は同じ）
- 主要USP
- 価格・送料・保証
- FAQ（重要なもの）
- 法令配慮（薬機法・景表法）

## 異なる訴求の使い分け

### PC版
- ストーリー型（開発秘話・職人）
- 詳細比較（自社内・競合）
- 専門情報（成分・性能・規格）

### SP版
- 即決型（USP・特典・送料）
- 視覚優先（画像中心）
- シンプル（情報は最小限に）

## 更新の手順

商品ページ更新時：

1. SP版を更新（最重要）
2. PC版にも反映
3. RMS で両方を別CSVでアップロード
4. プレビュー確認（SP・PC両方）
5. スマホ実機で確認

## 自動同期は難しい

PC版とSP版の自動変換ツールは無い（楽天独自のため）。

- PC版のHTMLからdiv・style等を除いてもSP版に最適化されない
- レイアウト思想が違うため、手作業での書き分けが必要

## 開発・運用の工夫

### バージョン管理
- SP版とPC版を別ファイルで管理
- 「商品A_sp.html」「商品A_pc.html」
- 変更履歴を残す

### テンプレート化
- SP版・PC版それぞれの定型構造を準備
- 商品情報を流し込むだけで生成

### チェックスクリプト
- 禁止タグの自動検出
- byte数チェック
- 画像URL検証

## 効果測定

| 指標 | 計測 |
|---|---|
| SP版のCVR | スマホからの CV / アクセス |
| PC版のCVR | PCからの CV / アクセス |
| 改善前後比較 | A/B 期間比較 |

→ SP版・PC版それぞれの効果を測定し、優先度を判断。
