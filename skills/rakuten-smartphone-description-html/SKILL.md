# 楽天SP（スマホ）商品説明HTML生成

## 概要

楽天RMSのSP用商品説明文は10,240byte（全角5,120字）まで、PC版より厳しい禁止タグ制約があります。本スキルは、ユーザーから提示された商品情報・訴求ベネフィット・画像構成を、縦スクロール最適のSP版HTMLとして生成します。

div・script・iframe・form・input・style・外部CSS/JSは使えず、p・br・font・b・img・a・table（横幅100%）の安全タグで構築。スマホ1画面目に強い訴求を入れ、特徴→スペック→使い方→注意→FAQの順で縦に流す設計です。

## 最重要原則

**「SP版禁止タグ（div/script/iframe/form/input/style）を絶対に使わない／縦スクロール前提で横長レイアウト禁止／1画面目で購入動機を伝える／画像は10枚以内（一部20枚）／byte数10,240を厳守／PC版HTMLの流用禁止」**。SP版とPC版は完全に別の説明文として登録される。

## 知識ベース

SP版商品説明文の主要仕様：

| 項目 | 仕様 |
|---|---|
| 上限byte数 | 10,240byte（全角5,120字） |
| 画像枚数 | imgタグ10枚（一部商品20枚） |
| 禁止タグ | div, script, iframe, form, input, style, 外部CSS/JS |
| 利用可能タグ | p, br, font, b, strong, img, a, table（width100%相当）, h2, h3, ul, li |
| 文字コード | Shift_JIS(CP932) |
| 改行 | CR+LF |

詳細：
- SP用説明文の仕様・禁止タグ詳細・許可タグ一覧：`references/sp-spec.md`
- スマホ最適化HTMLブロックテンプレ（ファーストビュー・特徴・スペック・FAQ・クロージング）：`references/sp-blocks.md`
- SP版とPC版の使い分けと役割分担：`references/sp-vs-pc.md`
- ジャンル別SP説明文の実例3パターン：`references/examples.md`

楽天固有数値（必ず確認）：
- PC/SP説明文10,240byte（全角5,120字）
- SP説明文の画像10枚（一部20枚）
- 商品名255byte（全角127字）、キャッチコピー174byte（全角87字）
- 画像規定：700×700px以上推奨、テキスト占有率20%以内

## 処理フロー

### Step 1：商品プロファイル把握

ユーザーから以下を確認（不足時は仮定して進める）：

- 商品名・ブランド・主要スペック
- 訴求したいベネフィット（3〜5個）
- 使用シーン・ターゲット
- 画像URLまたは画像構成（10枚以内）
- 禁止表現や法規制上の注意点（化粧品・健食等）
- 店舗トーン

不明な場合は「家電・差別化3点・画像6枚・店舗トーン丁寧」を仮置きし冒頭で明示。

### Step 2：縦スクロールブロック構成の設計

`references/sp-blocks.md` の標準構成（縦に並ぶ）：

1. ファーストビュー（商品名・主要訴求・大きい画像1枚）
2. 解決する悩み・購入理由
3. 特徴ブロック×3〜5（画像＋短文）
4. スペック（簡易表またはリスト）
5. 使用シーン・使い方
6. FAQ（3〜5個）
7. 保証・配送・返品案内
8. クロージング（レビュー誘導・あす楽訴求）

### Step 3：禁止タグの回避

`references/sp-spec.md` の禁止タグを確認：
- div→pまたはtableで代替
- style→font色・サイズ属性で代替
- script/iframe/form/input→使わない
- 外部CSS/JS→利用不可

### Step 4：HTMLコード生成

利用可能タグで構築：
- 段落：`<p>`
- 改行：`<br>`
- 強調：`<b>`、`<strong>`
- 色：`<font color="">`
- 画像：`<img src="" alt="">`
- リンク：`<a href="">`
- 表：`<table width="100%">`（横スクロール回避）
- 見出し：`<h2>`、`<h3>`
- リスト：`<ul>`、`<li>`

### Step 5：byte数とタグチェック

- Shift_JISでbyte換算、10,240byte以内
- 禁止タグ検出（自動チェック項目に列挙）
- img枚数カウント（10枚以内）

### Step 6：1画面目の最適化

スマホ1画面目（最初の500〜800字）で：
- 商品名＋強い訴求1文
- 大きい画像1枚（フルワイド推奨）
- 価格／送料／レビュー数の即時表示
- 「なぜ今買うか」を1〜2文

### Step 7：短縮版の生成

byte数オーバー時または軽量版が必要な場合、3,000byte版を併せて生成（FAQ・比較表を最小化）。

<p>レビュー4.3／50件・送料無料・あす楽対応</p>

<h3>こんな悩みありませんか？</h3>
<p>・コーヒーがぬるくなる<br>・ミルク温度がいつもバラバラ<br>・大きいケトルがない</p>

<h3>本商品の特徴</h3>
<p><img src="https://[IMG]/002.jpg" alt="温度調整パネル" width="100%"></p>
<p><b>6段階の温度設定（40〜100℃）</b><br>用途別に最適温度を選択。</p>

<h3>スペック</h3>
<table width="100%" border="1" cellpadding="6">
<tr><td>容量</td><td>1.0L</td></tr>

## 品質ゲート

- 禁止タグ（div/script/iframe/form/input/style／外部CSS・JS）が使われていないか
- 生成HTMLが10,240byte以内（Shift_JIS換算）か
- 画像（imgタグ）が10枚以内か
- 1画面目（最初の500〜800字）で購入動機が伝わるか
- 横長レイアウト（PC前提の表）が含まれていないか
- 重要情報（価格・サイズ・成分・保証）が画像だけでなくテキストでも記載されているか
- img要素全てにalt属性があるか
- 「最安」「絶対」「業界一」等の景表法リスク表現がないか
- 化粧品・健食の場合、薬機法対象表現がないか

## エッジケース

- **byte数オーバー時**：FAQと比較表を短縮、画像も10枚→6枚に削減
- **画像未確定**：プレースホルダ（[画像1：商品全体]）で構造を先に生成
- **化粧品・健食**：薬機法対象表現を回避（「実感」「すこやか」程度に留める）
- **食品**：原材料・賞味期限・保存方法・アレルゲン表示を必ず含める
- **PC版HTML流用要望**：禁止タグ含有で表示崩れ・登録不可リスクのため、SP版を別途生成

## 注意事項

- 楽天RMS仕様（許可HTMLタグ・byte上限・画像枚数）は随時改定。最終公開前にRMSヘルプを確認
- 文字コードはShift_JIS(CP932)、改行CR+LF。UTF-8で生成した場合は変換時に文字化けリスク
- SP説明文の禁止タグ違反は登録不可・表示崩れの原因
- 画像のテキスト占有率20%以内、白基調背景の規定（2024.6改定）に注意
- 価格・期間限定キャンペーン文言を本文に埋め込むと、終了後の差し替え漏れが頻発
- 景表法（「No.1」「最安」根拠なし）、薬機法（効能訴求）、特商法（保証・返品リンク）に注意
- 顧客個人情報・ログイン情報・他社商品の画像をSKILL.mdや出力例に保存しない
