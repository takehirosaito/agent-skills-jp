# 画像役割別 撮影・デザイン指示

## メイン画像（1枚目）

### 役割
- 検索結果一覧での **CTR最大化**
- 商品とUSPを瞬時に伝える

### 構図
- 商品本体が画像中央70-85%
- 上下左右に適度な余白
- 影は控えめ（自然光程度）

### 文字・図解
- USPコピー：1-2行、占有率20%以内
- バッジ風：「送料無料」「1年保証」「ポイント10倍」など
- 価格訴求は避ける（価格は商品ページに記載）

### 背景
- 白基調が無難
- 商品の色を引き立てる無地

### 撮影指示例
```
1枚目：メイン
- 商品（電気ケトル）を画像中央、商品占有率約75%
- 背景：白基調、影は柔らかく
- 訴求コピー（左上）：「1.0L大容量・7段階温度調整」
- バッジ（右上）：「1年メーカー保証」
- 占有率：商品75%＋テキスト18%＝合計93%
```

## スペック・サイズ画像（5-6枚目）

### 役割
- 数値情報の確認
- サイズ感の把握

### 構図・デザイン
- メジャーや基準物（A4用紙・スマホ）と並べる
- スペック表は文字主体（占有率注意）

### デザイン指示例
```

- 商品の幅・奥行・高さを数値で記載
- 商品の横にA4用紙またはスマホを並べたスケール感
- テキスト：幅22cm × 奥行16cm × 高さ23cm
```

## 撮影時の注意

### 照明
- 自然光が理想、難しければソフトボックス
- 影が強すぎない、柔らかい光
- 商品の色を正確に再現

### 構図
- 商品が画像端で切れない
- 安定した構図（傾き0度）
- ピント・露出を統一

### 後処理
- 過度なレタッチを避ける
- 実物と色が大きく異ならない
- サイズ感を実物より大きく／小さく見せない

## デザイン時の注意

### フォント
- 視認性の高いゴシック体
- スマホで読めるサイズ（最小14px相当）
- 文字色と背景色のコントラスト確保

### 色使い
- 商品の色を引き立てる
- ブランドカラーとの統一感
- 商品が小さく見えない配色

### 余白
- 文字の周りに十分な余白
- 詰め込み過ぎない
- 占有率20%を超えない

## 画像のファイル命名

- 連番：item_01.jpg、item_02.jpg ...
- 役割が分かる名前：main.jpg、size.jpg、scene_kitchen.jpg
- R-Cabinet（楽天CDN）にアップロード時に整理

## 楽天R-Cabinet

- 店舗ごとに割り当てられた画像保管領域
- URL：`https://image.rakuten.co.jp/[ショップURL]/cabinet/...`
- アクセス：HTTPS
- 容量制限あり、定期的に整理
