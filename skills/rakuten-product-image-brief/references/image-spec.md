# 楽天画像規定（2024.6改定版）

最新は RMS 店舗運営Navi の「商品画像登録ガイドライン」で確認。

## 基本要件

| 項目 | 内容 |
|---|---|
| サイズ | 700×700px以上推奨 |
| ファイル形式 | JPG、PNG、GIF |
| 縦横比 | 正方形推奨 |
| ファイルサイズ | 個別の上限値はモール仕様確認 |

## 背景（3種OK・2024.6改定）

| 背景タイプ | OK／NG | 例 |
|---|---|---|
| 白基調背景 | OK | 白／オフホワイト |
| 合成背景 | OK | グラデーション、抽象パターン |
| 写真背景 | OK | 自然・室内・スタジオ撮影 |

改定前は「白基調」のみが原則、改定後は3種OK。

## 枠の禁止

- 画像の外周に枠線（罫線・装飾）を入れない
- 内側のレイアウト要素として枠を使うのも避ける

## テキスト占有率

- 画像面積の **20%以内**
- 10×10マスに分割した場合、テキスト要素が **20マス以内**
- 文字背景の色面も含めて計算

## メイン画像（1枚目）

- 商品本体が明確に視認できる
- 商品占有率：高い割合（70-85%目安）
- 過大な装飾・ロゴを避ける
- 「セール」「ポイント10倍」等の販促バナーは商品が霞まない範囲で

## サブ画像（2-20枚目）

- 商品の異なる角度・使用シーン・サイズ感・スペック・比較表
- テキスト訴求はサブ画像で
- ただし占有率20%・枠禁止は同じ

## スマホ表示の制約

- スマホ商品ページの一覧表示で正方形に切り抜かれる
- 端の要素が切れる可能性 → 安全領域は中央寄り
- 文字サイズはスマホ視認性を確保

## NG加工

- 過度な色補正で実物と異なる印象
- 傷・汚れを隠す加工
- サイズ感を実物と異ならせる
- 「使用後の効果」を演出（スキンケアのbefore-after）

## ジャンル別 追加注意

### 化粧品（100939）
- before-after画像（スキンケア）はNG
- メーキャップ・物理効果はOK
- 「医薬部外品」表示は商品仕様に基づく
- 56効能を超える訴求はNG

### 健康食品（100938）
- 機能性表示食品は届出文言と一致
- 一般食品で「痩せる」「効く」等はNG
- 体験談を効能訴求として使うのはNG

### 食品（100227）
- アレルゲン表記（特定原材料8品目）
- 賞味期限・保存方法
- 原産地表示

### 家電（562637）
- 消費電力・サイズのスペック表示
- 「壊れない」「永久保証」等の断定NG

### ファッション
- モデル着用時はサイズ感の誤認を招かない
- 色・素材の実物との差異に注意

## 規定違反の影響

- 検索結果から非表示／表示順位低下
- スマホ一覧表示制限
- 楽天からの修正要請、最悪掲載停止
- 違反点数の蓄積

## 改定の把握

楽天は画像規定を定期的に改定する。改定情報の入手先：

1. RMS 店舗運営Navi のお知らせ
2. 楽天e-Naviのメール
3. RMSサポート問い合わせ

最新版を確認する習慣を持つ。
