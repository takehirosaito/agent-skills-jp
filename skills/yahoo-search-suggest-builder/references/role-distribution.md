# 商品名／キーワード欄／カテゴリ／JAN／captionの役割分担

各フィールドが**どんな種類のキーワード**を担うかを明確にする。

---

## 1. 商品名（name・全角75文字）

### 担う役割
- **検索の主軸キーワード**を入れる
- 検索結果サムネ・商品ページ・SNSシェアなど**多くの場面でユーザーに表示**される
- 先頭25文字で勝負が決まる

### 入れるべき
- 指名語（ブランド・モデル名・型番）
- 商品タイプ（財布／化粧水／ヘッドホン）
- 最重要属性（本革／200ml／ワイヤレス）
- 対象（メンズ／レディース／敏感肌）
- 主要シーン語（父の日／プレゼント）

### 入れないべき
- 表記揺れの3〜4個目（→ キーワード欄へ）
- 色・サイズすべてのバリエ（→ キーワード欄、または別商品）
- 装飾★◆♥
- 楽天1位など他モール訴求
- 薬機・景表抵触語
- 装飾的な接続詞

---

## 2. 検索キーワード欄（shopping-search-keywords）

### 担う役割
- **商品名に入りきらなかった補完キーワード**を回収
- ユーザーには直接表示されない（検索シグナルのみ）
- 半角空白区切り

### 入れるべき
- 表記揺れ（カタカナ／漢字／英字／同義語）
- ロングテールKWの素材
- 商品名で省略した属性
- 競合語（自社で正規取扱の場合のみ）
- サブの用途・シーン語

### 入れないべき
- 商品名と全く同じ単語の重複
- 関連性の薄い語（無視される）
- 商標権侵害になる他社ブランド名
- 薬機・景表抵触語
- 過剰なロングテール詰め込み

### 例
商品名：「ポーター 二つ折り財布 メンズ 本革 PORTER ブラック 父の日」

キーワード欄：「サイフ さいふ ウォレット wallet レザー 革製 タンカー ヒート 40代 ビジネスマン 革財布 ふたつ折り 黒 大人」

---

## 3. プロダクトカテゴリ（product-category）

### 担う役割
- **分類シグナル**
- 検索フィルタ・カテゴリランキング・関連商品の根拠
- 数字ID

### 入れるべき
- Yahoo!プロダクトカテゴリの**最も適切な末端ID**

### カテゴリで賄える属性
カテゴリで「メンズ財布」が確定すれば：
- 商品名で「メンズ」「財布」を強調しすぎる必要はない（自動シグナルが入る）
- ただし商品名にも入れた方が**サムネで認識される**

---

## 4. JAN／product-code

### 担う役割
- **カタログマッチング**
- 価格比較サイト・Google Merchant Centerでも参照
- 同一商品の検索精度向上

### 入れるべき
- JAN-13（13桁）／JAN-8（8桁）／ISBN（書籍）
- メーカー発番の正式GTIN

### 入れないべき
- 自社内コード（インストア02／20-29）を product-code に
- メーカー型番（別の `sub-code` 等へ）

---

## 5. ブランドコード（brand-code）

### 担う役割
- Yahoo!のブランドフィルタでの露出
- 検索精度

### 入れるべき
- Yahoo!登録のブランドID
- 正規取扱のブランドのみ

---

## 6. headline（全角60文字）

### 担う役割
- 商品名の下に表示される**サブ訴求**
- 補足キャッチコピー
- 検索シグナルとしては商品名ほど強くない

### 入れるべき
- 商品名で入りきらなかった訴求コピー
- 期間限定訴求（「父の日 6/16まで」）
- 在庫訴求（「在庫残りわずか」）

---

## 7. caption（全角5,000文字）

### 担う役割
- **商品の詳細説明**
- HTML可能（リンク・画像・テーブル）
- 検索シグナルとしては弱いが、CVR向上に直結

### 入れるべき
- 詳細スペック
- 使い方・お手入れ方法
- FAQ
- 配送・返品（最低限）
- メーカー情報
- 認証・保証

### 検索KWとしての補完
- 商品名・headlineに入れにくいロングテールKWを自然な文章で

---

## 8. abstract（全角160文字）

### 担う役割
- 一覧表示用の短い説明
- 検索結果リスト・カテゴリページで表示

### 入れるべき
- 商品の最重要訴求を1〜2文
- USPの言い換え

---

## 9. explanation（全角3,000文字）

### 担う役割
- 詳細説明の追加領域
- caption の補完
- スペック表・素材説明など長い情報

---

## 10. 役割分担サマリー（早見表）

| 入れたい情報 | 入れる場所 |
|---|---|
| ブランド名 | name、headline、brand-code |
| 商品タイプ | name、product-category |
| 主要属性 | name、product-category（カテゴリで賄える分） |
| サブ属性 | shopping-search-keywords、caption |
| 表記揺れ | shopping-search-keywords |
| 色・サイズすべて | shopping-search-keywords、option-data CSV |
| 用途・シーン | name 1〜2個、残りは shopping-search-keywords |
| スペック詳細 | caption、explanation |
| 価格・送料 | （自動表示エリア） |
| クーポン情報 | （自動表示エリア） |
| 配送・返品 | ストア情報、お買い物ガイド、caption（要点） |
| 注意事項 | caption、explanation |
| 認証マーク | caption、画像 |

→ **適材適所**で配置すると、商品名は短く強く、各検索シグナルも漏れなく機能する。

---

## 11. 役割分担チェックリスト

- [ ] 商品名（name）に主軸4要素（指名／商品タイプ／属性／対象）が入っているか
- [ ] 商品名が75文字を満たし、余白5文字以上残っていないか
- [ ] 商品名に薬機・景表抵触語が無いか
- [ ] shopping-search-keywords に表記揺れ・同義語が入っているか
- [ ] shopping-search-keywords に商品名と全重複の語が入っていないか
- [ ] プロダクトカテゴリが空欄でないか
- [ ] product-code（JAN）が空欄でないか（カタログ商品の場合）
- [ ] caption に詳細スペック・使い方・FAQが入っているか
- [ ] headline でサブ訴求を補完しているか
