## 9. 機能・効能の揺れ

化粧品・健康食品は薬機抵触語と表現の揺れの境界が重要：

| 主（OK） | 揺れ（NG / OK 確認） |
|---|---|
| 保湿 | しっとり／うるおい／モイスチャライザー（OK） |
| エイジングケア | アンチエイジング（NG／使用不可） |
| 日やけによるシミ・ソバカスを防ぐ | シミに効く／美白（NG） |
| すっきり | 痩せる／ダイエット効果（NG） |

→ 揺れと言っても、**法的にNGな揺れは使わない**。

## 10. 検索キーワード欄での書き方

`shopping-search-keywords` は半角空白区切り：

```
サイフ さいふ ウォレット wallet レザー 革製 タンカー ヒート 40代 ビジネスマン 革財布 ふたつ折り
```

注意点：
- 半角空白で区切る（全角スペースNG）
- 関連性の薄い語を入れすぎない（無視される場合）
- 商品名と完全重複は避ける（無駄）
- ブランド・他社商品名は商標権リスク
- 法務NG語は含めない

## 11. 揺れを商品名 vs キーワード欄でどう分けるか

| 揺れ | 商品名（name） | キーワード欄 |
|---|---|---|
| 同一意味の同義語 | 1個まで | 残り |
| カタカナ／漢字／英字 | 主表記1つ＋英字1つまで | 残り |
| サイズ・色のバリエ | 主要1〜2サイズ／1〜2色 | 全色全サイズ |
| ロングテール（複合） | 主要1〜2個 | 多数 |

例：
- 商品名：「ポーター 二つ折り財布 メンズ 本革 PORTER」（指名＋商品タイプ＋英字1）
- KW欄：「サイフ さいふ ウォレット wallet レザー 革製」（同義語・英字）
