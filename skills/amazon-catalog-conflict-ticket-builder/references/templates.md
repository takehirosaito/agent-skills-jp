# 文面テンプレート集

8種別のセラーサポート向け問い合わせ文テンプレート。実際の依頼時はASIN・社名・固有情報を差し替える。

---

## 1. ブランド名違い

### 件名
```text
ASIN:B0XXXXXXXX ブランド名修正依頼（[現在のブランド] → [正しいブランド]）
```

### 本文
```text
お世話になっております。下記ASINのブランド名修正をお願いいたします。

- 対象ASIN：B0XXXXXXXX
- 現在のブランド名：[現在のブランド]
- 修正後のブランド名：[正しいブランド]

修正根拠：
- 弊社は本ブランドの商標登録権者です（商標登録第○○号、添付1）
- Amazon Brand Registry 登録済み（ブランド名：[正しいブランド]）
- 本ASINは弊社が販売・流通させている正規商品です

添付資料：
1. 商標登録証
2. メーカー証明書（該当時）
3. 商品パッケージのブランドロゴ画像

ご対応いただけない場合は、追加資料の提出も可能です。必要な書類をご教示ください。

よろしくお願いいたします。
```

## 3. 画像差し替え

### 件名
```text
ASIN:B0XXXXXXXX メイン画像差し替え依頼
```

### 本文
```text
お世話になっております。下記ASINのメイン画像差し替えをお願いいたします。

- 対象ASIN：B0XXXXXXXX
- 修正根拠：現在のメイン画像が低画質・古いデザインのため、最新の正規画像に差し替えを希望します
- Brand Registry 登録状況：登録済み（ブランド名：○○）

提出画像：
- メイン画像（添付1）：純白背景RGB(255,255,255)、商品占有率85%以上、1500×1500px、JPG
- サブ画像1〜7（添付2〜8）：使用シーン・素材アップ・パッケージ・サイズ感

すべて Amazon メイン画像規定に準拠した画像です。

よろしくお願いいたします。
```

修正根拠：

添付資料：

2. 類似ASINの画面スクショ

## 5. ASIN統合

### 件名
```text
重複ASIN統合依頼（B0XXXXXXX、B0YYYYYYY → B0ZZZZZZZ）
```

### 本文
```text
お世話になっております。同一商品で重複しているASINの統合をお願いいたします。

- 統合先ASIN：B0ZZZZZZZ（正規）
- 統合対象ASIN：B0XXXXXXX、B0YYYYYYY（重複・無効化希望）

統合根拠：
- 3ASINとも同一の物理商品（JAN：[同一JAN]、メーカー型番：[同一型番]）
- 別ASINとして併存することで、レビュー分散・在庫管理重複が発生

添付資料：
1. メーカー仕様書（全3ASIN同一商品の証明）
2. JAN／メーカー型番一覧

統合後はB0ZZZZZZZのレビュー・在庫を残し、他2ASINを無効化希望です。

よろしくお願いいたします。
```

## 7. 相乗り出品の偽物通報

### 件名
```text
ASIN:B0XXXXXXXX 偽物相乗り出品者の通報・販売停止依頼
```

### 本文
```text
お世話になっております。下記ASINにおいて、偽物と思われる相乗り出品者がいるため、調査と販売停止をお願いいたします。

- 対象ASIN：B0XXXXXXXX
- 弊社は本商品の正規販売店です（Brand Registry登録済み）
- 通報対象セラー：[セラー名／セラーID]

通報根拠：
- 2025/XX/XX に当該セラーから試買を実施
- 受領商品は弊社製造ロットには存在しない偽造品と判定（添付1：真贋鑑定書）
- パッケージ仕様・ロゴ位置・シリアル体系が正規品と異なる

添付資料：
1. 真贋鑑定書
2. 正規品と偽造品の比較画像
3. 試買時の注文画面と到着商品スクショ

該当セラーの当ASIN販売停止と、Brand Registry 経由のテイクダウン手続きの両方を希望します。

よろしくお願いいたします。
```

## テンプレート共通の差替えポイント

各テンプレートで必ず差し替える項目：

- **ASIN**：B0で始まる10文字
- **社名／ブランド名**
- **正しい値／誤った値**
- **商標登録番号**（該当時）
- **添付資料ファイル名・内容**
- **過去のケース番号**（再提出時）

## テンプレート使用時の注意

- そのままコピペせず、必ず内容を実情に合わせて編集
- 添付資料は事実に基づき、改竄・捏造しない
- セラーID・パスワード・個人情報は本文に書かない
- 同じ内容で複数ASINに依頼する場合はASINリストを別ファイルで添付
