# バリエーション軸の整理

## バリエーション軸の典型

### カラー
- BK（ブラック）、WT（ホワイト）、NV（ネイビー）、PK（ピンク）、RD（レッド）、BL（ブルー）、GR（グレー）、BE（ベージュ）、GN（グリーン）、YL（イエロー）、BR（ブラウン）、OR（オレンジ）、PU（パープル）

### サイズ（アパレル）
- XS / S / M / L / LL / 3L / 4L

### サイズ（一般）
- S / M / L

### 容量（化粧品・食品）
- 30M（30ml）、50M（50ml）、100M（100ml）、200M（200ml）
- 30G（30g）、100G（100g）、500G（500g）、1K（1kg）
- 1B（1本）、3B（3本）、5B（5本）、10B（10本）

### 個数・セット
- 1P（1個）、3P（3個セット）、5P（5個セット）、10P（10個セット）

### 年度
- 24（2024年）、25（2025年）

### シーズン
- SS（春夏）、AW（秋冬）、SPR（春）、SUM（夏）、AUT（秋）、WIN（冬）

### 限定
- XMAS（クリスマス）、VAL（バレンタイン）、MOM（母の日）、DAD（父の日）

### グレード
- LITE / STD / PRO / PLUS

### 対象
- M（メンズ）、L（レディース）、K（キッズ）、U（ユニセックス）
- ※サイズの「M／L」と区別するため、Mens / Womens / Kids / Unisex のフルスペル使用も検討

## 軸の組合せパターン

### 1軸（バリエーション少）
```
ALS-COS-0001-30M
ALS-COS-0001-50M
ALS-COS-0001-100M
```

容量違いのみ。

### 2軸（カラー×サイズ）
```
ALS-AP-1500-BK-S
ALS-AP-1500-BK-M
ALS-AP-1500-BK-L
ALS-AP-1500-WT-S
ALS-AP-1500-WT-M
ALS-AP-1500-WT-L
```

アパレルの典型。

### 3軸（カラー×サイズ×容量）
```
ALS-CR-2000-BK-30M-3P
ALS-CR-2000-BK-30M-5P
ALS-CR-2000-BK-50M-3P
```

複雑になるため、軸の優先順位を決める。

## 軸の優先順位

1. **必須軸**：商品本体を識別
2. **第1軸**：最も大きな差（メンズ／レディース、シリーズ違い）
3. **第2軸**：主要バリエーション（カラー）
4. **第3軸**：副バリエーション（サイズ）
5. **オプション軸**：限定・年度・シーズン

## バリエーション数の上限

実務的に運用可能なバリエーション数：

| 軸数 | 軸あたり値数 | 総バリエーション数 |
|---|---:|---:|
| 1軸 | 5値 | 5 |
| 2軸 | 5値×5値 | 25 |
| 3軸 | 5値×5値×3値 | 75 |
| 4軸 | 5値×5値×3値×2値 | 150 |

**100バリエーション超え**は管理破綻のリスク。別商品コードで分割を検討。

## 軸の値コード化のコツ

### 短く明確に
- 「BK」（ブラック2字） vs 「BLACK」（5字）
- SKUの全体桁数を抑えるため短い方が好ましい

### 同種は2字、特殊は3字
- 標準カラー：BK、WT、NV（2字）
- 特殊カラー：PK1、PK2、PK3（3字、サブカラー識別）

### 1字は避ける
- 「B」（ブラック）と「W」（ホワイト）の混同リスク
- 2字で明確化

### 既存業界慣例に合わせる
- カラーは英2字（BK、WT、NV）
- サイズは英1字（S、M、L）

## 季節・限定軸の入れ方

### 末尾に追加
```
ALS-COS-0001-30M       通常品
ALS-COS-0001-30M-XMAS  クリスマス限定パッケージ
ALS-COS-0001-30M-SS24  2024春夏限定
```

### 商品コード位置に入れる（年度型）
```
ALS-24-SS-COS-0001-30M  2024春夏 通常
ALS-24-AW-COS-0050-50M  2024秋冬 通常
```

### 別商品コードとして
完全に別ラインなら別商品コード。例：「クリスマス限定セット」は「ALS-XMAS-2024-001」のような独立コード。

## バリエーション軸の追加・削除の運用

### 軸の追加
既存SKUを変更せず、新規軸を末尾に追加：
- 旧：ALS-COS-0001-30M
- 新：ALS-COS-0001-30M-VS（バニラの香り）／-RS（ローズの香り）

旧SKUは「香り：なし」として扱うか、後付けで「DEF」（デフォルト香り）を追加。

### 軸の削除
SKUは変えずに、属性を集約する側で対応：
- 容量軸が無くなった → 商品マスタの容量列を空欄に
- ただしSKU自体は維持

### 値の追加
新カラー追加：
- 新規SKU：ALS-AP-1500-NV-M（ネイビー追加）
- 既存値（BK、WT）はそのまま運用

## バリエーション軸とJANの関係

### バリエーション毎にJAN
原則：色違い・サイズ違いは別商品 → 別JAN。
- ALS-AP-1500-BK-M：JAN 4901234567890
- ALS-AP-1500-WT-M：JAN 4901234567906

### 親JAN・子JANの考え方
- 親商品（GS1事業者コード共通）
- 子商品（バリエーションごと固有JAN）

JANは事業者がGS1から発番する。詳細は別スキル jan-code-checker。

## バリエーション展開とモール別の運用

### 楽天SKUプロジェクト
- バリエーション項目（カラー・サイズ）で展開
- SKU管理番号はバリエーションごと
- 例：軸「カラー：ブラック、ホワイト」「サイズ：M、L」

### Amazon親子バリエーション
- 親ASIN：variation_theme = color-size
- 子ASIN：色×サイズの各組合せ
- 親子関係をfeed・テンプレートで明示

### Yahoo!バリエーション
- 商品コード内サブコード
- バリエーション項目

### Shopify
- Option1/2/3で3軸まで
- それ以上の軸は別商品 or アプリで拡張

## SKU設計例：ジャンル別

### 化粧品（容量バリエーション中心）
```
ALS-[カテゴリ2字]-[商品4桁]-[容量3字]
例：ALS-SK-0001-30M, ALS-SK-0001-50M
```

### アパレル（カラー×サイズ）
```
ALS-[カテゴリ2字]-[商品4桁]-[カラー2字]-[サイズ1-3字]
例：ALS-AP-1500-BK-M, ALS-AP-1500-NV-L
```

### 食品（季節限定多）
```
ALS-[カテゴリ2字]-[商品4桁]-[シーズン2字]
例：ALS-FD-0010-SS, ALS-FD-0010-AW
```

### 家電（モデル違い）
```
ALS-[シリーズ3字]-[モデル3字]-[カラー2字]
例：ALS-AC-PRO-WT, ALS-AC-LITE-BK
```

### 雑貨（複数軸）
```
ALS-[カテゴリ2字]-[商品4桁]-[サイズ2字]
例：ALS-MS-2050-S, ALS-MS-2050-L
```

### 健康食品（容量＋セット）
```
ALS-[カテゴリ2字]-[商品4桁]-[容量3字]-[セット2字]
例：ALS-HE-0001-30P-1B, ALS-HE-0001-30P-3B
```

## 軸の値リストを別表で管理

商品マスタとは別に「軸の値リスト」を持つ：

### カラーマスタ
| コード | 表示名 | 表示名英 |
|---|---|---|
| BK | ブラック | Black |
| WT | ホワイト | White |
| NV | ネイビー | Navy |
| PK | ピンク | Pink |
| PK1 | ローズピンク | Rose Pink |

### サイズマスタ
| コード | 表示名 | 対応実寸 |
|---|---|---|
| S | S | 身長155-160cm |
| M | M | 身長160-167cm |
| L | L | 身長167-172cm |
| LL | LL | 身長172-177cm |

これにより、SKU内のコードと顧客向け表示を分離管理できる。
