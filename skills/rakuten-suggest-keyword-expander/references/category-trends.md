# ジャンル別 サジェスト傾向

## レディースファッション（100371）

### よく検索される組合せ
- 「[商品種別] + [シルエット/丈] + [色/素材] + [年代] + [シーン]」
- 例：「ワンピース ロング ベージュ 30代 オフィス」

### 8軸の重視

| 軸 | 重視度 |
|---|---|
| 指名（商品種別） | 高 |
| 用途（シーン） | 高 |
| 季節 | 高 |
| 状況（体型・年代） | 中 |
| 場面 | 中 |
| 属性（サイズ・色・素材） | 高 |
| 贈答 | 中 |
| 悩み | 中（「着痩せ」「カバー」等） |

### 頻出ロングテール
- 「ぽっちゃり 大きいサイズ ワンピース」
- 「身長低い ロング丈」
- 「オフィスカジュアル きれいめ」
- 「結婚式 お呼ばれ ドレス」

## サジェスト分析の頻度

| 頻度 | 内容 |
|---|---|
| 月次 | 主要キーワードのサジェスト変動 |
| 季節前 | 季節キーワードの先取り |
| イベント前 | ギフト・SS・マラソンキーワード |
| 商品改廃時 | キーワード総入れ替え |
| 競合分析時 | 競合の新キーワード |

## サジェスト変動の傾向

- 新商品が話題に → 新ブランド名がサジェストに
- 季節商品の早期化 → 季節2-3ヶ月前から
- メディア露出 → 関連語がサジェスト上位
- 大規模イベント → イベント連動語

→ 定期的にサジェスト確認して、トレンドに乗る。
