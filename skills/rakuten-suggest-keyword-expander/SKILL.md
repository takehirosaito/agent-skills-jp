# 楽天サジェスト風キーワード拡張

## 概要

楽天で「拾いたいのに拾えていない検索語」を拡大するため、メインキーワードを起点に8軸で拡張するスキルです。楽天サジェスト（タンタンサーチ）は公式APIが限定的なため、本スキルは商品ジャンル知識に基づく経験則拡張を行います。

8軸：①指名語 ②用途 ③悩み ④状況・属性 ⑤季節 ⑥贈答 ⑦表記揺れ ⑧類義語。これらを掛け合わせ、ロングテール候補を生成。RPP広告／商品名／タグID／レビュー誘導での配置先まで提案します。

## 最重要原則

**「8軸を漏れなく回す／表記揺れ（漢字・カナ・英字・略称）を必ず含める／薬機景表抵触語と商標語は除外」**。1軸だけ厚く拡張せず、横展開で量を稼ぐ。

## 知識ベース

8軸の役割：

| 軸 | 主目的 | 例（電気ケトル） |
|---|---|---|
| 指名語 | カテゴリ捕捉 | 電気ケトル、ケトル、湯沸かし器 |
| 用途 | シーン捕捉 | コーヒー用、ハンドドリップ用、赤ちゃんミルク |
| 悩み | 課題捕捉 | 沸かしすぎ防止、保温したい、すぐ沸かしたい |
| 状況・属性 | 顧客像捕捉 | 一人暮らし、家族用、ペット給湯 |
| 季節 | 時期捕捉 | 冬、夏、新生活、引越し |
| 贈答 | ギフト捕捉 | 結婚祝い、新築祝い、母の日 |
| 表記揺れ | 検索ミス捕捉 | ケトル、けとる、kettle |
| 類義語 | 検索バリエ | 電気ポット、ティーケトル |

## 処理フロー

### Step 1：起点KWと商品プロファイル把握

ユーザーから取得：

- メインKW（起点）
- 商品ジャンル
- ターゲット属性
- 季節性

不明な場合は仮定して進める（明示）。

### Step 2：8軸で機械的に展開

各軸ごとに最低5語を出す。`references/8-axes.md` のパターンを参照。

### Step 3：表記揺れの強化

- 漢字／ひらがな／カタカナ／英字
- 略称／正式名
- 業界用語／一般語
- 商品コード／JAN（社内用、商品名には入れない）

### Step 4：薬機景表・商標除外

| カテゴリ | 例 | 扱い |
|---|---|---|
| 効能訴求（化粧品・健食） | 「シミに効く」「○○を治す」 | 除外 |
| 最大級表現 | 「最安」「No.1」「絶対」 | 除外 |
| 競合ブランド名 | 「ティファール」「デロンギ」 | 除外（商標） |
| 商標含む類似語 | 「ル○○ゼ」 | 除外（商標） |

### Step 5：配置先別の使い分け案

| KWタイプ | 推奨配置 |
|---|---|
| 高ボリューム指名語 | 商品名（メイン） |
| ミドル用途語 | 商品名（サブ）、キャッチ |
| 悩み・状況語 | キャッチコピー、説明文 |
| ロングテール | 説明文、レビュー誘導、RPPキーワード |
| 表記揺れ | タグID、説明文の言い換え |

### Step 6：RPP用と検索SEO用の分類

RPP広告ではビッグ／ミドル中心、SEOではロングテール中心に配分。

## 品質ゲート

- 8軸すべてに最低5語出ているか
- 表記揺れに漢字／ひらがな／カタカナ／英字／略称が含まれるか
- 商標問題のあるブランド名を除外候補にしているか
- 薬機景表抵触語を除外候補にしているか
- 配置先別マッピング（商品名／キャッチ／タグ／説明／RPP／レビュー誘導）が出ているか
- ロングテール候補が「2語以上の組合せ」になっているか

## エッジケース

- **指名語が非常にビッグ（化粧水・スマホ）**：競合多数、ミドル／ロングテール中心に
- **ニッチ商品（業務用）**：一般語より専門語を厚く、表記揺れ重要
- **化粧品・健食**：効能訴求KWは全除外、「使用感」「肌に優しい」など安全寄りで
- **季節商品（クリスマス・ハロウィン）**：オフ期も「予約」「先行販売」で拾う
- **業界用ジャーゴン**：一般語との両方を併記（例：「OPP袋」と「透明袋」）

## 注意事項

- 楽天サジェスト（タンタンサーチ）の公式API利用は楽天規約に従う、無断スクレイピング禁止
- 競合ブランド名・商標を商品名／タグIDに含めない
- 効能訴求語・最大級表現は薬機法／景表法違反リスク、必ず除外
- 拡張KWは仮説段階、実績データ（RPP CTR/CVR）で再評価する前提
- 表記揺れの「英字／ローマ字」は使いすぎると検索意図とズレる、ほどほどに
