# SJIS外文字・機種依存文字・推奨置換

楽天RMS／Yahoo!ショッピング／ネクストエンジン等のShift_JIS要件モールにアップロードする際、SJIS(CP932)で表現できない文字があるとモール側で「？」化・行ごと取り込み失敗等が起きる。事前に置換または除去する。

## カテゴリ別の注意文字

### 丸数字・括弧付き数字

CP932にも一部存在するが、IBM拡張領域でモール側のSJISパーサーが対応しない場合あり。**置換が無難**。

| 文字 | Unicode | 推奨置換 |
|---|---|---|
| ① ② ③ ④ ⑤ ⑥ ⑦ ⑧ ⑨ ⑩ | U+2460-U+2469 | (1)(2)(3)... |
| ⑪ ⑫ ⑬ ⑭ ⑮ | U+246A-U+246E | (11)(12)... |
| ⑴ ⑵ ⑶ | U+2474- | (1)(2)(3) |
| Ⅰ Ⅱ Ⅲ Ⅳ Ⅴ Ⅵ Ⅶ Ⅷ Ⅸ Ⅹ | U+2160- | I II III IV V VI VII VIII IX X |
| ⅰ ⅱ ⅲ | U+2170- | i ii iii |

### CJK拡張漢字（人名漢字）

戸籍上は正しいが、SJIS基本領域に無い人名漢字。CP932のIBM拡張漢字に該当するものもあるが、モール側パーサーが対応しないケースがある。

| 文字 | Unicode | 状態 | 推奨対応 |
|---|---|---|---|
| 髙 | U+9AD9 | CP932 IBM拡張 | 「高」に置換するか本人確認のうえ「髙」のまま |
| 﨑 | U+FA11 | CP932 IBM拡張 | 「崎」または「﨑」のまま |
| 𠮷 | U+20BB7 | CP932外 | 「吉」に置換 |
| 德 | U+5FB7 | CP932 IBM拡張 | 「徳」または「德」のまま |
| 凜 | U+51DC | CP932 IBM拡張 | 「凛」または「凜」のまま |
| 渡邊 / 渡邉 | 邊U+908A 邉U+9089 | CP932 IBM拡張 | 確認のうえ本字使用 |
| 𠀋 | U+2000B | CP932外 | 「丈」に置換 |
| 髙橋 ／ 高橋 | — | — | 戸籍上の正字確認が必要 |

**人名は本人確認なしで勝手に置換しない**。商品名・住所欄等で機械的に置換する場合は別問題（戸籍上の人名はクレームに直結）。

### 絵文字（U+1F300以降）

絵文字はSJISでは**完全に表現不可**。UTF-8モールでも一部非対応。

| 種類 | 例 |
|---|---|
| 顔文字 | 😀 😊 😍 |
| 物品 | 🎁 🛒 🏷️ |
| 矢印・記号 | ➡ ★ ☆ |

**置換策**
- ★ ☆（U+2605, U+2606）→ CP932にあり、楽天等で使用可能
- ☑ ✅ → CP932外、置換 or 削除
- 顔文字・絵文字 → 削除推奨

### ハイフン類の混在（数値・コードに影響）

商品コードや型番に含まれるハイフンは、以下が混在しがち：

| 字 | Unicode | 半角/全角 |
|---|---|---|
| - | U+002D | 半角ハイフン-マイナス（標準） |
| ‐ | U+2010 | ハイフン |
| ‑ | U+2011 | ノーブレークハイフン |
| ‒ | U+2012 | 数値用ダッシュ |
| – | U+2013 | EN-DASH |
| — | U+2014 | EM-DASH |
| ― | U+2015 | ホリゾンタルバー |
| − | U+2212 | マイナス記号 |
| ‐ | U+30FC（長音記号 ー） | カタカナ長音と混同しやすい |
| − | U+FF0D | 全角ハイフンマイナス |
| ー | U+30FC | 長音記号（カタカナ） |

商品コードでこれらが混在すると、検索一致／在庫連携／JANチェック全て失敗する。**全て `-`（U+002D）に統一**するのが安全。

## 一括置換のリスト（実務でよく使う組）

```
①→(1) ②→(2) ③→(3) ④→(4) ⑤→(5)
㈱→(株) ㈲→(有)
№→No. ℡→TEL
㎜→mm ㎝→cm ㎡→m2 ㎏→kg
–→- —→- −→- ‒→- ‐→- ‑→-
"→" '→' ‐→-（長音と紛らわしいものは個別判断）
```

## 検出方法（バイト単位）

CP932で扱えない範囲を機械的に検出する場合、Pythonで：

```python
def find_sjis_out_of_range(text: str) -> list[tuple[int, str]]:
    result = []
    for i, ch in enumerate(text):
        try:
            ch.encode("cp932")
        except UnicodeEncodeError:
            result.append((i, ch))
    return result
```

これでSJIS要件モールにアップロードする前の置換対象を網羅的に抽出できる。
