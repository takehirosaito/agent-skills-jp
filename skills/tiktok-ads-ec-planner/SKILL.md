# TikTok広告 EC運用 設計

## 概要

TikTok広告（TikTok for Business）をECの獲得・販売に使うための運用設計スキル。キャンペーン目的・計測（ピクセル/イベント）・オーディエンス・クリエイティブ方針・予算/テスト設計・TikTok Shop連携を整理する。TikTokは「発見型」で、音・縦型・冒頭フックなど他媒体と勝ち筋が異なる。媒体特性に合わせた設計で、検索/リターゲ中心の運用とは別軸の獲得を狙う。

このスキルはMetaのコピー作成（`meta-ad-copy-ec-jp`）とは別で、TikTok広告アカウントの構成・計測・クリエイティブ方針・検証フレームを扱う。

## 最重要原則

**「冒頭2〜3秒のフックで決まる／広告っぽさを抑えUGC的に／計測(ピクセル・イベント)を先に整える／少額で複数クリエイティブをテストして勝ち筋を増やす／予算は学習を阻害しない配分」**。TikTokは作り込んだ広告より自然な縦型動画が伸びやすい。計測基盤がないと最適化が回らないため最初に設計する。

## 知識ベース

運用の主要ブロック：

| ブロック | 論点 |
|---|---|
| キャンペーン目的 | コンバージョン/トラフィック/動画視聴等、目的とKPIの一致 |
| 計測 | ピクセル設置、主要イベント（購入/カート/会員）、計測の信頼性 |
| オーディエンス | 興味関心・類似・リターゲ。発見型では広めから学習させる発想 |
| クリエイティブ | 冒頭フック・縦型・テロップ・音・UGC風・複数バリエーション |
| 予算/入札 | 学習に必要な配信量、テスト→スケールの段階設計 |
| TikTok Shop | 連携の可否・在庫/配送・動画/ライブとの接続 |

クリエイティブの型（例）：問題提起→共感→解決(商品)→証拠→CTA／ビフォーアフター／使い方デモ／レビュー紹介。誇大・断定や薬機/景表に反する表現は避ける。

> 広告メニュー名・計測仕様・TikTok Shopの対応は変動する。確定は TikTok for Business 公式で確認。

## 処理フロー

### Step 1：商材・目的・予算の確認
- 商材、ターゲット、目標KPI(CPA/ROAS)、月予算、既存の計測有無、TikTok Shop利用意向
不明時は「単品・10〜30代・CV目的・小予算からテスト」を仮置きし明示。

### Step 2：計測設計
- ピクセル・主要イベントの設計、計測の信頼性確保。

### Step 3：オーディエンス設計
- 興味関心/類似/リターゲの構成。発見型は広めの母集団から学習させる方針を提示。

### Step 4：クリエイティブ方針
- フック・縦型・UGC風の複数バリエーション案（構成と訴求軸）。表現規制に配慮。

### Step 5：予算・テスト・スケール
- テスト予算配分、勝ちクリエイティブの判定基準、スケール時の配分設計。

## 出力フォーマット

```
# TikTok広告 EC設計：[商材]

## 0. 前提（商材/目的/予算・仮定）
## 1. キャンペーン目的とKPI
## 2. 計測設計（ピクセル/イベント）
## 3. オーディエンス構成
## 4. クリエイティブ方針（フック×訴求の複数案）
## 5. 予算・テスト・スケール計画
## 6. TikTok Shop連携の方針（任意）
```

## 品質ゲート
- 目的とKPIが一致しているか
- 計測（ピクセル/イベント）を先に設計したか
- クリエイティブが媒体特性（フック/縦型/UGC）に合っているか
- テスト→スケールの段階設計があるか

## 注意事項
- 広告仕様・メニューは変動。確定は公式で確認。
- 効果の断定・誇大表現、薬機法/景表法に反する表現は使わない。
- クリエイティブの著作権/音源利用ルールを守る。
