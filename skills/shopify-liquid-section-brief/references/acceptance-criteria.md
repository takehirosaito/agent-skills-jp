# 受け入れ条件テンプレート（UAT）

実装完了の判定基準。マーチャント／エンジニア／QA が共通して使える形で書く。

## 基本構造

```markdown
## 受け入れ条件

### 機能要件
- [ ] ...

### UI／レイアウト要件
- [ ] ...

### 編集体験（Theme Editor）
- [ ] ...

### 性能要件
- [ ] ...

### アクセシビリティ要件
- [ ] ...

### 多言語要件
- [ ] ...

### 互換性
- [ ] ...
```

## 機能要件（共通）

- [ ] テーマカスタマイザーで「セクションを追加」から本 section が選択できる
- [ ] preset で指定した初期 block が正しく配置される
- [ ] 全 settings が編集→保存→反映される
- [ ] block を1個から `max_blocks` 個まで追加できる
- [ ] block の並び替え（DnD）が動く
- [ ] block を削除しても他 block に影響しない
- [ ] section の `enabled_on` で指定したテンプレでのみ追加可能
- [ ] 空 block（画像なし／文言なし）でレイアウト崩壊しない
- [ ] フォールバック（プレースホルダー画像）が表示される

## UI／レイアウト要件

### レスポンシブ

- [ ] PC（≥990px）：指定のカラム数／余白／フォントサイズ
- [ ] タブレット（749-989px）：指定通り
- [ ] モバイル（<749px）：指定通り、横スクロール発生せず
- [ ] ブレークポイント間で文字／画像が崩れない

### ビジュアル

- [ ] フォントが theme settings の色／フォントを使用
- [ ] カラースキーム（color_scheme）が theme 設定と整合
- [ ] 画像の比率が指定通り（PC／SP で切替可能）
- [ ] アニメーション（あれば）が指定通り

## 編集体験（Theme Editor）

- [ ] `block.shopify_attributes` で block ごとに編集パネルが開く
- [ ] section 編集パネルが論理的に整理（`header` / `paragraph` で区切り）
- [ ] settings の `info` で必要な補足説明が出る
- [ ] `visible_if` で条件付き設定が正しく切り替わる
- [ ] block 追加時に preset の初期値が反映される

## 性能要件

- [ ] Lighthouse Performance：既存比 -5 以下
- [ ] 画像：`loading="lazy"`、`srcset` で複数サイズ提供
- [ ] CSS／JS：必要時のみ読み込み（section 専用 asset）
- [ ] jQuery を新規追加しない
- [ ] Web Vitals（LCP, INP, CLS）が悪化しない

## アクセシビリティ要件

- [ ] 見出し階層が正しい（h2 → h3 の順、飛ばさない）
- [ ] 画像 alt が `block.settings.image.alt` から取得
- [ ] キーボード操作（カルーセル・アコーディオン・タブ）が動く
- [ ] フォーカスインジケーターが見える
- [ ] カラーコントラスト：WCAG AA（4.5:1 以上）
- [ ] スクリーンリーダーで読み上げ可能（aria-label / aria-expanded 等）

## 多言語要件（Markets 対応時）

- [ ] schema 内の文言が `t:translation_key` 形式で locales/ から取得
- [ ] Translate & Adapt で section の `text` / `richtext` 設定が翻訳可能
- [ ] 翻訳後のテキストでレイアウト崩壊しない（長文／短文）
- [ ] hreflang が言語別 URL で正しく出力

## 互換性

- [ ] 親テーマ（Dawn等）のスタイルと衝突しない
- [ ] テーマアップデート時に上書きされない構成（カスタム section ファイルを独立）
- [ ] OS 2.0 / 非 OS 2.0 の判定済み（非 OS 2.0 なら別仕様）
- [ ] 主要ブラウザ（Chrome／Safari／Firefox／Edge）で動作確認

## テスト方法

| テスト項目 | 方法 |
|---|---|
| カスタマイザー動作 | Shopify Theme Editor で section 追加・編集・保存・プレビュー |
| レスポンシブ | Chrome DevTools で各幅をエミュレート |
| Lighthouse | DevTools 内蔵 Lighthouse でPerformance/A11y/SEO 測定 |
| アクセシビリティ | axe DevTools / Lighthouse A11y |
| 多言語 | Markets で言語切替、Translate & Adapt で翻訳 |
| 互換性 | BrowserStack 等で主要ブラウザ確認 |

## 引き渡し時のドキュメント

実装完了時に納品する書類：

1. **動作確認チェックリスト**（受け入れ条件をクリアしたかの記録）
2. **管理画面操作マニュアル**（マーチャント向け：section 追加・編集・複製手順）
3. **コード変更履歴**（git diff or テーマアップロード差分）
4. **既知の制約・既知のバグ**（あれば）

## マーチャント向けマニュアル雛形

```markdown
## ○○セクションの使い方

### 追加方法
1. Online Store → Themes → Customize
2. 配置したいページ（トップ／商品ページ等）を選択
3. 「セクションを追加」→「○○」を選択
4. プリセットを選択

### 編集方法
- 見出し：セクション設定の「見出し」を編集
- 各 block：block をクリック→ 画像／タイトル／本文を編集

### 注意点
- 画像サイズ：横 1200px 以上推奨
- block は最大 6 個まで
- ○○テンプレでのみ追加可能
```
