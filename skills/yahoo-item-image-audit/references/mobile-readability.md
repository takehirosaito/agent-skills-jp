# スマホ表示で読めるテキストサイズの実務ガイド

---

## 1. なぜスマホ表示が最優先か

Yahoo!ショッピングへの流入は**スマホ60〜80%**。PCで作った画像をスマホで見ると：
- 画像が縦150〜200px相当に縮小
- 文字が1/4〜1/3に圧縮
- 細い書体・薄い色は完全に潰れる
- 装飾★が小さくなって意味不明

**PC上で見ている自分の感覚はあてにならない**。必ずスマホで実機確認。

---

## 2. 文字サイズの目安

### 1080×1080px の画像基準

| 用途 | 制作時px | スマホ実表示換算（375px幅・画像横半分表示） |
|---|---|---|
| 大見出し（強訴求） | 100〜120px | 約35〜42px相当 |
| 中見出し | 70〜90px | 約25〜32px相当 |
| 通常テキスト | 50〜65px | 約18〜23px相当 |
| 注釈・打消し | 30〜40px | 約11〜14px相当（最小限度） |

### 検索結果サムネ（200×200px相当）の制約
サムネサイズでは文字はほぼ読めない。**形・色・商品認識のみ**で勝負。

---

## 3. 1枚に書ける文字数の目安

### 1枚目（メイン）
- メインキャッチ：1行15文字以内、最大2行
- サブ：1行10文字以内、最大1行

→ 合計 **15〜25文字**まで。多くて2行。

### サブ画像
- ステップ説明：各ステップ20文字以内、3〜5ステップ
- スペック表：列見出し＋値、項目10以内
- 比較表：縦3〜5項目、横2〜4列

---

## 4. 書体・色の落とし穴

### 推奨書体
- ゴシック体（読みやすい）
- 太字（ウェイト Bold〜Black）
- システムフォント（游ゴシック・ヒラギノ角ゴ・Noto Sans CJK）

### 避ける
- 明朝体（細部が潰れる）
- 細字（Light／Thin）
- 装飾系（手書き風・筆記体）

### 色のコントラスト
- 白背景＋黒／濃グレー文字 ✅
- 白背景＋淡いピンク／淡いブルー文字 ❌（コントラスト不足）
- 黒背景＋白文字 ✅
- 写真背景＋色文字 → **必ず影／白縁取り**で可読性確保

---

## 5. レイアウトの基本

### 余白
- 上下左右に**画像幅の5〜10%**の余白
- テキスト同士の行間：文字サイズの1.3〜1.5倍

### グリッド
- 三分割の交点に商品本体／訴求テキスト
- 中央配置：シンプル商品向け

### 視線誘導
- 左上 → 右下（Z型）／中央集中
- 矢印・吹き出しで誘導（過剰でない）

---

## 6. スマホ表示テスト手順

1. **画像を保存後、スマホに転送**（AirDrop／クラウド共有）
2. スマホで画像単体を確認（フルスクリーン）
3. 縮小表示（写真アプリのサムネ）で確認
4. **Yahoo!ショッピングアプリで実際の検索結果サムネ**を確認
5. ストアクリエイターProのプレビュー機能

### 確認チェックリスト
- [ ] サムネサイズで商品とカテゴリが認識できる
- [ ] 縦長スクロール時にテキストが読める
- [ ] 装飾★◆ が小さくなりすぎていない（むしろ削除推奨）
- [ ] 色のコントラストが十分
- [ ] 注釈・打消し表示が極小すぎない

## 7. デバイス別の表示サイズ

| デバイス | 画面幅 | 商品ページ画像表示 |
|---|---|---|
| iPhone SE | 375px | フル幅 ≈ 375px |
| iPhone 15 | 393px | フル幅 ≈ 393px |
| iPhone 15 Pro Max | 430px | フル幅 ≈ 430px |
| Android 中位機 | 360〜412px | フル幅 ≈ 360〜412px |

縦長ページ内の画像は**フル幅表示**で、1080×1080px の画像は約1/3に縮小される。

---

## 8. 画像内テキストの代替案

「画像内に書くと読めないけど、伝えたい情報がある」場合：

| 情報 | 推奨場所 |
|---|---|
| 商品名 | name（商品名） |
| キャッチコピー | headline |
| 詳細スペック | caption（HTML可） |
| 注意事項 | caption末尾 |
| 配送・返品 | ストア情報・お買い物ガイド |
| 価格・送料 | 自動表示エリア |
| クーポン情報 | クーポン取得バナー（自動表示） |

→ 画像にすべてを詰めず、**テキストフィールドと役割分担**。

---

## 9. 改善前後の比較例

### 改善前
- 1080×1080px に「商品名」「価格」「クーポン」「送料無料」「★1位」「期間限定」「数量限定」「保証」「人気No.1」が30〜40pxサイズで全部入る
- スマホ実表示で文字が15px以下 → 読めない
- 商品占有率 20%

### 改善後
- 1080×1080px に「商品名（80px）」「USP1行（60px）」「注釈（35px）」のみ
- スマホ実表示で文字が25〜30px → 読める
- 商品占有率 55%

→ **情報を絞ったほうがクリックされる**。
