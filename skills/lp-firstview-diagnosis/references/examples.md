## 例1：保湿化粧水LP（Meta流入）

### 改善前のFV
- 主見出し：「肌のうるおいで、毎日に自信を。」（情緒的）
- サブコピー：「全成分自然由来」
- 画像：暗めの背景・商品が小さい
- CTA：「詳しくはこちら」（フッターのみ）
- スマホ：FV内にCTAなし

### スコア：6/20点
| 項目 | スコア |
|---|---|
| Who | 0 |
| What | 1 |
| Why now | 0 |
| CTA | 0 |
| スマホ適合 | 0 |
| 信頼要素 | 0 |
| 広告整合性 | 1 |
| 画像品質 | 1 |
| 法務 | 2 |
| 視線 | 1 |

### 改善後のFV
- 主見出し：「乾燥肌の30代へ。単一農園素材の保湿化粧水」（28字）
- サブコピー：「初回30%OFF・30日返金保証・送料無料／★4.6 / 1,200件レビュー」（41字）
- 画像：明るい朝の窓辺＋商品＋オファー帯（右上）
- CTA：「今すぐ初回30%OFFで始める →」（橙色ボタン・大）
- スマホ：FV内に全要素配置

### 改善後スコア：18/20点

### 期待される改善
- CVR：+30-50%（業界一般値）
- 直帰率：-20%

## 例2：機能性表示食品サプリLP（Google検索流入）

### 改善前のFV
- 主見出し：「健康な毎日を、サプリと共に。」（情緒・抽象）
- 商品画像：パッケージ大
- 「機能性表示食品」表記なし
- 届出番号なし
- CTAあるが文言曖昧「お問い合わせ」

### スコア：5/20点（法務リスク0点）

### 改善後のFV
- 主見出し：「40代の内臓脂肪に。葛の花由来イソフラボン配合 機能性表示食品」（30字）
- 届出番号：「届出番号A123」（パッケージ画像と訴求帯両方に）
- 機能性表示文言（届出文言と一字一句一致）：「葛の花由来イソフラボンには、肥満気味の方の体重・お腹の脂肪を減らすのを助ける機能があることが報告されています」（サブコピー）
- オファー帯：「初回70%OFF・いつでも解約可」
- 信頼マーク：「★4.5 / 5,400件」
- CTA：「初回70%OFFで始める（定期コース）→」

### 改善後スコア：19/20点

### 法務上の最重要修正
- **届出番号A123を明示**（必須）
- **機能性表示文言を届出と一字一句一致**
- 「○kg痩せる」「内臓脂肪が消える」NG表現を削除
- before/after画像を使用していない

## 例5：母の日ギフトスイーツLP（Meta流入・季節）

- 主見出し：「特別な日に、最高の贈り物を。」（最上級・抽象）
- 商品画像：綺麗だが季節感薄い
- 配送締切日記載なし

### 改善後のFV
- 主見出し：「母の日5月8日までお届け／職人手作りバスクチーズケーキ」（28字）
- サブコピー：「のし・メッセージカード・限定包装・送料無料／4,800円」
- 画像：商品＋カーネーション＋オファー帯

## 例6：定期購入LPの法務リスク事例（修正必須）

### 改善前のFV
- 主見出し：「初回半額！いつでも解約OK」（大書き）
- 「定期コース」表記が画面下部に極小フォント
- 解約条件詳細なし
- 実際は最低継続3回縛り

### スコア：4/20点（**法務リスク：特商法定期購入規制違反**）

### 違反内容
- **定期コースであることの明示が不十分**（特商法11条違反）
- **「いつでも解約OK」が実運用と不一致**（最低3回縛り＝有利誤認）
- 最終確認画面6項目の表示が不適切（直罰3年以下懲役・300万円以下罰金）

### 改善後のFV
- 主見出し：「初回1,980円の定期コース／2回目以降4,500円」（24字・定期コース明示）
- サブコピー：「最低継続回数なし・いつでも解約可・送料無料」
- 訴求帯：「機能性表示食品（届出番号A123）」
- CTA：「定期コースに申し込む →」

### 必須修正
- 「定期コース」を主見出しと同等サイズで明示
- 初回価格と2回目以降価格を**並列表示**
- 解約条件を**FV近傍**で明示
- 最終確認画面に6項目を明瞭に
- 最低継続回数縛りを撤廃するか、正確に明示

### 改善後スコア：17/20点

## 共通の学び

1. **「カッコいい」と「伝わる」は別物**：FVの目的は伝達であってデザイン賞ではない
2. **スマホ1画面に4要素**（Who/What/Why now/CTA）が見えるかが最優先
3. **広告→FV→CTAの三点一致**は媒体審査でも見られる
4. **法務リスク表現は即修正**：公開停止・媒体審査リジェクト・課徴金リスク
5. **A/Bテストで仮説検証**：影響度の高い項目から1つずつ
