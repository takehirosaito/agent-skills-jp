# ギフト需要キーワード作成

## 概要

母の日・父の日・敬老の日・お中元・お歳暮・結婚祝・出産祝・快気祝・香典返し・法事・内祝・七五三・クリスマス・バレンタインなど、季節イベントおよび冠婚葬祭ギフトの需要を取り切るための、検索キーワード／広告コピー／商品名／LP見出し／のし表書き／配送スケジュールを一括設計するスキル。

ギフト需要は「検索キーワード」だけ揃えても売れない。配送締切・のし表書き・水引・贈答タブー・地域差・物流ピーク遅延を商品ページと運用カレンダーに正しく落とさないと、「常識を知らない店」と評価され、購入直前で離脱する。本スキルは検索の入口から購入後の運用までを一連の設計として出す。

## ★最重要原則

**「コア検索KW × 価格帯 × 贈る相手 × のし表書き × 配送締切」の5軸を1枚で揃える。** どれか1つが欠けると購入直前で離脱する。特に弔事・結婚祝の水引（蝶結び／結び切り／本数）と、お中元・お歳暮の地域差（関東／関西／九州）、出産祝・結婚祝・快気祝のタブー品物は、外すと炎上リスクすらある。

## 対応イベント

### 季節イベント（時期固定）
- 母の日（5月第2日曜）／父の日（6月第3日曜）／敬老の日（9月第3月曜）
- 御中元（関東6月下旬-7/15、関西7/15-8/15、九州8月）／御歳暮（12/13-12/25）
- 七五三（11/15）／クリスマス（12/24-25）／バレンタイン（2/14）／ホワイトデー（3/14）
- 入学祝・卒業祝（3-4月）／新生活（4月）

### 冠婚葬祭（通年）
- 出産祝・出産内祝／結婚祝・結婚内祝／快気祝・全快内祝／香典返し・満中陰志／法事・粗供養／新築祝・開店祝

## 処理フロー

### Step 1：入力情報の整理

必須：
- 商品ジャンル（食品／スイーツ／酒／コスメ／雑貨／花／カタログ）
- 対応イベント（母の日／お中元／結婚祝 等）
- 価格帯（〜3,000／3,000-5,000／5,000-10,000／10,000-30,000／30,000〜）
- 包装対応（のし／包装紙／メッセージカード／名入れ／別送）
- 配送条件（即日／翌日／指定可否／冷蔵冷凍／離島）

任意：
- 販売チャネル（楽天／Amazon／Yahoo!／自社EC／Meta／Google／LINE）
- 過去実績（前年同期の販売数・キーワード）

不足時は仮置きで初稿を出し、冒頭に「確認が必要」を表示する（ハイブリッド設計）。

### Step 2：贈る相手のセグメント

イベントごとに主要セグメントを確定する：
- お中元・お歳暮：取引先／上司／親族
- 母の日・父の日：実母・実父／義母・義父／祖母・祖父
- 敬老の日：祖父母／高齢の親
- 出産祝：上司の奥様／友人／兄弟
- 結婚祝：友人／兄弟／部下

セグメント別に「失礼にならない金額」「定番品」「タブー品」が変わる。

### Step 3：キーワードを3層で分類

| 層 | 例（母の日） | 用途 |
|---|---|---|
| コア検索KW | 母の日／母の日プレゼント／母の日ギフト | 商品名・カテゴリページ |
| 複合検索KW | 母の日 60代／母の日 義母／母の日 5000円／母の日 早割 | LP見出し・広告見出し |
| ロングテール | 母の日 60代 母 高級／母の日 義母 失礼にならない | コラム・FAQ・広告説明 |

完全リストは `references/gift-keywords-full.md`。

### Step 4：のし表書き・水引の確定

弔事と結婚祝は特に間違えやすい：

| 用途 | 表書き | 水引 |
|---|---|---|
| 御中元 | 御中元 | 紅白5本蝶結び |
| 御歳暮 | 御歳暮 | 紅白5本蝶結び |
| 母の日 | 御母の日／感謝／ありがとう | 紅白5本蝶結び or なし |
| 出産祝 | 御出産御祝／御祝 | 紅白5本蝶結び |
| 結婚祝 | 寿／御結婚御祝 | **紅白10本結び切り** |
| 快気祝 | 快気祝／全快内祝 | **紅白5本結び切り** |
| 香典返し（仏式） | 志 | **黒白結び切り** |
| 香典返し（関西） | 満中陰志 | 黄白結び切り |
| 法事 | 御供／粗供養 | 黒白／黄白結び切り |

完全表は `references/manner-guide.md`。

### Step 5：配送スケジュールの逆算

イベント当日から逆算して、広告表記オン日／早割締切／当日着最終締切／表記オフ日を確定する：

**母の日（5/10想定）**：
- 4/10 早割スタート・表記オン → 4/25 早割締切 → 5/8 当日着最終 → 5/10 当日 → 5/11 **表記オフ・広告停止**

**御歳暮（〜12/25）**：
- 10/25 超早割 → 11/25 早割締切 → 12/20 物流ピーク → 12/25 最終日 → 12/26 **表記オフ・「御年賀／寒中御見舞」への切替準備**

詳細は `references/delivery-schedule.md`。

### Step 6：価格帯別ターゲットの確定

| 価格帯 | 主なシーン |
|---|---|
| 〜3,000円 | カジュアル・友人・同僚 |
| 3,000-5,000円 | 親族・カジュアル取引先 |
| 5,000-10,000円 | 親族・上司・標準取引先 |
| 10,000-30,000円 | 重要取引先・家族の節目 |
| 30,000円〜 | VIP取引先・親しい家族の特別な機会 |

### Step 7：タブー品物のアラート設計

自動オーダー画面で「この用途×この商品」がタブーに該当する場合は確認ダイアログを出す：

- 出産祝に**刃物・櫛・白いハンカチ**（NG）
- 結婚祝に**割れ物・刃物・偶数金額（2/4/6万）**（NG）
- 快気祝に**残るもの（食器・タオル）**（消えもの推奨）
- 香典返しに**慶事の食品・派手な包装・お酒（地域・宗派）**（NG）

### Step 8：イベント後の運用カレンダー

イベント終了翌日（表記オフ日）にやること：
- [ ] 広告停止（Meta/Google/Yahoo!/LINE）
- [ ] LPを通常版に切替
- [ ] 商品名から「母の日」「○月○日まで」削除
- [ ] バナー画像差し替え
- [ ] メルマガ配信停止
- [ ] お中元・お歳暮は表書きを「暑中御見舞／残暑御見舞／御年賀／寒中御見舞」に切替準備

## 代表例：母の日 高単価スイーツ（5,000円帯）

**入力**：
- 商品：高級フルーツゼリー詰合せ 4,980円
- イベント：母の日（5/10想定）
- 価格帯：5,000円
- セグメント：実母／義母（50-70代）
- 包装：のし可（表書き「感謝」推奨）、メッセージカード可

**コアKW**：母の日／母の日プレゼント／母の日ギフト／母の日 スイーツ

**複合KW**：母の日 5000円／母の日 60代／母の日 70代／母の日 義母／母の日 早割／母の日 スイーツ 高級／母の日 ゼリー

**ロングテール**：母の日 義母 失礼にならない／母の日 60代 母 高級／母の日 当日 間に合う／母の日 メッセージカード 文例

**広告コピー（Meta プライマリ125字以内）**：
> 5月10日は母の日。いつも頑張るお母さんへ、ひと粒で笑顔がほころぶ高級フルーツゼリーを。冷蔵便で全国配送、のし「感謝」とメッセージカード無料対応。早割は4月25日まで。

**LP見出し（PASONA短縮）**：
1. 「お母さんへ、ありがとう」（共感）
2. 「ひと粒で表情が変わる、果実そのままの贅沢」（解決）
3. 「のし・メッセージカード無料／冷蔵便で全国へ」（オファー）
4. 「早割は4/25まで／5/8 23:59までのご注文で当日着」（限定）
5. CTA：「母の日に間に合うご注文はこちら」

**配送スケジュール**：
- 4/10 オン → 4/25 早割締切 → 5/8 当日着最終 → 5/11 オフ

**のし**：紅白5本蝶結び、表書き「感謝」または「御母の日」

詳細パターン（食品・酒・コスメ・カタログギフト・弔事系）は `references/examples.md`。

## 品質ゲート

- [ ] イベント／時期／贈る相手／価格帯／包装／配送 の6要素を全て確定した
- [ ] コア／複合／ロングテールの3層でキーワードを出した
- [ ] のし表書き・水引の選択肢が用途と一致している（弔事と慶事の混同なし）
- [ ] お中元・お歳暮は地域差（関東／関西／九州）を明示した
- [ ] 結婚祝で蝶結び（NG）を提案していない／紅白10本結び切り
- [ ] 快気祝で「残るもの」を主推奨していない／消えもの中心
- [ ] 香典返しでお祝い色・お酒・生もの・紅白の食品を提案していない
- [ ] 出産祝で刃物・櫛・白いハンカチをタブーアラート対象にした
- [ ] 配送スケジュール（早割・当日着最終・表記オフ日）を日付で明示
- [ ] 物流ピーク（GW・お中元・お盆・お歳暮・年末）の遅延+1〜2日を考慮
- [ ] 冷蔵便／冷凍便の地域別対応（離島・沖縄・北海道）を明示
- [ ] イベント後の運用カレンダーを添えた

## エッジケース

- **同じ商品で慶事と弔事の両方に対応**：用途別にのし／包装の選択肢を分けて出す。商品ページで「用途別おすすめ」を導線分け。
- **喪中の相手への御歳暮**：通常の「御歳暮」は控え、年明けに「寒中御見舞」へ。商品ページで「喪中対応」のFAQを出す。
- **海外・離島・冷蔵便**：通常+2〜3日の追加リードタイム。配送可否マップを商品ページに常設。
- **地域差が大きいお中元**：関東・関西・九州で配送締切が別。LP内で地域選択UI、または地域別ページを用意。
- **法人ギフトの大量注文**：別送・分納・領収書発行・税込／税抜表記・複数送り先の指定UIを必須化。

## 注意事項

- 配送業者の物流ピーク（GW／お中元／お盆／お歳暮／年末）は通常+1〜2日。実物流の最新を物流会社に確認。
- お中元・お歳暮の表書き・時期は地域差が大きい。「全国一律」と言い切らず、関東／関西／九州を分けて記載する。
- 弔事の水引（黒白／黄白／双銀／双白）は宗派・地域で違う。商品ページで複数選択肢を提示。
- 結婚祝の偶数金額（2万・4万・6万）と「重ねる」連想（重箱の重ね詞）はNG。商品設計時から避ける。
- 「皮膚科医推薦」（化粧品）「絶対」「最」「No.1」（景表法）など、ギフトでも基本の法令・媒体ポリシーは適用される。
- ステマ規制（2023.10〜）：インフルエンサー素材を流用する場合は「PR」「広告」明示と契約条項が必須（別スキル `influencer-brief-generator`）。
