# イベント別配送スケジュール

各イベントの「配送締切日」「広告／LP表記オン／オフ日」の標準スケジュール。

配送業者の物流ピーク時は通常+1〜2日。実物流の最新を物流会社に確認すること。

---

## 母の日（5月第2日曜）

### 例：2026年5月10日（日曜）の場合

| 日付 | 内容 |
|---|---|
| 4月10日 | 早割スタート・表記オン |
| 4月25日 | 早割締切 |
| 5月1日 | 母の日3日前到着希望の最終締切 |
| 5月8日 | 当日到着希望の最終締切（金曜） |
| 5月9日 | 物流ピーク（土曜・前日着の最終） |
| 5月10日 | 当日（日曜） |
| 5月11日（月） | **表記オフ日**：広告・LP・商品名から「母の日」削除 |

### 注意
- 5月3-5日のGWは物流が混雑するため、4月25日の早割を訴求
- カーネーション付きの場合、配送地域の温度管理（涼しい便）

## 御歳暮

### 例：12月25日までの場合

| 日付 | 内容 |
|---|---|
| 10月25日 | 超早割スタート |
| 11月25日 | 早割締切 |
| 12月10日 | 物流ピーク開始 |
| 12月20日 | 物流ピーク（年末ピーク） |
| 12月25日 | お歳暮期間最終日 |
| 12月26日 | **表記オフ日**：表書きを「御年賀」or「寒中御見舞」に切替準備 |

### 喪中対応
- 喪中の相手には御歳暮を控えるか、表書きを「寒中御見舞」（年明け）に切り替える

## 七五三（11月15日中心）

### スケジュール
- 10月中旬：表記オン
- 11月15日：当日
- 11月16日：表記オフ

### 関連商品
- 内祝として返礼ギフトの需要

---

## 卒業・入学祝（3月-4月）

### スケジュール
- 2月中旬：表記オン（高校卒業）
- 3月1-10日：高校卒業ピーク
- 3月20日前後：大学卒業
- 4月：入学
- 4月15日：表記オフ目安

---

## 出産祝・結婚祝・快気祝・香典返し・法事（通年）

### スケジュール感
- 出産祝：出産連絡から1ヶ月以内が一般的
- 結婚祝：挙式の1週間前まで or 挙式後1ヶ月以内
- 快気祝：退院後10日〜1ヶ月以内
- 香典返し：四十九日法要後（仏式）／五十日祭後（神式）
- 法事の引き出物：法事当日に手渡し

これらは通年商品で、表記オン／オフの管理は不要。ただし商品の在庫・賞味期限・対応可能日に注意。

## 物流ピーク時の遅延予測

### 通常時
- 関東-関西：翌日着
- 関東-九州：翌日〜翌々日着
- 関東-北海道／沖縄／離島：2-3日着

### 物流ピーク時（+1〜2日見る）
- 母の日（5月第2日曜直前）
- お中元（7月10-15日）
- お盆（8月10-15日）
- お歳暮（12月20-25日）
- 年末（12月25-31日）
- GW（4月29日-5月5日）
- お正月（12月31日-1月3日）

## 自社EC運営での配送スケジュール対応

### 商品ページに表示すべき情報
- 「○月○日までのご注文で○月○日着」
- 「物流ピーク時の遅延可能性」
- 「冷蔵便／冷凍便の地域別対応」
- 「お届け日指定の可否」

### カート・確認画面で
- 「お届け希望日」入力欄
- 「のし／包装／メッセージカード」選択
- 「複数送り先」指定機能

### 注文受付後
- 注文確認メールで配送予定日明示
- 発送完了メールで追跡番号
- 遅延発生時の連絡フロー

## イベント終了後の運用カレンダー

### 母の日終了後（5月11日）
- [ ] 広告停止（Meta/Google/Yahoo!/LINE）
- [ ] LP通常版に切替
- [ ] 商品名から「母の日」「5月8日まで」削除
- [ ] バナー画像差し替え
- [ ] メルマガ配信停止

### 御中元終了後（7月16日）
- [ ] 同上
- [ ] 表書きを「暑中御見舞」に切替準備

### 御歳暮終了後（12月26日）
- [ ] 同上
- [ ] 表書きを「御年賀」「寒中御見舞」に切替準備
- [ ] 年明けキャンペーン準備
