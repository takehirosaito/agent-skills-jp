# ギフトLP典型構成

季節キャンペーンLPと同じ構造だが、ギフト特有の項目を強調。

---

## ギフトLPの9セクション

```
[1] FV（ファーストビュー）
  ├─ イベント名＋配送締切（最重要）
  ├─ 主見出し
  ├─ メイン画像（季節感のあるパッケージ）
  ├─ ギフト対応マーク（のし・包装・カード）
  └─ CTA

[2] 贈る相手別おすすめ
  ├─ お母さん／お義母さん／祖母（母の日）
  ├─ お父さん／お義父さん／祖父（父の日）
  ├─ 上司／取引先／親族（お中元・お歳暮）
  └─ 60代・70代・80代別（敬老）

[3] 商品ラインアップ（価格帯別）
  ├─ 3,000円台／5,000円台／10,000円台
  └─ 商品グリッド

[4] ギフト対応詳細
  ├─ のし（用途別表書き早見表）
  ├─ ラッピング種類
  ├─ メッセージカード文例
  ├─ 配送日指定
  └─ 複数送り先指定

[5] 配送スケジュール
  ├─ 注文締切日
  ├─ 発送日
  ├─ 配送地域別到着日
  └─ 物流ピーク時の警告

[6] FAQ
  ├─ いつまでに注文？
  ├─ 送り先を複数指定できる？
  ├─ のしは無料？
  ├─ 賞味期限／アレルゲン
  └─ 不在時の対応

[7] 商品詳細（各SKU）
  ├─ 原材料・賞味期限・アレルゲン
  ├─ 内容量・包装サイズ
  └─ 注意事項

[8] CTA（最終）
  └─ 配送締切リマインダー付き

[9] 特商法表記
```

## FV必須要素（ギフトLP特化）

| 要素 | 例 |
|---|---|
| イベント名 | 「母の日特集」 |
| 配送締切 | 「5月8日までお届け」（最重要） |
| 主見出し | 「職人手作りスイーツで、ありがとうを贈る」 |
| ギフト対応 | のし・包装・カードのアイコン |
| 価格帯訴求 | 「3,000円台〜10,000円台」 |
| CTA | 「母の日に届ける」 |

## 贈る相手別おすすめのページ

### 母の日の例
```
[お母さん向け]
- ご年齢別おすすめ：60代／70代／80代
- 趣味別：花が好き／甘いもの好き／健康志向
- 価格帯：3,000円台／5,000円台／10,000円台

[お義母さん向け]
- フォーマル系の包装推奨
- 失礼にならない価格帯（5,000円〜）
- のし「御母の日」

[祖母向け]
- 食べやすい・軽い
- 文字が大きいメッセージカード
```

## ギフト対応詳細セクション

### のしの選択

```
[内のし]：包装紙の内側にのし。控えめ・郵送向き。
[外のし]：包装紙の上にのし。手渡し・主張する。

表書き（用途別）：
- 御母の日（一般）
- 感謝（やわらかい）
- ありがとう（カジュアル）
- 御祝（広く使える）
```

### ラッピング

- スタンダードラッピング（無料）
- 季節限定包装（母の日カーネーション柄／父の日青系）
- 高級ラッピング（有料：別途○○円）

### メッセージカード

文例：
- 「いつもありがとう。少しでも喜んでもらえたら嬉しいです。」
- 「お母さんへ。今日はゆっくりしてね。」
- カスタム文字入れ（最大○○字）

## 配送スケジュールセクション

### 表示すべき情報

```
[注文締切] 5月8日（金）23:59まで
[発送] 5月9日（土）〜5月10日（日）
[配送地域別到着]
- 関東：5月10日（日）
- 関西：5月10日（日）
- 北海道・沖縄・離島：5月11日（月）

[物流ピーク警告]
GW明けで物流が混雑しております。お早めのご注文をお勧めします。
```

## 商品詳細（各SKU）に必要な項目

### 食品ギフト
- 商品名
- 内容量
- 原材料
- **特定原材料8品目アレルゲン**（必須）
- 賞味期限
- 保存方法
- 製造者
- 配送方法（常温／冷蔵／冷凍）

### 雑貨・コスメギフト
- 商品名
- サイズ
- 素材
- 注意事項
- 包装サイズ・重量

## イベント終了後の運用切替

### 母の日終了後の例（5月11日以降）

#### 変更内容
1. **広告停止**：Meta／Google／Yahoo!／LINE全停止
2. **LP切替**：通常版（季節色を消す）
3. **商品名から削除**：
   - 「【母の日特集】職人手作りバスクチーズケーキ」
   - → 「職人手作りバスクチーズケーキ」
4. **バナー差し替え**
5. **メルマガ配信内容変更**

### 通常運用時の代替コピー

母の日コピー：「母の日に届く、職人手作りスイーツ」
通常コピー：「職人手作りバスクチーズケーキ／メッセージカード対応」
（メッセージカードは誕生日・お祝い事に通年使える）
