# CTR向上のための画角・構図パターン

メイン画像規定を満たしつつ、検索結果サムネイルで「クリックされやすい」画像を作るための実務テクニック。

## CTRに効く要素

### 1. 占有率は85%以上で「ほぼいっぱい」に
- 規定は85%以上だが、実務では90〜95%が最も視認性が高い
- 商品が小さく見える＝検索結果でスクロールされてしまう
- ただし上下左右の余白5%は確保（縁ギリギリで切れているのは違和感）

### 2. 商品の「最も特徴的なアングル」を選ぶ
- 正面：パッケージ・正面に情報がある商品（食品・コスメ・書籍）
- 斜め45度：立体感を見せたい商品（家電・家具・バッグ）
- 真上（オーバーヘッド）：平面商品（食器・小物雑貨）
- 側面：高さの違いを見せたい商品（背の高い家具・テント）

### 3. ライティングで質感を出す
- マット商品：ソフトボックスで柔らかく
- 光沢商品：トップライト＋反射板で輪郭を浮かせる
- 透明商品：背景に薄いグラデーション（規定範囲内で）or 商品の輪郭をライティングで強調

### 4. カラーで目立たせる
- 商品自体のカラーを強調できる構図
- 多色展開なら最もブランドカラーらしい色をメインに
- 競合商品との「色被り」を避ける

### 5. パッケージの場合は「ブランドロゴが正面に来る向き」
- 正面 = ロゴが読める向き
- ロゴが小さい場合は斜めにせずまっすぐ

## カテゴリ別の構図パターン

### 家電（白物家電）
- アングル：斜め45度、上から見下ろし気味
- 理由：立体感を出しつつ、操作パネルや特徴部分が見える
- 例：掃除機なら本体＋ヘッドの両方が見える角度

### 家電（小型家電）
- アングル：正面 or 斜め30度
- ハンディタイプ：縦に立てた状態で正面

### コスメ・スキンケア
- アングル：正面
- 背の高い容器（化粧水）：縦長配置
- 平たい容器（クリーム瓶）：斜め30度 or 正面

### 食品（パッケージ商品）
- アングル：パッケージ正面
- 文字が読める向き
- 賞味期限ラベル・JANは隠さなくてOK

### 食品（生鮮・未包装）
- アングル：オーバーヘッド or 斜め45度
- 商品を皿などに置かず、純白背景に直接

### アパレル
- 着用カット：正面 or 斜め30度のモデルカット
- 平置きカット：オーバーヘッド
- 着用＞平置きの方がCTR高い傾向

### バッグ・小物
- アングル：斜め30〜45度（立体感）
- 手提げの場合は持ち手が上に来る向き

### 靴
- アングル：斜め45度（甲・側面・かかとが見える）
- 1足のみ（ペアで横並びはOKだが情報量過多になることも）

### ベビーカー・大型品
- アングル：斜め45度
- 全体が見える距離
- 折り畳み式の場合は「展開状態」を主役に

### 書籍・DVD
- 表紙の正面のみ

### 文具（ノート・ペン）
- ノート：表紙正面
- ペン：横置きまたは斜め45度

## 「白背景の限界を超える」テクニック

### 1. 軽い接地影で立体感
- 規定で許容される自然な接地影
- 商品の足元20%以下の範囲で薄い影
- 「ふわっと浮いて見える」を避ける

### 2. ライティングのコントラスト
- トップから強め、サイドから補助
- 商品の凹凸が浮かび上がる
- 完全フラットなライティングは平面的に見えてCTR低下

### 3. カラーの彩度を最大化
- 商品本来の色を再現するが、彩度を10〜20%上げると目立つ
- ただし「実物と違う」レベルの加工は返品リスク

### 4. パッケージ要素の活かし方
- パッケージ印字はOKなので、ブランドロゴ・主要キーワードが見える向きに
- パッケージ自体のデザインで他社と差別化できる

## 検索結果サムネで負けないチェック

### Step 1：検索結果での見え方確認
- 該当キーワードで Amazon 検索
- 自社商品が競合と並んだ時の「目立ち度」を見る
- 隣の商品より明らかに「小さい」「暗い」「埋もれている」なら改善

### Step 2：A/Bテストの活用
- メイン画像を変更した前後で CVR・CTR を比較
- Amazon「商品ページの管理」でも画像変更履歴が見れる
- 大幅な差が出る場合あり

### Step 3：競合の傾向分析
- 同カテゴリ上位10商品のメイン画像を観察
- 共通する構図・角度・トリミング
- 自社商品が同じ枠で見える方が良い場合と、差別化する方が良い場合がある

## やりすぎ厳禁の落とし穴

### 規定違反になりやすい「やりすぎ」
- 商品占有率を95%超えにして縁ギリギリ → 切れて見える
- 過度な彩度上げ → 「実物と違う」クレーム
- 影を商品の輪郭強調手段にしすぎる → 規定違反疑い
- 背景に薄いグラデーション → 「純白」違反疑い

### 慎重に判断する要素
- パッケージに英語コピーが多すぎる商品 → 日本語訴求は商品ページ本文で
- 受賞バッジ・賞のロゴ → メイン画像内に焼き込み不可、パッケージ印字ならOK
- 「No.1」「業界一位」表記 → メイン画像不可、商品ページ本文も根拠5項目必須

## メイン画像の運用サイクル

1. 初期撮影 → 公開
2. 1ヶ月後：CVR・CTRをアクセス解析で確認
3. 3ヶ月後：競合商品のメイン画像変化を観察
4. 6ヶ月後：商品改良・パッケージリニューアル時に再撮影
5. 1年後：シーズン在庫・新色追加時にバッチで撮影更新

メイン画像は固定資産ではなく、運用しながら最適化する要素。
