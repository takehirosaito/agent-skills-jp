# メイン画像 必須規定（公式仕様）

Amazon.co.jp のメイン画像（1番目の画像）に課される公式ルール。違反すると検索ランキング低下・最悪サスペンドのリスク。

## 必須規定一覧

### 1. 背景：純白 RGB(255,255,255)

- 色値は厳密に「255, 255, 255」
- 「ほぼ白」「アイボリー」「クリーム」「グレーがかった白」はすべて違反
- 背景に部屋・テーブル・布・ペーパーが映り込むのもNG
- 透明商品の場合は背景を白にしつつライティングで輪郭を出す

### 2. 商品占有率：85%以上

- 画像枠の面積に対し、商品が占める面積が85%以上
- 上下左右の余白を最小限に
- 1:1 正方形画像が標準（カテゴリにより縦長許容あり）
- 余白多すぎ＝検索結果サムネで商品が小さく見え、CTR低下

### 3. 解像度：長辺1000px以上

- Amazon の「ZOOM機能」（ホバー時拡大）の対象になる
- 推奨：長辺2000〜3000px（Retina対応）
- これ未満ではZOOMにならず、購入意欲低下

### 4. カラープロファイル：sRGB

- CMYK は禁止（印刷物データの直接使用NG）
- グレースケール画像も sRGB プロファイル付きで書き出す
- Photoshop の「Webおよびデバイス用に保存」または「画像を書き出し」でsRGBに変換

### 5. ファイル形式

- 推奨：JPG（写真）、PNG（透過必要な場合）
- 許容：TIFF、GIF
- 不可：BMP、SVG、PDF
- ファイルサイズ：10MB以下

### 6. 商品：主商品のみ

- 売られている主商品のみが映る
- 付属品（取説・ケーブル・予備パーツ）は不可
- 「セット商品」なら全構成品をセットでレイアウト

### 7. テキスト・ロゴ・ウォーターマーク

- 画像内テキストは不可（パッケージに印字されているロゴ・テキストはOK）
- 「セール中」「限定」「新発売」のような販促文字は不可
- 透かし（©, ®, 著作権表記）も画像背景に焼き込み不可
- 「100% Natural」「Best Quality」のような英語コピーも不可

### 8. 枠線・装飾要素

- 枠（フレーム）不可
- 角丸処理不可
- 背景にグラデーション・パターン不可
- バッジ（受賞マーク・★マーク）の貼り付け不可

### 9. モデル・マネキン

- **アパレル**：モデル可（着用カット）、マネキン可
- **その他**：モデル・マネキン・手・指の写り込みは原則NG
- 「商品の使い方を見せる」シーンはサブ画像で

### 10. 影

- 自然な接地影（商品の足元の影）はOK
- 過度なドロップシャドウ・反射・グラデーション影はNG
- 「商品が空中に浮いて見える」レベルの影はNG

## カテゴリ共通の追加注意

### サイズ感の表現
- メイン画像で「サイズ感」を見せたい場合でも、手や物との比較はNG
- サイズ感はサブ画像で（定規・手・小物との比較）

### カラーバリエーション
- 全色を1枚に並べるのはNG（バリエーション機能で個別子ASINとして扱う）
- 親ASIN のメイン画像 = 代表色のメイン画像

### 動きのある商品
- 動画は別途販売ページに登録（メイン画像は静止画のみ）
- メイン画像で動きを表現する場合は連続写真ではなく1枚に絞る

## 「規定すれすれ」と「明らかに違反」の見分け

| 状況 | 判定 |
|---|---|
| 背景がアイボリー（240, 240, 235） | 違反（純白ではない） |
| 商品占有率82% | 違反（85%未満） |
| 解像度980px | 違反（1000px未満） |
| 影が自然な接地影 | OK |
| 影が画像の20%占有 | 違反 |
| パッケージにロゴ印字 | OK（パッケージ要素） |
| パッケージ周囲にテキスト合成 | 違反 |
| 透明ボトルで背景が完全に白なので商品が見えにくい | OK（ただしライティングで輪郭強調推奨） |

## 「規定違反だが Amazon が検出していない」状態

- 規定違反の画像でも一時的に表示はされる
- ただし以下のリスク：
  - 検索ランキングのアルゴリズムで低評価
  - Amazon の画像審査AI が後日検出 → 突然リジェクト
  - 競合・第三者から通報 → リジェクト
- 「今リジェクトされていない＝OK」ではない。規定遵守が正
