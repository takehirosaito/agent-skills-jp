# 撮影／レタッチブリーフの作り方

メイン画像の撮影・レタッチをカメラマン or レタッチャーに依頼する際のブリーフ作成手順。

## 撮影ブリーフ（新規撮影）

### 1. 基本情報

| 項目 | 内容 |
|---|---|
| 商品名 | （商品名・ASIN） |
| カテゴリ | （Amazon カテゴリ） |
| 数量 | （メイン1点／サブ8点） |
| 納品形式 | JPG／PNG、sRGB、長辺3000px以上 |
| 納品形式の比率 | 1:1 正方形 |
| 納品期限 | （日付） |

### 2. 撮影環境

| 項目 | 内容 |
|---|---|
| 背景 | 白ホリゾント or 白ペーパー or 白アクリル |
| ライティング | トップライト＋サイドライト、影は自然な接地影のみ |
| カメラ | フルサイズ／APS-C 一眼レフ／ミラーレス |
| レンズ | 50〜85mm 単焦点（歪み少なく自然な遠近感） |
| 三脚 | 必須（ブレなし） |
| 絞り | F8〜F11（被写界深度を確保） |
| ISO | 100〜200（ノイズ最小） |
| シャッタースピード | 1/125〜1/200（手ブレ防止） |

### 3. 構図

| 項目 | 内容 |
|---|---|
| 商品配置 | 画像センター |
| 商品占有率 | 85%以上（90%目安） |
| 角度 | 正面 or 斜め45度（カテゴリ別） |
| 上下左右余白 | 5〜10%以内 |
| 商品の向き | 左右非対称商品は「正面が読める向き」 |

### 4. 必須要件

- [ ] 背景は純白RGB(255,255,255)
- [ ] 商品占有率85%以上
- [ ] 長辺3000px以上
- [ ] sRGBプロファイル
- [ ] テキスト・ロゴ・枠なし
- [ ] アパレル以外はモデル・手なし
- [ ] 影は接地部分のみ

### 5. NG要素

- [ ] 背景にテーブル・布・壁などの要素
- [ ] 小道具（コップ・皿・植物・人物）
- [ ] テキスト・ロゴ・ウォーターマーク
- [ ] 過度なドロップシャドウ
- [ ] 商品占有率85%未満
- [ ] 解像度1000px未満

### 6. 参考画像

ブリーフに「参考にしてほしいメイン画像のURL」を1〜3点添える：

- 同カテゴリの売れ筋ASINのメイン画像
- 自社の他商品の良いメイン画像
- 撮影スタジオの過去事例

## レタッチブリーフ（既存写真の修正）

### 既存写真で対応可能な修正

| 修正項目 | レタッチで対応可 |
|---|---|
| 背景を純白に置換 | ◎ |
| 商品占有率を85%以上にトリミング | ◎ |
| 解像度をアップサンプル | △（元解像度が低すぎると限界） |
| sRGBプロファイルに変換 | ◎ |
| 不要なテキスト・ロゴ削除 | ◎ |
| 小道具削除 | ◎ |
| 手・指の削除 | △（重なり具合による） |
| 影の調整 | ◎ |

### レタッチで対応不可（再撮影必須）

| 問題 | 理由 |
|---|---|
| モデル・マネキンの除去（アパレル以外） | 商品との重なりが大きく不自然 |
| 商品の角度が不適切 | 角度補正は不自然になる |
| 商品が小さすぎる（占有率20%以下） | アップサンプルで品質劣化 |
| 暗すぎる／白飛び | 復元限界 |

### レタッチブリーフ項目

| 項目 | 内容 |
|---|---|
| 元写真 | （ファイル名・URL） |
| 修正内容 | 背景置換／占有率調整／要素削除／解像度アップ |
| 出力サイズ | 長辺3000px |
| 出力形式 | JPG（品質90） |
| カラープロファイル | sRGB |
| 納品期限 | （日付） |

### レタッチ前後のチェックリスト

- [ ] 背景が完全に純白RGB(255,255,255)になっているか
- [ ] 商品のエッジが滑らか（切り抜きのアラ）
- [ ] 商品占有率85%以上
- [ ] 解像度長辺2000px以上（理想3000px以上）
- [ ] sRGBプロファイル
- [ ] 修正前と修正後を並べて確認

## 撮影スタジオへの依頼ポイント

### 1. 規定への理解確認
- Amazon メイン画像規定の3大ルール（純白／85%／1000px）を撮影前に共有
- スタジオによっては「楽天向け」「自社サイト向け」の感覚で撮影することがあるため明示

### 2. テストカット
- 本撮影前に1〜2カットをテスト撮影してメインへ
- 規定準拠を確認してから残りを撮影

### 3. 納品時の確認
- 仕様通り（解像度・形式・プロファイル）
- 規定違反項目の有無
- 1点ごとに目視チェック

## 内製での撮影手順（簡易）

外注せず社内で撮影する場合の最低限：

1. 白いペーパー（A2サイズ以上）または白ホリゾント
2. スマホ or カメラ（高解像度設定）
3. 自然光 or LEDライト2灯（トップ＋サイド）
4. 商品をペーパー中央に配置、ペーパーは床と壁を緩やかにカーブで繋ぐ
5. 真正面 or 斜め45度から撮影、商品が画面の80%以上を占める距離
6. 撮影後、Photoshop or GIMP or 無料アプリで：
   - 背景を完全に純白にレタッチ
   - 1:1正方形にトリミング（商品占有率85%以上）
   - 長辺3000pxで書き出し
   - sRGBプロファイル付き

## 撮影時の優先順位

メインだけでなくサブ画像も同時撮影する。撮影点数の優先：

1. メイン画像（純白背景・本体単体・正面）
2. サブ画像1：商品の特徴的アングル（背面・横）
3. サブ画像2：素材・質感のマクロ
4. サブ画像3：使用シーン
5. サブ画像4：サイズ感（手・身体・小物との比較）
6. サブ画像5：付属品セット
7. サブ画像6：インフォグラフィック（スペック・特徴）
8. サブ画像7：パッケージ
9. サブ画像8：別カラー or 別バリエーション
