# Amazon メイン画像・サブ画像 規定チェッカー

## 概要

Amazon.co.jp の商品ページに登録する画像（メイン1枚＋サブ8枚程度）を、Amazon公式規定とCTR最適化の両軸でチェックし、差し替え指示書／撮影ブリーフを作るスキル。

メイン画像は **検索結果のサムネとして最大の CTR 影響要素**。規定違反は即サスペンドではなくとも、検索ランキング低下・突然のリジェクト・Brand Registry 通報の対象になり得る。本スキルは「規定遵守」と「CTR最適化」を分離してチェックする。

## ★最重要原則：「純白・占有85%・1000px超・sRGB・テキストなし」は必須、サブ画像で機能配分

メイン画像の公式必須規定は5つ：**①純白RGB(255,255,255) ②商品占有率85%以上 ③長辺1000px以上 ④sRGB ⑤テキスト・ロゴ・枠・小道具なし**。これは交渉余地なし。違反していたら必ず差し替える。

CTR を稼ぐのは **サブ画像7枚の役割配分**（サイズ感／使用シーン／パッケージ／成分・スペック／FAQ／比較／保証）。サブで「買うかどうかの最終判断」をさせる構造を作る。

ジャンル不明時はハイブリッド対応：仮ジャンルで暫定診断、冒頭で「カテゴリ別のモデル可否・パッケージ要件は要確認」を明示。

### メイン画像必須規定の早見

| # | 項目 | 規定 |
|---|---|---|
| 1 | 背景 | 純白 RGB(255,255,255)、アイボリーやクリームは違反 |
| 2 | 商品占有率 | 85%以上 |
| 3 | 解像度 | 長辺1000px以上（推奨2000〜3000px、ZOOM対象は1000px超） |
| 4 | カラープロファイル | sRGB（CMYK禁止） |
| 5 | ファイル形式 | JPG／PNG／TIFF／GIF（BMP・SVG・PDF不可）、10MB以下 |
| 6 | 商品 | 主商品のみ（付属品・取説NG。セット商品はセットでレイアウト）|
| 7 | テキスト・ロゴ | パッケージ印字はOK、画像内に合成はNG（販促文字も不可）|
| 8 | 枠線・装飾 | フレーム・角丸・グラデ背景・バッジ不可 |
| 9 | モデル・マネキン | アパレルは可、その他は手・指・モデル不可 |
| 10 | 影 | 自然な接地影OK、過度なドロップシャドウ・反射不可 |

## 処理フロー

### Step 1：入力情報の確認

- 対象ASIN
- ジャンル（家電／コスメ／食品／アパレル／日用品／ベビー／ペット）
- 現状の画像（URLまたは画像ファイル）
- 撮影素材の有無
- Brand Registry 登録状態

ジャンル不明時は仮設定して暫定診断、冒頭で確認必要を明示。

### Step 2：メイン画像 必須規定チェック（10項目）

`references/main-image-rules.md` の10項目で照合：

- 背景 純白RGB(255,255,255)：違反例「アイボリー(240,240,235)」
- 占有率：「85%未満」は違反
- 解像度：「1000px未満」は違反
- sRGB：CMYK だとプロファイル違反
- ファイル形式：BMP・SVG・PDFは不可
- 主商品のみ：付属品の同時写りはNG（セット商品は除く）
- テキスト・ロゴ：パッケージ印字は可、画像内合成は不可
- 枠・装飾：すべて不可
- モデル・マネキン：アパレル可、それ以外は原則NG（手の写り込みも）
- 影：接地影のみ、ドロップシャドウ・反射NG

### Step 3：カテゴリ別追加チェック

`references/category-specifics.md`：
- 食品：パッケージ正面・賞味期限の写りは避ける
- 化粧品：「医薬品的」「効能訴求」の合成テキスト不可
- 家電：本体のみ、リモコンは別画像
- アパレル：モデルカット可、サイズ感は別画像
- ベビー・ペット：危険使用シーンの警告ラベル

### Step 4：サブ画像の機能配分チェック

`references/ctr-optimization.md` の標準7枚配分：

| # | 役割 | 内容 |
|---|---|---|
| 1 | メイン（純白背景） | 検索結果サムネ |
| 2 | サイズ感 | 定規・手・物との比較 |
| 3 | 使用シーン | 屋内・屋外・使用者と |
| 4 | パッケージ／同梱物 | 開封状態 |
| 5 | 成分・スペック・規格 | 文字情報を整理してOK |
| 6 | FAQ／不安解消 | よくある質問を視覚化 |
| 7 | 競合比較／自社シリーズ比較 | 選び分け表 |
| 8 | 保証・サポート | 安心要素 |

サブ画像は規定が緩い（テキスト・図版OK、占有率も柔軟）ため、ここで情報量を担保する。

### Step 5：撮影ブリーフ／レタッチ指示書の作成

差し替えが必要な場合、撮影ブリーフを作る。`references/photography-brief.md` を参照：

- 商品名・ASIN
- 数量（メイン1点／サブ8点）
- 納品形式：JPG／PNG、sRGB、長辺3000px以上、1:1正方形
- 撮影環境：白ホリ／白ペーパー、トップ＋サイドライト、F8〜F11、ISO 100〜200
- 構図：センター、占有率90%目安、上下左右余白5〜10%
- 必須要件チェックリスト

### Step 6：差し替え後の検証

- セラーセントラルの「商品画像」ヘルプ／A+コンテンツマネージャーのプレビュー
- 反映後の検索結果サムネで違和感がないか
- ZOOM 機能が動作するか（1000px超）

## 代表例（コードレス掃除機・現状のメイン画像が違反）

入力：
- 現状メイン画像：背景が薄いグレー、商品占有率約70%、解像度800px、画像内に「★Amazon限定★」のオーバーレイ

### 規定チェック結果

| # | 項目 | 判定 | 違反内容 |
|---|---|---|---|
| 1 | 背景 純白 | NG | グレーがかった白（実値 240,240,240程度） |
| 2 | 占有率85% | NG | 約70% |
| 3 | 解像度1000px | NG | 800px |
| 4 | sRGB | 要確認 | プロファイル未確認 |
| 5 | ファイル形式 | OK | JPG |
| 6 | 主商品のみ | OK | 本体のみ |
| 7 | テキスト・ロゴなし | NG | 「★Amazon限定★」合成テキスト |
| 8 | 枠・装飾なし | OK | - |
| 9 | モデル不可 | OK | - |
| 10 | 影 自然のみ | OK | - |

→ 4項目違反。即差し替え必須。Brand Registry 登録なら自前で差し替え、未登録なら `amazon-catalog-conflict-ticket-builder` で修正依頼。

## 品質ゲート

- メイン画像10項目の規定すべて充足
- カテゴリ別追加ルールに準拠
- サブ画像が機能別に配分されている（最低5役割）
- サブ画像にも「画像内テキストは判読可能・占有率の妥当性」が確認されている
- 撮影ブリーフを作る場合、納品形式（JPG／sRGB／長辺3000px）・撮影環境・必須要件チェックリストが揃っている
- Brand Registry 未登録の場合は `amazon-catalog-conflict-ticket-builder` への引き継ぎ案内

## エッジケース

- **透明商品（瓶・容器）**：背景純白でも商品輪郭が消える → ライティングで輪郭強調、必要なら微かな影で立体感
- **カラーバリエーション商品**：メインは代表色のみ。全色を1枚に並べるのはNG（バリエーション機能で個別子ASIN扱い）
- **動きのある商品**：メインは静止画のみ。動画は別途販売ページに登録
- **セット商品**：全構成品をセットでレイアウト（個別の付属品単体写りはNG）
- **アパレル**：モデル着用カット可。サイズ感は別画像
- **食品**：パッケージ正面が原則。賞味期限の表示が映る場合はトリミング
- **規定すれすれ（背景が薄グレー）**：「今リジェクトされていないからOK」ではない。アルゴリズム評価で低下、後日突然リジェクトのリスク

## 注意事項

- 画像規定は更新の可能性あり。最新は Amazon セラーセントラル「商品画像の要件」ヘルプを確認
- 画像のZOOM対象判定は仕様変更がある。長辺2000〜3000pxを目安にしておくと安全
- Brand Registry 未登録ASINでは画像差し替え権限が他出品者と競合する場合あり
- 効能訴求の画像内テキストは薬機法の規制対象。`yakki-keihyo-expression-check` でクロスチェック
