# 商品グループ（メイングループ・サブグループ）の設計

futureshop の商品グループ構造は、商品ページのSEO・パンくず・サイトマップ・回遊導線のすべてに影響する。設計を慎重に行うべきポイントを整理。

## 商品グループの2階層モデル

futureshop では概念的に次の2つに分かれる：

- **メイングループ**：商品の主分類。商品マスタ上で1商品につき1つ
- **サブグループ**：複数所属可能。回遊・絞込み用

実装上は両方とも「商品グループ」として管理画面に並ぶ。設計者が「これはメイン」「これはサブ」と意図的に役割を分ける。

## グループツリーの組み立て方

### 原則：階層は3〜5まで

```
[トップ]
  └ レディース服      ← レベル1（大カテゴリ）
      └ アウター       ← レベル2（中カテゴリ・メイングループになることが多い）
          └ ジャケット ← レベル3（小カテゴリ・最も具体的）
              └ [個別商品]
```

5階層を超えると Google のクロール効率が下がり、回遊もしにくくなる。

### メイングループはレベル2〜3が標準

商品の主分類は、ユーザーが**カテゴリ階層を辿って商品にたどり着く際の最後の分岐点**にする。

例：
- レベル1「レディース服」だけだと商品が混在しすぎる
- レベル3「ジャケット」までで個別商品が並ぶのが見通しがよい

## サブグループの典型パターン

| パターン | 例 | 使いどころ |
|---|---|---|
| 用途別 | ギフト／自分用／オフィス／カジュアル | クロスセル・ギフト需要 |
| ターゲット別 | メンズ／レディース／キッズ／30代 | 顧客像別の絞込み |
| 季節別 | 春夏／秋冬／クリスマス／母の日 | 季節需要・回遊 |
| 価格帯 | 〜3,000円／3,000-5,000円／5,000円以上 | 予算別の絞込み |
| 機能別 | 防水／撥水／速乾／オーガニック | 機能訴求 |
| 特集 | 新商品／人気／再入荷／店長セレクト | 露出補強 |

## メイングループ設計の手順

### Step 1：商品ラインナップを棚卸し

- 全商品をリストアップ
- 商品名・素材・用途で似たものをグルーピング

### Step 2：顧客の検索動線を想像

- 「カテゴリから探す」場合の自然な階層
- 「○○がほしい」と検索する時に使う語

### Step 3：候補階層を作る

- レベル1（大カテゴリ）：5〜10個
- レベル2（中カテゴリ）：各レベル1配下に2〜10個
- レベル3（小カテゴリ＝メイングループ）：各レベル2配下に2〜10個

### Step 4：各カテゴリの商品件数を確認

- カテゴリあたり最低5商品以上が望ましい（薄ページ判定回避）
- 5商品未満のカテゴリは統合 or 特集ページ化

### Step 5：パンくずと商品マスタCSV のメイングループ列を確定

## サブグループ設計の手順

### Step 1：メイングループ確定後に、回遊軸を設定

- 用途別／ターゲット別／季節別／価格帯別／機能別／特集

### Step 2：各サブグループに対応する商品を抽出

- 各サブグループに最低5商品以上

### Step 3：商品マスタCSV のサブグループ列に複数IDをセット

例：「リネンノーカラージャケット」のサブグループ
- 用途：オフィス、カジュアル
- ターゲット：レディース、30代、40代
- 季節：オールシーズン
- 特集：新商品

## カテゴリページ（商品グループページ）のSEO

商品グループページにも独自のSEO設定が必要。

| 要素 | 内容 |
|---|---|
| グループ名 | カテゴリ名そのもの |
| SEOタイトル | 「[カテゴリ名] 通販｜[ブランド名]」 |
| SEOディスクリプション | カテゴリ全体の品揃え・特徴・差別化 |
| カテゴリ説明文（上部） | 100〜200字、選び方の軸 |
| カテゴリ説明文（下部） | 400〜800字、検索意図網羅 |
| h1 | カテゴリ名 |
| h2/h3 | 選び方の軸・用途別 |

商品ページとカテゴリページが **相互に内部リンクで結ばれる** 構造を作る。

## 重複・カニバリ回避

- メイングループとサブグループの粒度が近いと「同じ内容のページ」が二重にできる
- 「ジャケット」（メイングループ）と「ジャケット特集」（サブグループ）の中身が同じ → どちらかをcanonicalで束ねる、もしくは中身を差別化
- noindex／canonicalタグの活用はコマースクリエイター（CC）テンプレで設定する

## グループ構造変更時の注意

- メイングループ変更 = URL／パンくず／内部リンクのすべてに影響
- 変更前後で差分確認・サイトマップ再生成
- 古いURLからのリダイレクト（301）を設定
- Search Console の URL 再クロール申請
- 変更後数週間〜数ヶ月で検索順位が変動する前提で計画
