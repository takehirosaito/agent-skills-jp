# futureshop 商品マスタCSV のSEO関連列

futureshop の商品マスタCSV で SEO に直接関連する列を整理する。

仕様は変更されるため、最終的には **futureshop 管理画面のCSV ガイド・公式ヘルプ** で列名・上限の最新値を確認すること。

## 主要列の整理

| 列の役割 | 一般的な列名 | 内容 |
|---|---|---|
| 商品識別 | 商品コード（goods_id 相当） | 商品の主キー |
| 表示用 | 商品名（短） | カート・商品リスト・カート完了画面の表示 |
| 詳細表示用 | 商品名（ロング）／商品ページタイトル | 商品ページの h1 相当 |
| カテゴリ主 | メイングループ／メイングループID | 商品の主分類。パンくず階層に使われる |
| カテゴリ副 | サブグループ／サブグループID（複数指定可） | 複数所属。回遊・絞込み用 |
| 価格 | 販売価格／会員価格 | |
| 在庫 | 在庫数 | |
| 商品画像 | 画像URL（複数枚） | |
| 商品説明 | 商品説明本文（HTML可） | 商品ページ本文 |
| SEOタイトル | SEOタイトル／title | title タグに反映 |
| SEOディスクリプション | SEOディスクリプション／meta description | meta description に反映 |
| meta keywords | meta keywords | 現代SEOではほぼ意味なし、空欄でも可 |
| 構造化データ系 | JANコード／メーカー型番 | 構造化データ・Google Merchant Center 連携で使用 |

注：上記は「futureshop の一般的な商品マスタCSV」の整理であり、契約プラン・コマースクリエイター対応状況によって列名や有無が異なる。

## 文字数の目安

| 列 | 推奨文字数 | 補足 |
|---|---|---|
| 商品名（短） | 30〜40字 | カート画面で行送りされない長さ |
| 商品名（ロング） | 40〜60字 | h1 相当、訴求軸を1つ含める |
| SEOタイトル | 28〜32字 | Google 検索結果のタイトル |
| SEOディスクリプション | 80〜120字 | スニペット |
| meta keywords | 空欄でも可 | SEO効果は実質ない |

CSV側の文字数上限は仕様変動するため、CSV ガイドを確認すること。

## SEOタイトル・SEOディスクリプションの書き方

### SEOタイトル

構造：**[商品の主キーワード] + [差別化軸] + [ブランド名]**

OK例：
- 「高保湿フェイスクリーム30g｜乾燥肌向け｜[ブランド名]」（30字）
- 「リネン100%ノーカラージャケット／オールシーズン｜[ブランド名]」（31字）
- 「信州フロマージュ4種食べ比べセット 化粧箱入り｜[ブランド名]」（28字）

NG例：
- 「商品ページ｜通販ショップ」（11字、抽象的）
- 「[ブランド名] | [ブランド名] | おすすめ | 通販 | 公式 | 最安」（キーワード詰込み・最安は景表法リスク）
- 「フェイスクリーム」（短すぎ・差別化なし）

### SEOディスクリプション

構造：**商品の要約 + 差別化 + CTA色の語尾**

OK例（98字）：
- 「乾燥が気になる肌をうるおいで満たすフェイスクリーム30g。なじみのよいテクスチャで朝晩のお手入れの最後に。送料無料／レビュー多数。」

NG例：
- 全商品で同じテンプレ文（重複コンテンツ）
- 「お客様の声を大切に、誠実に運営しております」（個別商品の情報がない）
- 「シミが消える」「アンチエイジング」など薬機法違反

## メイングループID の選び方

メイングループは商品の主分類で、原則1つ。**パンくずの中階層に使われる**ことが多い。

### 設計原則

- 顧客が商品を探すときの最も自然な分類
- 「商品種別 > 商品種別の細分化 > 商品」の階層が3〜5階層を超えない
- 階層が深すぎると Google のクロール効率が下がる

### 例：化粧品の分類

```
スキンケア（メイン階層1）
  └ フェイスクリーム（メイン階層2 = メイングループ）
      └ [個別商品]
```

```
スキンケア
  └ 化粧水
      └ [個別商品]
```

### 例：食品の分類

```
ギフト
  └ チーズ
      └ [個別商品]
```

```
カテゴリ別
  └ チーズ
      └ 食べ比べセット
          └ [個別商品]
```

## サブグループ の設計

サブグループは複数所属可能。**回遊軸**として設定する。

### 設計の軸

| 軸 | 例 |
|---|---|
| 用途別 | 「ギフト用」「自分用」「贈答」 |
| ターゲット別 | 「メンズ」「レディース」「キッズ」「30代」 |
| 季節別 | 「春夏」「秋冬」「クリスマス」「母の日」 |
| 価格帯別 | 「3,000円以下」「5,000-10,000円」 |
| 特集系 | 「人気」「新商品」「再入荷」「店長おすすめ」 |

注：「人気」「ランキング」は **景表法上の根拠** が必要。実績ベース（販売実績○件・○期間）で運用する。

## CSV更新時の注意

- **メイングループID を変更すると、パンくず・URL構造・内部リンクに影響する**。SEO上の評価が一旦リセットされるリスクがある。変更前にバックアップ＋差分確認
- **SEOタイトル・SEOディスクリプションを一括更新するスクリプトを使う場合**、商品固有の情報が消えないようテンプレ化に注意
- **古い商品・販売終了商品のSEO設定** をどう扱うかを事前に決める（noindex／削除／リダイレクト）

## 文字コード・改行コード

CSV の文字コード・改行コードは futureshop の指定仕様に従う。Shift_JIS（CP932）+ CR+LF など、最新は管理画面のCSVガイドで確認。
