# コマースクリエイター（CC）のSEO設定箇所

コマースクリエイター（CC）は futureshop の新テンプレートシステム。SEO関連の設定がどこにあるかを整理する。

仕様は変更されるため、最終的には **futureshop コマースクリエイター公式ヘルプ・管理画面** で最新を確認すること。

## SEO設定の階層

CC の SEO 設定は概ね次の階層で分散している。

```
[1] ストア全体の設定
  ├ サイト共通のタイトル接尾辞（例：「| ブランド名」）
  ├ サイト共通のメタディスクリプション
  ├ robots.txt
  └ サイトマップXML

[2] テンプレート種別ごとの設定
  ├ トップページテンプレート
  ├ 商品ページテンプレート
  ├ 商品グループページテンプレート
  ├ カートページテンプレート
  └ その他コンテンツページ

[3] 個別ページの設定
  ├ 商品ページ：商品マスタCSV のSEO列が反映
  ├ 商品グループページ：管理画面の各商品グループ設定
  └ コンテンツページ：CC のページ作成画面で個別設定
```

## 商品ページのSEO設定

### 商品マスタCSV 経由

- SEOタイトル列・SEOディスクリプション列の値が `<title>` `<meta name="description">` に反映
- 各商品ページごとに固有の値が入る

### CC テンプレート経由

- 商品マスタにSEOタイトルが空欄の場合のフォールバック（テンプレ既定値）を CC テンプレで設定
- 構造化データ（Product schema）の出力もテンプレで制御
- パンくずの出力もテンプレで制御

### 設定優先順位（一般則）

1. 商品マスタCSV のSEOタイトル列に値あり → これが採用
2. 空欄 → テンプレートの既定値が採用
3. テンプレも未設定 → 商品名がそのまま title

## 商品グループ（カテゴリ）ページのSEO設定

### 管理画面の商品グループ設定

- 商品グループ名
- 表示順
- SEOタイトル
- SEOディスクリプション
- カテゴリ説明文（上部・下部）
- カテゴリページのカスタム画像

### CC テンプレート経由

- グループページの h1/h2 構造
- 関連グループへのリンク表示
- 絞込みフィルタの表示有無

## トップページのSEO設定

- ストア全体のメタディスクリプション（管理画面の「ストア基本設定」など）
- h1 はロゴ画像のalt or 明示的なh1テキスト
- 構造化データ（Organization, Website schema）

## サイトマップXML

- futureshop が自動生成するサイトマップが基本
- 生成範囲・更新頻度の設定がある場合は確認
- Search Console に登録

## robots.txt

- 通常は futureshop デフォルトのもの
- カスタマイズが必要な場合は管理画面 or CC テンプレで設定

## 構造化データ

商品ページに付ける Product schema（JSON-LD）の代表項目：

| プロパティ | 内容 |
|---|---|
| name | 商品名 |
| image | 商品画像URL |
| description | 商品説明 |
| brand | ブランド名 |
| sku | SKU |
| gtin13 | JANコード |
| offers | 価格・通貨・在庫・URL |
| aggregateRating | レビュー平均・件数 |
| review | 個別レビュー |

CC テンプレで JSON-LD を出力する場合は、商品マスタの値を変数として埋め込む。

## CC 移行前後の注意

- CC 移行前の旧テンプレと CC テンプレで、SEO設定の場所が異なる
- 移行時に **SEO設定の引き継ぎ漏れ** が起きやすい
- 移行前にすべてのSEO設定を棚卸し、移行後に差分確認

## 公開前チェック（CC固有）

- [ ] 商品マスタCSV のSEOタイトル・SEOディスクリプションが個別設定済
- [ ] CC テンプレートの既定値（フォールバック）が「商品名｜ブランド名」程度に設定済
- [ ] 商品グループの個別SEO設定が反映されている
- [ ] パンくずがメイングループ階層と一致
- [ ] 構造化データ（Product schema）が出力されている（Search Console のリッチリザルトテストで確認）
- [ ] サイトマップXML が最新（新商品・廃番商品の反映）
- [ ] robots.txt で意図しないページがブロックされていない
- [ ] noindex 設定が必要なページ（カート・マイページ等）に正しく付いている
