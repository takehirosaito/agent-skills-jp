# Shopify CVR診断スキル

## 概要

ShopifyストアのCVR低下要因を **ファネル単位**（商品ページ→カート→チェックアウト→決済→完了）で診断し、改善施策・A/Bテスト計画まで提案するスキル。

商品ページの離脱要因チェック30項目、カート・チェックアウト摩擦要因、モバイルUX問題、決済方法・配送方法のCVR影響、GA4イベント設計を網羅し、優先度付きで施策を返す。

## ★最重要原則

**症状（CVRが低い）ではなく、ファネル離脱箇所を特定してから施策を立てる**。商品ページ離脱と決済離脱では原因も対策も全く異なる。GA4で離脱箇所が分からない場合はイベント設計の不足を先に解決する。

### Shopify固有の要点

- Checkout：Shopify Plus は Checkout Extensibility、それ以外は標準チェックアウト
- 決済：Shop Pay / Apple Pay / Google Pay / コンビニ・代引・銀振（Shopify Payments + KOMOJU）
- モバイル比率：日本EC は 60-80%。CVR は PC比 50-70%が一般的
- ファネル計測：GA4 で `view_item` `add_to_cart` `begin_checkout` `add_payment_info` `purchase` の5イベント

## 処理フロー

**Step 1. 入力情報の確認（不足は仮定で進める）**
- 全体CVR・各ファネル段階のCVR（不明なら GA4 から取得方法を提示）
- 商品カテゴリ・単価帯
- モバイル／PC比率
- 主要流入チャネル（広告／オーガニック／メール）
- 過去3ヶ月のCVR推移
- 既に試した施策

不足時は仮定で進行し、後段でGA4イベント設計を提示。

**Step 2. ファネル離脱箇所を特定**
- 業界ベンチマーク（`references/cvr-funnel-benchmarks.md`）と比較
- 商品ページ離脱 / カート離脱 / チェックアウト離脱 / 決済離脱 のどれが主因かを判定

**Step 3. 該当箇所の要因チェック**
- 商品ページ離脱 → 30項目チェック
- カート離脱 → 送料・小計表示・在庫
- チェックアウト離脱 → ゲスト購入・住所入力UX
- 決済離脱 → 決済手段・エラー表示

**Step 4. モバイル／PC 別の問題切り分け**

**Step 5. 優先度付き改善施策リスト**
- 影響度×実装コストでマトリクス化
- 即時実装可能（テーマ設定変更）／要開発／要アプリ導入 の3分類

**Step 6. A/Bテスト計画と効果測定指標**

## 代表例（1パターン）

化粧品ストア（CVR 0.8%、業界平均1.5%、モバイル比率75%）：
- ファネル分析：`view_item → add_to_cart` が 5%（業界8%）で離脱大
- 主因仮説：商品ページの離脱（モバイル）
- 30項目チェックで特定された要因：①ファーストビューに価格が無い ②レビュー件数が0 ③カート追加ボタンが折りたたみ下
- 優先施策：カート追加ボタンの sticky 化 → A/Bテスト14日

他ジャンル（食品・ファッション・家電）の実例は `references/examples.md` を参照。

## 品質ゲート

- [ ] 全体CVRと業界ベンチマークの比較がある
- [ ] ファネル段階別の数値が4段階揃っている（不明な箇所は計測方法を提示）
- [ ] 離脱箇所が1つに特定されている（複数並列にしない）
- [ ] 改善施策が優先度付きで3-7項目
- [ ] 各施策に「想定影響」「実装コスト」がある
- [ ] A/Bテスト計画にサンプル数・期間がある
- [ ] モバイルとPCで別観点になっている
- [ ] 抽象論（「魅力的なページを作る」等）が無く具体的

## エッジケース

- **GA4イベントが正しく実装されていない**：診断不能のため、まず `references/ga4-event-design.md` を参照してイベント設計を返し、再度データ収集後に診断する旨を明示
- **CVRが業界平均を大幅に上回っている**：改善余地は小さいので、AOV／LTV／リピート率を見るべきと判断を返す
- **少額単価×高頻度購入（消耗品）**：CVRよりリピート率が重要なので診断軸を変更
- **B2B / Markets Pro**：CVR定義が異なる（見積依頼率・受注率）。BtoCの基準を当てない
- **広告流入が大半でランディング離脱が主因**：商品ページではなく広告クリエイティブとLP整合性の問題に切り分け、`shopify-lp-from-image-brief` で再構成を提案

詳細は `references/examples.md` を参照。

## 注意事項

- CVRはチャネル・季節・商品で大きく変動する。1日単位の変動では判断しない（最低14日）
- 業界ベンチマークは目安。自社の前年同期比・前月比を優先する
- A/Bテストは1要素ずつ。複数同時変更すると効果が分離できない
- 決済手段の追加・削除は Shopify Payments の契約・KOMOJU の手数料を確認
- Checkout のカスタマイズはプランによって制約あり（Shopify Plus / Checkout Extensibility）
- 公式仕様は変動するため、最終的にはストアの管理画面と GA4 で要確認
