# 決済方法・配送方法のCVR影響

## 日本市場での決済シェア（参考）

| 決済方法 | EC全体シェア（参考） |
|---|---|
| クレジットカード | 60-70% |
| コンビニ後払い | 5-10% |
| 銀行振込 | 3-5% |
| 代引き | 3-5% |
| PayPay | 5-10%（伸長中） |
| 楽天Pay | 2-5% |
| d払い／au PAY | 2-5% |
| Amazon Pay | 2-5% |
| Apple Pay / Google Pay | 1-3% |
| 後払い決済（NP後払い／Paidy等） | 5-10% |

→ **クレジットカードのみ** だと、市場の30-40%を取り逃す。

## ターゲット別の決済傾向

| ターゲット | 主な決済 |
|---|---|
| 20代女性 | クレジットカード、PayPay、Amazon Pay、Paidy |
| 30-40代女性 | クレジットカード、PayPay、コンビニ後払い、Paidy |
| 50-60代男性 | クレジットカード、代引き、銀行振込 |
| 高齢者 | 代引き、銀行振込 |
| 学生 | コンビニ後払い、PayPay |

## Shopify で使える主な決済

### Shopify Payments
- 標準決済（クレジットカード／Apple Pay／Google Pay）
- 手数料が他社より安い
- 日本円対応

### Amazon Pay
- アカウント連携で住所入力不要
- 30代女性〜40代男性に強い

### KOMOJU
- 日本市場特化：コンビニ／銀行振込／PayPay／d払い／代引き
- 必須レベル（クレジットのみは損失）

### Paidy
- 後払い：購入後コンビニ／銀行で支払い
- 若年層・主婦層

### Shop Pay
- Shopify 独自の高速決済
- 既存 Shop Pay ユーザーは指紋認証で完了

## 配送方法

### 配送業者の選択

- ヤマト運輸：標準
- 佐川急便：価格重視
- 日本郵便（ゆうパック）：安価・離島対応
- ネコポス／クリックポスト：小型商品

### 配送オプション

| オプション | 影響 |
|---|---|
| 配送日指定 | 中-高（特にギフト） |
| 配送時間帯指定 | 中（再配達対策） |
| お急ぎ便（翌日配送） | 中-高 |
| 送料無料閾値 | 高（5,000円が標準的、3,000円なら強い） |
| 北海道・沖縄追加料金 | カート放棄を生みやすい |

### 配送料の表示

- **商品ページ**：「送料：全国一律○円／○○円以上で送料無料」
- **カート**：あと○○円で送料無料バー
- **チェックアウト**：配送方法ごとの料金を明示

## 配送スピード

| スピード | CVR影響 |
|---|---|
| 翌日配送 | 大幅にプラス（モール並み） |
| 2-3日 | 標準 |
| 1週間以上 | マイナス（特にギフト） |
| 取り寄せ | 大幅マイナス（離脱率高） |

## 海外配送（Markets）

- 海外配送オプションを表示するか
- 関税・税の表示（DDP / DDU）
- Markets 設定で国別の配送ゾーン・料金

## ギフト関連

- ラッピング有料／無料
- メッセージカード対応
- のし（祝・志・内祝い等）
- 配送先と請求先を分ける（プレゼント発送）
- 価格を隠す（明細書非同梱）

## CVR改善のチェックリスト

### 決済方法
- [ ] クレジットカード以外を最低3種類提供
- [ ] PayPay／Amazon Pay／後払いのいずれかを提供
- [ ] 各決済の手数料・最低注文額の差を明確化

### 配送
- [ ] 送料無料閾値を商品ページ・カート・ヘッダーに表示
- [ ] 配送日数の目安を商品ページに表示
- [ ] 配送日／時間帯指定が可能
- [ ] 北海道・沖縄の追加料金を商品ページで予告

### 表示
- [ ] 税込価格を主表示
- [ ] 配送料を「商品ページ」「カート」「チェックアウト」の3箇所で一貫表示
- [ ] 配送業者・配送方法をマイページから確認可能

### ギフト
- [ ] ラッピング選択がチェックアウトで可能
- [ ] メッセージカード入力欄
- [ ] のし対応
- [ ] 配送先住所が請求先と異なる場合の処理

## アプリ・ツール

| 用途 | 主なアプリ |
|---|---|
| 後払い決済 | KOMOJU, Paidy, NP後払い |
| 配送日時指定 | あとらいず／日付指定アプリ |
| ラッピング | Gift Wrap |
| のし | のし対応アプリ（日本市場特化） |
| 配送料計算 | Shopify標準（ゾーン設定）or 配送カスタムアプリ |

## 注意（景表法）

- 「送料無料」表記は **配送料が無料** な意味で正確に
- 「全国一律」表記は北海道・沖縄を含むか明示
- 「最短翌日配送」は **全商品が対象か** 明示
- 「○日以内配送」は **営業日／カレンダー日** どちらかを明示
