# カート・チェックアウト 摩擦要因

## カート画面の摩擦

### A. 価格・送料表示

- **送料が後出し**：商品ページでは無料表示なのにカートで有料
- **送料無料閾値が見えない**：「あと○○円で送料無料」が無い
- **合計金額が見えにくい**：小計／送料／税が混在
- **税込／税別の表記が不明瞭**：日本は税込が標準
- **クーポン適用結果が見えにくい**

### B. クロスセル・押し売り

- **推奨商品が大量に表示**：購入意図を阻害
- **「あわせて買うとお得」が分かりにくい**
- **ポップアップで離脱**

### C. 操作性

- **数量変更が直感的でない**：「+」「-」ボタンが小さい
- **削除が誤操作しやすい**：確認なし削除
- **保存機能が無い**：「後で買う」リストへ移せない

### D. CTA

- **「チェックアウトへ進む」が目立たない**
- **「会員登録」を「チェックアウト」より先に押させる**
- **「カートに戻る」が無い**：チェックアウト中の引き返しが不可

## チェックアウトの摩擦

### A. 会員登録の強制

- **ゲスト購入不可**：CVR 大幅低下
- **「アカウント作成」を強制**

→ Shopify Standard は **ゲスト購入をON にできる**（管理画面 → Checkout → Customer accounts → Optional）。

### B. フォーム項目

- **必須項目多い**：氏名／カナ／郵便番号／住所／電話／メール
- **入力欄が小さい**（モバイル）
- **入力規則が厳しい**：電話番号のハイフン必須／不要が混在
- **エラーメッセージが分かりにくい**

### C. 配送方法

- **配送オプションが少ない**：宅配便1種類のみ
- **配送日指定不可**：ギフト需要を取り逃す
- **時間帯指定不可**
- **送料が高い**：他社比較で見劣り

### D. 決済方法

- **クレジットカードのみ**：日本市場では大幅損失
- **コンビニ後払い不可**：若年層・主婦層に影響
- **PayPay／楽天Pay／d払い無し**：モバイル決済の損失
- **Amazon Pay 無し**：ID入力の手間を減らせる
- **代引き不可**：高齢層・現金主義層

### E. 決済エラー

- **3Dセキュア認証で挫折**
- **モバイルで決済画面が崩れる**
- **タイムアウト**
- **カード情報の入力欄が小さい**

### F. その他

- **配送料の高さ**：北海道・沖縄追加料金が突然出る
- **割引適用エラー**：クーポンが効かない
- **在庫切れに途中で気付く**：商品ページから一気に通せていない

## Shopify Checkout Extensibility（Plus）

Shopify Plus プランでは Checkout UI extension で：
- カスタムフィールド追加
- 配送オプションのカスタム表示
- 決済方法の並び順
- 信頼バッジの追加
- バナー（送料無料閾値告知）
- メッセージカード入力欄（ギフト）

Standard プランは Checkout の大幅カスタマイズ不可。**設定の範囲内**で最適化する。

## カート放棄メール（Shopify標準）

Shopify は標準で **カート放棄メールを自動送信** する（Marketing → Automations → Abandoned cart）。

- 送信タイミング：放棄1時間後（デフォルト、変更可）
- リカバリーURL：1クリックで元のカート復元
- 統計：開封率・クリック率・回復率がダッシュボードで見える

→ `shopify-abandoned-cart-mail` スキルで設計を別途。

## モバイル特有

- **キーボードでフォームが隠れる**：iOS Safariで頻発
- **オートフィル機能の活用**：iOS / Chrome の住所オートフィルが効くか
- **タップターゲット**：最低 44×44pt
- **ピンチズーム可能**：フォームの文字が小さくても拡大できるように

## チェック方法

### 1. 自分で購入を試す

- 新規ゲストで端末を変えて購入してみる
- モバイル／PC 両方
- 各決済方法を試す
- カート放棄メールが届くか確認

### 2. GA4 で確認

| イベント | 確認内容 |
|---|---|
| `view_cart` | カート到達数 |
| `begin_checkout` | チェックアウト開始 |
| `add_payment_info` | 決済情報入力到達 |
| `add_shipping_info` | 配送情報入力到達 |
| `purchase` | 完了 |

`begin_checkout → purchase` の通過率が異常に低い段階を特定。

### 3. Shopify 標準分析

- Reports → Sessions converted to orders
- Reports → Marketing → Cart abandonment
- Reports → Online store conversion over time

## 優先改善ポイント

| 影響度 | 項目 |
|---|---|
| 最大 | ゲスト購入可、送料、決済方法多様化 |
| 大 | フォーム項目最小化、配送日指定 |
| 中 | クロスセル整理、エラー文言、モバイル UX |
| 小 | 信頼バッジ、メッセージカード |
