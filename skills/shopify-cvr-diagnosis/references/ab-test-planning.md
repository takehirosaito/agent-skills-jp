# A/Bテスト計画テンプレ

## A/Bテスト の基本構造

```markdown
# A/Bテスト計画：[施策名]

## 1. 仮説
（誰の何を変えると、何が改善するか）

## 2. テスト対象
- ページ／要素：
- 訪問者セグメント：

## 3. パターン
- A（対照群）：現状
- B（実験群）：変更内容

## 4. 成功基準
- 主要指標（KPI）：
- 副次指標：
- 統計的有意性：p < 0.05

## 5. サンプルサイズ
- 必要サンプル：（計算式）
- 期間目安：

## 6. 注意事項
- リスク：
- ロールバック条件：

## 7. 結果と判断
- 期間後、勝者を決定／引き分けなら継続検証／対照群が勝ったら撤回
```

## 例：送料無料閾値の変更

### 仮説
カート → チェックアウト通過率が低い（30%、業界平均45%）。原因は「送料300円が高い」と仮定。**送料無料閾値を 5,000円 → 3,000円 に下げると、平均注文単価が下がるが CVR が上がり、トータル売上が増える**。

### テスト対象
- ページ：全商品ページ・カート画面
- セグメント：新規セッション

### パターン
- A：送料無料閾値 5,000円（現状）
- B：送料無料閾値 3,000円

### 成功基準
- 主要KPI：**1セッションあたり売上**（CVR × AOV）
- 副次：CVR、AOV、カート放棄率
- 有意水準：p < 0.05

### サンプルサイズ計算

CVR 1%、改善期待 1.3%、有意水準 0.05、検出力 0.8 の場合：

| 1群あたり | 期間目安 |
|---|---|
| 約 7,000 セッション | 月間 30,000 セッションのストアなら 1-2週間 |

オンラインA/Bテスト計算機（Optimizely / Evan Miller）で算出。

### 注意
- リスク：粗利率の低い商品が増えて、トータル粗利は減る可能性
- ロールバック：粗利が10%以上下がったら即座に戻す

## 例：商品ページCTAボタンの文言

### 仮説
「カートに追加」より「今すぐ購入」のほうが心理的にCVR が高い。

### パターン
- A：「カートに追加」（現状）
- B：「今すぐ購入する」

### 成功基準
- 主要：商品ページ → カート率
- 副次：注文単価（衝動買いで単価が下がる懸念）

### 期間
2週間、各群5,000セッション

## 例：商品画像枚数

### 仮説
画像3枚 → 6枚に増やすと、購入率が上がる。

### パターン
- A：3枚（現状）
- B：6枚（使用シーン・テクスチャ・パッケージを追加）

### 成功基準
- 商品ページ滞在時間（GA4 engagement_time_msec）
- view_item → add_to_cart 率

## Shopify でA/Bテストする方法

### 方法1：Shopify テーマの分岐

```liquid
{%- assign user_id = cart.token | append: customer.id | md5 -%}
{%- assign group = user_id | modulo: 100 -%}

{%- if group < 50 -%}
  {%- comment -%}グループA{%- endcomment -%}
  <button>カートに追加</button>
{%- else -%}
  {%- comment -%}グループB{%- endcomment -%}
  <button>今すぐ購入する</button>
{%- endif -%}
```

## 検証時の注意

### 1. シーズナリティ

セール期間中／祝日／給料日後で行動が変わる。**通常期間** で実施。

### 2. 複数施策の同時実施を避ける

同時に複数を変えると因果がわからない。**1テスト 1変更** が原則。

### 3. データ抽出の漏れ

- 既存顧客が含まれていないか
- B2B 注文が含まれていないか
- 内部スタッフのアクセスを除外

### 4. 統計的有意性

CVR 1% のストアで「+0.05%」を有意に検出するには **数十万セッション** 必要。小規模ストアは短期A/Bテストに向かない。

## 結果の判断

| 結果 | 判断 |
|---|---|
| Bが p<0.05 で有意 | Bを全面採用 |
| Bが有意でなく僅差 | 期間延長 or 撤回 |
| Aが有意に勝ち | Aで確定、Bを撤回 |
| 主要KPIで引き分け、副次でBが優位 | 部分採用 |
