# CVR 診断ケース 実例集

## 例1：化粧品ストア（CVR 0.8% → 改善余地大）

### 現状
- サイト全体 CVR：0.8%（業界平均 2-3%）
- 商品ページ → カート：4%（業界平均 7%）
- カート → チェックアウト：30%（業界平均 45%）
- チェックアウト → 完了：65%（業界平均 60%）
- モバイル CVR / PC CVR：0.4（業界 0.5-0.7）

### 診断
1. **商品ページ離脱が大きい**（最大の問題）
   - レビュー件数：0件の商品が多い
   - 商品説明：1段落のみ、ファーストビューに価値提案が無い
   - 画像枚数：1-2枚
2. **カート → チェックアウト 通過率が低い**
   - 送料300円（5,000円未満）が後出し（商品ページに表示無し）
   - 配送日数：4-5日（モバイルで「すぐ欲しい」需要を取り逃し）
3. **モバイルCVR が低い**
   - LCP 4.2秒（遅い）
   - 固定CTAバー無し

### 施策（優先順）
1. **レビューアプリ導入**（Judge.me / Loox 等）→ 影響大、難易度中
2. **商品ページに送料表示・送料無料閾値バナー**→ 影響大、難易度低
3. **画像 WebP化・lazy load**→ モバイル LCP 改善
4. **商品説明テンプレを充実**（薬機法配慮した特徴／使い方／FAQ）
5. **配送業者の見直し**（翌日対応）

### 期待効果
- 商品ページ → カート：4% → 6% （+50%）
- カート → チェックアウト：30% → 38% （+27%）
- 全体 CVR：0.8% → 1.4%

### 注意
- 化粧品カテゴリのため、商品説明・レビュー本文の薬機法注意（`yakki-keihyo-expression-check` 併用）

## 例2：アパレルストア（モバイル劣勢）

### 現状
- PC CVR：2.5%
- モバイル CVR：0.6%（PC比 0.24、極端に低い）
- カート放棄率：78%

### 診断
**モバイル UX が深刻**
- タップ領域：色選択チップが 30×30px（小さすぎ）
- サイズ選択：プルダウンで一覧性が悪い
- 画像：ピンチズーム disabled
- フォームの郵便番号自動入力が動作しない（`autocomplete` 未設定）
- LCP：3.8秒
- カート放棄メール：未設定

### 施策（優先順）
1. **タップ領域拡大**（44×44pt以上）→ 即実装
2. **サイズ選択UI 改善**（プルダウン → チップ）
3. **autocomplete 設定**（`postal-code` `tel` `email`）
4. **画像ピンチズーム ON**
5. **カート放棄メール設定**（Shopify標準で簡単）
6. **モバイル LCP 改善**：画像 srcset、フォント subset

### 期待効果
- モバイル CVR：0.6% → 1.2%
- カート放棄率：78% → 65%

## 例3：機能性表示食品（定期購入率が低い）

### 現状
- 全体 CVR：3.2%（一回購入）
- 定期購入率：8%（業界 30-50%）
- LTV：低い

### 診断
**定期購入導線が弱い**
- 商品ページに定期購入オプションが無い／目立たない
- 「定期で○%OFF」訴求が無い
- 定期解約条件が不明瞭（潜在的不安）
- ステップメールでの定期誘導なし

### 施策
1. **商品ページに定期購入オプション**（Recharge / Loop Subscriptions等のアプリ）
2. **「定期で20%OFF」をファーストビューに**
3. **解約条件を明確化**（いつでも解約OK）
4. **初回購入後ステップメール**で定期切替訴求
5. **「定期購入のメリット FAQ」を商品ページに**

### 期待効果
- 定期購入率：8% → 25%
- LTV：3-4倍

### 注意（健康食品）
- 機能性表示食品の届出文言厳守
- 効能効果の標榜不可（一般食品扱い）
- 「治る」「効く」等の断定NG

## 例4：ギフトストア（季節依存）

### 現状
- 母の日／父の日／お中元／クリスマス商戦の月：CVR 4%
- それ以外の月：CVR 0.5%
- 全体平均：CVR 1.5%

### 診断
**通年集客が弱い**
- シーズン外は購入機会が無い／訴求が無い
- 「内祝い」「お返し」など通年需要を取りに行けていない
- ブログ／SEO のシーズン外コンテンツ少ない

### 施策
1. **通年ギフトの訴求強化**（内祝い・引越し祝・誕生日）
2. **ブログコンテンツ計画**（内祝いマナー／予算別ギフト等の通年KW）→ `shopify-blog-content-planner` 連動
3. **ギフトコレクション「シーン別」を充実**
4. **メルマガ：誕生日前月にレコメンド配信**

### 期待効果
- 通年平均 CVR：1.5% → 2.5%
- シーズン依存度が下がる

## 例5：食品ストア（送料が壁）

### 現状
- CVR 1.0%（業界平均 2-4%）
- AOV 2,800円
- 送料：全国一律 800円、5,000円以上で無料

### 診断
**AOV が送料無料閾値に届かないため、CVR が低い**
- 平均注文 2,800円 vs 送料無料閾値 5,000円のギャップが大きい
- 「あと2,200円で送料無料」と表示しても、購入1点しか考えていない人には響かない
- 単品商品が多く、まとめ買い動線が弱い

### 施策
1. **送料無料閾値を 3,500円に下げる**（A/Bテスト推奨）
2. **「2点目10%OFF」セット販売プロモーション**
3. **クロスセル強化**（カート画面で関連商品）
4. **メール定期便（送料無料）の訴求**

### 期待効果
- AOV：2,800円 → 3,200円
- CVR：1.0% → 1.4%

### A/Bテスト計画
- パターンA：閾値 5,000円（現状）
- パターンB：閾値 3,500円
- 期間：4週間
- 主要KPI：1セッションあたり売上（CVR × AOV）
- 副次：注文回数、粗利率

## 共通パターンの教訓

| 落とし穴 | 対策 |
|---|---|
| 商品ページのレビュー無し | Judge.me / Loox 等を導入 |
| 送料が後出し | 商品ページに送料明示、送料無料閾値バー |
| モバイル UX が PC より大幅劣勢 | Lighthouse、実機テスト、タップ領域 |
| 決済方法が少ない | PayPay / Amazon Pay / 後払い追加 |
| 配送日数が遅い | 翌日対応の業者検討 |
| 定期購入オプション無し（食品） | サブスクアプリ導入 |
| ステップメール無し | カート放棄メール、購入後フォロー |
| 通年集客弱い（ギフト） | SEO ブログ／メルマガでの通年訴求 |

## ジャンル別の優先施策

| ジャンル | 最優先 |
|---|---|
| 化粧品 | レビュー、薬機法配慮の説明 |
| アパレル | サイズ表、お手入れ、モデル情報、モバイルUX |
| 食品 | 賞味期限、保存方法、定期購入 |
| 健食 | 届出文言、定期、注意表示 |
| 雑貨 | 用途、サイズ、素材、レビュー |
| ギフト | ラッピング、配送日指定、シーン提案 |
