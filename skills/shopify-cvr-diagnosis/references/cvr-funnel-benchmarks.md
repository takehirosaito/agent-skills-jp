# CVR ファネル ベンチマーク

## EC全般のベンチマーク（参考値）

| 指標 | 業界平均 | 優秀 | 業界トップ |
|---|---|---|---|
| サイト全体 CVR | 1-3% | 3-5% | 5%+ |
| 商品ページ → カート追加率 | 5-10% | 10-20% | 20%+ |
| カート → チェックアウト開始率 | 40-50% | 60-70% | 70%+ |
| チェックアウト → 完了率 | 50-70% | 70-90% | 90%+ |
| カート放棄率 | 60-80% | 50-60% | 30-50% |
| モバイル CVR / PC CVR 比 | 0.5-0.7 | 0.8-1.0 | 1.0+ |
| 平均注文単価（AOV） | 業種依存 | - | - |
| リピート率 | 20-30% | 30-50% | 50%+ |

数値は Baymard Institute / Shopify公式ブログ / 各種EC分析記事の引用＋実務経験から。**業界・国・チャネル・季節で大きく変動**するため、絶対基準ではなく **自社過去比較** と組み合わせて判断する。

## 業種別の傾向

### 化粧品・スキンケア
- CVR：1.5-3%
- AOV：5,000-10,000円
- リピート率：高（30-50%）
- カート → 完了の通過率は高め（指名買いが多い）

### アパレル
- CVR：1-2.5%
- AOV：8,000-15,000円
- 返品率：高（10-20%）
- サイズ表記次第でCVR大きく変動

### 食品・サプリ
- CVR：2-4%
- 定期購入率：30-50%（高い）
- 初回CVR と定期CVR を分けて見る

### ギフト
- CVR：シーズン中 3-5%、通常 1-2%
- ラッピング・配送日指定がCVRに影響大

### 雑貨・家電
- CVR：1-2%
- 比較検討期間が長い
- レビュー数がCVRに直結

## デバイス別

| デバイス | 平均 CVR | 注意点 |
|---|---|---|
| PC | 2-4% | じっくり比較するユーザー |
| モバイル | 1-2% | 衝動買い／離脱しやすい |
| タブレット | 2-3% | PCに近い行動 |

→ モバイル CVR が PC の **0.5以下** なら、モバイル UX に深刻な問題。

## 流入チャネル別

| チャネル | CVR傾向 |
|---|---|
| 指名検索（オーガニック） | 高（5-10%） |
| カテゴリ検索（オーガニック） | 中（1-3%） |
| ディスプレイ広告 | 低（0.5-1%） |
| リスティング（指名） | 高 |
| リスティング（一般KW） | 中 |
| SNS広告 | 低-中 |
| メール | 高（既存顧客） |
| LINE | 中-高 |

## 比較すべき軸

1. **自社の過去（前月／前年同期）**：シーズナリティ補正
2. **業界平均**：Baymard 等の公開ベンチマーク
3. **競合**：似た規模・カテゴリの公開数値（あれば）
4. **デバイス別**：モバイル と PC を分けて
5. **チャネル別**：オーガニック／広告／メールで別評価

## 異常値の見つけ方

### 「異常に低い」段階のサイン

- **業界平均より-30%以上低い**：明確な問題あり
- **デバイス間で2倍以上の差**：UX問題（特にモバイル）
- **特定チャネルだけ低い**：流入の質が悪い、または着地ページのミスマッチ

### 「異常に高い」場合の注意

- 商品ページ → カート率 が30%以上：価格訴求が強い／衝動買い狙い
- カート → 完了率が95%以上：定期購入比率が高い／既存顧客のみ

## トレンドの読み方

1. **週次／月次の推移**：施策実施前後の変化
2. **施策ごとのリフト**：A/Bテストで因果を確定
3. **季節調整**：母の日・年末年始・ブラックフライデー
4. **新規 vs リピーター**：分けて分析
