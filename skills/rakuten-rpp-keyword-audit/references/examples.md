# RPP改善診断 実例パターン

## 例1：50商品の店舗・過去30日分析

### 全体実績（改善前）

| 指標 | 値 |
|---|---|
| 表示回数 | 800,000 |
| クリック数 | 8,000 |
| CTR | 1.0% |
| 平均CPC | 70円 |
| CV数 | 120 |
| CVR | 1.5% |
| 売上 | 720,000円 |
| 広告費 | 560,000円 |
| ROAS | 1.29倍 |

→ ROAS 1.29倍は赤字に近い。改善必須。

### キーワード別分析（一部抜粋）

| キーワード | クリック | CV | CPC | CVR | ROAS | 判定 |
|---|---|---|---|---|---|---|
| 電気ケトル | 1,200 | 12 | 80 | 1.0% | 1.0 | 入札下げ |
| 電気ケトル 1L | 600 | 25 | 60 | 4.2% | 4.2 | 入札強化 |
| 電気ケトル 温度調整 | 400 | 18 | 50 | 4.5% | 4.5 | 入札強化 |
| ケトル ティファール | 200 | 0 | 100 | 0.0% | 0.0 | 除外（商標） |
| 沸騰 早い ケトル | 150 | 8 | 40 | 5.3% | 5.3 | 入札維持 |
| 電気ポット | 800 | 2 | 50 | 0.25% | 0.5 | 停止 |
| キッチン家電 | 1,500 | 5 | 50 | 0.3% | 0.6 | 停止 |
| 電気ケトル 茶こし | 100 | 5 | 60 | 5.0% | 5.0 | 入札維持 |
| ケトル コーヒー | 300 | 12 | 60 | 4.0% | 4.0 | 入札維持 |
| ハンドドリップ 道具 | 50 | 3 | 80 | 6.0% | 6.0 | 入札維持・拡張 |

### 改善案

| アクション | キーワード件数 | 効果見込み |
|---|---|---|
| 停止 | 8（電気ポット、キッチン家電等） | 広告費削減 -120,000円 |
| 除外 | 5（競合ブランド名等） | 商標問題回避 |
| 入札下げ | 10 | 広告費削減 -60,000円 |
| 入札強化 | 5（電気ケトル 1L、温度調整等） | CV数増加 +30件 |
| 追加 | 15（茶こし、ハンドドリップ等から拡張） | CV数増加 +20件 |

### 改善後（見込み）

| 指標 | 値 | 変化 |
|---|---|---|
| クリック | 5,500 | -2,500 |
| CPC | 80円 | +10円 |
| 広告費 | 440,000円 | -120,000円 |
| CVR | 3.0% | +1.5% |
| CV数 | 165 | +45 |
| 売上 | 990,000円 | +270,000円 |
| ROAS | 2.25倍 | +0.96 |

→ クリック数は減るがROASとCV数は大幅改善。

## 例2：単品商品の集中分析（化粧水）

### 商品情報
- 売価：3,500円
- 粗利率：35%
- CV1件あたり広告許容額：3,500 × 35% × 0.5（目標利益率17.5%目安）= 612円

### CPC上限算出

| CVR想定 | CPC上限 | 商品一括（最低20円） | 個別入札・キーワード/商品名指定（最低40円） |
|---|---|---|---|
| 1% | 6円 | 運用不可 | 運用不可 |
| 2% | 12円 | 運用不可 | 運用不可 |
| 3% | 18円 | 運用不可 | 運用不可 |
| 5% | 31円 | 運用可 | 運用不可 |
| 7% | 43円 | 運用可 | 運用可（ギリ） |
| 10% | 61円 | 運用可 | 運用可 |

→ **商品一括で運用**するには CVR 約3.3% 以上必要（20÷612）。**個別入札（キーワード・商品名指定）で運用**するには CVR 約6.5% 以上必要（40÷612）。一般的なCVR（2-3%）では商品一括も個別入札も厳しい商品ということ。

### 戦略
- ロングテールキーワードに絞る（CVR高め）
- 商品ページCVR改善で運用可能領域を広げる
- 価格・粗利率の見直し

### 改善案
- 「敏感肌 化粧水 アルコールフリー」「化粧水 セラミド 保湿」等のロングテール
- 「化粧水」「コスメ」等のビッグキーワードからは撤退

## 例3：季節商品（クリスマス商品）

### 11月～12月の運用

| 期間 | アクション |
|---|---|
| 11/1-11/15 | キーワード準備、CPC低め（20〜30円ライン） |
| 11/16-11/30 | CPC段階的に上げる（60円→80円） |
| 12/1-12/22 | CPC最大（100-120円）、予算集中 |
| 12/23-12/24 | 即日配送可能商品のみ |
| 12/25-12/31 | 配信完全停止 |
| 1月以降 | 来年に向けて分析、停止維持 |

### 11月実績
- CPC：60円、ROAS：3倍

### 12月実績
- CPC：100円、ROAS：5倍（CVR上昇）
- 売上が3倍、広告費は1.5倍

→ 季節需要のピーク期はCPCを上げてもROAS改善する典型例。

## 例4：新商品の評価期間（家電）

### 商品情報
- 販売開始：2024-04-01
- 売価：12,000円、粗利率：30%

### 評価期間運用

→ 新商品は3ヶ月かけて評価し、改善しながら運用。即判定で停止しない。

## 例5：競合の入札強化による影響

### 状況
- 5月に競合店舗がCPC強化（推測）
- 自店の表示回数が30%減少
- ROASは維持

### 分析
- imp減少 → 競合に負けている可能性
- CPCを20%上げて表示回数回復を試みる
- ROASは目標を下回らないギリギリで運用

### 結果
- CPC：70円 → 85円
- imp：3,000 → 3,500（戻る）
- CV：30 → 35
- ROAS：5倍 → 4.5倍（やや低下、許容範囲）

→ 競合との競争でCPCが上がるのは避けられない。ROAS目標との折り合いで判断。

## 例6：商品グループ別のキャンペーン構成

- 上限CPC：80円

## 改善案の優先順位

1. **即時対応**：停止・除外（無駄を止める）
2. **1週間以内**：入札下げ（赤字キーワード）
3. **2週間以内**：入札強化（高ROASキーワード）
4. **1ヶ月以内**：キーワード追加（拡張）
5. **四半期**：キャンペーン構成見直し

→ 段階的に改善し、急激な変更で配信が乱れないように。

## RPP診断の月次フロー

### Day 1（月初）
- 前月実績CSVダウンロード
- 全体指標の確認

### Day 2-3
- キーワード別判定
- 改善案ドラフト

### Day 4
- 担当者・責任者レビュー
- 修正

### Day 5
- 改善実施（停止・CPC調整）
- 効果モニタリング開始

### Day 30（月末）
- 当月の効果測定
- 翌月の方針

→ 月次サイクルで継続改善。
