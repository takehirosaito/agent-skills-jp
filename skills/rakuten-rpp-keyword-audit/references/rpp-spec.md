# RPP基本仕様（2025.11以降の上限CPC方式）

最新仕様は RMS の RPP管理画面で確認。

## RPP（楽天プロモーションプラットフォーム）の概要

楽天市場の店舗向け検索連動型広告。検索結果・カテゴリページ・商品ページに広告枠を表示し、クリック課金で配信。

## 2025.11 全店完全移行：上限CPC方式

### 旧（固定CPC方式）
- CPC固定額を入札
- 入札順で表示順位決定

### 新（上限CPC方式）
- 上限CPCを設定（その額まで自動入札）
- 実際のCPCは競合状況で変動
- 楽天独自のオートビッディング

### 移行の影響
- 配信効率の最適化（楽天側が最適なCPCを自動算出）
- 上限CPCを意識した予算管理
- 「過剰に入札しないため」のシステム

## 最低CPC（2025.11以降・2階層）

| 種別 | 最低CPC |
|---|---|
| **商品一括**（全体の上限CPC設定） | **20円以上** |
| **キーワード・商品名指定**（個別入札） | **40円以上** |

→ これ未満のCPC設定は不可。**個別入札（キーワード・商品名指定）は40円が下限**であり、20円〜39円のCPC上限を出したい商品は個別入札ができない（商品一括での運用に限定される）。最新仕様はRMSのRPP管理画面で必ず確認すること。

## RPP の入札階層（2階層）

1. **商品一括**：全商品に対する上限CPCと予算（20円以上）
2. **個別指定**：特定キーワードや商品名指定での入札（40円以上）

優先度：個別指定 > 商品一括（個別指定がある場合はそちらが優先される）

過去解説で「キャンペーン/商品別/キーワード別の3階層」「一律20円」と書かれているケースがあるが、いずれも誤り。現行仕様は **商品一括（20円〜）／個別入札（40円〜）の2階層**。

## 主要指標

### 表示・クリック・CV

| 指標 | 内容 |
|---|---|
| imp（インプレッション） | 広告の表示回数 |
| クリック | 広告をクリックした回数 |
| CTR | クリック / imp = クリック率 |
| CV（コンバージョン） | 購入完了数 |
| CVR | CV / クリック = 購入率 |

### 費用・収益

| 指標 | 計算 |
|---|---|
| 広告費 | クリック × CPC |
| CPC | 広告費 / クリック |
| CPA | 広告費 / CV |
| ROAS | 売上 / 広告費 |
| 広告費比率 | 広告費 / 売上 |

### ベンチマーク（業種・商品次第で大幅変動）

| 指標 | 目安 |
|---|---|
| CTR | 1-3% |
| CVR | 1-5% |
| ROAS | 5倍以上 |
| 広告費比率 | 10-20% |

## 広告枠の種類

### サーチ広告
- 楽天検索結果に表示
- キーワード連動

### カテゴリ広告
- カテゴリページに表示
- カテゴリ連動

### 関連商品広告
- 商品ページ内の関連商品枠に表示

### CPCの相場（参考・市場次第）

| カテゴリ | CPC相場 |
|---|---|
| ファッション | 30-80円 |
| 家電 | 50-150円 |
| 化粧品 | 80-200円 |
| 食品 | 30-80円 |
| インテリア | 50-100円 |
| ベビー | 50-100円 |

→ 競合が多いカテゴリほどCPCが高い。

## キャンペーン設計の基本

### 商品グループの分け方

1. **粗利率別**：高粗利商品と低粗利商品でキャンペーンを分ける
2. **シーズン別**：通年商品と季節商品
3. **ライフサイクル別**：新商品（実績収集中）と既存商品

### 予算配分

| 目的 | 予算割合 |
|---|---|
| 主力商品（実績ある） | 50-60% |
| 新商品（評価期間） | 10-20% |
| 集客用（ロス・リーダー） | 10-20% |
| テストキャンペーン | 5-10% |

## 配信モード

### 標準配信
- 通常の配信、予算を平均的に消化

### 集中配信
- 短期間で予算を消化、特定期間の露出強化

### 学習期間
- 新規キャンペーンの最初の数日は楽天側が学習
- この期間は実績変動が大きい

## RPP分析の頻度

| 頻度 | 内容 |
|---|---|
| 毎日 | 予算消化率・配信状況 |
| 毎週 | キーワード実績・ROAS確認 |
| 毎月 | 商品別ROAS・改善検討 |
| 四半期 | キャンペーン構成見直し |

## 配信停止リスク

### 予算枯渇
- 月予算到達で配信停止
- 月末近くで残予算が少ない場合の対応

### 設定ミス
- CPC上限を最低額未満に設定
- 商品が除外リストに入っている
- キャンペーンが「停止中」

### 楽天側の措置
- 違反点数累積
- 商品ページ規約違反
- 商標問題
