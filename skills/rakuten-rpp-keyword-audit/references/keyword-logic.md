# キーワード判定ロジック

## キーワード分類マトリクス

### 4象限マトリクス

|  | 高ROAS | 低ROAS |
|---|---|---|
| 高CV | A. **入札強化＋増額** | B. **入札維持・コスト見直し** |
| 低CV | C. **入札上げ or 改善** | D. **停止・除外** |

### 各象限の対応

#### A. 高ROAS・高CV（成功キーワード）
- 入札を強化（CPCを上げて表示回数増）
- 予算を増額
- 関連キーワードを追加（同種のキーワードでも勝てる可能性）
- 商品ページに該当キーワードを含める（SEO連動）

#### B. 低ROAS・高CV（コスト過多）
- CPC上限を下げる（過剰入札の解消）
- 競合状況確認
- CPAが高すぎないか
- 商品ページCVR改善で同じクリック数でCV増を狙う

#### C. 高ROAS・低CV（埋もれている）
- 表示回数が少ない場合は入札上げ（imp増）
- CTRが低い場合は商品名・画像見直し
- 関連キーワード追加で範囲拡大

#### D. 低ROAS・低CV（不振）
- 30日経過後も改善なし → 停止
- CV0の場合は除外
- 競合・商品ページ・価格の根本見直し

## 個別の判定基準

### 「停止」の基準

以下のいずれかに該当：
- 過去30日：クリック30以上、CV=0
- 過去30日：ROAS<1.0（赤字）
- 過去30日：ROAS<2.0が継続3ヶ月以上

### 「除外」の基準

- 競合ブランド名（商標問題）
- 自社商品と無関係なキーワード
- 薬機法・景表法に抵触するキーワード（「シミに効く」「最安」等）
- 効能訴求キーワード（化粧品・健食）

### 「入札強化」の基準

- 過去30日：ROAS>10、CV>5件
- 過去30日：表示回数増加トレンド
- 季節要因で需要増加見込み

### 「追加候補」の基準

- 競合店舗が露出している
- 楽天サジェスト（タンタンサーチ）に出てくる
- 商品名・キャッチコピーに含まれている
- 季節・イベント連動

## キーワードの種類別

### ビッグキーワード（指名語）
- 例：「電気ケトル」「化粧水」「ワンピース」
- 検索ボリューム大、競合多、CPC高
- CVR は平均的、勝負しにくい

### ミドルキーワード（用途・属性）
- 例：「電気ケトル 1L」「敏感肌 化粧水」「ロング ワンピース」
- 検索ボリューム中、競合中、CPC中
- CVR は比較的高い、狙い目

### ロングテール（属性・状況）
- 例：「電気ケトル 1L 温度調整」「敏感肌 化粧水 アルコールフリー」
- 検索ボリューム小、競合少、CPC低
- CVR は高い、収益性高い

### 戦略
- ビッグ：露出維持（ブランド認知）
- ミドル：主力キーワード（収益源）
- ロングテール：拡張（カバレッジ拡大）

## キーワード追加の手順

### 1. 競合分析
- 楽天検索で商品を検索
- 上位表示の競合店舗を特定
- 競合の商品名・キャッチコピーから語句抽出

### 2. サジェスト分析
- 楽天検索バーのサジェスト
- Googleサジェスト
- 関連商品から抽出

### 3. 自社商品ページ分析
- 自社の商品名・キャッチコピー
- 説明文に含まれる語句

### 4. レビュー分析
- レビュー中に頻出する語句
- 顧客の言葉そのもの（リアルな検索語）

### 5. 季節・イベント分析
- 母の日／父の日／クリスマス等の連動語
- 「春夏」「秋冬」等の季節語

## キーワード除外の手順

### 1. 競合ブランドキーワード
- 「ユニクロ」「無印良品」「ニトリ」等の競合固有名詞
- 自社商品と完全に違う

### 2. 無関係キーワード
- 商品と関係ないキーワードに引っかかる
- 楽天の検索アルゴリズムで誤って表示

### 3. 効能訴求キーワード（化粧品・健食）
- 「シミに効く」「シワが消える」「痩せる」「○○病が治る」
- 薬機法・景表法に抵触

### 4. 過去の除外キーワード
- 一度除外したキーワードを再除外する場合
- 期限切れの季節キーワード

## CPC調整の原則

### CPCを上げる場合
- ROASが目標を上回っている
- 表示回数を増やしたい
- 競合に勝ちたい

### CPCを下げる場合
- ROASが目標を下回っている
- 過剰入札の疑い
- 予算超過

### CPC調整の幅
- 一度に大きく変えない（±20%以内）
- 1週間程度様子を見て再調整

## 商品別の戦略

### 高粗利商品（粗利率40%以上）
- CPC上限を高めに設定
- 多めのキーワードで露出
- 売上規模より粗利額を重視

### 中粗利商品（粗利率20-40%）
- 標準的なCPC
- 効率重視
- ROAS目標を厳守

### 低粗利商品（粗利率20%未満）
- CPC上限を低めに（商品一括20円以上で運用、個別入札・キーワード/商品名指定は40円以上でないと不可）
- 厳選キーワードのみ。個別入札が成立しない場合は商品一括で運用
- ロス・リーダー戦略でなければ広告自体を見直し

## 季節商品の運用

| 時期 | アクション |
|---|---|
| シーズン2ヶ月前 | キーワード準備、CPC低めで露出開始 |
| シーズン1ヶ月前 | CPC段階的に上げる |
| シーズン中 | CPC最大、予算集中 |
| シーズン終了直後 | 即停止・除外 |
| シーズン後 | 完全停止、来年に向けて分析 |

## 新商品の運用

| 時期 | アクション |
|---|---|
| 販売開始0-30日 | 実績収集期間、判定なし |
| 30-60日 | 初回評価、ROAS判定 |
| 60-90日 | 本格運用、キーワード見直し |
| 90日以降 | 通常運用 |

## キーワード見直しの頻度

| 頻度 | 内容 |
|---|---|
| 毎週 | 主力キーワードの実績確認 |
| 隔週 | キーワード追加・停止 |
| 毎月 | CPC調整、商品別ROAS確認 |
| 四半期 | キャンペーン構成見直し |
| 半年 | 年間戦略のレビュー |

## 改善の優先順位

1. **停止・除外**（即時、無駄を止める）
2. **CPC下げ**（赤字を止める）
3. **キーワード追加**（売上拡大）
4. **CPC上げ**（収益最大化）
5. **キャンペーン構成見直し**（中長期）

→ 「無駄を止める」が最優先。「拡大」はその後。
