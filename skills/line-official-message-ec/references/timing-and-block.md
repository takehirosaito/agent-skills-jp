# 配信時間とブロック率対策

LINEはプッシュ通知で即時に届く性質上、配信時間と頻度がブロック率を大きく左右する。

## 配信時間帯の目安

### 推奨時間帯

| 時間帯 | 特徴 | 効果 |
|---|---|---|
| 平日 12:00-13:00 | 昼休憩、開封率高 | クリックも高い |
| 平日 19:00-21:00 | 帰宅後、夕食後 | 購買検討モード |
| 土日 10:00-12:00 | 朝活・ブランチ前 | じっくり閲覧 |
| 土日 19:00-21:00 | 家族時間後の自由時間 | ECで多い |

### 避けるべき時間帯

| 時間帯 | 理由 |
|---|---|
| 深夜 22:00-翌朝 8:00 | 睡眠妨害、ブロック誘発 |
| 通勤ラッシュ 7:00-9:00 | 移動中で開封が浅い |
| 仕事中 9:00-12:00 / 14:00-18:00 | 開封が遅れ、夕方に埋もれる |

業種・客層によって最適時間は異なる。BtoB商材は平日昼、BtoCは夜の傾向。

## 配信頻度の目安

| 友だち層 | 推奨頻度 |
|---|---|
| 全友だち（一斉配信） | 週1-2回 |
| 新規友だち（ステップ） | 追加直後＋3日＋7日＋14日 |
| 既存活発層 | 週1-2回 |
| 休眠層 | 月1-2回（過剰配信は逆効果） |
| VIP層 | 月1回程度（特別感を保つ） |

### 過剰配信の閾値

毎日配信・1日複数配信は急激なブロック増加を招く。一般的な目安：

- 週3回以上の一斉配信 → ブロック率上昇傾向
- 毎日配信 → 週単位でブロック率が顕著に増加
- 1日2回以上 → 即時ブロックも発生

## ブロック率の指標

業界平均：3-5%程度（業種・運用で大きく変動）

| ブロック率 | 状態 |
|---|---|
| 〜3% | 健全 |
| 3-5% | 注意 |
| 5-10% | 配信戦略の見直しが必要 |
| 10%超 | 緊急。配信停止検討 |

ブロック率は累積で観測。新規友だち獲得が止まればブロック率は表面的に下がるが、配信効果は落ちている。

## ブロックを誘発する要素

### 内容面
- 販促・割引一辺倒（毎回値引き訴求）
- 配信目的が分からないメッセージ
- 受け手の関心と合わない商品紹介
- 煽り表現の多用（「今すぐ」「絶対」「限定」の連発）
- 長すぎる本文

### 形式面
- 配信頻度が高すぎる
- 配信時間が深夜・早朝
- 1配信に多すぎるブロック（3つ以上の連投）
- 画像の重さ（読み込み遅延）

### 信頼面
- ステマ規制違反（広告であることを隠す）
- 薬機法・景表法違反の表現
- 約束を守らない（クーポン使えない等）

## ブロック率を下げる工夫

### 配信内容の工夫
- 販促50%・情報30%・娯楽20%のバランス
- 友だち限定の有用情報（使い方ガイド・季節のおすすめ）
- ブランドストーリーや裏側を共有
- 季節の挨拶や雑談的なメッセージも取り入れる

### セグメント配信の活用
- 全配信より絞り込み配信を優先
- セグメント別に内容を変える
- 関心の低い友だちには配信を控える

### 配信タイミングの最適化
- 顧客層別の活動時間に合わせる
- 業種に応じた最適時間をA/Bテストで発見
- 災害・社会情勢を考慮（販促色強い配信は延期）

### 配信頻度のコントロール
- 月の総通数を予算化
- 過剰配信のアラート（週3回超過で見直し）
- 休眠層・VIP層には頻度を下げる

## 配信前チェックリスト

| チェック項目 | 基準 |
|---|---|
| 配信時間帯 | 推奨帯（昼12-13時・夜19-21時） |
| 配信頻度 | 週2-3回までが目安 |
| 通知文（冒頭36文字） | フックを含む |
| 本文の長さ | 適切（テキスト500字以内、画像は意味のあるもの） |
| 画像のサイズ | プラットフォーム推奨内 |
| リンク先 | 有効、期限切れページに飛ばさない |
| クーポン条件 | 最低利用金額・期限・利用回数 |
| 法務確認 | 薬機法・景表法・ステマ規制 |
| 通数試算 | プラン上限内 |
| セグメント | 適切な絞り込み |

## ブロック率の月次レビュー

毎月以下を観測：

- 友だち増減数
- 月間ブロック数
- ブロック率
- メッセージ別の影響（どのメッセージ後にブロックが増えたか）

ブロック率が3%を超え始めたら：

1. 直近メッセージのコンテンツを見直す
2. 配信頻度を一段下げる
3. セグメント絞り込みを強化
4. 友だち限定の有用情報を増やす（販促一辺倒を避ける）

## 災害・社会情勢時の対応

- 大規模災害・感染症拡大時は販促配信を一時停止
- お見舞いメッセージ・状況説明に切り替え
- 該当地域のみセグメントで配信停止
- 配信再開時は配慮した文面（突然のセール訴求は反感）

## 「友だち追加直後」と「長期友だち」の温度差

| 期間 | 状態 | 推奨配信 |
|---|---|---|
| 追加〜1週間 | 期待値高、関心高 | ステップ配信で教育＋初回特典 |
| 1週間〜3ヶ月 | 評価中、定着途中 | 関連商品・新着 |
| 3ヶ月〜1年 | 既存ファン | リピート促進＋VIPコース案内 |
| 1年以上 | ブランドファン | コミュニティ・先行販売 |

長期友だちには配信頻度を下げ、特別感のあるメッセージを選ぶ。短期友だちには教育的・関係構築的メッセージを優先。

## エラー時の通知

LINE Official Account Manager 上で、配信エラー・到達不能・ブロックによる失敗等が確認できる。月次のエラー件数も観測対象。

## まとめ：ブロック率を下げる10原則

1. 通知文（冒頭36文字）にフックを置く
2. 推奨時間帯（昼休憩・夜）に配信する
3. 週2-3回までの配信頻度を守る
4. 販促一辺倒を避ける（情報・娯楽も入れる）
5. セグメント配信を活用する
6. 友だち限定の有用情報を提供する
7. クーポンは条件を明確にする
8. 災害時は配信を控える
9. ブロック率3%を超えたら見直す
10. 月次でレビューする
