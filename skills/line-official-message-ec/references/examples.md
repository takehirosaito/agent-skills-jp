## 共通の品質チェック

各実例で確認すべき点：

- [ ] 通知文36文字以内、フックを含む
- [ ] 配信時間帯が推奨帯（昼休憩・夜）
- [ ] セグメントが適切に絞られている
- [ ] クーポン条件が明確（最低金額・期限・回数）
- [ ] リンク先が有効
- [ ] 法務的にグレーな表現がない
- [ ] 通数試算がプラン内
- [ ] CTAが明確（1配信1テーマ）
- [ ] 画像のサイズ・テキスト占有率が適切
- [ ] ダークモード時の表示確認
