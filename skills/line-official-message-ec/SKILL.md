# LINE公式アカウント配信メッセージ作成

## 概要

LINE公式アカウントからの配信メッセージ（通知文・本文・リッチメニュー・ステップ配信シナリオ・セグメント別訴求）を作成する。

LINEはプッシュ通知で即時届く媒体であり、配信時間・頻度・トーンがブロック率を大きく左右する。料金プランの通数試算とセグメント絞り込みを組み合わせて、コスト効率と効果を両立する設計を行う。

## ★最重要原則

**「冒頭36文字で勝負・通数試算とセグメント絞り込みで採算合致」**。
プッシュ通知に表示される冒頭36文字にフックを置き、本文より通知文を優先設計。配信は「友だち数 × 配信回数 × ブロック数」で通数が決まるため、セグメント絞り込みを前提に設計しないとコスト超過とブロック率上昇を同時に招く。

## 知識ベース（要点 + references/）

### 6種のメッセージ形式

| 形式 | 用途 | 主要KPI |
|---|---|---|
| テキストメッセージ | 短い告知・リマインダー（最大500字、要最新確認） | クリック率 |
| 画像メッセージ | ビジュアル訴求が強い商品（アパレル・コスメ・食品） | クリック率＋ブロック率 |
| カード（リッチメッセージ） | 商品1点を強く訴求＋ボタン | ボタンクリック率 |
| カルーセル | 複数商品の比較（3-10枚） | スワイプ率＋カード別クリック率 |
| クーポンメッセージ | 取得→利用の特典導線 | 取得率＋利用率 |
| リッチメニュー | トーク画面下部の常駐メニュー（6マス推奨） | マス別タップ率 |

詳細：`references/message-formats.md`

### 料金プランと通数試算

| プラン | 月額固定 | 無料通数枠 | 超過分課金 |
|---|---|---|---|
| コミュニケーション（無料） | 0円 | 〜200通 | 追加配信不可 |
| ライト | 月額固定（要確認） | 〜5,000通 | 追加配信不可の場合あり |
| スタンダード | 月額固定（要確認） | 〜30,000通 | 1通あたり追加課金 |

※具体的な料金・通数は変動。LINEヤフー社「LINE公式アカウント 料金プラン」公式ヘルプで最新確認。

通数計算式：
```
合計通数 = 配信対象人数 × 月間配信回数 × 1配信あたりブロック数
```

例：友だち10,000人・月8回・1配信3ブロック = 240,000通。スタンダード枠（30,000通）を超過し追加課金約21万通分。

通数を抑える運用：A. セグメント絞り込み／B. ブロック数を絞る／C. 配信頻度の最適化／D. 友だち数の精査。詳細：`references/plan-and-volume.md`

### セグメント別の訴求設計

| セグメント | 通知文の指針 | 配信タイミング |
|---|---|---|
| 新規友だち（追加〜2週間） | 「友だち追加ありがとうございます！初回限定[X]円OFFクーポン」 | 追加直後＋3日後＋7日後（ステップ） |
| 既存友だち（直近購入あり） | 「○○様におすすめの新作が入荷」 | 週1-2回 |
| 休眠友だち（3-6ヶ月未購入） | 「お久しぶりです！[X]円OFFクーポン限定配布」 | 月1-2回 |
| 購入直後（〜2週間） | 「[商品名]ご購入ありがとうございます。使い方ガイド」 | 購入後2-3日、7日、14日（ステップ） |
| 高単価VIP | 「VIP限定先行販売のご案内」 | 月1回程度 |

詳細：`references/segment-distribution.md`

### 配信時間・頻度・ブロック率

| 時間帯 | 効果 |
|---|---|
| 平日12:00-13:00 | 昼休憩、開封率高 |
| 平日19:00-21:00 | 帰宅後、購買検討モード |
| 土日10:00-12:00 | 朝活・ブランチ前 |
| 土日19:00-21:00 | 家族時間後 |

避ける時間帯：深夜22:00〜翌朝8:00（睡眠妨害でブロック誘発）／通勤7:00-9:00（流し見）／仕事中の午前午後。

ブロック率の指標：〜3%健全／3-5%注意／5-10%見直し／10%超で緊急。週3回以上の一斉配信、毎日配信、1日2回以上はブロック増加リスク。詳細：`references/timing-and-block.md`

## 処理フロー

### Step 1：配信目的と対象セグメントを確定
新規教育／既存リテンション／休眠復活／VIP特別／カテゴリ別 のどれか。全友だち一斉ではなく、原則セグメント絞り込み。

### Step 2：通数試算
配信対象人数 × 配信回数 × ブロック数 = 通数。プラン上限内に収まるか確認。超過する場合はセグメント絞り込み・ブロック削減・頻度調整。

### Step 3：メッセージ形式を選択
告知短文 → テキスト／1商品訴求 → カード／複数商品 → カルーセル／特典導線 → クーポン／常時導線 → リッチメニュー／教育シナリオ → ステップ配信。

### Step 4：通知文（冒頭36字）を最優先設計
プッシュ通知に出る部分。期限性・ベネフィット・パーソナライズ要素を含む。本文より先に決める。

### Step 5：本文・CTAを設計
1配信1テーマ。CTAは1-2個まで（複数CTAはタップ分散）。「クーポンを受け取る」「商品ページへ」など具体動詞。

### Step 6：配信時間帯・頻度の確認
推奨時間帯（昼12-13時／夜19-21時）、頻度（週2-3回まで）、災害・社会情勢時は販促配信を控える。

入力情報が不足する場合は冒頭に「仮定」「追加確認したいこと」を分けて明示。

## 代表例：化粧品自社EC・休眠復活（5,000人セグメント・木曜21:00配信）

ターゲット：直近6ヶ月未購入／キャンペーン：500円OFFクーポン（3,000円以上、3日間限定）

通知文（冒頭36字）：
```
【3日限定】お久しぶりです、500円OFFクーポンをご用意しました
```

本文：
```
○○のスキンケアをお選びいただいているみなさまへ。

しばらくお取り扱いがなくお寂しい想いをしておりました。
お試しいただきたい新作と、感謝のクーポンをご用意しました。

【3日間限定 500円OFFクーポン】
・3,000円以上のお買い物で利用可
・有効期限：[YYYY/MM/DD] まで

季節の変わり目、お肌のコンディションを整える時期に。

[クーポンを受け取る]
[新作スキンケアを見る]
```

通数：5,000人 × 1配信 × 2ブロック（テキスト＋クーポン） = 10,000通。ライトプラン枠内。

他5パターン（食品ステップ／アパレル楽天新作告知／コスメVIPサンプル／家電セール／法人BtoB）は `references/examples.md`。

## 品質ゲート

- 通知文36字以内でフックがある（「○○」「□□」だけのプレースホルダーが残っていない）
- 1配信1テーマ（複数テーマ混在で焦点分散していない）
- クーポンに最低利用金額・有効期限・利用可能店舗が明記されている
- 楽天等のモール規約：店外（自社EC・LINE）への誘導を含むメルマガ配信は規約違反になり得るため、各モールルールを確認
- ステマ規制：広告主が依頼するインフルエンサー協業時に「広告」「PR」表記、投稿冒頭または常時表示
- 化粧品：効能効果は薬機法56効能の範囲内
- 健康食品：トクホ・機能性表示・栄養機能・一般食品のカテゴリで言える範囲を守る
- 配信時間が深夜・早朝になっていない
- ブロック率3%超なら直近メッセージを見直す

## エッジケース

- **大型イベント（楽天SS／お買い物マラソン）期間中**：自社EC LINE配信での店外誘導はモール規約注意、楽天独自のキャンペーン期間に集中配信するとブロック率が一時上昇
- **災害・社会情勢時**：販促配信を一時停止、お見舞いメッセージに切替。地域セグメントで配信停止
- **新規追加直後の友だち**：期待値が高い時期、ステップ配信で教育（自己紹介＋初回特典＋人気商品＋使い方）
- **長期友だち（1年超）**：頻度を下げ、特別感のあるメッセージ（先行販売・コミュニティ・限定品）
- **VMC費用が出せない場合のなりすまし対策**：LINE公式アカウントの認証バッジ（青／緑）でブランド認証、未認証アカウントは検索流入が落ちる

## 注意事項

- 料金プラン・通数枠・追加課金単価はLINEヤフー社の改定で変動。契約前に公式ヘルプ・営業窓口で最新確認
- メッセージ形式の仕様（テキスト最大字数・画像サイズ・カルーセル枚数）も変動するため公式仕様確認
- アカウント停止・規約違反による配信制限の可能性あり（過剰販促・迷惑配信は運営判断）
- ブロック率は累積で観測、新規友だち獲得が止まると表面的に下がっても配信効果は落ちている
- 「No.1」「最安」「絶対」「保証」「完全」「治る」等の根拠なし断定表現は使わない
- 個人情報・特定顧客の購買履歴をメッセージ本文に直接書かない（パーソナライズはトークン置換のみ）
