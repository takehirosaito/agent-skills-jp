# A+コンテンツ 画像作成ガイドライン

## 解像度の基本

各モジュールの推奨サイズは `modules-basic-17.md` 参照。実務では Retina ディスプレイ対応のため、**仕様サイズの2倍**で書き出し、PNG/JPEG どちらでも 1ファイル 5MB 以内が目安。

| モジュール画像 | 推奨サイズ | 2x書き出し |
|---|---|---|
| 会社ロゴ | 600×180 | 1200×360 |
| シングルハイライト | 300×300 | 600×600 |
| 4イメージ&テキスト | 220×220 | 440×440 |
| マルチイメージA | 300×300 | 600×600 |
| ヘッダー | 970×600 | 1940×1200 |
| イメージヘッダー | 970×300 | 1940×600 |
| シングルレフト／ライト | 300×300 | 600×600 |
| Premium フルスクリーン | 1464×600 | 2928×1200 |
| Premium モバイル背景 | 600×450 | 1200×900 |

## カラープロファイル

- **sRGB必須**（CMYKは表示崩れの原因）
- 印刷物データを流用する場合は必ずsRGB変換
- グレースケール画像も sRGB プロファイル付きで書き出す

## ファイル形式

| 用途 | 推奨形式 |
|---|---|
| 写真（人・物・風景） | JPEG（品質80〜90%）|
| 図版・アイコン・ロゴ（透過必要）| PNG-24 |
| 図版・アイコン（透過不要） | JPEG または PNG-24 |
| 動画（Premium） | MP4（H.264）|

TIFF・GIF・BMP は使用しない。

## テキスト占有率

Amazon のメイン画像では占有率の規定があるが、A+モジュール画像には**明確な数値規定はない**。ただし以下が実務的に安全：

- **画像全体に対するテキスト占有率 20% 以内**
- 大量の文字を画像に焼き込むのは避ける。テキストはモジュールの見出し・本文に分離する
- 「画像内テキストが多い＝検索アクセシビリティが下がる」傾向（読み上げ・翻訳に乗らない）

## 推奨される画像パターン

### ヘッダー（970×600）
- 主役の商品 or 使用シーンを大きく配置
- テキストは上部または左右に短い見出し1〜2行
- 余白を多めに取ってブランドトーンを表現

### 4イメージ&テキスト（220×220 × 4）
- 4枚で統一感（カラートーン・撮影距離・背景）
- アイコン化・図版化も有効
- 各画像内に小さなアイコンを置き、見出しはモジュール側で

### シングルレフト／ライト（300×300）
- 商品のディテール・素材感を見せるマクロショット
- 質感が伝わる照明と被写界深度

### マルチイメージA（300×300 × 4）
- 4つのベネフィットを「ビジュアルで」見せる
- 例：朝・夜・季節・部位別の使い分けカット

### 比較表（モジュール11）の商品画像
- 各商品の正面カットを白背景で揃える
- 背景・ライティングを揃え、商品間の比較性を確保

## 撮影・素材調達時のチェック

- 商品単体カットを最低でも前後左右4方向
- 主要部位のマクロ
- 使用シーン（屋内・屋外・対象顧客が映る）
- パッケージ単体
- サイズ感が分かる引きカット（手・テーブル・人物との比較）
- 素材アップ（生地・素材表面）

## NGになりやすい画像表現

- 期限固定文字（「○月○日まで」「セール中」）
- 価格表記（A+は永続表示でセール価格と整合しない）
- 競合他社の商品・ロゴが映り込む
- 効能効果の断定（医薬品的・誇大）
- レビュー★や受賞バッジを根拠なく配置
- 「No.1」「業界一位」を画像内に焼き込む（根拠5項目が画像で示せないため）

## 撮影前のブリーフ項目

デザイナー／カメラマンへ渡すブリーフに必ず含める：

| 項目 | 例 |
|---|---|
| 商品 | （商品名・ASIN）|
| 用途モジュール | （番号と名称）|
| 出力サイズ | （×2まで指定）|
| 背景 | 白／木目／グリーン etc |
| ライティング | 自然光／スタジオ |
| 主役の構図 | センター／2/3 |
| テキスト要素 | 見出しのみ／なし |
| カラートーン | 暖色／寒色／ニュートラル |
| 参考画像 | URL or ファイル |
| 納品形式 | JPG/PNG、sRGB、5MB以下 |
