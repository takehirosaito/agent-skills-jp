# クーポン名・訴求文の型・NG表現

## クーポン名の型（30字以内目安）

| 型 | 例 |
|---|---|
| 金額型 | 「全品500円OFFクーポン」 |
| 率型 | 「全品10%OFFクーポン」 |
| 条件型 | 「5,000円以上で500円OFFクーポン」 |
| イベント型 | 「お買い物マラソン限定500円OFF」 |
| カテゴリ型 | 「[ジャンル名]対象10%OFF」 |
| 期間型 | 「土日限定500円OFFクーポン」 |
| 顧客型 | 「会員ランク別5%OFFクーポン」 |

### NG例
- 「絶対お得！全品半額！」（最上級表現・根拠不明・誇張）
- 「業界最安値クーポン」（No.1根拠なし）
- 「○○ショップだけの神クーポン」（過度装飾）

### クーポン名のコツ

1. **金額か率かは購入動機による**。低単価商品は「500円OFF」が分かりやすい、高単価は「10%OFF」のほうがインパクト
2. **最低購入金額の条件は名前に含める**（「5,000円以上で」）と顧客の混乱が減る
3. **記号は控えめに**。【】や◆◇は楽天の独自審査で問題になる場合がある

## バナー訴求文（150字以内）

### 構成テンプレート

```
[期間／対象] + [値引き内容] + [使い方／条件] + [緊急性／希少性]
```

**例**：
> 楽天スーパーSALE限定！店舗内全商品で使える500円OFFクーポンを配布中。お買い上げ5,000円以上でご利用いただけます。配布期間中はメルマガ・LINE限定商品も対象。先着3,000枚限定、なくなり次第終了。

### NG例
> 「お得すぎる！」「絶対買い！」「○○女子に人気No.1のお店から！」 → 根拠なし・有利誤認・No.1根拠不明

## 商品ページ併記文（80字以内）

商品ページで「このクーポンが使えます」と告知する短文。

**例**：
> 5,000円以上で使える500円OFFクーポン配布中。本商品も対象です。

**コツ**：
- 「対象です」「ご利用いただけます」と明示
- 期間がある場合は「○月○日まで」と書く
- 「お一人様1回限り」「先着3,000枚」等の条件を明示

## メルマガ・LINE向け短文

### 件名（40字以内）
- 【500円OFF】お買い物マラソン限定クーポン配布中
- 今だけ全品10%OFF｜会員ランクアップクーポン

### 本文冒頭（200字以内）
> 〇〇店をご利用いただきありがとうございます。本日からお買い物マラソン期間中、店舗内全商品で使える500円OFFクーポンを配布中です。お買い上げ5,000円以上でご利用いただけます。先着3,000枚、なくなり次第終了となります。

## 訴求文のNG表現一覧

| NG | 理由 | 代替 |
|---|---|---|
| 最安／業界最安／日本最安 | 景表法・No.1要件 | 「お得な価格」 |
| 半額／50%OFF（通常価格根拠なし） | 二重価格・8週間ルール | 通常価格を明示し、8週間ルール根拠を保管 |
| 絶対お得／必ず満足 | 断定表現・景表法 | 「ご好評いただいています」 |
| 業界初／日本初 | 根拠なき初出し主張 | 「当店オリジナル」 |
| みんなが使ってる | ステマ・誇張 | 「ご好評の○○」 |
| シミが消える／痩せる（健食・化粧品） | 薬機法 | 56効能・届出範囲内に |

## 二重価格表記の安全な書き方

OK：
- 「セール価格 4,500円（クーポン適用後）」
- 「定価4,980円→クーポン適用で4,480円」※定価＝メーカー希望小売価格が実在し、過去8週間で4週間以上売られていた価格

NG：
- 「通常価格5,000円→今だけ4,000円」※直近で値引価格でしか売っていない
- 「希望小売価格8,000円→当店4,000円」※希望小売価格の根拠なし

## 緊急性訴求の使い方

OK：
- 「先着3,000枚」（実在する枚数制限）
- 「○月○日 23:59まで」（実在する期限）
- 「お一人様1回限り」（実在する利用条件）

NG：
- 「在庫わずか！」（実在しない）
- 「今だけの特別価格！」（特別の根拠なし）
- 「もう買えなくなる！」（根拠不明な希少性煽り）
