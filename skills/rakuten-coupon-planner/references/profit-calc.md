# 粗利・ポイント計算式と検算例

## 基本式

### 売上（顧客支払総額）
```
売上 = (売価 × 数量) - クーポン値引 ± 送料
```

### 店舗の入金額
```
入金 = 売上 - 楽天システム利用料 - 決済手数料 - 店舗負担ポイント原資
```

### 店舗負担ポイント
楽天ポイントには「楽天負担分」と「店舗負担分」がある。SPU・各種キャンペーンの大半は楽天負担。**店舗が独自に設定するポイント倍率（通常倍以上の分）は店舗負担**。

```
店舗負担ポイント原資 = 売価 × 店舗負担ポイント率
```

例：通常1%（楽天負担）＋店舗独自で2%上乗せ → 店舗負担=売価×2%

### 粗利額
```
粗利額 = 入金 - 原価 - 送料負担 - その他コスト（梱包・配送・人件費按分）
```

### 粗利率
```
粗利率 = 粗利額 / 売価 × 100
```

## 検算例A：シンプルなクーポン

**前提**：
- 売価 5,000円
- 原価 3,500円（粗利率30%）
- 送料 店舗負担500円（送料無料商品）
- 楽天システム利用料 売上の5%（簡略仮定）
- 店舗負担ポイント 0%
- クーポン 500円OFF

**計算**：
- 顧客支払：5,000 - 500 = 4,500円
- システム利用料：4,500 × 5% = 225円
- 入金：4,500 - 225 = 4,275円
- 粗利：4,275 - 3,500 - 500 = 275円
- 粗利率：275 / 4,500 = **6.1%**

クーポン無しの場合：
- 入金：5,000 - 250 = 4,750円
- 粗利：4,750 - 3,500 - 500 = 750円
- 粗利率：750 / 5,000 = **15.0%**

→ **クーポンで粗利率が15.0% → 6.1% に低下**。500円のクーポンが粗利を約475円減らしている。

## 検算例B：ポイント併用

**前提**：例Aと同じ条件＋店舗負担ポイント3%

**計算**：
- 顧客支払：4,500円
- システム利用料：225円
- 店舗負担ポイント原資：4,500 × 3% = 135円
- 入金（実質）：4,500 - 225 - 135 = 4,140円
- 粗利：4,140 - 3,500 - 500 = 140円
- 粗利率：140 / 4,500 = **3.1%**

→ クーポン＋3%ポイント上乗せで粗利率は **3.1%**。実効値引はクーポン10%＋ポイント3%＋送料負担10%=合計約23%。

## 検算例C：値引率10%と販売数増加

**前提**：粗利率30%（売価5,000・原価3,500）の商品で10%OFFクーポン。販売数増加で粗利額をベースラインに戻すには何倍の販売が必要か。

**ベースライン（10個販売・クーポン無し）**：
- 粗利：(5,000 - 3,500) × 10個 = 15,000円

**10%OFF適用後（売価4,500・原価3,500）**：
- 単品粗利：4,500 - 3,500 = 1,000円
- 必要販売数：15,000 / 1,000 = **15個**
- ベースライン10個から **+50%（=1.5倍）の販売数** が必要

これが「10%OFFは販売数1.5倍が必要」の根拠。

## 値引率別の必要販売数（粗利率30%基準）

| クーポン値引率 | 値引後粗利／個 | ベース粗利15,000円に戻すための必要販売数 | 倍率 |
|---|---|---|---|
| 0% | 1,500 | 10個 | 1.0倍 |
| 5% | 1,250 | 12個 | 1.2倍 |
| 10% | 1,000 | 15個 | 1.5倍 |
| 15% | 750 | 20個 | 2.0倍 |
| 20% | 500 | 30個 | 3.0倍 |
| 25% | 250 | 60個 | 6.0倍 |
| 30% | 0 | ∞ | 採算合わない |

→ 粗利率30%の商品は **30%OFFが損益分岐**。それ以上の値引は赤字。

## 粗利率別の損益分岐値引率

| 元の粗利率 | 損益分岐となる値引率（粗利ゼロ） |
|---|---|
| 20% | 20% |
| 25% | 25% |
| 30% | 30% |
| 35% | 35% |
| 40% | 40% |
| 50% | 50% |

→ 簡単に言えば「**粗利率 = 損益分岐値引率**」。ただし送料負担・店舗負担ポイント・システム利用料を引いた **実質粗利率** で考えること。

## バンドル効果のシミュレーション

**前提**：最低購入金額5,000円・500円OFFクーポン。元の客単価4,000円。

**期待される顧客行動**：
1. 4,000円のままで離脱（クーポン適用条件未達）
2. もう1,000円足してクーポン適用（5,500円→5,000円購入）

**シナリオ2の店舗側計算**：
- 売上：5,000円（クーポン適用後）
- 上乗せ売上：1,000円分の追加商品
- 上乗せ粗利：1,000 × 30% = 300円
- クーポン値引：500円
- ネット粗利増減：300 - 500 = **▲200円**

→ バンドル金額の上乗せ粗利がクーポン値引額を超えないと、バンドル効果は赤字。粗利率50%以上の商品でバンドル設計するのが定石。

## 計算で押さえるべきポイント

- **「値引率10%＝粗利率10%減」は誤り**。粗利率は値引額が「売価」基準なので、もとの粗利率の構造で計算する
- **店舗負担ポイントを忘れない**。SPUや各種キャンペーンは楽天負担、店舗独自上乗せは店舗負担
- **送料無料化のコスト**を計上する。送料500円相当を店舗が負担している場合、実質値引きと同じ
- **システム利用料・決済手数料**はカテゴリ別に異なる。設計時は店舗カテゴリの率で計算
