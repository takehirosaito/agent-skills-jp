# 採点軸と配点（100点満点）

## A. ファーストビュー（25点）

### サブ項目

| 項目 | 配点 | 評価 |
|---|---|---|
| メイン画像のインパクト | 5 | 商品が明確、占有率適切 |
| 商品名（先頭20字） | 5 | 主要キーワード含む |
| USP訴求 | 5 | 強みが瞬時に伝わる |
| 価格表示 | 3 | 明確、送料の有無 |
| ポイント・特典 | 2 | 訴求あり |
| レビュー数・評価 | 2 | 信頼要素として表示 |
| CTA（カートボタン） | 3 | 視認性高い |

### 満点条件
- スマホ1画面で「商品・USP・価格・送料・信頼・CTA」が揃う

### 減点要因
- 商品が画像中央に無い
- 商品名先頭が「【】」等の装飾で重要語が後ろ
- 価格が見えない
- レビュー数が表示されていない

## B. 商品名（20点）

### サブ項目

| 項目 | 配点 |
|---|---|
| byte数（255byte以内） | 3 |
| 先頭20字に主要キーワード | 5 |
| ジャンル別必須属性（サイズ・色等） | 4 |
| 用途・ターゲット | 3 |
| 特典訴求（送料無料・ラッピング等） | 2 |
| 自然な日本語として読める | 3 |

### 満点条件
- 255byte以内
- 先頭20字に主要キーワード
- 用途・属性・特典がバランス良く含まれる
- スタッフィング感がない

### 減点要因
- 255byte超過
- 先頭が装飾記号で重要語が遠い
- 同じ語が5回以上繰り返し（スタッフィング）
- 競合ブランド名混入

## C. キャッチコピー（20点）

### サブ項目

| 項目 | 配点 |
|---|---|
| byte数（174byte以内） | 3 |
| USP明示 | 5 |
| 商品名と重複しすぎない | 3 |
| 特典・送料訴求 | 3 |
| レビュー数・実績 | 2 |
| 自然な日本語 | 4 |

### 満点条件
- 174byte以内
- 商品名に含まれない訴求要素
- USP・特典・実績のバランス

### 減点要因
- 174byte超過
- 商品名と内容が重複
- 抽象的な訴求のみ（「お得」「人気」だけ）
- 根拠なき「No.1」「最安」

## D. 画像構成（20点）

### サブ項目

| 項目 | 配点 |
|---|---|
| メイン画像（占有率・USP訴求） | 5 |
| サブ画像枚数（10枚以上推奨） | 3 |
| 角度違い・スケール感 | 3 |
| 使用シーン | 3 |
| スペック・比較表 | 2 |
| FAQ・不安解消 | 2 |
| 楽天規定遵守（700px・占有率20%・枠なし） | 2 |

### 満点条件
- 10-20枚で網羅
- 楽天画像規定に完全準拠
- 1枚目で売り、2枚目以降で安心

### 減点要因
- 画像3枚以下
- メイン画像で商品が小さい・分かりにくい
- 楽天規定違反（占有率超過・枠あり）
- before-after画像（スキンケアの場合）

## E. 商品説明文（15点）

### サブ項目

| 項目 | 配点 |
|---|---|
| スペック表 | 3 |
| 特徴・USPセクション | 3 |
| 比較表（自社or用途別） | 2 |
| FAQ 3問以上 | 3 |
| 送料・配送・保証 | 2 |
| HTMLレイアウトの読みやすさ | 2 |

### 満点条件
- 必要情報がすべて網羅
- FAQ 3-5問
- スマホ・PCどちらでも読みやすい

### 減点要因
- スペック表なし
- FAQなし
- HTMLが崩れている
- 「PC版だけで売れる構成」（SP対応なし）

## F. 価格・送料・ポイント（10点）

### サブ項目

| 項目 | 配点 |
|---|---|
| 価格の明確性 | 2 |
| 送料無料訴求（該当時） | 3 |
| ポイント還元訴求 | 2 |
| クーポン案内 | 1 |
| 8週間ルール根拠（二重価格時） | 2 |

### 満点条件
- 送料無料、ポイント、クーポンが分かりやすい
- 「通常価格→セール価格」表示には8週間ルール根拠
- 実質価格が魅力的

### 減点要因
- 送料が高い・別途
- 「通常価格」表示の根拠不明
- ポイント還元なし

## G. 信頼要素（5点）

### サブ項目

| 項目 | 配点 |
|---|---|
| レビュー数（100件以上） | 2 |
| 平均評価（4.0以上） | 1 |
| 受賞歴・実績（根拠あり） | 1 |
| 店舗情報・連絡先 | 1 |

### 満点条件
- レビュー多数＋高評価
- 受賞・メディア掲載歴（事実）
- 店舗情報が明確

### 減点要因
- レビュー10件以下
- 評価3.5未満
- 受賞歴を装飾的に演出（根拠なし）

## H. 法令配慮（5点）

### サブ項目

| 項目 | 配点 |
|---|---|
| 薬機法（化粧品56項目／健食NG表現） | 2 |
| 景表法（No.1・最安の根拠） | 1 |
| 二重価格8週間ルール | 1 |
| ステマ規制（PR表記） | 1 |

### 満点条件
- 化粧品・健食の効能訴求が範囲内
- 「No.1」「最安」「業界初」に根拠
- 二重価格は8週間ルール準拠
- インフルエンサー協賛時はPR表記

### 減点要因（重大）
- 「シミに効く」「アンチエイジング」「痩せる」（薬機法）
- 「最安」「No.1」根拠なし（景表法）
- 「通常価格」表示根拠なし（景表法）

## 採点の進め方

### 1. 各軸を独立で採点

軸を順番に見て、サブ項目ごとに減点。

### 2. 軸合計を計算

例：
- A. ファーストビュー = 18/25
- B. 商品名 = 15/20
- ...

### 3. 総合点を出す

各軸の合計が100点満点。

### 4. 評価

| 点数 | 評価 |
|---|---|
| 90-100 | 優秀 |
| 80-89 | 良好 |
| 70-79 | 標準 |
| 60-69 | 改善余地大 |
| 60未満 | 要見直し |

## 採点で気をつけること

### 主観を最小化
- 同じ軸を別人が採点しても近い点数
- 採点理由を明示

### 業界・カテゴリ別の補正
- ファッションと家電で重視する軸が違う
- 高単価と低単価で詳細度の必要量が違う

### 一時的な事情の考慮
- 在庫切れで一時的にレビューが少ない
- 季節外で売上が落ちている
