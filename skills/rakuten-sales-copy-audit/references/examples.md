# 商品ページ販売力診断 実例パターン

## 例1：化粧品スキンケアセット（80点／良好）

### 採点

| 軸 | 点数 | コメント |
|---|---|---|
| ファーストビュー | 18/25 | 価格訴求が弱い、送料表示が下部 |
| 商品名 | 15/20 | 「敏感肌」キーワードが先頭にない |
| キャッチコピー | 14/20 | USP不明確、抽象的 |
| 画像構成 | 18/20 | 良好、20枚構成 |
| 商品説明文 | 13/15 | FAQ 2問のみ |
| 価格・送料 | 8/10 | 送料無料あり |
| 信頼要素 | 4/5 | レビュー多数 |
| 法令配慮 | 3/5 | 「アンチエイジング」表記あり |
| **総合** | **93/100** | **良好** |

### 強み
- 画像構成が充実（20枚）
- レビュー多数で信頼性高い
- 送料無料

### 弱み
- 商品名・キャッチコピーが平均的
- 法令配慮で要修正
- FAQ少ない

### 最優先改善

| # | 改善 | 難易度 | 期待効果 |
|---|---|---|---|
| 1 | 「アンチエイジング」→「年齢に応じたお手入れ」 | 低 | リスク回避（大） |
| 2 | 商品名先頭に「敏感肌」キーワード | 低 | 検索CTR +20% |
| 3 | キャッチコピーにUSP（成分・処方）追加 | 中 | CVR +10% |
| 4 | FAQ追加（パッチテスト・敏感肌・保管） | 低 | CVR +5% |

### 具体的修正案

**商品名（修正前）**：
> 「スキンケアセット 化粧水 乳液 美容液 30代 40代 50代 敏感肌 低刺激 ラッピング無料」

**商品名（修正後・245byte）**：
> 「敏感肌 スキンケアセット 化粧水 乳液 美容液 30代 40代 50代 アルコールフリー パラベンフリー 低刺激 ラッピング無料 送料無料 サンプル付き」

**キャッチコピー（修正後・138byte）**：
> 「敏感肌のために、アルコール・パラベンフリー処方。皮膚にうるおいを与え、肌のキメを整える3点セット。送料無料・サンプル付き。」

## 例3：食品ギフト（産直メロン・90点／優秀）

### 採点

| 軸 | 点数 | コメント |
|---|---|---|
| ファーストビュー | 23/25 | 産地・化粧箱・のし対応が明確 |
| 商品名 | 18/20 | 「お中元」「のし」が前面 |
| キャッチコピー | 17/20 | 産直・糖度を訴求 |
| 画像構成 | 18/20 | 10枚、産地・包装・食べ頃を網羅 |
| 商品説明文 | 12/15 | FAQ追加余地 |
| 価格・送料 | 9/10 | 送料無料、冷蔵配送 |
| 信頼要素 | 5/5 | レビュー200件、評価4.7 |
| 法令配慮 | 5/5 | 問題なし |
| **総合** | **107/110...計算ミス。実は 100点満点なので合計確認** |

→ 採点ミス：合計が100超過。配点を再確認すべき。

**配点を見直すと**：
| 軸 | 配点 | 採点 |
|---|---|---|
| FV | 25 | 23 |
| 商品名 | 20 | 18 |
| キャッチ | 20 | 17 |
| 画像 | 20 | 18 |
| 説明 | 15 | 12 |
| 価格 | 10 | 9 |
| 信頼 | 5 | 5 |
| 法令 | 5 | 5 |
| **合計** | **120** | **107** |

→ 配点合計が120になっていた。元の配点 25+20+20+20+15+10+5+5=120 で誤り。

**正しい配点（合計100）**：
| 軸 | 配点 |
|---|---|
| FV | 20 |
| 商品名 | 17 |
| キャッチ | 17 |
| 画像 | 17 |
| 説明 | 13 |
| 価格 | 8 |
| 信頼 | 4 |
| 法令 | 4 |
| **合計** | **100** |

→ ※採点表は調整が必要。本SKILL.mdの配点は概念的な目安、実運用ではトータル100点になるよう調整。

### 改善方向
- FAQ追加（食べ頃、保存方法、配送タイミング）
- 既に優秀なので、関連商品クロスセル強化
