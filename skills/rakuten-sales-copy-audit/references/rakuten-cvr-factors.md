# 楽天独自のCVR要因

## 楽天のCVRを左右する要素

### 1. スマホ最適化

楽天の取引の80%以上がスマホ。

| 要素 | 影響 |
|---|---|
| スマホファーストビュー | 最重要 |
| スマホ商品名先頭20字 | 高 |
| 画像のスマホ表示 | 高 |
| スマホ説明文の読みやすさ | 中 |
| カートボタンの視認性 | 高 |

### 2. 楽天独自の信頼要素

| 要素 | 影響 |
|---|---|
| レビュー数 | 高 |
| 平均評価 | 高 |
| 「楽天ランキング1位」表示 | 高 |
| 送料無料バッジ | 高 |
| あす楽バッジ | 中 |
| 「最終販売日○月○日」のような期間訴求 | 中 |

### 3. ポイント・クーポン

楽天ユーザーは「ポイント獲得」を強く意識：

| 要素 | 影響 |
|---|---|
| 楽天通常ポイント | 標準 |
| SPU連動 | 高 |
| 買いまわり倍率（SS・マラソン） | 高 |
| 店舗独自ポイント上乗せ | 中 |
| クーポン適用可 | 高 |

→ ポイント・クーポンの訴求を商品ページで明示すると CVR 改善。

### 4. 価格表記

| 表記 | 影響 |
|---|---|
| 送料無料 | 大幅プラス |
| 送料別途 | マイナス |
| 「実質○○円」（ポイント込み） | プラス |
| 「通常価格○○円→セール○○円」（8週間ルール準拠） | プラス |
| 「ポイント10倍」 | 中 |

## 楽天検索順位とCVR

楽天検索結果での順位はCTRに大きく影響：

| 順位 | CTR目安 |
|---|---|
| 1位 | 10-15% |
| 2-3位 | 5-8% |
| 4-10位 | 1-3% |
| 11位以下 | 1%未満 |

→ 上位を狙う＝商品名・キャッチコピーのキーワード最適化が必要。

## レビューの影響

### レビュー数

| 件数 | CVRへの影響 |
|---|---|
| 0件 | 大幅マイナス |
| 1-9件 | マイナス |
| 10-49件 | 標準 |
| 50-99件 | プラス |
| 100件以上 | 大幅プラス |

### 平均評価

| 評価 | CVRへの影響 |
|---|---|
| 3.5未満 | 大幅マイナス |
| 3.5-3.9 | マイナス |
| 4.0-4.4 | 標準 |
| 4.5-4.9 | プラス |
| 5.0 | 大幅プラス（ただし件数次第） |

### レビュー新着頻度

最近のレビューが多いと「今買われている商品」感が出る → CVR プラス。

## カート投入率と購入完了率

カート投入後の離脱要因：

| 要因 | 対策 |
|---|---|
| 送料が予想と違った | 送料を商品ページ上部で明示 |
| 配送日が遅い | 「あす楽対応」明示 |
| 在庫切れ | 在庫状況をリアルタイム |
| クーポン適用ミス | クーポン適用方法明示 |
| 決済方法 | 多様な決済方法の明示 |

## 季節・イベントとCVR

| イベント | 影響 |
|---|---|
| 楽天SS/マラソン | CVR 1.5-2倍 |
| 5のつく日 | CVR 1.2-1.5倍 |
| ゾロ目の日（11、22） | 低（Yahoo!向け） |
| 月末・月初 | 標準〜やや高 |
| 給与日付近 | やや高 |

## カテゴリ別のCVR傾向

| カテゴリ | CVR目安 |
|---|---|
| 食品 | 3-7% |
| 化粧品 | 2-5% |
| ファッション | 1-3% |
| 家電 | 1-3% |
| インテリア | 0.5-2% |
| ベビー用品 | 3-6% |

→ カテゴリ平均と自社CVRを比較して、改善余地を判断。

## 楽天特有の購入動機

### 1. ポイント獲得目的
- 「ポイント獲得のためにここで買おう」
- SPU・買いまわりを意識した購入

### 2. 送料無料目的
- 「送料無料で買い揃えよう」
- 5,000円・10,000円ライン狙い

### 3. ギフト需要
- 「のし・ラッピング・メッセージカード対応」が決め手
- 配送日指定の重要性

### 4. ランキング・レビュー信頼
- 「ランキング上位だから安心」
- 「レビュー高評価だから良いはず」

### 5. お買い物マラソン買いまわり
- 「1ショップ1,000円以上で買い回りカウント」
- 1,000円以上の購入を狙う

## CVRを下げる典型ミス

| ミス | 影響 |
|---|---|
| スマホで商品名が省略される | 高 |
| メイン画像で商品が分かりにくい | 高 |
| 送料が見えにくい | 中 |
| 在庫状況が不明 | 中 |
| FAQがない・分かりにくい | 中 |
| サイズ表記が不正確 | 高（返品クレーム増） |
| 法令違反表現でモール独自審査 | 大 |

## CVR改善のための優先順位

### 高インパクト
1. スマホファーストビュー
2. メイン画像
3. 商品名先頭20字
4. 送料・ポイント訴求

### 中インパクト
5. キャッチコピー
6. レビュー対応
7. 商品説明文・FAQ
8. サブ画像

### 低インパクト（ただし重要）
9. 法令配慮（リスク回避）
10. 価格戦略（実質価格）

## CVR測定のタイミング

| タイミング | 測定指標 |
|---|---|
| 改善前 | ベースライン |
| 改善1週間後 | 短期効果 |
| 改善1ヶ月後 | 安定後の効果 |
| 改善3ヶ月後 | 中期効果 |

→ 改善の効果を継続測定し、当たらない改善は元に戻す。
