# 楽天ふるさと納税 返礼品ページ設計

## 概要

楽天ふるさと納税の返礼品ページ（お礼の品）の出品・原稿・写真構成・寄附金額設計を支援するスキル。返礼品は通常の物販と異なり、総務省ルール（地場産品基準・返礼割合等）に従う必要がある。ルール順守を前提に、寄附者目線の検索キーワード・内容量/配送時期の明記・レビュー獲得・年末需要への備えまで、伝わるページを設計する。自治体・中間事業者との連携が前提。

通常の楽天市場のSEO/商品名（`rakuten-seo`）とは制度・規制が異なる別領域。

## 最重要原則

**「返礼品ルール（地場産品・返礼割合・表示）を必ず順守／寄附者は容量・コスパ・配送時期で選ぶ→明記／検索される語（定期便・訳あり・人気・容量）を原稿に／配送時期と発送方法を明確に（年末は特に）／ワンストップ特例等の案内を添える」**。制度ルール違反は掲載停止・自治体の信用問題に直結する。寄附者は“いつ届くか・どれだけ入っているか”を重視する。

## 知識ベース

返礼品ページの要点：

| 要素 | ポイント |
|---|---|
| ルール順守 | 地場産品基準・返礼割合（目安3割）・適切な表示。確定は総務省/自治体に確認 |
| タイトル/原稿 | 品目・容量・特徴・配送時期・定期便/訳ありなどの検索語 |
| 内容量/規格 | 数量・重量・サイズ・賞味期限を明確に |
| 配送 | 発送時期（通年/期間限定/順次）、発送方法、年末締切 |
| 写真 | 実物量が伝わる主役カット、規格・梱包、利用シーン |
| 寄附後体験 | レビュー、ワンストップ特例/確定申告の案内、リピート（定期便） |

寄附者の検索傾向：容量重視（◯kg、◯個）、定期便、訳あり/規格外、ランキング/人気、季節（カニ・うなぎ・果物等）。年末（12月）に寄附が集中。

> 返礼品制度・基準・割合は改定される。確定は総務省/自治体/利用ポータルの最新情報で確認。

## 処理フロー

### Step 1：返礼品と前提の確認
- 品目、地場産品該当性、内容量/規格、配送時期、想定寄附金額、自治体/中間事業者の体制
不明時は仮定を置いて明示し、ルール確認を促す。

### Step 2：ルール順守チェック
- 地場産品基準・返礼割合・表示の観点で確認事項を提示（★確定は自治体/総務省）。

### Step 3：タイトル・原稿設計
- 容量・特徴・配送時期・検索語を盛り込んだタイトルと原稿構成。

### Step 4：内容量・配送・写真構成
- 数量/規格/賞味期限、発送時期/方法（年末締切）、写真の主役カットと規格カット。

### Step 5：寄附後体験・リピート
- レビュー獲得、ワンストップ特例/確定申告の案内、定期便/別品目への誘導。

```
# 楽天ふるさと納税 返礼品ページ：[品目]

## 0. 前提（品目/地場産品/配送・仮定）

## 2. タイトル案（検索語・容量・配送時期）
## 3. 原稿構成（特徴/内容量/配送/注意）
## 4. 写真構成（主役/規格/シーン）
## 5. 寄附後体験（レビュー/特例案内/リピート）
```

## 品質ゲート
- 返礼品ルール（地場産品/割合/表示）の確認を促したか
- 容量・配送時期・発送方法を明確にしたか
- 寄附者の検索語を原稿に反映したか
- ワンストップ特例等の案内を添えたか

## 注意事項
- 返礼品制度・基準は変動。確定は総務省/自治体で確認。
- 食品は賞味期限・アレルギー・保存方法を明記。薬機/景表に反する表現は不可。
- 配送時期の誤表示は寄附者トラブルの元。期間限定品は特に注意。
